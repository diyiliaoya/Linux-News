Arduino 的 299 美元 Ubuntu 驱动边缘 AI 主板已售罄

Arduino 的 VENTUNO Q 边缘 AI 主板以 299 美元的价格开启预购后迅速售罄。该主板搭载 Ubuntu 24.04 LTS，采用高通 Dragonwing IQ-8275 的“双脑”架构，配备八核 Kryo CPU、Adreno 623 GPU 和 Hexagon NPU（性能高达 40 TOPS），并辅以 STM32H5F5 微控制器用于实时电机控制。它拥有 16GB LPDDR5 RAM、64GB eMMC 存储、M.2 NVMe 扩展、Wi-Fi 6、蓝牙 5.3 和 2.5GbE 端口，支持视觉语言模型、语音识别和手势识别等边缘 AI 任务。该板卡还提供三个 MIPI-CSI 摄像头接口、40 针 GPIO 和 CAN-FD，适用于机器人及工业应用。

售价 299 美元的 Arduino VENTUNO Q 边缘 AI 主板预购已售罄。该主板运行 Ubuntu 24.04 LTS，于 8 月下旬开启预购，并迅速售罄了首批配额。

该主板面向边缘 AI、机器人和工业应用，起售价为 299 美元。Arduino 将其称为迄今“最先进的平台”，旨在“让开发者、创客、教育工作者和工程师拥有一块不仅能感知世界，还能与世界互动的板卡”。

Canonical 云与芯片合作伙伴副总裁 Cindy Goldberg 表示：“我们与 Arduino 和高通技术公司紧密合作，提供了一套‘工业级’软件栈作为起点。”

“通过在 VENTUNO Q 开发者主板上预装生产就绪的 Ubuntu 环境，我们消除了从原型到商业规模之间的障碍。”

这块主板有何不同？

它采用基于高通 Dragonwing IQ-8275 的“双脑”架构，配备八核高通 Kryo CPU、Adreno 623 GPU 和 Hexagon NPU，并搭配独立的 STM32H5F5 微控制器用于实时电机控制。

NPU 性能高达 40 TOPS，可支持在设备端运行 AI 视觉语言模型、语音识别和手势识别任务。

它还配备 16GB LPDDR5 RAM 和 64GB eMMC 存储，用于存放操作系统、AI 模型和本地数据，并带有 M.2 接口用于 NVMe Gen4 存储扩展。Wi-Fi 6、蓝牙 5.3 和 2.5Gb 以太网端口也内置其中。

视觉负载是主要应用场景，因此该主板拥有三个 MIPI-CSI 接口，并可通过 JMEDIA 排针额外提供两个接口。HDMI 和 USB-C DisplayPort、两个 USB 3.0 Type-A 端口以及一个用于供电的桶形插孔也包含在内。

40 针 GPIO 排针允许使用现有的 Arduino 和 Raspberry Pi 扩展板，而 CAN-FD 则为专业电机控制器和工业网络提供连接能力。

VENTUNO Q 预装 Ubuntu 24.04 LTS 和 Arduino App Lab IDE，但也支持 Zephyr Project 实时操作系统。Debian 支持将于今年晚些时候推出。

如需深入了解该主板的技术规格，可访问 LinuxGizmos，或访问 Arduino 官网的产品页面（如果你不介意大量营销宣传的话）。

截至本文撰写时，VENTUNO Q 的预购已售罄，但部分经销商仍接受预订，因此值得从商店链接查看你所在国家的经销商是否有货。

这不是一款通用型单板计算机；它专为边缘 AI 和机器人应用而设计。如果你只想在 Ubuntu 上运行 Kodi、复古模拟器，或在 Firefox 中观看 YouTube，市面上有更快、更便宜的选择——尽管它们不再像以前那样便宜了。
