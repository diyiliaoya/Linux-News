高通发布补丁，为其骁龙 X2 Mahua SoC 启用 GPU 支持

高通为骁龙 X2 系列中定位较低的 Mahua SoC 发布了开源 GPU 驱动补丁，以启用其 Adreno X2-85 GPU。相比 X2 Elite 所用的 Glymur，Mahua 的 GPU 切片更少、内部显存更小，因此仅需少量内核图形驱动代码即可支持。这些补丁已提交至 Linux 内核邮件列表并进入代码审查阶段。

高通发布补丁，为其骁龙 X2 Mahua SoC 启用 GPU 支持

2026年9月24日 晚上08:25 EDT。

昨天，高通在骁龙 8 Elite Extreme Gen 6 发布一天后，为其 Adreno 850 GPU 发布了开源 GPU 驱动补丁。昨天高通还公布了其骁龙 X2 的 Linux 支持计划。今天，他们又发布了针对定位较低的骁龙 X2 SoC 中 Mahua SoC 的 GPU 启用补丁。

高通此前已将其对骁龙 X2 Elite 的初步 GPU 支持上游化，现在这一支持正扩展至较低端的 X2 硬件。Mahua 是骁龙 X2 在较低 10 核和 12 核配置下的 SoC 代号，定位低于代号为 Glymur 的 X2 Elite。

今天发布到 Linux 内核邮件列表的补丁启用了 Mahua 的 Adreno X2-85 GPU，并指出与 Glymur 相比，其切片更少、内部显存更小。最终，启用 Mahua 的 GPU 只需要几十行新的内核图形驱动代码。

感兴趣的人可以在内核邮件列表中找到高通发布的这些 Mahua GPU 补丁，目前正在接受代码审查。
