Euro-Office（ONLYOFFICE 分支）现已推出桌面应用

Euro-Office 是 Nextcloud 支持的 ONLYOFFICE 分支，现已推出名为 Nextcloud Office Desktop 的桌面客户端，用户无需自建服务器即可离线使用。该套件基于 ONLYOFFICE 桌面编辑器，提供文字处理、电子表格、演示和 PDF 工具，支持微软 OOXML 和开放文档格式，并可连接服务器协作。目前提供 Windows、macOS 和 Linux 安装包，但尚无 Flathub 或 Snap 版本。

Euro-Office，这个由 Nextcloud 支持的 ONLYOFFICE 分支，现在可以作为 Nextcloud Office Desktop 下载并安装到桌面上了。

Euro-Office 于 2026 年 3 月发布，是欧洲地区替代 Microsoft 365 的方案，也是 ONLYOFFICE 的一个分支。目前用户可以在服务器上运行和托管（或付费请人托管），然后通过网页浏览器或移动应用访问。

现在不再需要这样做了，Nextcloud Office Desktop 是一个桌面客户端，安装和使用方式与传统桌面办公套件一样。你不需要托管服务器或保持在线就能使用；它是一个离线套件。

Nextcloud Office Desktop 基于 ONLYOFFICE 的桌面编辑器构建，所以如果你用过那个套件，就会熟悉这里提供的内容：功能丰富的文字处理器、电子表格、演示文稿和 PDF 工具。

它可以打开 Microsoft Office 的 OOXML 文件（如 DOCX、XLSX 和 PPTX），以及开放格式（如 ODT、ODS 和 ODP），并能连接到 Nextcloud 或其他服务器进行协作编辑。它还支持插件和“自带”AI 功能。

该套件在本地运行的一个好处是，可以选择已安装的字体。如果你需要用特定字体格式化文档，或确保文件在其他系统上对他人显示一致，都可以做到。

并非所有人都对此满意

ONLYOFFICE 背后的公司 Ascensio System SIA 对 Euro-Office 的出现不太高兴，LibreOffice 也是如此，尽管原因不同。

推出 Euro-Office 的欧洲公司发表了宏大的声明，宣称要促进数字主权和开源，减少欧洲对美国大型科技公司的依赖。他们能否在这款软件再包装上打上自己的印记？

目前，这感觉很像是一个换了品牌的 ONLYOFFICE。这本身并不是坏事，Nextcloud 和 IONOS 选择它是因为其现代代码库和强大的功能集。围绕主权有如此多的营销，我希望这只是一个起点。

更多选择从来不是坏事，但同样的选择换身衣服……更像是选择的幻觉——主权也需要实质内容。但愿如此。

下载 Nextcloud Office Desktop

Nextcloud Office Desktop 可从 Nextcloud 网站下载。提供了适用于 Windows 和 macOS 的 Intel/AMD 及 ARM64 版本安装程序，以及适用于 Linux 的 Intel/AMD 版本（DEB 和 RPM）。

目前还没有 Flathub 或 Snap Store 的上架信息。如果你比我先发现，请通过提示表单或我们的社交账号告诉我，谢谢！
