Kitty 0.50 系统重启后可恢复上次会话

Kitty 0.50 终端模拟器发布，新增系统重启后恢复会话功能，可保存并还原所有窗口、标签页及滚动缓冲内容。同时引入停靠窗口、三款光标轨迹着色器，以及 Wayland 下的触摸屏支持。此外修复了远程控制密码认证绕过漏洞和多个内存安全问题。

该版本还新增了停靠窗口、三款新的光标轨迹着色器，以及 Wayland 下的触摸屏支持。

Kitty 是一款基于 GPLv3 许可、面向 Linux 和 macOS 的 GPU 终端模拟器，使用 OpenGL 进行渲染，以 C、Python 和 Go 编写。它可以将工作组织为标签页和窗口，支持七种布局，支持称为 kittens 的小型终端程序来扩展功能，并可从 shell 进行控制。

在 Linux 和 macOS 上注销后，它可以恢复你打开的窗口。

kitty 现在会在会话结束时保存每个操作系统窗口、标签页和窗口及其滚动缓冲内容，并在下次启动时恢复它们。你可以在 kitty.conf 中通过 restore_session_after_logout 开启此功能。

在 Linux 上，这需要一个支持 v3 接口的桌面门户，并且 Linux 以未加密、仅你可读的方式存储状态；而 macOS 系统会使用钥匙串中的专用密钥对其进行加密。

停靠窗口也是新增功能，它们允许你将一个窗口固定到另一个窗口或标签页的边缘。它们位于布局之外，适用于状态栏或文件树等场景。窗口停靠会随其窗口移动，而标签页停靠会一直保留，直到该标签页中最后一个常规窗口关闭。

三款新的光标轨迹着色器，包括 cursor-trail-pixiedust。使用时，它们会从移动的光标上发射粒子，产生类似 pixiedust 的轨迹。它们需要开启光标轨迹，现在也可以通过按键触发着色器。

Wayland 用户现在可以使用触摸屏，通过轻点点击、滑动滚动，以及按住手指不动然后拖动来选择其余文本。GNOME 及类似合成器上的窗口装饰也看起来原生，并使用桌面的标题栏字体和按钮布局。

该版本还修复了一个允许恶意请求绕过远程控制密码认证的缺陷，以及多个内存安全错误。

在 Wayland 上使用 GNOME 51，全部运行在虚拟机中。

通过向我的配置添加两个键绑定：

map f1 launch --type=tab-dock --dock-edge=bottom --dock-size=1 --dock-skip-focus watch -n1 date

map f2 launch --type=window-dock --dock-edge=left --dock-size=25% top

首先。窗口底部出现了一行条带，并停留在那里。我将其指向了……但只得到了一个 shell 提示符。

接下来是 F2。它在左边缘打开了一个面板，shell 为其腾出了空间。我不断按下它，每次按下都会在第一个面板旁边添加另一个面板，总共三个。

使用……打开新标签页给了我一个干净的状态，之前的视图转入后台。

接下来，我测试了三种新光标轨迹之一，将 custom_shaders cursor-trail-pixiedust 添加到我的配置并重启 kitty。每当光标在窗口中跳跃时，它都会在身后留下一串白色小斑点。

你可以使用以下 cURL 命令获取 kitty：

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

它也可在大多数主流 Linux 发行版的仓库中找到，但这些仓库在新版本方面往往滞后。以下列表可帮助你快速开始：

sudo apt install kitty

sudo dnf install kitty

从源码构建也是一种可能的安装途径。

在离开之前，请知悉你可以通过调整各种设置来随心定制 kitty。
