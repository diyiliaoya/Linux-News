发行版发布：Unraid OS 7.4.0

Lime Technology 发布 Unraid OS 7.4.0，将 Linux 内核更新至 6.18.60，并带来多项改进：Docker 容器支持多个自定义网络和内存限制，Mover 支持进度跟踪并保留硬链接，新增共享任务托盘、启动设备备份和电源按钮选项，同时修复 WebGUI 和 Unraid API 安全问题并更新基础软件包以解决已报告的 CVE。

Lime Technology, Inc. 宣布发布 Unraid OS 7.4.0，这是该公司面向网络附加存储（NAS）部署的商业 Linux 发行版的更新版本。新版本将 Linux 内核更新至 6.18.60，并为其基于 Web 的管理用户界面带来多项改进：“Unraid OS 7.4.0 现已作为最新稳定版发布。它为 Docker 容器增加了多个自定义网络和内存限制、Mover 进度跟踪、改进的文件操作、共享任务托盘，以及新的启动设备备份和电源按钮选项。此版本还包括 WebGUI 和 Unraid API 安全修复，将 Linux 内核更新至 6.18.60，并更新基础软件包以解决已报告的 CVE。亮点：多个 Docker 网络——容器模板现在可以连接到多个自定义网络，这些连接在容器更新或重建时保持不变；Docker 内存限制——Docker 添加/编辑表单在高级视图中包含内存限制字段；Mover 进度——Mover 现在跟踪进度和状态，并在移动文件时保留硬链接；共享任务托盘——从一个任务托盘管理后台操作，可从任何浏览器标签页查看实时或已完成的输出……”

要阅读完整变更列表，请访问：unRAIDServer-7.4.0-x86_64.zip

Unraid OS 是一个基于 Linux 的商业操作系统，旨在为构建和管理网络附加存储（NAS）提供易于使用且灵活的平台。Unraid 的一些主要功能包括：能够混搭不同大小的硬盘、用于管理存储、虚拟机和 Docker 容器的易用 Web 界面、防止硬盘故障的保护、通过添加更多硬盘来扩展存储的能力。
