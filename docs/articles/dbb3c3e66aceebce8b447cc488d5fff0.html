Linux 7.5 的 ChaCha AVX-512 优化在 AMD Zen 5 上带来高达 99% 的性能提升

Linux 内核的 ChaCha 流密码代码针对现代 AVX-512 处理器进行了优化，新增 16 块 AVX-512 函数，在 AMD Zen 5 上性能提升高达 99%，Zen 4 上提升 39%。该补丁已进入 libcrypto-next 分支，预计随 Linux 7.5 合并窗口提交。

Linux 内核的 ChaCha 对称流密码代码长期以来一直有一条优化代码路径，但它是为了迎合早期支持 AVX-512 的 Intel CPU（Skylake）而设计的，这些 CPU 在使用时会降频。但现在计划随 Linux 7.5 引入的调整将使代码在当今不会受此限制的 AVX-512 Intel 和 AMD 处理器上表现更好。相应地，在当前一代 AMD Zen 5 处理器上，ChaCha 性能提升高达 99%。

StrongSwan 开发者 Martin Willi 为 libcrypto 中的 ChaCha 代码添加了一个 16 块 AVX-512 函数。这使得在现代 AVX-512 处理器上性能更佳，在 AMD Ryzen AI Max Strix Halo（Zen 5）上测试，完整的 AVX-512 512 位数据路径带来了高达 99% 的提升。即使在上一代 AMD Zen 4 的 256 位数据路径上，也仍显示出高达 39% 的提升。

Martin 解释说：

“AVX-512VL 代码在 256 位 ymm 寄存器中一次最多处理 8 个块。选择该宽度是为了避免 512 位 zmm 指令在 Skylake-X 上触发的严重核心降频。

在更新的 AVX-512 部件上，这一惩罚已经消失，完整的 512 位寄存器每次调用可以加密 16 个块，对于批量流量大致将数据级并行度翻倍。因此，在 VL=64 时第二次实例化共享块宏，只有最后的跨通道转置不同。在 avx512vl 路径之上启用它，仅由 X86_FEATURE_PREFER_YMM 控制，并对大于 8 个块的输入分派到该路径。”

该补丁已排入 Eric Biggers 的 libcrypto-next Git 分支，因此预计将在年底的 Linux 7.5 合并窗口提交。
