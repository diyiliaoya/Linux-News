发行版发布：Helwan Linux 5.0

Saeed Badreldin 宣布推出 Helwan Linux 5.0，这是该项目基于 Arch 的发行版的重要更新，主要面向开发者。新版本集成了强大的系统工具，支持无缝升级，无需重装系统，并在 Nemo 文件管理器中直接集成了 Copy Path、Force Kill 等生产力工具。Helwan Linux 提供 Home、Edu 和 Dev 三种版本，分别搭载 GNOME、Xfce 和 Cinnamon 桌面环境。

发行版发布：Helwan Linux 5.0

Saeed Badreldin 宣布推出 Helwan Linux 5.0，这是该项目基于 Arch 的发行版的重要更新，主要面向开发者：

“我们自豪地宣布 Helwan Linux 5.0 发布，这一版本标志着我们发行版理念与开发的质的飞跃。Helwan Linux 5.0 的新特性有哪些？集成技术身份——我们进一步优化了强大的系统工具集，确保为开发者提供更无缝、更稳定的集成体验。革命性更新系统——我们正式宣告‘重装’时代的终结。得益于 Helwan Linux 5.0 的基础架构，用户在新主要版本发布时，无需再擦除系统或执行全新安装。持续演进——新版本支持无缝升级；您当前的系统将演变为最新版本，包含所有新程序和创新功能，且不会影响您的数据或设置。以开发者为中心的体验——我们已将 Copy Path、Force Kill 和高级进程管理等生产力工具直接集成到 Nemo 文件管理器中，以加速您的开发工作流。”

请访问该发行版的发布公告以阅读完整内容。

发行版发布：Helwan Linux 3.0

Helwan Linux 是一款基于 Arch 的 Linux 发行版，专为家庭、教育和开发用途设计。其“Home”版本搭载 GNOME 桌面，“Edu”版本使用 Xfce，“Dev”版本则配备 Cinnamon 桌面以及一系列编译器和解释器，包括 PHP 和 Rust。该项目还制作了全面的“发行版构建”手册，其中包含 Archiso 工具（用于构建自定义基于 Arch 的 ISO 镜像）和 Calamares 系统安装器的指南。
