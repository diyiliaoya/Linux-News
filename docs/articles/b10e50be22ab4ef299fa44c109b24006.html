高通发布骁龙 X2 Linux 开发者预览版

高通发布了骁龙 X2 笔记本的 Linux 开发者预览版，以 Debian 13 为参考环境，面向内核开发者、发行版维护者和硬件适配工程师。该预览版包含自定义内核和用户空间，重点推动驱动进入主线而非维护树外补丁。系统通过 systemd-boot 启动，支持 USB、PCIe、UART、I2C、SPI 等接口，Mesa 开源驱动提供 OpenGL、Vulkan 1.3 和 OpenCL 支持，显示输出、浏览器加速和 GPU 计算已可用。高通还提供了官方文档，包含两条开发路径和预构建镜像。

高通发布骁龙 X2 Linux 开发者预览版

他们为骁龙 X2 笔记本发布了一个早期开发者预览版，以 Debian 13 作为参考环境。

这是一个早期开发者预览版，面向笔记本，邀请内核开发者、发行版维护者和硬件适配工程师上手这些硬件并开始测试。

自 2025 年骁龙峰会以来，他们一直在为此打基础，而今天的推进方向是让驱动进入主线，而不是发布只有少数人能维护的树外补丁。

该预览版并非面向最终用户。

当前预览版将一个用户空间与一个自定义内核配对，初期重点是在开发者能够在这类硬件上开展任何严肃工作之前，准备好他们所需的核心组件。

系统启动通过 systemd-boot 作为 UEFI 管理器来处理，而驱动覆盖了 USB、PCIe 以及高通通用外设串行引擎，用于 UART、I2C 和 SPI 连接。

Mesa 的开源高通驱动负责图形任务，涵盖 OpenGL，Turnip 负责 Vulkan 1.3，另外还有驱动处理 OpenCL 计算。

这三方面的工作都在进行中，但显示输出、浏览器加速和 GPU 计算工作负载已经可以实现。

驱动——高通用于将计算任务从 CPU 路由到 DSP 的机制——正在被推向上游，以开放本地 AI 推理工作负载的能力。电源管理和热管理支持也是这一系列开发的一部分。

骁龙 X2 Linux 软件的官方文档概述了开发者可以遵循的两条路径。

第一条是未注册路径，你使用预构建的固件二进制文件来构建，无需高通账户即可开始。第二条需要账户，让你获得完整的固件源代码访问权限，从而从头构建一切。

如果你想完全跳过构建直接刷机，也可以使用预构建的可刷写镜像。

主机要求也因你构建的内容而异。Debian 层需要一台运行 Ubuntu 24.04 LTS 或更高版本，或 Debian Trixie 的机器。固件构建需要 Ubuntu 22.04 LTS 或更高版本的主机。

如果你想亲眼看到 Linux 在骁龙 X2 硬件上运行的实操演示，那么今年在夏威夷毛伊岛举办的（活动）就是你要去的地方！

分阶段的路线图、文档门户、公共仓库中的专用构建脚本，以及向开发者征求反馈——这是其他希望将工作上游化的芯片厂商应该注意的做法。

每一个进入主线的驱动，都意味着发行版需要携带的补丁少一个，而这最终将使这些机器在早期采用者之外也能使用。
