Ubuntu 推出 php2shell 和 eMudhra 证书修复更新

Ubuntu 发布了针对 php2shell PHP 漏洞和 eMudhra 证书颁发机构密钥泄露的安全更新。php2shell 包含两个严重漏洞（CVE-2026-109618 和 CVE-2026-109619），CVSS 评分 9.2，攻击者可未经登录通过任何 PHP 应用执行代码。Ubuntu 桌面版默认未安装 PHP，不受直接影响。证书问题方面，Ubuntu 移除了两个信任 eMudhra 的根证书。所有支持 PHP5 及以上版本的 Ubuntu 系统均受影响，建议运行 sudo apt update && sudo apt upgrade 进行更新。

Ubuntu 已针对导致网站下线的 php2shell PHP 漏洞以及 eMudhra 证书颁发机构的密钥泄露发布了安全更新。

Ubuntu 桌面版不会直接受到 php2shell 的影响，因为默认情况下不安装 PHP。证书问题更多是浏览器层面的担忧，不过 Google、Apple 等公司已于 10 月 17 日屏蔽了这些不良证书。

Ubuntu 从信任列表中移除了两个根证书，这两个证书都为 eMudhra 提供了担保。这将有助于保护那些不使用自身列表的工具。

检查你的系统是否有可用更新。

你可能已经听说过这些安全漏洞，因为过去几天里两者都获得了主流媒体的报道，尤其是 php2shell。

php2shell 是两个漏洞的统称，即 CVE-2026-109618 和 CVE-2026-109619，它们影响 PHP 解释器。该漏洞可使具有网络访问权限的攻击者无需登录即可通过任何 PHP 应用程序执行代码。

PHP 被大约[数据缺失]的网站使用，包括像本站这样基于 WordPress 的网站，因此漏洞利用的规模可能非常巨大。许多遗留网站年复一年地以最少的维护运行着过时的 PHP 版本……

在 CVSS 4.0 严重性评分标准上，php2shell 得分为 9.2——严重级别。Cloudflare 已经观察到针对这些漏洞的攻击流量，但尚未说明是否有任何攻击成功。

eMudhra 安全密钥泄露如果被利用，将允许攻击者为网站创建虚假的安全证书并冒充合法服务器。

如果你在服务器、云环境或其他认为可能涉及 PHP 的地方运行 Ubuntu，最好努力去更新（或向你的托管提供商咨询他们何时更新的详细信息）以确保安全。

所有带有 php5 或更新版本的 Ubuntu 版本均受影响，但只有仍受 Canonical 支持的 Ubuntu 版本（14.04 LTS 至 26.04 LTS，以及 26.10）将收到修复——可随其他更新一起应用：

sudo apt update && sudo apt upgrade

在服务器上，升级[数据缺失]并不总是可行的，因此可以单独升级该软件包。Canonical 表示，如果无法进行完整的系统重启，任何使用 PHP 解释器的应用或服务也应手动重启。

如果未安装 PHP，你不会获得 PHP 修复——你也不需要它——但是[数据缺失]。

虽然 PHP 仅支持 v8.1 及更新版本，但 Canonical 会为受支持的 Ubuntu 版本向后移植关键修复，因此 Ubuntu 14.04 LTS 上的 php5 也会得到修补。

Ubuntu 14.04、16.04 和 18.04 LTS 只有在启用 Ubuntu Pro 的情况下才能获得更新。
