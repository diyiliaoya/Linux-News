两款外观炫酷的 GNOME Shell 天气扩展

本文介绍了两款外观炫酷的 GNOME Shell 天气扩展。第一款以动画效果为特色，面板图标和预报卡片均带动态展示，支持多种天气后端和自动定位，但存在后台占用 CPU/GPU 过高的问题，目前仅支持 GNOME 50。第二款自称“全功能气象站”，采用图表和彩色图形展示数据，布局比传统表格更吸引人，但实际显示数据不如截图全面，缺少雷达图和天文信息，同样仅支持 GNOME 50。

我最近修订了最佳 Linux 天气应用列表，但我知道大多数人更喜欢使用面板来获取当前天气状况和未来预报数据。

GNOME Shell 的天气扩展并不匮乏。各种类型都有——有些像在面板上显示一个简单的标签，另一些则在下拉菜单中提供大量气象数据，设计各异（有些情况下，垂直长度也各不相同）。

近几个月来，我看到一批较新的 GNOME Shell 天气扩展涌现出来。今年席卷全球的酷热热浪可能让开发者们比平时更关注（并为之汗流浃背）气温。

我想我应该展示其中几款，因为它们比常见的天气预报类扩展要炫酷得多。

**提供动画点缀**

这款扩展无疑会吸引眼球。当然，它做了大多数同类附加组件所做的事，即在一个易于解析的管理器中展示预报数据，但它的实现方式完全不同。动画，宝贝！

面板上的一个图标显示当前温度和天气状况的动画图标（循环动画）。点击它会显示一个带有动画背景的预报卡片，展示当前和逐小时天气状况，以及带有温度、降水量和风速图表的 8 天预报：

动画效果展示（动作有点太多了）

气象单位可以设置为公制或英制，但无法做到比如天气用英里/小时而温度用摄氏度。提供多种天气后端，包括 Open-Meteo、Met.no 和 NOAA NWS。还支持自动定位！

该扩展的偏好设置中有动画预览，以及禁用动画的选项——你可能会想禁用。即使扩展没有打开，它也在后台持续占用我的 CPU 和 GPU（因此消耗更多电量）。

它在我撰写本文时仅支持 GNOME 50，所以如果你最近升级到了 Ubuntu 26.04，你就可以试试看。

希望它能更新以支持 GNOME 51——并修复其激进的 CPU 占用问题。

**Weather Prime——看起来很美**

Weather Prime 是一个数据丰富的小程序，自称是 GNOME 顶部面板的“全功能气象站”。

商店截图承诺了很多

顶部栏中的一个胶囊形图标显示你所在位置的当前天气状况。点击后，会打开一个下拉菜单，包含常见的大量预报数据，但以更吸引人的布局展示。

图表、圆角卡片和少量彩色图形的使用，相比其他小程序提供的电子表格式表格，是一个不错的改变。

——不知是我的位置还是后端的问题，显示给我的数据不如截图那么全面或炫酷。

我也没有实时雷达图或“天文”详细信息（潮汐、月相、日落等）的选项（我当地的报纸过去在同一版面上刊登星座运势和天气，所以天文信息对我来说本来会很有意义）。

令人愉快？当然，但并不完全像图片所暗示的那样，是面板上的迷你版（我最喜欢的 Linux 天气应用）。

好的一面是，你不需要与 API 密钥纠缠；它使用 Open-Meteo 天气源，已预配置好，开箱即用。它也支持 WeatherAPI.com，但你需要注册、生成密钥并填入应用中——而且它可能无法工作（对我来说就没用）。

它适用于 GNOME 50（Ubuntu 26.04 LTS）。也可以从该仓库安装，但由于该仓库已有 4 个月不活跃，它获得 GNOME 51 支持更新的机会，就像冬天的日光一样，转瞬即逝。
