Linux 7.4 内核加密库在 x86 与 RISC-V 上获得优化的 AES 实现

Linux 7.4 内核加密库合并了由谷歌工程师 Eric Biggers 迁移的 x86/x86_64 和 RISC-V 优化 AES 模式实现，涵盖 ECB、CBC、CBC-CTS、CTR、XCTR、XTS，使库 API 在这些架构上获得加速，同时减少冗余胶水代码。此外，开发者还为 SPARC64 提交了利用加密操作码的优化 AES-XTS 实现。

Linux 7.4 内核加密库在 x86 与 RISC-V 上获得优化的 AES 实现

2026 年 10 月 21 日 下午 04:11 EDT。

由谷歌工程师主导的最新 Linux 内核加密子系统性能工作，正在将不同 AES 模式的 x86/x86_64 和 RISC-V 优化实现迁移到内核加密库中，以在那里获得更快的性能。

已为 Linux 7.4 内核合并，Biggers 将 AES 模式 ECB、CBC、CBC-CTS、CTR、XCTR、XTS 的 x86/x86_64 和 RISC-V 优化实现迁移到了内核加密库空间。相应地，库 API 现在在这些架构上得到了适当加速，同时也仍然加速 crypto_skcipher 的使用。在 Intel/AMD x86_64 CPU 上，这意味着利用 AVX 优化代码以及 AES-NI 指令。

这位 Linux 内核加密专家解释说，除了这些优化实现带来的加速之外，它还移除了大量冗余的胶水代码和代码重复。

另外，在 Linux 7.4 的加密库更新中，开源开发者 Stian Halseth 为 SPARC64 编写了一个优化的 AES-XTS 实现。新实现利用了 SPARC 的加密操作码。在 2026 年看到新的 SPARC 加密优化，并不是我预期会写到的内容……
