AMD EPYC 9006 Venice 与 NVIDIA Vera 的 HPC 性能基准对比

发布于 2026 年 11 月 11 日上午 10:44（美国东部时间）。

在昨日 AMD EPYC 9006 "Venice" SP7 平台的发布测试中，包含了针对 AMD EPYC 9996 256 核处理器以及高频型号的评测。当时有数百项基准测试，考察了从 EPYC Turin 到 EPYC Venice 的世代性能提升，以及与 Intel Xeon 6 Granite Rapids 的竞争情况。对于那些想知道 AMD EPYC Venice 如何与 NVIDIA Vera CPU 竞争的人来说，本文提供了一系列 HPC 工作负载下的对比结果。

由于无法持续远程或物理访问 NVIDIA Vera，在对比 Vera 与 Venice 的数据时，我不得不复用几周前上一轮 Vera 基准测试中的部分数字。具体来说，就是上个月的《NVIDIA Vera HPC 性能基准挑战 AMD EPYC 与 Intel Xeon》。由于软件栈存在差异，我不得不在 Venice 上单独进行额外测试，与昨日发布测试分开，使用前沿的 Ubuntu 26.10 搭配 Linux 7.3 内核。因此，这篇独立文章用于对比 Vera，而此前那篇文章中针对 EPYC/Xeon 的测试则是在 Ubuntu 26.04 LTS 上进行的。默认编译器使用 GCC 15，因为 Vera 也使用了该版本。GCC 16 才引入 Znver6 支持，若时间允许，我将发布更多针对 Venice / Zen 6 的专用编译器基准文章。

除了查看原始性能外，整个基准测试过程中还监测了峰值 CPU 频率和 CPU 功耗。
