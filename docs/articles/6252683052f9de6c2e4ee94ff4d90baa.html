操作系统发布：ReactOS 0.4.16

该项目开发一个开源操作系统，旨在与为 Microsoft Windows 创建的软件和驱动程序兼容。该项目的最新版本将其两个版本合并为一个，并引入了新的图形化系统安装程序。

“我们很高兴地宣布 ReactOS 0.4.16 的发布。经过一年半的开发，我们很高兴展示我们所做的改进，包括新的图形化安装程序、统一的启动光盘和 Live CD 镜像、视频、音频、网络和存储堆栈的改进、新的安装类型以及第三方代码同步。历史上，ReactOS 提供两个镜像供下载 - 一个 Live CD，让您在只读环境中测试 ReactOS，以及一个启动光盘，让您使用基于文本的安装程序将 ReactOS 安装到硬盘上。得益于 Hermès Bélusca-Maïto 的努力，ReactOS 0.4.16 有了新的图形化安装程序和合并的启动光盘与 Live CD。现在您可以使用同一个镜像来测试和安装 ReactOS。在 0.4.15 开发期间，核心开发者 Hervé Poussineau 为多显示器支持以及当显示驱动程序加载失败时回退到 VGA 驱动程序奠定了基础。这个基础使我们能够在 0.4.16 中继续追求更好的视频驱动程序兼容性。”

ReactOS 是一个免费开源的操作系统，基于 Windows NT 架构中最佳的设计原则。完全从头编写，ReactOS 不是基于 Linux 的系统，也不共享任何 UNIX 架构。ReactOS 项目的主要目标是提供一个与 Windows 二进制兼容的操作系统。这将允许 Windows 应用程序和驱动程序像在 Windows 系统上一样运行。此外，其外观和感觉与 Windows 相似。
