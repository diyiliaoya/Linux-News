D7VK 2.1 带来更快的加载时间和更多性能优化

2026年8月14日 下午4:26（美国东部时间）

D7VK 作为基于 Vulkan API 的 Direct3D 7/6/5/3 开源实现，用于 Linux/Wine 环境，现已推出新的功能更新。D7VK 持续成熟，进一步增强了这些较旧的 Direct3D API 版本，这些版本覆盖了 DXVK 所专注的 Direct3D 8 至 Direct3D 11 或 VKD3D-Proton 的 Direct3D 12 之前的范围。

在最近的 D7VK 版本中看到了大量性能改进之后，D7VK 2.1 在加载/启动方面做了更多工作。虽然这类老游戏通常不会有加载时间问题，尤其是在现代硬件上，但 D7VK 进行了增强，以加速对象创建/销毁、缓存等。与之前的 D7VK 版本相比，一些游戏的加载时间现在缩短了一半。

D7VK 2.1 还加入了一些额外的性能调整，以更好地支持不同的游戏，例如《生化危机2》和《地球帝国：征服的艺术》。

总体而言，D7VK 2.1 对于那些希望在 Wine/Proton 上通过 Vulkan API 享受老游戏的用户来说，似乎处于非常稳健和可靠的状态。今天的 D7VK 2.1 版本的下载和更多详细信息，请访问 [相关链接]。
