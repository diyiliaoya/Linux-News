十月的 Linux 应用发布带来了许多惊喜、几个小把戏，以及 thankfully 极少的惊吓。在这篇文章中，我将回顾上个月发布的更新。

阴影中还有其他幽灵在聚光灯下。十月给我们带来了双重打击：前者新增了……，后者新增了……——以及两者各自的其他变化。

它还带来了一个“完全重建”的……，带有可选的 AI 工具，以及……，后者新增了期待已久的 Wayland 自动输入支持。系统清理工具 BleachBit 修复了管理员清理相关的问题。

随着 2026 年 10 月已经入土为安，以下是桌面上悄然出现的其他内容。

OpenShot 4.1 新增原生文本输入

视频编辑器近来势头强劲，新增了数十项长期请求的功能，如色彩分级和屏幕捕获。

OpenShot 4.1 延续了这一趋势，首次推出新的画布文本工具，使创建下三分之一字幕、说明文字和片尾字幕更加容易，无需使用 SVG 或 Blender 标题，也无需打开……对话框。该对话框也经过重新设计，以便更轻松地自定义屏幕文本元素的外观，并在不同文本元素之间复制样式。

该视频编辑器原有的自动优化功能——为编辑创建更小、优化的视频片段副本，但导出全质量版本——现在能检测更多适合优化的片段。

由于这款视频编辑器现在由 LLM 编写代码，其自身对 AI 相关工作流的支持扩展也不足为奇。

新增了用于导出和基本编辑的 CLI 自动化，以便用户可以通过“提示”Claude Code 等代理工具来执行任务。

除此之外，还有更新的导出对话框、更多键盘快捷键、关键帧和时间线调整，以及时间线、预览文件等方面的常规性能改进。

OpenShot 4.1 可从 OpenShot 网站、……、Flathub 或 PPA 下载——OpenShot PPA 现在有 Arm64 构建版本。

FBReader 2.5 推出新书库

跨平台电子书阅读器……发布了其即将推出的 2.5 版本的候选版本，适用于 Windows、macOS 和 Linux（在我撰写本文时又发布了第二个候选版本）。

最大的变化是重新设计的书库视图，现在支持收藏夹、自定义书架和批量操作。还集成了……书店，在英国、美国和澳大利亚默认启用，可在应用内浏览和购买书籍。

另一个新集成是……“用于收集和组织来自不同阅读平台（包括 Kindle 和 Kobo）的书籍高亮和笔记的服务”。

在桌面上，FBReader 2.5 可以使用系统文本转语音引擎朗读书籍。它还可以播放 EPUB 文件内的音频和视频内容，并打开 CBR 和 CB7 漫画档案。还新增了 OPDS 2.0 目录支持。

稳定的 2.5 版本预计将在未来几周内发布。

从……下载最新的 Linux 候选版本。

Thunderbird 159 为托盘图标添加标记

……发布了，为 Linux 用户带来一个惊喜：系统托盘图标上的未读邮件指示器，以及工具提示中显示的消息计数。细节决定成败，对吧？

其他变化主要是驱除 bug，包括附件丢失或截断、消息搜索损坏、打印行为挑剔以及 CalDAV 和 CardDAV 同步问题。

其他增强提升了性能和可靠性，例如抑制过多的 Microsoft Graph 请求、减少格式错误的消息数据库导致的 CPU 使用率，以及平滑恢复打开的标签页时的启动挂起。

从……下载最新版本。

OBS Studio 33.0 重构插件

……悄然发布，这是流行直播和录屏软件的一次较大更新，改变了插件的安装位置，内置和第三方插件现在放在不同位置。现有安装了插件的安装不受影响，直到 v34.0。

预览窗口改进了源吸附，带有视觉指示器显示每个源的边缘位置，并允许它们吸附到另一个源的对应边缘。隐藏的源在定位可见源时不再被选中或触发。
