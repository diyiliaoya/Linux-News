Ubuntu Touch 向 Ubuntu 26.04、Vulkan 及应用更新稳步推进

2026年8月2日 上午06:37（美国东部时间）

继上周发布由社区维护的 Ubuntu Linux 移动版本 Ubuntu Touch 24.04-2.0 之后，现在有更多关于其后续开发工作以及最终过渡到 Ubuntu 26.04 基底的详细信息。

Ubuntu Touch Q&A 195 现已发布（虽然其报告日期为7月25日，但直到昨天才出现在其 RSS 订阅中），其中概述了当前开发工作以及未来版本的发展路线图。随着 Ubuntu Touch 24.04-2.0 的发布，目前在某些场景下已部分支持 Vulkan，支持用于 DRM 内容流媒体的 Widevine，浏览器更新，以及改进的设备加密处理等。

正在进行的一些开发工作包括：PulseAudio 集成更新，基于 Halium 16 的移植以支持更新的 Android 设备，内核补丁以实现冻结用户进程而非休眠以延长电池寿命，以及使用 Waydroid 支持 Play Integrity API 的实验。如果他们能够实现 Play Integrity 支持，就可以在 Ubuntu Touch 上运行一些 Android 银行应用等。

许多 Ubuntu Touch 应用最近已更新并持续获得新功能，Snap 包中的 Vulkan 支持正在开发中，同时还有各种安全改进。

Ubuntu Touch 24.04-2.1 计划在最近的 -2.0 版本基础上提供小幅改进和修复。但更大的里程碑是转向 Ubuntu 26.04 LTS 基底的 Ubuntu 26.04-1.0。目前尚无 Ubuntu Touch 26.04-1.0 的发布时间表，但这是一个正在努力实现的目标。更多详情请参阅：
