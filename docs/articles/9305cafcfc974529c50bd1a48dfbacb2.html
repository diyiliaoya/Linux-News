Linux 7.4 网络功能带来硬件节奏卸载、新驱动及更多性能提升

2026年10月29日上午08:55 EDT。

本周，针对正在进行的 Linux 7.4 合并窗口，大量 Linux 有线和无线网络驱动改进已被合并。

Linux 7.4 核心网络代码的新增功能是硬件节奏卸载（hardware pacing offload）功能。这包括为网络设备新增的 "pacing_offload" 属性。IDPF 驱动是首个接入该节奏卸载功能支持的驱动，该功能将传出网络数据包的时序和间隔控制卸载到网卡/智能网卡（NIC/SmartNIC）。

核心网络代码中还包含对混合 BIG TCP / 非 BIG TCP 代码路径吞吐量的改进，吞吐量提升最高可达 70%。此外，在性能方面还有一些围绕高效缓存使用和减少竞争的 TCP/IP 性能改进。在 Linux 无线方面，也有一些降低延迟的改进。

Linux 7.4 内核还在继续推进围绕 WiFi Aware 和其他 WiFi 8 功能的更多工作。

在网络驱动方面，包括初始的 Nebula Matrix NIX 驱动代码，以及 Meta Platforms 的网卡 "MPNIC" 作为 Mesa 的第二代网卡。第一代 Meta 网卡配合 FBNIC 驱动现在支持大型 IO_uring 零拷贝接收缓冲区。

高通 PPE 驱动新增了对 IPQ5424 芯片组的支持。Synopsys STMMAC 驱动新增了对 RK3568 SGMII、Allwinner H616 EMAC1、UltraRISC DP1000 和高通 sa8255p 的支持。

在 Realtek PHY 驱动方面，新增了对 RTL8261CE_CG 和 RTL8261D_VM 的支持。同时，Realtek RTW88 驱动新增了对 RTL8723BS 的支持，取代了内核暂存区中基础的 rtl8723bs 驱动。

最后，联发科蓝牙驱动新增了对 MT7928 的支持，高通蓝牙代码现在支持 QCC2072。
