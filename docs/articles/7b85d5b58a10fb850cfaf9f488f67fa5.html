Firefox 160 发布：支持语音转文字，可播放含 FLAC/MP3/PCM 音频的 MKV 文件

Firefox 160 稳定版发布，新增对含 FLAC、MP3 或 PCM 音频的 Matroska（MKV）文件播放支持，并集成 Web Speech API 的语音识别功能，实现设备端实时语音转文字，支持 40 种语言。此外，画中画播放器新增 0.25 倍至 2.0 倍速的播放语音设置，地址栏域名对比度也有所提升。

Firefox 160 发布：支持语音转文字，可播放含 FLAC/MP3/PCM 音频的 MKV 文件

2026 年 11 月 9 日 06:12 PM EST 发布。

Firefox 160.0 发布版本现已可用，这是 Mozilla 网络浏览器最新的双周稳定版更新。

Firefox 160 现已支持播放带有 FLAC、MP3 或 PCM 音频的 Matroska（MKV）文件。一年前 Mozilla 曾表示，由于使用率低，支持 MP3 的 Matroska 不在其功能计划中，但最终他们决定在支持 FLAC 和 PCM 音频的同时也实现对 MP3 的支持。

Firefox 160 的另一个显著变化是 Web Speech API 的语音识别部分，用于支持设备端实时语音转文字。Firefox 中集成的语音转文字支持可处理 40 种不同语言。

Firefox 160 还为画中画播放器新增了播放语音设置，速度从 0.25 倍到 2.0 倍。

此外还有一些界面优化，例如提高了地址栏中域名与其余地址之间的对比度。
