发行版发布：Koozali SME Server 11.0

Koozali SME Server 11.0 正式发布，基础系统从 CentOS 迁移至 Rocky Linux 8.10，支持周期延长至 2029 年。本次更新重点包括现代化改造、硬件支持增强、管理工具改进，并保留长期使用的模板系统。邮件服务器引入 Postfix 处理邮件提交，同时保留 Qpsmtpd 确保向后兼容。软件包管理集成 Koji 构建系统和 Git 版本控制。

Terry Fage 宣布发布 SME Server 11.0。这个服务器发行版的最新版本将其基础从 CentOS 迁移到 Rocky Linux，并对 Web 界面进行了全面改造。

"Koozali SME Server 开发团队很高兴地宣布发布 SME Server 11.0，这是 Koozali SME Server 的下一个主要版本。此版本基于 Rocky Linux 8.10。Rocky Linux 8.10 的 EOL（生命周期终止）日期为 2029 年 5 月 31 日。Koozali SME Server 11 标志着一个重大升级，从 CentOS 过渡到 Rocky Linux 8，以实现长期稳定性和安全性。此版本侧重于现代化、改进的硬件支持以及增强的管理工具，并保留了长期使用的模板系统，该系统使 SME Server 成为一款简单且健壮的服务器管理工具。主要功能和更新：基础操作系统升级——过渡到 Rocky Linux 8.10，取代 CentOS，确保持续的稳定性和支持；软件包管理增强——与 Koji 构建系统和 Git 版本控制集成，实现简化的 RPM 软件包构建和仓库管理；邮件服务器改进——引入 Postfix 用于邮件提交，同时保留 Qpsmtpd 用于最终投递，以确保向后兼容。"

Koozali SME Server 是一款完整且多功能的开源 Linux 服务器发行版，适用于家庭以及中小型企业。自 2007 年以来，它一直基于 Red Hat Enterprise Linux、CentOS 和 Rocky Linux 的源代码构建。Koozali SME Server 对任何个人或商业组织均可免费使用，仅通过捐赠获得支持。它被认为可靠且易于使用。
