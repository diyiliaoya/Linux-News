发行版发布：Gnoppix Linux 26_11

Gnoppix Linux 26_11 发布，基于 Debian Testing 分支和 Xfce 桌面。本次更新重点包括网络管理、隐私服务、本地 AI 执行能力和基础设施安全。新增 gnoppixCTL 支持特定国家独立桥接点，推出一次性电子邮件服务，后量子加密迁移接近完成，并升级了实时黑洞列表。

Andreas Mueller 宣布发布 Gnoppix Linux 26_11，这是该项目基于 Debian“Testing”分支、以 Xfce 为桌面环境的隐私加固 Linux 发行版的更新版本：“我们很高兴地宣布 Gnoppix 26.11 发布。此版本在网络管理、隐私服务、本地 AI 执行能力和基础设施安全方面带来了重大更新，同时整个系统也进行了常规更新。网络与隐私工具更新：新的 gnoppixCTL——已更新以支持来自特定国家的独立桥接点；一次性电子邮件服务（disposable.gnoppix.me）——Gnoppix Mail 生态系统的新增功能，无需注册即可获取即时临时电子邮件地址，以保护您的隐私并屏蔽您的收件箱；Gnoppix 后量子信使——我们向仅后量子加密的迁移已接近完成，此版本引入了 0.4.6 版 Tor 消息支持，可通过 Tor SOCKS5 代理进行点对点通信；开发状态——预计还需 4 至 6 个月的 CLI 开发，之后才会正式开始 GUI 界面的工作。我们已将实时黑洞列表（RBL）升级为通用格式。”请阅读余下内容以获取更多信息。
