发行版发布：LCOS 1.0.0

Bryan Lunduke 宣布推出 LCOS（Lunduke Computer Operating System）1.0.0 首个稳定版，这是一个基于 Devuan 的隐私优先、极简桌面 Linux 发行版。它承诺不要求身份或年龄验证，不内置人工智能功能，也不包含用 Rust 编写的软件克隆或内核二进制块。该系统基于定制 Linux 内核分支，采用 XLibre X11 服务器、Brave Origin 浏览器等组件，强调速度、简洁和经典桌面体验。

Bryan Lunduke 宣布推出 LCOS（Lunduke Computer Operating System）的首个稳定版本，这是一个注重隐私、极简的桌面 Linux 发行版，基于 Devuan。它承诺提供一个传统的操作系统，无需身份或年龄验证，不内置人工智能功能，也没有用 Rust 编写的软件克隆或内核二进制块。

来自发布公告：

Lunduke Computer Operating System（LCOS）1.0 版，一个面向台式计算机的 Linux 兼容系统，已正式发布，可供所有人免费下载。LCOS 之王 Bryan Lunduke 表示：“LCOS 解决了当今操作系统面临的最大问题。台式计算机正遭受着我们谁都不想要的垃圾攻击——身份验证和数据收集。强制在线账户。臃肿、缓慢的软件。被硬塞进简单文本编辑器的人工智能功能。被武器化的行为准则。当然，还有奇怪的、觉醒的政治。LCOS 没有这些乱七八糟的东西。只有出色的软件。”

Lunduke Computer Operating System 1.0 由可用的最佳桌面软件构建而成：一个 LCOS 专用的 Linux 内核分支（构建时不含不必要的 Rust 模块）；来自非觉醒、非歧视、注重精英管理的开发者的高质量组件，例如：XLibre X11 服务器；Devuan 项目；Brave Origin 网络浏览器；专注于速度、简洁和经典台式计算机风格的自定义构建工具。
