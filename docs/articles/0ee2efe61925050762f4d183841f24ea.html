发行版发布：Talos Linux 1.14.0

Talos Linux 1.14.0 发布，新增 DNS over TLS 和 DNS over HTTPS 支持，增强 DNS 查询与响应的加密，提升隐私与安全性。同时，该版本引入 Btrfs 作为新的文件系统选项，并支持通过内嵌 GoBGP 服务器运行原生 BGP 路由实例，无需再以系统扩展方式提供 FRR。此外，talosctl apply-config 命令的 --mode=reboot 选项被移除，默认应用配置无需重启。

发行版发布：Talos Linux 1.14.0

Talos Linux 是一个独立开发的 Linux 发行版，专为运行 Kubernetes（一个用于自动化部署、扩展和管理容器化应用的引擎）而设计，现已更新至 1.14.0 版本。本次发布启用了对 DNS over TLS 和 DNS over HTTPS 的支持，并新增 Btrfs 作为文件系统选项：

“欢迎来到 Talos 1.14.0 版本。Talos 现在支持 DNS over TLS（DoT）和 DNS over HTTPS（DoH），以实现安全的 DNS 解析。这些功能允许 Talos 加密 DNS 查询和响应，增强 DNS 流量的隐私和安全性。DNS 协议可以在 ResolverConfig 文档中按名称服务器进行配置，从而灵活配置 DNS 解析。talosctl apply-config 命令中的 '--mode=reboot' 选项已被移除；默认情况下，配置应用无需重启。大多数配置更改不需要重启；文档列出了需要重启的更改。Talos 现在支持通过内嵌的 GoBGP 服务器在主机上运行原生 BGP 路由实例，并使用 BGPInstanceConfig 文档进行配置。这消除了在常见面向网络结构场景中，以系统扩展方式提供 FRR 的需要。”

有关更改的完整列表，请参阅发布说明。
