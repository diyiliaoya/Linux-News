KNOD 在 Linux 内核 GPU 网络数据包处理卸载方面取得进展

KNOD 是一个开源项目，旨在利用 GPU 进行内核网络数据包处理卸载。该项目通过将 XDP 程序 JIT 编译为 GPU 机器码，让网卡将数据包直接放入 GPU 可访问内存并由 GPU 处理，在消费级 GPU 上实现了每秒 7000 万包和 80 Gbit/s 的 RX IPsec 性能。在 2026 年 Linux Plumbers 大会上，开发者分享了最新进展，并计划扩展对 Intel Arc 显卡、AMD 集成显卡以及 Broadcom 和 Intel 网卡的支持。

此前我们曾报道过 KNOD，这是一种将内核网络卸载到 AMD GPU 的实验性解决方案。这个开源的 KNOD 项目允许利用 GPU 以非常高性能且节能的方式处理数据包，而无需任何专用硬件。KNOD 一直在持续发展，本周在布拉格举行的 Linux Plumbers 大会上分享了开发进展。

KNOD 继续展现出巨大的潜力，可以将 GPU 用作内核管理的网络数据包处理加速器。KNOD 会将 XDP 程序 JIT 编译为 GPU 机器码，网络适配器将数据包直接放入 GPU 可访问的内存，然后由 GPU 进行处理。最近除了最初的 XDP 程序外，还增加了 RX IPsec 功能。在消费级 GPU 硬件上，KNOD 已证明其性能可达 XDP 工作负载每秒 7000 万包，RX IPsec 达 80 Gbit/s。

KNOD 背后的开发者发现，它不仅非常具有成本效益，而且比仅使用 CPU 进行数据包处理更加节能。

虽然迄今为止 AMD GPU 一直是他们的主要目标，但在 LPC 2026 上提到，他们还将探索对 Intel Arc 显卡的支持，并且 KNOD 也将适用于 Broadcom 和 Intel 网卡。此外，还将探索 AMD 集成显卡，而不仅仅是独立 GPU。
