发行版发布：Chimera Linux 20261103（DistroWatch.com 新闻）

Chimera Linux 是一个独立开发的发行版，在底层使用了不同寻常的技术组合。该项目的最新快照引入了新的网络工具，升级了桌面环境，并搭载了 7.3 版本的 Linux 内核。

20261103 镜像集现已发布。这是一次增量更新。原本没计划花一年时间刷新镜像，但新版本终于来了。镜像本身没有什么特别之处，但伴随而来的是这一年中系统周围发生的一整套更新。对实际使用影响最显著的变化是，基础镜像现在自带 NetworkManager，取代了 iwd。这应该能让网络配置更容易，即使是没有图形界面的基础系统（无线配置等）也是如此，同时为移除 AF_ALG 做好准备。该镜像集基于内核 7.3、GNOME 51 和 Plasma 6.8。新变化是，它们都不再附带 X.Org 服务器。希望下一版不会再等一年……
