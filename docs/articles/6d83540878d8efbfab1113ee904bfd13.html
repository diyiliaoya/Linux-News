发行版发布：Omarchy 4.0.0

Omarchy 4.0.0（代号“Quattro”）是该项目自启动以来最大的一次更新。整个桌面环境已用Quickshell重新设计，将任务栏、启动器、菜单、通知、屏幕显示、控制面板、锁屏和polkit代理整合到一个长期运行的shell进程中，并采用插件架构。此版本移除了Waybar、Walker等组件，新增双启动安装、OEM预配置、恢复出厂设置等功能，ISO体积缩减至6GB以下，安装速度提升30%，并全面兼容Hyprland 0.56。

发行版发布：Omarchy 4.0.0

David Heinemeier Hansson 宣布发布 Omarchy 4.0.0，这是该项目基于 Arch 的 Linux 发行版的一次重大更新，采用 Hyprland Wayland 合成器：

“Omarchy 4 又名‘Quattro’，是自项目启动以来最大的一次发布。整个桌面外壳已在 Quickshell 中重新设计——任务栏、启动器、菜单、通知、屏幕显示、控制面板、锁屏和 polkit 代理现在都运行在一个长期运行的 shell 进程中，并采用插件架构。这意味着 Waybar、Walker、Mako、SwayOSD、hyprlock、hypridle、swaybg 和 polkit-gnome 都已移除，取而代之的是一个统一、完全主题化、可通过 IPC 脚本控制的 shell。主要特性包括：在 Quickshell 中重新设计整个桌面外壳；将 Omarchy 内部组件从 git 迁移到系统包，以安全地分离用户修改；在有空闲空间时提供双启动安装；在安装过程中为新用户配置机器，使 OEM 和赠礼者可以为他人准备设备；允许从新的 Quattro 安装进行恢复出厂设置，以便安全转售或赠送你的机器；将 ISO 镜像体积缩减超过 1GB（现在低于 6GB）；安装速度提升 30% 以上；将所有 Hyprland 配置转换为 Lua，以完全兼容 0.56 版本……如需完整更改和新功能列表，请参阅发布公告。下载地址：...
