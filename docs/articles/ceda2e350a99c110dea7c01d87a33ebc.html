Linus Torvalds 的 AI 代码获改进：重构后性能大幅提升

2026 年 10 月 19 日 12:32 PM EDT 发布。

上周我报道了 Linus Torvalds 利用 AI 通过 Claude Code 对 Linux 内核做出了一项大幅改进。该代码用于在不获取 folio 引用的情况下从页面缓存读取，以帮助跨多个 CPU 线程对单个文件进行小量读取的工作负载。Meta 工程师 Kiryl Shutsemau 接手了该代码并进行了重构，展示了极具前景的性能结果。

Kiryl 今天宣布了他的补丁系列，基于 Torvalds 上周的代码，用于调整 Linux 内核内存管理代码，以便在不获取 folio 引用的情况下从页面缓存读取。他在补丁说明中解释道：

“从多个 CPU 对单个文件进行小量读取时，所有读取都会对同一个 folio 进行引用获取和释放，其引用计数在 CPU 之间反复弹跳。本系列允许 filemap_read() 和 shmem 在不获取引用的情况下从页面缓存复制。这是 Linus 的 RFC 的重构版本：此类读取者可能从中复制的 folio 仅在 RCU 宽限期之后才会被释放。”

他随后在 EXT4、TMPFS 和 XFS 文件系统以及裸块设备上测试了改进。测试使用 AMD Ryzen Threadripper CPU 的 64 线程，分别在启用和未启用默认 CPU 安全缓解措施的情况下进行。结果非常出色：

改进非常显著。这些补丁仍被视为征求意见稿（RFC），围绕该工作还有一些开放的设计元素，但希望很快都能得到解决，并在不久的将来进入主线内核。补丁可在 Linux 内核邮件列表上找到。
