发行版发布：Ubuntu Studio 26.10

Ubuntu Studio 26.10 正式发布，这是一款面向音频、视频、图形设计、摄影和桌面出版等创意领域的 Ubuntu 官方衍生版。新版本提供九个月支持，音频工具集新增 Sonic Pi、SuperCollider 及 SuperCollider 3 插件套件，并加入 JNoise 噪声发生器，为用户带来更完整的实时编码与算法作曲工具链。

发行版发布：Ubuntu Studio 26.10

Ubuntu Studio 是一款面向音频制作、视频制作、图形设计、摄影和桌面出版等创意领域的发行版。该项目的最新版本 26.10 提供九个月的支持，并带来了一些新工具。

Ubuntu Studio 的音频软件包选择现在包括 Sonic Pi、SuperCollider 和 SuperCollider 3 插件套件，与 Ardour、Carla 以及其余音频栈一起，为您提供完整的实时编码和算法作曲工具包。此外还有 JNoise，一个简单的白/粉红噪声发生器，纯粹因其实用性而被收录，便于测试音频设置以及房间或扬声器检查。带有希腊字母 pi 的徽标，粉色背景配以装饰性曲线。Sonic Pi 的加入灵感来自 DJ_Dave，一位将整首曲目作为实时代码构建和表演的音乐人。虽然她目前使用 Strudel——一个基于浏览器的实时编码环境——但使用 Sonic Pi 也能获得类似效果：写几行代码，立即听到循环播放，并在音乐播放过程中不断重塑它。Sonic Pi 在您的桌面上原生运行，并构建在 SuperCollider 的合成引擎之上，因此您可以从简单的循环和采样开始，逐步深入到更深层次的声音设计。

更多信息可在 ubuntustudio-26.10-desktop-amd64.iso 中找到。
