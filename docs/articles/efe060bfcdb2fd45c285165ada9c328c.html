Valve赞助将开源RADV驱动移植到Windows的工作

发布于2026年7月29日美国东部时间上午6:35。

Valve一直在资助Collabora工程师进行早期探索性工作，尝试将开源Radeon Vulkan“RADV”驱动移植到Microsoft Windows。

目前正在进行实验性工作，将Mesa RADV Vulkan驱动移植到Windows。该开源驱动实现被Linux游戏玩家广泛使用，并且是AMD驱动的Steam Deck以及现在的Steam Machine取得成功的重要因素。Valve资助了多名开发者从事开源RADV Vulkan驱动以及Linux图形栈其他部分的工作。现在，他们正在赞助Collabora的开发者，尝试让RADV在Microsoft Windows上变得可行。

Louis-Francis Ratté-Boulianne发布了一篇博客文章，介绍了他们将RADV移植到Windows的初步工作。除了在Windows上集成WDDM2之外，将RADV移植到Windows的一个重大挑战是依赖AMD Radeon Software Windows内核驱动。

当前工作的范围不包括将AMDGPU Linux内核图形驱动移植到Windows，因此他们正在努力将RADV带到Windows，同时依赖AMD的官方Windows内核驱动。这反过来导致了逆向工程和其他步骤，以弄清楚专有内核驱动的数据结构和其他元素，从而使RADV能够适配使用它。

最终要使这项工作顺利开展，他们要么需要一个稳定且有文档记录的AMD Windows内核图形驱动接口，要么创建一个垫片库，作为稳定接口位于RADV和内核驱动之间，以应对AMD Radeon Software Windows驱动版本之间未文档化的变更。
