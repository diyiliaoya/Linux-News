Linux 7.3 为笔记本电脑及其他设备带来更多音频修复

2026年8月30日，美国东部时间上午11:06。

继上周 Linux 7.3 的声音子系统更新（带来了大量新的音频硬件支持）之后，本周在 Linux 7.3-rc1 发布之前，又合并了第二轮声音更新。

这第二轮声音更新主要聚焦于“修复”，但也包含大量设备硬件怪癖（quirks），使各种笔记本电脑和其他音频设备在 Linux 下能够提供更好的声音支持。此外，还有一些新的设备 ID 等，构成了这个有趣的修复拉取请求：

- 罗技 PRO X 无线耳机具有热插拔麦克风，在 Linux 下当麦克风断开时会出现混乱。Linux 7.3 对此进行了修复，同时处理了其静音时的最小音量级别。

- 为微星 Thin A15 B7UC 笔记本电脑添加了怪癖，以支持该 AMD Ryzen 笔记本的内置麦克风。

- 针对 2018 年的 Intel Hades Canyon NUC，为 ALC700 编解码器添加了怪癖。当从 Windows 重启到 Linux 时，ALC700 编解码器无法使用。借助 Linux 7.3 的代码，即使从 Windows 重启到 Linux，它现在也能正确初始化。

- Creative Sound Blaster Play! 3 现在有了处理最小静音值的怪癖。

- 修复了 TongFang XxAF5xxx（也是 TUXEDO Computers 销售的笔记本型号）的麦克风检测问题。

- 为 SMSL USB DAC 添加了怪癖，以避免在内核模块探测时设置或从运行时挂起返回时出现可闻的爆音。

- 补丁使 M-Audio Venom USB 合成器能够在 Linux 下工作。MIDI 使用在 Linux 下已经可以工作，但 USB 接口直到现在才正常工作。

- 修复了 HP Laptop 15-fd0039nt 的麦克风静音 LED。

- 在 SoundWire RT766 驱动中新增了 Realtek RT766/RT767 VA1 设备 ID。

- 为联想 Yoga Pro 9 16IAH10、联想 Legion Pro 7 16ARX8H、联想 IdeaPad Slim 3 15ABR8 和 Alienware m18 R1 AMD 添加了额外的声音处理怪癖。
