为在 Linux 上启用 Apple Silicon Mac 扬声器和耳机插孔支持而发布的补丁

开发者 James Calligeros 向 Linux 内核邮件列表提交了 28 个补丁，旨在将 Apple Silicon Mac 的扬声器和耳机插孔支持合并到主线内核。该系列补丁引入了新的 macaudio 机器驱动，并包含针对 Apple M1 和 M2 系列 Mac 的设备树更改，M3 系列因缺少硬件节点将稍后支持。由于这些 Mac 的扬声器缺乏硬件保护，驱动还实现了故障保护机制，除非用户空间守护进程 speakersafetyd 运行，否则会静音并锁定所有扬声器的控件。

虽然下游的 Asahi Linux 内核已在 Apple Silicon Mac 上提供了可用的扬声器支持和耳机插孔功能，但主线 Linux 内核尚未支持这一功能。不过，今天在 Linux 内核邮件列表上发出的一组 28 个补丁正致力于将这一重要功能主线化，以便在上游 Linux 桌面上使用 Apple Mac。

James Calligeros 发出了这一大批补丁，以最终确定对 Apple Silicon Mac 主音频子系统的支持。这引入了一个新的“macaudio”机器驱动，该驱动历经数年打造，旨在让近期 Mac 上的扬声器和耳机插孔正常工作。Calligeros 在今天的 Linux 内核补丁系列中解释道：

“Apple Silicon Mac 上的音频子系统相当复杂。扬声器配置变化很大；有些机器只有一个单声道低音扬声器，而另一些则将多个低音扬声器和高音扬声器组合成一个立体声对。该驱动还暴露了耳机插孔的捕获 PCM。配备的 Apple Silicon Mac 上的内置麦克风不由该驱动处理，因为它们连接到常开处理器（实际上并非一直开启）。

在其他平台上由固件处理的许多功能，必须由内核或用户空间处理。最值得注意的是，扬声器保护由用户空间守护进程 speakersafetyd 处理。macaudio 机器驱动通过暴露一个捕获 PCM 来促进这一点，从中可以读取每个扬声器音圈上的电压和电流。鉴于绝对没有硬件或固件级别的故障保护来防止这些机器上脆弱的扬声器受到永久性损坏，该驱动还实现了一个故障保护，除非 speakersafetyd 正在运行，否则将静音并锁定每个扬声器的 kcontrol。”

与 macaudio 驱动一同提供的还有设备树更改，可在 Apple M1 和 M2 系列 Mac 上启用扬声器和耳机支持。Apple M3 系列 Mac 将稍后推出，因为缺少大多数先决硬件节点。Apple M3 系列是目前主线内核所支持的 Apple Silicon SoC 中最新的。

总计约 3000 行新代码现已提交审查，有望在不久的将来将这一 Linux 音频支持主线化。
