Fedora 45 第二次未获通过：要到11月才发布

Fedora 45 在10月22日的 Go/No-Go 会议上再次被判定为 NO-GO，原因是多个阻塞性缺陷尚未解决，包括 eMudhra 缓解更新、Fedora Server 45 AArch64 镜像超出最大体积、LUKS PV 升级后 LVM 自动激活失败以及 KDE Plasma Discover 安装 Fedora 44 旧版 RPM 包等问题。另有三个拟议阻塞项待评估。新计划发布日期为11月3日，能否成行取决于下周四前这些阻塞项是否解决。

Fedora 45 第二次未获通过：要到11月才发布

2026年10月22日 17:20 EDT。

Fedora 45 本周未能发布，原本理想的提前发布目标因上周的 Go/No-Go 会议前未能及时生成候选版本而落空。在今天的 Go/No-Go 会议上，由于存在未解决的阻塞性缺陷，Fedora 45 又被推迟至少一周。

Fedora 45 下周不会发布，因为今天的会议宣布了“NO-GO”。目前 Fedora 45 已接受的阻塞项包括：需要更新以缓解 eMudhra 相关问题；Fedora Server 45 AArch64 镜像超出其最大体积；在基于 LUKS 的 PV 配置上升级到 Fedora 45 后 LVM 自动激活失败；以及 KDE Plasma Discover 从 Fedora 44 仓库安装过时的原生 RPM 包。

还有三个拟议的发布阻塞项正在考虑中：安装期间通过 ip= 内核参数未配置网络接口；Stratis 加密池启动失败；以及加密的 Stratis 根分区在密码短语提示未应答后进入紧急模式。

此外还有若干已批准的冻结例外。Fedora 45 当前的阻塞项列表可通过以下链接查看。

目前下周发布 Fedora 45 的计划已不可行。因此新的计划发布日期为11月3日，他们将根据下周四前这些阻塞项是否得到解决来判断该日期能否实现。
