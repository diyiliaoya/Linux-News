ZimaOS 1.7.0 发布

IceWhale Technology 发布了 ZimaOS 1.7.0，这是其基于 Linux 的个人服务器与 NAS 操作系统的最新稳定版。新版本重新设计了应用商店，新增了应用管理页面、应用发现页面、原生 YAML 支持，并修复了备份页面文件计数重叠、大文件备份卡顿等问题，同时改进了应用列表、容器日志、容器终端、商业许可证检测、页面缓存清理策略及 OneDrive 连接体验。

IceWhale Technology 已发布 1.7.0 版本，这是该公司独立开发的、基于 Linux 的个人服务器与网络附加存储（NAS）操作系统的最新稳定版。新版本包含重新设计的应用商店及其他多项改进：

ZimaOS 1.7.0。新增：重新设计的应用商店，采用全新用户界面，提供更现代、更清晰的应用浏览体验；新增应用管理页面，可集中管理已安装应用、更新状态及常用操作；新增应用发现页面，改进了应用推荐、分类浏览和内容展示；新增原生 YAML 支持，提供更好的配置编辑与解析体验。修复：修复了备份页面上文件计数重叠的问题；修复了大文件备份时的卡顿问题。改进：改进了应用列表、分类页面和应用详情页面的显示体验；改进了容器日志显示，提升可读性和故障排查效率；改进了容器终端操作，提供更清晰的执行状态和交互反馈；改进了商业许可证检测逻辑，提升兼容性和准确性；改进了页面缓存清理策略，带来更流畅的浏览体验；改进了 OneDrive 连接体验，支持工作或学校账户登录。

更多详情请访问项目 GitHub 页面。
