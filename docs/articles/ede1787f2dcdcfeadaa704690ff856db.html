发行版发布：PorteuX 2.9

PorteuX 2.9 发布，这是一个基于 Slackware 的 Linux 发行版，提供多种桌面版本。本次更新主要聚焦稳定性，全面审查了运行时代码（initrd、rc 脚本、porteux-scripts 和安装程序），修复了大量错误并提升了安全性。内核也获得性能优化，包括更快的 zstd 解压、无锁页面缓存读取和更轻量的文件打开路径。Xfce 新增后台窗口间拖拽文件功能，并修复了 Chrome/LibreWolf 崩溃、Windows 编辑配置后 cheatcodes 失效、符号链接模块不释放 loop 设备等问题。

发行版发布：PorteuX 2.9（DistroWatch.com 新闻）

PorteuX 是一个基于 Slackware Linux 的 Linux 发行版。该项目提供多个桌面版本，2.9 版侧重于提升稳定性。

“本次发布主要关注稳定性。我们所有的运行时代码（initrd、rc 脚本、porteux-scripts 和安装程序）都经过了深入审查，修复了许多错误并提高了安全性。内核也进行了一些性能优化：更快的 zstd 解压、无锁页面缓存读取以及更轻量的文件打开路径。这些改进有助于模块加载和一般磁盘访问。Xfce 新增功能：现在你可以将文件从后台窗口直接拖拽到另一个窗口，而无需切换焦点，就像在 Windows 上一样。修复了 Chrome 和 LibreWolf 崩溃的问题；修复了在 Windows 上编辑 porteux.cfg 后 cheatcodes 不工作的问题；修复了通过符号链接激活的模块不释放其 loop 设备的问题；修复了模块在 PorteuX Modules 应用程序的“其他”部分显示两次的问题；修复了关机时残留进程在卸载前未被杀死的问题；修复了虚拟机无法从 virtio 存储启动的问题……”
