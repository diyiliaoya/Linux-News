Amazon Linux 2027 预览版发布：基于 Linux 7.1，支持 x86-64-v3，并采用 LTO 构建

发布于 2026 年 9 月 3 日 下午 05:13（美国东部时间）。

AWS 今天宣布了 Amazon Linux 2027 的公开预览版。鉴于自 Amazon Linux 2023 以来的时间跨度，Amazon Linux 2027 带来了大量软件更新，以及许多性能优化和其他调整，以便更好地运行针对 AWS 云的工作负载。

Amazon Linux 2027 默认使用 Linux 7.1 内核，现在默认启用 SELinux 强制模式，新增了加速器驱动程序，并包含各种其他改进。

Amazon Linux 2027 的软件包现在也全部以 -O2 优化级别构建，软件包在构建时启用了链接时优化（LTO）以获得更好的性能，并且 x86-64 软件包现在面向 x86-64-v3，以支持 AVX/AVX2。Amazon Linux 2027 的软件包现在还启用了自动向量化。

在增强 ARM 性能方面，对于 Amazon Linux 2027 上的 AArch64 Graviton 实例，默认还为 malloc 堆区域启用了透明大页（THP）。

Amazon Linux 2027 还默认使用新的 GCC 16.1 编译器，以及 LLVM/Clang 22 和更新版本的 Rust 和 Go。在包管理器方面，使用 DNF5。Amazon Linux 2027 部分基于 Fedora 44 和 Fedora 45。
