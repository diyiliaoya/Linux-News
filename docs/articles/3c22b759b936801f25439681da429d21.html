Zstd 1.6 发布：包含大量修复与新的性能优化

Zstandard 1.6.0 正式发布，这是自 v1.5.7 以来一年半后的重大更新。新版本为 64 位 ARM（AArch64）带来更快的解压性能，为支持 SVE2 的 CPU 提供更快的压缩，并优化了 RISC-V 的 RVV 向量扩展。此外还修复了多线程压缩/解压问题、32 位问题以及可能的内存损坏等大量缺陷，并对命令行参数和 API 做了小幅调整。

Zstd 1.6 发布：包含大量修复与新的性能优化

距离上一个 Zstandard 版本（v1.5.7）发布已过去一年半，而 Zstandard 1.6.0 不久前刚刚打上标签，标志着这个广泛使用的开源压缩算法及其实现迈出了下一个重要步伐。

随着 Zstandard 在新增优化/更高性能方面接近平台期，Meta 的工程师们最近投入了更多时间在 OpenZL 上，用于内容感知压缩。但很高兴看到 Zstd 1.6 现在可用，它整合了自 2025 年 2 月上一版本以来所做的所有改进。

Zstandard 1.6 为 64 位 ARM（AArch64）带来了性能优化，解压速度更快。对于支持可伸缩向量扩展 2（SVE2）的 CPU，压缩速度也有所提升。此外还有围绕 Neon 和 SVE2 使用的其他 AArch64 优化工作。

RISC-V 也获得了一些性能优化，例如针对 RVV 向量扩展的优化。

Zstandard 1.6 还包含大量修复，例如针对某些多线程（解）压缩问题的修复、32 位问题的修复、STD_compressSequences() 和 ZSTD_compressSequencesAndLiterals() 中可能的内存损坏问题，以及各种其他修复。

Zstd 1.6 还对其命令行界面参数做了一些调整，并有一些小的 API 变更。
