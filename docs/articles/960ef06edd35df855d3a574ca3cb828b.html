AMD EPYC 9996 256 核 CPU 基准测试

今天在双路配置下发布，组成 512 核 / 1024 线程的旗舰 Zen 6C 服务器配置，Phoronix 近期也测试了 EPYC 9686F 部件。AMD EPYC 9686F 是其新款高频 Zen 6 部件，拥有 96 核 / 192 线程，加速频率高达 5.3GHz！AMD 最初公布 EPYC 9686F 时标称加速频率为 5.0GHz，但鉴于量产芯片表现良好和/或营销原因，现在确认量产版实际为 5.3GHz。

AMD EPYC 9686F 是一头猛兽，96 核 / 192 线程，加速频率 5.3GHz，基础频率 3.4GHz。相比上代高频旗舰 Turin 部件 EPYC 9575F（64 核 / 128 线程，加速频率 5.0GHz），它不仅多了 32 个核心，提升巨大。EPYC 9686F 还拥有 384MB L3 缓存，而 EPYC 9575F 为 256MB。这款 Venice HF 部件默认 TDP 更高，为 500W（上代为 400W），但 EPYC 9686F 也支持 400W 至 600W 的 cTDP 范围。

与其他 EPYC 9006 SP7 处理器一样，AMD EPYC 9686F 支持 96 条 PCIe 6.0 通道，以及 DDR5 RDIMM 8000 MT/s 或 MRDIMM 12800 MT/s 内存。

从另一个角度看，Intel Xeon 6 方面，旗舰 Xeon 6980P 拥有 128 核 / 256 线程，但基础频率 2GHz，全核睿频 3.2GHz，最大睿频 3.9GHz……AMD EPYC 9686F 能加速至 5.3GHz，对单线程服务器任务将有奇效，搭配 MRDIMM 12800 MT/s 内存也能提供出色的内存带宽。对于某些 HPC 和技术计算工作负载等应该会非常出色，这正是我们今天文章要探讨的内容。

最高 600W 的 EPYC 9006 SP7 系列处理器仍可采用风冷。上代 AMD Volcano 2U 参考服务器为 EPYC 9005 选择了液冷，而 AMD Nigeria 2U 参考服务器则依靠相当厚重的风冷即可。

SP7 处理器的散热器体积巨大，但配合强力风扇能有效冷却这些高功耗处理器。

在 AMD EPYC 9006 SP7 系列今天发布/上市之际，本文测试的处理器包括作为上代 Turin HF 旗舰部件的双路 EPYC 9575F，以及作为 128 核旗舰 Zen 5 服务器处理器配置的双路 EPYC 9755。Intel 方面则是双路旗舰配置 Intel Xeon 6980P。本文没有 NVIDIA Vera 基准测试，因为我手头没有 Vera 来在相同操作系统软件栈和基准版本下进行干净的 1:1 对比测试。但在后续文章中，我将基于之前的 Vera 运行结果提供 NVIDIA Vera 与 AMD Venice 的对比数据。同样，本文也没有 AmpereOne 或其他 ARM 服务器选项的对比数据，因为手头没有其他最新一代 ARM 服务器。

AMD EPYC 9668F 和 Nigeria SP7 参考服务器在 Linux 下运行良好——我用 Ubuntu 26.04 LTS 和 Ubuntu 26.10 都做了测试。对于双路 EPYC 9686F 服务器以及本次评测中的所有其他处理器/服务器，所有硬件均测试了 Ubuntu 26.10，以获得非常新的软件栈，包括 Linux 7.3 内核和其他前沿软件。

这是基于我在今天解禁前重新测试现有 CPU/服务器的时间和服务器可用性做出的安排。未来几天/几周内，我将提供更多上代对比基准测试等。感谢 AMD 提供 Venice 处理器和参考服务器，使我能够今天以及未来数天/数月内运行基准测试；敬请期待伴随激动人心的新 CPU 发布而来的 Phoronix 常规基准测试。
