Ubuntu 26.10 每日构建 ISO 现已包含 Amd64-v3 安装程序

Ubuntu 26.10 的每日构建版本现已包含 amd64-v3 安装程序，允许用户在安装时直接使用针对 CPU 优化的软件包，无需安装后手动配置。此前，Ubuntu 26.04 LTS 仍默认使用标准 amd64 (v1) 基线，但用户可在安装后手动转换。amd64-v3 是较新的 CPU 指令集基线，支持 AVX2、FMA 等特性，可提升计算密集型任务的性能。大多数 2015 年后的 Intel 和 AMD 芯片均兼容。Canonical 尚未宣布 v3 ISO 将成为 26.10 的官方下载，但此举有助于收集测试反馈，为未来可能的基线升级提供参考。

Ubuntu 26.10 每日构建版本现已包含 amd64-v3 安装程序，让您从一开始就能尝试针对 CPU 优化的软件包，无需安装后进行额外配置。

去年，Ubuntu 开始以可选归档的形式构建 amd64v3 软件包，但 Ubuntu 26.04 LTS 仍默认使用标准 amd64 (v1) 基线（由于过程中出现了一些小问题，这一决定是明智的）。

Ubuntu 26.04 LTS 可以在安装后手动转换为 amd64-v3 软件包集，但 Ubuntu 26.10 每日构建版本突然提供内置支持，省去了这一麻烦：它从一开始就引导并安装 v3 优化的软件包。

什么是 Amd64-v3？

Amd64-v3（又称 x86-64-v3）是 CPU 指令集支持的新基线，包括 AVX2、FMA、BMI1/2 等特性，这些特性可提升计算密集型工作负载的性能（但对基本的电子邮件和网页浏览影响不大）。

大多数 2015 年后生产的 Intel 和 AMD 芯片均兼容 v3，但也有一些例外（低端和嵌入式芯片缺乏 AVX2）。运行针对 CPU 优化的 Ubuntu 软件包，可能意味着特定软件能获得更好的体验。

运行以下命令可检查您的 CPU 是否支持 x86-64-v3：

/lib64/ld-linux-x86-64.so.2 --help | grep x86-64

如果不支持，也不必担心；默认 ISO 仍可正常工作（较旧且不支持的 CPU 无法运行 v3 软件包，但 v3 CPU 可以运行 v2 和 v1 软件包）。

Red Hat Enterprise Linux 10 已要求支持 x86-64-v3，而 openSUSE Leap 16 提供 v2 支持，但 Ubuntu 在提高 CPU 基线方面一直较为谨慎。Canonical 决定将 v3 作为可选测试（而非强制更改）的做法受到了欢迎。

不过，Canonical 尚未表示 amd64-v3 ISO 将成为 26.10 的官方下载版本，而随着该版本（代号“Stonking Stingray”）临近发布，本周期内不太可能进行此类切换。

提供替代安装程序无疑是增加 Ubuntu v3 基线体验测试和反馈的务实方式。这些反馈必将为未来可能的切换决策提供参考。
