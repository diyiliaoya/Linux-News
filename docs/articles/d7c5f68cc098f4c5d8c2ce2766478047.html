Garuda Linux 通过推广其子系统开启 Nix 化进程

Garuda Linux 将其 Nix 子系统重新命名并提升为独立发行版，提供带 Calamares 图形界面的专用 ISO 和命令行工具，支持 Dr460nized 和 Mokka 两种版本。该子系统支持非持久化根文件系统、预设分区布局和多种硬件配置，现有 NixOS 用户可直接通过 flake 安装。

Garuda Linux 通过推广其子系统开启 Nix 化进程

Nix 子系统现在可作为独立发行版安装，并提供 Dr460nized 和 Mokka 两种版本。

Garuda Linux 已开始引导其用户群体转向 Nix。该发行版的维护者刚刚重新命名了该子系统，你会发现这一举措远比表面上的改名更为微妙。

这个曾经用于双启动 NixOS 的副项目，如今也拥有了自己的可启动安装程序。它附带一个带有 Calamares 图形界面的专用 ISO，以及一个用于脚本化安装的命令行工具。

这并非全新事物。作为子系统，它提供了一种在同一硬盘上 alongside Garuda 运行 NixOS 的方式，通过 BTRFS 子卷而非专用分区将两者隔离开来。

那么它提供了什么？

Garuda Nix 的“Mokka”和“Dr460nized”版本（来源：It's FOSS）。你会发现 Calamares 处理了大部分工作，要求你选择一个版本，然后让你选择额外组件以获得更好的游戏和打印支持。

命令行工具才是真正有趣的地方；它涵盖了安装此类 Linux 发行版的基础功能，同时还提供了桌面、笔记本、服务器和掌机设置的预设，以及八种分区布局，涵盖 ext4 和 BTRFS，包括加密和非加密。

不过，非持久化才是真正的亮点。开启后，每次机器重启时根文件系统都会被清空，要么通过 BTRFS 回滚到保存的快照，要么在 ext4 系统上从 tmpfs 运行根目录。

别担心，这些清除操作不会触及登录凭据。两者在写入生成的配置之前都会进行哈希处理，这正是它们能在回滚后得以保留的原因。

Garuda Nix 默认还会保留少量必要内容持久化，因此你的 Wi-Fi 凭据和每用户配置文件夹等都会安全保留。除此之外的任何内容都需要手动声明，否则会在下次重启时连同其他所有内容一起被删除。

两个版本现已可用。已经在运行 NixOS 的用户可以完全跳过下载，直接通过一条命令从已发布的 flake 中拉取安装程序。

无论你使用哪种安装方式进行设置，该 flake 引用默认都指向同一个稳定分支。在此基础上保持系统更新并不复杂，只需使用 NixOS 用户已经熟知的常规命令即可。

如果你是 NixOS 新手，那么你需要花些时间学习如何操作，因为这里几乎所有内容都是通过文本文件而非设置面板来配置的。

此外，这也不是 Garuda Linux 团队第一次做出如此规模的事情。他们提供的浏览器是从头重写以提供改进浏览体验的。
