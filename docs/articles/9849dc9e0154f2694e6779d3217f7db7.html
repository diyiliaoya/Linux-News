High Tide（Linux TIDAL 客户端）新增 DLNA 和 Chromecast 支持

开源 Linux TIDAL 客户端 High Tide 发布新版本，新增对 DLNA 和 Chromecast 设备的无线串流支持。用户可通过新增的“Play on”按钮将音乐投射到电视、智能音箱等设备，音频会转换为 FLAC 无损格式并通过内置 Web 服务器传输。该功能无需额外配置，但播放期间电脑需保持开机，且仅能通过电脑控制播放。

这款面向 Linux 的开源 TIDAL 客户端现在可以将音乐播放到 Chromecast 和 DLNA 设备上，例如电视和智能音箱。

该功能随本周末发布的版本推出，同时包含多项较小的错误修复和细微更新，包括在 Discord RPC 中显示艺术家名称。

但无线串流才是重头戏。

大多数人使用 High Tide 将音乐串流到同一设备上，如果想将音频推送到其他地方，可以通过蓝牙实现。

我敢说大多数 TIDAL 订阅用户都拥有可以运行官方应用的设备。这些应用提供了服务原生的音频切换技术——TIDAL Connect。Connect 让应用可以指示音箱直接从 TIDAL 服务器串流音乐。

但由于没有可供第三方应用使用的 Connect API，High Tide 的开发者想出了创造性的解决方案。

High Tide 使用了许多智能音箱、电视和音频设备已经支持的标准：DLNA 和 Chromecast。

DLNA 接收器内置于许多现代电视和智能电视盒子中，或以适配器形式存在。

使用起来很直接。点击应用控制栏中新增的“Play on”按钮。这会列出 High Tide 在网络上找到的所有 DLNA 和 Chromecast 设备（以及一个“在此设备上播放”选项，用于将声音带回电脑）。

如果你选择了目标设备，High Tide 会将曲目转换为 FLAC（无损）格式，并通过应用内运行的小型 Web 服务器提供。这意味着你的电脑自然需要保持开机才能播放。

你也只能从电脑上暂停、跳过等，所以不要因为电视遥控器没反应而生气。曲目在播放前也会被缓存，因此音频启动可能需要一点时间（因此没有无缝播放）。

由于使用该功能不需要任何额外设置或依赖，这是一种相对低摩擦的方式，可以将音乐推送到你可能经常路由到的设备上。

High Tide 是免费的开源软件，不过最新版本尚未发布——可从其 GitHub 页面获取。
