发行版发布：Ubuntu Unity 26.10

Ubuntu Unity 26.10 发布，代号“Stonking Stingray”，主要聚焦维护、打包更新及为安装介质默认集成 Lomiri 做准备。该版本继续使用 Unity 7.7，修复了长期存在的错误并替换了无人维护的软件包，默认加入 Lomiri 计算器、文件管理器和终端，修复了 nux 库的策略违规问题，并更新了 unity-settings-daemon 打包和新壁纸。下个版本（2027年4月）将改用 Ayatana 指示器并改进通知功能。

发行版发布：Ubuntu Unity 26.10

Ubuntu Unity 是 Ubuntu 的一个社区版本，采用 Canonical 公司曾经的桌面环境 Unity。该项目的 26.10 版本侧重于维护和错误修复：

“Ubuntu Unity 26.10 ‘Stonking Stingray’ 已发布。本次发布主要聚焦于维护、打包更新、适应 Ubuntu 26.10 的通用变更，以及为在安装介质中默认包含 Lomiri 做准备。因此，Ubuntu Unity 26.10 继续使用经过维护的 Unity 7.7。本次发布的首要目标是修复问题和错误，以便在开发后继版本的同时保持 Unity 7 的活力。这包括修复长期存在的错误，以及从不被维护的软件包迁移到受支持的替代方案。我们做出的显著变更包括：默认包含 Lomiri 计算器、Lomiri 文件管理器和 Lomiri 终端；修复了 nux 库中的策略违规问题；更新了 unity-settings-daemon 的打包，新增壁纸。本次发布未包含但我们正在开发、并将在 2027 年 4 月的下个版本中纳入的变更包括：切换到 Ayatana 指示器（Lomiri 也使用），通知改进——不再为带有按钮的通知单独创建窗口……”
