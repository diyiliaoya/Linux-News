GhostBSD 将用一款因拼写错误命名的新桌面取代 MATE

GhostBSD 开发者 Eric Turgeon 展示了一款名为 Mocka 的全新桌面环境，将逐步取代现有的 MATE 桌面。Mocka 的所有组件均从零构建，不依赖 MATE 代码，计划逐个替换组件直至功能对等。首个组件是一个任务栏风格的 Dock 小程序，已发布 Alpha 版供测试。项目还包含菜单、控制中心等规划，目前仍处于早期开发阶段。

GhostBSD 将用一款因拼写错误命名的新桌面取代 MATE

Eric Turgeon 展示了一款将随 GhostBSD 一起发布的全新桌面环境，其中包含自定义组件。Eric Turgeon 提出了 Mocka，这是该 BSD 发行版的新桌面，最终将取代 MATE。他还展示了将纳入其中的组件，以及一些初步概念和规格说明，向我们展示了 Mocka 未来的发展方向。

GhostBSD 的现有用户目前无需做任何操作，因为他们机器上的东西没有任何变化。毕竟这一切仍处于密集开发阶段。🤷

语法纳粹不会喜欢这个

Eric 展示了 Mocka Dock 的演示。

在寻找以“摩卡”（那种含咖啡因的饮料）命名的项目时，Eric 打了一个错字，最终将他的新创造命名为“Mocka”，其中每个组件都是从零构建的，没有从 MATE 项目中借鉴任何东西。

计划一次替换一个组件，对 MATE 已提供的功能进行逆向工程，直到实现完整的功能对等。一旦完成，我推测 GhostBSD 将默认使用 Mocka。

这也不是他第一次进行如此重大的变更。今年二月，他得出结论认为 MATE 尚未准备好支持 Wayland，于是 GhostBSD 将转向 XLibre，以保持其 X11 会话完好。

这一思路也与 Eric 现在的做法相符。

该桌面的第一个组件是一个用于 MATE 面板的任务栏风格 Dock 小程序，名为 Mocka Dock，现已作为 Alpha 版发布给早期测试者。它允许你打开应用、查看缩略图、将窗口带到前台聚焦，以及管理同一应用的多个窗口——基本上就是一个合格 Dock 该做的事。

有技术能力的人现在就可以获取它，看看它提供了什么，而我们其他人则只能等待它作为 GhostBSD 软件包更新出现。不过它尚未成为默认体验，你需要通过任务栏上的“+”按钮手动设置。

如果你查看 Mocka 的代码仓库，你会更好地了解除了 Dock 之外还在进行哪些工作。有一个文件列出了已完成的工作和待完成的工作。

该文档向我们展示了 meson 构建和 schema 工作已经完成，还有一长串待执行的工作。这将使 Mocka 能够显示带有列表项的菜单、处理搜索和键盘输入、与 Dock 集成等等。

还有控制中心。一旦完成，它将为用户提供一个单一入口点，用于管理 GhostBSD 机器的桌面外观、网络配置、电源管理、键盘布局以及其他以 UI 为中心的选项。

还有一个托管 Mocka 代码的仓库。它的开发进度比我们之前看到的菜单组件要落后得多，在撰写本文时仅包含占位内容。

该项目希望在向 GhostBSD 上的完整 Mocka 桌面过渡期间，确保这些新的 Mocka 组件与 MATE 保持兼容。
