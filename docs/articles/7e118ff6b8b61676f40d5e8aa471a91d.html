Ubuntu 26.10 开始推出 upki 证书吊销支持

Ubuntu 26.10 开始初步推出基于 Rustls 项目 upki 的证书吊销支持，由于该功能在9月才确定，目前仅在其 curl 包中默认启用。Canonical 计划在 Ubuntu 27.04 中将其扩展到 OpenSSL 包，以实现全系统浏览器级证书验证与吊销，此举也受到 eMudhra 中间 CA 私钥薄弱事件推动。

Ubuntu 26.10 开始推出 upki 证书吊销支持

2026年11月10日 晚上08:43 EST。

随10月发布的 Ubuntu 26.10，有一个鲜少被提及的功能——upki 吊销支持开始逐步推出。由于变更较晚，证书吊销的 upki 仅在 Ubuntu 26.10 的 curl 包中启用，但后续还有更多计划。

Canonical 正致力于在整个操作系统栈中实现浏览器级别的证书验证（以及在需要时进行吊销）。Canonical 正在推进 Rustls 项目的 upki 项目，以提供用 Rust 编写的浏览器级证书基础设施。这建立在 Mozilla 所做的基础工作之上，并检查由公共信任机构颁发的证书的吊销状态。upki 项目与 OpenSSL、Rustls 集成，并具有 C-FFI 接口。

Ubuntu 26.10 本想默认启用 upki，但由于该功能直到9月才确定，他们限制了初始范围，仅在其 curl 包中启用。

在 Ubuntu 27.04 中，开发者计划在 OpenSSL 包中利用 upki 进行证书验证。

鉴于10月发生的 eMudhra 暴露事件——一名研究人员发现中间 CA 证书的私钥强度较弱——Canonical 正在推动这种证书验证/吊销支持的需求。借助 upki，可以更快地在整个栈中吊销这些证书。
