LibreOffice 26.8 发布：段落布局改进、草稿视图等新功能 - OMG! Ubuntu

文档基金会已发布 LibreOffice 26.8，这是面向 Windows、macOS 和 Linux 的开源办公套件的一个重要新版本。

其中的变化包括一个新的段落布局算法。该算法改进了两端对齐文本的处理方式。在许多文字处理器中，两端对齐文本会被拉伸，使页面两侧形成平直的边缘，但这可能看起来不均匀。有些行排列紧密，有些行则出现空隙。

但在 LibreOffice 26.8 中，新的间距平衡算法会同时平衡多行的间距，而不是逐行处理，这可以带来更好的整体视觉效果：

LibreOffice 26.8 中的其他排版改进包括原生支持可变 OpenType 字体，让您可以调整“影响字形对比度和比例以适应文本设置大小的轴”。此外，还为文本框添加了基线网格对齐功能。

对于从右到左书写的语言（如阿拉伯语和希伯来语），LibreOffice 现在会在打开或粘贴文档时自动检测文档方向，而无需用户手动设置；并且，该套件的电子表格工具 Calc 在输入从右到左文本时，会自动设置单元格文本方向。

该套件还增强了对其他语言（包括从右到左书写的语言）的支持：

- 打开文件或粘贴文本时自动检测段落方向

- 在空单元格中输入从右到左文本时自动设置书写方向

- 双向控制字符现在会显示

- 对象调整大小手柄在从右到左和垂直中日韩（CJK）文档中正常工作

- CJK 文本网格选项已重命名

- 为 N'Ko 和 Adlam 语言添加了命名函数和运算符

“这些工作没有商业市场，”文档基金会表示，并指出他们这样做是因为不必根据回报来证明功能的合理性。这有点循环论证，但其中的理念是成立的：自由软件可以专注于真正重要的东西，而不是专注于能带来收益的东西。

LibreOffice 26.8 添加了我六月份报道过的彩色 Notebookbar 背景选项。这些选项旨在让用户更容易区分不同的应用程序，但在我看来，它们也让界面看起来更清新。

更改主题颜色不再需要重启应用程序，这在您想探索自定义选项时能节省大量时间。

LibreOffice 26.8 中的其他变化

互操作性（一个枯燥的词）始终是一个需要不断改进的领域。人们可能会选择 LibreOffice，但仍然需要与使用 Microsoft Office 的同事和协作者共享文件，反之亦然。

在互操作性方面，LibreOffice 26.8 修复了一个问题，该问题曾导致在 LibreOffice 中打开和编辑的某些较新的 Microsoft Excel 图表类型在再次用 Excel 打开时被损坏。LibreOffice 仍然无法处理这些图表，但至少不再会弄乱它们了！

- 数据透视表新增计算字段

- 数据有效性再次静默拒绝无效条目

- 单元格样式支持相对字体大小

- 随机排序命令可随机化区域中单元格的顺序

- 边框工具栏按钮会记住并重新应用最近使用的样式

- 改进了 XLSX 中引用单元格的线条处理

- XLSX 表单控件元素现在显示在导航器中

- 打开包含图像的大型文档速度更快

- 草稿视图隐藏页眉、页脚和页边距，实现无干扰工作

- 单个文档现在支持多种页面大小

- 幻灯片可以组织成命名组

- 许多捆绑模板提供 16:9 和 4:3 比例版本

- 允许交换鼠标滚轮行为，使缩放成为默认操作

- 侧边栏可搜索评论

- 不再捆绑字体

- 新文档默认使用起始对齐，而不是左对齐

- 安全模式更名为疑难解答模式

- 新增纸张尺寸（A0 至 B3）

- 对话框从地址中去除查询字符串

- 自定义词典具有搜索过滤器

LibreOffice 的数据库工具 Base 常常被忽视。
