Linux Mint 27 Beta 发布：全新应用与完整 Wayland 支持

2026年11月27日上午10:37（美国东部时间）。

在预计于圣诞节前后发布的正式版之前，Linux Mint 27 的 Beta 版于今日宣布开放测试。

Linux Mint 27 Beta 现已可供下载，这是这款基于 Ubuntu 的热门桌面 Linux 发行版的最新版本。Linux Mint 27 将过渡到 Ubuntu 26.04 LTS 基础。

Linux Mint 27 Beta 带来最新的 Cinnamon 桌面环境，并包含多款 Linux Mint 原创应用，例如 Clockenstein 日历应用、作为新终端应用的 Velocity、作为新系统监视器的 Superlight、作为轻量级归档管理器的 Unfold、作为新 EPUB 阅读器的 Xepub，以及新的系统管理功能、恢复的休眠支持等。

Linux Mint 27 Beta 还通过 Cinnamon 6.9 桌面实现了完整的 Wayland 支持，3D 加速、HiDPI、分数缩放、键盘布局及其他典型功能现在均可在 Wayland 下正常工作。
