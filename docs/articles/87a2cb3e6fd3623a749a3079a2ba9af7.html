StartOS 0.4.0 发布

StartOS 0.4.0 是一个基于 Debian 的个人服务器优化 Linux 发行版，支持 AArch64、riscv64 和 x86_64 架构。此版本是对 StartOS 的完全重写，带来了重新设计的用户界面、全新的网络栈、StartTunnel 反向隧道、LXC 容器运行时以及改进的备份功能。发行版由 Start9 Labs, Inc. 开发，可通过 Tor 网络从本地或全球访问。

Aiden McClelland 宣布了一个重大新版本的发布，这是一个基于 Debian 的 Linux 发行版，针对个人服务器进行了优化，支持 AArch64、riscv64 和 x86_64 架构：“0.4.0 版本是对 StartOS 的完全重写。经过六年的构建，我们相信已经找到了正确的架构和基础，以实现主权计算的承诺。亮点：重新设计的用户界面——更快、更直观、移动友好，带有实时系统指标仪表板；全新的网络栈——LAN 端口转发、Wireguard VPN 网关、私有和公共域名（clearnet）、Let's Encrypt、内置 DNS，以及可选的 Tor 插件；StartTunnel——免费、开源的反向隧道，可在公共域名上暴露服务而不泄露家庭 IP；LXC 容器运行时——用可靠的分层容器架构取代 Docker/Podman，支持硬件加速和多容器设置；改进的备份——差异备份、跨服务器恢复，以及用于跨平台可靠性的新 FUSE 模块……有关完整变更日志和升级说明，请访问。下载链接（startos-0.4.0-x86_64-nonfree.iso、startos-0.4.0-aarch64-nonfree.iso、startos-0.4.0-riscv64-nonfree.iso、startos-0.4.0-raspberrypi.img）。

StartOS 是一个基于 Debian 的 Linux 发行版，针对个人服务器进行了优化。它便于发现、安装、网络配置、服务配置、数据备份、依赖管理和自托管软件服务的健康监控。安装后，发行版会启动到 Firefox 浏览器，其中预装了几项服务，其他服务（包括各种比特币、通信、数据和人工智能服务）可从项目的在线市场获取。服务器可以通过 Tor 网络的 Onion 服务从本地或全球任何地方访问。该发行版由 Start9 Labs, Inc. 开发。
