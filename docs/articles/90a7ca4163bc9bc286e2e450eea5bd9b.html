发行版发布：Butterbian 0.4.0

Butterbian 项目发布了基于 Debian 的 Linux 发行版 0.4.0 版本，该版本默认支持 Btrfs 文件系统，并预配置了 Timeshift 定期快照功能。新版本主要更新了 Xfce 桌面的视觉外观，包括全新的壁纸、启动菜单、LightDM 登录界面和 Orchis 黑色主题，使系统从开机到桌面呈现统一的视觉风格。

Butterbian 项目已宣布发布 0.4.0 版本，这是该项目基于 Debian 的 Linux 发行版的最新稳定版本，默认支持 Btrfs 文件系统，并预配置了 Timeshift，该工具会定期对已安装的文件系统进行增量快照。新版本更新了其 Xfce 桌面的视觉方面："Butterbian Xfce 0.4.0 已发布。快照优先的基础没有改变——为你布局好的 Btrfs 子卷、每次 apt 操作前的 Timeshift 快照、从 GRUB 菜单回滚。改变的是你所看到的一切。0.3.3 看起来像是带有壁纸的普通 Xfce，而 0.4.0 看起来像一个真正的发行版。壁纸是为这个版本绘制的暮色场景——黑暗山脊上的一座孤独灯塔。启动菜单使用相同的艺术风格，因此从开机到桌面是同一个场景。小屋和灯笼变体也随附其中，如果你想重新混搭，SVG 源文件在仓库中。LightDM 现在采用深色 Butterbian 风格，而不是普通的灰色——聚光灯艺术、Butterbian 标志作为你的账户图片，以及一个与系统其余部分匹配的登录框。锁定屏幕也会进入相同的界面。桌面主题是 Orchis 的黑色变体——近黑色、扁平、蓝色点缀，搭配匹配的窗口边框，因此标题栏和应用程序终于协调一致。" 阅读 butterbian-xfce-0.4.0-trixie-20260826.iso 的其余内容。
