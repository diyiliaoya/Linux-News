Apple M4 与 Apple A18 Pro 的初步支持进入 Linux 7.4

Linux 7.4 内核合并了大量 SoC 补丁，新增对 Apple M4、A18 Pro、Google Tensor G5 以及两款未发布高通 SoC 的初步支持。Apple M4 目前仅能启动内核并显示控制台，多数功能尚未支持。此外还加入 Steam Frame VR 头显主线支持及一款 RISC-V 开发板。

大量 SoC 补丁已进入内核，为数十款新开发板以及包括 Apple M4 和 MacBook Neo 中所见的 A18 Pro 在内的多款新 SoC 提供支持。Google Tensor 5 也终于随 Pixel 10 设备一起进入主线。此外还有一些未发布的高通 SoC 支持为这批更新画上句号。

仅 Linux 7.4 的高通支持就包括两款新 SoC 并启用 22 款开发板。新 SoC 代号为 Hawi 和 Nord，采用定制的 Oryon 核心。Hawi 和 Nord 的产品名称尚未公布——很高兴看到早期上游支持！

高通硬件的新开发板覆盖范围包括七款使用高通 Dragonwing SoC 的手持游戏设备。

可以说最引人注目的是内核终于有了基本的 Apple M4 支持以及 A18 Pro 支持。但就像最近主线内核中的 Apple M3 启用一样，这足以启动内核并显示控制台，但除此之外，大多数功能/特性尚未被主线内核支持，实际体验会因情况而异。M4 设备树适用于 MacBook Pro（14 英寸，M4，2024）、iMac（24 英寸，2x USB-C，M4，2024）、iMac（24 英寸，4x USB-C，M4，2024）、MacBook Air（13 英寸，M4，2025）、MacBook Air（15 英寸，M4，2025）和 Mac Mini（M4，2024）。

去年 Pixel 10 智能手机所使用的 Google Tensor G5“Laguna”也终于获得主线内核支持。

Linux 7.4 的 SoC 拉取请求中另一个非常令人兴奋的新增内容是 Steam Frame VR 头显的主线支持。

对于 Linux 7.4，只新增了一款 RISC-V 开发板，即搭载 T-Head TH1520 SoC 的 Milk-V Meles 单板计算机。

计划在 Linux 7.4 中移除大量 32 位 ARM 代码。但由于 Linux 7.3 还是 7.4 将成为今年的 LTS 内核尚未确定（希望是 v7.4！），该计划至少推迟到 Linux 7.5。
