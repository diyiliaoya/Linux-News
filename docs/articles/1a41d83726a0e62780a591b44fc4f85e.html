GNOME 的 Git 客户端 Gitte 日趋成熟

GTK4 驱动的图形化 Git 客户端 Gitte 发布 v0.10 版本，新增并排差异对比、Git LFS 与子模块支持、工作流快捷键及多项界面改进，并修复了若干错误。与此同时，GNOME 51 计划于 9 月 16 日发布，将带来自定义指针加速配置等更新。

对于寻求 GNOME 或整个 Linux 桌面图形化 Git 客户端的用户来说，由 GTK4 驱动的 Gitte 持续发展得相当不错，本周发布了其 v0.10 版本。

Gitte 0.10 在其 GTK4 界面中新增了并排显示差异（diff）的功能，支持 Git LFS 和子模块，增加了用于增强工作流的新快捷键，以及各种界面改进。
