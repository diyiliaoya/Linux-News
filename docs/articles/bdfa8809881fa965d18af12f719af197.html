XWayland 26.1 RC1 发布，带来众多新特性

2026年8月19日，上午10:11（美国东部时间）

Red Hat 的 Olivier Fourdan 今天宣布了 XWayland 26.1 的首个候选版本（RC1）。这是自 2024 年 XWayland 24.1 以来的首个新特性版本！因此，其中包含了许多新特性。

XWayland 26.1 为在 Wayland 环境中运行 X11 客户端带来了许多新功能和改进。XWayland 26.1 改进了其 rootful 实现、与 X Input 2 的多席位兼容性、支持 Wayland fixes 协议、改进的 RandR 模拟、支持 XDG System Bell 协议以及其他更改。它还移除了 EGLStream 支持，因为 NVIDIA Linux 驱动栈现在无需它也能正常工作。

* 移除了 EGLStream 支持。

* Xwayland rootful 实现了剪贴板/主选择桥接（通过 "-clipboard" 启用），允许在 rootful Xwayland 与 Wayland 桌面其他部分之间进行复制/粘贴。

* 通过 Xi2 实现多席位：Wayland 席位及其设备被镜像到 XInput 2 层次结构中。

* 支持 "wl_fixes"，即 destroy_global 和 ack_global_remove。

* RandR 模拟现在优先使用原生模式，最高可达物理分辨率，并且模拟模式现在考虑旋转。

* Xwayland rootful 全屏默认使用实际输出分辨率，而不是将 640x480 的分辨率放大。

* 支持 xdg-system-bell：当合成器支持时，Xwayland 现在通过 Wayland 系统铃协议响铃。

自 XWayland 24.1 以来，由于两年的变更积累，总计有数百项更改。有关 XWayland 26.1 RC1 的下载和所有工作的更多详细信息，请参阅邮件列表公告。目前还没有关于新的 X.Org Server 特性版本的消息，只有独立的 XWayland。
