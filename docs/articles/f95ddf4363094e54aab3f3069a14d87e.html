GNOME 的 Dhruva Dock 扩展重现了老派桌面风格

Dhruva Dock 是一款高度可定制的 GNOME Shell 扩展，提供浮动或边缘停靠样式，支持多种动画效果、模糊背景和预设主题（如 Ubuntu、macOS、Windows）。它包含应用启动器、窗口预览、媒体播放器等小部件，但存在一些 bug，如启用某项功能可能导致另一项失效。该扩展支持 GNOME 45 至 51，适合喜欢复古桌面特效的用户尝试。

自 2011 年 Unity 成为默认桌面以来，Ubuntu 就在屏幕左侧放置了一个 dock（或者叫启动器），2017 年切换回 GNOME 时也保留了这一设计。如果你想要一些不同的东西，比如带有炫酷效果的浮动 dock，或者集 dock 与面板于一体的设计，有很多替代方案可供选择——但通常你只能二选一。

最近引起我注意的是 Dhruva Dock。它被宣传为 GNOME Shell 的“可定制”dock，经过几天的试用，我可以肯定它确实名副其实。

Dhruva Dock 几乎无所不能

在这个扩展中，炫酷至上。它包含一键预设，可将 dock 塑造成知名桌面的风格，包括 Ubuntu、macOS 和 Windows。但这些只是调整的起点。就像过去的 Linux dock（以及其它类似工具）一样，这个 dock 非常注重定制化。

它有大量的动画效果，包括鼠标悬停在 dock 图标上时的放大缩放、点击图标启动应用时的可爱花式效果（弹跳、果冻等），以及最小化窗口时的视觉提示，比如必不可少的魔法灯效果。

我的截图都显示 dock 位于屏幕底部，但它可以放置在屏幕的任何边缘。

尽管这些效果很花哨（有些情况下还有点小故障），但很高兴看到一个 dock 倾向于有点张扬——不过那些更花哨的装饰并非强制。

dock 的外观也是可配置的，你可以设置透明度和颜色，并在静态模糊或动态模糊之间选择（前者允许你选择一张图片进行模糊，后者使用实时壁纸），从而调整出符合你品味的 dock 美学。

一个选项丰富的 GNOME 桌面 dock

喜欢小型浮动 dock，还是与顶栏集成的边缘到边缘 dock？这个扩展两者都能做到——或者介于两者之间。小部件包括一个类似仪表盘的部件和一个可选的图标等。

常见的 dock 设置也一应俱全，包括大小、位置、自动隐藏和躲避行为。你还可以启用窗口预览、应用窥视和显示桌面按钮，并为运行中的应用选择指示器样式。

这里几乎没有什么是固定的（好吧，除了它的首选项窗口，该窗口无法从右侧优雅地调整大小，会截断选项和标签）。

如果这种可塑性有代价的话，那就是精细度。它有 bug，包括一些启用一项功能却莫名其妙禁用另一项的情况。

可以原谅也可以修复（毕竟这是开源软件）。这里展现的雄心？我很共鸣（这么说吧）——不过，我基本上是在直播博客记录那个黄金年代的人。

想自己试试吗？

支持 GNOME 45 到 GNOME 51。如果你使用的是 Ubuntu 24.04 LTS 或更高版本，可以去玩玩；记得先禁用（某个东西），否则你可能会迷失方向。

除了古怪的首选项窗口，我试用的版本中还有：一个设置组合意味着如果我启用了某个小部件，然后添加一个自定义文件夹，它就会消失。模糊设置一度完全消失，改变边缘偏移的控制也消失了。而且当存在小部件时，调整 dock 背景的缩放动画需要更长时间才能恢复到静止状态，就像它先吸附到一个值，然后才想起重新计算实时值。绝对是微不足道的 bug，但我还是提一下。
