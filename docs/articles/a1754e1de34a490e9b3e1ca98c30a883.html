HyprBSD 提供基于 Wayland 的 FreeBSD 桌面，并支持 Steam 游戏

HyprBSD 是一个基于 FreeBSD 15.1-RELEASE 的新桌面发行版，提供基于 Wayland 的 Hyprland 桌面环境，支持 AMD、Intel 和 NVIDIA 显卡，并附带图形安装器。它通过 FreeBSD 的 Linux 兼容层运行 Steam，已验证可运行多款游戏，包括受 BattlEye 保护的游戏。该项目由资深 FreeBSD 管理员 Sam Sheridan 创建，旨在提供开箱即用的流畅桌面体验，目前处于候选发布阶段。

FreeBSD 一直在努力改善其桌面和笔记本电脑体验，但这项工作尚未以发布形式出现在操作系统安装程序和其他持续进行的努力中。现在，一个新的 FreeBSD 桌面发行版 HyprBSD 登场了，它提供基于 Wayland 的桌面体验，并借助 Linux 二进制兼容层，甚至为通过 Steam 玩游戏提供了一条便捷途径。

在因 FreeBSD 开箱即用的桌面体验（尤其是围绕 NVIDIA 显卡驱动）感到沮丧之后，拥有 25 年以上经验的 FreeBSD 管理员、IT 顾问 Sam Sheridan 着手创建了 HyprBSD，以提供良好的开箱即用体验。多年来，也有其他一些旨在提供良好 FreeBSD 桌面体验的努力，例如……

HyprBSD 目前基于 FreeBSD 15.1-RELEASE，附带一个图形安装程序，可在约三分钟内让系统启动并运行。支持 AMD、Intel 和 NVIDIA 显卡。对于基于 Wayland 的桌面体验，他们使用了 Hyprland 合成器。

HyprBSD 通过 FreeBSD 的 Linux 兼容层让 Steam 运行起来，并已验证可与多种游戏兼容，包括受 BattlEye 保护的游戏。XWayland 也能正常工作，以支持依赖 X11 的软件。其中许多修改也可以对原版 FreeBSD 安装进行，但这里的意图是提供更顺畅、更精致的开箱即用用户体验。

作为这项新计划的一部分，还对 FreeBSD 进行了各种修复，以进一步增强 FreeBSD 在桌面上的表现。
