Arch Linux 与 CachyOS 及 Omarchy 4.5 性能基准对比

2026 年 11 月 6 日上午 09:55 EST 发布。

CachyOS 最近推出了基于 Linux 7.3 的内核及其他多项改进，同时 Omarchy 4.5 于本周发布，本文旨在展示 CachyOS 和 Omarchy 相对于上游 Arch Linux 在性能方面的竞争表现。

测试在一台搭载 AMD Ryzen AI Max+ 395 "Strix Halo" 处理器、64GB 内存、集成 Radeon 8060S 显卡和 2TB WD_BLACK SN7100 NVMe SSD 的电脑上进行，三个 Linux 发行版均在此系统上测试。

Arch Linux 使用通用 archinstall 配置并搭配 KDE Plasma 桌面安装，CachyOS 采用默认设置安装并更新，Omarchy 4.5 也使用其原版安装。

测试时，CachyOS 运行 Linux 7.3 内核，而 Omarchy 和上游 Arch Linux 仍为 Linux 7.2。三者均使用 GCC 16.2。值得注意的是，Omarchy 默认开箱即用性能模式，而 Arch Linux 和 CachyOS 在此笔记本上默认为平衡性能模式。CachyOS 还包含大量开箱即用的优化，包括针对 Zen 4+ 优化的软件包和其他调优。

这是我们首次观察 Omarchy 相对于 Arch Linux 和 CachyOS 的性能表现，让我们来看看。
