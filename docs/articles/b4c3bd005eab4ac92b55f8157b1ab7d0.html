Gentoo 需要你的帮助！多家赞助商已撤出

Gentoo Linux 项目因多家长期赞助商撤资，正面临基础设施支持危机。该项目主要依赖赞助的服务器、虚拟机和托管资源运行，现公开征集新的基础设施赞助商，接受虚拟机、物理服务器、机架空间、捐赠设备或资金支持。项目尤其急需美国以外的托管容量，并优先考虑认同其开源理念的支持者。

他们愿意接受虚拟机、物理服务器、机架空间、捐赠机器或托管资金。

许多开源项目仅靠善意维持运转，贡献者投入时间却不求回报。而另一些项目则依赖外部支持，如现金、捐赠硬件或由他人承担托管费用。

这类支持很少受到关注，但这些需求是任何认真寻求发展的项目最基础的方面之一。

Gentoo 属于第二类。这个基于源码的 Linux 发行版围绕 Portage 包管理器构建，主要依靠赞助的基础设施运行，因为它只能维持少数关键机器。

遗憾的是，许多多年来一直支持 Gentoo 的赞助商已决定停止贡献。该项目现在正在寻找替代者，并公开征集基础设施赞助商。

Gentoo 的维基页面列出了俄勒冈州立大学开源实验室、CDN77、惠普和 Hetzner 等名称，但可能尚未反映已退出的赞助商。

Gentoo 寻找赞助商

Gentoo 列出的部分赞助商。

根据 Gentoo 维基页面，有五种帮助方式，优先考虑认同该项目尊重选择、对用户驱动变更保持开放理念的支持者。

第一种方式是接受用于该项目美国托管地点的虚拟机。他们要求不高；任何足以处理当今服务器相关任务的配置都是不错的捐赠。

第二种是主机托管，一种物理托管形式。赞助商提供机架空间、电力和网络连接，Gentoo 负责寻找放入其中的硬件。目前他们最迫切的需求是美国以外的容量，不过来自美国的提议也欢迎。

第三种是虚拟机，最低配置为 2 个 vCPU、4GB 内存和 25GB 存储。该项目表示，他们尽可能更多地依赖云，但许多服务是单体式的，Kubernetes 并不适合他们。

第四种是全包式托管物理服务器。维基给出了两个例子：像 Hetzner 提供的那种专用服务器，或者赞助商提供较旧或未使用的服务器，Gentoo 获得完全远程访问权限。

在第二种情况下，赞助商仍拥有和管理硬件，而 Gentoo 负责操作系统和远程管理，只要求在发生任何迁移事件前提前通知。

第五种是资金。任何捐赠的资金都将用于支付主机托管和托管费用。

Gentoo 远非唯一需要这类支持的项目。

LVFS，即 Linux 的固件更新服务，曾严重依赖 Linux 基金会和红帽，Framework 和开源固件基金会每年出资 1 万美元。
