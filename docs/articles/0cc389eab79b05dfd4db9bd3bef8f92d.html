备受期待的 Linux 多功能工具 Flipper One 现已开放预购

Flipper Devices 正式发布 Linux 多功能工具 Flipper One，搭载 RK3576 芯片、8GB 内存、Wi-Fi 6E 和 M.2 扩展，Kickstarter 售价 399 美元且无利润销售。该设备定位为口袋大小的 Linux 计算机和网络工具，采用双处理器架构，运行基于 Debian 的 Flipper OS，支持多种配置文件切换，并与 Collabora 合作推动 RK3576 进入主线 Linux 内核。

备受期待的 Linux 多功能工具 Flipper One 现已开放预购

这款开源 Linux 多功能工具搭载 RK3576 芯片、8 GB 内存、Wi-Fi 6E 和 M.2 扩展，Flipper Devices 表示将以零利润销售。

我拥有一台 Flipper Zero。对于任何有黑客思维的人来说，这都是一个有趣的小设备，那种你用来碰触 NFC 标签、红外遥控器和 Sub-GHz 信号，只为看看会发生什么的小工具。

所以当 Flipper Devices 首次展示 Flipper One 时，我以为它只是规格升级。事实并非如此。

Flipper One 首次发布时，这是一台口袋大小的 Linux 计算机，同时也是一款严肃的网络工具。简而言之，它比前代产品能力强大得多。

现在它正式发布了。Flipper One 的 Kickstarter 众筹活动现已上线，定价为 399 美元。这是 Flipper Zero 价格的两倍，你可以把这大幅涨价归咎于 AI 时代的芯片短缺。

Rockchip RK3576（8 核）+ Raspberry Pi RP2350 协处理器

8 GB LPDDR5 内存，64 GB UFS 存储

Wi-Fi 6E、千兆以太网、内置 eSIM

M.2 和 GPIO 模块（5G、LoRa、SDR）

Flipper One 在 Kickstarter 上售价 399 美元。之前购买了 20 美元预购优惠券的用户被承诺可享受 379 美元的价格。

Flipper Devices 也明确表示，这不是 Flipper Zero 的继任者。Zero 离线工作，直接与 NFC、RFID、红外和 Sub-GHz 无线电等物理事物交互。Flipper One 则向上移动到网络计算层：高速连接、数据处理和真正的设备端计算。

在内部，它采用双处理器设置。八核芯片运行 Linux、网络、USB 3 和视频输出。一个低功耗的 256x144 灰度显示屏、按钮和电源。这意味着即使主 Linux 操作系统未使用，屏幕和按钮也能继续工作。

网络方面才是真正有趣的地方。它可以同时管理多达五个上行链路，充当热点，运行 VPN 和防火墙，扫描有线和无线网络，并分析 Wi-Fi 流量。内置的 eSIM 附带 Flipper SIM 数据套餐。

它还可以兼作电池监测器，跟踪自身电量以及你插入的任何设备。

通过 USB-C DisplayPort Alt Mode 将其连接到显示器，它就能变成台式计算机。或者将其连接到电视，用作媒体盒子。它是一款多功能设备。

Flipper OS 与主线内核

我喜欢他们投入精力开发了一个名为 Flipper OS 的自定义操作系统，这是一个基于 Debian 的系统，你可以在针对不同任务的预配置配置文件之间切换：网络路由器、无线电实验室、桌面、电视媒体盒子。

每个配置文件都有自己的设置、内核和应用程序。你在 Linux 加载之前从启动菜单中选择一个。你的更改保存在覆盖层中，因此如果你搞砸了，可以将配置文件擦除回默认状态。正如他们所说，自由实验。

Flipper Devices 还与 Collabora 合作，将 RK3576 纳入主线 Linux 内核。该设备已经运行在主线内核上，DisplayPort Alt Mode 补丁正在审核中。目标是打造一台没有二进制固件块的 ARM 计算机。任何在 ARM 板上与厂商 BSP 斗争过的人都会欣赏这一点。

还有一些工作要做。团队正在研究动态内存频率调节以提高能效，并移除启动过程中剩余的少数闭源部分。所有这些都在公开知识中，可在 Flipper 开发者门户上获取。

399 美元定价，零利润！

全球内存短缺使内存价格波动剧烈（或者我应该说是充满敌意）。Flipper 表示，内存和 UFS 存储现在占 Flipper One 总硬件成本的一半以上。

他们没有等待或提高价格，而是以成本价销售硬件，并押注社区来资助首次生产。大胆的举动，还是内存定价已经糟糕到何种程度的标志？可能两者兼有。
