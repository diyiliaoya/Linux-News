Dropbeat：GNOME Shell 又一款炫酷音乐控制器

Dropbeat 是一款面向 GNOME Shell 的面板音乐小程序，为 MPRIS 兼容的 Linux 音乐播放器提供暂停、播放和切歌的替代控制方式。它通过当前歌曲的专辑封面生成模糊背景，并支持点击封面进入沉浸式全屏模式，还提供可配置的全局快捷键。尽管功能与内置媒体控件相似，但其全屏视觉效果和快捷操作增添了亮点。目前不支持将播放器窗口前置，也不会禁用 GNOME Shell 自带的媒体控制器。适用于 GNOME 48 至 50，可通过 GNOME Extensions 网站或 Ubuntu 软件中心安装。

Dropbeat 是 GNOME Shell 又一款炫酷的音乐控制器，它是一首老曲调的新变奏：一个基于面板的音乐小程序，为支持 MPRIS 的 Linux 媒体播放器提供暂停、播放和跳曲的替代方式。

这类小程序数不胜数，而这个面板小程序并没有比你过去尝试过或正在使用的那些（想要花哨功能，可以试试那个）有太多不同。

但它确实在某些方面有所不同。

安装后，它会在你的面板上添加一个按钮，点击后，“显示一个炫酷的卡片来控制你的媒体播放器”，引用其描述，利用当前播放歌曲的专辑封面生成模糊画布。然后，它以此作为面板小程序和全屏模式的背景。

这种方法的一个明显缺点是，当你切换曲目时，模糊背景通常需要片刻才能出现，小程序也需要时间跟上，这在快速跳过曲目时会破坏乐趣，但嘿：每个人都是批评家。

点击专辑封面将进入全屏模式。专辑封面、曲目标题和艺术家名称在模糊背景上大号显示：

通过点击专辑封面轻松激活沉浸式全屏模式

第三点也是最后一点，它支持可配置的全局快捷键，无论何时都能切换打开卡片，无需将鼠标移出当前操作，这可能很方便。

当然，如果你想访问其他媒体播放器功能，如收藏曲目、调节音量、启用随机播放或循环，或在曲目内快进，你仍需进入应用本身（或使用其他小程序）。

目前，Dropbeat 没有将播放器窗口前置的方式，这是其他插件和应用能做到的。它也不会在激活时禁用 GNOME Shell 自带的媒体控制器，所以你仍会在通知列表中看到它。

它是否做到了 GNOME Shell 内置媒体小部件能做的一切？是的，虽然两者都将控制项隐藏在视线之外，直到你主动寻找，但 Dropbeat 加入了由专辑封面构建的全屏视图，为操作增添了一些额外炫酷效果。

如果你喜欢它的外观，可以通过网络浏览器在 GNOME Extensions 网站上获取，或者通过桌面应用（在 Ubuntu 软件源中可用）减少麻烦。

Dropbeat 支持 GNOME 48 至 50。

喜欢这种风格但不喜欢样式？有一个流畅的替代方案，提供实时歌词，并能嵌入 Ubuntu Dock 而非面板。对于非扩展方案，还有一个可自定义的桌面“正在播放”小部件。
