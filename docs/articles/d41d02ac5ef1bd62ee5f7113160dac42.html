Linux 7.3-rc1 接近 4100 万行代码，AMD 内核图形驱动达 650 万行

Linux 7.3-rc1 版本即将发布，其代码规模已接近 4100 万行。其中，AMD 内核图形驱动（包括 AMDGPU、AMDKFD 及相关显示代码）占据了约 650 万行，占整个内核的约 16%。Linus Torvalds 在发布公告中指出，本次版本中 AMD GPU 寄存器头文件（如 DCN6.0）的引入是补丁规模庞大的主要原因，约占 rc1 补丁的三分之一。与上一版本 7.2 相比，内核代码增加了约 56 万行。预计 Linux 7.4 将轻松突破 4100 万行。

Linux 7.3-rc1 接近 4100 万行代码，AMD 内核图形驱动达 650 万行

2026年8月30日晚上8:23 EDT

Linus Torvalds 在 Linux 7.3-rc1 发布公告中提到，AMD 内核图形驱动的改动约占 -rc1 补丁的三分之一，原因是 AMD 为 DCN 6.0 和其他新 IP 添加了庞大的 GPU 寄存器文件。以下是一些最新的代码统计。

随着 AMD 在 Linux 7.3 中为即将推出的图形硬件启用新的硬件 IP 块，内核的规模也随之膨胀。Linus 在 7.3-rc1 公告中指出：“这个版本的实际补丁规模也很大，原因并不令人意外：这又是一个包含大量 AMD GPU 寄存器转储的版本。这次是 AMD DCN6 寄存器头文件。它们非常庞大，一如既往。当你把所有硬件定义以 C 头文件 #define 的形式转储出来时，就会得到这样的结果。此外还有与新代际配套的代码。总而言之，AMD GPU 代码和头文件转储约占整个 rc1 补丁的三分之一。”

根据 Linux Git 树在 v7.3-rc1 时的数据……

Linux 7.3-rc1 的代码量达到 4098 万行。其中包括 5,134,418 行空行（由 cloc 检测）、4,912,366 行代码注释，以及 30,937,090 行实际代码。相比之下，Linux v7.2 的代码量为 4042 万行。可以肯定地说，Linux 7.4 的代码量将轻松超过 4100 万行。

这包括头文件、AMDGPU 内核图形驱动、AMDKFD 计算驱动，以及相关的显示代码和其他部分，总计 652 万行。这还不包括位于该目录之外的经典 Radeon DRM 驱动（用于 pre-GCN 硬件）。因此，现代 AMD 内核图形驱动代码现在约占 Linux 内核的 16%。在 Linux v7.2 中，cloc 测得为 635 万行。

内核持续增长。考虑到 AMDGPU/AMDKFD 驱动以及整个 Linux 内核的开发方式，这并不特别出人意料，但至少这些是当前的数据，供好奇者参考。
