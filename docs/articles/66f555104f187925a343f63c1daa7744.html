我们终于复活了Firefox扩展（晚了10年）

OMG! Ubuntu 官方 Firefox 扩展在中断十年后重新上线。该扩展提供工具栏图标，点击可显示最新12条头条（含缩略图），支持未读计数、跨设备同步、桌面通知等功能。与Chrome版本功能几乎一致，但缺少通知按钮支持。扩展不持续后台运行，而是定期唤醒检查更新。

我们终于复活了Firefox扩展（晚了10年） - OMG! Ubuntu

官方 OMG! Ubuntu Firefox 扩展回来了——尽管比计划晚了很多（对此表示抱歉）。

过去十年里，这个扩展会让人感到熟悉，因为它和以前一样，只是现在在Firefox上。外观相同，（几乎）功能也相同，因为它是同一个东西（尽管API名称有所更换，manifest也有调整）。

这并非本博客首次提供Firefox扩展。我们的旧版扩展在2017年失效了，虽然我们本想修复它，但十年就这么一晃而过。

与Chrome版本一样，它提供了一种快速、低开销的方式来浏览最新头条，仿佛你正身处Web 2.0的巅峰时代（还有人记得Firefox的实时书签吗？）。

OMG! Ubuntu Firefox通知器

我们的扩展能做什么？嗯，它不会帮你洗袜子。

它会在工具栏添加一个图标，点击后弹出一个可滚动的列表，显示来自本站的最新12条头条（含缩略图）。工具栏图标上有一个徽章计数，显示有多少未读文章（最多12篇）。刷新按钮可检查新文章。

你无需保持标签页打开（这个功能让我很暖心），也无需访问首页（当然，经常访问首页的朋友们，我依然爱你们），因为新闻会主动来找你。

如果你登录了Mozilla账户，未读计数会在所有安装了该扩展并登录同一Mozilla账户的设备上同步（我们的Chrome版本也实现了这一点，不过使用的是原生同步功能）。

未读文章旁边有一个橙色书签标记。点击书签可将该文章标记为已读，而无需打开阅读。或者，你也可以让它保持未读状态，作为提醒稍后回来查看。底部有一个“全部标记为已读”按钮，以防——天哪——没有哪篇文章吸引你。

点击列表中的任意文章，即可在浏览器的新标签页中直接阅读。是的，是新标签页；这不是浏览器中的浏览器，所以弹出窗口中没有移动端视口。点击文章阅读时，它会自动标记为已读。

我们的扩展不会持续在后台运行。相反，它会定期唤醒检查新文章，然后继续休眠。如果发现新文章，它会发送桌面通知提醒你。点击通知即可在新标签页中阅读文章。

Chrome版本的通知带有操作按钮，但Firefox不支持这些按钮。

除了访问我们内置的RSS源之外，不需要任何实际权限。与Chrome版本相比，唯一的功能差异是缺少通知按钮（因为Firefox不支持它们）。

目前，你无法在Firefox扩展中禁用通知。我们很快会重新添加这个选项（Chrome已将通知控制移至浏览器本身，因此我们移除了设置页面以保持简洁）。

这只是关注OMG! Ubuntu的另一种方式。

对于这个本质上很简单的工具，我写了太多废话了——我并不指望你会使用它：有很多方法可以随时了解我们的报道：Chrome扩展、macOS上的RSS阅读器、RSS源、社交媒体账号等等。

坦白说，我们重写了Chrome扩展，但没有重写Firefox版本。它之前一直能用，直到突然失效，然后因为只有大约一百人在使用，它的优先级就降低了。我们的Chrome扩展有几千名用户。
