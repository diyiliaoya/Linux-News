发行版发布：NebiOS 10.3

Sarp Mateson 基金会发布了基于 Ubuntu 的桌面 Linux 发行版 NebiOS 10.3 稳定版。该版本采用基于 Wayfire 的自研 NebiOS Wayland 合成器，桌面环境全面重构，新增首次运行设置与欢迎屏幕，支持日文、中文和韩文输入，并实验性支持 Apple Silicon。控制中心重新设计，设置支持搜索，窗口可缩放，顶栏和快速设置采用新外观，启动器与文件搜索性能提升，系统监视器重写并支持 GPU 监控。

发行版发布：NebiOS 10.3

Sarp Mateson 基金会宣布发布 10.3，这是该项目基于 Ubuntu 的桌面 Linux 发行版的最新稳定版本，采用基于 Wayfire 的自定义 NebiOS Wayland 合成器：“NebiOS X 10.3 周年更新已作为稳定版发布。桌面环境已从头重构，新增首次运行设置和欢迎屏幕，可以输入日文、中文和韩文，NebiOS 现在以实验性版本运行在 Apple Silicon 上。桌面环境已从头重构：控制中心经过重新设计，设置中支持搜索并可直接跳转到找到的设置项，窗口现在可随屏幕缩放并可调整大小；顶部面板——显示聚焦应用的图标和名称，旁边有窗口菜单（置顶、粘性、沉浸模式、固定到实用面板、最小化、最大化、关闭），当客户端触碰时变为黑色，桌面聚焦时透明；快速设置和 OSD——新的深色外观，快照以动画形式呈现而非实时界面，因此在负载下保持流畅；启动器——打开和滚动更快，文件搜索使用真实索引，图标异步加载；小部件——系统监视器已重写（GPU、网络、电池、磁盘、交换和温度，AMD 上的 GPU 使用率以及使用专有驱动的 NVIDIA）……”
