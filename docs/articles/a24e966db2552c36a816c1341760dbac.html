Orion for Linux beta更新新增隐私浏览和链接预览功能

Kagi发布了Orion for Linux的v0.4.1测试版，该版本基于WebKitGTK，新增了隐私窗口、下载管理器、工具栏溢出菜单、链接预览、自定义操作按钮、本地同步等功能，并改进了稳定性与性能。用户可通过Flatpak安装，但需添加Kagi的专属仓库。尽管功能逐步完善，但部分高级特性如网页元素擦除、工具栏图标重排及Chrome扩展支持仍未就绪。

Kagi发布了Orion for Linux的新测试版，这是其macOS和iOS浏览器基于WebKitGTK的移植版本。

Orion for Linux v0.4.1在5月发布的版本基础上，增加了更多macOS和iOS版本中的功能，并改进了现有功能。

新测试版新增了可用的隐私窗口、功能齐全（尽管简陋）的下载管理器以及工具栏溢出菜单。溢出菜单允许你隐藏按钮，但又不至于难以访问。

不熟悉Orion？

我在之前的报道中介绍过这个浏览器是什么以及它为何存在。本文仅关注v0.4.1的新内容。

链接预览功能也登陆Linux。这不是那种“AI摘要”式的预览（谢天谢地）。更像是macOS上网页的“快速查看”；你可以预览当前页面上的链接，而无需打开新标签页。

在这个测试版中，没有键盘快捷键来激活链接预览——macOS用户可以通过按Command+点击来触发——但在右键点击链接时会出现上下文菜单项。预览窗口无法调整大小，但有一个“在标签页中打开”按钮：

在Orion for Linux 0.4.1中预览链接而无需打开它们

此外，v0.4.1测试版还包含了Orion的可编程按钮功能。这些按钮允许你创建自定义工具栏按钮，按需运行代码或对网页应用条件，类似于书签小工具。它们可以放在工具栏上，或隐藏在溢出菜单中。

你可以使用浏览器内置编辑器手动添加和编辑这些操作按钮。也可以从URL导入现成的按钮。Orion的GitHub上有一个开源可编程按钮仓库，如果你需要一些灵感的话。

本地同步支持也加入了此测试版，这很受欢迎。

iOS和macOS版本的Orion使用iCloud在平台间同步书签、标签页等。Kagi计划未来提供自己的云同步后端，但就目前而言，你现在可以将关键数据导出为文件，并导入到另一个构建中。

有一个选项可以在新标签页中打开页面（如果网站加载失败，也会显示一个按钮），并且你可以在地址栏中添加和使用自定义搜索引擎。

更多基础浏览器快捷键，包括Ctrl+L聚焦地址栏、Ctrl+T新建标签页等。

Kagi表示，此构建提升了浏览器的整体稳定性和性能，界面也更加精致和打磨。智能跟踪防护现已对所有WebKit网络会话启用。

然而，Orion的许多新颖浏览器功能，如擦除网页元素，尚未移植或仍处于重度开发中，一些核心浏览器能力，如重新排列工具栏图标或使用Chrome扩展，同样尚未就绪。

如何安装Orion的Linux测试版

Orion for Linux并非完美，但一直在进步

Orion for Linux可通过Flatpak在所有主要发行版上安装，但不在Flathub上。Kagi已建立了自己的Flatpak仓库。

如果你在Ubuntu上使用Flatpak，添加新的Orion浏览器Flatpak仓库：

flatpak remote-add --if-not-exists orion-beta https://flatpak.orionbrowser.com/orion-beta.flatpakrepo

然后，安装Orion for Linux（测试版）：

flatpak install orion-beta com.kagi.Orion

由于Orion是GTK4/libadwaita应用，它依赖GNOME 50运行时。如果你的系统没有该运行时，它会在你安装第一个需要它的应用时一并下载。

要更新到未来的测试版，请从终端运行此命令：

flatpak update com.kagi.Orion

或者，你也可以使用GUI包管理器（如GNOME Software）更新Flatpak软件。两者都在Ubuntu 26.04 LTS仓库中可用。

测试版就是测试版，各位

Kagi表示，这个测试版“让Orion感觉更接近日常使用”，但请记住，它仍然是一个测试版。
