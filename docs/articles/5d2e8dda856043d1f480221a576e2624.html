FFmpeg 9.0 发布：更多 Vulkan 加速、动画 WebP 及更多 AMD AMF 支持

2026年8月3日，美国东部时间晚上8:49。

FFmpeg 9.0 现已作为这一广泛使用的开源多媒体库的最新功能版本发布。

FFmpeg 9.0 包含大量重大改进，包括更多 Vulkan API 加速工作，例如 Vulkan APV 视频解码、Apple ProRes RAW Vulkan 加速、Vulkan v360 视频滤镜，HE-AAC 960 解码，NVIDIA CUDA 转置滤镜，动画 WebP 解码与解封装，持续的 AMD AMF 增强，以及更多 AVX-512 优化。

官方 FFmpeg 更新日志将 9.0 版本的重点列出如下：

- 扩展 AMF 色彩转换器（vf_vpp_amf）的 HDR 能力

- MP4 封装器中支持 LCEVC 轨道复用

- Playdate 视频编码器和封装器

- 新增 v360_vulkan 滤镜

- HE-AAC 960 解码（DAB+）

- transpose_cuda 滤镜

- 新增 AMF 帧率转换器（vf_frc_amf）滤镜

- SMPTE 2094-50 元数据支持与透传

- ProRes RAW VideoToolbox 硬件加速

- 动画 WebP 解码器

- 动画 WebP 解封装器

- 移除 CELT 解码支持（不影响 Opus CELT）

- 移除 ogg/celt 解析

- 用于分割 Dolby Vision 多层 HEVC 的比特流滤镜

- 新增 AMF 硬件内存映射支持

- ONNX Runtime DNN 后端，支持 GPU 执行提供程序

- 移除已弃用的 NVENC 选项及对 11.1 之前 SDK 版本的支持

- 新增 AMF 视频质量增强器（vf_vqe_amf）滤镜

那些从源代码构建的用户可以着手编译，以获取这些最新的多媒体库功能。
