Linux Mint 将自动删除旧内核版本

Linux Mint 宣布对其内核管理进行全面改革，现在将每周自动删除旧内核。内核管理从系统管理工具中移出，并按系列而非单个版本跟踪内核。用户可以选择跟踪哪些内核系列，以及每个系列中保留的旧内核数量。受保护的内核不会被删除，自定义内核也可标记为受保护。手动清理按钮可立即释放空间，且提供已删除内核的列表。此更改可能通过软件更新到达现有用户，或随 Linux Mint 23 发布。

Linux Mint 宣布对其内核管理进行全面改革，现在将每周自动删除旧内核。

内核管理将从标准版和 LMDE 版本的系统管理工具中移出，现在按系列而非单个版本跟踪内核。

您可以选择跟踪哪些内核系列，以及系统在每个系列中应保留的旧内核数量（除了您当前启动的内核之外；它不会自拆台脚）。

受跟踪系列的内核更新将像以前一样出现在更新管理器中，但一个显著的变化是，您较旧的、未使用的内核版本将每周自动删除。

项目负责人 Clement Lefebvre 表示，手动“清理”按钮还可让您“立即释放空间”。一个历史按钮将使您能够轻松查看已删除的内核列表及其删除时间。

扩展的内核管理选项（图片：Linux Mint / OMG! Ubuntu）

如果您担心旧内核在后台被删除，不用担心：您有控制权。

单个内核可以标记为“受保护”。这使它们免于被删除，无论其他设置或条件如何。简而言之：要防止特定内核被删除，无论它是否被跟踪，您必须在更新管理器中将其标记为受保护。

从其他系列安装内核，例如 OEM、Azure、IBM、Real Time，将提示工具列出完整系列，并为您提供跟踪它的选项。跟踪会自动安装任何相关的元包和未来更新，因此值得这样做。

虽然您可能安装的自定义内核（例如来自随机 PPA 或 .deb）无法被正确“跟踪”，但您可以将它们标记为受保护，以防止它们在清理过程中被删除。但是，Linux Mint 的工具会警告您，您有责任实际更新它们。

删除未使用的内核释放空间

您可能会惊讶于 Mint 保留了多少内核……

如果您不太关注更新，您可能不知道发布和安装了多少内核更新——并且它们会并排保留安装。在 GRUB 引导加载程序中选择您的发行版的“高级选项”，以查看所有已安装且可引导的内核列表。

在我的一台 Linux Mint 22.3 安装中，我列出了 4 个不同的内核（见上图）以及它们各自的恢复模式。保留它们很有用，但并非严格必要——尤其是多个系列内修订版。

所有这些旧内核都占用空间，如果您从不使用或需要它们（因为当前内核运行良好），那么删除它们是回收数百兆字节空间的简单方法。但是，我建议您保留一个已知的备份内核，以防万一。

Mint 的博客文章中没有明确说明这些更改是否会作为软件更新提供给现有的 Linux Mint 22.3 和 LMDE 用户，还是随 Linux Mint 23“Alfa”（临时代号）一起发布，后者计划于今年年底发布。
