gThumb 4.0 发布，看起来像一款全新应用

gThumb 4.0 正式发布，基于 GTK4 和 Vala 重写，界面焕然一新。新版改进了图像查看器，支持触摸板手势、动画 WebP/PNG 和 JPEG XL 格式，新增审查工具。部分旧功能如网络相册、联系表和查找重复项被移除。Ubuntu 用户可通过源码或 PPA 安装，官方仓库尚未更新。

gThumb 4.0 已发布，看起来像一款全新应用 - OMG! Ubuntu

gThumb 基于 GTK4 和 Vala 的大规模重写已正式稳定并可供下载。

早在五月，我们就曾评论过 UI 刷新给这款应用带来的巨大变化——这款长期存在的照片管理器看起来像一款全新的应用。

gThumb 界面的每一部分都受益于向 GTK4/libadwaita 的移植，后端性能通过使用更新版本的库得到提升，桌面集成也跟上了步伐——在 GNOME 上，使用了带有图标缩略图的现代文件选择器。

图像查看器大幅改进

更多地使用内边距和间距，让一切——编辑工具、文件属性、设置等——都有更多呼吸空间。按钮、工具栏和标签更易于识别，而某些操作（如缩放）的叠加控件会显示在图像上方。

gThumb 4.0 在其编辑套件中新增了一个审查工具（与应用的其余部分一样，它从 GTK4 的升级中受益匪浅）。现在支持动画 WebP 和 PNG 图像，同时图像可以保存为 JPEG XL 格式。

gThumb 4.0 带来了新的审查工具

图像查看器现在响应触摸板手势。水平滑动可在文件之间左右移动，而捏合缩放让你可以——捏合缩放。有带侧键的鼠标？你也可以用它们在图像之间导航。

gThumb 4.0.0 的其他变化：

幻灯片使用微妙的淡入动画

元数据属性被缓存

视频元数据现在显示帧率和采样率

标签现在按名称排序

大图像使用快速缩放算法

使用上/下箭头键进行视频跳转

gThumb 的一些旧功能已从此版本中移除。不包括网络相册，你找不到联系表，而且（巧妙的）‘查找重复项’工具也被去掉了。

在 Ubuntu 上安装 gThumb 4.0

gThumb 4.0 可作为源码从项目的 Gitlab 下载

Flathub 上的 gThumb 列表尚未更新，非官方的 gThumb Snap 也没有更新。其他第三方打包包括一个为 Ubuntu 26.04 LTS 提供软件包的 PPA。

Ubuntu 26.10 的仓库中不包含 gThumb 4.0，sudo apt install gthumb 仍然会拉取基于 GTK3 的版本。

最近也发布了另一个版本，尽管没有使用 libadwaita，因此看起来和以往一样——但这是现代化自身的重要第一步。与此同时，它被设定为与 Gwenview 竞争。
