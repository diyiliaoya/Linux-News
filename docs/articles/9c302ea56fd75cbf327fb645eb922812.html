Framework 99美元无线触控板键盘开启预购

Framework推出售价99美元的无线触控板键盘，现已开启预购。该键盘支持蓝牙连接三台设备，并通过USB-A接收器连接第四台，也可通过USB-C有线使用并充电。内置1200mAh电池，日常使用续航超一个月，闲置超一年。键盘采用剪刀脚结构，键程1.5mm，触控板支持多指手势。目前仅提供美式ANSI布局，预计2027年第二季度发货。

Framework 以其易于维修的笔记本电脑而闻名，但现在它也拓展到了外设领域——无线触控板键盘现已开启预购。

该公司今年早些时候发布了一款紧凑型键盘。与它的笔记本电脑一样，这款产品在设计时也考虑到了可维修性，并提供了 CAD 设计图，因此用户可以使用基于浏览器的工具进行自定义和重新映射。

它还包含一些使其用途广泛的特性。

无线触控板键盘

在许多场景下都实用

Framework 将其无线触控板键盘宣传为“适用于你的媒体电脑、树莓派或房间另一头任何电脑的紧凑、坚固键盘”。

它可以通过低功耗蓝牙与最多三台设备配对，并通过 USB-A 接收器连接第四台设备。切换设备只需快速按键，无需使用组合键或执行开关机流程。

通过 USB-C 线缆连接时，它也可以有线工作，内置电池也通过这种方式充电。据说 1200mAh 的锂聚合物电池在日常使用下可续航一个多月，闲置时可超过一年。如果电池耗尽，也可以轻松更换。

便捷的连接与酷炫的设计

内置触控板在 Windows、macOS 和 Linux 上支持多指手势。其尺寸为纵向 68.8 × 85.6 毫米，如果你更习惯在全尺寸触控板上随意滑动手指，可能会觉得它作为主要输入设备有些受限。

对于挑剔的手指来说，按键采用剪刀脚结构，键程为 1.5 毫米。作为对比，这比苹果的妙控键盘多 0.5 毫米。

对于非美国用户来说，一个缺点是它仅提供美式 ANSI 布局，因此没有 ISO 选项（带有大型 L 形回车键和额外按键），也没有任何非英语或非 QWERTY 版本。

Framework 确实鼓励任何想要购买不同语言或布局版本的人通过产品信息页面上的表格登记兴趣——该页面也是可以预购的地方。

如果你感兴趣，Framework 无线触控板键盘已在美国、英国和其他国家开放预购，售价为 99 美元/99 英镑（定金 50 美元/50 英镑）。

新订单的发货时间预计为 2027 年第二季度，所以别指望这个圣诞节就能从圣诞老人那里收到它！

Framework 笔记本电脑用户可能会有兴趣听说，一款可 discreetly 容纳 USB-A 接收器的扩展卡正在计划中。
