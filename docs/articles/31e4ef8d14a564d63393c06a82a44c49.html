Ubuntu 26.10 amd64v3 可为低端/预算硬件带来显著提升

2026 年 9 月 16 日 下午 01:37 EDT

Canonical 最近开始制作 Ubuntu 26.10 amd64v3 每日 ISO，以补充他们过去几个发布周期一直在试验的 amd64v3 软件包档案。虽然我们仍不清楚 Ubuntu 26.10 对 amd64v3 的官方计划是什么，但即使对于低端/预算硬件，相比通用 amd64 二进制文件，性能提升也非常值得。

过去在 Phoronix 上的许多基准测试都是针对高端硬件进行的，因为那是目前实验室中最令人兴奋和有趣的硬件。在那里的性能提升相当不错，因为 amd64v3 / x86_64-v3 构建允许假定支持高级矢量扩展 AVX/AVX2、BMI2、MOVBE、FMA 以及其他较新的 CPU ISA 能力，这些能力自 Intel Haswell 或 AMD Excavator 以来的 CPU 中就已存在。

CHUWI UniBook 是一台售价 449 美元的笔记本电脑，搭载 Intel Wildcat Lake 处理器和 8GB 内存，我在实验室中决定用这台非常入门的笔记本电脑来看看 Ubuntu amd64v3 在低端领域的影响。

在这台 Intel Core 3 304（1 个 P 核 + 4 个 LPE 核）和 8GB 内存的设备上，我运行了 Ubuntu 26.10 amd64 每日版，然后在同一硬件上重复相同过程，但使用所有 Ubuntu 26.10 amd64v3 二进制文件，以查看这对预算型笔记本电脑带来的差异。
