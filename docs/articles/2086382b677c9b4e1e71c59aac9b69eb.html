CachyOS 让 Linux 最大的游戏难题之一变得简单多了

CachyOS 现在为 Easy Anti-Cheat 游戏提供了独立内核。这个 EAC 内核拥有自己的启动项，同时还提供了用于 Btrfs 快照的恢复环境。

CachyOS 是一个既适合高级用户也适合游戏玩家的发行版选择。安装程序提供 17 种以上的桌面环境可供选择，游戏玩家还能获得适用于 Steam Deck 和 ROG Ally 等设备的掌机版。

它基于 Arch Linux，自带内核和针对特定 CPU 的软件包构建，安装程序提供图形界面或命令行版本。

CachyOS 现已发布今年第六个版本，这个版本改变了系统启动、恢复和安装软件的方式。

CachyOS 现在为使用 Epic 的 Easy Anti-Cheat (EAC) Linux v2 的游戏提供了专用内核。EAC 在允许游戏运行前会检查启动链，而新内核使用 CachyOS 密钥进行签名。

别担心，它拥有专用启动项，你常规的启动项保持不变，由脚本处理引导加载程序配置。由于 DKMS 模块无法在此内核上加载，NVIDIA、ZFS 和 r8125 都以预构建软件包的形式提供。

这是一个救援镜像，位于 EFI 分区上，可以从引导加载程序菜单或直接从 UEFI 启动，无需 Live USB。

从其菜单中，你可以启动任何具有可写根目录的 Btrfs 快照，先进行检查，满意后再回滚。回滚也可以通过桌面通知运行。

它无需 Snapper 即可工作，并支持 LUKS 加密磁盘。该软件包是 cachyos-recovery-legacy 变体，专门用于 BIOS 机器。

软件管理器达到 v2.0，拥有全新界面。它现在可以处理 AUR、Flatpak 和 AppImage 软件包，且每项都需要用户主动选择启用。

在运行 AUR 构建之前，你可以阅读 PKGBUILD 和安装脚本，静态分析步骤会突出显示值得仔细检查的内容。更新时会附带与已安装版本的差异对比。

包含 CachyOS 调优配置的软件包带回了系统内存不足终止机制，并默认启用。它根据交换空间使用情况介入，并跳过用户会话。

辅助程序取代了早期 KMS 和相应模块。早期 KMS 过去在启动过程中初始化图形驱动，使 CachyOS 能更早切换到显示器的原生分辨率。

现在，该辅助程序会阻止登录屏幕显示，直到图形驱动加载完成，这适用于任何驱动，而不仅仅是 NVIDIA 的驱动。如果加载失败，屏幕上会显示二维码。

硬件检测工具也相应放弃了早期 KMS，现有用户需要在更新后运行 sudo 命令来应用更改。

使用 CLI 安装程序的步骤，其余部分正在逐步迁移。本身已重构到同一库上。

启动闪屏 Plymouth 现在是可选的，rEFInd + AI SDK 引导加载程序选项已被移除。CachyOS 现在还可以通过新镜像在 Windows Subsystem for Linux 上运行。

最后，内核升级到 Linux 7.3.5，同时包含 NVIDIA 620.73.04 和 Mesa 26.3.1。完整更新日志可在 获取。
