终于来了——从24.04升级到Ubuntu 26.04现已开放

Canonical终于为LTS系统开启了从Ubuntu 24.04直接升级到26.04的通道，用户无需命令行操作即可通过更新管理器完成升级。由于需要修复bug并经过测试，此次LTS到LTS的升级比预期延迟。升级后系统将不再支持在X11/Xorg上运行默认GNOME桌面，但X11应用仍可通过XWayland运行。系统内存推荐要求也从4GB提升至6GB。用户可自行选择是否立即升级，24.04 LTS的支持将持续到2029年。

虽然比预期花了更长时间，但用户现在可以直接从24.04升级到26.04，无需命令行变通方法。

Canonical终于为LTS系统开启了原地升级的开关。系统会弹出通知告知用户有新的LTS版本可用，用户可以立即执行、忽略或选择“稍后提醒”。

Ubuntu 26.04 LTS于2026年4月23日发布，从Ubuntu 25.10的直接升级在ISO下载上线几周后便已启用。

Ubuntu 24.04 – 26.04：有哪些变化？

然而，从24.04 LTS升级到26.04 LTS当时并未开放。Canonical只在新系列的第一个点版本发布后，才会批准LTS到LTS的升级。

Ubuntu 26.04.1 LTS于8月发布，但从24.04的升级因bug而延迟——这些bug需要修复；修复需要测试和打包，然后升级还需要重新测试。

但现在升级已经上线。

长期支持版本被大多数Ubuntu用户使用，而且有整整两年的变更需要迁移，额外的测试能确保更多人放心升级。

用户的配置也各不相同。我怀疑没有哪个读者运行的是操作系统原封不动的状态——没有改过任何设置，也没有安装其他应用。这其中有大量边缘情况需要考虑。

Ubuntu 26.04 LTS的新功能

Ubuntu 26.04 LTS不再支持在X11/Xorg上运行默认的GNOME桌面。

如果你从Ubuntu 24.04升级，Xorg不会从系统中移除，但你在登录界面将无法选择Xorg GNOME会话登录。

X11应用在Ubuntu的Wayland上仍然可以通过XWayland运行，后者仍然预装。

如果你确实需要X11桌面会话，你并非没有选择。Xfce、LxQt、Cinnamon和MATE等替代桌面环境继续支持X11/Xorg——支持它的Linux桌面仍然多于不支持的。

Ubuntu 26.04的系统要求有所提高。该发行版现在建议6GB内存以保证流畅运行，而24.04仅建议4GB。这不是强制的最低要求，所以你可以升级，但如果你的设备内存较低，请留意这一点。

其他变化包括——好的方面：新应用、重新设计的文件夹图标、性能改进、更新的驱动以及一系列额外设置。我的“有哪些变化”指南详细介绍了24.04到26.04之间最大的变化，可以查看了解更多。

从24.04升级到26.04

系统准备好后会提醒你

在从24.04升级到Ubuntu 26.04之前，你需要安装待处理的更新。打开更新管理器，检查并应用列出的更新。

完成后，更新工具会显示“Ubuntu 26.04.x现已可用（你当前是24.04）”，并提供一个“更新…”按钮。点击它即可执行。

或者，你也可以从命令行启动升级：

sudo do-release-upgrade

两种方法都会触发GUI向导引导你完成整个过程。大部分内容不言自明：点击是、点击下一步、等待、点击下一步、等待，如此反复。

有一件事会让一些人害怕，那就是“外部软件包”弹窗。如果你安装了来自Ubuntu主仓库之外的软件包，它就会出现。看起来吓人，但大多数情况下，你只需点击“是”就可以继续升级。

我25.10升级文章中的逐屏操作指南在这里同样适用，因为从24.04升级和从25.10升级的界面和步骤是一样的。

你不必立即升级

尽管Ubuntu 26.04 LTS升级现已开放，但你不需要立即升级。如果你的系统运行良好，而且你并不迫切需要任何新功能，再等一段时间也无妨。

Ubuntu 24.04 LTS的标准支持将持续到2029年，期间会持续提供更新，之后你还可以选择启用Ubuntu Pro，再获得5年的高影响安全修复。
