BSD 发行版：GhostBSD 26.2

GhostBSD 26.2 发布，基于 FreeBSD 15.1-RELEASE，带来全新安装器 Install Station、GELI 全盘加密、更小的 ISO 镜像，以及 GhostBSD 工具的多项修复。新安装器在首次启动时通过 Setup Station 配置网络和创建用户，并支持多语言。此外，Backup Station 更名为 BE Station，Update Station 支持在引导环境中安装升级，NetworkMgr 改用 wpa_cli 管理 Wi-Fi。

Eric Turgeon 宣布发布 GhostBSD 26.2，这是该项目基于 FreeBSD 的桌面操作系统的最新版本，提供 MATE 和 Xfce 桌面环境。此版本将基础系统更新至 FreeBSD 15.1：

“我很高兴地宣布 GhostBSD 26.2-R15.1p6 发布。此版本基于 FreeBSD 15.1-RELEASE，带来了新的安装器、安装器中的全盘加密、更小的 ISO 镜像，以及 GhostBSD 工具中的许多修复。主要亮点：GhostBSD 现在基于 FreeBSD 15.1-RELEASE；新的安装器——Install Station 负责安装系统，然后 Setup Station 在首次启动时配置网络并创建用户；Install Station 新增了 ZFS 页面和网络页面，并已翻译成所有支持的语言；安装器中支持使用 GELI 进行全盘加密；隐藏启动菜单，按键可显示，并新增菜单选项以取消静音启动日志；Backup Station 现在是 BE Station，可以从选定的引导环境创建引导环境；Update Station 现在在引导环境中安装次要版本和发行版升级；NetworkMgr 现在通过 wpa_cli 驱动 Wi-Fi，并且仅在网络连接后保存网络；Software Station 增加了区分大小写的搜索选项……”

阅读完整的发布公告以获取更多信息和升级说明。
