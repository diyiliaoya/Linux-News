Rust 发出警告：核心开发者成为攻击目标

Rust 安全响应工作组和 Crates.io 团队警告称，针对 Rust 语言核心开发者及热门 crate 所有者的定向攻击正在进行。攻击者通过伪造 LinkedIn 资料，以招聘或项目合作为由诱导开发者安装恶意软件或执行恶意命令，以在 Rust 生态中传播恶意软件。团队呼吁开发者保持警惕，启用多因素认证等安全措施。

Rust 安全响应工作组和 Crates.io 团队发出警告，称针对 Rust 编程语言核心开发者的定向攻击正在进行中。

据报道，负责开发 Rust 编程语言的 Rust-Lang 团队关键成员以及热门 Rust crate 的所有者正成为攻击目标，攻击者试图入侵他们的设备和账户，以便在 Rust 生态系统中传播恶意软件。

此次攻击手段似乎相当复杂，攻击者会建立虚假的 LinkedIn 个人资料，然后以招聘或合同机会为诱饵，诱导开发者安装恶意软件：

“他们会安排一次视频通话，理由看起来很正面——可能是为了工作，可能是为了项目，也可能是为了合同机会——然后利用这一途径让目标在其计算机上安装某些东西（例如一个据称缺失的音频编解码器），或执行另一条命令（例如通过将命令放入剪贴板）。

这些攻击者正在建立看似合法的新公司资料，包括看似可信的 LinkedIn 存在，以便通过粗略的审查。”

他们鼓励 Rust 开发者保持警惕，确保其账户使用多因素认证和其他安全防护措施。
