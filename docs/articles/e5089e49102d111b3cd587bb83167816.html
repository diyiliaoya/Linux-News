PostgreSQL 19 带来显著性能提升，基于第六代 AMD EPYC Venice 的基准测试

2026年11月25日 美国东部时间上午11:31。

PostgreSQL 19.0 终于发布了，由于今年开源开发者面临 AI/LLM 负担而延迟。不过等待是值得的，在我的基准测试中，PostgreSQL 19 相比 PostgreSQL 18 展现出非常不错的性能提升。以下是在全新的第六代 AMD EPYC Venice 平台上进行的初步 PostgreSQL 19 与 18 数据库服务器基准测试。

本周我针对去年的 PostgreSQL 18 系列对 PostgreSQL 19.0 进行了一些基准测试。结果相当诱人，在未更改 PostgreSQL 数据库服务器配置或任何其他更改的情况下——相同的服务器配置、相同的 pgbench 用于促进基准测试，仅从 PostgreSQL 18 迁移到新的 PostgreSQL 19——就获得了非常好的性能改进。

PostgreSQL 19 带来了各种各样的变化以帮助提升性能，包括自动扩展异步 I/O 工作线程、针对现代 CPU 的更多 SIMD 加速、更快的外键检查、并行自动清理行为，以及各种其他优化和可扩展性改进。PostgreSQL 19 还最终默认禁用了其即时（JIT）编译，因为性能不可靠。

为了运行一些初步的 PostgreSQL 19 与 18 基准测试，我在实验室中最令人兴奋和强大的平台上运行了它们……全新的 AMD 第六代 EPYC 9006 "Venice" SP7 服务器。PostgreSQL 数据库服务器基准测试使用单个 AMD EPYC 9996 256 核 Zen 6C 处理器、十六通道内存和 PCIe Gen6 NVMe SSD 存储完成。存储是一块 Micron 9650 PRO（MTFDMBQ7T6THM-1BP1JABDC）PCIe Gen6 固态硬盘，容量 7.6TB。随着我们迈入 2027 年，凭借 Zen 6(C) 核心、MRDIMM-12800 内存和 PCIe Gen6 存储，这是一个无与伦比的数据库服务器平台（以及更多用途！）。感谢 AMD 提供评测硬件使这次测试得以进行。

两次运行之间唯一的改变是在其他相同配置下迁移到 PostgreSQL 19.0。
