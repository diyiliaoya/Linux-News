Linux 7.3 即将带来的特性：从优化英特尔混合 CPU 到支持老旧的 AMD Athlon XP

2026年8月14日 上午07:00 EDT

Linux 7.2 预计将于周日稳定发布，以下是我一直在关注的、预计将在周一开启的 Linux 7.3 合并窗口期间提交的变更。

像往常一样，每个新的 Linux 内核版本都充满了新特性和硬件支持方面的变化，同时也在迭代现有功能，并且最近也在移除更多老旧硬件/驱动支持，因为在 AI 时代这些支持成为了更大的维护负担。根据我对“-next”Git 分支的持续监控，Linux 7.3 有很多内容。除非 Linus Torvalds 在最后一刻提出任何问题或反对意见，以下是预计将出现在 Linux 7.3 中的部分特性。这不是一个详尽的列表，请继续关注 Phoronix 在两周合并窗口期间的新闻文章。之后将进行 Linux 7.3 内核性能基准测试。

如果你还在使用支持 SSE 但不支持 SSE2 的 AMD Athlon XP 时代系统，Linux 7.3 将带来一个小的优化。在 AMD CPU 方面，还有针对 Zen 6 的 AMD P-State 动态 EPP 每 CPU 核粒度支持。AMD 还增加了对新的 CPU“低功耗”核心类型的识别，可能用于某些 Zen 6 SoC。

AMD Ryzen AI Halo LED 驱动也将被引入，用于控制 Ryzen AI Halo PC 的 LED 开关和 RGB 颜色。

对于英特尔 CPU，Linux 7.3 中已排队了一个 KCFI 优化，以惠及较老的英特尔 CPU 的控制流完整性（CFI）。对于采用 P 核和 E 核混合架构的较新英特尔 Core (Ultra) CPU，Linux 7.3 应该能更好地处理集群负载均衡。此外，在英特尔 CPU 方面，Linux 7.3 还为英特尔 Starfire 做好了准备，这是基于 Panther Lake 的 SoC，用于太空等极端环境。

英特尔定向封装级热中断也计划在 Linux 7.3 中作为效率增强功能。在英特尔图形方面，英特尔 Nova Lake S 显卡在 Linux 7.3 中被视为稳定，这些下一代处理器将在未来几个月内推出。英特尔显卡驱动还增加了对 Xe3 峰值带宽阈值功能的支持。

Linux 7.3 的 CPU 调度将进行扁平化选择，以改善游戏工作负载及其他场景的调度。

在 ARM 方面，Apple M1 系列硬件在 s2idle 期间将获得小幅功耗节省。此外，还有初步的 Apple M3 Pro / Max / Ultra 支持，以补充 v7.2 中添加的 Apple M3 基础型号支持。但该 Apple M3 系列支持目前还无法供最终用户使用，目前基本上只能启动到控制台。

在图形方面，TTM 内存管理将变得更加激进。AMDGPU 驱动正在为下一代图形硬件做准备。得益于 Valve，旧款 AMD GPU 的 GPU 重置恢复也得到了改进。此外，Timur 的另一个特别之处是旧款 AMD 硬件上的 DRM 格式修饰符支持，使得 GFX11 APU 上的第二个图形管道得以启用。

Qualcomm MSM DRM 驱动现在支持 Adreno 704 和 Adreno 722 GPU。

在开源 NVIDIA 内核图形驱动方面，基于 Rust 的 Nova 驱动继续开发，更多功能已就位，但尚未准备好供最终用户使用。与此同时，较老的 Nouveau 驱动正在准备支持 Mesa NVK 驱动的 Vulkan Video。

对于硬件监控感兴趣的用户，Linux 7.3 将为更多联想笔记本电脑带来风扇传感器，并为更多华硕台式机主板带来传感器监控。

FailFS 预计将被上游化，作为 NullFS 的补充。Linux 7.3 中另一个与 I/O/存储相关的改进是解决 PCIe Gen5 NVMe SSD 上小 I/O 的显著瓶颈。

在网络方面，有 Realtek RTL8261C 和 RTL8261D 支持。

在掌上电脑/游戏设备方面，Linux 7.3 应该会引入 MSI Claw 游戏手柄配置驱动，该驱动正在开发中。
