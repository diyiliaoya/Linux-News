AMD Zen 6 CPU 将采用基于 RISC-V 的 TEE

最新 AMD Linux 固件提交显示，Zen 6 处理器（Family 1Ah M80h）将采用基于 RISC-V 的可信执行环境（TEE），取代此前基于 Arm Cortex-A5 和 TrustZone 的 AMD 安全处理器方案。该固件为 AMD 平台管理框架（PMF）可信应用 v4，使用更大共享内存布局并支持扩展策略条件，包括最多 20 个自定义 BIOS 输入。

今天我注意到的最新 AMD Linux 活动中的一个有趣技术细节是，Zen 6 处理器显然将采用基于 RISC-V 的可信执行环境（TEE），而过去使用的是基于 ARM 的核心。

今天在一个 Git 提交中透露了一个小信息，可能是 Zen 6 的新特性，或者是近期 Zen 5 处理器未曾广泛报道的内容，但至少现在 Zen 6 CPU 有了基于 RISC-V 的 TEE。我未能找到任何其他关于 AMD EPYC/Ryzen 处理器采用 RISC-V TEE/核心实现的引用，但今天提交到 linux-firmware.git 的内容提到了针对 Family 1Ah M80h（即即将推出的 AMD Ryzen Zen 6 客户端处理器）的基于 RISC-V 的 TEE：

“amd_pmf: Add AMD PMF TA Firmware v4 for 1AH_M80H

This adds the PMF TA FW v4 for the 1AH_M80H platform. The TA now runs on the RISC-V based TEE, uses a larger shared memory layout and supports an extended set of policy conditions, including up to 20 custom BIOS inputs.”

基于 RISC-V 的 TEE。传统上，AMD 安全处理器/平台安全处理器（PSP）基于 Arm Cortex-A5 核心与 Arm TrustZone 技术。现在，对于下一代 Ryzen 处理器而言似乎是新的，或者只是现有 SoC/APU 从未提及的，是基于 RISC-V 的可信执行环境。

关于今天的固件更新，它是用于管理电源、散热和系统行为的 AMD 平台管理框架（PMF）可信应用（TA）。很高兴看到 AMD Ryzen Zen 6 的工作在产品正式发布前得到妥善处理。
