Linux 因 AI/LLM 噪音移除最后一批 1980 年代 VersaModular Eurocard "VME" vme_user 代码

Linux 内核因 AI/LLM 在邮件列表中产生大量噪音，决定移除已弃用的 1980 年代 VME 总线 vme_user 驱动。该驱动自 2022 年起被降级至 staging 区，无人维护且无其他内核代码依赖，移除将减少近 9000 行代码。Greg Kroah-Hartman 确认此变更已在 linux-next 中测试无问题，预计在 Linux 7.4-rc5 发布前合并。

Linux 内核正在移除更多旧驱动代码，原因是 AI/LLM 在源码树中针对这些未使用、过时的代码产生了更多噪音。继移除各种旧 ISA 和 PCMCIA 代码、业余无线电、ISDN 及其他旧网络代码之后，最新被剥离的 Linux 内核老古董是 1980 年代的 VersaModular Eurocard "VME" 总线 vme_user 驱动。

在明天 Linux 7.4-rc5 发布之前，Linux 内核收到了一份合并窗口后的拉取请求，要求移除最后一批 VersaModular Eurocard "VME" 并行计算机总线代码中用于用户空间访问的 vme_user 驱动。该 "vme_user" 驱动多年来一直位于 Linux 内核的 staging 区域——VME 代码于 2022 年被降级至 staging。内核树中已无其他代码依赖 vme_user 驱动，且该驱动无人维护、面向过时硬件，鉴于它一直在邮件列表中引发 AI/LLM 噪音，是时候将其移除了。

移除该驱动将减少近 9000 行代码。移除补丁的理由如下：

"staging 中的 VME 用户空间驱动已无人维护，Greg KH 要求提交补丁将其移除，而不是继续修复仅存在于 staging 的问题。移除该驱动、其文档、Kconfig 和 Makefile 条目、VME MAINTAINERS 部分，以及 powerpc 86xx 配置中过时的 VME 选项。"

Greg Kroah-Hartman 证实了 AI/LLM 噪音问题：

"这是一个移除 vme_user 驱动的单一 staging 驱动补丁。该驱动已无用户，而 LLM 们正争先恐后地试图找出该驱动中所有的‘安全漏洞’，尽管实际上从未有人使用过它。所以直接移除它，以免浪费大家的时间。此移除已在 linux-next 中存在相当长一段时间，未报告任何问题。"

因此，除非最后一刻出现问题，vme_user 代码将在明天 Linux 7.4-rc5 内核发布前被移除。
