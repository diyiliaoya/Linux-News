FFmpeg 实现 H.265 Vulkan 编码性能优化

FFmpeg 多媒体库近日合并了一项针对 hevc_vulkan 编码器的优化补丁，通过采用与 h264_vulkan 类似的调优策略，显著提升了 H.265/HEVC 视频编码性能。优化后，H.265 编码速度与 H.264 基本持平，在 1080p 测试中，帧率从原来的 200-317 fps 提升至 289-358 fps，与 H.264 的 288-359 fps 相当。该补丁还修复了编码配置同步问题，确保输出视频可解码。

FFmpeg 实现 H.265 Vulkan 编码性能优化

2026年8月17日 下午4:14 EDT

FFmpeg 多媒体库现在可以通过 Vulkan 加速的编码路径享受更快的 H.265/HEVC 视频编码。随着今天合并的优化，H.265 编码性能应大致与 H.264 编码速度持平。

一个优化补丁今天被合并到 FFmpeg Git 中，用于加速 hevc_vulkan，该补丁遵循了 h264_vulkan 的一些相同调优。提交信息解释了这一点并提供了一些性能数据：

"在不启用 ALLOW_ENCODE_PARAMETER_OPTIMIZATIONS 且最小 CU 强制为 8x8 的情况下，hevc_vulkan 在常见质量级别下保持了比 h264_vulkan 更重的编码配置（16x16 宏块，无最小 CU SPS 字段）。设置会话标志并在 CTB >= 32 时使用最小 CU 16x16；同时修复了 max_transform_hierarchy_depth_inter 的赋值。

在应用 GetEncoded SPS 反馈时，同步覆盖的字段（extent/conf_win、最小/差异 CU 和 TB 大小、变换层次）。仅复制 log2_diff 会导致 CtbLog2SizeY=7，并在某些实现重写最小 CU 后产生无法解码的 HEVC。

报告者命令（1080p testsrc2，质量 1，1000 帧）：

之前：hevc ~200–317 fps，低于 h264

之后：hevc 289/325/358 fps，h264 288/317/359 fps（持平）"

很高兴看到 HEVC Vulkan 编码性能不仅比以前更快，而且与 H.264 编码速度持平。
