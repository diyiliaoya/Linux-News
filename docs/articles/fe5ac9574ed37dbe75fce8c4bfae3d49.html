Snapdragon X2 在 Linux 上的性能在初步基准测试中超出预期

Phoronix 首次对高通 Snapdragon X2 Elite Extreme 在 Linux 下进行基准测试，使用 Ubuntu 26.10 X1E Concept ISO，在 ASUS Zenbook A16 上运行。初步结果显示性能超出预期，Adreno 显卡在开源驱动下正常工作。但部分测试未能运行，且缺乏功耗监控数据。测试对比了英特尔 Core Ultra 和 AMD Ryzen AI 等平台。

今天为您呈现的是高通 Elite Extreme 在 Linux 上的首批基准测试，使用新的 Ubuntu 26.10 X1E Concept ISO 为 Snapdragon X 笔记本电脑提供 Linux 支持。Snapdragon X2 Elite Extreme 旗舰 SoC 在 ASUS Zenbook A16 UX3607OA 笔记本电脑中进行了测试。

感谢 Phoronix 读者 David 提供 Snapdragon X2 Elite Extreme / ASUS Zenbook A16 的远程测试，今天发布的是新高通 Snapdragon X2 系列的首批数据。不幸的是，我没有收到高通或其硬件合作伙伴提供的任何 Snapdragon X2 系列评测样品，但感谢 Phoronix 读者 David 允许进行一些远程基准测试，以初步了解 X2 Elite Extreme 在 Linux 下非常新鲜的状态下的性能表现。话虽如此，这只是初步基准测试，一些基准测试未能在 X2 上成功运行，而且也没有功耗监控。由于在 Linux 下没有 PowerCap/RAPL 或其他 Snapdragon X 功耗指标的 Linux 报告，并且在此次远程测试期间没有通过 WattsUp Pro 等外部功耗监控，遗憾的是，本轮测试没有涵盖这一非常重要的方面。而且，遗憾的是，今年的硬件预算已耗尽。希望未来我们能获得一些评测硬件，以便对 Snapdragon X2 系列进行功耗测试和其他更广泛的 Linux 性能基准测试。

ASUS Zenbook A16 UX3607OA 搭载 Snapdragon X2 Elite Extreme X2E96100，配备 48GB LPDDR5-9523 MT/s 内存。18 核高通 X2 Elite Extreme X2E96100 的单核加速频率为 5.0GHz，多核最高频率可达 4.4GHz。据报道，Snapdragon X2 Elite Extreme 在标准设计下的 TDP 为 20W 至 40W，在持续工作负载下 CPU 最高可达 65W。再次说明，本轮远程测试无法进行功耗/每瓦性能测试。

该笔记本电脑使用 Ubuntu 26.10 X1E Concept ISO 进行标准功能测试。尚未开箱即支持的是 WiFi、音频和网络摄像头。随着未来 Linux 内核版本的发布，Snapdragon X2 的 Linux 驱动支持持续改进；X1E Concept ISO 目前使用 Linux 7.3，与上游 Ubuntu 26.10 相同。

令人高兴的是，即使在 Ubuntu 26.10 状态下，X2 Elite Extreme 的 Adreno 显卡也能在开源高通驱动栈下正常工作。

相比之下，我的 Snapdragon X1 Elite Acer Swift 14 AI 笔记本电脑在 Ubuntu 26.10 概念镜像上仍然存在显卡问题，并回退到 LLVMpipe……

为了了解 Snapdragon X2 Elite Extreme 的性能，我使用新的 Ubuntu 26.10 状态对几台现有笔记本电脑进行了新的基准测试。新重新测试用于与 X2 Elite Extreme 对比的笔记本电脑包括 Core Ultra 9 285H - StarFighter Ultra、Core Ultra X9 388H - Framework 13 Pro、Ryzen AI 9 365 - Zenbook S16、Ryzen AI 9 HX 370 - Framework 13 和 Snapdragon X1 Elite - Acer Swift 14 AI。这提供了 Snapdragon X2 Elite Extreme 在 Linux 上与当前 AMD Zen 5 Strix Point（遗憾的是没有 Strix Halo 笔记本电脑可供测试）以及英特尔 Arrow Lake 和 Panther Lake 的对比。再加上上一代 Snapdragon X1 Elite 进行对比。
