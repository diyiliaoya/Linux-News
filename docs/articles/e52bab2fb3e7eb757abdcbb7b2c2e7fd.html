Ubuntu 26.10 为 Intel Panther Lake / Framework Laptop 13 Pro 带来显著提升

2026 年 9 月 24 日下午 2:46（美国东部时间）。

对于 Framework Laptop 13 Pro 或其他搭载 Intel Core Ultra 系列 3 的笔记本电脑，即将发布的 Ubuntu 26.10 相比 Ubuntu 26.04 LTS 带来了一些不错的开箱即用改进。

在 Phoronix 实验室的更多系统上，尤其是现代硬件平台上，持续取得不错的性能提升。随着 AMD Strix Halo Framework Desktop 等设备的加入，这个即将发布的 Ubuntu “Stonking Stingray” 版本由于更新的内核（现已升级到 Linux 7.3）以及其他软件升级，已经取得了一些不错的成果。Intel Panther Lake 的性能也得到了很好的改善，正如本文所示，尤其是在 Intel Arc B390 显卡方面，更新的 Mesa 对 Vulkan 工作负载特别有帮助。

本轮测试中，我使用了搭载 Intel Core Ultra X9 388H、64GB LPDDR5-7467 内存、2TB WD_BLACK SN7100 NVMe SSD 以及集成 Arc B390 显卡的 Framework Laptop 13 Pro。将开箱即用并安装了所有稳定版更新的 Ubuntu 26.04 LTS 与截至 9 月 22 日的每日构建版 Ubuntu 26.10 进行了对比。
