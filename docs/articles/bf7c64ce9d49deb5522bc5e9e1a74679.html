发行版发布：Ludora 45.0

Ludora 45.0 发布，这是基于 Fedora 45 的重大更新。新版本改用基于官方 kernel.org 源码构建的独立内核，保留 BORE 调度器和 POC 空闲 CPU 选择器，并集成 CachyOS 调优设置。支持安全启动，安装时自动签名内核，首次启动需在 MokManager 中注册密钥（密码：ludora）。对所有来自个人开发者和小型项目的软件包进行了恶意代码审查。

Lars Søe Mikkelsen 宣布发布 Ludora 45.0，这是该项目基于 Fedora、面向游戏、配备定制内核、内置 Btrfs 快照和 KDE 桌面的 Linux 发行版的一次重大更新：“这是首个基于 Fedora 45 的 Ludora 版本，可能也是迄今为止最大的版本。Ludora 不再基于 CachyOS 内核构建，而是现在提供基于官方 kernel.org 源码构建的独立内核。它仍然包含 BORE 调度器和 POC 空闲 CPU 选择器，但现在直接取自其作者 firelzrd。来自 CachyOS 的调优设置已被继承并内置于内核中。Ludora 现在在启用安全启动的情况下安装和运行。Live ISO 镜像启动 Fedora 签名的内核，因此可在开启安全启动的情况下工作。如果安全启动已开启，并且在安装期间选择 Ludora 内核，它会在你的机器上签名，首次启动时你需要在 MokManager 中注册一次密钥（密码：ludora）。这意味着用户无需关闭安全启动，无论是安装还是使用 Ludora。Ludora 使用来自不同来源的软件包，包括个人开发者和小型项目。为最小化恶意代码风险，已对所有由此类开发者提供的软件包进行了恶意代码审查。”更多信息和截图请见。ludora45.0-x86_64.iso
