Purism 众筹 Librem 5 v2：一款售价 1599 美元、带物理开关的 RISC-V Linux 手机

Purism 为其第二款 Linux 手机 Librem 5 v2 发起众筹，售价 1599 美元。该手机采用八核 RISC-V 处理器、8GB 内存、可拆卸电池，并保留硬件级物理开关以切断摄像头、麦克风和无线模块。虽然配置无法与旗舰手机相比，但目标用户是重视隐私与数据安全的记者、外交官、活动人士等。Purism 还计划若达到 5000 订单，将主要电路板放在美国生产。

Purism 众筹 Librem 5 v2：一款售价 1599 美元、带物理开关的 RISC-V Linux 手机

专注于隐私的 Linux 手机迎来 RISC-V 芯片、8GB 内存和可拆卸电池。Purism 新款 1599 美元的 Linux 手机在规格上无法与 iPhone 匹敌，但这并非重点。

如果你关注这个领域已有一段时间，肯定听说过 Purism。这是一家美国公司，以隐私和安全为唯一焦点来构建硬件和软件。

Purism 生产 Linux 笔记本电脑、手机、安全密钥、VPN 服务以及自己的 Linux 发行版。其设备的一个标志性功能是物理开关。拨动这个开关，摄像头、麦克风或无线射频就会在硬件层面被切断。任何软件都无法将其重新打开。

Purism 曾众筹初代 Librem 5。近十年后，它带着第二款智能手机 Librem 5 v2 的众筹活动回归。而这一次，它运行在 RISC-V 上。

Librem 5 V2 关键规格

八核 RISC-V SpacemiT K1

128 GB，外加 microSD（SDR104，80 MB/s），可启动

4500 mAh，用户可拆卸

改进的 4G 调制解调器（5G 计划后续推出），双 SIM 卡

USB Type-C（充电），3.5 毫米耳机插孔

是，搭配自由固件（chopstx）

硬件物理开关：

蜂窝调制解调器、Wi-Fi/蓝牙、麦克风/摄像头

PureOS（第四个版本）

手机售价为预付 1599 美元，或现在支付 129 美元，之后 15 个月每月支付 99 美元。

这里的主要变化是处理器。Librem 5 v2 用八核 RISC-V SpacemiT K1 芯片取代了 ARM。RISC-V 是一种开放指令集架构，符合 Purism 尽可能控制整个技术栈的理念。

不过，Purism 自己也表示，RISC-V 尚未为 PureOS 做好“即插即用、开箱即启”的准备。图形、外设、ARM64 应用兼容性、浏览器性能和电源管理都被列为进行中的工作。你基本上是在资助这项工程工作，同时也在购买一部手机。

其余硬件充其量只是中规中矩。你得到的是 5.7 英寸 720 x 1440 显示屏、8GB 内存和 128GB 存储，以及一个可启动 PureOS 的 microSD 插槽。摄像头配置为后置 1300 万像素和前置 800 万像素。

说实话，1599 美元已经进入了 iPhone Pro 和 Galaxy S Ultra 的领域，而 Librem 5 v2 的规格并不在同一级别。屏幕、芯片性能，尤其是摄像头，都远不及旗舰手机。如果你想拍出精美的晚餐照片，这不是你的手机。

但 Purism 本来也不是要打造通用旗舰。目标受众是那些更看重隐私和数据安全而非规格的人：记者、外交官、活动人士、技术高管以及从事敏感行业的人。基本上，任何负担得起高价以保持数据私有的人都行。

在隐私方面，有三个硬件物理开关。一个用于蜂窝调制解调器，一个用于 Wi-Fi 和蓝牙，一个用于麦克风和摄像头。手机运行 PureOS，你不需要 Apple、Google、Microsoft、Amazon 或 Meta 账户即可使用。

🇺🇸 如果 Purism 获得 5000 份订单，将在美国制造

Purism 在美国的制造设施

Purism 还向那些关心在最大全球供应链（读作中国）之外构建技术的人推销这次活动。

只有众筹达到 5000 份订单的扩展目标，这才会实现。届时，Purism 表示主要的 PCBA（手机的主电路板）将在其美国自有设施中制造，也可能在欧盟制造。

如果美国制造的电子产品对你来说是必须的，Purism 计划按照 Librem 5 v2 的时间表推出“美国制造电子产品的 Liberty Phone v2”。目前的 Liberty Phone 已经售价 1999 美元，所以预计“美国制造”的特权会让你支付更多。
