为 Nautilus 文件管理器添加它缺失的“计算机”视图

Nautilus 文件管理器缺少一个集中查看所有驱动器及剩余空间的专用视图。第三方扩展 nautilus-my-computer 填补了这一空白，提供驱动器列表、存储使用条、首选文件夹区域，并支持自定义显示哪些驱动器、使用条颜色以及启动时默认打开该视图。该扩展还附带可选的 Miller 列浏览功能。由于是第三方补丁，安装前需注意未来更新可能导致兼容性问题。

为 Nautilus 文件管理器添加它缺失的“计算机”视图 - OMG! Ubuntu

文件管理器非常适合浏览文件和文件夹，但它缺少一种专门的方式来查看所有驱动器以及每个驱动器上还剩多少空间——不过你可以添加一个。

这是一个面向 GNOME Files 的第三方视图，提供一个集中页面列出驱动器，并带有存储使用条，显示哪些挂载点、卷、分区等还有剩余空间，哪些即将装满。

驱动器可以像文件夹一样交互，因此双击其中一个即可进入，或右键单击以访问在新标签页、新窗口中打开，或卸载、弹出等选项，具体取决于驱动器/挂载类型。

视图顶部有一个“首选文件夹”区域，显示常用文件夹和位置。这可以管理；你可以将最常用的文件夹固定在这里以便快速访问，并移除你觉得没用的内容。

概览页面可以以大视图或紧凑视图呈现，区别在本文顶部的截图中可见。
