Linux 7.4 改进短切片任务的调度延迟，NVIDIA Vera 偏好 SMT

2026 年 10 月 22 日 上午 11:42 EDT。

正在开发中的内核的调度器更新已合并，带来多项不错的调度增强。

首先是 EEVDF 调度器更新，用于改善短切片任务的调度延迟。Linaro 工程师 Vincent Guittot 致力于最新的短切片任务调度延迟改进。总体而言，这些补丁在 Linux 7.4 上观察到延迟降低高达 55% 的非常不错的改进：

这是对 Vincent 在 Linux 7.3 内核中已做的短切片任务调度器改进的补充。

Linux 7.4 调度领域的新增内容是用于增强 Linux 虚拟机的 steal governor。steal governor 用于基于窃取时间进行动态 vCPU 管理，以降低 vCPU 抢占成本。

另一个值得注意的调度器变更是针对 Vera CPU 的 NVIDIA Olympus 核心增强，优先使用 SMT 兄弟核心以获得更好性能。更多细节见《NVIDIA Olympus SMT 优化为 Vera CPU 带来 3~6% 性能提升》。

调度器拉取请求还包含在同等浅层 CPU 核心中随机选择空闲核心的工作，以在高核心数服务器/工作站上获得更好性能。

在缓存感知调度方面，有一项修复可避免发布不完整的最后一级缓存（LLC）利用率数据。
