AMD openSIL 与 Coreboot 为 Phoenix AM5 支持提交拉取请求

2026年8月4日，美国东部时间上午10:07。

上周，3mdeb 固件咨询公司发布了首个面向现代 AMD Ryzen AM5 平台的开源固件，他们将 AMD openSIL 和 Coreboot 移植到其下游 Dasharo 版本中，并应用于一款 MSI 桌面 ATX 主板。目前该工作进展顺利，3mdeb 正努力将 AM5 平台支持和 Phoenix SoC 支持上游化到 AMD openSIL 和 Coreboot 中。

3mdeb 固件工程师 Michał Żygowski 今日提交了一个 AMD openSIL 拉取请求，旨在将 AM5 支持和 Phoenix Ryzen 8000 系列处理器所需的更改上游化。

该拉取请求包含一些与 Coreboot 启动配合所需的修复、Phoenix 桌面 CPU 处理更新、MMIO 处理更新、用于芯片组初始化的 Promontory21 IP 块支持、缺失的 SMU/USB/GFX 初始化，以及与 AMD openSIL 中当前 Phoenix 概念验证代码相比的其他缺失元素。

Żygowski 在评论中表示：

“借助这些更改，我成功启动了搭载 AMD B850 芯片组的 AM5 Phoenix 平台，并使用 coreboot 引导了 Ubuntu 26.04 和 Windows 11。”

今天还提交了用于上游化 Coreboot 更改的拉取请求。这包括针对 Coreboot 的各种 AMD Phoenix 更改、Promontory21 处理，以及针对 AM5 处理器的其他更改。此外，还包括 MSI PRO B850-P WIFI 主板的初始树，3mdeb 一直专注于该主板的移植工作。

很高兴看到他们提交 openSIL 和 Coreboot 更改以供审查，以便将这些新增内容上游化。那些希望以简便易用的方式体验的用户，可以查看 3mdeb 为 MSI PRO B850-P WIFI 发布的 Dasharo 固件版本。我将很快对该主板进行测试。
