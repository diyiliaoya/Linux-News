AMD ROCm 10.2 发布：带来最新优化并扩展 Ryzen 笔记本支持

AMD 发布 ROCm 10.2，这是其开源 GPU 计算栈最新的六周功能更新。该版本升级了 SGLang 和 vLLM 支持，继续推进 Hyperloom、ROCm CLI 和 AMD Skills 相关工作，并新增针对 PCIe GPU 的 RCCL 性能优化。同时扩展了 Ryzen 笔记本官方支持范围，新增 18 款基于 gfx1103 架构的处理器，并增加对 RHEL 10.3、RHEL 9.9 和 SLES 16.1 的官方支持。

AMD ROCm 10.2 今日发布，这是该开源 AMD Radeon/Instinct GPU 计算栈最新的六周功能版本。

ROCm 10.2 升级了其 SGLang 和 vLLM 支持，继续围绕 Hyperloom 开展工作，并持续推进 ROCm CLI 和 AMD Skills 的相关工作。此外还有新的性能优化，例如针对基于 PCIe 的 GPU 的 RCCL 改进。

ROCm 10.2 还扩展了官方支持的 Ryzen 笔记本范围，更多较旧的基于 RDNA3 的型号终于获得支持：

“ROCm 通过支持 18 款新的 AMD Ryzen 处理器，拓宽了 Ryzen 笔记本上的本地 AI 支持，这些处理器与现有 Radeon 700M 系列处理器基于相同的 gfx1103 架构。开发者可在 Windows 和 Linux 上获得兼容性，无需自定义构建或特殊配置。这得益于 HIP、PyTorch 和 vLLM 中经过验证的 gfx1103 支持。”
