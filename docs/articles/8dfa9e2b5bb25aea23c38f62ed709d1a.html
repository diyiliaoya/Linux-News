Papirus 图标集时隔一年多迎来首次更新，新增 80+ 个图标

Papirus 图标集在 2026 年迎来首次更新，新增或更新了 80 多个图标，涵盖应用、游戏、用户界面图标，以及新的文件 MIME 类型和修订的符号链接。维护者 Serhii Yeremenko 对更新延迟表示歉意。此次更新扩展了游戏图标（如《突击立方体：重装版》《黑色沙漠》《城市：天际线 2》等），改进了 C 语言家族 MIME 类型图标，并优化了 Cinnamon、LxQt 和 XFCE 桌面环境的支持。用户可通过 GitHub 下载或添加 PPA 安装。

Papirus 图标集时隔一年多迎来首次更新，新增 80+ 个图标 - OMG! Ubuntu

主题爱好者们会很高兴听到有一个新更新——这是 Papirus 自 2026 年以来的首次更新（其维护者 Serhii Yeremenko 对更新迟缓表示歉意），带来了 80 多个新增或更新的图标，涵盖应用、游戏和用户界面图标，以及新的文件 MIME 类型和修订的符号链接。

频繁的更新正是 Papirus 图标在 Linux 用户中长久受欢迎的原因。通常，Linux 图标包以盛大的方式登场，初期动力推动几次修订，但随后随着人员和维护者的离开而归于沉寂。

Papirus 自 2013 年以来一直存在，并自那时起定期更新。

维护一个图标主题需要付出大量努力。新应用不断发布，需要考虑打包格式的怪癖，应用会更改品牌或进行 UI 改版，期望提供更新的符号图标。

一个覆盖缺口常常会破坏整体外观。

在 Papirus 202608 更新中新增的图标（或接收符号链接更改）包括：

游戏覆盖范围扩大。新增了《突击立方体：重装版》《黑色沙漠》《城市：天际线 2》《军团要塞 2：机密》《守望先锋》和《空洞骑士：丝之歌》的图标。

MIME 类型和文件图标覆盖范围也扩展了更多 ROM 文件，包括任天堂 DS 模拟器使用的文件。

其他图标更改惠及 Cinnamon、LxQt 和 XFCE 桌面的用户，后者获得了更新的符号链接，为相关应用提供图标。

C 语言家族 MIME 类型图标的更改

Papirus 202608 包括为 IntelliJ IDEA Ultimate 和 Community 版重新设计的图标，其 Community 版和开源参考管理器以及项目 ReadMe 文件也获得了修订的 MIME 类型。

整个 C 语言家族 MIME 类型（文件）图标已在 Papirus v202608 中更新。它们现在使用相同的文本样式，与官方徽标衍生的页面颜色保持一致，并为“Objective”C 版本使用不同的颜色。

如何安装 Papirus 图标

从 GitHub 下载最新的 Papirus 图标发布版，然后手动将解压的文件夹移动到相关位置（例如，/usr/share/icons，凭记忆）。

如果你使用 Ubuntu、Linux Mint 或类似系统，可能会发现通过 PPA 安装更容易。PPA 为 Ubuntu 20.04 LTS 打包了最新版本。

要添加 PPA，请打开终端并运行：

sudo add-apt-repository ppa:papirus/papirus

sudo apt install papirus-icon-theme

安装后，你可以将图标主题更改为 Papirus。在 GNOME Shell 上，安装 GNOME Tweaks（sudo apt install gnome-tweaks），而其他桌面环境通常提供内置的方法来更改图标主题。

值得注意的是：沙盒应用（如 Snap 或 Flatpak）并不总是“继承”系统级别的图标主题。
