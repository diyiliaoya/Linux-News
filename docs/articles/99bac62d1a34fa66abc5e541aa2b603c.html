Ubuntu 26.10 Beta 版推迟一周发布

Ubuntu 26.10 Beta 原定于9月24日发布，因“未预见的基础设施问题”推迟至10月1日。Canonical 表示问题将很快解决，不会影响最终稳定版于2026年10月15日发布。此次推迟使社区测试时间不足两周，该版本包含 Linux 7.3 内核、Rust 核心工具、GNOME 51 桌面、GTK4 版 DING 扩展及新窗口平铺功能等重大更新。

Ubuntu 26.10 Beta 版发布推迟至10月1日

原定于9月24日发布的 Ubuntu 26.10 Beta 版已推迟至10月1日。

Canonical 的 Matthieu Clemenceau 宣布了这一延迟，表示“未预见的基础设施问题”需要将发布推迟一周。

具体问题未详细说明，但 Clemenceau 补充说，公司预计很快就能解决原因，并且预计不会对最终的稳定版 Ubuntu 26.10 发布日期产生任何影响。该日期仍定于2026年10月15日。

虽然只是推迟一周，但这意味着更广泛的 Ubuntu 社区只有不到两周的时间来测试该版本及其众多变化。

其中包括：从 Linux 7.2 到 Linux 7.3 内核的后期切换、一整套 Rust 核心工具，以及一项内存不足处理机制的调整，旨在防止为了释放内存而牺牲桌面会话。

该版本还包括 GNOME 51 桌面、更新的应用程序、桌面图标扩展（DING）的 GTK4 移植版（提升了 UI 一致性），以及一项新的窗口平铺功能，与 Windows 11 上的功能类似。

所以，别再刷新 Ubuntu CD 镜像服务器了，关掉那个标签页吧——这个版本已被证明是个滑头货。

如果你已经预留了周末来测试，也不必烦恼：Ubuntu 26.10 的每日构建版可供使用。虽然未被“祝福”为 Beta 版，但 ISO 包含相同的软件包集。可以在虚拟机、外部驱动器或备用分区中安装，并保持更新。

下周这个时候，你就可以说“Beta 版？早就搞定了，伙计”。
