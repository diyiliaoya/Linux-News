Linux 7.3 将为 Intel Starfire 奠定基础

发布于 2026 年 8 月 2 日上午 10:32（美国东部时间）。

Intel 最近宣布了 Starfire，这是他们基于 Panther Lake 衍生的航天级 SoC，专为极端环境设计……例如在太空中的生存能力。随着 Linux 7.3 的到来，我们将开始看到首批针对 Intel Starfire 的补丁进入内核。

Intel 在 7 月发布了航天级 Starfire SoC，工程样品将于本季度开始出货。这些美国制造的 18A SoC 专为极端环境设计，且在这些环境中 Linux 比 Windows 更常见。

上周，错误检测与纠正（EDAC）子系统的 edac-for-next Git 分支中已加入了对 Intel Starfire SoC 的支持。从 EDAC 的角度来看，Starfire 的内存架构与 Panther Lake 非常接近，并复用了 IGEN6 驱动中现有的代码路径。最终，对于错误检测与纠正处理，只需一个新的设备 ID 即可支持 Starfire。

这是目前所见到的首个针对 Intel Starfire 的 Linux 补丁。预计还会有更多补丁，很可能主要是添加新的设备 ID，并遵循现有的 Panther Lake 驱动支持代码路径。也有可能 Starfire 实际上与之前在内核中提到的“加固型”Panther Lake 相同。

无论如何，鉴于目前 Intel Linux 支持的良好状态，一旦所有必要的设备 ID 添加完成，Starfire 的 Linux 支持也应该会处于良好状态。另外值得一提的是，Intel 的 Starfire 并不是 Linux 内核中唯一的“Starfire”，因为主线 Linux 内核中还有现有的 Adaptec Starfire 网络驱动。
