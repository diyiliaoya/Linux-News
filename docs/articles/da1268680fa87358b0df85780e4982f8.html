Sublime Text 获得新的 C# 高亮器和文件图标主题

Sublime Text 发布 v4213 版本，这是自 2025 年 5 月以来的首个重大更新。新版本默认使用 Python 3.14，重写了 C# 语法高亮器，新增文件图标主题支持，并带来 Git reftables 支持、新的 io_workers 设置以及大量 Linux 平台修复。

Sublime Text 获得新的 C# 高亮器和文件图标主题 - OMG! Ubuntu

已发布——这是这款跨平台（且闭源）文本编辑器自 2025 年 5 月以来的首个重大更新。

Sublime Text v4213 将 Python 3.14 设为默认版本（取代 v3.8）。该编辑器仍然附带 Python 3.3——尽管它非常古老——但默认处于禁用状态。它将在未来的更新中被移除，但为了应对插件兼容性问题，还会再保留一段时间。

本次更新的新功能包括重写的 C# 语法高亮器，以及对语法高亮的更普遍（但未具体说明）的“改进”。

还引入了对文件图标主题的支持。这些主题让用户可以自定义侧边栏中文件旁边显示的小图标，通过一个 .json 文件定义，该文件将文件扩展名映射到包文件夹内 PNG 文件的名称。

在 Ubuntu 上运行的 Sublime Text v4213

其他变化包括一个新的命令，用于启动外部终端模拟器；作用域选择器可以使用某些语法来匹配子作用域；如果文件在编辑器之外被更改，该文件的撤销/重做历史将不再恢复。

据说保存大量文件的速度更快，git status 也更快。标签页滚动开启时拖动标签页的问题得到了改进，模糊匹配在某些情况下排序更好。使用特定命令连接行时，括号闭合也更干净。

支持 Git reftables

新增“io_workers”设置

为所有平台修复了 Sublime Text 的功能。

本次更新解决的问题包括：关闭项目在某些情况下可能损坏工作区文件、在文件中查找不搜索以点开头的文件夹、点击内联差异外部时光标消失，以及侧边栏的各种小问题。

一系列 Linux 专属修复，包括以下内容：

模态对话框不再阻塞所有打开的窗口

从某处拖动文本后，拖动状态不再卡住

选择多个工作表时，选择剪贴板正确设置

关闭窗口后修饰键不再保持按下状态

KDE 的“替代字符”输入法可以正常工作

Wayland 下拖动标签页不再触发意外的空投

在 Ubuntu 上安装 Sublime Text 的方法

从其官方网站下载，该网站提供 Windows、macOS 和 Linux 的安装程序——包括 DEB 包，以及可选的 APT 仓库。

Linux 用户还可以在 Snap Store 上获取 Sublime Text，尽管这是由社区维护的非官方包。

sudo snap install sublime-text --classic

Sublime Text 是一款专有文本编辑器，理论上需要付费许可证才能使用。然而，它可以在没有实质性限制的情况下免费使用。那些喜爱或依赖它的人可能想购买许可证密钥，以支持它的持续存在。

为什么要为文本编辑器付费呢？许多（优秀的）免费开源文本编辑器确实存在，就像观点一样，每个人都认为自己的是“正确”的。

但选择是双向的。人们喜欢他们熟悉的东西，许多跨操作系统和设备工作的开发者喜欢能够使用他们偏好的编辑器。

Sublime Text 并不时髦，也缺乏 AI 集成，但对忠实用户来说，它快速且熟悉。
