红帽致力于改进 QEMU 虚拟机的内存分层以节省 RAM

红帽工程师正在探索多种方案以改进 QEMU 虚拟机的内存分层，目标是在当前内存价格高企的情况下，让 QEMU 虚拟机在更多场景中利用 NVMe SSD 替代 DRAM 以节省内存。在 KVM Forum 2026 上，红帽虚拟化工程师 Peter Xu 介绍了相关评估方案，包括新的 maccess() 系统调用、QEMU 全用户空间分层以及利用现有内核 API 进行热页迁移。其中利用现有内核 API 的方案因无需修改内核且 QEMU 改动较小而成为当前主要候选，并可通过新内核补丁进一步改进 MADV_PAGEOUT 行为。

红帽正在努力改进 QEMU 虚拟机的内存分层以节省 RAM

2026 年 11 月 14 日上午 08:12 EST 发布。

红帽工程师正在研究几种可能的方案，以增强基于 QEMU 的虚拟机的内存分层能力，从而帮助节省内存。鉴于当前内存价格高企，他们的最终目标是在更多场景中为 QEMU 虚拟机利用 NVMe SSD，以节省 RAM 使用量。

红帽虚拟化工程师 Peter Xu 本周在加拿大温哥华举行的 KVM Forum 2026 上介绍了 QEMU 内存分层。目标是让 QEMU 虚拟机更好地与内存分层配合，以便在更多情况下使用相对更便宜的 NVMe SSD 替代 DRAM，同时仍能提供良好的性能。

正在评估的途径包括：新的 maccess() 系统调用、由 QEMU 负责拥有慢速层的 QEMU 全用户空间分层，或使用现有内核 API 进行热页迁移。最后一种方案目前看来是主要候选，因为它无需修改内核，且 QEMU 改动较小。最后一种方案还可以通过新的内核补丁解决 MADV_PAGEOUT 行为的内核限制来进一步改进。
