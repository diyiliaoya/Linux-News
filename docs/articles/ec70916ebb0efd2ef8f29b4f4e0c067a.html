发行版发布：Linux Lite 8.2

Linux Lite 8.2 正式发布，这是一个基于 Ubuntu 的 Xfce 桌面发行版，主要面向 Windows 用户。本次更新将 Linux 内核升级至 7.3 版本，提供桌面和游戏两种内核变体，并修复了加密安装失败的问题。

Jerry Bezencon 宣布发布 Linux Lite 8.2，这是该项目用户友好、基于 Ubuntu 的 Linux 发行版的更新版本，采用 Xfce 桌面环境。新版本将 Linux 内核更新至最新的 7.3 版本：

“Linux Lite 8.2 最终版现已可供下载。这是一个次要版本，主要特性是 Linux 内核 7.3。在 8.0 系列中，Linux Lite 内核从主线 7.x 推进到 7.3，基于 kernel.org 主线 tarball（经 GPG 验证）加上精选的 CachyOS 补丁子集构建。提供两种变体——‘linuxlite’（桌面版，启用缓解措施）和‘linuxlite-gaming’（关闭缓解措施，在 7.3 上启用 ORC 和 BORE 调度器）。通过‘linuxlite-nvidia-kernel-patch’包在主线上内核上支持 NVIDIA 专有驱动。为 8.2 版本重新品牌化了安装程序。修复了加密安装在最后阶段失败并提示‘无法关闭目标系统上的加密分区’的问题。在 0110 中，安装现在可以完整运行——grub-install 成功，crypttab/initramfs 已写入，但 umount 作业在未先运行‘swapoff’的情况下对加密交换映射器调用‘cryptsetup close’，导致仍处于活动状态的交换设备繁忙，Calamares 报告整个安装失败，尽管磁盘上的系统已完整且可启动。”
