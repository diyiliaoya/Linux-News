WinBtrfs 1.10 发布：两年改进成果助力 Windows 上的 Btrfs

2026年9月1日，下午5:57（美国东部时间）

WinBtrfs 是一个用于 Microsoft Windows 的驱动程序，支持对 Btrfs 文件系统进行读写操作。WinBtrfs 支持 Windows XP 及更高版本。该项目已有两年多没有发布新版本，但现在推出了一次重大功能更新，结合了新功能和错误修复。

WinBtrfs 1.10 于今天发布，现在支持写入空闲空间位图以及写入压缩内联文件：这两个功能在 WinBtrfs 上此前已具备读取支持。新的 WinBtrfs 版本还改进了对可移动设备的处理，增强了在内存不足或磁盘空间不足时的错误恢复能力，并进行了多种不同的错误修复。

WinBtrfs 1.10 的修复包括：在子卷之间移动文件时可能出现的崩溃；同时创建大量文件（如 Steam 客户端中观察到的情况）时的崩溃；预分配问题现已解决；多设备卷的磁盘使用统计；以及其他修复。

WinBtrfs 1.10 的发布公告还提到，Claude 被用于漏洞查找，并证明不仅在漏洞查找方面，而且在代码审查方面都“帮助很大”。不过，WinBtrfs 1.10 的代码全部由人工编写，未使用人工智能。
