OverlayFS 因 AI 代码审查获得大量修复

在 Linux 7.4 合并窗口期间，OverlayFS 联合挂载文件系统获得了大量修复，这些修复由 Chris Mason 的 AI/LLM 驱动代码审查发现，包括信息泄露、释放后使用、空指针解引用等可由非特权用户触发的安全漏洞，以及 nfs_export 数据丢失等问题。相关补丁已合并并将回移植到稳定内核版本。

本周末为 Linux 7.4 合并、并标记为回移植到当前稳定内核版本的是 OverlayFS 联合挂载文件系统的一系列修复。

Linux 7.4 的 OverlayFS 变更仅由许多修复组成，其中一些涉及安全影响。这些修复也被标记为回移植到稳定的 Linux 内核版本。

以 Btrfs 闻名的 Chris Mason 最近专注于

AI/LLM 驱动的 Linux 内核代码审查

，最终发现了多个 OverlayFS 缺陷。Amir Goldstein 在 OverlayFS 更新的拉取请求中解释道：

“- 修复 Chris Mason 的 AI 审查发现的缺陷，其中几个可由非特权用户触发：信息泄露、释放后使用和空指针解引用缺陷、远程层导致的 RCU 遍历停滞以及 nfs_export 的数据丢失

- 修复带有空 security.capability xattr 的文件的 copy up，任何用户都可以设置该属性来阻止 copy up

- 修复 v6.16 中 override_creds 挂载选项的回归

- 两个 casefold 修复”

在过去一周中，Chris Mason 在代码中发现这些问题后，最终为 OverlayFS 提交了十几多个补丁。由于信息泄露、UAF 及相关缺陷可由非特权用户触发，因此存在安全考量。
