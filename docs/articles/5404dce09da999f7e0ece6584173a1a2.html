Canonical 工程师模拟了一款使用 AI 的 Ubuntu 启动器

Canonical 工程师 Didier Roche-Tolomelli 发布了一款名为 warty-prototype 的 Ubuntu 启动器原型，模拟了设备端 AI 如何增强桌面体验。该原型是半交互式自动化演示，展示了通过 AI 查找文件、设置壁纸、匹配主题色、搜索应用以及从剪贴板历史创建日历行程等任务。它并非真实工具，而是设计讨论原型，旨在探索 AI 在 Ubuntu 桌面上的实际应用场景。

Canonical 工程师模拟了一款使用 AI 的 Ubuntu 启动器

Ubuntu 桌面更深入的 AI 集成会是什么样子？嗯，你不需要想太多就能知道。

Canonical 的一位工程师发布了一款原型启动器，模拟了设备端 AI 如何被用来增强和帮助 Ubuntu 桌面用户。

Didier Roche-Tolomelli（又名 didrocks）开发的 snap 是一个真正的启动器。它是一个半交互式的自动化模拟。它模拟了用户可以做的事情，包括与一个（理论上的）设备端 AI 模型交互以完成任务。

“下一代 Ubuntu 启动器的设计讨论原型”

这个措辞很有意思——不过目前我只能理解到这个程度。这或许暗示了未来可能的功能，但并未承诺会发布或真正将其构建为现实产品。

这个小盒子能做的事——如果它能用的话

我安装了这个原型并运行了模拟任务，以了解它能做什么（有一个满是任务的菜单）。启动器本身由顶部面板上的一个小 Ubuntu 标志触发，而且只是表面上的交互。

一个模拟任务展示了使用启动器查找本地图像文件（使用文件过滤器）。启动器的 AI 框被使用，模型被要求将图像设置为桌面壁纸，并调整系统强调色以匹配。

用 AI 查找应用，却不用 AI 查找文件

另一个任务使用 AI 查找用户可以安装以打开 ePub 的合适应用。来自 Snap Store 的匹配结果会过滤回启动器内，并带有安装按钮，点击即可触发安装。不错。

还有一个在我看来更令人印象深刻的用例：AI 根据从剪贴板历史中选择的几项内容创建可添加的日历行程。点击下方嵌入的视频播放观看：

“warty-launcher”的模拟演示

它也旨在作为常规启动器使用，例如打开应用、查找文件、选择表情符号、剪贴板历史、查找打开的浏览器标签页以及查看最近的“任务”。

在整个模拟过程中，结果会以各种图标和操作出现，以便在启动器内操作或管理它们，使其更像是一个主动工具而非被动工具。

在这方面，很像苹果在近期 macOS 版本中（更强大的）Spotlight。不难想象这个启动器如何进一步扩展，以处理比简单的查找和检索更复杂的任务。

这是一个演示，Jim。但不是我们所知道的那种。

我们确实知道 Canonical 热衷于在 Ubuntu 中“加强”AI 功能。它本月发布了技术预览版的 Myna AI 听写工具，其工程师正在将 LLM 和代理编码工具用于各种工作、基础设施管理等。

但该公司也表示，不会为了 AI 而强行加入 AI。它所探索的任何集成，即使在这个“模拟”中，也将基于实际用例并利用设备端 AI 模型。

试试演示（记住这只是演示）

你可以从 Snap Store 安装 warty-prototype 启动器演示。它将在大多数受支持的 Ubuntu 版本上运行：

sudo snap install warty-prototype --edge

安装后，从命令行启动它。点击顶部面板中的 Ubuntu 图标以显示启动器（以及可观看的模拟菜单）。

请记住，你不能用它做任何事情。它是一个启动器模型，不是工具。它不会与你的系统集成、查找你的应用，也不会兼作你的治疗师兼精神病诱导器。

对于那些想知道为什么叫“warty”的人，那是第一个 Ubuntu 版本的代号——之所以这样命名，是因为第一个版本可能有点不成熟。
