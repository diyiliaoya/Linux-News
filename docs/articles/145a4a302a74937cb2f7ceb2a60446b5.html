Linux 7.3 为上游化 FAMFS 文件系统做准备

2026年8月23日 上午07:20（美国东部时间）

Linux 7.3 周期的 NVDIMM 和直接访问（DAX）补丁已合并。本周期大部分 DAX/NVDIMM 活动都在为即将提交的 Micron FAMFS 文件系统做准备。

Linux 7.3 中的 DAX 代码经历了一系列修复、代码重构和其他改进，为 FAMFS 的引入做准备。

Micron 多年来一直在开发 FAMFS（至少自 2024 年起），这是一种面向结构附加内存（FAM）设备的专用文件系统。Micron 希望能在 2026 年将 FAMFS 上游化，该文件系统本身的补丁现已历经十三轮补丁审查。这种结构附加内存文件系统对于未来现代 CXL 服务器将非常重要。

它不适用于通用文件系统用途，而是围绕基于文件的字节级访问设计，面向非常大的共享/分解内存应用，常见规模约为 100TB 以上内存。尽管有人担心 Linux 内核中文件系统数量过多，但 FAMFS 正是为此用途专门设计的。Micron 工程师曾尝试移植到用户空间的 FUSE，但最终发现独立的内核文件系统驱动是最佳方案。Micron 还承诺维护 FAMFS，并明确其客户需求。

Linux 7.3 已合并所有 NVDIMM 和 DAX 更改。FAMFS 尚未提交上游包含，但看起来已接近可被接受的阶段。不过没有迹象表明它会在 v7.3 合并窗口期间提交。感兴趣的人可以查看当前形式的 FAMFS。
