Linux 应用发布汇总（2026年9月）

2026年9月，Linux 应用生态迎来多项更新。Shotcut 26.9 新增调整剪辑功能和新标志；Audacity 4.0.1 修复了键盘快捷键、导出对话框等大量问题；Plank Reloaded 解决了重复图标等缺陷；PeaZip 11.3.0 为内置密码管理器增加了主密码保护。此外，Firefox、Vivaldi 8.2 和 Orion 测试版也带来了新特性。

秋日气息或许正在吹来（至少对北半球而言），但 Linux 应用开发者们可没打算蜷缩起来。2026年9月，一批各式各样的 Linux 应用更新发布了。

值得专门撰文介绍的重大发布包括重新设计的版本（前者早该更新，后者看起来完全像一款新应用）。我还报道了 Calibre 那一波（奇特的）AI 功能集成——如果你不想读书的话。

Firefox 发布了两次更新（数一数），不过最受关注的还是某功能的推出。Vivaldi 8.2 新增了地址栏计算器，而 Linux 版 Orion 的新测试版则加入了工具栏编辑器。

本文汇总了那些我没有在本站专门撰文介绍的软件发布。

Shotcut 新增调整剪辑和新标志

Shotcut 的新版本于9月底亮相。

此次更新带来了全新应用标志，以及用户界面部分区域更圆润的边角（后者是为了与系统主题保持一致性，而非“搞个 Nova 风格”——参见 Firefox 157）。

在我看来，最大的新功能是调整剪辑。可以生成一个“哑”视频剪辑，它本身没有视频内容，但你可以对其应用滤镜，这些滤镜会影响其下方所有视频轨道的合成效果。

我爱死它们了；调整剪辑是懒人剪辑师的最佳伙伴。

此外，音频时间线轨道可以开启自动音频闪避功能。当上方轨道出现语音或其他音频时，它会尝试自动降低音量。即便永远做不到完美，也能让手动闪避这项（枯燥的）任务稍微快一点。

其他变化还包括升级至 FFmpeg v9.0、轨道头部新增音频混音控制，以及时间线性能提升。Linux 上的 VA-API HEVC 硬件编码在 v26.9 中得到修复，还有一堆其他 bug 也被解决。

Shotcut 26.9 现已可从 Snap Store 获取。

Audacity 重大版本迎来重大 bug 修复

Audacity 4.0 带来了现代化界面和更好的编辑工具，广受好评，但也并非没有一些小毛病。9月发布的版本修复了大量已发现的问题，并解决了一些未被注意到的回归问题。

一批 Audacity 3 时代的键盘快捷键（有些已深入工作流，比如分别用于跳到开头和结尾的快捷键）在 v4.0 中失效了，而“导出”对话框也丢失了将多轨导出为独立音频文件的选项。这两项都在 v4.0.1 中恢复。

bug 修复数量众多，涵盖从剪辑选中时闪烁、导出后文件名被随机缩短，到在 Linux 上运行时 WAV 文件无法被 Audacity 识别等各种问题。VST3 设置在不同会话之间被重置的问题也已解决。

如果你曾尝试在 Ubuntu 26.04 LTS 或非 systemd 的 Linux 发行版上打开 Audacity 4 AppImage 却无法运行，好消息是：这个版本可以了。

Audacity 是免费开源软件，可从官方 Github 下载，支持 Windows、macOS 和 Linux。

Plank 分支修复了重复图标问题

桌面 dock 的用户会想要更新到 v0.x。这是一个 bug 修复版本，解决了一系列小毛病，比如由 BAMF 类冲突导致的重复图标，并确保固定的启动器能正确匹配到运行中的应用。

最新更新还增加了对数据文件夹、子文件夹或名称中带空格的应用程序显示徽章和进度的支持，并防止 dock 图标使用来自 2x 主题文件夹中为其一半尺寸绘制的图像——也就是说，模糊图标更少了。

Plank Reloaded 可从项目页面下载。

PeaZip 让压缩包密码更安全

PeaZip 11.3.0 发布，但如果你将压缩包密码保存在内置的“密码管理器”中，你应该知道它现在需要主密码了。

开发者建议你在当前版本中——也就是更新到新版本之前——设置一个密码，然后右键点击密码列表并选择相应选项。之后你可以替换 PeaZip 配置文件夹中的文件。
