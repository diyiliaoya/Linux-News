Ubuntu 的新 AI 驱动听写工具 Myna 尚未正式发布，但你可以提前测试。

Canonical 最近在 Snap Store 中添加了 Myna 编排器 snap 和两个语音识别 AI 模型，并通过 PPA 提供了新的桌面应用供测试。

Ubuntu 26.10 还预装了另一个组件，因为 gnome-shell-ubuntu-extensions 包包含一个 GNOME Shell 扩展，当 Myna 本地 AI 语音转文字技术正在监听或转写时，会触发屏幕上的 HUD。

虽然官方尚未正式征集测试，但测试 Myna 所需的所有组件都已可用——供那些愿意自己组装的人使用。自 8 月份我预览以来，该功能已经发生了很大变化。

如果这包括你，请继续阅读操作方法——但请注意，目前不要期望一切都能完美运行。

以下是安装每个组件的方法。

安装 Myna 设置桌面应用

通过添加以下 PPA（由一位参与 Myna 工作的 Canonical 工程师维护）来安装应用，该 PPA 为 Ubuntu 26.04 LTS 和 26.10 提供软件包：

sudo add-apt-repository ppa:charles05/myna-config

sudo apt install myna-config

安装 Myna 客户端 snap

在安装之前，启用 Myna 所需的一个实验性 snap 功能：

sudo snap set system experimental.user-daemons=true

安装 Myna 语音转文字客户端

sudo snap install myna --edge
