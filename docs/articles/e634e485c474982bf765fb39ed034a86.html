Intel 为提升 Arc 显卡上的 Linux 游戏体验开发 DXVK-IGDEXT

Intel 工程师正在开发 dxvk-igdext 项目，作为 DXVK 的组件，让游戏在 Wine 下通过转发机制使用 Intel D3D11 图形扩展（如 UAV overlap、MultiDrawIndirect、深度边界），避免回退到较慢的默认 D3D11 行为。该 DLL 由 Valve 的 Proton 自动处理，旨在改善 Intel Arc 显卡在 Linux（Steam Play）上的游戏体验。项目目前仅限 Linux/Wine，已在 GitHub 开源。

Intel 为提升 Arc 显卡上的 Linux 游戏体验开发 DXVK-IGDEXT

2026 年 9 月 23 日上午 10:54（美国东部时间）。

Intel 工程师一直在悄然开发 dxvk-igdext，作为他们自己的 DXVK 组件，用于在 Vulkan API 之上实现 Direct3D 8 / 9 / 10 / 11，以利用 Intel Direct3D 11 图形扩展。

DXVK-IGDEXT 是 Intel 的一个新项目，它提供了相应的 DLL，让游戏能在 Wine 下使用 Intel D3D11 图形扩展。Valve 的 Proton 会自动处理这个 DLL，以改善 Intel Arc 显卡硬件上的 Linux（Steam Play）游戏体验。

该项目的 GitHub 对 DXVK-IGDEXT 的总结如下：

“用于 Wine/DXVK 的 igdext64.dll：让游戏在 Wine 下使用 Intel D3D11 图形扩展（UAV overlap、MultiDrawIndirect、深度边界），通过将它们转发到 DXVK 的原生实现，而不是在扩展不可用时让游戏静默回退到较慢的默认 D3D11 行为。

注意：目前仅限 Linux/Wine，不适用于原生 Windows。”

关于这项最近开源的工作的更多细节，可通过 GitHub 上的 GameTechDev/dxvk-igdext 查看。
