发行版发布：FunOS 26.10

FunOS 是一个基于 Ubuntu 的 Linux 发行版，采用轻量级 JWM 窗口管理器，现已更新至 26.10 版本。新版本扩展了 Broadcom 无线支持并解决了屏幕空白问题：“FunOS 团队自豪地宣布发布 FunOS 26.10，它构建于 Ubuntu 26.10 ‘Stonking Stingray’ 之上。此版本对核心工具、多媒体处理和硬件支持进行了重大升级，同时提供了焕然一新的外观和感觉。FunOS 26.10 有哪些新特性？基于 Ubuntu 26.10 - FunOS 26.10 构建在 Ubuntu 26.10 的坚实基础之上，确保可以访问最新的软件包，并提升系统性能和现代硬件兼容性；Linux 内核 7.3 - 此版本搭载 Linux 内核 7.3，为最新硬件提供增强支持、性能优化和更新的驱动管理；100% Rust 核心工具 - 延续对安全性和可靠性的关注，FunOS 26.10 完成了向使用基于 Rust 的核心工具的过渡；过渡到 dbus-broker - FunOS 26.10 从 dbus-daemon 迁移到 dbus-broker；过渡到 PipeWire - 我们已完全过渡到 PipeWire 作为默认多媒体服务器。”
