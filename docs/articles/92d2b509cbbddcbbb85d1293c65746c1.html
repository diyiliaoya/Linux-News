Tuba，Linux 上最好的 Mastodon 客户端，刚刚迎来重大更新

Tuba 是 Linux 上功能最丰富的 Mastodon 客户端，其 0.11.0 版本带来了重大更新，包括对 Mastodon 引用（quote）功能的完整支持、集合（Collections）功能、统一推送支持、自定义时间线、自定义缩略图、帖文投票等。此外，Tuba 还推出了实验性的 Android 版本，但官方建议 Android 用户使用其他更成熟的客户端。该版本还修复了 Linux 移动端的一些问题，并提供了多种安装方式。

Tuba，Linux 上的 Mastodon 应用，增加了引用和集合支持。

这款基于 GTK4/libadwaita 的 Fediverse 客户端，迎来了其首个重大更新，并同时推出了实验性的 Android 版本。

Tuba 0.11.0 是该社交应用的第一个重大更新，带来了对 Mastodon 引用功能的完整支持。在撰写器中，你可以引用帖子、控制他人是否可以引用你的帖子，以及撤销对已引用者的授权。

虽然该应用此前已经提供了自己的“引用推文”分享方式，但对 Mastodon 基于“同意”的引用支持，意味着你在引用时能够尊重这个去中心化社交媒体平台上其他用户的需求。

集合（Collections）是基于主题或话题的账户精选列表，通过链接分享——类似于 BlueSky 的 Starter Packs。

在 Tuba 0.11.0 中，如果你的实例支持集合，你可以浏览集合、关注其中的单个账户（设计上不提供“全部关注”选项），并在 Tuba 内创建和编辑自己的集合。

统一推送（UnifiedPush）支持。在桌面端，如果系统提供了统一推送服务并已启用，Tuba 将保持连接活跃，而不是在后台运行以监听通知。

其他功能包括：从多个话题标签创建自定义时间线，在帖子撰写器中为视频或音频附件添加自定义缩略图，以及创建同时包含附件和投票的帖子（在支持的实例上）。

Tuba 0.11.0 中其他较小的显著变化：

- 个人资料备注显示完整内容，且更易于编辑

- 键盘快捷键速查表

- 在较窄窗口下使用紧凑间距

- 保存媒体时的提示显示“打开文件夹”按钮

- 重写了自定义表情选择器

- 字体大小滑块取代了按钮

- 当转发带有附件但无替代文本的帖子时发出警告

- 可以禁用“精选”和“媒体”（以及媒体回复）个人资料标签页

总的来说，这是对 Linux 桌面上功能最丰富、最友好的 Mastodon 应用的一次受欢迎更新。这无疑是一个大版本，因此要尽情享受所有细节，请查看完整的发布说明。

Tuba 现已登陆 Android

Tuba 的 Android 版本（图片：geopjr）

Tuba 现已提供 Android 版本，但构建仍处于早期阶段。应用自己的发布说明提到，在 Android 上使用 Mastodon 有“更好的选择”。

不过，在开发 Android 移植版的过程中，影响 Linux 移动端的一些“烦扰和用户体验小问题”被发现并解决了。即使你或其他人坚持在谷歌移动操作系统上使用那些“更好的选择”，这项工作仍然带来了益处。

然而，你暂时不会在 Play Store 或 F-Droid 中找到 Tuba。相反，你可以从 nightly 构建中下载。

如何获取 Tuba 0.11.0

你可以安装最新版本。有一个官方的 Snap Store 构建，但截至撰写本文时，它尚未更新。

要体验本文提到的更改，你可以在 Ubuntu 24.04 LTS 及更高版本上从仓库安装旧版本，使用命令：

sudo apt install tuba

如果你使用的是 Ubuntu 26.10 每日构建版，v0.11.0 将包含在仓库中。

否则，请前往 Tuba 官方网站。那里有下载链接以及所有可用的 Linux 包和格式的详细信息，还有 Windows 安装程序，如果你喜欢在双启动设置的另一侧使用该客户端的话。
