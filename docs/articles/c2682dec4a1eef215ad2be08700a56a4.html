Ubuntu 固件 HWE 将防止旧内核出现问题

Ubuntu 计划推出新的固件包方案，以解决 HWE 内核固件更新可能影响使用 GA 内核用户的问题。此前 Ubuntu 24.04 LTS 的固件回移植曾导致 Linux 6.9 GA 内核出现 AMD 回归问题。新方案让 HWE 内核使用独立的固件包，使 GA 内核用户继续使用标准固件集，同时两者在各自支持期内仍能获得针对性修复。Ubuntu 26.10 的固件包正被打包为 hwe 版本，预计 2027 年初回移植至 26.04。

Ubuntu 正计划推出一个新的软件包，以降低针对较新内核的固件更新给使用旧内核的用户带来问题的风险。

在 Ubuntu 长期支持（LTS）版本中，用户可以在支持期内一直使用发布时的标准（GA）内核，也可以安装 HWE 更新，后者将较新的 Linux 内核版本引入现有的 Ubuntu LTS 版本。

目前，两种内核共享同一个固件包，这意味着为 HWE 内核设计的固件更新可能会给坚持使用 GA 内核的用户带来问题。

Ubuntu 开发者 Juerg Haefliger 指出，针对 Ubuntu 24.04 LTS 的固件回移植（原本为其 Linux 7.0 HWE 内核准备）给使用 Linux 6.9 GA 内核的用户带来了两个 AMD 回归问题。

因此，需要一种新的方法。

Haefliger 提出的方案是让 HWE 内核使用一个软件包，该包会引入现有固件子包的 HWE 版本。如果你错过了那条消息，Ubuntu 的固件包在 24.04 中也被拆分成了子包。

这一变化将让坚持使用 GA 内核的用户继续使用标准固件集，而不会收到为 HWE 内核准备的更新。

但两套固件在各自的支持期内都将继续获得 Canonical 针对已报告问题的针对性修复。

不过，有一个小问题。

我们大多数运行 LTS 版本的人，在某个时候都会在同一设备上安装 GA 和 HWE 内核。由于只能安装一个固件包，同时拥有两种内核的系统将需要某种变通方案。
