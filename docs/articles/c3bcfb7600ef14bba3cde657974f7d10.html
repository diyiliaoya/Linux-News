Linux 内核为 AMD TLBI 勘误 #1718 引入变通方案

2026年10月11日上午09:20 EDT。

AMD TLBI 勘误 #1718 此前已通过 CPU 微码解决，该缺陷存在于部分 Zen CPU 中，即转换后备缓冲器失效指令的使用可能导致过时的转换条目。但对于使用受影响 AMD CPU 且未运行更新微码的用户，随着今日 Linux 7.3-rc7 内核的发布，一项内核变通方案被引入，并将向后移植到先前内核版本。

受此缺陷影响的 CPU 在较旧的 CPU 微码版本上执行 / TLBSYNC 指令对时，可能无法正确失效 TLB 条目。自 2024 年底以来，Linux 一直使用 AMD INVLPGB 进行内核 TLB 刷新以提升性能，正如之前 Phoronix 基准测试所示。随着该代码今日主线化，现在采用软件变通方案强制使用 TLBSYNC，以确保在未通过微码缓解的情况下正确失效 TLB 条目。

这是今日拉取请求进入 Linux 7.3-rc7 的唯一修复，并将在未来几天内向后移植到过去两年支持的稳定内核分支。
