Wine 11.23 发布：支持 ARM64 macOS，在 ARM64 上实现 32 位模拟的 AVX

Wine 11.23 作为双周开发版发布，新增对 ARM64 macOS 的初步支持（需 macOS 27），并在 64 位 ARM 的 32 位模拟中引入 AVX 支持。该版本还集成了 VKD3D 2.2 对 Direct3D 12 的改进，改进了 WIDL 生成 C++ 头文件的能力，并支持远程 OpenGL 交换链图像呈现，使 Chromium 嵌入式框架在 Wayland 下运行更佳。此外包含 40 项已知错误修复。

Wine 11.23 发布：支持 ARM64 macOS，在 ARM64 上实现 32 位模拟的 AVX

2026 年 11 月 27 日 20:31 EST 发布。

我们正接近 Wine 12.0 候选发布阶段，但今天发布的 Wine 11.23 是最新的双周开发版本，继续为 Wine 引入新功能。

Wine 11.23 新增了对 macOS 上 ARM64 的初步支持。终于来了。为支持 ARM64 macOS，需要进行多项 Wine 构建更改，以及一些 NTDLL 更改，以正确处理过去六年 Apple Silicon Mac 上的 ARM64 macOS。ARM64 支持依赖于 macOS 27。

在 ARM64 方面，Wine 11.23 的另一个显著变化是在 64 位 ARM 上的 32 位模拟中增加了对高级矢量扩展（AVX）的支持。Wine 11.22 为 64 位（x86_64）引入了 ARM64 上的 AVX 模拟，而现在 32 位软件也能使用了。

Wine 11.23 还引入了新版本，通过 Vulkan API 为 Direct3D 12 带来许多改进。

Wine 11.23 版本还改进了 WIDL 中生成 C++ 头文件的支持。

最后但同样重要的是，Wine 11.23 支持远程 OpenGL 交换链图像呈现，这也使得 Chromium 嵌入式框架（CEF）在 Wine 下的 Wayland 上能够良好运行。

Wine 11.23 还包含 40 项已知错误修复，有助于各种 Windows 游戏和应用程序。Wine 11.23 的完整修复和补丁列表可通过发布公告查看。
