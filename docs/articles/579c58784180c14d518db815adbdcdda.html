Firefox 155 发布：通过 Happy Eyeballs v3 加速页面加载，支持 HTTP/3 的 QUIC v2

发布于 2026 年 8 月 31 日下午 4:48（美东时间）

Mozilla Firefox 155 的发布二进制文件现已可用，早于周二正式公告。与以往版本相比，Firefox 155 带来了更多新功能。

借助 Firefox 155，网页加载速度得以提升，这得益于 Happy Eyeballs v3 技术——浏览器可同时尝试多种方式连接网站，并选择最先成功的那一种。Happy Eyeballs v3 在并行进行 IPv4 与 IPv6 选择的基础上，进一步利用现代 DNS 记录来发现服务器支持的协议，并同时尝试 HTTP/2 和 HTTP/3，以找到最快的连接方式。

此外，Firefox 155 还支持将 QUIC 版本 2 用于 HTTP/3 连接，并在服务器通过兼容的版本协商选择该协议时自动使用。

Firefox 155 还引入了 Smart Window，这是一个可选的、由 AI 驱动的桌面浏览窗口。该功能允许用户授权访问其打开的标签页和浏览历史。Smart Window 最初仅面向美国、加拿大和法国的用户开放。

Firefox 155 还修复了一个问题，该问题曾导致 Linux 系统在长时间浏览后无法进入休眠状态。

Firefox 155 还包含许多开发者相关的变更，例如支持 WebAssembly Compact Import Section、支持 128 位算术指令的 WebAssembly Wide Arithmetic、将 font-width 属性作为 font-stretch 的标准名称、改进 WebRTC 互操作性，以及支持 CSS 的 progress() 函数。
