Manjaro Linux 26.1 发布，搭载 GNOME 50 与 KDE Plasma 6.7 桌面环境

2026年8月12日下午2:28（美国东部时间）

Manjaro 26.1 Bian-May 现已发布，这是这款基于 Arch Linux 的桌面 Linux 发行版的最新功能版本。

这是自 1 月份 Manjaro 26.0 以来的首个新标签版本。Manjaro 26.1 带来了许多新软件包。其中，面向用户最直观的更新是提供了 GNOME 50 和 KDE Plasma 6.7 桌面环境。此外，对于偏好轻量级桌面的用户，还提供了 Xfce 4.20。

Manjaro Linux 26.1 采用 Linux 7.1 稳定内核，同时为感兴趣的用户提供 Linux 6.18 LTS 和 Linux 6.12 LTS 内核。
