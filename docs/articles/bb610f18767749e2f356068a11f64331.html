发行版发布：Proxmox 9.3 "Virtual Environment"

Proxmox 9.3 "Virtual Environment" 正式发布，基于 Debian 13.8 "Trixie"，默认搭载 Linux 内核 7.0，并集成 QEMU 11.1、LXC 7.0 和 ZFS 2.4。新版本重点简化了集群中的 SAN 与多路径配置，引入唯一客户机标识以可靠追踪迁移和备份，改进 Web UI 的日常维护与故障排查，并扩展了 SDN 和安装程序的安全能力。此外还带来 LVM 厚置备快照链、HA 维护模式 GUI、自定义存储插件支持、嵌套通知规则、Ceph Tentacle 20.2 稳定默认等亮点。

发行版发布：Proxmox 9.3 "Virtual Environment"（DistroWatch.com 新闻）

该项目已发布新版本 Proxmox 9.3 "Virtual Environment"，引入了新的管理工具，并运行在 Linux 内核 7.0 版本上。

“我们很高兴地宣布 Proxmox Virtual Environment 9.3 发布。此版本专注于简化跨集群的 SAN 和多路径设置，通过唯一的客户机身份实现迁移和备份过程中可靠的客户机追踪，改进 Web UI 中的日常维护和故障排查，并扩展软件定义网络（SDN）和安装程序的安全能力。Proxmox VE 9.3 基于 Debian 13.8 'Trixie'，默认包含 Linux 内核 7.0 作为稳定版本（内核 7.3 可作为可选版本使用）。除了核心系统增强外，此更新还集成了我们关键底层技术的最新版本，包括 QEMU 11.1、LXC 7.0 和 ZFS 2.4。以下是 Proxmox VE 9.3 的亮点：集群范围的多路径和 SAN 视图（iSCSI、光纤通道、NVMe-oF）；在厚置备 LVM 上将快照作为卷链；通过 GUI 实现 HA 维护模式；GUI 支持自定义存储插件；虚拟机和容器的唯一客户机身份；嵌套通知匹配规则；SDN：为 Simple 区域提供专用 VRF、实时 WireGuard 状态；Ceph Tentacle 20.2 作为稳定默认版本，同时 Ceph Umbrella 21.2 作为可选项。”
