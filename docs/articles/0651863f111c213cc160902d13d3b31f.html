Ghostty 1.4 速度更快、内存占用更低，但放弃对 Ubuntu 24.04 LTS 的支持

Ghostty 1.4 经过七个月开发发布，性能提升且内存占用降低，但不再支持 Ubuntu 24.04 LTS，因需要 GTK 4.18 和 libadwaita 1.7。新版本改进了分数缩放下的文本清晰度、减少撕裂，支持分屏拖放、Wayland 全局快捷键、背景模糊，并压缩回滚缓冲区节省 70%-90% 内存，默认回滚限制提升至 50MB。还实现了完整的 Kitty 图形协议，修复了十个安全问题。

Ghostty 1.4 经过七个月开发后发布

Ghostty 1.4 速度更快、内存占用更低，但放弃对 Ubuntu 24.04 LTS 的支持

放弃 Ubuntu 24.04 支持是因为原生构建需要一些更新的依赖。无论如何，这个 Ghostty 版本还有更多内容。

Ghostty 是 HashiCorp 联合创始人 Mitchell Hashimoto 开发的一款终端模拟器，它实现了 GPU 加速，同时在每个支持的平台上保持原生外观。

在 Linux 上，该应用使用 GTK，而在 macOS 上，应用使用 SwiftUI。

该项目声称拥有数百万日活用户，许多其他终端模拟器已经采用了它提供的基于 C 的虚拟终端模拟器库 libghostty。

Ghostty 1.4 是一个重要版本，有超过 170 名贡献者和 2,800 多次提交。我们将主要关注 Linux 用户获得的内容，并简要介绍其他平台的变化，以便你了解全貌。

Ubuntu 24.04 无法运行原生构建的原因是 Ghostty 1.4 需要 GTK 4.18 和 libadwaita 1.7，如果加载较旧的库，启动时会退出。开发者表示，用户可以选择较旧的构建来在系统上运行 Ghostty。

回到本次发布，GTK 应用在分数缩放（如 125% 或 150%）下获得清晰文本，此前由于一些上游更改而显得模糊，重建的三重缓冲渲染器预计将减少撕裂。

然后是分屏窗口的拖放功能，macOS 自 1.3 起就有此功能，现在可以将一个分屏拖放到任何其他分屏上，甚至在不同标签页或窗口中，其运行的进程和工作目录会随之移动。

Wayland 上的全局快捷键现在在 Hyprland 0.56 及更新版本的合成器上使用 global-shortcuts 协议，其余则通过桌面门户。这应能改善不同 Wayland 合成器上的热键行为。

背景模糊现在在 GTK 应用上生效。toggle-quick-terminal 命令帮助无法注册全局快捷键的窗口管理器。

GTK 应用还重新设计了一些键盘快捷键：

Ctrl+Shift+Page Up/Down 可用于横向移动当前标签页。

在前后提示符之间跳转可以通过 Ctrl+Shift+Arrow-Down 完成，而不再仅由 Ctrl+Shift+Arrow-Up 处理。

Ctrl+Shift+Arrow-Up 现在行为不同，依赖旧行为的用户被告知改用 Ctrl+Shift+Page Up。

终端空闲时，屏幕外回滚缓冲区现在会被压缩，估计可节省 70% 到 90% 的内存。

压缩还为更高的默认回滚限制腾出了空间，从 10MB 提升到 50MB。

一些额外变化：

Ghostty 现在实现了完整的 Kitty 图形协议，该项目声称除了 Kitty 本身之外没有其他终端做到这一点。还有一个新的 ssh 命令，替代 ssh 并在连接前在远程主机上安装 Ghostty 的 terminfo。

修复了十个安全问题，其中四个仅影响 macOS，其余包括一个粘贴保护漏洞和一个特殊命名的目录，可能使 shell 集成发送转义序列，包括悄悄替换剪贴板的序列。

Mac 用户获得对 macOS 27 的支持，而较旧的 Mac 获得 macOS 13 支持，该支持一直保持到项目在未来版本中放弃它。

在 Windows 上，项目决定从其路线图中放弃 GUI 支持，并指向已经为 Windows 构建的下游项目。

Ghostty 项目只提供源代码，各个发行版自行打包，Arch Linux、NixOS、Alpine Linux、Gentoo、openSUSE 和 Ubuntu 26.04 是拥有它的发行版。

也存在静态构建，但建议从源代码构建。

你可以使用源代码压缩包构建 Ghostty，构建说明中有你需要的步骤。
