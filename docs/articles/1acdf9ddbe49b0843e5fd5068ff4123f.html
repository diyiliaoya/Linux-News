Linux 7.0-mk2 发布：多内核 Linux 性能表现令人期待

Linux 7.0-mk2 作为多内核 Linux 的首个公开版本正式发布。该架构允许单个物理机器上同时运行多个独立的 Linux 内核实例，每个实例运行在专用 CPU 核心上，共享底层硬件资源，无需虚拟机监控程序。开发者通过设备树声明实例，并支持动态迁移资源。初步基准测试显示，其性能优于 KVM，在 24 核配置下双内核运行比单内核更具优势。目前该特性尚未确定是否及何时合入主线内核。

此前，有人提出了 Linux 内核的多内核架构，允许单个物理机器上共存多个独立的内核实例。采用“多内核”Linux 的每个内核可以运行在专用的 CPU 核心上，同时共享底层硬件资源。今天发布的 Linux 7.0-mk2 正是针对这一多内核行为打了补丁的内核。

在过去一年中，多内核补丁陆续发布，而今天它们被便捷地整合到 Linux 7.0 内核树中，以便于测试和评估。这被认为是多内核 Linux 树的首个公开版本。

Multikernel Technologies 的开发者 Cong Wang 总结道：

“mklinux 让一台机器能够在裸机上同时运行多个独立的 Linux 内核，而无需虚拟机监控程序。宿主内核拥有一个 CPU、内存和 PCI 设备池，将该池划分为多个实例，并通过 kexec_file_load() 将生成的内核启动到每个实例中。每个生成的内核都在自己的 CPU、自己的物理内存和自己的设备上原生运行。没有任何模拟，也没有任何陷入；唯一共享的是你选择共享的内容。

实例通过写入 /sys/fs/multikernel/ 的设备树来声明，设备树覆盖可以在不重启的情况下在池和运行中的实例之间移动内存、CPU 和设备。实例可以被关闭，其资源被回收，并用不同的内核重新生成。

与虚拟机相比，没有 VM 退出路径，没有第二级页表，也没有设备模型。与容器相比，实例不共享内核，因此一个内核中的锁、崩溃或漏洞无法影响到另一个内核。”
