多内核 Linux 登陆 ARM64，mklinux 7.0-mk5 发布

多内核 Linux 补丁发布 mklinux 7.0-mk5 版本，基于上游 Linux 7.0 内核。此次更新最大亮点是补丁扩展至 64 位 ARM（ARM64/AArch64）架构，此前仅支持 x86_64。新代码还改进了设备丢失与 DMA 限制处理、VT-d 集成、链式接管等方面。多内核架构可用于容错内核、在特定 CPU 核心上运行实时内核等非传统计算场景。

多内核 Linux 补丁发布新版本，允许在同一物理机器上运行多个独立的内核实例。

多内核架构对于容错内核用途、在特定 CPU 核心上运行实时（RT）内核以及其他非传统计算用途颇具吸引力。最近还通过 Kmorph 展示了多内核在无重启 Linux 内核崩溃恢复方面的应用。

现已发布 mklinux 7.0-mk5，这是基于上游 Linux 7.0 内核的多内核补丁的最新迭代版本。此次多内核更新最值得注意的是，补丁已扩展至可在 64 位 ARM（ARM64 / AArch64）上运行。此前多内核仅能在 x86_64 硬件上工作，现在 ARM64 也可运行。

更新后的多内核代码还在设备丢失与 DMA 限制、VT-d 集成工作、链式接管等方面有所改进。

对多内核工作感兴趣的人可通过 7.0-mk5 公告了解更多信息。有关多内核工作本身的更多细节可在相关页面找到。
