GIMP 3.2.8 发布，改进文本工具与性能

GIMP 3.2.8 作为当前稳定系列的第四个维护更新发布，主要聚焦于错误修复和细节优化，未引入全新功能。此次更新改进了对话框初始定位、页面加载速度，增强了文本工具对从右到左语言的支持，修复了链接图层文件编辑问题，并优化了大渐变缓存和“蚂蚁线”动画性能。此外还包含针对 macOS 和 Windows 的平台修复及若干安全更新。

GIMP 3.2.8 提供了更好的对话框初始定位，使页面加载更快，并允许通过[某功能]创建色彩丰富的半透明边框。

此更新还增强了对文本工具对从右到左（RTL）语言的支持。方向键行为正确，画布界面会显示方向图标。如果未设置文本方向，Unicode 双向算法会根据输入的第一个字符选择方向。

修复了编辑链接图层文件（GIMP 对 Photoshop 智能对象的对应功能）时的一个“陷阱”。当链接文件正在添加过程中时，属性对话框不再允许点击“确定”。“取消”仍可选择，以备需要。

性能调整带来了对大型渐变（6000px）更好的缓存，以及更高效的“蚂蚁线”动画。HEIF 加载代码经过调整，允许加载更大的图像。

对于开发者，新增了一套 GUI 测试套件。团队[表示]这将帮助他们在开发过程中而非之后检查 GUI 的回归问题。计划很快分享更多细节。

除此之外，v3.2.8 更新还为 GIMP 的 macOS 和 Windows 版本带来了一些平台特定的修复，包括更好的主题匹配、打印和窗口行为。

除了整体上稍微更好之外，此更新也稍微更安全。包含了一小组安全更新，修补了 GIMP 使用的库中最近发现的几个漏洞。
