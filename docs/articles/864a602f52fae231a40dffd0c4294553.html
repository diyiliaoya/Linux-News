Raspberry Pi Zero 3 W 与 Raspberry Pi 4 Model A 现身 Linux 内核补丁

在 Raspberry Pi 官方 Linux 内核树中，新合并的补丁为 Raspberry Pi Zero 3 W 和 Raspberry Pi 4 Model A 添加了设备树文件。Zero 3 W 采用与 Raspberry Pi 4 相同的 Broadcom BCM2711 四核 Cortex-A72 SoC，距 Zero 2 W 发布已五年。Raspberry Pi 4 Model A 则可能是应对元器件涨价、面向低需求用户的低成本精简版。新硬件有望很快发布上市。

看起来下一代 Raspberry Pi Zero 即将现身，即备受期待的 Raspberry Pi Zero 3 W。而一个有趣的转折是，在当前 PC 元器件成本高企和供应链受限的时期，还出现了一款 Raspberry Pi 4 Model A。

Raspberry Pi 官方 Linux 内核树已合并补丁，为 Raspberry Pi Zero 3 W 以及 Raspberry Pi 4 Model A 添加了设备树文件。

距离 Raspberry Pi Zero 2 W 发布已过去五年，许多人都在猜测是否会有继任者，尤其是在近期内存价格和供应链瓶颈的背景下。好吧，从这次 Raspberry Pi 内核的动态来看，它似乎很快就会到来。Raspberry Pi Zero 3 W 的设备树文件显示其使用 Broadcom BCM2711 SoC，即 Raspberry Pi 4 所用的同款四核 Cortex-A72 SoC。该设备树添加中尚无更多关于 Raspberry Pi Zero 3 W 的详细信息。

另一个惊喜是 Raspberry Pi 4 Model A。Raspberry Pi 曾推出初代 Model A、Model A+ 以及 Raspberry Pi 3 Model A+ 版本，作为全功能 Model B 单板计算机的低成本精简版。Model A 版本通常略小、功耗更低，但 I/O 能力较少，甚至省略了以太网，不过价格也更低。

尽管 Raspberry Pi 5 是最新一代，但随着整个行业元器件价格上涨，Raspberry Pi 单板计算机持续面临挑战，推出 Raspberry Pi 4 Model A 似乎是合理的，可以为不需要全功能、最新一代 Raspberry Pi 单板计算机的用户提供选择，并以相对较低的价格实现。

随着这些补丁进入 Raspberry Pi 内核，希望我们很快能看到新硬件发布并上市。
