Tether 将 Apple 连续互通体验带到 Linux

Tether 是一个开源项目，旨在将 Apple 的连续互通（Continuity）体验带到 Linux，无需 Mac 设备即可在 iPhone 和 Linux 之间同步 iMessage、短信和 OTP 验证码。该项目由开发者 Zack 创建，使用蓝牙和加密配对，支持通过 CLI 和 GTK4 应用管理，并提供 iOS 应用。目前，Tether 已支持多项功能，部分仍处于测试阶段。用户可通过 AUR 安装，并需安装 iOS 应用及浏览器扩展以启用 OTP 自动填充。

Tether 将 Apple 连续互通体验带到 Linux

这款开源方案可在 iPhone 和 Linux 之间同步 iMessage、短信和 OTP 验证码，无需 Mac 设备。

有一位开发者全职切换到 Linux，并且基本上没有回头考虑过之前日常使用的 macOS。然而，有一个例外。

这个例外就是 Apple 的连续互通（Continuity）功能，它让 iPhone、iPad 和 Mac 之间能够相互协作。它涵盖了许多小便利：在 iPhone 上复制内容，在 Mac 上粘贴；在一台设备上开始写邮件，在另一台设备上完成；即使手机在房间另一头，也能在 Mac 上接听电话。

但毫不意外的是，它的支持存在缺口。它并不官方支持 Linux。因此，Zack 构建了一个开源项目，在 Linux 上复刻了部分连续互通体验，且无需 Mac 设备。

考虑到这个应用在几个月前（5 月）才刚刚发布，Tether 已经覆盖了很多功能。目前所有功能都已上线，其中一些仍处于测试阶段。

Tether 在 Linux 上处理设备间通信，通过 CLI 和原生 GTK4 应用进行配对。SwiftUI 编写的 iPhone 应用会自动发现 Linux 上的守护进程（daemon）。

Linux 没有官方途径访问 iMessage 或短信，而 Zack 排除了通过实际 Mac 代理所有内容的常见变通方案。

BlueZ 和 libimobiledevice 提供了足够的蓝牙基础，让他能够构建自己的路径，不过两者都是 GPL 许可的，因此用 C++ 重写使 Tether 保持 GPL 许可。此外，他在配对过程中使用了端到端加密，因此 iPhone 和 Linux 守护进程在连接前都必须证明各自的身份。代码库还定期通过 Anthropic 的 Opus 和 Fable AI 模型进行安全扫描。

如果你认为 KDE Connect 已经做了很多 Tether 能做的事情，要知道 Zack 知道它的存在，并称其“很棒”，但他指出该应用并不满足他设想的使用场景。

此外，你需要从 App Store 下载 Tether - Linux Companion 应用，这要求你的设备至少运行 iOS 17。

如果你希望 OTP 自动填充正常工作，还需要两个扩展：一个浏览器扩展，能在验证码到达时自动填入登录表单；以及 Thunderbird 扩展，它会监视你的收件箱，查找任何看起来像验证码的内容，并将其交给 Linux 机器上运行的 Tether 应用。
