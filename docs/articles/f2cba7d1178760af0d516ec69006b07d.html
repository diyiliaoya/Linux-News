Wisp 让在 GNOME 桌面管理 Btrfs 快照变得更轻松

2026年9月26日 06:45 EDT。

Wisp 是一款新的 GNOME Shell 扩展，让以图形方式管理 Btrfs 文件系统快照变得更加容易。

在最新一期（主要关于 GNOME 51 发布后的应用更新）中，我觉得最有趣的是 Wisp 这个新的 GNOME Shell 扩展。Wisp 与 Snapper 对接，提供了一种在系统上管理 Btrfs 文件系统快照的便捷方式。

对于那些不想通过命令行与 Snapper 交互来管理其基于 Btrfs 的 Linux 系统的用户，Wisp 提供了一种在现代 GNOME 桌面中以图形方式轻松完成这些操作的方法。

通过 Wisp，用户可以轻松查看给定 Btrfs 快照之间哪些文件发生了变化、调整保留策略和其他 Snapper 相关设置、手动创建新的文件系统快照以及执行相关任务。

Wisp 可从 GNOME 扩展网站获取，也可以通过其他途径找到。
