Asahi Linux 希望尽快发布支持 Apple M3 设备的版本

2026年8月26日，美国东部时间晚上8:25。

致力于将 Linux 带到 Apple Silicon 硬件上的 Asahi Linux 团队今天发布了关于其项目的最新状态更新，主要围绕 Apple M3 的适配工作，以及一些 M4/M5 的进展。

目前正在进行的工作旨在改进主线上 Linux 内核中对 Apple CPU 核心的电源管理。由于上游要求 ARM64 设备使用电源状态协调接口（PSCI）进行电源管理，而当前 Apple Silicon 和 Asahi 驱动设计无法很好地满足这些约束，因此目前只有下游的 Asahi Linux 代码提供了“深度”等待中断（WFI）指令的使用。不过，团队正在努力实现一个基于 UEFI 运行时服务的 PSCI 通道，以适用于 Apple Silicon / Asahi 的 Linux 使用场景。

Asahi Linux 开发人员也在继续推进 Apple M3 系列机器的适配工作。麦克风处理方面有一些细微变化，得益于新的补丁，M3 设备上的网络摄像头支持现已正常工作，此外还有其他改进。Apple M3 的 USB 端口控制器变化带来了更多的逆向工程工作和麻烦，但借助最新的下游 Asahi Linux 代码，USB 3.0 和 Thunderbolt 现已正常工作。

Asahi Linux 开发人员几乎已经准备好发布一个支持 Apple M3 的版本，供使用其下游代码的用户使用。未来几周内，预计将公布更多关于 Asahi Linux 上 Apple M3 的详细信息。显然，将所有代码上游整合到主线 Linux 内核还需要更多时间。

Asahi Linux 开发人员也在继续推进 Apple M4 和 M5 的适配工作，但仍有更多工作有待完成。

Asahi Linux 的帖子还详细介绍了他们在适配 Apple M4 过程中面临的挑战，包括 Apple 的设计选择以及 Apple 安全特性带来的其他麻烦。

Asahi Linux 开发人员还在努力实现 GPU 直接扫描输出支持，这是另一个重要的改进，但在向用户推出之前仍有更多工作要做。
