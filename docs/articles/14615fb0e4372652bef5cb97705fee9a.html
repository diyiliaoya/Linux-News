发行版发布：XXRI OS 2.7

XXRI OS 2.7 正式发布，这是一款专为老旧及低配置电脑（包括32位系统）设计的超轻量级桌面Linux发行版，搭载自定义XXRI桌面。新版本重点提升了系统稳定性、硬件兼容性和桌面易用性，改进了x86_64架构支持，为32位和64位系统提供独立应用目录，增强64位AppImage集成，并优化了XXRI商店的索引加载、搜索与安装体验，同时新增系统托盘并改进多显示器窗口定位。

Jantzen Maximillian Kimlim 宣布发布 XXRI OS 2.7。XXRI OS 是一款超轻量级桌面 Linux 发行版，专为老旧和低配置电脑设计，包括 32 位系统。它采用名为 XXRI 的自定义桌面环境。该项目的最新版本承诺带来更流畅的桌面体验和更好的硬件支持：

“XXRI OS 2.7 来了。此版本在整个系统层面带来了大量改进，重点关注稳定性、硬件兼容性、桌面可用性以及我们 64 位平台的持续演进。以下是新增内容：改进的 x86_64 架构支持；为 32 位和 64 位系统提供独立的应用目录；改进的 64 位 AppImage 集成；新增打包应用目录支持，使商店访问更可靠；改进的硬件检测，包括基于 eMMC 的设备；改进的启动初始化和根设备检测。XXRI 商店：通过新的索引系统加快目录加载速度；修复搜索和滚动崩溃问题；修复安装进度指示器；改进应用程序安装与集成；修复缺失的应用图标；新增更清晰的安装状态和诊断日志；改进更新处理和商店响应速度。桌面与显示：新增系统托盘；改进多显示器窗口定位……”

以上内容发布于该项目的 SourceForge 页面。
