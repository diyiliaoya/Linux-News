System76 推出 Thelio Mira AI，搭载 AMD Ryzen 及 NVIDIA 或 AMD 显卡

System76 发布新款桌面电脑 Thelio Mira AI，基于 AMD Ryzen 9000 系列平台，支持最高双 NVIDIA RTX PRO 6000 或 AMD Radeon AI PRO R9700 显卡，面向多 GPU AI 训练、模型微调、推理、计算机视觉和图像生成等任务，起售价 3299 美元。

System76 今日发布了其最新台式机 Thelio Mira AI。System76 Thelio Mira AI 在 AI 方面专为多 GPU AI 训练、模型微调、AI 推理、计算机视觉和图像生成任务而设计。凭借其 AMD Ryzen 9000 系列 CPU 以及 NVIDIA/AMD GPU 选项，它也是模拟和其他 HPC 类工作负载的理想选择。

今年早些时候，System76 推出了搭载 AMD Ryzen 9000 系列 CPU 的新款 System76 Thelio Mira Linux 桌面。Thelio Mira AI 沿用了同样更新的机箱设计和 Ryzen 9000 系列平台，但现在增加了额外的 GPU 选项、可使用更低功耗的 AMD CPU 以便为 GPU 留出更多供电容量，以及其他组件选项。Thelio Mira AI 起售价为 3299 美元。

在我对它的 Linux 测试中表现相当不错，而现在的 Thelio Mira AI 是它的进化版。CPU 选项包括 AMD Ryzen 7 9700X / Ryzen 9 9900X / Ryzen 9 9950X。GPU 方面最高可选 AMD Radeon AI PRO R9700 或 NVIDIA RTX PRO 6000。如果预算允许，最多可配备两块 RTX PRO 6000 显卡。标配 64GB 内存，可升级至 128GB 或 192GB，并提供多种 SSD 选项。

如果需要在 CPU 方面更强大、采用 AMD Ryzen Threadripper 的产品，System76 Thelio Major 是目前 Phoronix 的最爱。
