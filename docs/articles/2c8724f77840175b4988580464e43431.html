Calibre 电子书管理器新增 AI 驱动的写作游戏

Calibre v9.15 新增“创建你自己的冒险”AI 互动小说功能，用户可构建虚构世界并交由 AI 实时管理。该功能完全可选，需配置兼容 LLM 的 API 密钥。此外更新还改进了电子书查看器的高亮面板、侧边栏自定义按钮和封面网格布局，并修复了朗读、拼写检查及加拿大艾伯塔省时区变更导致的启动问题。

Calibre v9.15 新增了一款 AI 驱动的互动小说游戏。这款广受欢迎的开源电子书管理器，如今具备了一个 AI 驱动的写作游戏。

根据发布说明，“创建你自己的冒险”功能让你构建一个虚构世界，并将控制权交给 AI，AI 会根据你的回应实时管理这个世界。我想，这有点像古老的文字角色扮演游戏。

更新日志以明显的轻描淡写指出，该功能“偏离了 Calibre 的常规功能”，并补充说它最初是开发者测试工具 AI 后端的一种方式，后来发展成了“某种有趣的东西”。

在 Calibre v9.15 中设置你的 AI 世界

与 Calibre 中所有 AI 功能一样，它完全可选，因为它依赖于你添加兼容 LLM 的 API 密钥。要尝试它，请转到“首选项 > 工具栏”，将“创建你自己的冒险”按钮添加到工具栏。点击此按钮打开设置向导。

这并不是 Calibre 获得的第一个令人费解的 AI 功能。上个月，它新增了使用 AI 提示和预设风格生成电子书封面的功能（如黑色电影风格；低俗科幻风格的芭芭拉·卡特兰小说，等等）。

Calibre 用户大多是喜欢读书的人——大多数人都有大量读不完的书。喜欢用 LLM 生成小说的人可能不需要电子书管理器，反之亦然。

我确实在想，Calibre 是否应该专注于添加有帮助而非分散注意力的 AI 功能：让用户整理电子书、修复元数据，或根据用户的图书馆和品味生成“接下来读什么”的播放列表。

生成垃圾封面、总结书籍，以及现在的生成小说，感觉与其角色格格不入。

Calibre 9.15 的其他变化

此更新还带来了一些不会让人集体挠头的改进。

电子书查看器中的面板让你可以选择多个高亮，并右键单击它们来更改样式；如果高亮有笔记，鼠标悬停时可以在提示框中看到该笔记（此行为可以禁用）。

还有更多自定义选项。可以在侧边栏添加一个按钮，在保存的窗口大小之间切换；在封面网格中，你现在可以通过“首选项 > 外观 > 封面网格 > 布局”选择书目标志出现在哪个角落。

修复了大量错误，包括朗读在大图片处停止的问题、拼写检查忽略带单个撇号的单词的怪癖，以及加拿大艾伯塔省用户因最近时区变更而无法启动的问题。

Calibre 是适用于 Windows、macOS 和 Linux 的免费开源软件。

从官方网站下载——在 Linux 上，Calibre 通过命令行脚本安装和更新，该脚本会下载二进制文件，将其解压到系统文件夹，并创建在应用菜单中找到和打开它所需的各种快捷方式等。
