DistroWatch 周刊，第 1186 期

本周 DistroWatch 周刊报道了多个 Linux 发行版的最新动态：Kubuntu 用户将受益于 Plasma 的长期支持；Redox OS 改进了安装程序并提升了上下文切换速度；NetBSD 正在更新 Enlightenment 移植版本；Mint 推出了新的内核管理器；Proxmox 现已支持 ARM 处理器；Mageia 重点介绍了 Pidgin；Arch 项目将阻止向 AUR 的新推送；Ubuntu 将为 LTS 版本提供虚拟化工具升级；Garuda 更新了 FireDragon 浏览器；Haiku 获得了在移植浏览器上使用 Firefox 品牌的权利。此外，本期还包含对 Helwan Linux 5.0 的评测，以及关于发行版默认 shell 的投票。
