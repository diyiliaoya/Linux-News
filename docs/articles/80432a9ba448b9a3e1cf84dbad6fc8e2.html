Ubuntu 已为阿尔伯塔省和摩洛哥时区变更做好准备

Ubuntu 更新了 tzdata 时区数据库，以应对加拿大阿尔伯塔省将于2026年11月永久采用夏令时（UTC-6），以及摩洛哥将于2026年9月恢复格林尼治标准时间（GMT+0）的变更。更新将自动推送到所有受支持的 Ubuntu 版本（包括16.04 LTS）及基于 Ubuntu 的发行版（如 Linux Mint、ZorinOS 和 Pop!_OS），确保用户系统时间自动同步，避免因时间错误导致的安全和访问问题。

时区在变，Ubuntu 也在跟进——嗯，算是吧。

今年11月，加拿大大部分地区将把时钟拨慢一小时，但加拿大西部省份阿尔伯塔省不会。该省决定永久保留夏令时，而不是回拨至标准时间。

与此同时，摩洛哥在9月将反其道而行：在比格林尼治标准时间快一小时运行了八年之后，它将回归 GMT。

因此，Ubuntu 更新了其 tzdata 软件包，以便这两个地区的用户——或任何前往这些地区的人——都能在时间上保持系统同步。

此次更新刷新了数据库，使操作系统能够识别并计算适用于各地的时区规则。

基于 Ubuntu 的下游发行版，如 Linux Mint，也会获得此更新。

如果没有该更新，Ubuntu 将继续应用旧规则。除了造成困惑之外，系统时间不正确也是一种安全风险，这可能导致访问网站、软件仓库和安全功能时出现问题。

阿尔伯塔省或摩洛哥的用户在各自的变更日期到来时，无需手动调整系统时间。只要安装了 tzdata 2026c 更新（或更新版本），时钟变更时就会自动显示正确时间。

该更新正在向所有受支持的 Ubuntu 版本推送，最早可追溯至 16.04 LTS（在 Ubuntu Pro 中仍通过 Legacy 附加组件获得支持）。它也将应用于基于 Ubuntu 的发行版，如 Linux Mint、ZorinOS 和 Pop!_OS，这些发行版使用 LTS 基础版本。

阿尔伯塔省将从2026年11月1日起全年保持 UTC-6（称为“阿尔伯塔时间”）。阿尔伯塔省的部长们更倾向于在一天结束时而非早晨保留更多光照。该省计划在第一个完整年度后“监测过渡情况”，以确保其运行良好。

摩洛哥将从2026年9月20日起改用 GMT+0。自2018年以来，该国在一年中的大部分时间使用 GMT+1，仅在斋月期间回拨至 GMT+0，斋月结束后再拨快。这一做法并不受欢迎；要求废除它的公众压力最终占了上风。
