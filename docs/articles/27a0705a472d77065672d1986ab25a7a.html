ML4W OS 是一款基于 Arch Linux 的发行版，采用高度定制的 Hyprland 平铺合成器。该项目主要专注于为 Hyprland 创建高级配置，即所谓的“点文件”，这些配置可安装在其他多个基于 Arch 的发行版以及 Fedora 和 openSUSE 上。然而，ML4W OS 的 live ISO 镜像是一个独立的、功能完整的 Linux 发行版，包含所有 Hyprland 配置文件、应用程序、图标、主题和壁纸。它可以使用自定义的文本模式系统安装程序安装到硬盘上。该项目还提供了关于设置和配置 Hyprland 的广泛文档。
