Linux 7.2 晚期声音修复带来更多设备 quirks，Intel Nova Lake HDMI-In 采集支持

Linux 7.2 内核在正式发布前合并了最后一批声音修复和 quirks，包括为 HyperX OMEN 游戏笔记本 16-ap1xxx 启用内置麦克风，修复 SteelSeries Arctis Nova 5 耳机在近期内核上的混音器控制问题，并为即将推出的 Intel Nova Lake 平台添加 HDMI-In 采集支持。这些修复通过声音子系统 pull 请求合入，确保新硬件在 Linux 下正常工作。

Linux 7.2 晚期声音修复带来更多设备 quirks，Intel Nova Lake HDMI-In 采集支持

发布于 2026 年 8 月 15 日 07:03 AM EDT。

在明天预期的稳定内核发布之前，一些最后时刻的声音修复/quirks 已合入这个下一个内核版本。

对于搭载 AMD Ryzen 7/9 处理器的 HyperX OMEN 游戏笔记本 16-ap1xxx（HP 主板 8F06），一个新的 quirk 及时合入 Linux 7.2，允许内置麦克风在 Linux 下使用。没有这个 quirk，HP HyperX OMEN 游戏笔记本 16-ap1xxx 的内置数字麦克风阵列在 Linux 下一直无法使用。

还有一个针对 SteelSeries Arctis Nova 5 耳机的 quirk 修复，以解决其在近期内核上无法正常工作、混音器控件被禁用的问题。

此外，通过这次声音 pull 请求，Linux 7.2 还加入了即将推出的 Intel Nova Lake 平台的 HDMI-In 采集支持。在必要的 ID 添加到 Intel 和 Sound Open Firmware 驱动代码后，Intel Nova Lake 上的 HDMI-In 采集支持已准备就绪。

本周声音补丁的完整列表可以在已合入 Linux 7.2 最终版之前的那个链接中找到。
