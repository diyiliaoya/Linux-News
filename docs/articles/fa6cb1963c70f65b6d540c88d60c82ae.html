Wine 11.22 在 ARM64 上引入 x86 AVX 模拟

Wine 11.22 作为最新双周开发版发布，最引人注目的是在 ARM64 平台的 x86 模拟路径中新增 AVX 支持，通过 ARM64EC 构建可模拟 AVX 以运行依赖该指令集的现代 Windows 软件。此外还更新了 Unicode CLDR 49 区域数据、增加地址空间随机化、改进 Tahoma 字体字形度量、在 XML 中重新实现 DTD 验证，并包含 34 项已知错误修复，涉及 Logos Bible Software、激战2、星际公民等应用和游戏。

Wine 11.22 今日发布，作为最新的双周开发版本，正逐步接近 Wine 12.0 稳定版的发布准备工作。

Wine 11.22 最引人注目的变化是在 Wine ARM64 的 x86 模拟路径中增加了对高级矢量扩展（AVX）的支持。为了帮助运行假定支持 AVX 的现代 Windows 软件，现在可以通过 ARM64EC 构建很好地模拟该指令集。这延续了此前围绕 XState 处理为 ARM64EC 上的 AVX 引入初始 NTDLL 支持的工作。

Wine 11.22 还将区域数据更新至 Unicode CLDR 49，增加了地址空间随机化，改进了 Tahoma 字体的字形度量，在 XML 中重新实现了 DTD 验证，以及常规的一系列错误修复。

Wine 11.22 此版本包含 34 项已知错误修复，涵盖从 Logos Bible Software 到激战2、星际公民以及各种其他游戏和应用修复。
