发行版发布：Asmi Linux 26.10

Asmi Linux 26.10 已发布，基于 Ubuntu 26.10，采用定制 Xfce 4.20 桌面和 Linux 7.3 内核，支持九个月至 2027 年 7 月。新版本默认使用扩展布局，禁用不必要的 AI 功能，将 Ristretto 设为 AVIF 等新格式默认查看器，并以仅 700 KB 的汇编编写文本编辑器 Rhun 取代 Geany。

Tony George 宣布推出 Asmi Linux 的更新版本。这是一款基于 Ubuntu 的发行版，采用定制化的 Xfce 桌面和“Asmi 设置”——一个自行构建的系统配置工具。它基于新发布的 Ubuntu 26.10：“Asmi Linux 26.10 基于 Ubuntu 26.10‘Stonking Stingray’，现已可用。Asmi Linux 是 Debian/Ubuntu LTS 的再混合版本，配备现代 Xfce 桌面，既实用又易于使用。它精简轻量，适合偏好使用 X11 显示服务器的传统桌面的用户。亮点：基于 Ubuntu 26.10；Xfce 4.20 桌面；Linux 内核 7.3；支持九个月，将在 2027 年 7 月前从 Ubuntu 仓库接收更新。新特性？Xfce——默认使用扩展布局；全新编辑器——禁用不必要的 AI 功能和干扰；Ristretto——设为打开 AVIF 及更新图像格式的默认程序；Rhun 是新的默认文本编辑器，取代 Geany，Rhun 用汇编语言编写，速度非常快，大小仅 700 KB。该 Linux 发行版可免费下载。
