操作系统发布：Sculpt OS 26-10

Genode 项目发布了 Sculpt OS 26-10，这是基于 Genode 微内核的极简通用开源操作系统的最新版本。该版本默认使用 Genode 自研微内核，放弃 XML 配置，支持 VirtualBox 7 虚拟机，并将 USB 主机控制器驱动变为可插拔组件。此外还改进了鼠标指针、组件依赖可视化、网络摄像头灵活性和英国键盘支持。四大底层变化包括：首次采用自研微内核、完成从 XML 到 HID 配置格式的过渡等。

Genode 宣布发布 Sculpt OS 26-10，这是该项目基于 Genode 自有微内核的极简、通用、开源操作系统的最新版本：“Sculpt OS 26.10 发布。Sculpt OS 26.10 默认使用 Genode 的自定义微内核，放弃 XML，在 VirtualBox 7 中托管虚拟机，并将 USB 主机控制器驱动转变为可插拔组件。尽管有一些用户便利性改进，例如可缩放且用户可自定义的鼠标指针、新增的依赖组件可视化概览、网络摄像头使用的更高灵活性，以及对英国键盘的新支持，但当前版本的四大主要转变都在表面之下。首先，Sculpt 26.10 是首个基于 Genode 自定义微内核而非依赖第三方内核的版本。该内核从头开始为 Genode 和 Sculpt OS 的特定需求而设计，不仅比 Genode 支持的任何其他微内核更加‘微’，还解决了长期存在的 CPU 调度和内核内存管理缺陷。Sculpt OS 终于站在了 Genode 自己的 footing 上。其次，该版本标志着从 XML 向 Genode 的 HID 配置格式过渡的终点，提升了系统文本用户界面的舒适度。”阅读其余内容。

Sculpt OS 是由 Genode 开发的一款独立开源操作系统。它结合了 Genode 的微内核架构、基于能力的安全机制、沙盒化设备驱动和虚拟机，为商用 PC 硬件和 PinePhone 提供了一种新颖的操作系统。Sculpt 使用名为“Leitzentrale”的管理用户界面。
