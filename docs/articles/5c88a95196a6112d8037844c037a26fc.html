Rust Coreutils 0.10 发布：增强安全加固，提升 GNU 兼容性

2026年8月5日，美国东部时间下午6:59。

Rust Coreutils 0.10 于今日由 uutils 项目发布，作为 GNU Coreutils 的替代品。Rust Coreutils 0.10 的开发重点在于额外的安全加固，同时提升 GNU 测试套件的兼容性和健壮性。

Rust Coreutils 0.10 现在又通过了 20 个 GNU 测试套件用例，使总通过率达到历史最高的 93.48%。这些 GNU 兼容性更新涉及行为对齐、不同 CPU 条件下的 nproc 处理、日期超出范围年份的处理，以及各种格式差异的修复。此外，Rust Coreutils 的许多错误信息也得到了改进。

Rust Coreutils 0.10 还进行了第二轮安全加固，包括更多的检查时间到使用时间（TOCTOU）修正、安全递归下降修复、mkdir/mkfifo/mknod 在创建时应用 SELinux 标签，以及其他安全更新。

这个新版本还移除了多个核心工具中的 panic 和 abort，现在支持原子交换两个路径，支持新特性，并进行了各种性能改进和其他改进。
