Intel 持续为 Linux 7.5 启用 GPU D 系列“Crescent Island”驱动支持

2026 年 11 月 11 日下午 4:04（美国东部时间）。

基于 Xe3P 的 AI 加速器硬件——现称为 Intel GPU D 系列——持续迎来大量 Linux 内核驱动活动。即将到来的 Linux 7.5 内核正在继续为这款即将推出的硬件构建支持。

Intel 软件工程师一直在为 Linux 推送 Crescent Island 驱动补丁，且是在 Intel 于当年 10 月宣布 Crescent Island 仅数周后便已开始。一年之后，作为面向 Linux 7.5（将是 2027 年首个稳定内核系列）的新工作，已有更多启用代码就位。

最新提交至 DRM-Next 的 drm-xe-next 拉取请求加入了 Xe 硬件监控（HWMON）代码的温度传感器处理、平台上报的 VRAM 热通道、PCIe 与内存控制器温度支持以及其他传感器工作。

Linux 7.5 中为 Intel GPU D 系列带来的还有对 RAS 错误的通用平台错误记录（CPER）日志支持。

此外，还为 Crescent Island 添加了 OOBMSM 遥测“OCode”延迟绑定支持。同时还有对内存双位 ECC 错误的处理。

关于这些最新的 Intel GPU D 系列 / Crescent Island 新增内容以及其他为 Linux 7.5 积累的 Xe 驱动变更的更多细节，可通过以下内容了解：

Intel 发布新 CPU 微码以修复多种功能问题

Intel ANV 为 AV1 编码加入码率控制

Intel One Mono 字体系列更新，带来多项增强

实验性项目让 Intel XeSS 在 XMX 上与 Valve 的 Steam Play（Proton）协同工作

Intel Compute Runtime 持续为 GPU D 系列做准备，为 Nova Lake P 提供 OpenCL LEO

Intel 将 RPL-M/RPL-P SoundWire 引入上游 Linux，面向搭载 Raptor Lake 的汽车
