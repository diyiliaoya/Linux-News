好消息，玩家们！GOG 正式登陆 Linux

GOG 公司已确认正在开发 Linux 版 GOG GALAXY 客户端，并已招聘相关工程师。该客户端将支持自动更新、云存档、成就追踪等功能，且延续 GOG 一贯的无 DRM 政策，允许用户下载离线安装包并自由复制。目前尚无具体发布时间表，但此举被视为 GOG 独立后战略重点之一。

好消息，玩家们！GOG 正式登陆 Linux

他们已聘请专人将 GOG GALAXY 客户端带到该平台。

GOG 整个品牌都建立在销售无 DRM 游戏并提供离线安装包的基础上，这些安装包无需网络连接或任何来自他们一方的验证即可使用。用户可以下载安装包并将其复制到光盘等物理介质上，将副本视为己有。这是该领域的大玩家 Steam 和 Epic Games 无法做到的，因为两者都将你的游戏库绑定在他们的客户端上。

更别提账户状态了。如果你违反他们的规则，他们有权暂停你的账户，或者更糟，直接封禁，让你无法访问自己的游戏。

GOG GALAXY 是该公司的可选客户端，具备人们对此类应用所期望的功能。它处理自动更新、云存档、成就追踪、补丁破坏存档时的回滚，并整合来自其他平台的游戏库。

然而，这些功能从未正式登陆 Linux，因为该客户端仅提供 Windows 和 macOS 版本。希望在系统上使用它的 Linux 玩家必须通过 Bottles 或 Lutris 等兼容层运行 Windows 客户端，而不是直接安装。

当你从 Linux 电脑访问 GOG GALAXY 网站时，会看到这样的画面。

不过，并非全是坏消息，因为现已确认 Linux 版 GOG GALAXY 即将到来。在接受 GamingOnLinux 的 Liam 采访时，GOG 联合首席执行官 Krzysztof Papliński 表示，他们已经有一个“Linux 构建版本”，并且正在寻找“支持 Linux 的最佳方式”。

在你过于兴奋之前，要知道 Krzysztof 在原始邮件回复中并未提及任何发布窗口，他指出：

这是一项重大工程，因此虽然我们尚未准备好分享任何具体计划、时间表或成果，但这确实是我们正在投入时间和精力的领域。

这并非凭空出现。去年年底，GOG 在 CD Projekt 将其出售给联合创始人 Michał Kiciński 后成为一家独立公司，结束了其作为子公司的历程。

几天后，在一月份，Michał 告诉媒体，GOG 的“软件质量差”，并且他并不惊讶人们正在完全远离这个生态系统。

在同一采访中，董事总经理 Maciej Gołębiewski 表示 Linux 已经是 GOG 今年战略中的一部分。

大约在同一时间，招聘信息发布，寻找一名高级软件工程师，职位描述将 Linux 称为该平台的下一个主要前沿。

GOG GALAXY Windows 客户端的占位图。

原生 GOG GALAXY 客户端最终将让 Linux 玩家像 Windows 和 Mac 用户一样管理他们的 GOG 游戏库。虽然我不确定是否会支持其他游戏平台。

但尽管如此，玩家们仍然可以利用一个功能齐全的启动器，轻松处理大型游戏库。它还辅以便利的自动更新、云存档、多设备同步以及与朋友保持联系等功能。

顺便说一句，这比你想象的要重要得多。如今，数字商店对哪些游戏能留在你的库中拥有最终决定权。最近 Xbox 游戏的下架就清楚地表明了这一点。

物理介质也在消失，例如索尼最近确认将从 2028 年 1 月起停止为新的 PlayStation 游戏生产游戏光盘，将新发行版推向纯数字领域。

GOG 的无 DRM 安装包以及让你下载这些安装包的可选客户端消除了这两个问题。由于无需回传检查许可证，将这些安装包复制到 U 盘或刻录到蓝光或 DVD 上，就足以在商店消失后长期保持游戏库的可玩性。
