Firefox 重新设计将在 v157 版本中推出

Mozilla 的 Firefox 浏览器即将迎来名为“Nova”的全新 UI 重新设计，该设计将在 Firefox 157 版本中向所有用户默认启用，预计于 9 月底发布。Nova 设计最初包含圆角 UI 元素、浮动工具栏、网页内容不再与浏览器窗口边缘齐平，以及大量柔和渐变等特色。经过几个月的调整，这些变化被适度收敛，例如圆角程度减轻、工具栏与内容的间隔被取消、默认渐变更加柔和，并重新加入了紧凑模式选项。用户可通过隐藏标志在现有稳定版中提前体验，但最终版本可能有所不同。

Firefox 重新设计将在 v157 版本中推出 - OMG! Ubuntu

Firefox 的全新“Nova”重新设计将在 Firefox 157 版本中向所有用户启用，该版本预计于 9 月底发布——当然，除非出现最后一刻的意外。

Mozilla 的工程师们一直在致力于 Nova 设计。最初的构想是圆角 UI 元素、浮动工具栏、网页内容不再与浏览器窗口边缘齐平，以及更引人注目的柔和渐变。

在过去的几个月里，这些变化经过了精炼和调整，正如你在下面的对比中看到的那样（拖动滑块进行比较）：

Firefox 155 稳定版中的 Nova 与 v157 Nightly 版中的 Nova

圆角程度被适度收敛，用于分隔和浮动工具栏与内容的“间隔”被悄然关闭，默认渐变变得更加柔和，并重新加入了紧凑模式选项，让希望减少额外内边距的用户可以自行调整。

——顺便感谢提供提示——一位用户在评论中调侃道，放弃间隔的决定意味着 Nova 现在只是一个“更圆的 Proton”加上渐变——但在 Linux 上，即使是这些渐变在默认状态下也是缺失的：

启用垂直标签时 v155 与 v157 中的 Nova 对比

Mozilla 的窗口装饰有助于以“潮流”的方式改变浏览器的美学风格。类似的圆角和渐变也用于 Android 上较新版本的 Google Material You 设计，以及 macOS 和 iOS 上 Apple 备受争议的 Liquid Glass 设计。

其他 UI 变化还包括浏览器内置艺术，使用新的 Firefox 吉祥物 Kit，以及面向用户的功能，如新标签页上的小组件——其中大部分已经就位。

3 月份的模型展示了一种主观性强的设计，但我们在 Firefox 157 中看到的是一种更为温和的呈现。

Nova 可以为窗口装饰添加渐变色调

当然，对于 Firefox 是否需要重新设计，甚至是否需要这种特定的设计，意见自然会有所不同。根据过去的趋势，这次重新设计已经迟到了：

“Australis”设计于 2014 年推出，“Photon”重新设计于 2017 年推出，而 Nova 将在 Firefox 157 中启用（计划当然可能改变）。

不想等待？你不需要等待。你可以通过 about:config 中的隐藏标志在当前稳定版 Firefox 中启用 Nova。

如果你选择提前测试，请记住，你看到的 Nova 版本与 v157 中的版本会有所不同（使用 Nightly 版本可以获得更准确的预览）。

真正的意见将在 9 月 29 日 Firefox 157 发布后形成。
