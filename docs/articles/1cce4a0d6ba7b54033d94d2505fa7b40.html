Dynamic Music Pill 新增逐词歌词高亮功能

Dynamic Music Pill 是一款 GNOME Shell 扩展，可在面板或 Dock 中显示当前播放曲目信息和歌词。其最新版本 v1.3.0 引入了两个新的歌词提供者 API，并支持基于 TTML 的逐词同步歌词，实现卡拉OK风格的逐词高亮显示。该功能可在扩展的歌词视图或面板中启用，若曲目无逐词歌词，则自动回退到逐行或静态歌词。此外，新版本还改进了音量调节方式（可选择调节媒体播放器或系统音量）、增加了音量 OSD 显示，并修复了若干小问题。该版本已可在 GitHub 下载，稍后将通过 GNOME Extensions 网站发布。

Dynamic Music Pill (GNOME Extension) 新增逐词歌词高亮功能

Dynamic Music Pill 的更新版本已发布，这是一款 GNOME Shell 扩展，可在面板或 Dock 中显示当前播放曲目信息和歌词，并带有动画效果。

如果你喜欢在桌边哼唱，Dynamic Music Pill v1.3.0 带来了两个新的歌词提供者 API，并支持解析 TTML（定时文本标记语言）以实现逐词卡拉OK风格的高亮显示。

如果正在播放的曲目具有词级同步歌词，扩展会在小程序控制器中显示它们（点击扩展内的专辑封面即可访问歌词视图）或面板中，具体取决于你的配置方式：

词级同步功能在可用时启用——大多数曲目不具备此功能。

Dynamic Music Pill 可以显示词级同步歌词高亮——无论是在 Dock 还是面板中——如果你启用“词级卡拉OK”开关。

以下视频展示了启用后的效果：

逐词歌词可以显示在胶囊本身中。

如果当前播放的曲目没有逐词歌词，扩展会愉快地回退到逐行同步或静态歌词（如果其支持的四个歌词提供者中有提供）。如果找不到歌词，则显示无内容。

这有趣吗？当然。但取决于胶囊的宽度（你可以根据需要设置固定宽度）以及歌词演唱或说唱的速度，可能很难跟上——歌词行快速闪过，没有给你太多时间记住被高亮的单词。

在 Dock 中看起来确实比在面板中更难，因为宽度更小，但高度更大意味着文本可读性更好……

不喜欢哼唱？没关系；新的 Dynamic Music Pill v1.3.0 版本还带来了一些较小的质量改进。

该扩展已经允许你通过在胶囊上滚动来调节音量，但现在你可以选择调节的对象：活动媒体播放器或系统总音量。使用此功能时，胶囊内会显示 OSD 反馈音量级别。

如果你更喜欢扁平外观，可以关闭胶囊弹出窗口中专辑艺术下方的阴影。

修复的次要错误包括：在关闭专辑艺术的情况下点击进度条时，会跳转到曲目开头而不是预期位置的问题。

Dynamic Music Pill v1.3.0 可从 GitHub 下载。

该更新将在未来一周内发布到 GNOME Extensions 网站，但尚未通过审核。如果你已经安装了该扩展，一旦准备就绪，此更新将自动到达。

如果你喜欢它的外观，就去试试吧。它适用于 GNOME 46（Ubuntu 24.04 LTS）及更高版本，但最新版本需要 GNOME 50（Ubuntu 26.04 LTS）。

在 Ubuntu 上使用 GNOME Extension Manager 可以更轻松地浏览、安装和管理 GNOME 扩展，该工具可在软件仓库中获取（sudo apt install gnome-shell-extension-manager）。

有大量设置可供筛选和尝试：可视化样式、背景颜色、紧凑模式、动画旋转封面艺术等等。

TTML（定时文本标记语言）是一种 W3C 标准的 XML 格式，专为字幕设计，因此非常适合对单个单词而非整行进行计时。

它可以在胶囊中一次只显示一个单词，至少在 Dock 模式下如此。这肯定会很迷幻，但单个单词“heartbeat”比一行文字更适合受限宽度。虽然我有点贪心，但一个轻松切换歌词显示的方法会很好。打开设置有点过时了。
