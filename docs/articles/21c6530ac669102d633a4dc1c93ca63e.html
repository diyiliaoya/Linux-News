GXVK：在现代 Vulkan 之上实现 3Dfx Glide API

开源项目 D7VK 发布 2.4 版本，意外带来 GXVK 项目：将 1990 年代的 3Dfx Glide API 通过 Vulkan 在现代系统上实现。GXVK 由 D7VK 贡献者基于 DXVK 代码分叉开发，目标是实现 3Dfx 发布的所有三种 32 位 Glide API 变体，目前以 Wine/Linux 为重点。

开源项目 D7VK 实现了 Direct3D 7/6/5/3 API 在 Vulkan API 之上的运行，以获得更快、更现代的性能，现已发布新版本。D7VK 2.4 新版本的发布有些出人意料，因为就在上个月 D7VK 才宣布其成熟状态，并大致进入维护模式。但在今天的 D7VK 2.4 公告中带来了一个更大的惊喜：现在有了一个在 Vulkan 之上实现的 3Dfx Glide API。

D7VK 的一位贡献者分叉了 DXVK 代码（D7VK 也是从 DXVK 分叉而来），并实现了对 3Dfx Glide API 的支持。Glide API 最初是为 Voodoo 显卡开发的，在 OpenGL 和 Direct3D 兴起之前，如今它为一些经典游戏提供了 Vulkan 实现。

这个 1990 年代的图形 API 遗物现在得益于 GXVK 项目，可以在现代系统上通过 Vulkan 运行。GXVK 的希望是实现 3Dfx 发布的所有三种 32 位 API 变体。开发工作以 Wine/Linux 为重点。
