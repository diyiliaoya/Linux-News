Firefox 160 发布，带来全新浮动“迷你窗口”模式

Firefox 160 正式发布，新增“迷你窗口”模式，可将标签页或网页局部内容弹出为始终置顶的浮动窗口，方便多任务时保持信息可见。画中画模式新增播放速度调节按钮，地址栏右键菜单区分“粘贴并搜索”与“粘贴并访问”。此外还支持从侧边栏拖拽历史记录到标签栏、MKV 格式支持、macOS 上 WebGL 使用 Metal API 等改进，并包含安全修复。

Firefox 160 今日发布，带来一些新功能。

新增的“迷你窗口”选项允许你将一个标签页或网页的选定部分移动到一个始终置顶的窗口中，以便在浏览时随时查看。该功能目前处于测试阶段，Mozilla 表示，该功能“在你进行多任务处理、需要同时保持多个信息来源可见时非常有用”——可以把它理解为画中画模式，但用于查看网页的局部或整个页面。

使用起来很简单。你可以右键点击标签页，将鼠标移入“移动标签页”菜单，选择“移动到迷你窗口”，即可将整个页面放入一个专用的浮动、可调整大小且紧凑的窗口中，该窗口带有自动隐藏的地址栏和导航按钮。

或者自定义工具栏并添加相应图标。在页面上按下该图标，你可以选择共享整个标签页或仅共享一部分。

你也可以通过右键 >“移动区域到迷你窗口”来对页面的一部分进行“画中画”操作。这会提示你框选出想要弹出的区域，然后执行弹出。

Firefox 160 中的次要变化

画中画模式在此次更新中也得到增强。画中画窗口现在有一个按钮可调节播放速度，范围从 0.25 倍到 2.0 倍，具体取决于源。不过，速度按钮仅在播放器窗口足够大、能够显示该按钮时才会出现。

如果你经常将文字复制到剪贴板以便搜索，Firefox 的地址栏右键菜单现在对纯文本显示“粘贴并搜索”，而“粘贴并访问”仅保留给 URL 使用。

Firefox 160 中的其他变化：

从侧边栏拖动历史记录条目到标签栏以打开它们

将页面保存为 PDF 时使 MathLab 内容对屏幕阅读器友好

阻止网站请求处理 mailto 等链接

支持 Matroska（MKV）（含 FLAC、MP3 或 PCM 音频）

macOS 上的 WebGL 内容现在使用 Metal 图形 API

智能窗口的“整理标签页”功能现已支持法语

通过实时语音转文字

美国用户现在可以在聊天机器人侧边栏中访问 Yahoo! Scout

修复改进了域名与地址栏其余部分之间的视觉对比度，解决了使用触摸输入时文本选择和光标放置的小问题，并消除了一些影响使用 NTLM 或 Kerberos 的内网网站登录的小卡顿。
