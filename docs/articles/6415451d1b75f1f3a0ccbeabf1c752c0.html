发行版发布：4Mlinux 52.0

4MLinux 发布了 52.0 版本，该版本已标记为 STABLE。新版本包含多项关键软件包更新，简化了无线网络配置，增强了对旧显卡的支持，并新增了一款游戏。用户可使用 LibreOffice、Firefox、Chrome、Thunderbird、Audacious、mpv 或 VLC 等软件进行办公、上网和娱乐。此外，还提供了 PHP、Perl、Python 和 Ruby 等编程语言，并新增了对 Ultra HDR 图像的支持。Linux 内核已升级至最新的 LTS 版本 6.18。

发行版发布：4Mlinux 52.0

4MLinux 是一个极简发行版，现已发布新版本 52.0。新版本包含多项关键软件包更新、简化的无线网络配置、对旧显卡的更好支持，以及一款新游戏。

4MLinux 52.0 系列的状态已变更为 STABLE。使用 LibreOffice 26.2.5 和 GNOME Office（AbiWord 3.0.8、GIMP 3.2.4、Gnumeric 1.12.61）编辑文档，使用 Firefox 153.0 或 Chrome 151.0 浏览互联网，并通过 Thunderbird 153.0 发送电子邮件。使用 Audacious 4.6.1 欣赏音乐收藏，使用 mpv 0.41.0 或 VLC 3.0.23 观看喜爱的视频，并畅玩由 Mesa 26.0.3 驱动的游戏。您还可以设置一个非常轻量级的 HTTP/FTP 服务器（基于 BusyBox 1.37.0）。同时提供 PHP 8.5.4、Perl 5.42.1、Python 3.14.3 和 Ruby 3.4.8。一如既往，这个新的主要版本包含一些新功能，包括简化的 Wi-Fi 配置和改进的对旧显卡的支持。Rocks'n'Diamonds（经典平台游戏）、Elvis（旧的 vi 克隆）、PDF Tricks（用于处理 PDF 图像的 Ghostscript GUI）可作为可下载扩展提供，而 ksh（KornShell）和 audioconvert（命令行实用程序）则开箱即用。还添加了对 Ultra HDR 图像的支持（通过 libultrahdr 和 ImageMagick）。最后，4MLinux 中的 Linux 内核已升级至最新的 LTS 版本，即 6.18。
