发行版发布：NawaOS 2.0

NawaOS 2.0 是基于 Debian 的 Linux 发行版，专为游戏玩家设计，预装并配置了 Steam、Lutris、Wine 和 RetroArch。此版本引入了首次启动设置向导、NawaOS 商店、Companion 2.0 远程控制、更新前快照与恢复模式、游戏存档云同步、即时回放、掌机支持、驱动管理器、防火墙和自动安全更新，以及全新的深色主题。

发行版发布：NawaOS 2.0

Ahmed Abdulla 宣布发布 NawaOS 2.0，这是该项目基于 Debian 的 Linux 发行版的新稳定版本，主要面向游戏玩家。该版本预装并配置了 Steam、Lutris、Wine 和 RetroArch。此新版本带来了快照、设置向导以及各种用户友好的游戏增强功能：

“NawaOS 2.0 是迄今为止最大的版本。设置、更新、存档和恢复现在都由系统为您处理。新增功能包括：首次启动时的设置向导，支持阿拉伯语或英语，驱动程序、应用程序，几分钟内完成；NawaOS 商店——超过 60 款游戏、启动器和工具，一键安装；Companion 2.0——将您的手机用作加密遥控器，直接通过浏览器使用，无需安装应用；每次更新前自动创建快照，并在启动菜单中提供恢复模式；每次游戏会话后，游戏存档自动同步到您自己的 Google Drive 或 Dropbox；即时回放——按 Super + R 保存最近 30 秒的游戏画面；掌机支持——在 ROG Ally、Legion Go 和 Steam Deck 上提供控制台模式、TDP 控制和可用的指南按钮；驱动管理器——一键为您的显卡安装正确的 NVIDIA 驱动；默认开启防火墙并自动进行安全更新；整个系统重新设计的深色主题，并附带新的壁纸合集。”

该消息发布在项目的 GitHub 页面上，更多信息可在发行版的 NawaOS-Gaming-2.0.iso 页面获取。

发行版发布：NawaOS 2.0

NawaOS 是一个基于 Debian 的 Linux 发行版，专为游戏玩家设计，预装并配置了 Steam、Lutris、Wine 和 RetroArch。它还支持 Xbox、PlayStation 和其他控制器。该发行版具有定制化的 Cinnamon 桌面、Calamares 系统安装程序，以及用于流式传输游戏画面的 OBS Studio。NawaOS 适合没有 Linux 使用经验的用户。
