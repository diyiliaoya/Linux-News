高通发布Kuno SoC支持Linux补丁：2026年Cortex-A7平台

2026年8月9日，美国东部时间上午11:35。

高通工程师今日向Linux内核提交了一组共15个补丁，以启用高通Kuno SoC及其参考开发平台的支持。

我未能通过搜索找到关于高通Kuno的官方信息，搜索结果仅指向这些高通Linux补丁本身。但在过于兴奋之前，需要说明的是，高通Kuno是一款32位Cortex-A7平台，在2026年甚至过去十年中，其性能都难以令人兴奋。

该补丁系列总结如下：

“本系列添加了对高通Kuno SoC及Kuno IDP参考板的初始支持。

Kuno是高通的一款32位ARM（Cortex-A7）平台。本系列引入了启动到串行控制台所需的基本SoC基础设施：

- 全局时钟控制器（GCC）和RPMh时钟控制器

- 互连（NoC）提供程序

- TLMM引脚控制器

- PDC中断控制器和SCM固件接口

- SoC和Kuno IDP板的设备树”

这些补丁使Kuno SoC的基本启用工作得以完成，考虑到Cortex-A7在此阶段的成熟度，工作量并不算大。此外，还包括了高通集成开发平台（IDP）参考板的设备树。
