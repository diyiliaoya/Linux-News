openEuler 是由开放原子基金会运营的开源项目。它是一个数字基础设施发行版，可适应各种服务器、云计算、边缘计算和嵌入式部署。openEuler 兼容多种 CPU 架构（包括 x86_64 服务器、云环境、ARM 驱动的嵌入式设备和 RISC-V 板卡），适用于广泛的环境。该项目每两年发布一个长期支持（LTS）版本，为企业用户提供稳定的平台。每六个月发布一个新的 openEuler 临时版本，以提供更新的技术。虽然 openEuler 专注于服务器部署，但也提供桌面环境（包括 UKUI、Deepin、GNOME 和 Xfce）。
