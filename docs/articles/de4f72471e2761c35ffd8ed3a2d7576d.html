Nouveau 为 HDMI 2.1 DSC 做准备，AMD HDMI FreeSync 修复将进入 Linux 7.4

上周提交给 DRM-Next 的 DRM-Misc-Next 变更集包含了针对即将到来的 Linux 7.4 内核周期的 HDMI 2.1 相关工作，涉及 AMDGPU 内核驱动和 Nouveau 开源 NVIDIA 驱动。Nouveau 方面，为 Blackwell GPU 支持 2.147 GHz 像素时钟，为 HDMI 2.1 DSC 做准备，并默认启用原子模式设置。AMDGPU 方面，修复了 DRM EDID 解析器对 AMD VSDB FreeSync 功能的处理，以更好地检测某些显示器制造商的 VRR 能力。

上周提交给 DRM-Next 的 DRM-Misc-Next 变更集包含了针对即将到来的 Linux 7.4 内核周期的 HDMI 2.1 相关工作，涉及 AMDGPU 内核驱动以及 Nouveau 开源 NVIDIA 驱动。

作为上周 DRM-Misc-Next 拉取请求的一部分提交的 Nouveau 变更包括为 Blackwell GPU 支持 2.147 GHz 像素时钟。这与 Nouveau 上最近其他与显示相关的修复一起，这些修复以纯修复的形式进入了 Linux 7.3。Nouveau 需要为 Blackwell GPU 支持 2.147 GHz 及更高的像素时钟，以为 HDMI 2.1 显示流压缩（DSC）支持做准备。目前，Nouveau 未压缩的 HDMI FRL 仅能达到约 1.78 GHz，但一旦 DSC 完全启用，将达到更高的限制。Nouveau 的 DSC 支持是否能及时为 Linux 7.4 内核周期做好准备，目前仍有待观察。

此拉取请求中另一个值得注意的变化是最终默认启用 Nouveau 的原子模式设置。很高兴看到这项工作终于完成，并赶上了其他长期默认使用原子模式设置的 Linux DRM 驱动。

DRM-Misc-Next 拉取请求还包含一些在 AMDGPU 方面值得一提的内容。有一些 DRM EDID 解析器修复，用于处理 AMD VSDB FreeSync 功能，因为一些显示器制造商仅在 AMD 供应商特定数据块（VSDB）中宣传其可变刷新率（VRR）能力。目前，通用的 Linux DRM EDID 解析器无法处理某些版本的 AMD VSDB，这将在 Linux 7.4 中得到解决，以更好地检测 VRR 能力。

关于这些针对 Linux 7.4 的最新 Linux DRM 驱动功能变更的更多详细信息，请参阅此 drm-misc-next 拉取请求。
