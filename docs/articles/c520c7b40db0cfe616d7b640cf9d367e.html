RISC-V 在 Linux 7.4 中获得出色的可移植性能优化

Linux 7.4 内核合并了 RISC-V 架构更新，其中一项关键优化是将原本在 Linux 7.3 中需编译时启用的非对齐访问优化改为运行时检测。这使得发行版和通用内核构建也能受益，在支持快速非对齐访问的 RISC-V 硬件上可跳过软件对齐，用户拷贝性能提升最高达 11%。此外还新增了崩溃热插拔支持、页表函数优化、上下文切换优化以及新的 ISA 扩展报告等功能。

RISC-V 在 Linux 7.4 中获得出色的可移植性能优化

发布于 2026 年 10 月 29 日 20:36 EDT。

RISC-V 架构的变更已于今日合并入内核，其中一项优化尤为亮眼。

在 Linux 7.3 内核中，Tenstorrent 合并了一项 RISC-V 优化：对于为原生支持快速非对齐内存拷贝的 RISC-V 硬件编译的内核，跳过软件对齐。在 Tenstorrent 进行的测试中，这带来了高达 11% 的带宽提升，效果显著：

但 Linux 7.3 内核要求该支持必须编译进内核，因此无法在混合硬件的 RISC-V 内核构建中通用，因为其中一些硬件可能不支持快速非对齐访问。

在 Linux 7.4 中，对于具有“HAVE_EFFICIENT_UNALIGNED_ACCESS”的 RISC-V 硬件，跳过软件对齐现在改为在运行时决定。这样一来，发行版的 RISC-V 内核构建和其他更通用的内核构建也能携带这项出色的优化。该优化现在可以在运行时检测到快速非对齐访问时，在用户拷贝中跳过软件对齐。

这一用户拷贝性能的改进是 Linux 7.4 中令人兴奋的变更之一，该代码已于不久前合并到 Git。Linux 7.4 中的 RISC-V 还新增了对崩溃热插拔的支持、优化了涉及某些页表函数的代码路径、优化了上下文切换、将“B”RISC-V ISA 扩展添加到 hwcap 和 hwprobe 报告中，并支持报告 RISC-V Zic64b ISA 扩展。
