Ubuntu 26.10 发布：全面拥抱 Rust 的过渡版本

Ubuntu 26.10 作为过渡版本正式发布，搭载 Linux 7.3 内核、GNOME 51 桌面环境及改进的 App Center。该版本最大亮点是核心工具全面转向 Rust 实现的 uutils，并引入 Rust 版 OpenPGP 工具 Sequoia。此外还带来 NVIDIA 615 驱动、OpenSSL 4、TPM 全盘加密改进及 RISC-V 平台支持等更新，仅提供九个月支持至 2027 年 7 月。

它搭载 Linux 7.3、GNOME 51、改进的 App Center 以及许多其他升级。

标题之所以这么说，是因为直到现在，Ubuntu 中的核心工具还没有完全 Rust 化。由于兼容性问题，它们一直停留在 GNU 版本。此后它们已迁移到基于 Rust 的 uutils 实现，使该发行版在其“氧化”进程中更进一步。

Ubuntu 26.10，代号“”，是一个过渡版本，这意味着它比之前的 LTS 带来更新的软件，但只获得九个月的支持，将于 2027 年 7 月结束。

尽管我们的功能汇总已经覆盖了，但仍有一些变化被遗漏了。😅

⭐ Ubuntu 26.10：有哪些新内容？

好吧，我们从驱动这个过渡版本的内核开始，它支持最新的 Snapdragon X2 Elite 笔记本电脑，以及来自联想、惠普和宏碁的几款较旧的 Snapdragon X Elite 和 X Plus 机器。

游戏玩家会很高兴知道，Valve 工程师 Natalie Vock 的 VRAM 超额分配工作的也已合入此内核。显存过少的显卡上的游戏应该运行得更好，因为部分数据现在可以卸载到常规系统内存中。

你已经知道这个 Linux 版本正在成为 Ubuntu 最注重性能的版本之一。

Ubuntu 还转向 NVIDIA 615 驱动系列，它取代了 595 和 610，并且仅提供开放内核模块，支持 Turing 及更新的 GPU。

我们之前谈到的 Rust 化也扩展到了 OpenPGP，由前 GnuPG 开发者构建的基于 Rust 的实现已进入主归档。其工具现在与 GnuPG 的工具并存。

对于桌面环境，它带来了一系列升级，例如面板中的指纹管理器、设置中的 DNS 搜索域，以及当你拖动多个项目时在中的计数徽章。

Ubuntu Tiling Assistant 为内置的可吸附窗口布局提供了界面。

如果你希望有重新设计的安装程序和首次启动引导流程，这些计划在下一个长期支持版本 Ubuntu 28.04 LTS 中推出。

🛠️ 其他更改与改进

以下是此版本中其他一些值得注意的更改：

OpenSSL 4 带来加密客户端问候（ECH）和更好的 QUIC 支持。

如果设置了 PIN 或密码短语，TPM 支持的全盘加密现在无需硬件信任根即可工作。

RISC-V 平台获得对 SpacemiT K3 板和 SiFive 的 BigSky 平台的官方 RVA23 支持。

在评选中选出的十二张新壁纸。

工具链升级包括 GCC 15.2.0、LLVM 22.1.8、Python 3.14.7、Rust 1.97.1、Go 1.27 和 OpenJDK 25.0.4。
