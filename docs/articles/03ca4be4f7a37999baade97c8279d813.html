mpv 4.20 新增对 DVD 与蓝光菜单、Wayland HDR 的支持

开源命令行媒体播放器 mpv 发布 0.42 版本，新增 DVD 菜单导航、蓝光 HDMV 与 BD-J 菜单支持，可直接播放 DVD/蓝光 ISO 备份。同时加入 Wayland 会话管理、不依赖 Vulkan 的色彩管理、改进的 HDR 色彩空间信号，以及基于网络的 HTTP/2、HTTP/3 后端等多项改进。

mpv 4.20 新增对 DVD 与蓝光菜单、Wayland HDR 的支持 - OMG! Ubuntu

这款开源命令行媒体播放器现已发布

mpv v0.42 现在能够导航 DVD 菜单，以及蓝光光盘使用的两种菜单系统：HDMV 和 BD-J（后者需要 Java）。

还新增了对一种提供更高分辨率音频的 niche 格式的支持。

此外，如果你有 DVD 或蓝光光盘的 .iso 备份，mpv 0.42 可以直接播放它们——无需先挂载，这很方便。

新增了基于网络的网络后端，提供 HTTP/2、HTTP/3 和连接复用。根据流媒体源和类型的不同，流媒体可能启动更快或运行更流畅。

在 Ghostty 中通过 Kitty 运行 MPV

Wayland 会话管理已接入。在兼容的合成器上，mpv 会注册其窗口，窗口可以手动命名，后续窗口如果名称相同，可以替换现有会话。

此次更新还为 Wayland 带来了色彩管理，且不依赖 Vulkan API，并改进了 Linux DRM 输出（内核的图形和显示子系统，不是数字版权管理）的 HDR 色彩空间信号。

mpv 4.20.0 中的其他显著变化包括：

支持杜比视界 Profile 7 增强层

MPEG-TS 节目和 HLS 质量变体可作为版本选择

使用微软 Fluent 图标的浮动 OSC 布局

右键上下文菜单从新的

重做的终端视频输出，用于

libmpv 的 D3D11 渲染 API 后端

AMD 帧率转换滤镜

显示同步音频漂移补偿已重写
