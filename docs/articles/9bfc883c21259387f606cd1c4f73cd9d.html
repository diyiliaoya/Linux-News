Canonical 宣布重启 Ubuntu Core Desktop 不可变桌面操作系统项目，计划在 Ubuntu 27.04 周期加速开发，初期聚焦浏览器中心设备、开发者工作站和游戏机三大用例。主要挑战包括 Snap 应用可用性、桌面模块化、权限提示及 KDE Plasma 支持。Canonical 已成立新团队恢复镜像构建流水线，预计每日镜像将随 27.04 周期推出。

Canonical 重启其不可变 Ubuntu Core 桌面项目

2026年10月28日 上午11:11 EDT。

Canonical 工程师曾在 2023 年概述了 Ubuntu Core Desktop 作为其不可变 Linux 桌面的计划。他们取得了一些良好的初步进展，但自 2024 年以来便相当沉寂。如今他们正在重启 Ubuntu Core Desktop 作为其不可变桌面操作系统产品，并对未来有着宏大计划。

Canonical 工程副总裁 Jon Seager 今天分享了加速 Ubuntu Core Desktop 开发的计划，同时承认他们 2023 年的预览版“未达到”他们的愿景。在 Ubuntu 27.04 周期中，他们将更加专注于 Ubuntu Core Desktop，并瞄准三大用例：浏览器中心设备、开发者工作站和游戏机。

向 Ubuntu Core Desktop 表达的关键挑战归结为应用程序可用性，以 Snap 形式提供的应用是其主要障碍之一。这种应用可用性也是他们最初瞄准三大用例的原因。其他关键挑战包括桌面模块化、处理权限提示，以及除 GNOME 外良好支持 KDE Plasma。

他们最近在 Canonical 成立了一个新的 Ubuntu Core Desktop 团队，以重启 2023 年的预览版，重新建立用于生产不可变镜像的流水线，并了解当前状态。预计在 Ubuntu 27.04 周期内将提供 Ubuntu Core Desktop 的每日镜像。

Seager 以以下内容结束了今天的公告：

“当前形式的 Ubuntu Desktop 不会消失。然而，这可能是我自领导 Ubuntu 以来能够宣布的最令人兴奋的事情。一段时间以来，我一直相信 Ubuntu Core 是 Ubuntu 的未来，但我们一直未能执行其中的桌面部分。

我们前路漫长，有许多技术挑战需要克服，但结果将是一个更安全、更有弹性、更值得信赖且面向未来的 Ubuntu，我相信你会喜欢使用它。

我的长期使命是让 Ubuntu Core 成为 Linux 应用程序和工作流的默认目标，以及桌面、数据中心和边缘的默认 Ubuntu 体验，而推动桌面议程将进一步促进所有这些用例。”

所有详细信息可在 Canonical 网站上完整阅读。
