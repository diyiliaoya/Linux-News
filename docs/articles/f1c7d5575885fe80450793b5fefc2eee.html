Linux Mint 就不能炫酷？Silent Horizon 说“再想想”

Silent Horizon 是一款 Linux Mint 改造脚本，通过安装自定义桌面小部件、面板小程序、壁纸、Plank 停靠栏主题等，为 Cinnamon 桌面带来暗色、现代的全新外观。其亮点包括带动态边缘光效的天气与系统监控卡片、随时间变化的地平线视图等。但该改造包对性能要求较高，在低功耗设备上可能导致 CPU 占用飙升甚至系统卡死，且配置面板存在一些混乱问题。

用 Silent Horizon 为 Linux Mint 打造戏剧性新外观

人们常说“Linux Mint 看起来过时了”，然而 Cinnamon 桌面其实高度可定制——一个新的改造包就展示了令人眼前一亮的效果。

Silent Horizon 是一个 Linux Mint 改造脚本，它安装了一套自定义桌面小部件（desklets）、面板小程序、壁纸、Plank 停靠栏主题以及一些细微的 Cinnamon 布局调整。它出自 [作者名] 之手，据其所说，它创造了一个“平静、极简的桌面，带有一些让它感觉鲜活的微小细节”。

那些“微小细节”确实增添了动感。

以天气和系统监控桌面小部件为例：这些“卡片”的边缘有一圈循环流动的光效，在你工作时不会停止——点击播放这个视频就能看到，虽然视频被加速以便更明显：

但有些炫酷效果是有代价的：性能。

一个脚本让它从这样（左）变成了这样（右）

就改造包而言，Silent Horizon 是颠覆性的。运行脚本后，Linux Mint 的默认桌面获得了戏剧性的新外观，更暗、更流畅。乍一看，很少有人能轻易看出这是 Cinnamon，因为它更像现代平铺式桌面环境。

这种设置的缺点是性能。

在低功耗设备和虚拟机上，桌面小部件运行时 CPU 使用率明显偏高。我的 Chuwi 笔记本电脑在 modest Intel m3-8100y 上运行完整版 Ubuntu 都毫无压力，但运行这个却 [原文缺失]，两次硬锁定。

性能迟缓的原因——拥有大型游戏主机的用户几乎不会注意到——是那些“桌面小部件”。天气/地平线和系统监控卡片资源消耗大，我猜测是因为沿着边框流动的实时发光效果。

目前没有选项可以关闭该效果，也不能禁用系统监控卡片（它大约每秒刷新一次统计数据，这并非没有小的性能成本）。

移除桌面小部件解决了我的性能问题——但可以说它们才是视觉上的亮点。

另一个问题——也许是“氛围编码”的接缝暴露了——是自定义桌面小部件的配置面板。它令人困惑。选择一个进行配置，另一个会消失，或者对于时钟来说，会新增一个（叠在一起，很难注意到）。

如果开发者能将系统、天气和地平线桌面小部件分开就好了。这样，如果你只想要其中一个而不需要其他的，就可以做到——并回收一些 CPU 周期用于实际应用和任务。
