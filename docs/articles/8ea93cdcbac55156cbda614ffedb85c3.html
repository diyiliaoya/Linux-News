Ubuntu 因安装程序漏洞撤下 24.04.5 下载

Canonical 因安装程序漏洞撤下了 Ubuntu 24.04.5 桌面 ISO。当用户选择扩展安装选项时，安装程序会崩溃。问题源于桌面 ISO 中残留的 TPM 全盘加密引用，导致底层 subiquity 安装程序混淆。仅影响标准 amd64 桌面镜像，其他架构和衍生版不受影响。修复预计下周初发布，用户可暂时使用 24.04.4 ISO 并后续更新。

Canonical 因一个漏洞撤下了桌面 ISO，该漏洞会在用户选择扩展安装选项时导致安装程序崩溃。

24.04 的第五个点版本于 9 月 10 日发布，带来了由新内核驱动的刷新安装介质。一些下载了该版本的用户发现，如果他们选择了扩展安装选项，就无法完成操作系统安装。

桌面 ISO 中残留的 Ubuntu TPM 支持的全盘加密引用似乎是原因所在，尽管该功能所需的组件已被移除，这些残留引用仍让底层的 subiquity 安装程序感到困惑。

只有标准的 amd64 Ubuntu 桌面镜像受到影响。其他 Ubuntu 24.04.5 镜像，包括 Arm64 和衍生版，均不受此崩溃影响。它们仍可下载。

Canonical 的 Matthieu Clemenceau 分享了这一更新，指出发布团队已“识别出问题并正在修复”。

一旦修复经过审查和测试，新的桌面镜像将立即“构建”出来。预计下周初发布，请关注发布服务器（或本文，我会在新 ISO 发布时更新提及）。

目前，任何需要安装 Ubuntu 24.04 桌面的用户可以使用 Ubuntu 24.04.4 ISO——可在发布页面获取——然后通过安装所有可用的软件更新并重启来升级到 24.04.5。

一些用户可能倾向于等待替换镜像，因为新的 24.04.5 ISO 使用 Linux 7.0 内核启动，从而对新硬件提供更好的支持。

如果你已经下载了有问题的 ISO，不要丢弃它：一旦修复后的镜像发布，你可以使用 zsync 来更新它（它只下载更改的部分），而不必再次下载完整的约 6GB ISO。
