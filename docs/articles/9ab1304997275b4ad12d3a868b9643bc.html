AMD ARG“AMD Root Guest”Linux 补丁将于 2027 年推出

2026 年 11 月 15 日 06:24 AM EST。

EPYC 9006“Venice”服务器处理器的一项新特性尚未在公开的 Linux 软件支持中实现，即 AMD Root Guest（ARG）。首批补丁预计于 2027 年第一季度发布，以进一步增强 AMD SEV-SNP 机密计算体验。

本周在加拿大温哥华举行的 KVM Forum 2026 上，有一场关于 AMD Root Guest 功能的演讲。在那场演讲之前，我未曾看到 AMD Root Guest 在其他地方被提及，尽管事后搜索显示 AMD 上周也发布了其 AMD Root Guest（ARG）技术白皮书。从时间上看，一切似乎都吻合。

AMD Root Guest 旨在帮助改善受 SEV-SNP 保护的客户机虚拟机的实时迁移体验，而无需对客户机 VM 镜像或客户机操作系统做任何更改。ARG 扩展了 SNP 能力以支持额外的平台服务。

AMD 的 David Kaplan 和 Tom Lendacky 在 KVM Forum 上介绍了 AMD Root Guest 架构。

ARG 相当于一个签名的 SEV-SNP VM，具有提升的权限和信任根，每个系统只有一个活动 ARG。

ARG 的 Linux 支持仍在进行中，实现仍处于原型阶段，尚无公开补丁。AMD 预计首批 ARG Linux 补丁将于 2027 年第一季度左右发布。之后我们将看到需要多少轮审查才能将这一 AMD Root Guest 支持纳入主线内核，以简化由 EPYC Venice 上 SEV-SNP 支持的 AMD 机密计算客户机 VM 内的实时迁移和其他功能。
