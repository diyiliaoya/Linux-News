OpenIndiana 2026.10 发布：更新工具与编译器，新增应用

OpenIndiana Hipster 2026.10 作为基于 Illumos 的操作系统的最新六个月更新现已发布。此版本为 live 镜像启用了 illumosfb X.Org 驱动以支持 UEFI 帧缓冲，并带来大量软件包更新，包括 Firefox 和 Thunderbird 159、GCC 15.3、LLVM Clang 23.1.4、Perl 5.44、Python 3.15.2，以及更新的 QEMU 和 VirtualBox、TeX Live 2026、Foliate 电子书阅读器和 zoxide 等新应用。该版本主要聚焦于更新这一社区驱动的 Solaris 生态系统中的开源软件包。

OpenIndiana Hipster 2026.10 于今日发布，这是基于 Illumos、血统可追溯至成果丰硕的 Sun OpenSolaris 时代的操作系统的最新六个月更新。

OpenIndiana 2026.10 现在为 OpenIndiana live 镜像启用了 "illumosfb" X.Org 驱动，以支持 UEFI 帧缓冲。此外还有大量软件包更新，从 Firefox 和 Thunderbird 159 到 GCC 15.3、LLVM Clang 23.1.4、Perl 5.44、Python 3.15.2 等。虚拟化支持也得到更新，包含更新的 QEMU 和 VirtualBox 版本，以及新的 TeX Live 2026、Foliate 电子书阅读器和 zoxide shell 导航工具。

总体而言，OpenIndiana 2026.10 主要是在更新这个社区驱动、基于 Solaris 的生态系统中提供的所有捆绑开源软件包。

由于我上次尝试 OpenIndiana 已有一段时间（根据 Phoronix 之前的文章，大约十年前……），我决定试用 OpenIndiana 2026.10 live。我使用的是搭载 Intel Panther Lake 的 Framework Laptop 13 Pro。它启动进入了 MATE 桌面，尽管大多数设备驱动支持缺失。外观与我多年前测试 OpenIndiana/OpenSolaris 时大致相同。
