COSMIC Epoch 1.10 发布：启动器现已采用 GPU 加速渲染

System76 发布了基于 Rust 的 COSMIC 桌面环境最新增量更新 COSMIC Epoch 1.10。此版本最显著的改进是 COSMIC 启动器默认启用 GPU（WGPU）渲染路径，解决了此前因软件渲染器导致的严重卡顿问题。此外还新增了绘图板映射到指定显示器的功能，修复了合成器多项问题，并优化了初始设置中的 WiFi 页面显示逻辑。

System76 今日发布了 COSMIC Epoch 1.10，这是这款基于 Rust 的桌面环境的最新增量更新，与其 Pop!_OS Linux 发行版同步开发。

COSMIC Epoch 1.10 的显著变化之一是 COSMIC 启动器默认使用 GPU "WGPU" 渲染代码路径。由于部分系统在使用软件渲染器时性能极差、感觉迟钝，现在默认启用了 GPU 渲染。这源于近期一则题为"Cosmic 启动器仍是有史以来最慢的启动器"的反馈：

"我在 3 台不同的机器上试过，涵盖 Intel、AMD 到 Nvidia，不知为何，一旦你在搜索框里输入任何内容，列表滚动就变得慢得无法忍受（大约 1fps）。无论你是用鼠标滚动还是用方向键遍历列表，刷新都慢得离谱。而且你输入得越多，文本输入也变得越来越慢。

这种情况从第一天起就存在。据说曾经有人在某处写过这是 iced 的问题，更新到更新的 iced 后问题就会消失——但什么都没变。

一个像 Cosmic 这样流畅、快速的桌面环境，却在最基本、最基础的 UI 组件上卡顿，这实在令人非常沮丧。"

现在，缓慢的 COSMIC 启动器应该能通过 GPU 渲染得到解决。

COSMIC Epoch 1.10 现在还允许将绘图板映射到特定显示器，对 COSMIC 合成器进行了多项修复，COSMIC 初始设置仅在存在 WiFi 适配器时才会显示其 WiFi 页面，以及大量其他修复。
