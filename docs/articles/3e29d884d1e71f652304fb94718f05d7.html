Omarchy Linux 获科技界巨头800万美元投资

Omarchy Linux 创始人 DHH 宣布投入800万美元成立非营利组织 Omacom 基金会，用于支持项目发展及依赖的开源开发者。Hyprland 成为首个受益的外部项目，其开发者 Vaxry 获得三年独家赞助，可全职投入开发。此外，Framework 等公司也参与赞助，但此前因争议引发讨论。Omarchy 最新版本 Quattro 将 AI 代理集成到桌面系统中，这一战略可能吸引了投资者的关注。

Omarchy Linux 获科技界巨头800万美元投资

一个全新的非营利组织正在筹建，将管理这笔资金，而 Hyprland 成为首个受益的外部项目。

David Heinemeier Hansson（即 DHH）已经明确了他对桌面 Linux 的认真程度，这个数字是800万美元，这笔资金将注入一个名为 Omacom 的全新非营利组织。

DHH 目前正在注册成立该基金会，旨在覆盖 Omarchy 商标、基础设施和托管、项目推广，以及为其所依赖的开源开发者提供资金支持。

这笔资金不仅是为了让 Omarchy 触达更多用户，更是为了改变人们使用计算机的方式。

DHH 本人及其他几位投资者各投入了100万美元。

DHH 表示，人们已经喜欢使用 Omarchy，他希望这笔资金能尽可能持久，而不是一次性花完，同时最大化其效用。

Hyprland 率先受益

Hyprland 是 Omarchy 之外第一个获得这笔资金的项目。Omacom 将提供独家赞助，支持 Omarchy 所依赖的 Wayland 合成器开发者 Vaxry。

根据协议，Vaxry 将锁定三年合约，并有可能延长两年。

这样，Vaxry 就可以全职投入 Hyprland 的开发，无需为资金分心。作为协议的一部分，每月5欧元的订阅服务将被取消，所有相关服务将免费提供。

DHH 还开玩笑说，要为 Vaxry 找个女朋友。

“非常感谢 37signals（你好，我自己！😂）、Butterfly 和 Framework 帮助 Hyprland 走到今天。很高兴 Omacom 基金会能从10月10日起接管，让这位 Linux 新时代最优秀的开发者之一有机会全力以赴。”

（* 该协议不包括帮助 Vaxry 找女朋友的直接协助，但我个人愿意作为任何相关询问的推荐人。）

你还记得吗？

“我们很高兴继续赞助并支持更多 Linux 生态系统项目！我们最近也加入了 LVFS（Linux 供应商固件服务），并成为其（可能是第一个？）企业赞助商。我们很快还会宣布其他几项赞助！”

— Framework (@FrameworkPuter)

这不是我们第一次讨论资金和 Hyprland 的话题。早在2025年，Framework 就成为该项目的黄金级赞助商。但这引起了许多人的不满，因为不久后，官方论坛上出现了“Framework 支持极右翼种族主义者？”的帖子。

发帖者指责 Vaxry 早前被 freedesktop.org 封禁，并要求 Framework 解释为何资助该项目。Framework 官方账号当天发布了将 Omarchy 比作旧 Windows XP 产品密钥梗的帖子，使情况更加恶化，人们将其解读为对 DHH 的认可。

尽管 Framework 确实向 Omarchy 团队发送了硬件，但项目本身从未获得直接资金支持。后来，由于人们不断询问该公司资助了谁以及为何资助，Framework 不得不开始公布其赞助明细。

Omarchy 的未来方向

Omarchy 的最新版本 Quattro 默认将 AI 代理集成到桌面系统中，而不是将其视为附加功能。虽然八位赞助者中没有人公开表示 Omarchy 的 AI 押注影响了他们支持基金会的决定。

我的看法是，这一点很难忽视，尤其是考虑到 DHH 的公司正在大力投资 AI 基础设施。一个围绕 AI 代理构建的发行版，正是销售 AI 硬件的公司愿意支持的赌注。

这一切都与 DHH 所说的“真正实现 Linux 民主化”相呼应。

这800万美元和非营利结构是否能带来“Linux 桌面之年”，则是另一个问题。

Canonical 已为一个为期三年的博士项目提供资助，该项目旨在实现 Ubuntu 重要组件的 C 到 Rust 自动翻译。
