Ubuntu Pro 用户可提前获取 AI 编写的安全修复

Canonical 为 Ubuntu Pro 用户推出名为 Edge 的可选归档，提供 AI 生成的已知安全漏洞补丁。该公司构建了多智能体系统 Surge 来为“用户空间”软件包回移修复，机器生成的补丁进入 Edge 归档，需手动启用。这些修复不会自动推送到稳定版，常规更新渠道仍严格由人工验证。Edge 归档面向希望提前获取修复的用户，Ubuntu Pro 个人用户最多可在 5 台设备上免费使用。

Ubuntu Pro 用户可提前获取 AI 编写的安全修复 - OMG! Ubuntu

Canonical 正在向 Ubuntu Pro 用户提供针对已知安全漏洞的 AI 生成补丁的早期访问权限，这些补丁可通过一个名为 Edge 的新可选归档获取。

为了更快地向客户和用户提供修复，该公司构建了一个名为 Surge 的多智能体系统，用于为“用户空间”软件包中的漏洞回移修复。

机器生成的补丁会进入 Edge 归档。这是可选加入的，默认不启用。希望在修复经过完整测试或“资格认证”之前就获得它们的 Ubuntu Pro 用户，需要在受支持的系统上手动启用 Edge 归档。

Surge 并未被用于修补内核漏洞（不过据一些人说，内核漏洞现在确实能获得更快的安全更新）。

Surge 修复不会自动推送到稳定版本，现有的 Ubuntu 安全政策——即通过正常更新渠道发布更新前进行测试和审查——将继续执行，并保持“严格由人工验证”。

其安全团队今年迄今发布的修复数量已是去年的两倍，需要应对 LLM 辅助的漏洞报告和 AI 智能体攻击的增加。

但它指出，人工工程、审查和测试可能“比一些用户和客户所能容忍的耗时更长”。新的 Edge 归档正是为那些不愿等待的人准备的。

Canonical 在公告中表示：“我们始终相信，最具韧性的软件是在开放环境中锻造出来的。”

“通过 Ubuntu Pro […] 研究人员和高级用户可以在真实环境中评估机器生成的修复，帮助我们在将其认证为可推广到 Ubuntu LTS 通用可用性时验证稳定性。”

在 Ubuntu 上启用 Edge 归档

Ubuntu Pro 在最多 5 台设备上个人使用免费，因此你不需要是企业或客户，就可以在 Ubuntu 18.04、20.04、22.04、24.04 或 26.04 LTS 上使用 Edge 归档（需承认相关注意事项）。

首先，在 Ubuntu 26.04 LTS 上通过 Ubuntu Pro 应用设置 Ubuntu Pro（较旧版本可通过该工具或使用命令行工具完成）。你需要一个 Ubuntu One 账户来完成登录。

然后，通过 CLI 启用新的 Edge 归档：

sudo apt install pro-edge && sudo pro-enable-edge

来自 Edge 归档的更新默认不会自动安装，但你可以手动选择想要的安全更新。

太麻烦？你可以通过运行以下命令接收自动更新：

sudo pro-enable-edge --automatic-updates

要禁用/退出 Ubuntu Pro Edge 更新，请通过移除该归档来禁用它。
