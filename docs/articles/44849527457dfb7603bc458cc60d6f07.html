Chrome 终于登陆 Arm64 Linux，包含 Widevine DRM

Google 正式为 Arm64 Linux 设备（包括树莓派）提供 Chrome 浏览器安装包，原生支持 Widevine DRM。此前 Google 承诺在 2026 年第二季度推出，但现已提前上线。该版本包含 Google 账户同步功能，并原生集成 Widevine 模块，但受限于软件安全 DRM，4K 和 HDR 内容仍无法播放。在树莓派 5 上测试显示，2K YouTube 播放流畅，BBC iPlayer 表现优于 Firefox Snap。

立即为 Arm64 Linux 下载 Google Chrome

你现在可以在 Arm64 Linux 设备（包括树莓派）上安装官方 Google Chrome 构建版。

Google 曾承诺在“2026 年第二季度”推出 Arm64 Linux 版 Chrome，以便单板计算机、AI 桌面以及日益增多的骁龙笔记本电脑用户能够使用这款旗舰浏览器，并享受其相比普通 Chromium 构建版所提供的额外功能。

此后，这家搜索巨头对此事并未多言，但 Chrome 的 Arm64 构建版最近已被添加到 Google 面向基于 Debian 和 RPM 的 Linux 发行版的官方 Linux 仓库中。

——感谢 Steven H 提供线索

当我前往官方页面时，在我的运行 Ubuntu 26.04 LTS 的树莓派 5 上，它提供了一个 AMD64 安装程序。这行不通。但只需快速编辑下载 URL，将相应部分替换后，就成功了：一个原生的 Arm64 版本。

Google Chrome Arm64 Deb 包通过 apt 在 Ubuntu 上顺利安装，让我在稳定频道获得了 Google Chrome v150 的构建版。

由于 Deb 包在安装过程中添加了 Google 的仓库，未来的更新将与其他更新一同正常进行。我尚未测试 RPM 版本，因此如果你在 Fedora 上一切正常，请在评论中告知我。

Chrome (arm64) 在我的树莓派 5 上运行良好

2K YouTube 播放无需硬件解码即可流畅进行

Chromium（Chrome 的开源版本）早已在 Arm64 设备上可用，众多基于 Chromium 的网页浏览器也是如此，包括……。Google Chrome 正式版的到来，可以说本身并不算什么大事——至少对长期使用 Arm 的用户而言。

更有趣的是它附带的其他功能。

Chromium 缺少 Google 账户同步功能，但 Chrome 正式版具备此功能。在我的测试中它运行正常。我登录了 Google 账户，它同步了我的扩展程序、书签、密码和设置。对于经常在不同设备间切换的用户来说，同步功能非常实用。

包含 Widevine，但问题依然存在

它还通过 Widevine 支持 DRM 播放。从历史上看，在 ChromeOS 之外的 Arm Linux 上运行 Widevine 一直依赖变通方法，即从 ChromeOS 中提取 Widevine 二进制文件，通常需要第三方脚本来解决集成问题。

chrome://media-internals 页面报告显示 Widevine 模块位于 /opt/google/chrome/WidevineCdm/_platform_specific/linux_arm64/。这表明它是一个原生构建版，而非兼容层。

Firefox (aarch64) 不具备 Chrome (aarch64) 的功能

然而，在 Linux 上，它可能仍然局限于“Software Secure”（一种基于软件的 DRM），该方案将 Linux 上的 Netflix 及其他内容限制在 720p 或 1080p，这意味着由于缺乏硬件支持的 TEE 链，无法播放 4K 或 HDR 流。这很烦人，但在 Intel/AMD 平台上也是同样的情况。

从积极方面看，由于这是一个原生 64 位模块，整体可靠性以及激活时的系统性能应该会更好。

iPlayer 在“最佳设置”下（显然在浏览器中不使用 Widevine）

总体而言，BBC iPlayer 在其最高设置下，在我的树莓派 5 上播放流畅——这与 Ubuntu 的 Arm64 版 Firefox Snap 形成对比，后者在较高码率下播放 iPlayer 的任何内容都难以流畅。

YouTube 性能更好。诚然，4K YouTube 出现了大量丢帧和卡顿，但这是树莓派硬件的瓶颈，而非 Chrome 的问题。而 1080p 甚至 2K 的 YouTube 内容则播放得极为流畅——当然，我只打开了几个标签页。

如果你拥有 Arm64 设备——这不仅限于单板计算机；它同样适用于 PineBook Pro、骁龙 X 笔记本电脑或昂贵的 Arm PC（如 System76 Thelio 和 NVIDIA DGX Spark）——请从 Chrome 网站下载：

https://dl.google.com/linux/direct/google-chrome-stable_current_arm64.deb

我找不到关于 Arm64 构建版已可投入使用（或测试——它们可能还不够稳定，不适合日常使用）的官方“公告”。官方文档目前尚未提及 Arm64 Linux 受支持。如果你尝试此版本，请保持谨慎。

不过，Google 很可能在未来几周内就这些构建版发布“官方”声明。
