发行版发布：Nitrux 7.0.0

Nitrux 7.0.0 正式发布，这是一次重大更新。该版本基于 Debian，采用不可变基础系统与 Hyprland Wayland 合成器，搭载带 CachyOS 补丁的 Linux 7.2.6 内核、Hyprland 0.55.4、NVIDIA 开源内核模块 615.71.09、KDE Frameworks 6.26.0 等。更新工具升级至 3.0.3，界面重新设计为 MauiKit 风格卡片，并优化了更新状态与进度显示。提供 NVIDIA 和 AMD/Intel 两种变体。

Uri Herrera 宣布发布 7.0.0，这是该项目基于 Debian 的 Linux 发行版的一次重大更新，其特色是采用不可变基础系统和 Hyprland Wayland 合成器：“我们很高兴地宣布 Nitrux 7.0.0 的发布。这个新版本结合了最新的软件更新、错误修复、性能改进和开箱即用的硬件支持。我们更新了发行版中的以下组件：带有 CachyOS 补丁（由 Nitrux 提供）的 Linux 内核，版本 7.2.6；Hyprland 更新至 0.55.4 版本，所有包含的 Hypr 实用程序也已更新；NVIDIA 开源内核模块更新至 615.71.09 版本；Lüv 图标主题更新至 0.8.9 版本；KDE Frameworks 更新至 6.26.0 版本；Nitrux 更新工具系统更新至 3.0.3 版本；重新设计了更新程序界面，采用 MauiKit 风格的卡片来显示系统状态、更新可用性和操作进度；优化了更新状态、进度展示和工具栏控件，并移除了多余的更新按钮；在“关于”对话框中添加了分支和提交信息，并修复了一个编译失败问题；更新了应用程序图标和桌面入口……”

阅读完整的发布公告以了解更多细节。Nitrux 7.0.0 提供 NVIDIA（cachy-nvopen）和 AMD/Intel（liquorix-mesa）两种变体；以下是下载链接：

Nitrux 是一个基于 Debian 构建的桌面 Linux 发行版，但采用不可变基础系统、OpenRC 初始化系统，并且不包含任何传统的 Debian 软件包管理工具。它使用 Calamares 系统安装程序，并包含 Hyprland 窗口管理器、Hypr 实用程序、greetd+QtGreet 登录管理器和 Waybar Wayland 栏。Nitrux 强调使用 AppBox 来管理最终用户软件，并且还支持 AppImage。
