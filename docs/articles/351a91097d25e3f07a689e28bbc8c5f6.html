Canonical 重启了基于 Snap 的不可变 Ubuntu Core Desktop 开发，目标使其成为默认桌面体验，并计划通过 LXD 容器运行经典应用、引入权限提示。同时，工程师提议为 Ubuntu LTS 引入 linux-firmware-hwe 包，将 HWE 内核的固件与 GA 内核隔离，避免新固件导致旧内核出现回归问题。两项改动均处于早期阶段。

随后为该版本推出更新的内核。Ubuntu 24.04 搭载内核 6.8 发布，其当前 HWE 内核为 7.0。

24.04 的桌面安装默认跟随 HWE，而服务器则停留在 GA，除非你选择加入。目前两个内核共享一个固件包，因此为较新内核向后移植的固件也会落到 GA 系统上，Juerg 指出供应商很少用新固件测试旧内核。
