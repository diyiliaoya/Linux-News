Canonical 每年捐赠 4 万欧元资助 Rust 软件相关工作

Canonical 的工程师于 2025 年开始“氧化”该发行版——用 Rust 替代方案替换基础软件。他们认为这样做具有安全优势，因为 Rust 在编译时就能捕获内存错误，而 C 编译器则不能。

Ubuntu 25.10 是首个附带基于 Rust 工具的版本，并默认使用基于 Rust 的 sudo。这一过程并非一帆风顺，但 Canonical 一直很用心。他们在 26.04 之前委托进行了一次安全审计，发现了导致这三个命令保留 GNU 版本的问题。Canonical 还是 Trifecta Tech Foundation 的黄金赞助商，每年提供 4 万欧元资助其 Rust 软件工作。

该非营利基金会正在进行基于 Rust 的网络时间协议（NTP）重写，Ubuntu 计划在 27.10 中将其用作默认时间同步客户端。

在这里，coreutils 迁移的完成对最终用户没有功能上的差异。基于 Rust 的版本旨在与 GNU 版本实现即插即用兼容，并将任何偏差视为 bug。这是有意为之；关键在于提升安全性。

Ubuntu 26.10“Stonking Stingray”测试版将于本月晚些时候发布，稳定版则于 2026 年 10 月 15 日发布。
