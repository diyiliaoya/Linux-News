Borealis：Asahi Linux 的 Apple Silicon Mesa Vulkan 驱动被分叉用于 Vibe Coding

Aurora Silicon 项目从 Asahi Linux 的 HoneyKrisp 驱动分叉出 Borealis Vulkan 驱动，专为 Apple GPU 设计，支持 M1 至 M5 及 A18 Pro。该驱动在自有 Mesa 分支中维护，并注册独立驱动 ID。分叉原因与允许 AI 贡献的“vibe coding”开发模式有关，其代码移除了 Mesa 的 AI 代理政策并替换为自有政策。

今天上午看到一份引入新“Borealis”驱动 ID 的 Vulkan API 驱动拉取请求时，我感到很意外，因为这是我第一次听说这个驱动。原来它是 Asahi Linux 项目为 Apple Silicon 硬件在 Mesa 中的 HoneyKrisp 驱动的分叉。

Borealis 在今天的描述中写道：“这为 Borealis 注册了 VK_DRIVER_ID_AURORA_BOREALIS (35)，Borealis 是 Aurora Silicon 为 Apple GPU 开发的开源 Vulkan 驱动。Borealis 源自 Asahi Linux 的 Honeykrisp，可在 M1 到 M5 以及 A18 Pro 上运行。它位于我们的 Mesa 分支而非上游 Mesa，现在报告自己的 driverName，因此需要自己的 ID 来与 Honeykrisp 区分。在此合并之前，它报告 VK_DRIVER_ID_MESA_HONEYKRISP。”

而 Aurora Silicon 项目在自我介绍中表示：“我们的目标是在 Apple Silicon 上提供完整且精致的 Linux 体验，从安装到日常使用。我们的工作涵盖内核、图形驱动以及让一切协同工作的工具。我们还在努力将 Windows 移植到 Apple Silicon。”Aurora Silicon 最近才起步，似乎是 Asahi Linux 代码的一个分叉。

好奇他们为何要分叉 HoneyKrisp 驱动并在 Mesa 主项目之外开发这个 Apple Silicon Vulkan 驱动，看来是出于一次 vibe coding 冒险的兴趣。到目前为止，Borealis 驱动分叉只是移除了 Mesa 的 AI 代理文档/政策，并替换为自己的 AI 代理/助手政策，该政策允许 AI 贡献。这一更改也由 Claude Opus 5.5 共同编写。

我们将看看这个 Borealis 驱动以及更广泛的 Aurora Silicon 项目在这种 AI 驱动的开发下最终会产出什么。
