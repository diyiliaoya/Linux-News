AerynOS 2026.11 发布：新增安装器选项及其他改进

AerynOS 2026.11 正式发布，引入 lichen-installer 作为新的替代安装器，目前仍保留默认安装器但已放入 ISO 便于测试。该版本还将 Fwupd 纳入仓库以方便固件更新，并新增 Budgie 桌面作为安装选项。系统包含 GNOME 51.1、KDE Plasma 6.8.2、COSMIC 1.11、Mesa 26.2.6 等更新，采用 Linux 7.2.14 内核。

AerynOS 2026.11 于今日发布，同时发布了一篇长文博客，重点介绍了这款原创 Linux 发行版近期的开发工作。

AerynOS 2026.11 现已作为最新版本提供，并引入了 lichen-installer 作为新的替代安装器。Lichen-installer 尚未取代当前的默认安装器，但现已包含在 ISO 中，以便于测试。Lichen-installer 应有助于使安装过程更加稳健。

AerynOS 也终于将 Fwupd 纳入其软件仓库，便于进行 Linux 固件更新。

AerynOS 现在为早期采用者提供 Budgie 桌面作为选项，包括作为安装时的选项。

AerynOS 近期的一些软件包更新包括 GNOME 51.1、KDE Plasma 6.8.2、COSMIC 1.11、Budgie 10.10.4、Mesa 26.2.6、QEMU 11.1.3、Wine 11.21 以及许多其他更新。AerynOS 2026.11 使用了 Linux 7.2.14 内核。
