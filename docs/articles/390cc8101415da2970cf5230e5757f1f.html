更新版Coreboot/Dasharo适用于MSI PRO Z690-A / Z790-P主板，新增超频功能

发布于2026年8月13日美国东部时间下午3:08。

3mdeb在技嘉EPYC服务器主板上提供基于Coreboot的Dasharo，基于AMD openSIL，首次为AMD Ryzen AM5平台发布Dasharo版本，适用于MSI PRO B850-P WIFI。该固件咨询公司今天发布了针对MSI PRO Z690-A和MSI PRO Z790-P的更新版Dasharo移植，适用于这些Intel Core主板。

早在2022年，他们最初推出了适用于MSI PRO Z690-A WiFi主板的Dasharo，并最终也支持了Z790-P主板。他们持续维护这些移植，并时不时推出新更新。

今天发布的Dasharo固件v1.17（适用于MSI PRO Z690-A）和Dasharo固件v0.9.5（适用于MSI PRO Z790-P）现在提供了初始SMI传输模式（STM）支持。此外，还有新的平台设置菜单，甚至实验性的CPU/超频选项。超频支持非常实验性，警告可能损坏硬件。同时，针对DDR4主板还提供了实验性的RAM电压配置支持。

更新后的开源固件还增加了EZ Debug LED支持、通过CMOS电池重置恢复默认设置、XMP配置文件与电压验证/调整，以及其他改进和修复。
