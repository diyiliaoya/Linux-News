Kwi 正在开发中：全新 KDE 终端模拟器，性能提升 3 至 35 倍

KDE 开发者 Eike Hein 宣布正在开发全新终端模拟器 Kwi，基于 Ghostty 的 libghostty-vt 库构建，支持 OpenGL/Vulkan GPU 加速。官方称其整体性能比 Konsole 快 3 至 35 倍，并符合最新 KDE HIG 标准。目前 Kwi 仍处于实验阶段，尚未发布 v0.1.0 版本，也未被提议取代 Konsole。

一款新的 KDE 终端模拟器正在开发中，作为 Konsole 的现代替代方案。Kwi 就是这款基于 Ghostty 库构建的新终端应用。

KDE 开发者 Eike Hein 今日宣布了 Kwi 的开发，这是一款快速且现代的终端，符合 KDE HIG 和 UI 规范。Kwi 采用 Ghostty 的 libghostty-vt 库以及其他成熟的 KDE Frameworks。因此，Kwi 终端通过 Qt Scene Graph 支持基于 OpenGL 或 Vulkan 的 GPU 加速。

“整体性能快 3 至 35 倍，具体取决于基准测试。例如在测试系统上运行 DOOM-fire-zig 达到 870 fps，而 Konsole 为 23 fps。”

Kwi 自称整体性能比 Konsole 快 3 至 35 倍，符合最新的 KDE HIG 标准，并且架构比 Konsole 更现代。

目前 Kwi 被视为实验性项目，尚未被提议作为 Konsole 的替代品。当前状态总结如下：

“Kwi 进展顺利，已在小范围朋友间进行了有限测试，但它也非常新，甚至还没有打上 v0.1.0 标签。因此，请大幅降低预期，并预料到明显且即时的 bug :-)。它完全无法与 Konsole 29 年持续开发工作相提并论，后者每天有数百万用户使用。”
