Mesa 26.3 发布：为 RADV 带来 VK_AMD_anti_lag 及众多 Vulkan 改进

Mesa 26.3 作为 2026 年第四季度的功能版本正式发布，为开源 OpenGL 和 Vulkan 驱动合集带来大量更新。亮点包括 RADV 支持 VK_AMD_anti_lag、改进早期 GCN 架构 GPU 支持、默认启用 Intel Jay 着色器编译器、Intel Nova Lake 图形默认启用、NVK 驱动支持 Vulkan Video、Intel 为 DXVK 启用缓冲区压缩以提升游戏性能，以及 Panfrost/PanVK 新增多款 GPU 支持等。

Mesa 26.3 于今日发布，这是该开源 OpenGL 与 Vulkan 驱动合集在 2026 年第四季度的功能版本。

Mesa 26.3 带来了许多令人兴奋的变更，例如 RADV 支持 VK_AMD_anti_lag、改进 RADV 对早期 GCN 时代 GPU 的支持、默认启用新的 Intel Jay 着色器编译器、Intel Nova Lake P 64 位 GPU 模式、Intel Nova Lake 图形默认启用（不再处于实验状态）、NVK 驱动支持 Vulkan Video、Intel 为 DXVK 启用缓冲区压缩以提升游戏性能、Intel Vulkan Video 改进、AND GFX1171 GPU 支持，以及各种其他变更。
