Ubuntu 26.04.1 LTS 发布，包含首批修复集合

2026年8月27日，晚上8:13（美国东部时间）

Canonical 今天发布了 Ubuntu 26.04.1 LTS，这是“Resolute Raccoon”长期支持系列的首个维护版本。

Ubuntu 26.04.1 LTS 包含了自 4 月 Ubuntu 26.04 LTS 发布以来收集的所有稳定版更新（SRU）中的错误修复和安全更新。这个首个维护版本不包含任何新的硬件支持（HWE）栈（如更新的内核等）——这些将在 Ubuntu 26.10 发布后随 Ubuntu 26.04.2 LTS 一起提供。

Ubuntu 26.04.1 LTS 主要旨在通过捆绑过去四个月中纳入的所有修复，提供更快速、更愉快的安装体验。有关今晚 Ubuntu 26.04.1 LTS 发布的下载和更多详细信息，请参阅邮件列表公告。
