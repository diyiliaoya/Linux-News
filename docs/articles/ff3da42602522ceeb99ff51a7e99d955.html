发行版发布：ZelixOS 2026.10.26

ZelixOS 2026.10.26 是 Arch 基础的滚动发行版，搭载 KDE Plasma 桌面，专注游戏、软件开发和高性能计算。新版本 Aurora 1.0.0 经过大量测试和打磨，优化了单色桌面、更新核心工具，提供简洁的 Arch Linux 基础。改进包括 OLED 友好的深色主题、精简启动器、90 张精选壁纸，以及统一的 GRUB、Plymouth 和 SDDM 启动登录主题。

Muhammed Yasir Peker 宣布了 ZelixOS 更新版本的可用性。ZelixOS 是一个基于 Arch 的 Linux 发行版，专注于干净简洁的桌面体验、专用的内置工具和用户自由：“经过大量测试和打磨，完整的 ZelixOS Aurora 1.0.0 版本现已发布。它完善了我们的单色桌面，更新了核心工具，并提供了干净的 Arch Linux 基础。Aurora 1.0.0 是一个完整版本，专注于开箱即用的精致桌面、功能更强大的 Zelix 工具，以及将软件选择权留给用户的轻量级基础。更平静、更一致的工作空间：单色 KDE Plasma——OLED 友好的深色样式经过重新调整，采用明亮点缀，面板和小组件之间的对比度更加一致；精简桌面——默认启动器已清理，使初始工作空间保持专注和极简；90 张精选壁纸——Zelix Extras 壁纸集合加入默认极简壁纸，可从桌面设置中选择；更新的启动和登录主题——GRUB、Plymouth 和 SDDM 从启动选择到启动过程再到登录屏幕都带有 Aurora 外观。”

请访问发行版公告页面获取新版本的详细信息和截图。

发行版发布：ZelixOS 2026.10.26

ZelixOS 是一个基于 Arch 的滚动发行版 Linux 发行版，以实时模式提供 KDE Plasma 桌面。它专注于游戏、软件开发和高性能计算。该发行版的一些关键功能包括名为“Zelix Installer”的自定义 Python/PyQt6 图形安装向导、在安装过程中选择首选桌面环境或 Wayland 合成器的能力、名为“Zelix Hello”的安装后欢迎屏幕、对 Steam 游戏平台的支持以及各种性能调整。
