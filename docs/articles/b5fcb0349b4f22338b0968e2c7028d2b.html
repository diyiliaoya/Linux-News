RISC-V Linux 内核自动向量化展现出可喜成果

在 Linux Plumbers Conference 2026 上，Andy Chiu 展示了利用 RISC-V 向量扩展对 Linux 内核构建进行自动向量化的优化效果。实验显示，LZ4 性能提升高达 15%，Btrfs 提升 8.4%，XFS 提升 5%，Nginx 提升 2%。但启用向量需管理额外上下文，增加时间和内存开销，且内核空间使用 FPU/向量可能受限，最佳性能还需按 CPU 进行编译器调优。

RISC-V 的 Linux 内核构建目前尚未利用 CPU ISA 的向量扩展，但通过编译器自动向量化来利用它，已显示出能够为提升 RISC-V Linux 性能带来良好结果。

Andy Chiu 上周在 Linux Plumbers Conference 2026 上介绍了利用 RISC-V 向量优化 Linux 内核构建。对于加密、RAID、XOR 和用户拷贝等内核用例，RISC-V 向量能力有助于提升性能。尽管内核随后会依赖向量单元，构建的可移植性会降低。真正为最佳自动向量化性能量身定制，还需要按 CPU 进行编译器目标设定。

但在所进行的实验中，RISC-V 向量优化 Linux 内核可以带来可观的收益：

LZ4 提升高达 15%，Btrfs 提升高达 8.4%，XFS 提升高达 5%，而对 RISC-V Linux 系统上 Nginx 性能的影响最终高达 2%。不利之处在于，启用向量使用需要管理额外的上下文，进而增加时间和内存需求。此外，在内核空间使用 FPU/向量可能是个禁忌。再者，要让内核构建发挥最佳性能，还需要编译器按 CPU 进行调优。
