Auto-CPUFreq 3.1 为 GUI 添加监控模式、新配置选项及修复

发布于 2026年7月26日 美国东部时间上午07:00。

Auto-CPUFreq 是一个致力于成为 Linux 系统 CPU 速度和功耗优化器的开源项目，旨在不显著影响用户体验的前提下延长电池续航。今天发布的 v3.1 是 Auto-CPUFreq 的最新功能版本。

Auto-CPUFreq 3.1 在程序的图形用户界面中新增了监控模式。该 GUI 监控模式相当基础，提供了与通过替代命令行界面使用 Auto-CPUFreq 进行监控时相似的布局：

Auto-CPUFreq 3.1 还在 GUI 中添加了蓝牙控制功能，类似于 CLI 中已有的功能，方便那些希望关闭蓝牙无线电以节省电量的用户。

此新版本还将节能模式检测扩展到了更多联想系统型号，新增了一个“强制平台配置文件”配置选项，支持缺少 /sys/class/power_supply/ sysfs 接口的系统，并进行了各种其他错误修复。
