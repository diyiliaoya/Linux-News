Ubuntu 新AI语音输入功能上手体验

Ubuntu 26.10 将引入名为 Myna 的 AI 语音输入功能，允许用户在任意文本字段中通过语音输入文字。该功能基于本地 AI 模型，完全离线运行，保护隐私。目前仍处于开发阶段，但已加入默认安装的 GNOME Shell 扩展，提供屏幕指示器。本文作者通过早期构建版本进行了测试，体验了热键激活、屏幕显示动画和文本转录过程。Myna 支持多种本地 AI 模型，可根据硬件选择最佳方案。Canonical 强调 AI 功能需提供实际价值，Myna 将作为可选功能推出。

Ubuntu 的 AI 语音转文字功能 Myna 上手体验

AI 驱动的语音输入即将登陆 Ubuntu，这是一项语音转文字功能，让你可以在任何有效的文本字段中说话输入。它仍在开发中，但我提前拿到了早期构建版本，看看它的进展如何。

随着 Ubuntu 26.10 进入冻结阶段，Myna 面向用户的部分正在逐步就位。本周，一个新的 GNOME Shell 扩展被添加到默认安装中，当 Myna 正在监听和录音时，会在屏幕上显示指示器。

如果你对这个功能的原理和原因感兴趣，我的文章会详细介绍细节（随着更多信息的出现，我已经更新了那篇简短的双人对话文章）。

这是一个 GNOME Shell 扩展。它是一个编排器，负责管理加载 AI 模型、热键激活、将麦克风音频传递给模型进行转录，然后通过 IBus 将输出反馈到文本字段。

但扩展很重要。它是你能看到的部分，让你知道 Myna 何时在积极监听和处理音频（以及是否失败）。

下面是一段快速屏幕录制，我在其中激活了 Myna，并用它把一句简单的话转录到文本字段中。

在虚拟机中测试 Myna——不要评判性能

“无论你是想免提口述文本、改善无障碍体验，还是简化工作流程，myna 都能将无缝语音识别直接带到你的 Linux 生态系统中。”

在我尝试的版本中，我通过按下（但不是按住——这与 Canonical 之前描述该功能的方式有所不同）键盘快捷键来激活 Myna，同时已聚焦到我想使用语音输入的应用程序中的文本字段。

屏幕上会出现一个显示（OSD）来指示监听已激活。当我说话时，OSD 内的动画“波浪”会振荡。这是一个很好的确认反馈，让你知道它正在工作。

完成后，再次按下相同的键盘快捷键会停止监听。OSD 动画变平，音频在后台转录。短暂停顿后，文本出现在我想要输入的应用程序的文本字段中。

Myna GNOME Shell 扩展让你知道它是否在工作

根据规格说明，如果在激活 Myna 后关闭或最小化“目标”窗口，它将停止工作。我无法让这种情况发生，不过 Myna 的 OSD 确实会在某些时候让我知道焦点丢失了。

根据规格，聚焦另一个窗口或 Alt+Tab 切换离开不会中断输入。Myna 会跟踪预期的目标——这意味着你不会把正确的内容粘贴到错误的文本字段中！

如果 Myna 没有听到任何音频，它会告诉你；它无法转录静音，唉，也无法通过心灵感应工作。

不同的 AI 模型将为 Myna 提供动力

Canonical 表示，不会有音频离开你的设备。Myna 不依赖云端模型；它完全离线运行，无论是比喻意义上还是字面意义上。任何用于转录的音频都不会被存储、记录或用于训练。

在我的测试中，Myna 使用了某种模型。但将提供多种本地 AI 模型（全部作为 snap 包），包括一些可以仅在 NVIDIA GPU 上运行的模型，一些仅支持 CPU 的模型，一些具有更广泛语言支持的模型等。

当这个功能准备好进行更广泛测试时，将使用最适合你系统硬件的本地 AI 模型。

我还没有在 Snap 商店中找到任何语音 snap 包或 myna 编排器，但我从 GitHub 上的源代码让它运行起来了。由于该功能将作为 snap 包分发……

好消息是它运行良好，相当准确，虽然有点慢（我是在虚拟机中运行 WIP 源代码，所以我不做任何定论）。输入成功出现在我尝试的大多数字段中，包括文本编辑器、GNOME Shell 概览和 Firefox。

Ubuntu 的听写功能，而非由 Ubuntu 强加的听写功能

Canonical 将对其 Ubuntu 中的 AI 功能采取审慎的方法，据其工程副总裁 Jon Seager 表示。他说，为了 AI 而使用 AI 很少奏效，Ubuntu 中的任何功能都需要为用户提供真正的价值。
