Ubuntu 将另一个系统 Deb 包转换为 Snap

Ubuntu 正在将其另一个核心系统 Deb 包转换为沙盒化的 snap 格式，以提升安全性并改善桌面集成。该包为 hwctl，是一个预装在 Ubuntu 桌面和服务器上的小型命令行工具。Canonical 工程师 Sergio Costas 表示，为了将 hwctl 与 gnome-control-center 及其他前端集成，并增强安全性，hwctl 包将仅以 snap 形式提供。在 Ubuntu 26.04 LTS 上，用户将自动迁移至 snap 版本，现有系统通过更新将 Deb 包替换为自动安装 snap 的虚拟包。Ubuntu 26.10 及更高版本将直接默认包含该 snap。

Ubuntu 正在将其另一个核心系统 Deb 包转换为沙盒化的 snap 格式，此举据称将提升安全性并实现更好的桌面集成。

涉及的包是 hwctl，这是一个预装在 Ubuntu 桌面和服务器上的小型命令行工具，属于 Canonical 的硬件 API 工具集的一部分。

Canonical 工程师 Sergio Costas 表示：“为了将 hwctl 与 gnome-control-center 及其他前端集成，并增强安全性，HWCTL 包从今往后将仅以 snap 形式提供。”

如果你使用的是 Ubuntu 26.04 LTS，你将被自动迁移至 snap 版本。Canonical 将把当前的 Deb 包转换为一个虚拟包，在标准系统更新期间自动安装 snap 版本。

然而，这一转换尚未发生，因为对于 Ubuntu LTS 版本，必须遵循必要的稳定版更新（SRU）流程。

在 Ubuntu 26.10 及更高版本中，该 snap 将成为构建 ISO 的默认种子的一部分，因此无需任何包替换技巧。

hwctl 和其他硬件 API 工具是在 Ubuntu 25.10 中添加的。这些包用于支持各种操作系统功能，包括 Ubuntu Pro 和可选的 Ubuntu Insights 系统遥测。
