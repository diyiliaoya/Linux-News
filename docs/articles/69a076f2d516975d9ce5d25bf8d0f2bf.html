发行版发布：Garuda Linux 260819

Garuda Linux 发布了新版本260819 "Temeraire"，该版本改进了磁盘扇区处理方式，安装程序在创建新磁盘布局时会选择磁盘支持的最大扇区大小，并使用LUKS2和argon2加密。同时，默认内核从linux-zen切换为linux-garuda（基于CachyOS），采用EEVDF调度器，并通过DKMS确保Nvidia驱动兼容。

发行版发布：Garuda Linux 260819

该项目已发布新版本。新版本 260819 "Temeraire" 引入了一种改进的磁盘扇区处理方式，并将默认内核切换为与 CachyOS 匹配的内核。

“在创建新的磁盘布局时，安装程序将选择磁盘支持的最大扇区大小，对于希望使用 LUKS 加密磁盘的用户，安装程序现在使用 LUKS2 和 argon2 加密，并采用与磁盘相同的扇区大小。此前，在支持更优的 4096 扇区大小的磁盘上，默认值仍为 512。新的默认内核：laptop：传统上，Garuda Linux 多年来一直使用 linux-zen，主要是因为在我们选择它作为默认内核时，它比当时的其他替代方案更稳定。从本次发布开始，这一情况将改变 - linux-garuda 是我们许多人已经使用的出色的 Linux CachyOS，确保在更新前通过 DKMS 始终针对 Nvidia 驱动进行构建。该内核版本使用 EEVDF 调度器。当然，所有功劳都归功于 CachyOS；他们在这方面做得非常出色！”

更多详细信息可在项目的发布公告中找到。
