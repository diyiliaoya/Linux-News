OpenZFS 2.4.4 发布，支持 Linux 7.2，包含数十项修复

2026年8月21日，美国东部时间晚上8:40。

OpenZFS 2.4.4 今日发布，这是面向 Linux 和 FreeBSD 系统的 ZFS 文件系统实现的最新稳定点版本。

OpenZFS 2.4.4 版本最重要的变化是现已支持最新的稳定内核版本。所有必要的更改均已到位，使得树外 OpenZFS 文件系统能够与上游 Linux 7.2 内核状态良好兼容。同时保持了对 Linux 4.18 及更早版本的回溯兼容性，当然也支持 FreeBSD 13.3 及以上版本。

OpenZFS 2.4.4 还带来了数十项错误修复，包括更新的测试用例、各种安全策略改进、使 systemd-udev-settle 在导入单元中变为可选、各种其他 Linux 内核兼容性修复，以及广泛的其他修复。
