发行版发布：Mainstream OS 1.3.0

Mainstream OS 1.3.0 发布，这是一款基于 Arch 的易用 Linux 发行版，采用 Hyprland 合成器上的 Quickshell 工具包定制桌面。新版本改进了桌面界面，支持将 Dock 放置在屏幕任意边缘，主题可记忆 Dock 位置，优化了弹出窗口、媒体组件、计时器、分隔线等细节，并修复了窗口规则编辑器的问题。该发行版提供 Material You 桌面布局、工作区布局切换、会话恢复、游戏模式及图形化设置工具，使用 Calamares 安装器，并在每次更新前自动创建 Btrfs 快照。

发行版发布：Mainstream OS 1.3.0

Mainstream OS 是一款基于 Arch 的易用 Linux 发行版，其高度定制的桌面使用 Hyprland 合成器之上的 Quickshell 工具包。该发行版已更新至 1.3.0 版本。项目提供了关于最新一轮桌面界面改进和错误修复的详细信息：

“将 Dock 放置在屏幕的任意边缘：顶部、底部、左侧或右侧；当您将 Dock 放置在某个边缘时，任务栏会主动让位；主题现在会记住 Dock 所在的边缘，以及它们记住的其他所有设置；灵活空间组件已退役——任务栏现在自行管理其各个部分，而您已保存的布局会自动迁移；任务栏弹出窗口会在其所属组件下方居中打开，无论您将其放置在何处；靠近屏幕边缘的弹出窗口会保持在屏幕内，而不会超出屏幕；媒体组件在中心区域之外保持其大小和弹出窗口位置正确；计时器在倒计时时保持稳定的宽度，而不会挤压相邻组件；分隔线保持在任务栏圆角背景内部；您可以从窗口规则编辑器的角落关闭它，并在不关闭编辑器的情况下切换规则……”
