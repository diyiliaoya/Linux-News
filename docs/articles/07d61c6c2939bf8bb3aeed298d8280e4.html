发行版发布：Equestria OS 2026.10.28

Equestria OS 2026.10.28 发布，这是一个基于 Arch Linux、面向初学者的发行版，采用 KDE Plasma 桌面。新版本新增了 GPU 管理器、时钟、日历、笔记、计算器、屏幕录制器、取色器、音视频转换器、窗口关闭器等自定义图形工具，均支持 10 种语言并跟随角色主题。面板时钟、昼夜主题、角色主题和光标主题也得到增强。

发行版发布：Equestria OS 2026.10.28（DistroWatch.com 新闻）

Lucia Lunadottir 宣布发布 Equestria OS 的新版本，这是一个面向初学者、基于 Arch 的 Linux 发行版，首选桌面环境为 KDE Plasma。Equestria 的主要特色是一系列自定义图形工具，让计算机管理变得轻松。新版本标记为 2026.10.28，增加了几个新工具：

“本次发布有哪些新内容？新的 Equestria 应用（均提供 10 种语言，均遵循你的角色主题）：GPU 管理器——显示你的显卡并推荐和安装正确的驱动；时钟——闹钟、计时器和秒表，可从系统托盘持续运行；日历——月相、带重复的提醒、月/周/年视图；笔记——带图片和待办复选框的笔记；计算器；屏幕录制器；取色器；音视频转换器——17 种音频格式、修剪、淡入淡出、速度、音量、标签、WebM/MKV；Closer——关闭冻结的窗口；时钟和日历现在打开已有窗口，而不是启动第二个副本。面板和外观：新的面板时钟——带周数的日历、Equestria 日历事件、其他时区；昼夜主题——KDE 自动在浅色和深色之间切换；角色主题现在应用于每个 Equestria 应用，每个角色都有新的调色板；整个系统使用一个光标主题，原生 Plasma 锁屏和注销屏幕。”

以上内容发布在该项目的 GitHub 页面上。

Equestria OS 是一个面向初学者的 Linux 发行版，基于 Arch Linux，采用 KDE Plasma 桌面。其主要特色是内置了 20 多个独特的图形工具，让计算机管理变得轻松，基本无需使用终端模拟器。该发行版集成了 Proton 引擎，这是 Steam 客户端兼容工具，可让仅限 Windows 的游戏在 Linux 上安全、隔离地运行。
