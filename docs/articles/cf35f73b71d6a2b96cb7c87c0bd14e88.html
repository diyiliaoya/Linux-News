发行版发布：CachyOS 260809

CachyOS 发布了 260809 版本，该版本对系统安装程序、欢迎窗口和手持设备检测进行了改进。欢迎窗口的 DNS 功能得到重构，服务器排名现在能正确选择最快的 DNS 服务器。chwd 改进了手持设备检测，并添加了保加利亚语本地化。内核管理器后端从 C++ 重写为 Rust，并集成到 chwd-kernel 中。Cachy-Update 基于 Arch-Update v4.x 重写，系统托盘应用改用 Rust 编写，并新增了自动更新检查选项。默认的 GUI 包管理器 Shelly 从 C# 重写为 Zig，降低了内存使用并加快了启动速度。

发行版发布：CachyOS 260809

该项目已发布新快照。该发行版的八月版本对系统安装程序、欢迎窗口和手持设备检测进行了改进。

“CachyOS 欢迎窗口进行了 DNS 重构，因此基于速度测试的服务器排名现在能正确选择最快的 DNS 服务器。在 chwd 中，通过特定的主板名称匹配改进了手持设备检测，并添加了保加利亚语本地化。内核管理器后端从 C++ 重写为 Rust，并直接集成到 chwd-kernel 中。Cachy-Update 已基于 Arch-Update v4.x 重新构建，其系统托盘小程序用 Rust 重写。新增的 --check --enable 选项可一键开启自动更新检查并启动系统托盘，托盘现在通过 TrayUpdatesPerPage 支持可配置分页，默认检查间隔提高到 6 小时。Shelly，我们默认的 GUI 包管理器，已从 C# 重写为 Zig，作为其重大版本发布，放弃了托管运行时，改用原生二进制，内存使用更低，启动更快。桌面应用新增了首次运行欢迎界面、列表和网格软件包浏览、AUR PKGBUILD 预览及构建输出，以及用于数据库同步、缓存清理和孤立包删除的实用工具页面。”

更多详细信息可在 cachyos-desktop-linux-260809.iso 中找到。
