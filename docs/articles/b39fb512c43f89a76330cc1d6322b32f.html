Ubuntu 26.04.1 LTS 现已开放下载

Ubuntu 26.04.1 LTS 已发布，这是 Ubuntu 26.04 LTS 系列五个点版本中的第一个。该版本不包含新功能，但提供了更新的安装镜像，集成了自 4 月发布以来的所有错误修复、安全补丁和软件包更新。新镜像适用于多种版本和官方衍生版。现有用户无需重新安装，只需定期更新即可。此外，从 Ubuntu 24.04 LTS 直接升级到 26.04 LTS 的通道即将开启，用户可通过图形界面进行升级。

Ubuntu 26.04.1 LTS 已发布，现有用户无需重新安装。

Ubuntu 26.04.1 LTS 现已开放下载，这是计划中的 5 个点版本中的第一个。

该版本不添加新功能，但提供了更新的安装镜像（.iso），其中包含了自 4 月 Ubuntu 26.04 LTS 发布以来所有错误修复、安全补丁和软件包更新。

由于没有更新的 Ubuntu 版本可供反向移植内核和图形驱动集，因此未包含新的硬件支持栈。明年的 Ubuntu 26.04.2 LTS 将带来 Ubuntu 26.10 中的 Linux 内核和 GPU 驱动。

新镜像也适用于各种版本（Raspberry Pi、Arm64、RISC-V）以及参与 4 月 LTS 发布的 Ubuntu 官方衍生版。

Ubuntu 26.04 LTS 于 4 月 23 日发布，搭载 GNOME 50，并新增了两个默认应用。Snap 商店和网页搜索可在 GNOME Shell 概览中使用，您还可以启用 Ubuntu Pro。此外，还有新的文件夹图标、命令的可视化密码反馈，以及更简便的 NVIDIA CUDA 和 AMD ROCm 安装（现已包含在软件源中）。

这是为新用户准备的，而非现有用户。

如果您已经在使用 Ubuntu 26.04 LTS，则无需下载或重新安装任何内容。.1 版本中包含的所有内容都已经在您的系统上（前提是您及时安装了更新）。实际上，如果您前往设置，应该会看到更新后的版本号。

点版本的意义在于定期刷新安装介质，这样可以减少安装后需要下载和应用的更新数量，节省用户的时间和精力，对 Canonical 来说也节省了带宽。

从 Ubuntu 24.04 LTS 升级已启用

从 24.04 直接升级到 26.04 即将上线

Ubuntu LTS 系列中的第一个点版本还因另一个原因而引人注目：这是从上一个 LTS 版本升级的通道开启之时（尽管并不总是与 ISO 发布同日，请耐心等待）。

Ubuntu 24.04 LTS 用户可以通过图形界面直接升级到 Ubuntu 26.04 LTS，无需命令行变通方法。官方提示会出现，但需在运行更新检查后才会显示。

不必急于升级。Ubuntu 24.04 LTS 支持至 2029 年，包含标准更新，之后通过启用 Ubuntu Pro 还可获得额外 5 年的关键修复。

Canonical 最初会延迟长期支持版本之间的升级。由于从 24.10、25.04 和 25.10 以及 26.04 中积累了两年的变更，升级过程需要经过大量测试以确保可靠过渡。

如果您确实从 Ubuntu 24.04 LTS 升级，会有很多新内容——我的文章列出了 26 项值得关注的变更，包括改进的 APT、基于 Rust 的 coreutils、总共 7 个新的默认应用、通知分组、锁屏媒体控制等。

通过官方 Ubuntu 网站或 cdimage 服务器下载 Ubuntu 26.04.1 LTS。
