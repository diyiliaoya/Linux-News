NextCloud 推出面向桌面用户的办公套件

Nextcloud 发布了基于 Euro-Office 的开源桌面办公套件，支持离线编辑本地文件，并可连接 Nextcloud 实现协同编辑，覆盖 Linux、Windows 和 macOS。该套件包含文本、表格、演示和 PDF 四个编辑器，支持 Microsoft Office 和 OpenDocument 格式。Nextcloud 提供签名分发的 APT/DNF 包，适合生产环境，而 Euro-Office 社区版未签名，仅建议测试使用。

NextCloud 推出面向桌面用户的办公套件

由 Euro-Office 提供支持，该应用可离线处理本地文件，并连接 Nextcloud 在 Linux、Windows 和 macOS 上进行协同编辑。

Nextcloud 的办公编辑器早已能在浏览器中使用，而截至目前，又推出了一款开源桌面应用，应该会吸引更广泛、偏好本地处理文档的用户群体。

该应用基于 Euro-Office 的 DesktopEditors 代码，你可能还记得，Euro-Office 是一个欧洲公司联盟，其首要目标是提供开放且自主的文档编辑，首个生产就绪版本已于六月发布。此外，该代码是 ONLYOFFICE 的修改版本，后者背后也有自己的故事。

现在，让我们看看 Nextcloud 的应用提供了什么。

Euro-Office，但有所不同

Nextcloud Office 与 Euro-Office 构建的桌面编辑器并非完全不同的应用。它是 Nextcloud 对同一源代码的签名分发版本，但更面向生产使用。

Nextcloud 托管了签名的 APT 和 DNF 仓库。添加后，应用会随系统其余部分一起更新。

这些包经过签名，意味着它们经过完整性验证，适合受管设备批量部署。

Euro-Office 社区构建来自同一源代码，但未签名，项目宣传其用于测试和贡献。它们仅以 GitHub 发布形式提供，没有包仓库。

项目建议不要在受监管环境或受管设备批量部署中使用它们，那里的 Nextcloud 集成也仅以尽力而为的方式提供。

另一方面，Nextcloud Office 会针对 Nextcloud 版本进行集成测试和额外测试。

支持方式也类似。Nextcloud Office 有专门的企业订阅，提供社区和专属支持，而社区构建仅获得社区支持。
