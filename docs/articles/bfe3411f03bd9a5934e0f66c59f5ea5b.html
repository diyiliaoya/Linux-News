Firefox 154 发布，带来翻译、AI 与界面调整

Mozilla 发布了 Firefox 154，这是浏览器在 9 月初切换到每两周一次发布周期前的最后一次月度更新。本次更新引入了 AI 控制快捷方式、改进的整页翻译功能（支持 iframe 内容）、更快的视频定位速度，并移除了工具栏上的 Firefox View 图标。此外，还包含 PDF 文本选择颜色修复、垂直标签栏全屏隐藏、macOS 配置文件备份支持、本地网络访问保护扩展至 WebSocket 连接等多项改进。

Mozilla 发布了 Firefox 154，带来了一些与 AI 相关的小改动、改进的整页翻译功能，以及“在所有操作系统上”更快的视频定位速度。

Firefox 154 是浏览器在 9 月初切换到更快的每两周一次发布周期之前的最后一次月度发布。这意味着几周后你就能看到“Firefox 155 发布”的消息，而不是通常的四周。

但先别管即将到来的，看看现在有什么新功能？

Firefox 154 的主要变化

Firefox 在最近的版本中不断扩展地址栏操作。我们在 v152 中获得了标签页静音操作，在 v153 中获得了颜色选择器。Firefox 154 新增了浏览器 AI 控件的快速链接。在地址栏输入“Manage AI”即可看到“设置 > AI 控件”的快捷操作。

Firefox 154 中的“管理 AI 控件”快速操作

在 AI 功能方面，如果你可以使用 Firefox 的 AI 驱动浏览模式，你将获得基于大语言模型的标签页分组功能。与经典模式中使用本地模型进行匹配的“智能标签页分组”不同，该模式使用云端大语言模型来分析你的标签页，将相关的标签页分组并建议一个合适的名称。

使用整页翻译功能时，现在可以翻译 <iframe> 内容。它还会在所有页面加载时运行语言检测，Mozilla 表示这将“为用户提供更好的翻译体验”。

你用过 Firefox View 吗？如果没有，现在更难找到它了。Firefox 154 在新配置文件和一段时间未使用该功能的配置文件中，从工具栏移除了 View 图标。用户可以手动将其添加回来，或者通过“列出所有标签页 > 查看所有标签页”获得相同的功能。

Firefox 154 的其他变化

在 PDF 中选择文本（在 Firefox 内置的 PDF 查看器和编辑器中）现在使用正确的文本选择高亮颜色，并遵循浏览器检测到的操作系统高对比度设置（当然，这些设置可能因 Linux 桌面环境而异）。

在 Windows 和 Linux 上，垂直标签栏现在会在 Firefox 进入全屏时正确隐藏，同时主浏览器工具栏也会隐藏。将光标移到屏幕顶部即可恢复所有内容。

Firefox 配置文件备份现在可在 macOS 上使用。备份可以在所有三个平台上恢复，例如，可以从 Linux 备份导入到 Windows 等。

如果你排除了某些网站在关闭时清除其 cookie 和站点数据，现在可以设置这些网站而不将其排除在跟踪保护和其他 cookie 限制之外。

本地网络访问保护现在包括 WebSocket 连接。

（德国、法国、奥地利、瑞士、荷兰）现在会清除/更新缓存的网站图标。

JSON 查看器为所选条目增加了面包屑路径。

最后，Windows 上的 Firefox 用户可以在设置中选择不同的浏览器应用图标。但是，他们必须完成一些步骤，例如将 Firefox 设为默认浏览器，才能“解锁”额外的图标。Mozilla 表示，可自定义的应用图标“很快”会登陆 Linux 和 macOS。

“显著更快”的视频定位——还是不是？

回到开头提到的视频定位修复。Firefox 154.0 发布说明称：“视频定位在所有操作系统上现在显著更快”，使得在浏览器中跳转到流媒体视频的特定部分更加容易。

但该功能引用的错误报告特别针对 macOS 上启用硬件解码时的视频定位修复。此前，解码器在定位期间会闲置帧，并为即将丢弃的帧生成帧图像。根据 Mozilla 的测试，定位延迟从约 260 毫秒降至约 30 毫秒。这使其在相同硬件上的测试中与 Google Chrome 相当。

那么为什么提到“在所有操作系统上”呢？

也许是因为 Firefox 有一系列“视频解码和定位性能”修复。并非所有修复都已落地，但有一些已经落地，它们解决了在 Firefox 中播放视频或音频内容、通过蓝牙音频设备输出并触发定位操作时出现的音频丢失和同步问题。
