ChatGPT 桌面应用现已推出 Linux 版本（预览版）

OpenAI 正式发布了 ChatGPT 桌面应用的 Linux 预览版，支持 Ubuntu、Debian 和 Fedora。该应用集成了 ChatGPT、ChatGPT Work、Codex 及内置浏览器，可在本地仓库运行 Codex、控制其他应用并访问本地文件。OpenAI 表示 Linux 是用户最常请求的平台之一，此次发布后，ChatGPT 桌面应用已覆盖所有主流操作系统。目前为公开预览版，可能存在缺陷，不建议用于关键任务。

ChatGPT 桌面应用现已推出 Linux 版本（预览版） - OMG! Ubuntu

官方 ChatGPT 桌面应用的 Linux 预览版已发布。

与在浏览器标签页中使用 ChatGPT 相比，这款 GUI 桌面应用可以在你的本地仓库中运行 Codex，通过扩展连接并控制其他应用，处理 ChatGPT 工作相关任务，并探查你的本地文件，而无需将内容上传到其他地方。

OpenAI 在一封电子邮件中表示，“Linux 一直是其桌面应用最常被请求的平台之一”，而随着此次发布，该应用终于覆盖了所有主要操作系统。

这款新的“超级应用”功能强大

ChatGPT 桌面应用 Linux 版加入了 Anthropic 的 Claude 桌面应用 Linux 版（后者于上个月进入测试阶段）。

你之前肯定见过大量非官方的 ChatGPT 包装器，而且通过 Codex CLI 已经可以访问命令行。

此次发布的是 OpenAI 官方版本的（某种程度上）全新“超级应用”，它结合了 ChatGPT、ChatGPT Work、Codex，甚至还内置了网页浏览器。

下载适用于 Linux 的 ChatGPT

可从所有主流网页浏览器获取（只要它们还存在）

你可以下载适用于 Ubuntu 的 ChatGPT Linux 应用，提供 64 位 Intel/AMD 或 Arm64 的 .deb 安装包。OpenAI 表示，该应用已在 Ubuntu 24.04 LTS 和 Ubuntu 26.04 LTS 以及 Debian 13 上测试通过。Fedora 用户可使用 RPM 构建版本。

安装 .deb 包后，系统会添加 OpenAI 的软件源。未来的更新将通过 apt 与其他软件更新一起安装。

显然，ChatGPT 是闭源软件，虽然免费下载和使用（需要免费 OpenAI 账户），但某些功能需要付费套餐才能访问。

另外请注意，这目前是公开预览版。可能存在缺陷，功能集成可能无法可靠运行，因此不要将其用于任何关键任务。
