ReactOS 从 Wine 引入重大 DirectX 栈更新，支持更多游戏

2026 年 9 月 24 日 下午 05:43 EDT。

致力于提供与 Microsoft Windows 应用程序/游戏以及驱动程序二进制兼容性的开源 ReactOS 项目，今天迈出了一大步，从 Wine 项目引入的代码对其 DirectX 栈进行了重大更新。

一项艰巨的任务已经完成，将 Wine 10.0 状态的 DirectX 栈改进并引入 ReactOS。ReactOS 开发者 Justin Miller 为此投入了数百小时的工作。它还移除了 ReactOS 中许多先前的 DirectX 补丁。

现已合并的代码包含 49.8 万行新代码，并移除了 11.9 万行旧代码。这些新代码允许 ReactOS 使用 OpenGL 和 Vulkan 来转译 DirectX，同时也提升了 ReactOS 的 DirectX 栈在 Windows 本身上运行的能力。

据称此次更新有助于数百款游戏。Miller 在评论中表示：

“这真是来之不易，到目前为止已经耗费了我至少 230 多个小时。（而且还没完成，哇哦！）

这个 PR 的目标是将我们的 DirectX 栈更新到 WINE-10.0，同时移除我们大量的补丁。

这使得 ReactOS 能够使用 Vulkan 和 OpenGL 来转译 DirectX（尽管 Vulkan 仅能通过自定义分支或 mesa 软件渲染器实现），它也提升了我们的 DirectX 栈在 Windows 本身上运行的能力。

修复了一些测试，以及更多内容。

这个 PR 与其他已打开的 PR 结合后所解锁的游戏数量在数百款。

但即使仅针对 NT5.x，这也让诸如《龙腾世纪：起源》这样的游戏终于能够启动。”

ReactOS 开发者评论道，很快在 ReactOS 上实现 DirectX 10 / 11 / 12 游戏兼容性将成为可能。

激动人心的时刻仍在继续。
