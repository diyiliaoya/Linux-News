Servo 实现 CSS Grid 支持，Threadboost 带来大幅提速

Servo 项目发布八月状态报告，基于 Rust 的浏览器引擎取得多项进展。最显著的是 CSS Grid 支持落地，使更多网站能正确渲染；同时新增 CSS color-scheme、animation-composition 等特性及多个 DOM API。JavaScript 方面升级至 SpiderMonkey 153，并引入可选的磁盘 HTTP 缓存。性能上，实验性 Threadboost 功能将 Speedometer 基准分数提升 50%。

Servo 的八月状态报告终于发布，概述了这款基于 Rust 的开源浏览器引擎所取得的进展。此前不久，Servo 0.6 软件刚刚发布，其中包括 Servoshell 演示浏览器。

Servo 近期最引人注目的功能之一是 CSS Grid 支持。因此，现在有更多网站能在 Servo 上正确渲染。

Servo 还加入了其他新特性，如 CSS color-scheme、animation-composition、full-width、text-transform 等。多个新的 DOM API 也已就位。

在 JavaScript 方面，Servo 引入了 SpiderMonkey 153，以修复安全和崩溃问题。Servo 现在还提供了一个可选的磁盘后端 HTTP 缓存，但目前尚无清除该缓存的方法。

Servo 在无障碍方面也有更多工作正在进行，并为 AudioWorklet 做前期准备等。该引擎的性能改进也在持续落地。一项名为“Threadboost”的实验性功能将 Speedometer 基准测试分数提升了 50%。
