GNOME 51 发布，支持通行密钥登录并带来更流畅的用户体验

GNOME 51 正式发布，新增 FIDO2 通行密钥登录、截图区域键盘调整、显示器亮度记忆等功能。Mutter 合成器优化了帧调度和屏幕录制性能，使动画和滚动更流畅。核心应用也获得改进，如地图支持离线下载和实时公交数据、文档可添加手写签名等。Ubuntu 26.10 将于 10 月 15 日搭载该版本发布。

GNOME 51 发布，带来 FIDO2 通行密钥登录、一个选项以及帧调度变更，使 UI 动画和滚动感觉更流畅。

核心应用也有所改进。桌面地图应用获得离线区域下载和实时公交数据，文档现在允许你添加视觉签名，文件则加快了大文件夹的加载速度。

尽管这是一个比我们习惯的更为温和的版本——一些计划中的变更，比如文档的 GTK4 移植和用于改变触摸板滚动速度的滑块，并未纳入——但仍有很多值得期待的内容。

Ubuntu 26.10 将于 10 月 15 日发布，搭载 GNOME 51，并在其之上加入自己的定制。新的 GNOME 版本不会被回溯移植，因此 Ubuntu 26.04 LTS 在其支持期内将保持在 GNOME 50。

GNOME 51：新功能

Mutter 让帧更流畅

Mutter 是驱动 GNOME Shell 的合成器，其最新版本又进行了一系列后端变更，以优化内容在屏幕上的“绘制”方式。

本周期的变更之一是对帧时钟估算渲染时间的方式进行了调整，这有助于减少在旧有固定估算过于严格或过于宽松的系统上出现丢帧的可能性，具体取决于硬件。

Mutter 51 还改进了屏幕录制和远程桌面会话，减少了抓取过程中在后台进行的不必要工作。降低总体开销（无论硬件还是软件渲染）意味着最终结果更流畅。

那 GNOME 获得毛玻璃模糊效果呢？许多 Linux 博客大肆宣传，但这并不是面向用户的变更——至少现在还不是。Mutter 已获得对 Wayland 背景模糊效果协议的支持，但应用和表面必须主动请求——默认情况下没有应用这样做。

GNOME Shell 默认没有背景模糊，所以不要去寻找开关，因为你找不到。

使用键盘调整截图区域大小

方向键调整区域大小

GNOME Shell 的交互式截图工具现在支持键盘调整。

使用键盘的方向键，你可以扩大、缩小或移动选择区域，无需使用鼠标。

按一个方向键选择一条边，然后继续按击以使选定区域变大或变小。按住某个修饰键同时按方向键可以更大或更精细的增量移动，按住另一个修饰键同时按方向键可以移动整个选择区域。

按某个键可以完全重置选择区域。与早期版本一样，当截图功能打开时，你可以按某个键进行抓拍——在这个版本中，不再使用相机快门音效，因为 Adwaita 现在有了自己的原生声音集。

Web 和 FIDO2/通行密钥登录支持

更多登录和解锁方式（为需要的人）

GNOME 显示管理器（GDM）改进了对认证机制的支持，包括智能卡和基于 Web 的登录，在登录和锁屏界面上。这些主要对拥有企业或远程设置的用户有用，而非家庭用户。

智能卡登录并不新鲜，但 GDM 的统一认证框架增加了 Web 登录（二维码和 URL）以及 FIDO2/通行密钥支持。这项工作全部设计为可扩展的，以便将来可以轻松添加其他认证方法。

GNOME Shell 保存显示器亮度

GNOME Shell 现在为每个显示器保存亮度级别以及任何色彩模式设置（例如 HDR），并在重启时恢复。

以前，内核 sysfs 背光接口被假定会记住它，但缺陷在于……亮度可能因省电模式（即调光）而改变。“调暗”的值会在下次启动时恢复——这并不总是你想要的。

还有对更新的 HDR 设置的处理。亮度可能完全由软件（即 Mutter）控制，因此硬件不会保存任何内容；系统可能希望保持硬件背光以支持 HDR 高光，这意味着滑块值不准确。

在 GNOME 51 中，Shell 改为存储和恢复亮度。显示器通过其 EDID 供应商、产品和序列号进行识别。
