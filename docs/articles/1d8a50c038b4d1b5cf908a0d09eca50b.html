GNOME 51 Beta 发布，带来众多小幅改进

2026年8月15日，美国东部时间下午1:12。

GNOME 51 Beta 现已可供测试。这个 Beta 里程碑的周期主要是整个庞大软件包集合中一系列小幅改进。

GNOME 51.beta 今天正式宣布，这个新测试版本中的一些更新包括：

- GNOME 控制中心在用户区域新增了指纹管理界面。

- GNOME 初始设置现在支持 systemd-homed 账户。

- GNOME Shell 现在遵循“减少动态效果”设置，以满足希望减少动画/视觉效果的用户需求。此外，还支持与 KDE 相同格式的 SVG 光标。

- Mutter 合成器现在支持背景模糊效果以及其他各种改进。

- GNOME 软件改进了图标加载和 PackageKit 仓库优化的性能。

- GTK 现在支持 ext-background-effect Wayland 协议，重新设计了 GDK 帧时钟以提高精度并减少丢帧，还有其他增强。

- GVFS 守护进程为空闲后端添加了自动卸载支持。

- Nautilus 文件管理器进行了各种细微改进。

- GNOME Web Epiphany 浏览器重新启用了 WebRTC 支持，在历史和概览模型中添加了 URL 固定支持，以及其他改进。

- Glycin 图像加载代码现在支持 GIF、TIFF 和 WebP 图像文件中的 XMP 元数据。Glycin 现在还支持 Radiance HDR 格式。

- GNOME Connections 现在在 Flatpak 构建中启用了 H.264。

- 整个项目进行了各种错误修复和翻译更新。
