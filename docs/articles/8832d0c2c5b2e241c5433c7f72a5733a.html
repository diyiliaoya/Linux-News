Intel Xeon 678X Windows 11 vs. Ubuntu 26.04 性能对比：HP Z4 G6i 工作站实测

发布于 2026 年 8 月 10 日上午 10:35（美国东部时间）

HP 最近推出了 Z4 G6i 工作站，我在过去几周内一直在测试这款产品。HP Z4 G6i 搭载了 Granite Rapids WS 处理器，本次评测样机具体配置为 Intel Xeon 678X。由于该设备预装了 Microsoft Windows 11 Pro，并且这是我首次接触 Granite Rapids WS 硬件，我借此机会进行了一些 Windows 11 与 Ubuntu 26.04 LTS 的性能基准测试，以比较这款 48 核 / 96 线程工作站处理器在不同操作系统下的性能表现。

HP Z4 G6i 在过去几周的测试中表现良好，后续将发布相关评测和数篇基准测试文章。这款 HP 工作站配备了 Intel Xeon 678W GNR-WS 处理器、4 条 32GB DDR5-6400 内存、2TB SK Hynix NVMe 固态硬盘，以及 NVIDIA RTX PRO 6000 Blackwell 显卡。

Windows 11 Pro 测试采用 HP 出厂预装配置，并安装了测试时所有可用的 Windows 更新。Ubuntu 26.04 LTS 则进行了全新安装，使用其 Linux 7.0 内核和其他默认软件组件。

这次 Windows 与 Linux 的对比主要是出于好奇心，因为这是我首次接触 Granite Rapids WS 硬件。此外，我还使用各操作系统默认提供的驱动程序，对 NVIDIA RTX PRO 6000 Blackwell 进行了 Windows 与 Linux 的对比测试。关于这款 Intel Xeon 678X 在 Linux 下的其他基准测试，将在后续文章中陆续发布，因为我还会继续使用这款 HP Z4 G6i 工作站数周。感谢 HP 为 Phoronix 提供测试硬件。
