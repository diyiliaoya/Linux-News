GNOME 51 如期发布，带来离线地图、指纹管理器、更完善的 GNOME Shell、GDM 与 Mutter 修复，以及设置、软件、文件、日历、地图和网页等预装应用的升级。

准时！GNOME 51 携一系列不容错过的改进登场

离线地图、指纹管理器以及更完善的 Shell 是你可以期待的部分新增功能。

对于大多数踏入 Linux 世界、尝试第一个发行版的人来说，GNOME 仍然是初始桌面环境。我这么说是因为 Ubuntu 和 Fedora Workstation 等主流选择都默认搭载它，直接将新用户带入 GNOME 生态系统。

尽管我们看到像动态平铺窗口管理器这样的方案采用率在上升，但像 GNOME 这样的传统桌面环境仍然是许多人的日常主力选择。

现在，一个新版本 GNOME 51 已经到来，带来了许多升级，例如行为更完善的 Shell、看起来更时尚的新壁纸，以及一系列更新的预装应用。

继续阅读以了解完整细节。

这是 GNOME 中你直接交互却甚至没有意识到其存在的部分。GNOME Shell 代表顶栏、概览、应用网格、通知、锁屏，以及窗口在工作区之间移动的方式。

GNOME 51 清理了许多粗糙边缘，为你带来诸如显示器亮度在会话之间保存和恢复，以及更精细的截图取景，让你可以将选区一直拖到显示器边缘等好处。

应用网格中的屏幕阅读器导航也重新设计，两个较小的烦人问题——另一个工作区上最小化窗口的 bug 和损坏的德语日期格式——已修复。

同样，连接 USB 驱动器时出现的自动运行提示也得到了改进。

这两个也是 GNOME 技术栈的重要组成部分。GDM 是登录屏幕背后的显示管理器，在你通过身份验证后启动会话。Mutter 是绘制窗口、决定窗口位置并处理输入的合成器。

GNOME 51 为回退会话增加了一个设置。回退会话是用户没有首选会话或首选会话无法启动时使用的会话。管理员可以将从未登录过的账户指向他们选择的会话。

自动登录绕过也被关闭了。此前，被攻破的欢迎程序可以为任何本地账户请求自动登录；幸运的是，这不再有效。

在 Mutter 中，对旧版 NVIDIA 驱动的支持已移除，在 HDR 显示器上，SDR 内容不再看起来褪色。窗口处理本身也得到了一些修复。边缘平铺窗口现在可以正确全屏，最大化窗口可以从键盘移动到另一个显示器而不会出现问题。

它还停止了一次报告多个显示器为主显示器，并且在输入捕获会话运行时鼠标光标会隐藏自身——就像远程桌面工具打开的那种会话。

GNOME 51 设置、软件、文件。

捆绑应用也经历了各自的重要升级。我们首先从设置应用开始，它在网络页面添加了 DNS 域搜索选项，获得了各种翻译更新，并通过 GNOME 二维码小部件处理 Wi-Fi 共享。

关于页面得到了清理，移除了“检查更新”字段，并扩展了软件和硬件信息组，让用户可以快速访问重要的系统细节。

因此，专门的“检查更新”按钮已成为过去。

软件现在会在安装已达到生命周期结束状态的应用之前警告你，其 Flatpak 权限列表已扩展，应用评分使用不同的衡量方法来显示平均评分。

文件（文件管理器）在拖动多个项目时显示计数徽章，复制操作完成后复制的文件保持选中状态。从另一个应用打开的位置会显示在新标签页中，而预览器现在支持重命名和移到回收站操作。

你可以通过选择一个文件或文件夹并按“空格”键来访问预览器功能。它会显示所选项目的预览以及一些关键细节。
