发行版发布：EndeavourOS 2026.08.15

该项目发布了新版本，作为两个主要版本之间的过渡版本。EndeavourOS 2026.08.15“Titan Nova”修复了一些键盘设置问题，改进了对NVIDIA GPU的支持，并移除了Budgie桌面环境作为安装时的选项。

“Titan Nova的实时环境和离线安装程序搭载了Calamares 26.03.2.3、Firefox 153.0.4、Linux内核7.1.8、Mesa 26.1.7、X.Org Server 21.1.24、nvidia-utils 610.57.04、nvidia-open 610.54.01。

键盘设置修复 - 修复了最近的键盘配置更新导致设置错误的问题。目前采用临时补丁确保一切配置顺利进行，永久修复计划在即将发布的Triton版本中推出。

改进了ISO上使用Nouveau驱动程序的NVIDIA GPU体验。

移除Budgie桌面 - 暂时移除了安装Budgie桌面环境的选项。当前上游软件版本正处于向新显示技术（Wayland）过渡的阶段，并未提供我们满意的默认体验。我们预计Budgie将在未来的版本中回归。”

EndeavourOS是一个基于Arch Linux的滚动发行版Linux。该项目旨在成为Antergos的精神继承者，在Arch基础上提供简易安装和预配置的桌面环境。EndeavourOS提供离线和在线两种安装选项。离线安装程序Calamares默认使用KDE Plasma桌面。在线安装程序可以安装可选的软件组件，包括大多数流行的桌面环境。
