Enlightenment 桌面环境 0.28 发布，网络功能增强

Enlightenment 0.28 版本发布，这是该开源桌面环境的重大更新。新增网络管理器模块，支持有线和无线及蓝牙连接与 VPN；音频方面加入原生 PipeWire 混音器；集成剪贴板历史模块；改进便携设备支持，包括电池充电限制和 ACPI CPU 电源配置。此外还有大量窗口管理、指针处理和显示器检测方面的修复。该版本需 EFL 1.29.0 或更新版本，Ubuntu 用户可通过脚本自动化安装。

Enlightenment 桌面环境 0.28 发布，网络功能增强 - OMG! Ubuntu

这是该开源桌面环境的首个重大更新。鉴于距离上一个版本已有一段时间，更新日志相当长。列表包括网络和音频栈增强、UI 和 UX 调整，当然还有大量错误修复——不过没有令人瞠目结舌的 UI 变化。

v0.28 新增了一个网络管理器模块。它支持连接和管理无线、有线和蓝牙网络连接，以及 VPN。它可以显示信号强度、安全性和其他连接详情。

在音频方面，除了现有的 PulseAudio 混音器外，还提供了原生 PipeWire 混音器，混音器操作现在可以在不同的“接收器”之间循环切换，并在设备输出之间更改。

经常复制粘贴？有一个集成的剪贴板历史模块，保留半持久日志。它可以控制跟踪哪些内容、跟踪多长时间，让你清除项目，并决定内容是否应在会话之间保留。

Enlightenment 0.28 还改进了对便携设备的支持，增加了对启用和配置电池充电限制（有助于保护电池健康）、ACPI CPU 电源配置文件（内核提供）以及更好的资源轮询的支持。

修复众多，包括一堆窗口管理增强、更好的指针处理和焦点选择、显示器 DDC 和 EDID 检测等。不过，按桌面和按屏幕的配置文件支持已被移除。
