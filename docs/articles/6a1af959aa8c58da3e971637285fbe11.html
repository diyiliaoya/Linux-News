Linux 7.2 与 Linux 7.3 对比：AMD Strix Halo 上展现若干改进

2026年9月22日下午03:23 EDT。

上周我进行了一些基准测试，展示了 AMD Ryzen AI Max+ "Strix Halo" 在 Ubuntu 26.10 上的性能提升。随后不久，在对某日常状态（使用 Linux 7.2 内核）进行测试后，Canonical 将 Ubuntu 26.10 的内核切换到了 Linux 7.3。以下是针对搭载 AMD Ryzen AI Max+ 395 "Strix Halo" 的 Framework Desktop 进行的 Linux 7.2 与 Linux 7.3 基准测试对比。

此前的基准测试是在 Linux 7.2 上的 Ubuntu 26.10 上进行的，当时状态已经很好，相比使用 Linux 7.0 内核的 Ubuntu 26.04 LTS 有不错的提升。现在 Ubuntu 26.10 已过渡到 Linux 7.3 内核（将于10月发布），我在 Strix Halo 上运行了 Linux 7.2 与 7.3 的基准测试，以寻找其他变化。

这些内核对比基准测试使用了同一台 AMD Ryzen AI Max+ 395 Framework Desktop。

对于 Radeon 8060S 显卡，Linux 7.3 相比 Linux 7.2 的图形基准测试结果大致相同，但在少数情况下（如 DDNet 平台游戏）有小幅改进。

网络延迟测试在 Linux 7.3 上略低，与这个开发中内核版本的其他系统基准测试类似。

由 Stress-NG 测量的 NUMA 性能在 Linux 7.3 上大幅改善。这与近期观察到的重大 NUMA 基准测试改进一致：

AMD EPYC 服务器性能在 2026 年因 Linux 内核改进几何平均提升约 8%

以及在 Strix Halo 上 Linux 7.3 的其他部分内核微基准测试中的一些改进。

然而，在最终测试的数十个其他实际工作负载中，Linux 7.3 在这台 AMD Ryzen AI Max+ 台式机上与 Linux 7.2 相比并没有带来太大差异。但 Linux 7.2 已经在 Ubuntu 26.10 上相对于 Ubuntu 26.04 LTS 的 Linux 7.0 表现出色。

即使对于这款 Linux 支持已经成熟且所测试工作负载特定的 Framework Desktop 而言，Linux 7.3 没有带来任何戏剧性的性能胜利，但它仍包含许多其他令人兴奋的功能：

AMD BC-250 在 Linux 下持续改进，补丁现已启用 PSP

AMD 发布 Linux 补丁，为 PCIe 6.0 启用 SEV-TIO TDISP

AMD 的 GAIA 本地 AI 现在能够转录和总结会议录音

AMD P-State 驱动将在 Linux 7.4 中针对 Zen 6 客户端 CPU 进行调优

Linux 补丁即将修复 AMD Zen 5 TLB 大小低报问题

AMD 为 EPYC 虚拟机准备增强 SMT 保护 "ESMTP" 的 Linux 支持
