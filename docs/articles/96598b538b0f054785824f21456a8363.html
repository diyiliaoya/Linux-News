Conflux 图标集为 Linux 桌面带来现代外观

Conflux 是一款新的 Linux 图标集，旨在兼具美观与中性风格。它不强制固定形状，能更好地兼容未覆盖的第三方图标，避免视觉突兀。该图标集借鉴了其他流行图标集的元素，并持续更新覆盖范围。用户可通过命令行安装，并在 Ubuntu 上编辑 index.theme 文件以继承 Yaru、Adwaita 等主题。

这是一个新的 Linux 图标集，旨在既美观又中性——我认为它两者都做到了。

许多人想为桌面找到一款“现代外观”的图标包，认为很多图标包过于风格化、过时，或者在某些情况下设计不佳。另一个要解决的动力是未主题化图标的外观。

我们中很少有人使用相同的应用集，也很少有图标集能覆盖所有内容（尤其是因为新应用不断出现）。当应用未被覆盖时，独特的设计往往更容易被破坏。持续更新有帮助——

但作为一个“多变形状”的图标集，未主题化的图标在视觉上与已主题化的图标保持兼容。

我最近读到的一条评论指出，尽管我们拥有高密度显示屏，能够呈现比以往更多的颜色，但现代 UI 设计却没有什么有趣的东西可看：扁平统一的形状、块状颜色、简单化的设计

Conflux 正试图打破这一趋势。

在 Ubuntu 上安装 Conflux 图标

Conflux 的文件夹图标，在 Ubuntu 上展示，令人愉悦

你可以像安装大多数图标一样在 Ubuntu 上安装 Conflux：即，将解压的主题文件夹放入隐藏的 ~/.local/share/icons 目录。

已安装，你可以通过命令行完成所有操作：

mkdir -p ~/.local/share/icons

cd ~/.local/share/icons

git clone --depth=1 https://github.com/MoshiurRahmanAdib/Conflux-Icon-Theme.git Conflux
