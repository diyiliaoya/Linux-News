Vanilla OS 3 重磅来袭，历经漫长等待终获 ARM64 支持

Vanilla OS 3（代号“Reunion”）正式发布，带来了对 ARM64 架构的完整支持，所有软件包均同时构建 ARM64 和 x86_64 版本，且除 NVIDIA 构建外，大多数镜像现已实现逐位可复现。该版本搭载 GNOME 50 和 Linux 内核 7.1.3，并引入了多项桌面改进，如默认启用分数缩放、移除 X11，以及新的默认应用（Ptyxis 终端、Papers 文档查看器、Resources 系统监视器）。此外，新增快照备份工具 Continuity，支持本地、加密外部驱动器或远程服务器备份。社区还可通过 GitHub 构建自定义版本，现有中国用户专属的“源”版本。现有 Vanilla OS 2 用户可通过系统升级获取此版本。

我与 Vanilla OS 的渊源可以追溯到 2022 年，当时我报道了它的首个稳定版发布，那仅仅是我在 It's FOSS（一个关于开源和 Linux 的网站）任职一个月后。

自那以后，我的关注点转向了其他发行版和以治理为核心的开发动态，不过我确实关注过它转向 Debian Sid 的过程，并远远地看着它经历了一次重大变革。我后来一直没有真正运行过它（生活就是这样，我想），但事情往往如此。

如果你之前没有听说过 Vanilla OS，它是一个基于不可变和原子化设计的发行版，其核心机制是在容器内安装软件包，而不是直接修改基础系统。

Reunion 有什么新特性？

如果你正在使用 ARM64 设备，无论是单板计算机、笔记本电脑，还是支持 UEFI 启动的完整工作站，那么你会很高兴地知道，Vanilla OS 现在对 ARM64 架构提供了完整支持。

现在每个软件包都同时为 ARM64 和 x86_64 构建，而且开发团队并没有将 ARM64 视为次要平台；在功能上，它应该与 x86_64 一一对应。

此外，除 NVIDIA 构建外，Vanilla OS 的大多数镜像现在都可以逐位复现。这意味着你可以自行重建镜像，并检查它是否与项目发布的版本一致，而不是盲目信任其构建基础设施的输出。

桌面端升级

该版本搭载了 GNOME 50，并配有 Linux 内核 7.1.3。虽然我们已经在其他发行版的发布中多次讨论过这个桌面环境，但这里为你做一个简要回顾。

GNOME 50 延续了之前 GNOME 放弃的 X11 移除计划。分数缩放也在此次版本中正式推出，不再需要实验性标志。

你还将获得一系列新的默认应用。Ptyxis 取代了 Black Box，其容器支持是值得关注的原因。Papers 取代了 Evince，提供了明显更现代的 PDF 阅读体验，而 Resources 则取代了 GNOME 系统监视器，让你清晰地了解应用和硬件的实际运行情况。

此外，配置处理、权限和日志记录现在在两个工具中终于以相同的方式工作，而不是各自为政。

另一个新增功能是 Continuity，这是一个基于快照的备份和恢复工具，与 ABRoot 协同工作。如果配置得当，它可以保存你的主目录、已安装的 Flatpak 应用以及 ABRoot 自身的元数据。

快照的存储位置由你决定。默认情况下，本地目录即可，但你也可以将 Continuity 指向一个使用 LUKS2 加密的外部驱动器，或者通过 SFTP、FTP 或 NFS 将备份发送到远程服务器。

此外，还推动了社区构建镜像的发展。GitHub 上的 Vanilla OS 组织现在托管了“源”版本，该版本面向中国大陆用户。

如果你想构建并维护自己的版本，Vanilla OS 开发者欢迎你与他们联系。

下载 Vanilla OS 3

Vanilla OS 3“Reunion”的镜像现已上线官方网站。请注意，下载页面会要求你先选择架构，然后选择捐赠金额。

你可以输入“0”作为金额来获取免费下载链接，也可以输入大于零的捐赠金额来直接支持项目，然后下载 ISO。

在撰写本文时，项目集成的 PayPal 捐赠功能暂不可用。

如果你已经在使用 Vanilla OS 2 Orchid（v1.4.0），此版本将作为常规系统升级提供。如果升级耗时过长，你可以运行以下命令来获取该版本：

```

sudo vanilla upgrade

```
