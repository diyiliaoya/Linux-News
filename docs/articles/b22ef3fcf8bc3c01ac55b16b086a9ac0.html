Servo 浏览器引擎持续扩展 Web 兼容性并新增功能

Servo 开源浏览器引擎项目发布九月状态报告，作为 v0.7 版本的一部分，带来了扩展的 Web 兼容性、新的 HTML 和 JavaScript 功能、WebGL2 改进以及嵌入能力的持续增强。亮点包括支持 progress 元素、CSS 类型化算术、font-width 属性、alpha() 函数和 CSS 模块，升级至 SpiderMonkey 153.3 和 Mozangle 0.7，Candy Crush 现已可玩，并优化了性能和内存使用。

Servo 开源浏览器引擎项目终于发布了状态报告，重点介绍了九月份取得的改进。包括扩展的 Web 兼容性、新的 HTML 和 JavaScript 功能、WebGL2 改进，以及持续扩展该引擎嵌入能力的工作。

Servo 九月的一些亮点（属于 Servo v0.7 版本的一部分）包括：

- 支持 "progress" HTML 元素。

- 支持 CSS 类型化算术。

- 支持 font-width 属性。

- 新的 CSS 功能，如 alpha() 函数和 CSS 模块。

- 升级至 SpiderMonkey 153.3 和 Mozangle 0.7，并包含安全修复。

- 扩展的 Web 兼容性：从 egui.rs 到 Candy Crush 现在均可游玩。

- Servo 的 WebGL 2 实现通过更好的一致性得到改进。

- HTML 视频元素隐藏字幕功能的进展。

- 嵌入 API 改进，以持续增强 Servo 的嵌入能力。

- Servo 还在改进引擎性能、减少内存使用、Linux 上的线程亲和性提升以及其他优化方面开展了工作。
