发行版发布：Voyager Live 26.10

该项目发布了新版本 26.10。新版本提供两个版本，一个支持 Flatpak，一个支持 Snap 软件包。

“我向您呈现 Voyager 26.10，基于 Ubuntu ‘Stonking Stingray’。提供两个标准版本——一个基于 Ubuntu，使用 Snap 和 deb 软件包；另一个基于 Flatpak 和 deb。请注意，这些是中间版本，提供九个月的更新，主要用于 LTS 版本的实验和测试。这些中间版本也可以毫无问题地安装。此版本将完全按照最新 Ubuntu 版本的结构构建，包括其环境和安全层。默认版本使用 Snap、Dracut 和 Rust，是完整的标准版，使用基于 Snap 的更大的 Subiquity 安装器。或者，还有 Flatpak 版，使用更轻量、更易用的 Ubiquity 安装器。软件包包含 GNOME 51，这是一个轻量、快速、现代、流畅、安全且高性能的混合环境，适用于 PC 和平板电脑。此版本基于 Linux 7.3 内核。终端中的 AI 聊天机器人 ChatGPT 已集成，无需双重 API 密钥，使用 GNOME 扩展，并可选移除 AI。”

Voyager Live 是一个基于 Xubuntu 的发行版和 live DVD，展示 Xfce 桌面环境。其功能包括 Avant Window Navigator 或 AWN（类似 dock 的导航栏）、Conky（在桌面上显示有用信息的程序），以及 300 多张可用作桌面背景的照片和动画。该项目还开发其他几个版本。
