发行版发布：MX Linux 25.3

MX Linux 25.3 发布，为 25.x 系列带来更新。该版本从 Debian 上游引入安全修复和固件，并更新了 MX-Welcome、MX-Tools 等工具界面，新增 ISO 签名验证工具和主题颜色定制工具，在软件包安装器中加入 siduction 7.X 内核，并默认启用 lazytime。现有用户无需重装，通过常规更新通道即可升级。

发行版发布：MX Linux 25.3

该项目发布了 25.x 系列的新更新。除了从 Debian 上游引入新的安全修复和固件外，MX Linux 项目还包含多项新变化：

“在 MX 方面，我们在此过程中已推送了大部分更新，但这次有一些特别值得注意的更新。MX-Welcome、MX-Tools 和 custom-toolbox（供 Fluxbox 使用）获得了用户界面改版。Verify-iso-sig 是一个新工具，不仅可验证 MX ISO 的数字签名，还可验证许多流行发行版家族的 ISO。MX-Theme-Colors 是一个有趣的工具，可从现有 MX 主题（GTK）创建自定义高亮主题。在 mx-packageinstaller->popular apps->kernels 中引入 siduction 7.X 内核。mx-packageinstaller->popular apps 中第三方 VPN 安装器有许多更新。mx/gazelle-installer 将在新安装中默认在 fstab 中设置 lazytime。更新了手册和 FAQ 条目。

大多数 mx-tools 的翻译更新。自上次正式发布以来的所有错误修复、维护和功能版本。现有用户无需重新安装。所有更新均通过常规更新通道提供。”

更多 MX Linux 新闻...

MX Linux 是一个面向桌面的 Linux 发行版，基于 Debian 的“Stable”分支，是 antiX 和前 MEPIS Linux 社区的合作项目。它使用 Xfce 作为默认桌面（也提供独立的 KDE Plasma 和 Fluxbox 版本），是一个中等重量的操作系统，旨在将优雅高效的桌面与简单配置、高稳定性、可靠性能和中等占用空间相结合。
