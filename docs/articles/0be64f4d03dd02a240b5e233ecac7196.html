Ubuntu 26.10 发布：搭载 GNOME 51、Linux 7.3 及全新平铺技巧

Ubuntu 26.10 正式发布，支持 9 个月，搭载 GNOME 51、Linux 7.3 内核和 Mesa 26.2。新特性包括拖拽窗口时弹出布局选择器、登录界面支持通行密钥、Rust 核心工具集、更强大的应用中心、RISC-V 桌面 ISO 以及扩展的 TPM 全盘加密。此外还改进了 PDF 签名、截图键盘控制、Nautilus 拖拽计数与标签页概览，并将桌面图标扩展移植至 GTK4。

窗口平铺新增拖拽上移布局选择器

视频展示了新的布局选择器

Ubuntu 26.10 首次推出了一种更新、更快的拖拽中平铺窗口方式。

当你开始移动窗口时，布局选择器会从屏幕顶部探出。将窗口向上拖向它即可展开布局选择器。将窗口移到某个区域上方，就能看到窗口将落位置的幽灵预览。如果满意，松开即可将其吸附到位。

很巧妙？当然，但也可能很烦人。Ubuntu 默认没有提供简单的关闭方式，但如果你觉得每次拖动窗口时布局选择器忽隐忽现很分散注意力，可以用以下命令禁用这个弹窗：

gsettings set org.gnome.shell.extensions.tiling-assistant enable-layout-picker false
