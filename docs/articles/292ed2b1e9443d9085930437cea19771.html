使用 Sober 在 Linux 上无需 Wine 玩 Roblox

Sober 是 Vinegar 项目开发的第三方非官方运行时，让 Linux 用户无需 Wine 即可运行 Roblox。它不涉及模拟或虚拟机，支持所有 PC 专属功能，性能与 Windows 客户端相当或更好。Sober 非开源，仅通过 Flathub 分发，系统要求不高，但不受 Roblox 官方支持，服务器端更新可能导致功能失效。

在 Linux 上无需 Wine 玩 Roblox，使用 Sober - OMG! Ubuntu

Roblox 官方并不支持 Linux，但 Linux 用户可以使用 Sober 来运行它，这是一个非官方的第三方“移植”，无需 Wine 即可工作。

我知道；这不是一款“游戏”——除非你正迫不及待想玩。大多数 Roblox 用户年龄在 16 岁以下，通过手机访问，并对 Robux（游戏内虚拟货币）有着不健康的兴趣。

但你可能——像我一样——有那些讨厌的亲戚，他们要求在你的 Linux 电脑上玩 Roblox，因为他们的平板电脑需要充电……

性能“与 Windows 相同或更好”

在 Roblox 世界里享受清醒体验，无需 Wine

Sober 是由 Vinegar 项目制作的“专为 Roblox 代码设计的专用运行时”。这里不涉及模拟或虚拟机。它提供对 Roblox 所有 PC 专属功能的访问，包括聊天、声音，当然还有浏览和加入“游戏”。

Roblox 上的游戏被称为“体验”。最常访问的之一：99 Nights in the Forest，这个标题深深烙印在我的交感神经系统中，因为我的一个侄子（7岁）连续两天每句话都要完整说它 20 遍。

游戏在官方服务器上运行，因此你需要在线才能玩，图形在本地渲染。据说在相同硬件上，Linux 上的性能“与 Windows 客户端相同或更好”。

非开源，且仅在 Flathub 上提供

Sober 未获得 Roblox Corporation 的支持或批准，服务器端的更改可能随时部分或完全破坏功能。你的账户不应因使用它而被封禁，因为 Vinegar 表示正常使用“很少”会导致 moderation 行动。

该项目也不是开源的。Vinegar 表示他们选择保持代码闭源，以“减少滥用的可能性”。此外，Sober 也只能通过 Flathub 安装，没有计划提供其他包格式。

好的一面是，它的系统要求不高；支持 SSE4.1 的 x86-64 CPU（推荐 SSE4.2）和处理 OpenGL ES 3.0 的 GPU（推荐 Vulkan 1.1）。充足的可用内存有帮助（所以关掉几个浏览器标签页）。

有一个实验性的 ARM 版本，但要访问安装程序，你需要加入该项目的 Discord。

还有其他努力和方法，例如，在 Linux 上运行 Android APK。
