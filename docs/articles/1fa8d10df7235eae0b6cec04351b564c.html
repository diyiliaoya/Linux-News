发行版发布：Parted Magic 26.11

是一个小型 live CD/USB/PXE，其主要目的是对硬盘进行分区。该项目的最新版本 26.11 引入了对运行 64 位 ARM 处理器的计算机的支持。

“此版本为 ARM 计算机增加了 Parted Magic 的第二个版本，包含六个新程序和 Linux 内核 7.3。Erase 验证驱动器的速度大大提高，并按照 IEEE 2883 的要求清除存储卡。Parted Magic 现在推出了适用于 64 位 ARM 计算机的第二个版本。其 ISO 镜像与 PC ISO 一起放在下载页面中，无需额外费用——所有能下载此版本的人都可以下载两者。它专为从 UEFI 启动的 ARM 服务器和 Snapdragon X 笔记本电脑而设计，并且启动时开启安全启动。我在 Ampere Altra 服务器和联想 ThinkPad T14s Gen 6 上进行了测试。它不适用于 Mac 或树莓派等开发板。它包含 Erase、VisParted、Clone、Rescue、Boot Repair 以及下面的其他新程序，并以 Google Chrome 作为其网络浏览器。USB 安装器将其写入 USB 驱动器。ARM 版还内置了 USB 安装器，因此 ARM 计算机也可以为 PC 制作 Parted Magic 驱动器。”

Parted Magic 是一个小型 live CD/USB/PXE，其主要目的是对硬盘进行分区。尽管 GParted 和 Parted 是主要程序，但 CD/USB 还提供其他应用程序，例如 Partition Image、TestDisk、fdisk、sfdisk、dd、ddrescue 等。2013 年 8 月，该发行版成为商业产品，不再提供免费下载。
