NVIDIA 开发 "Display Config Server" 以改善 Linux/Wayland 在显示墙上的表现

NVIDIA 正在开发 Display-Config-Server，旨在提升 Linux 在复杂显示墙场景下的能力。该方案基于 Vulkan Direct-to-Display 模型，通过集中管理显示器并租借给 Vulkan 客户端，避免每个应用自行处理显示校准与配置。目前代码计划在 GitHub 开源，但尚未公开。

作为 NVIDIA 在 AI 领域之外改善 Linux 生态的一项举措，他们一直在开发 Display-Config-Server，作为一种新解决方案，帮助增强 Linux 在复杂显示墙方面的能力。

NVIDIA 工程师 Austin Shafer 今天上午在 XDC 2026 上发表了关于下一代显示墙上 Linux 的演讲：这些复杂显示设置出现在电视制作、剧院等场景中。如今许多这类复杂显示墙运行在 Microsoft Windows 上，而 NVIDIA 希望改善 Linux 在此类视频/媒体墙上的使用。

如今运行 Linux 的显示墙通常仍基于 X.Org Server，并利用 NVIDIA Mosaic 显示功能。对于这类显示墙，单独使用 Wayland 会变得更加困难，因为涉及不同的合成器和其他复杂性。不过，有一条前进路径：使用 Vulkan Direct 2 Display "D2D" 与 VK_KHR_display 扩展，让 Vulkan 交换链无需任何窗口系统即可驱动物理显示器。

NVIDIA 决定设计 Display Config Server，通过“拥有”显示器并将其租借给 Vulkan 客户端，来改进 Vulkan 直接到显示器的模型，从而避免每个应用程序都需要包含处理显示校准和配置的逻辑。Display Config Server 实现了集中配置、客户端之间的无缝交接，并使应用程序更容易实现。

XDC 2026 的演讲分享称，NVIDIA 正在努力支持 Display Config Server 与 Wayland 合成器嵌套运行。他们还在改进 Vulkan 直接到显示器 API 在显示墙上的呈现方式。

Display Config Server 代码将通过这个 GitHub 仓库开源，但截至撰写本文时似乎尚未公开可用。
