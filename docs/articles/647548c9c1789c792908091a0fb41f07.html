OpenCourant：Rocky Linux 开发者创建 OpenRadioss 社区分支

2026年10月4日下午01:51 EDT。

本周，西门子关闭 OpenRadioss 项目的决定令人意外且遗憾。该项目由 Altair Engineering 四年前创立，基于其著名的 Radioss 有限元求解器。西门子不仅终止了项目，还关闭了托管开源代码的 GitHub 仓库，并移除了围绕该项目建立的其他资源。幸运的是，OpenRadioss 有了一个新的社区分支——OpenCourant。

Rocky Linux 及 Rocky 企业软件基金会（RESF）的创始人兼副总裁 Brian Clemens 发起了 OpenCourant，作为 OpenRadioss 的社区分支。OpenCourant 基于西门子关闭并移除 Git 仓库访问权限之前最后一个公开已知的开源 OpenRadioss 快照。

OpenCourant 在其新项目页面上将自己描述为 OpenRadioss 的社区延续：

“OpenCourant 是一个开源有限元求解器，用于碰撞、冲击和高度非线性动力学仿真——在 GNU AGPL 许可下，公开地延续 OpenRadioss 代码库，这是它应有的归属。”

OpenCourant 继续沿用 OpenRadioss 的 AGPLv3 许可，并将作为 Rocky 企业软件基金会的一部分运营。

不过，他们遇到了一个小问题：OpenRadioss 的一部分由二进制依赖组成，且在西门子移除仓库之前并未获得最新版本。有关详情，请参见此讨论帖，如果有人恰好拥有较新的 OpenRadioss 二进制文件，欢迎提供。

希望 OpenCourant 能够顺利发展，延续 OpenRadioss 留下的成功。我期待在未来的基准测试文章中使用 OpenCourant。
