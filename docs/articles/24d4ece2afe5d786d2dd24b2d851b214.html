Firefox 155 将AI驱动的智能窗口扩展到更多国家

Firefox 155 作为浏览器新双月发布计划的首个版本，将AI驱动的浏览模式带到了更多国家，用户可自主选择阿里巴巴、OpenAI或Google的AI模型。该版本还引入了个性化对话开场白、更快的Exa网络搜索引用响应，以及更智能的标签分组功能。此外，Firefox 155 还包含多项小改进，如地址栏跟踪器计数显示、容器重新排序、乌尔都语和马拉地语翻译支持、PDF缩放超过100%、Linux系统睡眠问题修复、Windows上Nintendo Switch Pro控制器支持等。

Firefox 155 已发布，这是浏览器新的双月发布计划中的首个版本。

此次更新将Firefox的AI驱动浏览模式带到了更多国家的用户。目前该功能仍为可选启用（暂时如此），并由用户从阿里巴巴、OpenAI和Google中选择的AI模型提供支持。

Mozilla还增加了一些变化以吸引你更多聊天（“个性化恢复对话开场白”），使助手通过Exa网络搜索引用响应更快，并让智能窗口在分组相关标签方面表现更好。

如果这些都不合你意，你可以通过禁用Firefox中的AI功能来移除窗口框架中的智能窗口按钮。就这样！不过，直到你访问任何搜索引擎、社交媒体、购物网站、公司网站，它们也会要求你接受它们的AI集成。

Firefox 155 的小改动

重新排序容器并翻译更多语言，包括乌尔都语

Firefox 155 中的地址栏现在会在你浏览时提示它已阻止的跟踪器数量。Mozilla表示，这使用户更容易看到其“内置隐私保护”在我们浏览时的工作情况。如果这个计数让你分心，你可以隐藏它。

你可以从浏览器的设置页面重新排序容器（该功能在Firefox 153中“引入”）。你偏好的顺序会反映在容器列出的所有位置，主要是上下文菜单中。

Firefox的内置隐私翻译工具现在支持乌尔都语和马拉地语，较小的PDF现在可以缩放超过100%以打印整页大小（其他浏览器，包括Microsoft Edge，已经支持此功能）。

在Linux上，Firefox之前会在长时间浏览会话后阻止系统休眠，这个问题现已解决。同样解决的还有Microsoft 365 Word Online和Linux上的Web应用中文本消失的问题（尽管该问题仅影响某些键盘布局）。

在Windows上使用Firefox？Nintendo Switch Pro和类似的第三方控制器现在可以在网页游戏中使用——所有按键都已映射，即插即用。Mozilla与Nvidia合作支持GeForce NOW进入浏览器的努力显然已见成效。

强制门户检测域名移至firefox-portal-detection.com

链接触发改为显式用户交互

CSS块和函数嵌套限制为75层以防止崩溃

现在适用于所有属性

直接解析Promise的键控对象

函数内联调整任何颜色的不透明度

限制为少量允许列表站点

JSON查看器支持JSON Lines文档

开发者工具现在可以模拟prefers-reduced-motion偏好

修复以允许在X上复制直接消息和YouTube上的评论

此外，还有各种错误修复和一批新的安全更新

升级到Firefox 155

Firefox 155 从今天（星期二，9月1日）起可从Firefox网站或Mozilla FTP（如果你想直接下载）获取。

现有用户？你可以在Windows和macOS上通过应用内更新，或者在Linux上如果你使用Firefox二进制文件。否则，请等待更新通过你的软件管理器或应用商店推送。

Ubuntu用户将通过Snap Store自动后台更新获得此更新，因此无需特别关注——一旦准备好，通知会提示你重启。
