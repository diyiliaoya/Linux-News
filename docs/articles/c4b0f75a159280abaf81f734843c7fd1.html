Mesa 26.3 的 RADV 与 RadeonSI 已为旧款 AMD GPU 准备好 DRM 格式修饰符支持

Linux 7.3 为 GFX6 至 GFX8 时代的 AMD GPU（从初代 Radeon HD 7000 到 Polaris、Fiji 系列）引入了 DRM 格式修饰符支持。如今 Mesa 26.3 已合并 RadeonSI 与 RADV 的用户空间补丁，使这些旧 GPU 能利用格式修饰符，从而支持基于 Vulkan 的 Wayland 合成器、改善 OpenGL 与 Vulkan 互操作性，并兼容 Zink 等实现。

Mesa 26.3 的 RADV 与 RadeonSI 已为旧款 AMD GPU 准备好 DRM 格式修饰符支持

发布于 2026 年 9 月 10 日下午 05:19（美国东部时间）。

随 Linux 7.3 一同到来的是面向 GFX6 至 GFX8 时代 GPU 的 DRM 格式修饰符，涵盖从初代 Radeon HD 7000（GCN 1.0）显卡一直到 Polaris 和 Fiji 系列。Valve 的 Timur Kristóf 所做的这项工作，对于这些旧 GPU 支持基于 Vulkan 的 Wayland 合成器、改善 OpenGL 与 Vulkan 或其他 API 之间的互操作性、支持运行在 Zink（Vulkan 之上的 OpenGL 驱动实现）上的合成器，以及其他诸多好处而言，都是必要的。如今，Mesa 26.3 已合并了 RadeonSI 和 RADV 用户空间侧的支持，以便在这些旧 GPU 上使用格式修饰符。

在 AMDGPU 的 GFX6 至 GFX8 DRM 格式修饰符已合并到当前 Linux 7.3 周期（将于 10 月作为稳定版首次亮相）之后，Mesa 侧的补丁也已合并到 Mesa 26.3 中，后者预计将于 11 月作为稳定版首次亮相。

DRM 格式修饰符提供了有关图像缓冲区的平铺、压缩及其他属性的详细信息。根据布局的不同，它还可以帮助实现更好的性能以及其他更灵活的用例。

Timur Kristóf 今天合入 Mesa Git 的补丁包含了针对 GFX6 至 GFX8 修饰符支持的所有 Mesa 侧更改。GFX9 及更新版本此前已由 AMDGPU 和 Mesa 支持。
