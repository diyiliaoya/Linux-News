Linux Mint 27 'Adrien' 将于今年圣诞节发布，带来更多新应用

Linux Mint 宣布改变版本编号方式，下一版本将命名为 Linux Mint 27 'Adrien'，预计2026年圣诞节发布，基于 Ubuntu 26.04 LTS。此次更新将带来大量新功能和应用程序，包括日历、闹钟、系统监视器、归档管理器和终端模拟器等，全部用 Python 编写，注重用户友好性。代号也从传统的女性名字改为男性名字。

Linux Mint 27 'Adrien' 将于今年圣诞节发布，带来更多新应用 - OMG! Ubuntu

今年早些时候，Linux Mint 调整了其发布计划，现在又改变了版本编号方式——下一个主要版本将不是 Linux Mint 23，而是 Linux Mint 27。

版本号现在将按年份编号。Linux Mint 27 之后将是 v28，依此类推。

此次发布也开启了一系列新的版本代号。Mint 传统上使用女性名字，从2006年的 Linux Mint 1.0 'Ada' 开始，按字母顺序循环，一直到2026年的 'Zena'。随着 Linux Mint 27，这一系列回到 'A'，代号已公布为 'Adrien'。

是的，Linux Mint 正在转向男性名字——为什么呢？

多年来，Linux 社区中一些人指责 Mint 使用女性代号作为装饰是性别歧视，甚至是物化。虽然该发行版没有明说，但我怀疑这一转变，也许是无意识地，是对那些批评的回应。
