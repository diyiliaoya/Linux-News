GIMP 3.2.6 发布，为最终移植 GTK4 做了一些早期准备

2026年9月10日下午6:12（美国东部时间）。

从 GTK2 过渡到 GTK3 的版本去年才发布稳定版。但 GTK4 已经推出多年，GIMP 开发者已开始为不可避免的 GTK4 移植做一些非常早期的准备。

GIMP 3.2.6 现已发布，包含部分上述准备工作，以及针对这款 Adobe Photoshop 自由软件替代品的各种其他修复和改进。

在性能方面，GIMP 3.2.6 进行了“改进”，以提升加载大量字体时的性能。仍存在一些明显的延迟，但总体而言，对于拥有大量字体文件的用户，以及在文本工具中输入和关闭字体列表时，启动速度有了更好的进展。预计在迁移到 GTK4 时还会有进一步的性能优化。

可以说最引人关注的是，GIMP 3.2.6 已开始为最终的 GTK4 移植做准备！在 GIMP 3.0 中，他们终于从 GTK2 迁移到了 GTK3，而 GTK4 已经推出近六年。GIMP 开发者已开始对代码库进行一些修改，以避免使用已弃用的功能，并进行其他更改，以便更好地迎接最终的 GTK4 移植。从 GTK3 到 GTK4 的迁移比从 GTK2 到 GTK3 的侵入性更小，但可能还需要一段时间才能看到可能被称为“GIMP 4.0”的版本。

在其他新功能方面，GIMP 3.2.6 增加了在图层组上使用剪切的功能。还新增了一个用于绘画的“旋转”（桶形旋转）动态输入，供较新的 Wacom 笔使用。

对于 macOS 用户，现在有一个新的 macOS 软件包，与 Linux 和 Windows 软件包同时生成。

GIMP 3.2.6 还包含多项安全修复以及较小的错误修复。
