这些开源开发者正在为Linux逆向工程Xbox Game Pass

一个名为Xodus的开源项目正在逆向工程Xbox Game Pass，旨在让Linux用户无需云流媒体即可运行Xbox PC游戏。项目负责人Paweł在Reddit上确认，Xbox认证和游戏下载等最困难的部分已经实现。该项目已获得广泛关注，但开发者提醒仍处于早期阶段，距离可用版本还有数月。若成功，将填补Linux与Windows游戏体验之间的最后空白。

这些开源开发者正在为Linux逆向工程Xbox Game Pass

他们已经破解了Xbox游戏下载，macOS支持也在开发中。

Xbox Game Pass在Linux上从未真正良好运行过，除了延迟严重的云流媒体，但一个名为Xodus的开源项目正试图改变这一现状。

根据Reddit上的一个帖子，Xodus的项目负责人Paweł（网名）确认，在Linux上运行这些游戏最困难的部分——Xbox认证和游戏下载——已经可以工作了。

该项目正试图逆向工程Xbox的整个认证、许可和分发流程，以便在Linux上运行Xbox PC游戏。

Xodus自称是“向Linux的伟大游戏迁移”，同时提醒人们它未经微软认可，使用它存在风险。要知道，现代Xbox PC游戏运行在微软的GDK（游戏开发套件）上，并以加密的MSIXVC格式分发。在Linux上运行游戏意味着要同时处理这两者。

该项目的GitHub页面目前包含多个仓库，包括用Rust编写的主客户端、一个用于读取MSIXVC的fork库，以及xgameruntime——一个为Wine构建的GDK开源实现。另一个仓库则记录了该DLL的内部工作原理。

此外还有由Xodus团队维护的fork版本，包含自定义调整，以及从OpenXbox fork出来的Xbox认证库。

目前还没有可供试玩的二进制文件；仍有大量工作要做。Xodus的可用版本仍需数月时间。

开发者们感到惊讶

得益于Reddit上的回复，该项目获得了一波媒体报道，这让开发者们措手不及。在Digital Foundry报道后，Paweł在项目的Discord服务器上写道：“哇，这真是疯了。”

尽管最初的报道似乎来自VideoCardz.com，但许多媒体都弄错了一个细节。将Xodus描述为Heroic Games Launcher团队的项目是不正确的，因为Paweł是唯一一位同时参与过Heroic Games Launcher的Xodus贡献者，而非整个团队。

另一位开发者（一直在追踪这波意外报道）指出，其中一篇文章对Xodus的评价相当尖刻，而另一位开发者（olivi-r）则分享了一些重要的开发进展。

“最近几天，xgameruntime方面的进展相当快，XTaskQueue几乎已经实现，还有一些模式和怪癖需要解决。

目前正在修复XUser，因为签名生成似乎有点问题😬

还需要将票据从xodus加载到XUser中，我一直硬编码自己的票据用于测试，还不确定我们是采用stdio代理还是直接在Wine中实现IPC。

如果Xodus成功，它将填补Linux和Windows游戏体验之间的最后一大空白。Steam、GOG和Epic Games上的游戏库已经可以通过Proton和Heroic良好运行，但Xbox PC和Game Pass游戏此前一直局限于Windows或延迟严重的云流媒体。

如果你问我，这是微软让Xodus的工作变得更容易的最佳时机，类似于Valve在上游处理Wine开发的方式。这样，整个生态系统都能受益，而不仅仅是Steam。

如果Xbox决定帮助这个项目，他们确实有很多途径可以探索……
