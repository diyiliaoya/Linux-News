SPEC 发布适用于 Linux 的 SPECviewperf 15.0.1

2026 年 9 月 22 日上午 10:36 EDT。

SPEC 在 2025 年 5 月推出了 SPECviewperf 15，这是该行业标准工作站图形基准测试的最新主要版本。遗憾的是，Linux 支持再次落后，SPECviewperf 15 最初仅在 Microsoft Windows 上发布。不过今天 Linux 已经赶上，SPEC 发布了 Linux 原生版本的 SPECviewperf 15.0.1。

SPECviewperf 15.0.1 于今日发布，相比之前的 Linux 版本 SPECviewperf 2020 是一次重大更新。该 Linux 版本可用于 x86_64 和 AArch64 工作站。

虽然 Windows 上的 SPECviewperf 15 增加了 DirectX 12 和 Vulkan 图形 API 支持，但 Linux 版本的 SPECviewperf 15.0.1 仅支持 OpenGL 4.5。
