Canonical 重申计划：Ubuntu 27.04 将默认使用 ntpd-rs

2026年10月6日 下午5:08 EDT

早在今年三月，Canonical 就宣布了其下一个目标，作为将更多 Ubuntu Linux 系统组件过渡到基于 Rust 实现的一部分。这个时间同步软件包已在即将发布的 Ubuntu 26.10 中提供测试，并计划在 Ubuntu 27.04 中成为默认选项。

ntpd-rs 项目是一个基于 Rust 的、功能完整的网络时间协议（NTP）和网络时间安全（NTS）实现，同时支持客户端和服务器功能。ntpd-rs 是 Trifecta Tech Foundation 的项目之一，该基金会专注于使用 Rust 来提高安全性和稳定性。

在今天的一篇 Ubuntu 博客文章中，Canonical 总结了 Ubuntu 26.10 的一些亮点，其中提到 ntpd-rs 已在 Ubuntu 26.10 中提供测试，并重申了在 Ubuntu 27.04 中默认使用它的计划：

“准确的时间是 TLS 证书验证、Kerberos、可靠的日志时间戳和审计追踪的基础。如果系统时钟严重错误，有效证书可能显示为已过期或尚未生效，Kerberos 身份验证可能因时钟偏差而失败，安全日志也难以在不同系统之间可靠地关联。Ubuntu 26.10 在归档中包含了一个更新版本的 ntpd-rs——一个内存安全的 NTP 实现——用于测试，目标是在 Ubuntu 27.04 中将其设为默认。”

文章还重点介绍了 Ubuntu 26.10 更小的 Secure Boot 路径、Linux 7.3 内核的使用、在更多系统上基于 TPM 的加密、Rust Coreutils 的完全过渡、OpenSSL 4.0，以及 Dbus-Broker 取代经典的 Dbus 守护进程。Ubuntu 26.10 还实现了其目标，即通过本地 AI 提供 Myna 作为桌面语音转文字功能。
