发行版发布：RefreshOS 3.1

eXybit Technologies 发布 RefreshOS 3.1，这是基于 Debian 的桌面 Linux 发行版更新，采用 KDE Plasma 桌面。新版本基于 Debian 13.7 更新，集成官方 RefreshOS APT 仓库，建立 Stable、Testing 和 Experimental 频道，并加入 refreshos-release 包以支持后续品牌和系统配置更新。

eXybit Technologies 已宣布发布 RefreshOS 3.1，这是该项目基于 Debian 的桌面 Linux 发行版的更新版本，采用精致的 KDE Plasma 桌面：“RefreshOS 3.1 建立在 RefreshOS 3.0 'Colorful Cosmos' 的基础上，整合了更新的 Debian 软件包、RefreshOS 仓库集成、改进的软件包管理以及系统配置修复。Debian 13 更新：将底层 Debian 13 'Trixie' 系统从最初的 Debian 13.4 构建更新至包含 Debian 13.7 可用的更新；安装了当前的 Debian 软件包更新，并作为发布准备工作的一部分移除了过时的软件包和旧内核文件；将系统更新为使用 Linux 内核 6.12.113 进行最终 ISO 构建。RefreshOS 仓库和软件包管理：引入了与官方 RefreshOS APT 仓库的集成；建立了 Stable、Testing 和 Experimental 仓库频道，用于分发和测试 RefreshOS 特定软件包；在 RefreshOS 3.1 安装中添加了 refreshos-release 软件包，使得未来可以通过软件包管理器更新 RefreshOS 品牌和系统配置。……” 请参阅该发行版的发布公告以获取完整的更改和改进列表。

RefreshOS 是一个用户友好的 Linux 发行版，基于 Debian 的“Stable”分支，采用 KDE Plasma 桌面。其主要特性包括扩展的驱动支持、精致的用户体验和优化的系统性能。该发行版附带 Brave 网页浏览器、LibreOffice 办公套件、GIMP 图像编辑器以及各种用于生产力和创意任务的流行应用程序。RefreshOS 维护一个不包含 Snap 和 Flatpak 软件包的干净环境。
