Intel CPU 微码 20260811 版本修复八个安全问题

2026 年 8 月 11 日下午 03:26（美国东部时间）

Intel 今天发布了 20260811 CPU 微码更新，以修复现有处理器的各种问题，包括首次为 Bartlett Lake 和 Wildcat Lake 提供新的微码镜像。新的微码更新可追溯至 Intel Core Gen10 处理器。

今天的 Intel 20260811 CPU 微码更新共解决了八个安全问题。INTEL-SA-01379 是一个高等级的权限提升漏洞，涉及 Intel TDX 和 Xeon 6 处理器。

INTEL-SA-01404 是 Xeon 6 CPU 与 Intel TDX 相关的信息泄露漏洞。

INTEL-SA-01423 是 Intel 处理器的信息泄露漏洞，涉及 Ring 0 瞬态执行期间错误数据转发的加载值注入问题。该漏洞可追溯至第十代 Intel Core CPU。

INTEL-SA-01428 是一个影响所有 Intel Core Ultra CPU 以及 Xeon 6 处理器的权限提升漏洞。

INTEL-SA-01435 是 Xeon 6 处理器因 Ring 3 中不当访问控制导致的权限提升漏洞。

INTEL-SA-01441 是 Core Ultra Series 2 和 Core Ultra Series 3 处理器的拒绝服务漏洞。

INTEL-SA-01442 是 Intel Xeon 处理器的权限提升漏洞，原因是某些固件中始终不正确的控制流，以及与之相关的第二个 CVE（不当输入验证）。

INTEL-SA-01443 是第三代 Xeon Scalable 处理器因硬件逻辑竞争条件导致的拒绝服务漏洞。

除了这八个安全漏洞之外，本月的 Intel CPU 微码更新还修复了各种功能性问题。
