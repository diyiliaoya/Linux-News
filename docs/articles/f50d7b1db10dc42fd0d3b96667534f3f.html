Ubuntu 27.04 每日构建版已开放下载

Ubuntu 27.04 的每日构建镜像现已开放下载，供希望密切跟踪开发进展的用户测试。每日构建基于开发代码生成，将持续整个开发周期直至稳定版发布。Ubuntu 27.04 计划于2027年4月22日发布。建议在备用分区或虚拟机中运行，避免作为主力系统使用。

如果你计划密切关注 Ubuntu 27.04 的开发进展，每日构建镜像现已可供下载。

每日构建在整个开发周期内持续产出，直至最终的稳定版本发布。它们（显然）基于开发代码构建，并且（几乎）每天生成，以便于测试变更。

没有特定测试需求的用户不应使用，但有需要或希望测试的用户无需等待公开测试版，也不必费心从早期版本升级（顺便说一句，这也是可行的）。

Ubuntu 27.04 计划于2027年4月22日发布。

Ubuntu 每日构建可以更新至稳定版本。持续安装更新，到四月份时你将与全新安装的用户处于相同的核心软件包集。

尽管这些是开发构建版，并不打算被安装或用作日常主力系统（即你信任用于关键任务的主要操作系统）。

有些人喜欢将它们作为主要系统并“驾驭”开发浪潮。

在可能的情况下，请将 Ubuntu 开发版本安装在第二个分区（或第二个磁盘，如果可能），并能访问另一个操作系统以备出现问题。你也可以在虚拟机中运行它们，但这有其自身的注意事项。

除非你有需要，否则不必急于下载。目前没有太多可看的内容；最初几个月涉及软件包同步、工具更新和底层管道。桌面上面向用户的变化要在几个月后才会到来。

获取 Ubuntu 27.04 每日构建

Ubuntu 27.04 每日构建可从 Ubuntu CD 镜像服务器下载。目前提供常规 Intel/AMD64 和 Intel/AMD-v3（又名 x86-64-v3）的 ISO。

“current”文件夹存放已通过一组（基本）自动化检查以确保安装和启动的镜像。

“pending”文件夹包含下一组待检查的镜像，但尚未签署通过。除非你知道其中有某个修复或变更。
