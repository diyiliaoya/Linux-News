DankMaterialShell 更名为 Dux Shell，Dank Linux 品牌重塑为 Dux Labs

Dank Linux 项目宣布全面品牌重塑，DankMaterialShell 更名为 Dux Shell，整个套件及项目本身统一采用 Dux 名称，并发布 DMS 2.0 版本。新版本包含 Material 3 Expressive 重新设计、插件系统、可自定义锁屏等，同时新增独立文件管理器 Dux。项目已迁移至新的 GitHub 组织 Dux Labs。

DankMaterialShell 更名为 Dux Shell，Dank Linux 品牌重塑为 Dux Labs

围绕 DankMaterialShell（DMS）构建的 Wayland 桌面套件已在 X 上以新名称发布，告别旧身份。与此同时，一个名为“DMS 2.0”的版本几小时前刚登陆 GitHub。

如果你还不了解，这个 shell 是一个 Quickshell 和 Go 项目，用于替代类似工具。围绕它还有迎宾器、日历应用、系统监视器和搜索服务。

它最初是一个业余项目，去年 12 月发布了 1.0 版本。此后，新版本增加了桌面小部件、新启动器和基于弹簧的动效等亮点。

随着套件中组件增多，项目现在将所有组件统一更名。品牌重塑覆盖整个套件。DMS 现在更名为 Dux Shell，迎宾器、搜索工具、系统监视器和日历分别更名为 Dux Greeter、Dux Search、Dux Monitor 和 Dux Calendar。Dank Linux 更名为 Dux Labs，这也成为整个项目及套件中每个应用的新名称。

Dux Files 是一个独立文件管理器，是唯一新增而非更名的组件。它提供标签页、分屏视图、回收站和网络共享等功能。如果 shell 正在运行，它会自动采用你的 DMS 主题。

Dux 是套件的吉祥物，名字呼应 Linux 的企鹅吉祥物 Tux。以 D 开头也让 dux 系列命令得以保留原名。

项目进行品牌重塑的理由是，围绕单一产品构建的名称已不再适合一个拥有独立应用集合和插件社区的套件。

另一点值得注意的是，早先的版本仍带有 Dank 名称，其路线图列出了独立文件浏览器和手机集成，但从未真正提及更名。

至于 DMS 2.0 版本，内容非常丰富，新增了 Material 3 Expressive 重新设计、仪表板和 dock 插件，以及可自行排列小部件的锁屏。还有 Dux Bar，一个自由浮动的栏伴侣或替代品，可转变为通知、天气、媒体和壁纸视图，以及控制中心、仪表板和启动器。

项目已从旧 GitHub 组织迁移至名为 Dux Labs 的新组织。你会找到许多曾以 Dank 名称闻名的仓库，包括 dux-shell（原 DankMaterialShell）、dux-gop（dgop）、dux-search（danksearch）、dux-calendar（dankcalendar）和 dux-greeter（dank-greeter）。

个人而言，我更喜欢 Dank 品牌。但如果开发者认为这是最佳方案且社区接受，那就没必要再讨论过去的事了。
