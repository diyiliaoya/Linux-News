Fedora 45 将为骁龙 X1 笔记本带来更流畅的体验

Fedora 45 计划于今年10月发布，将显著改善对高通骁龙 X1 笔记本的支持。得益于红帽资深工程师 Hans de Goede 的持续投入以及更多骁龙 X 支持进入主线内核，搭载骁龙 X1 的设备在使用 Fedora 45 AArch64 镜像时将获得更流畅的体验，不过部分硬件可能仍需少量变通方案。由于 Fedora 45 默认搭载 Linux 7.2 内核，骁龙 X2 的完善支持预计将在后续内核版本中逐步落地。

Fedora 45 将为骁龙 X1 笔记本带来更流畅的体验

2026年9月28日 下午12:07 EDT

去年红帽招募了其顶尖的 x86_64 Linux 笔记本专家之一 Hans de Goede，这确实对增强 Fedora Linux 对高通骁龙 X 硬件的支持产生了积极影响。

Hans de Goede 今年早些时候最初致力于为 Fedora 44 改善高通骁龙 X1 的体验。如今随着 Fedora 45 定于10月发布，骁龙 X1 的体验将更加完善。

由于更多高通骁龙 X 支持进入主线内核，以及 Hans 管理的各项发行版层面的改进，对于那些想用即将发布的 Fedora 45 AArch64 镜像尝试骁龙 X1 笔记本的用户来说，应该会获得“更加流畅的体验”。不过他指出，某些硬件可能仍需少量变通方案。

Hans 还在今天的发文中写道，虽然骁龙 X2 支持已开始进入主线内核，但 Fedora 45 开箱即用搭载 Linux 7.2 内核，意味着目前支持的重点仍是 X1 Plus/Elite 笔记本，X2 将在未来的内核版本中发挥更大作用。

如果在我用于测试的 Acer Swift 14 AI 笔记本（SF14-11T-X3RZ）上运行良好，我很快会进行一些骁龙 X1 上 Fedora 45 的基准测试，并与 Ubuntu AArch64 镜像进行对比。
