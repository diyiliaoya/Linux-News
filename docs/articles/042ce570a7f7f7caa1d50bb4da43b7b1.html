开发版发布：TUXEDO OS 20260813

总部位于德国的 Linux 台式机和笔记本电脑制造商 TUXEDO Computers 宣布发布其基于 Debian 的 TUXEDO OS 的首个公开测试版。虽然该发行版过去的版本基于 Ubuntu，但项目最近决定转向 Debian 的“Testing”分支，用于所有未来版本：“欢迎来到下一代 TUXEDO OS 的公开测试版。TUXEDO OS 正在迁移到一个新基础——Debian‘Testing’。通过这次公开测试，我们开放了开发过程，邀请您试用新系统，在真实场景中使用它，并帮助我们塑造最终版本。这不仅仅是关于发现崩溃或明显错误。我们想知道系统的使用感受。如果有任何让您感到惊讶、困惑、拖慢速度或行为不符合预期的地方，请告诉我们。TUXEDO OS 的未来版本将永久使用 Debian‘Testing’作为基础。我们将这种方法称为‘持续 Debian’。它使我们能够保持 TUXEDO OS 的混合发布模式，同时致力于更灵活且持续更新的基础。在日常使用中，TUXEDO OS 的许多方面将保持熟悉。系统继续使用 Debian 的软件包管理生态系统，并以 KDE Plasma 作为桌面环境。”更多信息请阅读完整公告。感兴趣的测试人员可以从这里下载此测试版：TUXEDO-OS-DEBIAN-202608131141.iso。（披露：TUXEDO Computers 是 DistroWatch.com 的赞助商之一。）
