开发版本：Ubuntu 26.10 Beta

Ubuntu 26.10 Beta（代号“Stonking Stingray”）发布，涵盖桌面、服务器、WSL和云产品，以及Edubuntu、Kubuntu、Lubuntu等十个衍生版本。该测试版集成了最新开源技术，引入新功能并修复了大量错误，供用户提前体验和测试。

开发版本：Ubuntu 26.10 Beta（DistroWatch.com 新闻）

Utkarsh Gupta 宣布了 Ubuntu 26.10 的测试版快照，代号为“Stonking Stingray”。

“Ubuntu 发布团队很高兴地宣布 Ubuntu 26.10 桌面、服务器、WSL 和云产品的 Beta 版本。Ubuntu 26.10，代号‘Stonking Stingray’，延续了 Ubuntu 引以为豪的传统，将最新最伟大的开源技术整合到一个高质量、易于使用的 Linux 发行版中。团队在整个周期中一直努力工作，引入新功能并修复错误。此 Beta 版本不仅包含 Ubuntu 桌面、服务器、WSL 和云产品的镜像，还包括 Edubuntu、Kubuntu、Lubuntu、Ubuntu Budgie、Ubuntu Cinnamon、UbuntuKylin、Ubuntu MATE、Ubuntu Studio、Ubuntu Unity 和 Xubuntu 这些风味版本。”
