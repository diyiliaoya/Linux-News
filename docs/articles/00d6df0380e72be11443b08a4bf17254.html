Ubuntu 26.10 切换至 Linux 7.3 内核

Ubuntu 26.10 原计划搭载 Linux 7.2 内核，但由于上游 Linux 7.1 和 7.2 开发周期未出现延迟，Canonical 内核团队重新评估后决定将目标内核提升至 Linux 7.3。目前该内核已进入 Ubuntu 26.10 的 proposed 仓库进行早期测试，并将在下周 Beta 版发布前推送至主归档。Ubuntu 26.10 正式版定于 10 月 15 日发布，内核冻结日期为 10 月 1 日。

Ubuntu 26.10 切换至 Linux 7.3 内核

2026 年 9 月 18 日 20:50 EDT。

令人非常惊喜的是，即将发布的版本现在将由 Linux 7.3 内核驱动，而非最初计划的 Linux 7.2 内核。

早在今年 5 月，Canonical 内核团队宣布 Ubuntu 26.10 将搭载 Linux 7.2，这是基于当时为在 Ubuntu Linux 十月更新中提供最新上游主要内核版本而制定的发布对齐计划。但今天，根据 Phoronix 读者邮件以及我在部分测试机器上执行 sudo apt dist-upgrade 的结果，Linux 7.3 现已出现，这是一个非常美妙的惊喜。

Linux 7.3 将为 Ubuntu 26.10 提供支持，而非 Linux 7.2。原来本月早些时候我错过了一则消息，他们宣布重新对齐至 Linux 7.3。由于 Linux 7.1 和 Linux 7.2 均未出现延迟，Canonical 内核团队对 Linux 7.3 而非 Linux 7.2 感到足够放心。

“继我们早前的公告之后，Canonical 内核团队重新评估了 Ubuntu 26.10（Stonking Stingray）版本的目标内核。得益于上游 Linux 开发日程在 7.1 和 7.2 发布周期中未出现延迟，并且 7.3-rc1 已经发布，我们很高兴地宣布我们正在提高目标：Ubuntu 26.10 现在将目标定为 Linux 7.3 内核，而非 7.2。这一更新使我们与最新的上游能力保持一致，特别是在最新硬件支持方面，同时仍能按计划推进即将到来的发布里程碑。团队目前正在基于 7.3-rc1 上游内核启用所有 Ubuntu 特定功能；它将很快在 -proposed 仓库中提供以供早期测试。”

考虑到 Linux 7.3 中的所有新功能和改进，这非常棒。

Linux 7.3 内核此前已在 Stonking Stingray 的 proposed 归档中，但现在正在下周 Beta 版发布前推送至 Ubuntu 26.10 “Stonking” 归档。

Ubuntu 26.10 计划于 10 月 15 日发布，内核冻结日期为 10 月 1 日。因此，在稳定版更新之前的官方 ISO 将最终处于预发布内核状态。如果 Linux 7.3 按时发布，将于 10 月 18 日推出；否则如果需要额外的候选版本，将推迟至 10 月 25 日。由于这不是 Ubuntu LTS 版本，他们正在积极追求最新的上游内核版本。
