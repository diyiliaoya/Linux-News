Linux 7.3 KSMBD 增加对 Apple Time Machine 备份的互操作性

Linux 7.3 内核中的 KSMBD（内核 SMB3/CIFS 服务器）新增了对 Apple Time Machine 备份的可选支持，通过实现 Apple 的 SMB2 扩展（如 Finder、流、COPYCHUNK 等），使 macOS 的 backupd 能够通过 SMB 协议将数据备份到 Linux 服务器。这些扩展未公开文档，需逆向工程实现，因此目前为可选功能。此外，KSMBD 还实现了 SMB2 命令序列窗口、SMB3 请求重放、每共享加密和 SMB Direct RDMA 加密支持。同时，Linux 7.3 的 CIFS/SMB3 客户端修复了 33 个问题，但无重大新功能，因维护者 Steve French 不幸去世，由 Paulo Alcantara 接任。

作为内核中的 SMB3/CIFS 服务器，KSMBD 相比用户空间的 SMB/CIFS 协议实现具有更高的性能和更低的资源占用，而随着开发中的 KSMBD 现在支持可选的 Apple Time Machine 集成，它变得更加有用。这使得通过 backupd 进行的 Apple Time Machine SMB 备份可以使用 Linux KSMBD 服务器来备份数据。这是因为 Apple Time Machine 依赖许多 Apple SMB 扩展，而此前 Linux KSMBD 并不支持这些扩展。

Apple 的“AAPL”SMB2 扩展包括 Finder、流、COPYCHUNK、稀疏文件、CHANGE_NOTIFY 和 RPC 兼容性位。通过 Gael Blivet 编写的代码，这些 Apple 扩展中已有足够多的部分被实现，以满足 Apple Time Machine 与 KSMBD 的对接。

这些 Apple 扩展没有公开文档，必须从客户端/服务器行为中逆向工程得出。因此，至少目前这项支持是可选启用的。

Linux 7.3 中的 KSMBD 还实现了 SMB2 命令序列窗口支持、SMB3 请求重放支持、每共享 SMB3 加密支持，以及 SMB Direct RDMA 加密支持。

关于这些新功能以及对这个 Linux 内核 SMB 服务器的许多修复的更多细节，请参阅相关链接。

与此同时，本周还合并了针对 Linux 7.3 的客户端更新。其中包含三十三个客户端修复。由于维护者 Steve French 不幸突然去世，Paulo Alcantara 接任后，没有安排重大功能变更。
