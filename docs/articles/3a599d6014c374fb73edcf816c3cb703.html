Intel 逆转取消其开源字体项目的决定

2026年9月12日上午09:45 EDT。

过去两年，Intel 因公司成本削减措施而缩减开源项目，其最新被列入裁撤名单的开源项目是几年前开发的一款独特字体。该项目本周被归档，但两天后便改变了方向。

Intel 陆续关停各种不再积极维护或相关员工已离职的开源项目。其中一些令人意外，比如一些开源 AI/LLM 项目受到影响，而另一些则无关紧要，比如其先前已停产的 Optane 内存的开源代码。令人意外的是，被归档后又恢复的，是他们的 One Mono 字体。

Intel 曾宣布为开发者创建一款新的开源字体。Intel One Mono 是一款富有表现力的等宽字体家族，注重清晰度、易读性，并“考虑到开发者的需求”。

起初看到 Intel 开发 One Mono 就有些令人意外，这家 CPU 厂商开发开源字体从未在我的预料之中。该字体自 2024 年中期以来没有新版本发布，在成本削减措施下被停产也不会让人感到意外。但如今令人惊讶的是，在本周被归档后，出于某种内部决定，它又被恢复，以继续维护该字体。

One Mono 的活动并不多，2025 年唯一的变更是 README 更新，最后一次真正的代码更改是在 2024 年 7 月。但如果你恰好是这款 Intel 字体的粉丝，它仍然存在，并可通过以下方式获取。
