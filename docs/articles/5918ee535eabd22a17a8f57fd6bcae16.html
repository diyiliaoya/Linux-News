为什么Ubuntu 26.04从24.04的升级被推迟（至9月）

Ubuntu 26.04 LTS的首个点版本发布后，用户仍无法直接从24.04升级，原因是Canonical需要回传几个修复，以解决rust-coreutils中的回归问题。升级通常不会随ISO发布而立即启用，LTS到LTS的升级需在首个点版本后才会正式开放。此次延迟预计至9月初，用户可耐心等待，或使用开发标志进行升级，但需注意风险。

为什么Ubuntu 26.04从24.04的升级被推迟（至9月） - OMG! Ubuntu

如果你想知道为什么尽管首个点版本已经发布，你仍然无法直接从24.04升级到Ubuntu 26.04，Canonical的Oliver Reiche在Ubuntu 26.04.1 LTS的邮件列表公告中表示，升级将推迟几周，以便让几个回传更新落地。这些更新将“解决最近版本rust-coreutils中的回归问题”。

Ubuntu 25.10的用户不受此影响；

与针对固定发布日期发布的ISO不同，升级没有固定的发布日期。当ISO发布时，并不意味着升级会立即启用——这会让一些用户感到困惑。对于LTS到LTS的升级，这种困惑更是加倍，因为它们只在首个点版本发布后才正式启用。

这种额外的等待是因为，一次性处理两年的软件包变更，没有两个系统是完全相同的，而且LTS版本注重稳定性，因此需要进行更多的测试，并发现边缘情况下的错误。

全新安装可以跳过所有这些。

直接升级必须大规模迁移数千个相互关联的软件包、依赖链等。修复可能需要落在基础LTS版本或正在升级到的版本中。这可能需要时间——前面提到的rust-coreutils回归就是一个很好的例子！

保持冷静，停止刷新

所以，事情就是这样；你可以减少每小时刷新页面的频率，放松一下手指，不用再频繁运行`sudo do-release-upgrade -c`。你将在9月初能够升级，所以请耐心等待。

如果你不想等待，你可以使用命令行从24.04升级到26.04，但由于升级路径尚未正式启用，你需要传递开发标志，并注意可能的风险：

sudo do-release-upgrade -d
