Cloudflare 开源 Kitesurf：专为 AI 代理打造的网页浏览器

2026 年 11 月 13 日 下午 04:07 EST。

今年早些时候，Cloudflare 宣布推出 Kitesurf，一款面向 AI 代理的无状态网页浏览器。在完善其功能后，他们如今兑现了将其开源的承诺。

Kitesurf 现以 Apache 2.0 许可证开源，这款浏览器专为代理构建。Kitesurf 构建于 Cloudflare Workers 之上，无需浏览器容器即可解析 HTML、处理 CSS 并执行 JavaScript。

关于 Cloudflare 对 Kitesurf 的明确动机：

“我们的主要目标是给 AI 代理一个轻量、高效的浏览器——它能够加载网站、执行 JavaScript 并与页面交互，同时比 Chromium 这样的完整浏览器使用更少的 CPU 和内存，并能在 Cloudflare 的全球 Workers 网络上按需扩展。”
