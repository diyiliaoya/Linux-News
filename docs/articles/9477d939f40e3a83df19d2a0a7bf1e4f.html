OPI Abstraction v0.1 发布，旨在标准化 DPU/IPU 生态系统

2026 年 7 月 30 日，美国东部时间下午 1:05。

Linux 基金会主办的开放可编程基础设施（OPI）项目宣布了其首个协调版本 OPI Abstraction v0.1。开放可编程基础设施的工作旨在标准化数据处理单元（DPU）和基础设施处理单元（IPU）生态系统。

开放可编程基础设施抽象 v0.1 是使 IPU 和 DPU 基础设施更易于消费、集成和扩展的第一步。它包含一个跨 26 个存储库的厂商中立 API 层。

开放可编程基础设施的初始重点围绕 Kubernetes 网络功能卸载蓝图，这是由 Nginx、Intel 和 Red Hat 开发的生产级部署模式。
