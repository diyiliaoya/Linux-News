Ubuntu 26.10 Beta 版发布，搭载 Linux 7.3 与 GNOME 51

Ubuntu 26.10 的 Beta 版现已开放下载——比原计划晚了一周。

Ubuntu 26.10 Beta 运行在 Linux 7.3 内核（候选版本）之上，并搭载了 GNOME 51。底层变化包括完整的 Rust 核心工具集以及对低内存情况的更好处理。

Beta 版本并非最终或稳定版本，但通常比早期的快照更可靠。用户和开发者都可以测试新版本并报告发现的任何错误，以便修复能及时赶上 Ubuntu 26.10 最终稳定版的发布，该版本将于 2026 年 10 月 15 日推出。

Ubuntu 26.10 有什么新功能？

GNOME 51 获得布局选择器

GNOME 51 版本带来了 Ubuntu 26.10 大部分面向用户的更改。除其他内容外，它引入了一个新的辅助功能设置，可调低大多数 UI 动画，使指纹注册更容易，并重新调整了系统信息面板。

窗口吸附也变得更加容易。

——预装的 GNOME Shell 扩展之一——获得了 Windows 风格的布局选择器。拖动窗口时，屏幕顶部会滑入一个小框，显示布局选项。将窗口放到你想要使用的布局上即可。

桌面图标扩展

DING 已移植到 GTK4。视觉元素（上下文菜单、对话框等）现在与桌面其余部分保持一致。添加了键盘快捷键，剪贴板处理也改为异步。

Papers（前端）获得新能力

默认应用得到改进。你现在可以在 PDF 文档中添加手写签名，在系统监视器中查看文件堆叠数量，在拖动多张图片时也能看到。

Mutter，GNOME 的底层合成器，修订了帧时钟的估算方式。这应该意味着 UI 动画期间丢帧更少，从而带来更流畅的整体桌面体验。

登录选项登场

登录和锁屏界面新增了对 FIDO2/通行密钥和基于 Web 的登录（二维码或 URL）的支持， alongside 现有的智能卡支持。这将使企业或受管理设置的用户受益。

自 26.04 以来，在 Ubuntu 中启用第三方驱动变得更加棘手，因此开发者已开始将硬件驱动管理集成到附加组件中。

“附加驱动”部分仅出现在需要 Ubuntu 档案库中打包的闭源驱动的设备上。如果你完全看不到它，那不是错误——你的硬件正在使用可用的最佳驱动。

有一项你不会在系统中找到的是 Myna，Ubuntu 的本地 AI 听写工具，因为它正在积极开发中。如果你想尝试，所有组件都已可用——如果你有兴趣看看它能做什么，请查看我关于如何在 Ubuntu 上安装 Myna 的指南。

后端与底层

基于坚实核心构建

Ubuntu 26.10 Beta 运行在 Linux 7.3 内核上——该版本仍在开发中，预计要到 10 月 15 日之后才会发布稳定版。

Linux 7.3 的亮点包括为 EXT4 精简的多块分配器，使大文件下载期间的文件空间预分配更快；FUSE 零拷贝缓冲区池；以及一个 KSM 修复，可减少重内存负载下的 UI 微卡顿。

Mesa 26.2 GPU 驱动相比 Ubuntu 26.04 LTS 中的 26.0.x 系列有所提升，NVK 中支持网格着色器，AMD 用户通过 RADV 获得低延迟 Vulkan 视频编解码，Vulkan 描述符堆支持默认启用。

改变了低内存情况的处理方式

以更好地保护桌面会话不被 OOM 守护进程“终止”。核心桌面进程被赋予更低的 OOM 分数，因此理想情况下，桌面应用会首先被终止。
