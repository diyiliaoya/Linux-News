AMD 开始为配备 GDDR7 的显卡准备开源 Linux 驱动

AMD 发布了最新的 Linux 内核图形驱动补丁，开始为 GDDR7 显存提供支持，并添加了 GDDR7 标识符。这些补丁还涉及中断处理程序的新 IP 块和最新版 New Bus InterFace，可能对应下一代 RDNA5 显卡。此举延续了 AMD 在开源 GPU 驱动上的提前布局，预计 RDNA5 显卡将在 2027 至 2028 年推出。

AMD 今天发布了最新的 Linux 内核图形驱动补丁，以启用一些新的硬件 IP 块。作为其中的一部分，AMD 正在为 AMDGPU 驱动准备 GDDR7 显存支持。

有传言称，下一代 AMD RDNA5 显卡将配备 GDDR7 显存。当前一代 AMD RDNA4 显卡依赖 GDDR6，而 NVIDIA GeForce RTX 50 桌面显卡则使用 GDDR7。RDNA5 使用 GDDR7 并不令人意外，也在情理之中。

作为明确围绕 GDDR7 的工作，今天发出的补丁添加了“GDDR7”标识符作为显存名称。这同样并不意外，只是确认了相关事项，并且现在将这些新的和近期的 AMDGPU 驱动补丁与可能属于 RDNA5 的 IP 块联系了起来。

今天还发布了新的补丁，用于启用中断处理程序的 IP 块，以及最新版本的 New Bus InterFace。此外还发布了其他几个较小的补丁，为新 IP 做了更多常规性的准备工作。

这延续了近期其他补丁的工作，例如引入 Display Core Next 6（DCN6）和其他 GFX 13.0.x 相关工作。

很高兴看到 AMD 面向消费级 GPU 的开源 GPU 启用工作远早于产品发布。近期传言称，由于持续的行业供应限制，RDNA5 可能在 2027 年推出有限的 SKU，而其他 SKU 可能要到 2028 年才会推出。无论如何，希望到那时上游开源 Linux 内核驱动已经准备就绪，并为这些 GPU 做好充分准备。
