Gravity Linux 旨在为 Apple M4 及更新机型提供良好体验

2026年9月21日下午3:58 EDT。

有一个新的 Linux 发行版专注于支持 Apple Silicon Mac 上的 Linux。Gravity Linux 是这个新发行版，它是 Fedora Remix 的一个衍生版，面向仍处于实验性支持阶段的 Apple M4 Mac 及更新机型。除了利用 Asahi Linux 代码和逆向工程外，Gravity Linux 还借助 OpenAI Codex 和 Claude Code。

Gravity Linux Early Alpha 现已作为该项目的首个版本发布，最初面向 Apple M4 Mac Mini。它还包括实验性的 OpenGL 3.3 / OpenGL ES 3.0 支持，带 GPU 加速，并运行 KDE Plasma 桌面与 Wayland。

虽然 Mac Mini M4 的一些功能已经可用，但有一系列硬件功能已知目前不受支持：

“以下功能已知无法工作：挂起、USB-C 端口上的显示输出（HDMI 可用）以及 Thunderbolt/USB4。此外，功耗可能高于预期（对台式机而言不太相关）；出于安全原因，我们为最大扬声器音量设置了保守限制；关机/重启不稳定（不过你随时可以使用电源按钮）。此处未列出的所有功能均可正常工作并已通过测试。”

此版本仅适用于 M4 Mac Mini，接下来他们希望支持其他 M4 / M4 Pro / M4 Max 设备，并且也在关注 MacBook Neo。

他们希望最终他们的所有工作都能进入上游 Linux 内核。希望了解更多信息的人可以通过 GravityLinux.org 的公告了解。

尽管他们指出在开发此 M4 Linux 支持时只进行了净室逆向工程，但他们正在利用 OpenAI Codex（GPT-6 Astra）和 Claude Code（Claude Fable 5.1）作为工作的一部分。查看 gravity-m4 Git 分支可以看到近期由 OpenAI Codex 和 Claude Code 大语言模型协助的活动。
