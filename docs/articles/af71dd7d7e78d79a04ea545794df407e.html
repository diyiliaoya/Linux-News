Ubuntu 的长期支持（LTS）版本至少支持 5 年。在前 3 年期间，会定期发布“点版本”。这些版本刷新安装镜像（ISO），以便新用户无需在安装后下载长达 3 年的更新。

因此，Ubuntu 24.04 LTS 将继续获得持续支持，直到 2029 年 4 月。此后，通过 Ubuntu Pro 再提供 5 年的安全覆盖（用户可免费注册并启用）。

Ubuntu 24.04 用户可在本月晚些时候正式升级到 Ubuntu 26.04 LTS。
