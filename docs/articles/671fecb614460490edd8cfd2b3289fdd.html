发行版发布：ML4W OS 2.17

ML4W OS 2.17 发布，这是一个基于 Arch Linux、搭载定制 Hyprland 平铺窗口管理器的发行版。新版本引入壁纸轮播功能，可通过 SUPER+W 或壁纸选择器中的新按钮打开；窗口浮动切换现在会将浮动窗口以 16px 间距网格排列；侧边栏新增“窗口模式”开关；默认应用仅在初始安装时安装，更新时不再重复安装，便于安全替换；音量图标新增静音切换，状态栏音量模块新增音频输出菜单。

发行版发布：ML4W OS 2.17（DistroWatch.com 新闻）

Stephan Raabe 发布了 ML4W OS 2.17，这是该项目基于 Arch 的 Linux 发行版的更新版本，搭载定制的 Hyprland 平铺窗口管理器：“版本 2.17：新增壁纸轮播，作为壁纸选择器的现代替代方案，可通过 SUPER + W 或壁纸选择器搜索框左侧的新按钮打开；切换工作区所有窗口的浮动状态（SUPER + SHIFT + T）现在会将浮动窗口以 16px 间距网格排列在显示器的空闲区域内（尊重状态栏和 dock），而不是保持其平铺或全屏尺寸；侧边栏新增‘窗口模式’开关，用于选择窗口模式——关闭使用平铺（默认），开启使用浮动；安装程序中列出的软件包（packages、packages 默认应用——Kitty、Neovim、Nautilus、GNOME 文本编辑器、Firefox）仅在初始安装时安装，更新时不会安装，这样可以安全替换选定的默认应用，例如卸载 Firefox 并切换到其他浏览器后，更新不会再次安装它；侧边栏音量图标新增静音切换；状态栏音量模块新增音频输出菜单……”

完整变更列表请见 GitHub。

发行版发布：ML4W OS 2.12.0

ML4W OS 是一个基于 Arch Linux 的发行版，搭载深度定制的 Hyprland 平铺合成器。该项目主要专注于为 Hyprland 创建高级配置，即所谓的“dotfiles”，这些配置可安装在其他多个基于 Arch 的发行版以及 Fedora 和 openSUSE 上。然而，ML4W OS 的 live ISO 镜像是一个独立、功能完整的 Linux 发行版，包含所有 Hyprland 配置文件、应用程序、图标、主题和壁纸。它可以使用自定义的文本模式系统安装程序安装到硬盘上。
