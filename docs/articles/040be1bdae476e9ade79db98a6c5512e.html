AMD PMF 测试工具计划用于 Linux 7.3

2026年7月27日下午5:28 EDT。

即将被添加到 Linux 内核源码树以用于即将到来的 Linux 7.3 周期的，是 test_amd_pmf，一个用于测试 AMD 平台管理框架（PMF）接口并转储各种系统数据点的小型测试应用程序。

AMD PMF 测试工具“test_amd_pmf”计划驻留在 Linux 内核源码树内，它只是一个类似于 Turbostat 和其他内核源码树内应用的小型用户空间应用程序。Test_amd_pmf 读取 /dev/amdpmf_interface 并打印各种指标，用于测试和分析目的。

这个小工具将报告诸如检测到的电源来源、AMD Ryzen 笔记本电脑的表面温度、电池状态、自定义 BIOS 输入/输出、确定的笔记本电脑放置位置、盖子状态、是否检测到用户在场或离开笔记本电脑、性能滑块位置、环境光、平均/最大 C0 驻留时间、插槽功耗以及其他参数。

主要用于测试目的，或对于那些好奇不同 AMD PMF 功能在热/功耗特性或用户存在检测等功能上表现如何的人。

已进入 platform-drivers-x86.git 的“for-next”Git 分支，距离 Linux 7.3 合并窗口还有几周时间。
