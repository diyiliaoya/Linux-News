XWayland 26.1 RC2 发布测试，带来更多修复

XWayland 26.1 第二个候选版本 RC2 现已发布，包含多项 XKB 修复、损坏跟踪改进、X Input 字节交换调整等。该版本是自 2024 年 XWayland 24.1 以来首个重要更新，提供更好的 rootful 实现、多席位兼容性、新 Wayland 协议支持及 RandR 模拟改进，并移除了 EGLStream 支持。

在上个月 XWayland 26.1 首个候选版本发布并带来众多新功能之后，第二个候选版本现已推出，包含大量修复。

XWayland 26.1 正蓄势成为一次重大发布，这是自 2024 年 XWayland 24.1 首次亮相以来首个被标记的重要更新。XWayland 26.1 提供了更好的 rootful 实现、与 X Input 2 的多席位兼容性、对新 Wayland 协议的支持、更好的 Resize and Rotate（“RandR”）模拟，以及许多其他改进。它还移除了对 EGLStream 的支持。

在今天的 XWayland 26.1 RC2 版本中，包含了多项 XKB 修复、损坏跟踪改进、X Input 的字节交换更改，以及为本候选版本贡献补丁的三位开发者带来的其他修复。

有关 XWayland 26.1 RC2 版本的下载和更多详细信息，请访问 xorg 邮件列表。

X.Org Server 26.1 也正在向发布迈进，这将是自 xorg-server 21.1 稳定系列首次亮相以来更大的一次更新。
