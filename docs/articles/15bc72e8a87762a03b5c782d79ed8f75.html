为你的Ubuntu桌面添加多个图片小部件

本文介绍了一款名为“Picture Desktop Widget Remake”的GNOME Shell扩展，它是对原有桌面图片小部件的改进版，允许用户在Ubuntu桌面上添加多个图片小部件，并为每个小部件分配不同的图片文件夹，支持随机显示。用户可单独调整每个小部件的大小、位置、圆角半径和宽高比，并可通过开关隐藏而不删除。尽管该扩展存在一些缺陷，如编辑时图片显示错误、无法拖拽移动位置等，但整体功能可用，且支持GNOME 46至50版本。

去年我写过关于GNOME桌面图片小部件的文章，但发现它对于个性化偏好来说有点过于基础，你并不是唯一这么觉得的人。

另一位用户认为它缺乏足够的灵活性，因此对其进行了分叉和改进。

Picture Desktop Widget Remake

改进了原始版本。它允许你在Ubuntu桌面上添加多个图片小部件，并为每个小部件分配不同的文件夹来随机拉取图片。

此外，你可以单独设置每个小部件的大小、位置、圆角半径和宽高比。每个相框在设置中都有自己的开关按钮，因此你可以隐藏它而不必完全删除。

单个小部件的偏好设置（不清楚窗口标题）

自2009年以来，我一直痴迷于桌面杂物——时钟、Conky脚本、正在播放的音乐控制器，我喜欢那些东西。但问题是：我很少在桌面上最大化应用窗口，所以桌面上总是空荡荡的——为什么不放些照片呢？

尝试过之后，我可以报告说它确实能用，但存在一些怪癖。

在编辑新小部件时，现有小部件经常显示相同的图片（尽管为它们分配了不同的文件夹）。让它们从各自的图片池中显示正确图片的唯一方法是关闭整个扩展再重新打开。

你也不能设置单张图片或禁用刷新（也许是个边缘情况）。此外，在调整宽高比时，也没有办法设置相框如何约束图片。这很烦人，因为较高和较宽的相框经常尴尬地裁剪图片。

然而，最大的问题是，你不能在桌面上拖动这些可爱的小图片小部件来重新定位它们（不，即使禁用Ubuntu的“桌面图标”也不行）。你必须手动定位每一个：

将它们拖到合适位置会更容易

尽管如此，它还是能完成它的任务（大多数时候）。我没有注意到启用它后内存使用量大幅增加，但据我所知，无法判断单个GNOME Shell扩展使用了多少内存，所以你的情况可能会有所不同。

如果这些没有让你望而却步，并且你希望像祖父母的壁炉架一样装饰你的工作区，你可以在GNOME Shell扩展网站上找到Picture Desktop Widget Remake，或者从GitHub获取源代码。

它支持GNOME 46（Ubuntu 24.04）到50（Ubuntu 26.04）。
