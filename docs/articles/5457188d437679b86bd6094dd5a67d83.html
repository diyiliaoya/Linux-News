OpenUK 希望英国停止免费赠予开源成果

OpenUK 发布报告，呼吁英国政府建立自己的开源基金会，以持有代码、治理权和标准，防止英国公共资金资助的开源项目流失到美国等其他国家。报告以 MCP（模型上下文协议）为例，该协议由伦敦工程师创建，最终却归入美国基金会治理。OpenUK 认为这是资金和治理缺口，而非技术问题，并指出德国、中国已有成功先例。

他们指出 MCP（模型上下文协议）——由伦敦两名工程师构建——最终却归入美国主导的治理之下。

OpenUK 近期发布了其报告，在这份 40 页的文件中，隐藏着一个对英国政府的重大请求：建立属于英国自己的基金会，以持有代码、治理权和标准，方式如同 Linux 基金会。

如果你第一次听到这个名字，OpenUK 是一个倡导开放技术的非营利组织，由……领导。他们最初是在提交给……的《让英国成为开源之家》中发出这一呼吁的。

《AI 开放度》报告此次以更紧迫的口吻重申了这一主张。

OpenUK 将提议的英国版 Linux 基金会描述为一个“……”，一旦成立，该机构将持有用英国公共资金构建的代码库、标准和数据集，而不是看着这些成果迁移到位于其他国家的服务器和治理委员会。

它还将负责培训、社区参与和活动组织。这些领域原本需要单独的基础设施，比如开源项目办公室。

OpenUK 将此视为资金和治理缺口，而非技术问题。

他们指出，英国在开源软件和 AI 开放度方面位列欧洲第一，却没有与 Linux 基金会、德国的“主权技术机构”相当的组织。

英国正在流失开源成果。

这家非营利组织无需费力就能证明其观点，因为 MCP 是其最强有力的例证。

模型上下文协议（MCP）——如今已成为 AI 模型连接外部工具和数据背后的标准——由伦敦的两名工程师创建。

Anthropic 支持了该协议，并最终将其捐赠给了 Linux 基金会的“智能体 AI 基金会”，一同捐赠的还有 Block 的 Goose 和 OpenAI 的……

在与 OpenUK 的对话中，MCP 的联合创始人之一表示，他们之所以免费赠予 MCP，是因为需要该标准保持供应商中立，避免商标和许可风险。

如果英国有一个成熟的基金会，那么他们就不会把 MCP 拱手让给美国。

欧盟委员会已经展示了一项倡议，旨在通过迈向开放的欧洲数字生态系统，摆脱美国的技术主导。该倡议将涵盖云计算、人工智能、网络安全、开放硬件、互联网技术以及汽车和制造等工业应用领域。

德国更接近 OpenUK 为英国所设想的目标。其……已转变为一个政府机构，报告称其为“……”。

中国已经证明了这种模式行之有效。开源在其……下成为国家支柱，并由一个名为……的专门基金会提供支持。

DeepSeek 的 R1 展示了这种专注如何带来回报，它利用开放权重和知识蒸馏，以极低的成本提供了前沿水平的 AI。

OpenUK 希望吸引英国各公共部门组织的兴趣，同时旨在与全球专家合作，最终为国家提供最佳方案。
