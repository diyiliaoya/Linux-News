红帽的 Lightwell 不等待上游维护者行动

红帽的 Lightwell 项目针对企业开源安全中上游维护者未修补的漏洞，通过直接向后移植修复来绕过等待时间。目前已清除 Java 库中 400 个漏洞，并宣布 Clearinghouse Premier 服务正式可用，向所有企业开放。该服务提供定制化漏洞管理和早期通知，是 IBM 和红帽 50 亿美元开源安全承诺的一部分。

一份状态更新显示，它清除了 Java 库中的 400 个漏洞，并且一项关键服务现已正式可用。

这是红帽和 IBM 针对企业开源安全中一个特定问题的回应。漏洞存在于生产库版本中，而上游维护者尚未修补，在某些情况下也不会修补。

据数据显示，超过 90% 的企业应用程序代码可追溯到开源或第三方库，而典型的企业代码库包含超过 500 个已知漏洞。

他们表示，针对已知漏洞的攻击平均在补丁存在前一周就会到来。

Lightwell 的方法是绕过这个时间线。它不等待上游维护者将修复推送到企业实际运行的库版本，而是直接向后移植这些修复，通过安全的软件包仓库交付。

红帽最近联系我们，分享了其进展。

已清除 400 个，还有更多

迄今为止，Lightwell 已经成功清除了基础 Java 库中 400 个先前未知的漏洞，超越了已报告的漏洞，并按照负责任的披露协议向上游贡献修复。

到目前为止，主要目标是那些运行 Java 环境且依赖版本被固定、无法安全更新的组织。Lightwell 就地修补这些漏洞，保持固定版本不变。

路线图上还包括扩展到 Java 之外。每个都将遵循相同的方法，将修复向后移植到已投入生产的版本，并将适用的补丁贡献给上游。

Clearinghouse 开放

Clearinghouse Premier 此前一直在限制性条款下运营。在今天之前，它仅面向关键基础设施领域预先选定的组织群体。

这一限制现已解除，因为它已达到正式可用状态，这意味着任何企业都可以直接注册 Clearinghouse，无需等待基础设施指定来清除访问权限。

如你所见，Lightwell 分为两个访问层级。Clearinghouse 于 7 月正式可用，作为面向任何组织的自助订阅服务。它提供对向后移植补丁及其合规文档的访问。

Clearinghouse Premier 提供的服务更加定制化。组织可以指定哪些漏洞对其环境最重要，在问题公开前获得早期通知，并确切知道修复何时到达。

总体而言，Lightwell 属于 IBM 和红帽对开源安全的 50 亿美元承诺的一部分，两家公司都指出 AI 辅助工具提高了较旧、未修补的开源依赖的风险。

这一立场得到红帽 Lightwell 副总裁兼总经理的进一步强化，他表示：

AI 代理在一夜之间改变了威胁格局，以机器速度利用旧依赖。它们不在乎代码库是十年前的还是被认为稳定的，因为一个小裂缝就足以串联起一次攻击。

如果你对所提供的内容感兴趣，可以通过红帽的网站进一步了解，它将引导你完成修补工作流程。
