NetBSD 11.0 发布，支持 RISC-V，增强 Linux 系统调用兼容性

2026年8月1日，美国东部时间下午12:49。

今天正式发布，这是这个流行的 BSD 操作系统的第十九个主要版本。

NetBSD 11.0 是该项目的首个支持 64 位 RISC-V 架构的版本，并在基于 StarFive JH71XX 的平台（如 VisionFive 2 和 STAR64）上提供了初始硬件支持。NetBSD 11.0 也支持在 QEMU 上运行 RISC-V。此外，NetBSD 还支持 AMD64、ARM、SPARC64、MIPS 以及许多其他架构。

在 Arm 方面，NetBSD 11.0 对 Qualcomm Snapdragon X1 Elite 硬件提供了初步支持，包括 Oryon CPU 核心和其他硬件启用工作。

NetBSD 11.0 还更好地支持 POSIX.1-2024 和 C23 标准，通过其“compat_linux”代码增强了与各种 Linux 系统调用的兼容性，为 x86/amd64 提供了新的 MICROVM 内核，以实现极快的虚拟机启动，以及一个 virt68k 端口，用于在 QEMU 中使用半虚拟化设备运行 Motorola 68000 端口。

NetBSD 11.0 还带来了一些新的 Intel 和 AMD 驱动程序，AArch64 上的 SIMD 加速 X.Org Server 优化，各种内核优化，以及其他全面的硬件启用。
