Wine 11.18 持续推进其 NTOSKRNL 实现

发布于 2026 年 9 月 18 日下午 05:24（美国东部时间）。

Wine 11.18 于今日发布，这是这款用于在 Linux、macOS 及其他平台上运行 Windows 游戏和应用程序的开源软件的最新双周开发版本。

在 Wine 11.18 中，大量补丁被合入，以进一步构建其面向内核驱动的 NTOSKRNL 实现支持。NTOSKRNL 是 Microsoft Windows 操作系统的主要内核可执行文件，是内核层与执行层的核心。NTOSKRNL 负责硬件抽象、进程处理、内存管理及相关基础功能。

在 Wine 11.18 中，围绕 NTOSKRNL 的工作涉及 PnP 设备启用、容器 ID，以及实现多种必要函数。Wine NTOSKRNL 代码的测试覆盖也在同步跟进。

Wine 11.18 还包含多种代码正确性修复、标准 C 头文件中的兼容性修复，以及 21 个已知错误修复。本次发布的错误修复范围从 Adobe Creative Cloud 的修复到《刺客信条：叛变》等游戏的修复。
