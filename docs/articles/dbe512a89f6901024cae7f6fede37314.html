Claude artifacts 现可作为桌面应用安装（Linux 除外）

Claude 现在允许用户将聊天中创建的小型交互工具（artifacts）作为独立桌面应用安装。这些应用拥有独立窗口和图标，可发送桌面通知、注册快捷键并添加面板小程序，还能获得完整系统权限。该功能处于测试阶段，面向 Windows 和 macOS 用户开放，但 Linux 平台暂不支持。

Claude 现在允许用户将 LLM 在聊天中创建的小型交互工具（即 artifacts）作为独立（近似）桌面应用安装。

通过“安装为应用”添加后，artifacts 会在自己的窗口中运行，并拥有自己的图标。它们还可以发送桌面通知、注册键盘快捷键，并向面板添加小程序。应用可获得完整的系统权限，从而读取、编辑和删除文件。

这项新功能处于测试阶段，但面向所有套餐（包括免费套餐）的用户开放，适用于最新版本的 Claude 桌面应用（Windows 和 macOS，截至 2026 年 11 月 24 日）。

然而，该功能在 Linux 上不可用，相关说明指出 Linux 在发布时不受支持。这可能意味着永远不支持，也可能意味着未来会支持。其他 Claude 功能也曾如此。我相信主流 Linux 发行版之间有足够的底层共性来支持它们。

即便如此，现阶段 Linux 支持并非板上钉钉。

Claude 桌面应用展示

为了演示这些应用能做什么，提供了一组演示应用（通过一个烦人又酷炫的模拟桌面访问，如上图所示）。

这些应用中包括一个功能齐全的多层图像编辑器，名为……一个终端（使用底层系统 shell）和一个文件管理器，据说看起来像是“为电影布景而造”（也许是低预算的那种）。

还有一个磁盘使用分析器和系统监视器、一个房间规划器、一个冥想园艺模拟器，以及一个待办事项应用，它本该做更多（明白吗）来脱颖而出。

是一个人体图谱，给我一种 2000 年代教育 CD-ROM 附赠品的感觉。我确实觉得用于检查太空垃圾的交互式地图很鼓舞人心——

“Claude，重做这个应用，但绘制感染率……”

这些应用都独立于主 Claude 桌面工具运行，但离开它就无法使用。它们也无法在不登录 Claude 账户的情况下使用，或离线工作。这些应用可以与他人共享，前提是他们也使用 Claude 并拥有账户。

听起来像围墙花园？但愿如此。

我不介意奇思妙想软件被限制在专有孤岛中。话说回来，我厌倦了 AI 代理每天给我发邮件，谈论某人的最新 GitHub 废话，其实际功能被层层溢美之词（外加订阅费）所掩盖。

但这确实印证了那个常被提及的理论：AI 公司会逐渐让我们依赖租用访问权，而“计算”的概念将日益受限。
