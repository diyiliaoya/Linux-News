Sprout Pi 让旧 iPod 运行 Linux 应用并串流 Spotify

Sprout Pi 是一个开源硬件项目，为旧 iPod 提供无需焊接的现代主板替换方案，保留原屏幕、点击轮和外壳，新增 Wi-Fi、蓝牙、USB-C DAC 及 Spotify 串流和 AirPlay/Google Cast 支持。项目提供两个版本，其中 Pi 版搭载树莓派 CM0 运行 Linux 应用，并保留经典 iPod 界面。

Sprout Pi 让旧 iPod 运行 Linux 应用并串流 Spotify - OMG! Ubuntu

一个新的硬件项目正在利用开源硬件和软件，为几十年前的 iPod 添加 Wi-Fi、蓝牙和音乐串流应用。

该项目由伦敦的 FOSS 人士开发，是“旧 iPod 的现代主板”，无需焊接。它甚至复用了 iPod 的所有原始部件，包括屏幕、点击轮和外壳。

其理念很简单：打开旧 iPod，移除原主板，换上新的主板，从而增加对蓝牙耳机（包括 Apple AirPods）、Wi-Fi 以及通过 USB-C 传输音频的 HiFi DAC 的支持。

图片：Certain Things

它甚至支持从 Spotify 串流音乐，以及通过 Apple AirPlay 和 Google Cast 从设备投送。

开源 iPod 软件修改并不新鲜——Rockbox 已经存在了几十年——但硬件修改通常是剧烈的或需要技术技能。这看起来很简单，而且升级是可逆的——我相信这对技术纯粹主义者来说是一种解脱！

Sprout 将提供兼容以下 iPod 型号的主板：

iPod mini 第一代和第二代

iPod 的存储焊接在主板上（通过这次替换被换掉），因此使用 microSD 卡作为存储，让你积满灰尘的旧 20GB iPod 容量提升 100 倍。

Sprout 将有两个版本：Sprout（基础版）和 Sprout Pi，后者将微控制器与 Raspberry Pi Compute Module Zero 配对。

开发者将后者描述为使用双架构，播放使用 RP2350 以获得更好的电池寿命，而资源密集型应用，如 3D 游戏甚至操作系统模拟器，则在运行基于 Linux 系统的 CM0 上运行。

iPod 是目的明确的设备，Sprout 的 UI 保留了标志性且易于使用的 iPod 界面，导航由点击轮和菜单按键驱动。

贴心的时代唤起细节包括 Coverflow、更好的播客 UI、用于配置硬件功能的 AirPods 应用。甚至还有旧 iPod 游戏的重制版（我在公交车后座输在 Vortex 上的那些小时）。

苹果尚未批准此项目，而且 Sprout 的 UI 所回应的某些界面元素可能正有专利在积累，尘封在大多数这款产品所针对的 iPod 所在的同款抽屉里。

在我看来，UI 足够接近以感觉正确，但又足够不同，不是一个毫无价值的克隆。
