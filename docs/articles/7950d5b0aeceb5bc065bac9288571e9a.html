Linux 7.2 发布：更快的 I/O、新的 AMD 与 Intel 驱动改进

2026年8月16日晚上7:12（美国东部时间）

Linus Torvalds 刚刚发布了 Linux 7.2 稳定版！在经历了因 AI/LLM 时代带来的补丁和报告量激增而异常繁忙的内核周期后，Linux 7.2 今天按计划顺利发布，这是一个功能丰富的内核。Linux 7.2 将为 Ubuntu 26.10 及其他即将发布的 Linux 发行版提供支持。

Linux 7.2 带来了许多新特性，包括缓存感知调度（Cache Aware Scheduling）、Intel 开发的 USB4STREAM 协议、多项 Intel 和 AMD 硬件驱动改进，以及 AMDGPU HDMI 2.1 FRL 等优秀功能。

在性能方面，Linux 7.2 为系统带来了显著的 I/O 性能改进。此外，Intel Arc B390 图形性能也有所提升，轮询（poll）性能更快。

在 Linux 7.2 开发周期的最后一周，有一些最后一刻的声卡设备 quirk/新增，回退到 DRM FIFO 调度器（因为新的“公平”默认策略导致了性能回退），并在今天合并了新的 tlbi=ipi 启动选项。此外还有许多其他小的 bug/回退修复。

Linus Torvalds 在发布公告中写道：“嗯，这个发布的最后一周——再次——比我预期的要大，但嘿，在‘新常态’下，如果我因为这个原因推迟发布，我们可能永远不会有发布。有一些相当晚的回退——DRM 调度器的回退很突出，但这里还有其他一些。这可能不漂亮，但这是处理‘哦，那段代码还没准备好并导致了问题’的正确方式。人们以后会再试的。

但虽然 DRM 回退很突出，并且是这里一些较大的补丁，但到处都有很多小的修复。主要在驱动中，但网络在上周也保持相当活跃。然后还有一些随机的架构文件和 perf 核心补丁。

这样，7.3 的合并窗口明天显然会打开，我已经有 40 个待处理的拉取请求。我感谢所有及时的人。你们知道你们是谁。”

Linux 7.3 合并窗口看起来非常令人兴奋。
