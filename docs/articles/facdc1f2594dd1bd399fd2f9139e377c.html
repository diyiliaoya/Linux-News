GeForce NOW Linux 应用退出测试版，获得官方 Flatpak 仓库

Nvidia 的 GeForce NOW 原生 Linux 应用在经历七个月测试后正式退出测试版，现支持 Ubuntu 24.04 LTS 及更高版本。该应用作为云游戏服务前端，提供超过 4500 款 PC 游戏，用户无需高端硬件即可享受 RTX 级性能、光线追踪和 DLSS。测试期间根据社区反馈进行了性能、稳定性和打磨改进。此外，Nvidia 还优化了 DLSS 帧生成技术，提升流式游戏体验。为简化安装，Nvidia 提供了官方 Flatpak 仓库，用户可通过终端轻松安装和更新。免费版有诸多限制，付费订阅可解锁更多功能。

GeForce NOW 的原生 Linux 应用在经历七个月的测试后正式退出测试版，现官方支持 Ubuntu 24.04 LTS 及更高版本。

该应用是 Nvidia 游戏流媒体服务的前端，提供超过 4500 款 PC 游戏在 Nvidia 服务器上云端运行。用户无需拥有相关硬件即可获得 GeForce RTX 级性能、光线追踪和 DLSS 支持。

在一篇宣布其“毕业”测试版的博客文章中，GeForce NOW for Linux 因测试期间的社区反馈而获得了“性能、稳定性和打磨”方面的改进。

该公司还提及了服务端的一些通用云侧变更，这些变更惠及所有平台的用户。其中包括对 DLSS 帧生成的优化，Nvidia 表示这能让流式游戏体验在本地感觉更灵敏，即使在 60 和 120fps 下也是如此。

GeForce NOW 可以免费使用，但带有广告支持，不过有游戏、访问和性能限制（仅 2000 款游戏，无光线追踪，1 小时游戏时长限制，最高 1080p 等）。付费订阅层级提供更多游戏、更宽松的限制和更好的性能等。

在 Linux 上更轻松地安装 GeForce NOW

GeForce NOW Linux 应用支持 Ubuntu 24.04 LTS 及更高版本。Nvidia 网站提供 .bin 文件形式的应用，您需要使其可执行并运行以进行安装。

如果这听起来很麻烦，Nvidia 已设立了一个专门的 Flatpak 仓库，使安装 GeForce NOW for Linux 并保持更新变得更加容易。

如果您在 Ubuntu 上使用 Flatpak，请通过终端添加 GeForce NOW Flatpak 仓库：

flatpak remote-add --user --if-not-exists GeForceNOW https://international.download.nvidia.com/GFNLinux/flatpak/geforcenow.flatpakrepo

然后安装客户端本身：

flatpak install --user GeForceNOW com.nvidia.geforcenow

安装完成后，从桌面的应用程序启动器中启动它。

Linux 系统要求

在尝试之前，请注意：大多数现代系统应该能正常运行，但建议 Nvidia GPU 用户登录 Xorg 会话以运行该应用——在 Ubuntu 26.04 LTS 上使用标准 GNOME 桌面时无法做到这一点。
