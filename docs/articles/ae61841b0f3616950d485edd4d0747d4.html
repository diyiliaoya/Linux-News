ReactOS 0.4.16 发布，带来全新图形安装程序与更好的硬件支持

2026年8月29日，上午08:56（美国东部时间）

ReactOS 0.4.16 于今日发布，作为这一“开源 Windows”项目的最新重大更新，提供了一个与 Windows 驱动和应用程序兼容的开源操作系统。

对最终用户而言，最引人注目的是 ReactOS 0.4.16 引入了全新的图形安装程序，该程序现已出现在合并的启动 CD 和 Live CD 环境中。因此，从同一镜像中，用户终于可以测试和安装 ReactOS，类似于多年前 Linux 的 Live 体验。

ReactOS 0.4.16 还引入了新的 ReactOS Server Core 安装类型，类似于自 Windows Server 2008 以来的 Windows Server Core。在 ReactOS Server Core 中，图形资源管理器外壳被禁用。

ReactOS 0.4.16 还包含围绕多显示器支持的基础设施工作、各种图形驱动改进、更好的音频驱动支持、众多存储增强、更好的网络性能、更新的第三方代码以及其他各种改进。
