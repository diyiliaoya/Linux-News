Firefox 157 发布，带来“多年来最大规模的视觉刷新”

Firefox 157 正式发布，Mozilla 称其为浏览器“多年来最大规模的视觉刷新”。新版本默认启用 Nova 主题，界面元素更圆润、色彩更丰富，并重新引入紧凑模式。此外还改进了加密密钥日志警告、新增欧洲多国赞助内容建议、更新新标签页快捷方式图标、移除亚马逊内置搜索引擎，并支持 WebRTC 硬件 AV1 解码。用户可通过 about:config 禁用 Nova 主题。

Firefox 157 发布，带来“多年来最大规模的视觉刷新” - OMG! Ubuntu

全新的 Firefox 157 已经到来，Mozilla 将其描述为浏览器“多年来最大规模的视觉刷新”。

最新稳定版更新默认启用。这种“现代化”外观使核心 UI 元素更加圆润、色彩更丰富，微妙的柔和渐变在 Windows、macOS 以及 Linux（尽管在 Linux 上为可选启用）上为窗口镶边增添了色彩。

Nova 使用 Linux 系统主题（后）与不使用（前）

早在三月份，技术博主就分享了 Mozilla 内部关于计划变更的模型图。事情进展迅速；从想法到实现非常快。但计划中的变更数量被缩减了。

在 Firefox 157 中，你会看到更圆润的标签页、菜单、地址栏、弹出窗口、侧边栏、搜索框和信息栏。拖动下方前后对比图片上的滑块，看看刷新在实际场景中显得多么温和：

启用与未启用 Nova

在 Firefox Nightly 版本中测试的某些变更更为醒目，因为元素周围有间隙，以创造“浮动岛屿”效果，最显著的是在工具栏、垂直标签栏和网页内容周围的框架上。

最终这些间隙没有被采用。

Firefox 还（正式）重新引入了紧凑模式选项，标准与紧凑模式的区别（动画 AVIF）

如你所料，紧凑模式减少了工具栏、标签页和菜单项内的间距，为网页内容留出更多空间。Mozilla 表示，它“在较小屏幕和分屏布局中很有用”。

“自动”设置会在其认为合适时启用它。

如果你不喜欢 Nova 的外观，可以暂时禁用它——在新标签页中打开 about:config，搜索 Nova 主题开关，双击将其设为 false。无需重启；更改立即生效。

Firefox 157 的其他变更

TSL/SSL 日志记录有提示

除了 Nova 主题工作外，Firefox 157 还带来了一些其他适度的变更。

如果设置为通过 SSLKEYLOGFILE 记录加密密钥，Firefox 157 会在地址栏和站点信息面板（盾牌图标弹出窗口）中显示警告。这很重要；该日志文件中的密钥可能被设备上的其他应用查询，以读取任何加密的网络流量。

包括奥地利、比利时、捷克共和国、丹麦、芬兰、匈牙利、爱尔兰、荷兰、挪威、波兰、葡萄牙、斯洛伐克、西班牙和瑞典在内的众多欧洲国家的 Firefox 用户可以看到赞助内容建议。嗯哼。如果赞助内容——无论是无害的体育比赛结果，还是令人讨厌的付费网站出现在地址栏下拉列表中你正在寻找的网站之上——这种杂乱想法不吸引你，你可以通过设置 > 搜索 > Firefox 建议将其关闭。

新标签页列表图标和“添加快捷方式”现在可见

新标签页使得更容易知道你可以添加自己的自定义快捷方式。现在，快捷方式行末尾始终可见一个“+”图标，之前仅在悬停时显示。和以前一样，它允许你添加标题、URL 和图像链接来创建自定义磁贴。

并且窗口栏中的“列出所有标签页”小部件使用了新图标，之前是一个相当不起眼的“v”形。

亚马逊不再作为内置搜索引擎包含在内

WebRTC 视频通话可以使用硬件 AV1 解码（在支持的情况下）

现在将焦点移到地址栏和搜索栏的文本字段

对话框现在匹配页面主题

此更新还包含一系列安全漏洞修复。

Firefox 157 从今天（9 月 28 日星期一）起可从下载，该网站提供所有主要操作系统的二进制构建和安装程序（与官方网站将链接到的相同）。

Windows、macOS 和 Linux（二进制构建）上的现有用户可以从明天（9 月 29 日星期二）起在应用内更新，届时 Linux 发行版仓库、软件商店（Flathub、Snap）和其他格式也将开始打包它。

如果你使用的是 Ubuntu，只需等待；此更新将作为自动更新到达——如果浏览器正在运行，桌面通知会告诉你何时可以安装。
