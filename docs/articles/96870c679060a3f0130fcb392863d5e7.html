Firefox 换新装！Nova 重设计已成默认

在设计图泄露六个月后，Firefox 157 版本终于完成了这一转变。

Firefox 拥有了全新的外观，使其达到了 2026 年网页浏览器的标准，其中简洁、极简的用户体验正成为一种日益增长的潮流。

在官方公告发布之前，Mozilla 在几个月后通过概述他们如何应对这一重大转变来追赶进度。

事实证明，这一转变比设计图看起来要复杂得多。

泄露六个月后

当内部设计文件在三月被公开时，这些设计图看起来与以往任何 Firefox 版本都不同。标签栏、工具栏和地址栏被整合到顶部一个悬浮的岛屿中，与下方的页面之间留有明显的间隙。

在这些设计中，网页内容也得到了同样的处理，被放置在一个圆角容器内，从浏览器边缘抬起，而不是沿着边缘延伸。但问题是，这两个想法都没有进入最终版本，最终版本更加精致。标签页、菜单和地址栏明显更圆润，活动标签页上带有微妙的渐变，为界面增添了温暖感。

Firefox Nova 在右侧。

我将 Firefox 156 与 157 进行了对比，看看有什么变化，结果令我印象深刻。

打开新的浏览器标签页让我看到了投入最多精力的地方，标签栏明显更圆润，地址栏的角落也更柔和，使界面看起来非常精致。

我已经开始不喜欢 Firefox 那种扁平/平淡的外观了；每当我从使用 Vivaldi 或 Chrome 等其他浏览器回来时，它都会让我感到困扰。

你看，这两款浏览器都已经采用了我非常喜欢的药丸形设计理念。

加载网站时也是如此，界面更纤薄，为网页留出了更多可用空间，工具栏元素之间的分隔线也比以前更少。

设置菜单也焕然一新。在 156 中，侧边栏以紧凑列表的形式呈现，内容面板相当简单。在 157 中，这些面板位于圆角卡片内，各个部分为每个设置区域提供了更多的视觉空间和更好的可读性。

自从我上次使用以来，它已经发生了很大变化。Nova 重设计让该功能相比首次在 Firefox 138 中推出时感觉更加完整。

当时，标签组在标签栏中显示为带颜色的标签条，管理选项仅限于命名和折叠。虽然该功能可用，但感觉像是早期实现。

现在，标签组更自然地存在于标签栏中，在它们之间切换或将某个标签组折叠起来感觉不再那么笨拙，使用起来更加直观。

“”按钮也发生了变化，采用了不同的图标（而不是向下箭头）和视觉风格，与整体的药丸形设计很好地融合。你可以使用它一次性查看所有标签组中的每个标签页。

紧凑密度、新主题和窗口切换器。

2021 年的功能回归了。紧凑模式现在可在“设置 > 外观”中使用，除了“密度”选择器外，还新增了“紧凑”选项。

你还会发现许多新主题，可以通过“”安装，以及右上角新增的经典/智能窗口切换器按钮，用于在传统和之间快速切换。
