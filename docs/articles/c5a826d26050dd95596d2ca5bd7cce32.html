Linux 7.3 带来图形驱动改进：从旧 GPU 到下一代硬件

2026年8月23日下午2:10 EDT。

直接渲染管理器（DRM）子系统的更新已合并到正在进行的 Linux 7.3 合并窗口中。这个周期有许多令人兴奋的 GPU 内核驱动改进，从对旧 AMD Radeon 图形硬件的一些显著增强，到启用对下一代 AMD 图形 IP 块的支持，再到 Intel 方面，Nova Lake S 图形默认启用。

对于显存容量非常有限的用户来说，令人兴奋的是由 Valve 的 Natalie Vock 领导的 DMEMCG 换出工作，它改善了超出显存容量时的 Linux 游戏性能。DMEMCG 换出最初应该对 AMDGPU 和 Intel 图形都能良好工作。

同时，来自 Valve 的 Timur Kristóf 为旧 AMD GPU（GFX6 到 GFX8 时代硬件）提供了 DRM 格式修饰符支持。这是 Timur 过去一年专注于增强 Linux 上原始 GCN 时代显卡支持的一部分。此外，AMDGPU 在 Linux 7.3 中还改进了 GPU 重置恢复。

AMDGPU 驱动还在现代 AMD APU 上启用了第二图形管道，修复了 8K 显示问题，支持 DCN 6.0 显示核心，支持 DC CACP，以及其他改进。

在 Intel 方面，Linux 7.3 同样令人兴奋的是 Xe3P Nova Lake 图形现在被认为是稳定的，并默认启用，而不是被限制在“强制探测”选项后面。

Linux 7.3 的 DRM 还继续构建 Rust 驱动能力，现在已添加了额外的基础设施。基于 Rust 的 NVIDIA Nova 驱动也继续构建，包含 Blackwell 和 Hopper 修复、GSP 启动改进，并且现在可以在启用 vGPU 的情况下启动 GSP。现有的 Nouveau 开源 NVIDIA 驱动现在还支持 NVK Vulkan Video。

在 DRM 核心方面，TTM 现在更加积极。

关于 Linux 7.3 中许多直接渲染管理器驱动更改的更多细节，请参见周五合并到 Git 的内容。
