发行版发布：KaOS 2026.11

KaOS 项目发布了 2026.11 版 live ISO 镜像。新版本改进了 Plasma 之后的 niri/Noctalia 桌面配置，Noctalia 5 增加了大量插件。系统启动改用 dinit、turnstile 和 seatd，进一步减少对 systemd 组件的依赖，并新增 kss 图形工具用于调整 KConfig 模块。默认显示管理器为基于 greetd 的 Tuigreet。

KaOS 项目致力于开发一个滚动发布的 Linux 发行版，专注于将 Qt 开发平台和 KDE 应用程序集成为完整的桌面环境，现已宣布发布 2026.11 版 live ISO 镜像。此新版本包含了 Noctalia shell 的最新改进和新插件：

“非常荣幸向您呈现十一月发布的新稳定 ISO 镜像。KaOS 在 Plasma 之后的 niri/Noctalia 配置得到进一步改进。Noctalia 5 增加了一系列令人印象深刻的插件，大幅扩展了此 shell 的功能。在 niri 中为 xdg 自启动功能添加 dex 后，权限问题得到改善，因此屏幕录制等功能再次正常工作。KaOS 创建了一个新应用程序（kss），以便仍然能够通过图形界面调整 KConfig 模块。KaOS 使用 dinit、turnstile、seatd 进行系统启动、席位和服务管理。对 systemd 应用程序部分的使用进一步减少。仍在使用的部分主要用于 udev 和 tmpfiles。使用了 Elogind，但不是用于系统登录，纯粹是为了提供可用的 polkit。添加了 openrc-settingsd，以重新加入 localed、timedated 和 timesyncd 的独立组件。console-setup 的使用范围已扩展，现在也提供独立的 localectl 替代品。默认显示管理器是基于 greetd 的 Tuigreet。Greetd 与 seatd 完全集成，因此在新配置下更适合 KaOS。”
