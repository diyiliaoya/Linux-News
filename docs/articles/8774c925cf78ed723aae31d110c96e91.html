Ubuntu 24.04 获得重大 open-vm-tools 更新

Ubuntu 24.04 LTS 用户将收到 open-vm-tools 的重大更新，该工具用于增强 Linux 虚拟机与 VMware 虚拟机监控程序的集成。此次更新将软件包从 v12.3.5 升级至 v13.0.10，与 Ubuntu 26.04 LTS 版本同步。更新内容包括时钟同步、优雅关机、vSphere API 支持、共享文件夹等，并修复了安全问题和改进了日志记录。对于在 VMware 中运行 Linux 桌面的用户，open-vm-tools-desktop 包还提供了剪贴板共享和窗口大小调整等额外功能。该更新通过标准更新渠道推送，用户可通过 apt 命令获取。

Ubuntu 24.04 获得重大 open-vm-tools 更新 - OMG! Ubuntu

一个将 Linux 虚拟机与 VMware 虚拟机监控程序集成的软件包，正在向 Ubuntu 24.04 LTS 用户推送。

“如果不进行 SRU（稳定版更新），用户在新版虚拟机监控程序上运行时可能会遇到问题。”Canonical 的 Lena Voytek 在回传请求中解释道。这是一次从 Ubuntu 26.04 LTS 的完整回传，以支持平台启用，使运行 24.04 LTS 的用户受益。

该软件包从 v12.3.5 升级至 v13.0.10（与 Ubuntu 26.04 LTS 中的版本相同）。

open-vm-tools 软件包支持与虚拟机监控程序主机进行时钟同步，实现优雅关机的“平稳”电源管理，提供 vSphere API、共享文件夹支持，将客户机操作系统统计信息回传给虚拟机监控程序以进行监控——以及更多功能。

如果你在 VMware Workstation Pro（macOS 上的 Fusion Pro）中运行 Linux 桌面会话，open-vm-tools-desktop 软件包还提供额外的集成功能，如共享剪贴板和客户机窗口大小调整。该软件包依赖于基础软件包并继承其功能。

在维护版本汇总中的变更包括：使用 systemd 而非传统的 init 命令，更好地处理瞬时错误，安全修复，几个新的开发者控制项，以及改进的日志记录。

没有引人注目的功能，但出于实际原因，这确实是个福音。并非所有人都在使用桌面发行版，而是将虚拟化用于特定任务的工作负载，无论是无头还是图形界面，稳定性往往比花哨的新功能更受青睐。

如果你运行 Ubuntu 24.04 LTS，此更新将通过标准更新渠道推送给你。运行以下命令：

sudo apt update && sudo apt dist-upgrade
