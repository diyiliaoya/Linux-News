GNU Linux-Libre 庆祝旧款 802.11 b/g WiFi 芯片组的逆向工程固件

GNU Linux-libre 项目发布了基于旧版 Linux 6.12 LTS 内核的新版本 6.12.119-gnu，庆祝其为 VIA VT6656 802.11 b/g WiFi 芯片组实现了开源逆向工程固件。该固件由开发者 Jason Self 通过反汇编原始二进制文件完成，使该驱动符合 GNU Linux-libre 的自由软件标准。然而，由于该驱动在 Linux 6.13 中因缺乏维护被移除，此支持仅存在于 6.12 LTS 分支中。

GNU Linux-Libre 庆祝旧款 802.11 b/g WiFi 芯片组的逆向工程固件

2026 年 11 月 25 日 08:35 AM EST 发布。

今天令人意外的是，GNU Linux-libre 为较旧的 Linux 6.12 LTS 内核发布了一个新的内核版本。通常，该项目很少宣布针对旧版/LTS 内核的新更新，但今天他们庆祝一个 WiFi 芯片组现在可以在其经过清理的 Linux 内核版本上工作。如果你不介意使用传统的 802.11 b/g WiFi，那么有一个新近获得认可的驱动选项。

今天发布的 GNU Linux-libre 6.12.119-gnu 包含了对 VT6656 驱动的支持，即 VIA 802.11 b/g VT6656 WiFi 芯片组，支持 USB 2.0 和高达 54 Mbps 的传输速率。VT6656 的开源 Linux 驱动早已存在，但它依赖于闭源固件，因此不符合 GNU Linux-libre 的标准。开源开发者 Jason Self 为这款 802.11 b/g WiFi 芯片组逆向工程了固件。

因此，现在有了针对 VIA VT6656 的逆向工程开源固件，它获得了维护 GNU Linux-libre 内核的 FSFLA 组织的认可。可惜的是，这距离该 WiFi 芯片组首次亮相已经过去了二十年。

逆向工程是通过反汇编原始的 VIA 固件二进制文件完成的。该固件二进制文件曾作为 VIA 树外 VT6656 驱动的一部分分发，该驱动包含 GPL 许可证，但固件没有任何源代码。GPL 允许反汇编，因此固件被反汇编并转换为 C 代码。

至于今天在旧的 6.12 LTS 分支而非最新的 Linux 7.3/7.4 上游代码上发布 GNU Linux-libre 6.12.119-gnu 内核，是因为 VT6656 驱动在 Linux 6.13 中因无人维护而被移除……所以现在硬件有了开源固件，但由于驱动代码无人维护，该驱动甚至不再存在于主线内核中。

“现在，有一些不太好的消息：它并不是那么新的外设，而且它的驱动在上游 6.13 系列中被移除了，所以 6.12 是最后一个仍包含它的稳定长期支持版本系列。

（……截至本公告发布时。希望我们能改变这一点。有志愿者愿意推动其重新纳入上游，并在那里维护它吗？你自己怎么样？:-）

上游移除它的理由并不是那么充分。硬件仍然可用且被广泛使用，但似乎没有人有兴趣维护它。希望这一进展能改变这种情况？”

所以，如果你仍在使用任何 VT6656 WiFi USB 适配器，或者正在寻找一款具有开源固件且不介意 802.11 b/g 性能的无线芯片组，那么在 2026 年即将结束之际，这是一个意想不到的进展。至少这一进展赶上了假日购物季，FSF 已经认可了各种尊重你自由的旧硬件——2023 年的假日推荐包括 802.11n WiFi 和 USB 转并行打印机线缆，以及其他自由软件基金会认证的硬件。
