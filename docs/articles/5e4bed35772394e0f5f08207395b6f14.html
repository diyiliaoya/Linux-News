微软命令行文本编辑器现已支持语法高亮

微软开源命令行文本编辑器 Edit 发布 v2.0.0 更新，新增语法高亮、改进正则表达式处理和编辑快捷键。其轻量级语法高亮器仅增加 40Kb 体积，支持 C、Rust、JavaScript 等十余种语言，处理速度超 100MB/s。此外还加入初始主题支持、多行缩进、自然排序文件选择器等改进。Ubuntu 用户可通过 snap 安装 msedit。

微软的命令行文本编辑器现已支持语法高亮 - OMG! Ubuntu

微软的开源命令行文本编辑器在 v2.0.0 更新中新增了语法高亮、改进的正则表达式处理以及新的编辑快捷键。

它是一个小巧的跨平台文本编辑器，具有 VS Code 风格的键绑定、鼠标支持，可处理 LF 和 CRLF 行尾，并允许打开多个文件。简洁的终端用户界面（TUI）非常易于使用。

该编辑器于今年早些时候发布，但非官方的 Linux snap 包（由 Canonical 的 Aaron Prisk 维护）直到 9 月 14 日才更新——正是通过那次更新我才得知有新版本发布。

迟来地介绍一下新版本带来的内容。

Edit 敏捷的语法高亮

msedit v2.0 中的 JavaScript 语法高亮

语法高亮是本次的重大新增功能。开发者构建了一个自定义的轻量级语法高亮器，仅给二进制文件增加 40Kb 体积，却覆盖了十多种流行的编程语言，包括 C、Rust 和 JavaScript。

根据发布说明，它以超过 100MB/s 的速度处理文本，这对于经常处理长文件的用户来说体验相当迅捷。

更新日志中的其他改进：

可在替换中复用匹配的文本

可用于移动行

缩进/取消缩进多个选中行

选中当前行

选区内的空白字符现在可见

终端标题中的 • 表示文件有未保存的更改

通过 CLI 打开目录会打开文件选择器

文件选择器使用自然排序

保存时自动创建缺失的父目录

自发布以来一直有人要求提供自定义工具的方式。此版本带来了初步的主题支持，尽管仅限于此。

修复了若干错误，该软件包现在可使用 Rust v1.93 或更高版本构建（此前需要 nightly 构建），并且 GitHub 仓库中添加了一个文件，为非官方 Snap 包提供了受支持的构建配置。
