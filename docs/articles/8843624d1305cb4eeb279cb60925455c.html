Banshee 音乐播放器起死回生（好吧，算是吧）

Banshee 音乐播放器的 Snap 包已上架 Snap 商店，让这款 2014 年发布最后一个稳定版的经典 Linux 音乐播放器得以在现代桌面运行。该包由 Alan Pope 打包，包含兼容性修复并恢复部分在线服务，但并非官方延续。实测可正常播放本地音乐、支持专辑封面和媒体键，但 Last.fm 登录和视频播放不可用。

Banshee snap 包让老牌 Linux 音乐播放器重获新生，现已上架 Snap 商店，使其在最后一个稳定版发布十余年后仍可在现代 Linux 桌面上使用。

由 Alan Pope（又名 popey）打包，新的 Banshee snap 让你现在就能在现代化 Linux 桌面上运行 2014 年的最终稳定版。这不仅仅是重新打包；Snap 商店的描述提到它包含“兼容性修复并恢复了部分在线服务”，但也指出并非所有“历史”服务都能正常工作。

Banshee snap 在 Ubuntu 26.04 LTS 上播放音乐

这是官方延续吗？不是。

这更像是“复活的尸体”而非转世重生。Popey 的 snap 几乎像是一次软件保存行动。像 Snap 这样的容器格式非常适合“时间胶囊”式的努力，因为旧依赖可以打包在内而不影响宿主系统。

抛开怀旧奇趣不谈，这个 snap 提供了一个真正可用的音乐播放器：指向一个装满曲目的文件夹即可加载、浏览、管理和播放。要读取存储在外置驱动器上的文件，你需要授予 snap 权限。

连原始的指示器小程序也还在

我在 Ubuntu 26.04 LTS 上试用了它。首次运行时它提示我选择音乐文件夹，并很快加载了曲目。我尝试的每种音乐格式它都能处理。专辑封面没有问题，MPRIS 和媒体键也能正常响应，这很棒。

但我无法登录 Last.fm（Snap 商店列表确实说明并非所有功能都能用）。在尝试认证过程时，应用弹出了“无法启动 URL”的错误对话框。

视频播放完全不行——但这我早有预料。自 2014 年以来，格式、分辨率和编解码器已经发生了很大变化。我没费心去测试 Banshee 的 DVD 播放，因为说实话，当年它也从来就不好用。

Banshee 与 Ubuntu 渊源已久

Banshee 运行在 Ubuntu 10.04 LTS 桌面上

Banshee 曾在 2011 年至 2012 年间作为 Ubuntu 的默认音乐应用。它的入选在当时是件大事——不仅因为它取代了当时非常流行的 Rhythmbox，还因为它的编写语言：Mono。

Mono 是（现在仍然存在）微软 .NET 技术栈、C# 语言及相关库部分内容的开源重新实现。它由 GNOME 联合创始人 Miguel de Icaza 创建。

Linux 社区中许多人讨厌 Mono，担心它的使用是捕获 Linux 的特洛伊木马，使用它的发行版和开发者可能会受到微软的法律威胁。

微软确实曾成为 Mono 的管理者，但后来将其移交给了 Wine 项目。Ubuntu 最终确实放弃了基于 Mono 的应用，将其从默认安装中移除。然而，那是因为磁盘空间和依赖关系的考虑，而不是被专利妖怪吓到了。

但 Ubuntu 用户最后一次听到 Banshee 的哀鸣是在 2018 年。该软件包被从 Debian 档案库中移除，因为它持续依赖 Debian 维护者正在淘汰的已弃用库。

安装 Banshee Snap

Ubuntu 用户只需打开 Ubuntu 软件中心并搜索 Banshee 即可安装，或通过终端获取：

sudo snap install banshee

Banshee snap 依赖 Core22 运行时，因此如果你使用的是未预装该运行时的较新版本 Ubuntu（如 Ubuntu 26.04 LTS），它也会被一并拉取。

值得用吗？作为一次回忆之旅，当然。我很想拉上窗帘，假装现在是 2012 年，我们又回到了美好的时间线——为了完全的复刻氛围，我甚至可能拿起干草叉去抱怨 Mono。

Banshee 属于它的时代。它是一个 GTK2 应用。在 2026 年，这可能是个问题，因为 UI 在使用分数缩放的现代显示器上“缩放”得不太好——有些部分能适应，有些则不能。它在 2014 年有的任何 bug 现在依然存在。

你还记得当年用过它吗？我很想听听你的想法。
