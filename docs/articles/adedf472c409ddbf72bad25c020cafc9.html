通常，在测试不同的 Linux 发行版或比较 Windows 与 Linux 时，我们使用的是顶级的旗舰台式机或服务器硬件，但今天我们关注的是 Ubuntu、CachyOS 和 Windows 在性能光谱另一端的表现。我们使用全新的 CHUWI UniBook 449美元笔记本，搭载英特尔酷睿3处理器和8GB系统内存，来看看这三款操作系统在各种工作负载下的对比情况。

由于 CHUWI UniBook 评测样机预装了微软 Windows 11 专业版，考虑到 CachyOS 和 Ubuntu 26.04 LTS 这两个 Linux 发行版的受欢迎程度，我决定将这台 Wildcat Lake 笔记本上预装的更新版 Windows 11 环境与滚动发布的 CachyOS 以及 Ubuntu 26.04 LTS 进行对比。在基准测试过程中，所有操作系统均已更新并保持默认设置。

提醒一下，CHUWI UniBook 搭载的是英特尔酷睿3 304 Wildcat Lake 处理器，由1个P核和4个LPE核组成。配有8GB LPDDR5-6400内存和256GB NVMe 固态硬盘。这与我们通常用于测试高端 Linux 性能的硬件处于完全相反的光谱末端。
