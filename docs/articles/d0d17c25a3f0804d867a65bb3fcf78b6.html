GNOME Sushi 迎来 GTK4 改造与新功能

GNOME Sushi，Nautilus 文件管理器的空格键预览工具，已移植到 GTK4，适用于 GNOME 51。新版界面更美观，支持明暗模式，窗口大小自适应，新增键盘快捷键，支持动画 GIF/TIFF 预览，HTML 预览可阻止远程内容，并采用 Rust 图像解码库。维护工作由新开发者接手，预计 9 月随 GNOME 51 发布。

GNOME Sushi，Nautilus 文件管理器的空格键预览工具，已移植到 GTK4，适用于 GNOME 51。

对于不熟悉它的人来说，Sushi 就像 macOS 上的“快速查看”：你在 Nautilus 中高亮一个文件（图片、音乐、视频、文档等），其内容的即时预览就会出现。再次按下空格键即可关闭预览。

对于 v51 版本，Sushi 的 GTK4 移植意味着它在更新的 GNOME 版本上看起来更美观。标题栏更扁平，某些文件类型（如媒体）上的覆盖控件让内容从下方透出。明/暗模式偏好现在也能被正确遵循。

改进后的 Sushi 预览不同文件类型

早期版本的 Sushi 在使用方向键循环浏览文件时，不会调整窗口大小。我用它预览各种尺寸/比例的图片时，预览框会保持第一个文件预览的尺寸——这很烦人。

所以我很高兴看到 Sushi v51 解决了这个问题。开发者彻底修改了窗口大小调整逻辑，并使其在显示缩放时表现更好。预览画布现在可以动态调整大小，非常流畅：

Sushi v51（夜间构建版）中的自适应调整演示

还新增了键盘快捷键：

- 按 F2 重命名预览中的文件

- 按 Delete 将文件移至回收站

- 按 Enter 在默认应用中打开该文件类型

- 按空格键暂停/恢复视频/音频内容的播放

HTML 文件预览会阻止远程内容加载。信息栏会提示你这种情况，并让你选择是否允许内容加载。你现在还可以在 HTML 预览中右键点击 URL，在默认网页浏览器中打开它们。

如果你曾因在动画 GIF 上按空格键却只看到静态帧而感到恼火，那么现在可以欢呼了：Sushi 现在能够播放动画 GIF 和 TIFF 图像。

文本查看器支持自动换行

点击视频预览可暂停/恢复播放

打开预览的文件夹时，会在父文件夹中打开

音频文件预览显示嵌入的封面图

双击预览区域可进入/退出全屏

标题栏新增全屏图标

支持 XHTML 和更多办公文件 MIME 类型

如果预览加载需要时间，会显示动画加载指示器

旧的 Gdkpixbuf 图像渲染已被基于 Rust 的图像加载库所取代。这个沙盒化的解码器库也被其他 GNOME 应用使用，包括图像查看器 Loupe。

Sushi 再次被提上日程

维护工作最近移交给了开发者 Peter Eisenmann，他与 Lorenzo Ubaldi 和 Tau Gärtli 一起，在完善功能和现代化代码库方面做出了卓越努力；GTK4 移植由 Corey Berla 完成。

Sushi 是一个 GNOME 项目，作为 Nautilus 的配套工具。它曾在 2017 年被提议纳入默认安装，但与其他在从 Unity 过渡到 GNOME 期间提出的计划一样，最终未能实现。

GNOME 设计追踪器上有一个提案，其中包含一些早期建议。主题是什么？为什么，当然是让 Sushi 成为默认安装。

提前体验 Sushi 51

Sushi v51 将于 9 月发布，与 GNOME 51 的稳定版同步。希望它能被打包进 Ubuntu 26.10 的软件源，但截至撰写本文时，软件源中只有 v50 版本——希望新版本能顺利进入。

如果你使用 GNOME Nightly Flatpak 仓库，可以从那里安装 Sushi 的开发构建版。请记住，该仓库还需要 GNOME 51 开发运行时、编解码器，并且你也需要 Nautilus 51。
