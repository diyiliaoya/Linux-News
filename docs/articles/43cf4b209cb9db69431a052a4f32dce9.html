AMD 在 Linux 7.4 中将 Radeon iGPU 的 AI/LLM 性能提升高达 18~23%

AMD 将在 Linux 7.4 中引入 PerfOpt 功能，通过绕过 IOMMU 直接访问系统内存来降低开销，从而提升 Radeon 集成显卡的 AI/LLM 推理性能。测试显示，在 Strix Halo、Strix Point 和 Krackan 等 Ryzen AI 平台上，启用 PerfOpt 后性能提升可达 18~23%。该功能默认启用，可通过内核参数关闭。

AMD 在 Linux 7.4 中将 Radeon iGPU 的 AI/LLM 性能提升高达 18~23%

2026 年 9 月 29 日下午 2:57（美国东部时间）。

如果你拥有一台 AMD Ryzen 笔记本或台式机，并希望利用集成显卡的 AI/LLM 能力，这将是一个真正的福音，尤其是对低端硬件而言。AMD 在 Linux 7.4 中引入的新 PerfOpt 功能将带来可观的性能提升，正如今天在不同 AMD Ryzen/Radeon 硬件上进行的这些基准测试所示。

在 Linux 7.4 合并窗口于 10 月下旬开启之前，最近已排队进入 IOMMU 子系统 Git 树的是一个补丁，为 AMD 集成显卡系统启用新的 AMD PerfOpt 功能。

AMD PerfOpt 是 AMD IOMMU 性能优化（Performance Optimization）的一部分，属于 AMD I/O 虚拟化技术（IOMMU）规范。借助 PerfOpt，你可以在直接访问系统内存时绕过 IOMMU，从而避免那部分开销。AMDGPU 驱动将在使用集成显卡时默认启用 AMD PerfOpt。随着这些补丁进入 Linux 7.4，PerfOpt 将在 AMD iGPU 配置上自动启用，同时也可以通过 amdgpu.iommu_perfopt=0 内核模块选项强制关闭，以便比较其影响。

出于对 PerfOpt 影响的好奇，我从 IOMMU Git 树中为 Linux 7.4 准备的代码构建了一个测试内核。然后我在同一内核上测试了 PerfOpt 启用（默认）与禁用的情况。由于缺少 Strix Halo 笔记本进行持续实测，我在一台 AMD Strix Halo 台式机上进行了测试，另外还使用了 Strix Point 和 Krackan 笔记本，以更全面地了解对性能的影响。

在这轮初步测试中，我使用了本地 AI 服务器，后端为 Llama.cpp，在这些 AMD Ryzen AI 系统上进行本地 AI/LLM 推理。未来几周在考察 Linux 7.4 内核整体性能时，我还会提供更多 AMD PerfOpt 基准测试。Linux 7.4 周期将于 10 月下旬启动，稳定版内核将在日历年年底左右发布。它也很可能成为今年的 LTS 内核版本。
