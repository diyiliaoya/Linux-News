OpenShot 4.0 发布：视频编辑器界面适配 Qt6

OpenShot 4.0 于今日在 GitHub 上发布，这是这款开源非线性视频编辑应用的最新重大版本。主要变化是从 Qt5 迁移到 Qt6 工具包，并进行了大量代码修改和 UI 增强，如新增录制视图、音频录制停靠面板、实时多资源录制时间轴预览。此外，还引入了新的 ComfyUI 模板（用于音频降噪、清理、修复和语音增强）、阴影和发光效果、分析视图、胶片颗粒剪辑预设、YOLOv5 设置和 YOLO 模型选择器。Windows 软件包也有所改进。

OpenShot 4.0 发布：视频编辑器界面适配 Qt6 - Phoronix

OpenShot 4.0 于今日下午在 GitHub 上标记发布，这是这款开源非线性视频编辑应用的最新重大功能版本。

OpenShot 4.0 的主要变化（也是从 3.5.1 版本升级的原因）是现在采用了 Qt6 工具包。OpenShot 已从 Qt5 移植到当前的 Qt6 版本。在迁移到 Qt6 工具包的过程中进行了大量代码修改，同时还进行了其他 UI 增强，例如录制视图和音频录制停靠面板。现在还有实时多资源录制时间轴预览。

此外，还新增了用于音频降噪/清理/修复/语音增强的 ComfyUI 模板、新的阴影和发光效果、新的分析视图、新的胶片颗粒剪辑预设、YOLOv5 设置、用于对象检测过滤器的 YOLO 模型选择器，以及其他改进。OpenShot 4.0 的 Microsoft Windows 软件包也得到了改进。

想要试用 OpenShot 4.0.0 的用户可以在 GitHub 上找到源代码和各种发布二进制文件。
