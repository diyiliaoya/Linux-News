发行版发布：CarotOS 1.3

CarotOS 1.3 发布，这是一个基于 Debian、专为课堂网络安全教育设计的 Linux 发行版。新版本代号“Eggshell”，新增五款应用（包括基于 ClamAV 的杀毒软件、蜜罐、文件转换器等），系统健康检查增至 23 项，USB 检查增加按需 ClamAV 扫描，欢迎向导有 21 页，应用商店目录从 51 款增至 153 款。提供 AMD64 ISO 下载。

Yusuf Miraç Üzümcüler 宣布发布 CarotOS 1.3，这是该项目基于 Debian 的专业 Linux 发行版的最新版本，主要面向课堂网络安全教育。它包含多种安全工具，涵盖网络扫描、流量分析、Web 与密码测试以及防火墙配置，还包括若干用 Python 编写的自定义应用。所有这些工具均提供土耳其语和英语版本。发布摘要（土耳其语）介绍了近期的一些变更和新增内容：“CarotOS 1.3 ‘Eggshell’。五款新应用——Carotene（基于 ClamAV 的杀毒软件）、CarotPot（本地网络蜜罐）、Filenor（文件与媒体转换器）、CarotOS Former（安全工具动画指南）和 CarotOS GSD（161 词条双语词汇表）；系统健康检查现在运行 23 项检查（从 20 项增加），并新增使用 debsums 和 rkhunter 的可选详细扫描；USB 检查增加了按需 ClamAV 扫描，仅报告且从不改动文件；欢迎向导有 21 页；CarotOS 商店目录从 51 款应用增至十个类别下的 153 款。” CarotOS 1.3 可从发行版网站下载：carotos-1.3-amd64.iso。

发行版发布：CarotOS 1.3

CarotOS 是一个基于 Debian 的专业 Linux 发行版，主要面向课堂网络安全教育。它包含多种安全工具，涵盖网络扫描、流量分析、Web 与密码测试以及防火墙配置，还包括若干用 Python 编写、以通用公共许可证第 3 版发布的自定义应用。主要学习工具名为 CarotOS Poligon，是一对学生/教师应用，用于在隔离的本地课堂环境中练习渗透测试。CarotOS 启动进入定制的 Xfce 桌面，默认语言为土耳其语，但也可从欢迎向导中选择英语。
