移动操作系统发布：UBports 24.04-2.0

该项目发布了一项新的功能更新，UBports 24.04-2.0，引入了网页浏览器更新以及对输出显示中“刘海”区域的支持。

“Ubuntu Touch 24.04-2.0 是与先前版本基于相同 Ubuntu 24.04 基础的功能更新。尽管如此，此版本包含了令人兴奋的更新和功能。最值得注意的是：在 Ubuntu Touch 24.04-2.0 中，Morph 浏览器的基础浏览器引擎从 Chromium 87 大幅升级至 Chromium 134，虽然这还不是最新版本，但显著提升了与当今网站和 Web 应用的兼容性。此次升级为未来的 Chromium 升级奠定了基础；我们希望在后续的 24.04-2.x 小版本更新中能够提供更多浏览器引擎升级。作为额外福利，我们还包含了一个 Widevine 安装程序，Widevine 是许多服务提供商使用的 DRM 实现。依赖 DRM 保护内容的用户现在可以使用 Morph 浏览器来消费此类内容。”
