两个独立项目希望将 MATE 引入 Wayland，各显其能

两个独立项目正以不同方式将 MATE 桌面环境引入 Wayland：Polo 项目为 MATE 构建全新的合成器、窗口管理器和会话管理器，基于 libweston 16，遵循 Marco 的窗口管理规则；MATE Wayland Desktop 项目则使用现有的 labwc 合成器替代 Marco，并基于 Ubuntu 提供可安装 ISO。两者都通过 XWayland 兼容仅支持 X11 的应用。

两个独立项目希望将 MATE 引入 Wayland，各显其能

Polo 为 MATE 构建新的合成器，而 MATE Wayland Desktop 则在基于 Ubuntu 的 ISO 上通过 labwc 运行 MATE。

大型 Linux 桌面环境大多已下定决心。GNOME 已完成从登录管理器中移除 X11，而上个月 KDE Plasma 也采取了行动，开始移除 X11 会话。Cinnamon 稍慢一步，但预计在圣诞节前后发布的版本将提供一个不再处于实验阶段的 Wayland 会话，不过 X11 仍是默认选项。

较小的桌面环境在这条路上处于不同阶段。Xfce 在 v2.3.0 中取消了其 Wayland 会话的实验标签，而 Budgie 在相应版本中随 labwc 转向仅支持 Wayland。另一方面，MATE 则零散推进。自 MATE 1.26 起，像这样的应用可以在 Wayland 上运行，而官方配置是一个简单的实验性设置，依赖 Wayfire。

仍然缺失的是 MATE 的原生 Wayland 窗口管理器。它自己的 Marco 没有 Wayland 模式，而以下两个项目现在旨在以不同方式取代它。

Polo 来自开发者，它是一个合成器、窗口管理器和会话管理器，面向希望 MATE 在 Wayland 上保持当前外观和行为的用户。它基于 libweston 16 构建，遵循 Marco 的窗口管理规则，并保留 MATE 用户已有的设置、主题和键绑定。仍需 X11 的应用在 XWayland 下拥有自己的窗口管理器。

Polo 也处理会话，使用 D-Bus 接口，面板、Caja 和屏幕保护程序可以像在 X11 上一样与之通信。11 月 12 日发布的版本支持平铺、工作区、通过 xdg-desktop-portal 进行屏幕共享，以及为兼容 layer shell。

DRM 后端负责处理多显示器和记住屏幕布局。还包括晃动窗口和桌面立方体等效果。

在 Fedora 44 或 45、Debian 14 或 Ubuntu 26.04 或 26.10 上从源码构建 Polo。安装后，LightDM 中应出现一个“”条目。

他表示，如果 Debian 和 Ubuntu 的 MATE 团队不提供支持 Wayland 的软件包，他可能会托管自己的仓库。

MATE Wayland Desktop 则使用现有合成器而非编写新合成器。它用 labwc 替换 Marco，并作为基于 Ubuntu 的可安装 ISO 发布，以 Linux 7.0 和 MATE 1.29 组件为基础。

其中八个 MATE 软件包从更新的上游代码重新构建，其中之一是启用了 Wayland 支持的 mate-panel 1.29.2。仅支持 X11 的应用通过 XWayland 运行。

安装由 Calamares 处理，并提供可选的 LUKS2 全盘加密。该项目也明确说明了其中的粗糙边缘。

控制中心中的键盘、鼠标和键盘快捷键面板在原生运行时崩溃，因此 MATE Wayland Desktop 通过 XWayland 打开它们。对话框在 Wayland 上也无法工作。启动器中的“”条目会打开。

在安装和使用过程中，必须关闭 Secure Boot，ISO 启动时使用开源 Nouveau GPU 驱动。之后可以用安装 NVIDIA 自己的驱动。

鉴于这是一个新事物，我强烈建议你在完整安装之前先在备用机器上测试。

你可以在 x86_64 系统上通过官方下载门户获取其 ISO 开始使用。
