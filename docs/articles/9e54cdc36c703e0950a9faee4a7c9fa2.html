Linux 的 RAID6 检查工具通过批处理实现 3 倍性能提升

Linux 的 raid6check 工具用于检查和修复 MD RAID6 软件 RAID 阵列中的错误。开发者 David Guillen Fandos 将原本逐条带处理的 I/O 操作改为批处理，以约 512MB 内存为代价，在 6 块 4TB 机械硬盘的 RAID6 配置上实现了 3 倍性能提升。该代码已合并到 mdadm Git 仓库。

Linux 的 RAID6 检查工具通过批处理实现 3 倍性能提升

2026 年 11 月 5 日东部时间下午 12:09。

对于使用 Linux 的 raid6check 命令来检查/修复 MD RAID6 软件 RAID 阵列设备错误的用户来说，新合并的代码显示性能提升高达 3 倍。

raid6check 工具利用 RAID6 阵列的双校验能力来对 Linux 软件 RAID6 设备进行错误检查和修复。目前 raid6check 每次只处理每个磁盘上的一个条带，而开发者 David Guillen Fandos 将其改为批处理以加速 I/O。

David 在现已合并到 mdadm Git 仓库的提交中解释道：

“raid6check 每次只处理（每个磁盘的）一个条带，这使其不受 I/O 限制。通过批处理 I/O 操作，我们以合理的内存代价显著提升了性能（选择了 512MB 作为合理数值，因为更大的值不会带来更多提升，而且对于如今的 RAID 机器来说这也是合理的预期内存量）。

在使用普通机械硬盘、充足内存和现代内核的 RAID6 配置（6 块磁盘 * 4TB）上，这将性能提升了 3 倍。我只能假设类似配置也会有类似的加速效果。”

对于 Linux 软件 RAID 的 RAID6 检查工具性能来说，这是一个非常好的改进。
