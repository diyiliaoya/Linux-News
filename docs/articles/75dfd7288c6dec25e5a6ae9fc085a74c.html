Wine-Staging 11.18 新增补丁进一步改进 WoW64

2026 年 9 月 19 日 09:22 EDT。

在昨天的双周开发版基础上，Wine-Staging 11.18 现已发布。这个 Wine 的实验性版本目前在上游 Git 状态之上携带了 273 个额外补丁，其中包括一些有助于增强 WoW64 支持的新补丁。

Wine-Staging 11.18 包含一些新的 WoW64 补丁，用于在设置 WoW64 入口之前检查二进制文件，以及不为 64 位二进制文件写入 WoW64。提醒一下，Wine WoW64 是在纯 64 位环境中运行 32 位 Windows 应用程序的方式。

这些暂存区中最新 WoW64 补丁的修复之一涉及内核服务代码。同样，2020 年的一个修复也存在于 WoW64 服务代码中。

Wine-Staging 11.18 还包含新补丁，用于在 Quartz 代码中渲染时将 YV12 转换为 RGB，以解决《Worms Forts: Under Siege》（GOG.com）在尝试播放开场动画时崩溃的问题。

除此之外，Wine-Staging 11.18 还引入了最新的 VKD3D Git 代码。
