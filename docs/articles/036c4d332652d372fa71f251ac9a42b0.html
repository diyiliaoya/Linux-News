OpenShot 视频编辑器现已（正式）以 snap 形式提供

OpenShot 视频编辑器现已正式登陆 Canonical Snap Store，用户可通过 snap 命令安装。该 snap 包让旧版 Ubuntu LTS 用户也能用上新版本，但需手动授予麦克风、摄像头和可移动存储权限。目前 Deb 包仍为 3.4 版，Flathub 版本也未更新至 4.0。

OpenShot 视频编辑器现已作为 Snap 提供

现已在 Canonical Snap Store 上架。

这款基于 Qt 的编辑工具的官方 snap 包于今日（9 月 22 日）正式上线。新的 snap 已可通过命令行在所有受支持的 Ubuntu 版本上安装，不过 Ubuntu 归档中也包含 Deb 包，因此搜索时会出现两个结果：

这款开源视频编辑器现已作为 Snap 提供

添加 snap 包将使 Ubuntu 用户更容易安装该视频编辑器。它还能让使用较旧 Ubuntu LTS 版本的用户用上新版本，因为这些用户的 Qt 版本可能阻止他们使用官方 PPA 包。

OpenShot 在 8 月加入了一系列显著改进，包括期待已久的色彩分级工具、更好的多轨录制，以及与基于云的 ComfyUI AI 服务更深入的集成。

如何安装 OpenShot snap 包

OpenShot 4.0 比以往更强大

要从命令行安装 OpenShot snap：

sudo snap install openshot-qt

在撰写本文时，OpenShot 的沙盒版本还不是“安装即用”。你需要授予明确权限，应用才能访问麦克风、摄像头，或打开/保存可移动/外部驱动器上的文件。

可通过以下方式授予这些权限：

设置 > 应用 > OpenShot，或从命令行执行：

sudo snap connect openshot-qt:audio-record

sudo snap connect openshot-qt:camera

sudo snap connect openshot-qt:removable-media

OpenShot 的开发者 Jonathan Thomas 已请求自动连接批准（并请求将 snap 名称改为简单的 openshot），这两项可能在未来几天内获批——如果发生变化，我会修订本文。

OpenShot Deb 包呢？

这对 OpenShot 意味着什么？

OpenShot 的 PPA 已存在很长时间，为不想使用 snap（或官方 AppImage）的用户提供了一种安装应用并持续获得更新的方式。

OpenShot 已在 Flathub 上架，但这是一个未经验证的包，截至本文撰写时尚未更新到最新版本（4.0）——随着其 Snap Store 首秀完成，也许下一步就是正式的 Flathub 发布？

OpenShot 的 Debian 包尚未更新到 v4.0，因此你在 Ubuntu 26.10 归档中找到的 Deb 版本仍是 v3.4。
