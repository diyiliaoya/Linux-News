Linux 7.3 将把英特尔 Nova Lake S 显卡视为稳定版

发布于 2026 年 7 月 30 日下午 5:10（美国东部时间）。

在预计于 2027 年初开始推出的下一代英特尔 Nova Lake 处理器之前，即将到来的 Linux 7.3 内核周期将开始将 Nova Lake S 处理器及其集成显卡视为稳定。

英特尔软件工程师数月来一直在上游提交 Xe3P 显卡支持，其中包括 Nova Lake 的集成显卡。主线内核中已有实验性的 Nova Lake 集成显卡支持，但在现有内核中，需要使用 Intel 显卡 PCI 设备 ID 的 "force_probe=" 模块参数手动启用该支持。但从 Linux 7.3 开始，Nova Lake S 显卡将被视为稳定，并默认启用。

移除 NVL-S 的 "force_probe" 要求的补丁仅说明：

"NVL-S 已足够稳定，我们可以移除 force_probe 要求。让我们这样做。"

该补丁是最终 drm-xe-next 拉取请求的一部分，该请求中的新内容现已提交到 DRM-Next，为下个月的 Linux 7.3 合并窗口做准备。除了默认启用 NVL-S 显卡外，还有各种新的工作区、GuC 更新、RAS 改进和其他修复。

因此，在未来几个月内，如果希望在 Linux 上使用 Nova Lake S 集成显卡，Linux 7.3 将是安全的最低基础版本。
