Fedora CoreOS 将默认启用 systemd-oomd 与 zRAM 交换空间

2026年8月10日，美国东部时间下午3:35。

Fedora 的 CoreOS 作为其面向容器优化的操作系统，将在 Fedora CoreOS 45 中默认启用 systemd-oomd。此外，zRAM 上的交换空间也将默认启用。

Fedora 工程指导委员会（FESCo）现已批准在 Fedora CoreOS F45 版本中启用 systemd-oomd 和 zRAM 交换空间。这使 CoreOS 与其他已使用这些默认设置的 Fedora 变体保持一致。Fedora CoreOS 此前因 Kubernetes 直到最近才兼容节点上的交换空间而推迟了该变更。

相关计划已在该变更的提案中详细说明，该提案现已获得一致通过。

FESCo 本周还批准了将 Fedora Atomic 切换到 Anaconda WebUI，而非基于 GTK 的传统 Anaconda 安装程序。此外，还有针对原子桌面的基于 Web 的远程安装支持。
