Omarchy 4.0 Linux 发行版发布，桌面外壳现通过 Quickshell 实现

2026年8月14日，美国东部时间下午2:10。

Omarchy 作为由 David Heinemeier Hansson（DHH）/ Basecamp 开发的 Arch Linux 发行版，今日发布 Omarchy 4.0，这是该发行版迄今最大的一次发布。

Omarchy 4.0 使用 Quickshell 重写了整个桌面外壳。任务栏、启动器、菜单、通知以及其他元素均基于 Quickshell，通过一个长期运行的 shell 进程实现，该进程连贯、全主题化、支持 IPC 脚本化，取代了原先围绕 Hyprland 合成器部署的多个独立组件。

Quickshell 是一个使用 Qt Quick 的工具包，提供“桌面的构建模块”，兼容 X11 和 Wayland。

Omarchy 4.0 现在还支持双启动安装，ISO 体积比之前更小，新的网络面板使用 NetworkManager，并且这个以桌面为中心的发行版还进行了多项其他增强。

Omarchy 4.0 的完整更改列表以及该新版本的 ISO 下载，可在 Phoronix 网站上查看。
