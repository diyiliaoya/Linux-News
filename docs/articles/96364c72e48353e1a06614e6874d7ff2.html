Redox OS 获得安装程序改进与性能增强

发布于 2026 年 8 月 11 日晚上 8:47（美国东部时间）。

今天，Redox OS 团队发布了一篇新博客文章，重点介绍了这款基于 Rust 的开源操作系统在七月份所做的所有有趣改进。

Redox OS 继续完善其 EEVDF 调度器支持，并降低 CPU 上下文切换的成本，同时改进扩展性。Redox Summer of Code 开发者 Akshit Gaur 通过最新工作，将合成基准测试的时间从约 1.15 微秒降低到约 250 纳秒。最终，当这项工作完成时，将大大提升 Redox OS 的性能能力。

Redox OS 还在改进其基于 GUI 的安装程序，以支持不同的安装模式、镜像快照创建和其他功能。

此外，Redox OS 继续将更多用户空间软件移植到系统中。uutils 的 grep 和 sed 实现现在可以在 Redox 上运行，各种应用程序也是如此。

Redox OS 还进行了各种内核改进、持续的驱动程序增强和其他系统改进。

关于 Redox OS 近期所有这些重大改进的更多细节，请参阅他们的七月亮点报告。
