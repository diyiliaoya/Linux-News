Orion for Linux 测试版更新，支持自定义工具栏

Orion for Linux 测试版 v0.4.3 发布，新增工具栏自定义功能，用户可拖拽添加、移除和重新排列按钮，并支持重置。此外还加入了页面内查找、更新日志对话框和更多网站设置选项，并修复了大量错误。该浏览器基于 WebKitGTK，目前仅以 Flatpak 形式提供。

Orion for Linux 测试版更新，支持自定义工具栏 - OMG! Ubuntu

iOS 和 Mac 网页浏览器的原生 WebKitGTK 移植版现已推出。

Orion Beta v0.4.3 继续完善浏览器的功能集，以与其苹果平台版本保持一致。你现在可以自定义工具栏了。早期测试版中已有上下文菜单选项，但打开的是一个无法使用的按钮选择器——现在它可以正常工作了。

从调色板的“当前工具栏”区域拖出项目即可移除它们，或者从调色板拖到顶部区域来添加。你也可以通过拖拽重新排列按钮。如果需要，还可以重置回默认工具栏布局：

编辑 Orion 的工具栏就像使用 Firefox 一样

我觉得默认工具栏对我来说太杂乱了，所以我一直在等这个功能。

v0.4.3 测试版还新增了可用的页面内查找功能，可以快速跳转到网站上的特定文本；由于 Orion 的对话框中加入了发布说明，了解每次更新的新内容变得更加容易。还添加了更多“网站设置”选项。

页面内查找在 v0.4.3 测试版中可用

v0.4.2 测试版中加入了更多网站设置选项（我之前没来得及介绍）。你可以针对单个网站强制启用深色模式、调整字体大小、禁用粘性页眉，并使用“擦除元素”功能永久移除页面元素——非常方便。

本次更新的其余部分，正如你所料，主要是错误修复。修复了很多。Kagi 团队解决了一系列问题，包括全屏模式下侧边栏和工具栏不隐藏的异常，以及地址栏中锁图标消失的问题。

Kagi 提到对 GTK4/libadwaita 界面进行了进一步改进，但没有详细说明。遗憾的是，驯服那个超大号汉堡菜单还不在其中，唉。

一如既往，Orion for Linux 仍处于测试阶段。它会有错误，会崩溃，也不会给你做早餐。我建议将它作为稳定浏览器的辅助工具——Firefox 156 本周已发布——而不是完全依赖它。

在 Ubuntu 上安装 Orion 测试版

Orion 测试版仅以 Flatpak 应用形式提供。更新来自 Kagi 托管的专用 Orion Beta Flatpak 仓库——Orion Browser 是……

Orion 共享 GNOME 50 运行时。如果这是你将安装的唯一 Flatpak 应用，你需要先添加……以便拉取运行时。

sudo apt install flatpak

flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

flatpak remote-add --if-not-exists orion-beta https://flatpak.orionbrowser.com/orion-beta.flatpakrepo

flatpak install orion-beta com.kagi.Orion

从应用程序网格（或你使用的等效界面）中启动。
