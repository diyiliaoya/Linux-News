Amazon Linux 2027 在 AWS 云中的 AMD EPYC 上展现出显著的性能提升

发布于 2026年9月4日 上午11:33（美国东部时间）

AWS 宣布了 Amazon Linux 2027 的公开预览版，作为当前 Amazon Linux 2023 内部发行版的继任者。随着所有软件升级和改进，例如现在使用链接时优化（LTO）构建软件包、强制执行 x86-64-v3 构建以及其他更改，我迫切希望在 EC2 云中对 Amazon Linux 2023 和 Amazon Linux 2027 进行性能基准测试。

Amazon Linux 2027 带来了许多重大软件包升级，例如默认内核为 Linux 7.1，而 Amazon Linux 2023 当前的默认内核是 Linux 6.18。编译器升级幅度很大，从默认的 GCC 11.5 跃升至新的 GCC 16.1。还有其他关键升级，例如从 Python 3.9 升级到 Python 3.14。一些软件包更新并不那么重要，比如 OpenJDK 25~26，这些更新已经回移植到了 Amazon Linux 2023。

但除了软件包版本升级之外，Amazon Linux 2027 现在使用 LTO 编译器优化、x86-64-v3（假设支持 AVX/AVX2）以及其他基础改进，这使得基准测试变得非常有趣。Amazon Linux 2027 的软件包大致基于 Fedora 44~45 的源代码，并包含一些更改。

从昨天开始，我一直在对当前状态的 Amazon Linux 2023 与新的 Amazon Linux 2027 公开预览版进行全新的基准测试。由于没有获得任何云额度，且 Phoronix 的运营预算持续非常紧张，我将 Amazon Linux 基准测试限制在单个实例上，使用 AMD EPYC 第五代“Turin”处理器，采用通用型 m8a.4xlarge 实例，因为 16 个 vCPU 大小的云虚拟机最受欢迎。与我通常的测试相比，运行的基准测试数量也相当有限，同样是为了在这些网络出版领域的困难时期尽量减少成本。

EPYC 9R45 配备 16 个 vCPU，搭配 64GB DDR5-6400 内存和 400GB 本地存储。在此基础上，进行了 Amazon Linux 2023 和 Amazon Linux 2027 的 m8a.4xlarge 基准测试，以了解这个新 Amazon Linux 版本的默认性能表现。
