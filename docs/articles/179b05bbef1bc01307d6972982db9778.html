有保质期的发行版？Gravity Linux 是面向 Apple Silicon 的新发行版

Gravity Linux 发布了首个 alpha 版本，面向 M4 Mac mini，基于 Fedora 和 KDE Plasma on Wayland。其驱动通过逆向工程开发，目标是最终将所有驱动工作上游至 Linux 内核，届时该发行版将不再必要并计划终止。当前版本支持硬件加速图形，但暂不支持休眠、雷电/USB4 和 USB-C 显示输出，且升级到 beta 需完全重装。

其首个 alpha 版本面向 M4 Mac mini，基于 Fedora，所有驱动工作都瞄准上游 Linux 内核。

与你对新发布的 Linux 发行版的预期相反，Gravity Linux 有一个长期目标：不再作为一个发行版存在。该项目是面向 Apple Silicon Mac 的发行版，默认搭载 KDE Plasma on Wayland 桌面。

其中的一切均通过逆向工程构建，确保没有 Apple 源代码、反汇编或泄露的技术信息进入该项目的代码。

Gravity Linux 的主要推动力来自……，它从……分叉而来，共同目标是将 Linux 带到 Apple Silicon。他们走上这条路是因为在 LLM 使用方面的贡献政策存在分歧。Gravity Linux 的立场在其提交历史中清晰可见，该项目的内核分支带有公开将 AI 编码工具与人类作者并列署名的提交。

工作与不工作内容的概述。

首个 alpha 版本运行在 M4 上，显示控制器和 GPU 均可工作，并包含 OpenGL ES 3.0 和 OpenGL 3.3 合规性，这意味着硬件加速图形可用。

这是一个面向开发者的 alpha 版本，存在一些使其不适合日常使用的缺点。休眠不可用，Thunderbolt 和 USB4 支持不存在，USB-C 显示输出不受支持，不过通过 HDMI 输出可以工作。

关机和重启被描述为不稳定，建议使用电源按钮作为获得可预测体验的变通方法。扬声器音量也被限制以确保硬件安全。

用户还应了解，当 beta 版本在稍后发布时，需要完全重新安装，因为 Gravity Linux 团队不保证从 alpha 版本的升级路径。

有保质期的发行版？

尽管 M4 Mac mini 是首个目标，但它并不是唯一的目标。当前计划涵盖以及其余的 M4、M4 Pro 和 M4 Max 产品线，一些新贡献者已经在其中几款设备上取得进展。

M5 则是另一回事。在 M5 Pro 和 M5 Max 硬件上，macOS 27.0 Beta 5 使设备在启动时配置错误，阻止次级 CPU 核心启动。Apple 据称已知晓此问题，但没有关于何时修复的消息。

Gravity Linux 还计划在发布支持之前将整个 M5 产品线保持在相同的固件版本上，因此在 Apple 解决该问题之前，M5 将一直搁置。

最终目标是将所有驱动工作上游至 Linux 内核和相关用户空间项目，同时公开记录其逆向工程方法的每一步。

已经反映了这一方向。除了发行版层脚本之外，该项目还维护 Linux 内核、Mesa 和 U-Boot 的分叉。这些正是这项工作最终需要落地的上游项目。

一旦上游工作落地，任何主流 Linux 发行版都可以在受支持的 Apple Silicon 硬件上运行，而无需像这样的单独重制版。到那时，Gravity Linux 这个发行版就不再必要，团队也计划在那时终止它。
