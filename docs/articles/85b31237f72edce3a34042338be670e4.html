AMD开始为RDNA5 GPU提交Display Core Next 6 "DCN6" Linux补丁

AMD在7月底发布了新的AMDGPU显示核心补丁，其中包含多个为下一代显示IP——Display Core Next 6（DCN6）奠定基础的补丁。这些补丁将DCN6与AMD GFX13图形引擎关联，预计用于下一代RDNA5图形处理器。这是DCN6的首次公开提及，其IP版本为6.0.0，接替DCN 4.2.1，但DCN5尚未在驱动中出现。补丁还引入了新的缩放线性度、表面特性、UPSP预缩放器及更多像素格式。RDNA5 GPU预计2027年发布，未来将有更多开源驱动补丁。

AMD在7月底发布了新的AMDGPU显示核心（DC）补丁。在这次每周补丁例行更新中，最引人注目的是多个补丁开始为Display Core Next 6（DCN6）奠定基础，这是他们的下一代显示IP。这些补丁将DCN6与AMD GFX13图形引擎关联起来，预计该引擎将用于下一代RDNA5图形处理器。

对于AMDGPU Linux驱动，目前持续进行的工作包括扩展显示代码的KUnit单元测试覆盖范围、一些修复、围绕显示流验证的重构，以及最重大的——启用DCN6支持。

这些是DCN6的首次公开提及，它是为即将推出的AMD GPU准备的下一代显示逻辑。有趣的是，这个DCN 6.0.0 IP接替了DCN 4.2.1……那么DCN 5在哪里？在今天的补丁中，至少有一处提到了DCN5，但在AMDGPU驱动中尚未发现DCN5的bring-up。我们将看看这是否会到来，也许DCN5用于某些未来的AMD移动平台，而DCN6可能用于桌面显卡。或者，DCN5可能因未知原因被最终跳过。

这些补丁确实将一些DCN6引用与GC/GFX 13.0.1关联起来，后者被认为是带有GFX13的RDNA5。

AMD DCN6带来了新的缩放线性度和用于平面的cositing表面特性，UPSP预缩放器可在缩放前对420/422内容进行上采样，以及额外的像素格式和其他底层更改。

由于RDNA5 GPU预计要到2027年才会推出，我们将看看未来几个月会有哪些更多的开源Linux图形驱动补丁出现。希望在发布之前，我们能看到成熟的开源AMD RDNA5图形驱动支持。
