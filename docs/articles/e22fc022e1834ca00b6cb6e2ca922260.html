Intel 与 AMD 现已在 PyTorch/oneDNN 上合作进行软件优化

Intel 和 AMD 宣布将围绕 oneDNN 展开合作，把 AMD Zen 处理器的优化整合进 oneDNN，使其成为 PyTorch 在 x86 平台上的默认开源加速库。AMD 还将加入 UXL 基金会并担任指导成员。此举延续了两家公司在 x86 生态系统咨询小组中的合作，标志着竞争对手在软件生态上的罕见联手。

Intel 长期致力于为其硬件调优神经网络库，并见证了该库被 PyTorch 和其他 AI 框架采用。AMD 则维护着作为其下游分支的 oneDNN API 兼容版本，同时针对其 Zen 处理器设计进行适配。有趣的是，AMD 和 Intel 今天联合宣布，他们将围绕面向 PyTorch 的 oneDNN 展开合作，并将 AMD Zen 的改进推入 oneDNN。

这两家竞争公司宣布，他们将致力于把针对 PyTorch 的 x86 CPU 优化工作合并到 oneDNN 中。此前，他们已在 x86 生态系统咨询小组的 ISA 层面进行过合作。

两家公司将专注于将 oneDNN 作为 PyTorch 中 x86 加速的默认开源库。AMD ZenDNN 的优化将进入 oneDNN。此外，AMD 将以指导成员身份加入 UXL 基金会。

随着许多原 oneAPI 软件项目转入由 Intel、三星、高通、Arm 和其他厂商支持的该联盟，AMD 现在也加入其中，为 oneDNN 做出贡献。
