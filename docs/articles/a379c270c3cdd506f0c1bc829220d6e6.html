Shader Effects 是你这个周末最该尝试的 GNOME 扩展

Shader Effects 是一款新的 GNOME Shell 扩展，能为整个桌面或特定窗口添加 GPU 加速的复古滤镜效果，如扫描线、NTSC RGB 泛光和 CRT 绿光闪烁。用户可调节效果强度、动画速度和帧率，但高数值会增加 GPU 负担。该扩展适合短时间使用，让截图或录屏更具视觉趣味，支持 GNOME 48-51。

你是否曾好奇，如果你的 Ubuntu 桌面看起来像是在一盘磨损的 VHS 录像带或老式单色 CRT 显示器上播放，会是什么样子？

你大概没想过，但一个新的 GNOME Shell 扩展让你无论如何都能一探究竟。

它会对整个桌面或（如果你愿意）仅对特定窗口应用 GPU 加速的滤镜，比如扫描线、NTSC RGB 泛光和闪烁的绿色 CRT 辉光。
