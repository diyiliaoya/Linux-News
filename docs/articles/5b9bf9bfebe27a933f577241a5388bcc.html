Framework Laptop Pro 13 / Core Ultra X9 388H 在 Linux 7.1+ 上运行带来的显著性能提升

Phoronix 对 Framework Laptop 13 Pro（搭载 Intel Core Ultra Series 3 "Panther Lake"）在 Linux 7.0、7.1 和 7.2 内核下的性能进行了基准测试。测试表明，在 Ubuntu 26.04 LTS 上，升级到 Linux 7.1 或即将发布的 7.2 内核能带来更好的性能表现。这些性能提升预计也适用于其他搭载 Intel Panther Lake 处理器的笔记本电脑。

最近发布的搭载 Intel Core Ultra Series 3 "Panther Lake" 的 Framework Laptop 13 Pro 在 Ubuntu 26.04 LTS 和其他现代 Linux 发行版上运行良好。在 Ubuntu 26.04 搭配 Linux 7.0 的情况下，虽然一切功能正常，但升级到 Linux 7.1 或即将推出的 Linux 7.2 内核会获得更好的性能。以下是 Framework Laptop 13 Pro 搭载 Core Ultra X9 388H 在 Linux 7.0、7.1 和 7.2 内核下的基准测试结果。

对于那些好奇升级到 Linux 7.1 稳定版性能差异，或者想知道预计本周末发布的 Linux 7.2 内核是否还有额外性能提升的人，以下是我最近在 Framework Laptop 13 Pro 上进行的基准测试，比较了 Ubuntu 26.04 在三个最新内核系列下的表现，同时保持软件和硬件堆栈的其他部分不变。

虽然所有这些测试都是在 Framework Laptop 13 Pro 上进行的，但内核升级带来的性能影响在很大程度上应该也适用于其他搭载 Intel Panther Lake 处理器的笔记本电脑。再次感谢 Framework Computer 提供 Framework Laptop 13 Pro，使得这些持续的 Linux 性能测试得以进行。
