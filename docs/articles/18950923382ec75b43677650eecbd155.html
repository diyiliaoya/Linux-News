Polo：MATE 桌面的 Wayland 合成器

Polo 是专为 MATE 桌面设计的新 Wayland 合成器，旨在让 MATE 在 Wayland 下的行为尽可能接近 X11。它已支持窗口管理、平铺、工作区、剪贴板、多显示器、缩放、屏幕共享和 MATE 会话管理，并包含经典桌面特效如 3D 立方体、摇晃窗口和神灯最小化。目前尚不完整且未经充分测试，开发者 Kerem Söke 正寻求志愿者测试。MATE 官方尚未有 Wayland 会话，但若 Polo 运行良好，未来可能被采纳。

Polo 是 MATE 桌面的一个新 Wayland 合成器。

MATE 可能有意保留着过去的一面，但这并不意味着它的粉丝们没有放眼未来——而未来将包括 Wayland。

Polo 是一个新的 MATE 桌面 Wayland 合成器，模仿了该桌面现有的基于 X11 的窗口管理器 Marco（它源自 GNOME 的 Metacity）。

“我们的想法是让 MATE 的行为尽可能接近它在 X11 上的表现，而不是为了适应不同的合成器而改变桌面，”独立于 MATE 项目开发 Polo 的 Kerem Söke 说道。

Polo 已经支持窗口管理和平铺、工作区、剪贴板、多显示器设置、缩放、屏幕共享和 MATE 会话管理。它甚至包含经典的桌面特效，比如标志性的 3D 桌面立方体、摇晃窗口以及像神灯一样的窗口最小化效果。

Polo 包含经典桌面特效和视觉亮点。

它还不完整，也没有经过充分测试。因此，Söke 正在寻找志愿者在他们的硬件上以及日常使用的应用程序中尝试它。遗憾的是，测试并非易事。Polo 需要从源代码编译，最好还搭配最新的 MATE 桌面。

许多 Linux 桌面在同时支持传统 X11/Xorg 显示服务器多年后，已经放弃或正在逐步放弃对其的支持。对于代码库较旧、志愿者较少的较小桌面环境来说，迁移到 Wayland 是一项艰巨的任务。

MATE 的开发者们正在为 Wayland 做准备。最近的版本已经为桌面图标渲染等应用程序添加了 Wayland 支持。这项工作零敲碎打，而且通常只有在使用正确的编译标志构建时才会存在。

目前还没有官方的 MATE 合成器或 Wayland 会话。虽然现在这还不是官方的，但如果它能工作，并且工作得很好，那么没有理由说它不能被采纳。
