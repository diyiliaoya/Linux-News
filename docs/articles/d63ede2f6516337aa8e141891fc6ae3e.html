2026年10月8日，Ubuntu 网站遭遇“持续分布式拒绝服务攻击”，导致 canonical.com、ubuntu.com 等主要域名离线约4小时12分钟。这是 Canonical 今年第二次重大攻击，5月曾发生类似事件。本次 PPA、Launchpad、Snap Store 等服务未受影响。事件已解决。

Ubuntu 网站因“持续”DDoS 攻击而离线

Ubuntu 的网站今天（2026年10月8日）正经历一场“持续的分布式拒绝服务攻击”。

事件已解决，网站离线时长4小时12分钟。

其部分在线站点将“间歇性不可用”，同时团队正在努力解决该事件。目前没有恢复上线的时间表，但这可以理解，因为“自动化 volumetric 攻击”很少按计划进行。

这是该公司今年经历的第二次重大攻击。

早在5月，Canonical 的大片基础设施被迫离线，原因被其称为“持续的跨境攻击”。该事件导致主要网站和博客、Launchpad PPA、Ubuntu 单点登录、邮件列表、签名密钥和 Snap Store 中断。

Ubuntu 的 APT 仓库（已镜像和分发）当时未受影响，操作系统构建基础设施和 ISO 下载也未受损害。

据我所知，Canonical 没有公开表示谁应对5月的攻击负责，也没有说明为何成为目标。它确实进行了事后“解剖”，以吸取教训并加固基础设施，防止再次发生。

那些“教训”奏效了吗？

这一次，只有主要的 Ubuntu 和 Canonical 域名出现中断，包括 canonical.com、ubuntu.com、blog.ubuntu.com、developer.ubuntu.com 以及 Ubuntu 安全 API 和通知页面。

截至撰写本文时，Ubuntu PPA、CD 镜像服务器、Launchpad、Snap Store、Ubuntu SSO 等均正常运行。

您可以通过 Canonical 和 Ubuntu 状态页面实时监控情况。
