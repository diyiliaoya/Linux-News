Ubuntu 应用中心让安装缺失的媒体编解码器变得简单

Ubuntu 应用中心新增功能，可安装受限媒体编解码器和硬件驱动。此前用户在系统安装时若未勾选“安装受限编解码器”或离线安装，后续获取编解码器较为麻烦。新流程在应用中心提供图形化安装入口，并新增驱动管理页面，方便安装 NVIDIA 等专有驱动。

Ubuntu 的应用中心让安装缺失的媒体编解码器变得简单——OMG! Ubuntu

现在可以安装受限媒体编解码器以及硬件驱动了。

新的流程应该会让以下用户更省事：那些在 Ubuntu 操作系统安装程序中没有选择“安装受限编解码器”的用户（不是所有人都觉得自己需要它），以及那些在没有活跃互联网连接的情况下安装的用户，因为那个选项是灰显的。

如果你知道正确的……就能轻松获取相关编解码器

……不会在搜索结果中显示系统或库软件包（而且“媒体编解码器”这个词有点太笼统了）。

增加一个图形化安装流程，让人们去他们自然会看的地方找，能让安装后的媒体设置稍微容易一点。

我应该提一下，如果用户尝试播放需要某些编解码器的文件，……确实会触发一个安装对话框。这很有用，但有缺陷：那个界面既不够优雅，信息也不够充分，而且它并不涵盖所有缺失的编解码器。

应用中心正在扩展

在选定的硬件上，新的……页面也会出现在这个页面中，该页面将在 26.10 中推出。它旨在让安装和管理 NVIDIA GPU、某些 Wi-Fi 网卡/适配器以及其他特定硬件的专有驱动变得更容易。

Ubuntu 26.04 LTS 将……工具从其默认软件阵容中移除，该工具此前被用户用来检查并启用/禁用闭源硬件驱动（它有自己的应用快捷方式）。
