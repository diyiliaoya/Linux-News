从 JDK 8 到 OpenJDK 27 的 Java 性能基准测试

发布于 2026 年 9 月 23 日美国东部时间上午 10:17。

随着最近的发布，由于已有几年没有关注 OpenJDK Java 性能，我开始进行一些新的基准测试。一发不可收拾，我最终重新测试了所有主要的 OpenJDK 版本，一直追溯到古老的 JDK 8。

使用搭载 AMD Ryzen Threadripper 9980X 的 System76 Thelio Major 工作站，运行 Fedora Workstation 44，我对从 Java 8 时代以来的所有 OpenJDK 版本进行了基准测试。不过，所使用的一些 Java 基准测试在 OpenJDK 11 之前的版本上最终出现了问题。

为了严谨性和可复现性，在这次 Java 运行时性能评估中，每个 OpenJDK 版本都使用默认配置/设置和官方 OpenJDK 二进制文件进行开箱即用的测试。

因此，对于那些好奇 OpenJDK Java 运行时性能从十多年前（2014 年）的 OpenJDK 8 时代以来如何演变的人，以下是各种 DaCapoBench 和 Renaissance Java 基准测试的结果。
