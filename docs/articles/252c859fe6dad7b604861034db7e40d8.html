发行版发布：PrismLinux 2026.08.15

基于 Arch 的 Linux 发行版 PrismLinux，带有自定义系统安装程序，支持 Cinnamon、GNOME 和 KDE Plasma 桌面，以及 niri Wayland 合成器，已更新至版本 2026.08.15：

“经过两个多月没有发布，PrismLinux Reborn 1.0 终于来了。此版本代表了整个发行版的一轮重大重新设计、迁移、优化和生态系统清理。安装程序已全面重新设计并打磨，作为从 Web 技术迁移到原生实现的一部分。新的和改进的安装程序功能包括：安装期间选择键盘语言；可选的 Chaotic-AUR 支持；在 GRUB、systemd-boot 和 rEFInd 之间选择引导管理器；GRUB 作为默认引导管理器；固件感知选择——不支持 systemd-boot 或 rEFInd 的系统，包括传统 BIOS 安装，将仅提供 GRUB；每个支持的桌面环境默认启用 Flatpak。驱动程序处理已优化。安装程序现在检测系统，并为该硬件安装适当的驱动程序和相关软件包。”

更多 PrismLinux 新闻...

PrismLinux 是一个基于 Arch Linux 的极简发行版。live 镜像启动到 River Wayland 合成器和自定义系统安装程序，该安装程序提供了多种流行的桌面选项可供安装，包括 KDE Plasma、GNOME、COSMIC 和 Cinnamon，以及定制的 Niri Wayland 合成器。该发行版使用长期支持（LTS）Linux 内核，编译时带有针对速度优化的内核参数，并包含预配置的 TLP 实用程序以延长电池寿命。
