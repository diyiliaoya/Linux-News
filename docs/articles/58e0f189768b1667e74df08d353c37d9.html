Ubuntu Phone工程师因十年前的bug关闭而意外重聚

一个在Ubuntu Launchpad上存在近十年的bug于上周末被标记为无效，意外引发了前Canonical工程师们的即兴重聚。该bug由一位花费700英镑购买Ubuntu手机和平板硬件的用户在2016年提交，因缺乏官方文档而抱怨。随着bug被关闭，订阅该bug的前工程师们收到邮件通知，纷纷在评论区回忆往事，表达对Ubuntu Phone项目的怀念。尽管该项目在2017年被终止，但其技术遗产通过Ubports等项目得以延续。

一个在Ubuntu Launchpad上存在近十年的bug于上周末被标记为无效，意外引发了前Canonical工程师们的即兴重聚。

该bug由一位用户在2016年提交，他花费了700英镑购买Ubuntu手机和平板硬件，但在访问官方网站时，发现没有任何文档告诉他如何使用这些设备。Canonical在2017年终止了Ubuntu Phone项目，导致这个bug一直未解决。

Ubuntu bug分类团队成员Adolfo Jayme Barrientos于上周末标记该bug为无效，并附上评论解释（迟到了近十年）称，手机“相关工作已拆分至Ubports”。但在评论关闭时，任何订阅了该bug（或选择接收Ubuntu特定部分bug通知）的人，如前工程师们当时所做的那样，都会收到邮件通知状态变更。这意外引发了一场怀旧潮。

Ubuntu Phone：用‘Scope’而非应用

“这是什么，前‘疣猪’重聚吗？”曾在手机交付团队工作并担任Ubuntu Phone‘Scope’技术负责人的Chris Wayne在收到更新后回复道。

Marcus Tomlinson曾帮助构建Scopes框架，但在加入重聚行列时，却意外坦白：“我其实仍然不太清楚‘Scope’是什么……而且是我写的”——你和全世界都一样，对吧Marcus？

对于那些不熟悉的人来说，Ubuntu Phone的主屏幕由‘Scope’组成，表面上取代了应用的需求，你可以在Scope中访问其内容（我选择将其解读为对这个博客的模糊记忆）：“哦天哪 :) 我在他们解散整个Ubuntu Phone团队时离开了Canonical :D 我对那个项目有着非常美好的回忆。”

Matt Fischer，自2010年代初在Canonical工作，将这次即兴重聚描述为“令人惊叹的怀旧”，并指出手机/平板是他在这家公司期间参与的最后一个项目。“每隔一段时间，就会有人关闭我提交的旧bug，”他写道。

温暖的评论持续不断，夹杂着常见的寒暄。“希望大家一切都好！”等等。如果重聚持续到深夜，希望像上次同学聚会一样，有人喝醉并端上茶来。

Ubuntu Phone并非毫无价值

Ubuntu Phone通过Ubports得以延续。Canonical在2017年裁掉了大部分手机团队成员（以及许多其他员工），此前Mark Shuttleworth承认事情并未如愿。公司投入了大量资金，却未能成功，因此回归核心业务。

Ubuntu Phone并非白费力气。Ubports诞生于Ubuntu Phone的遗产；Mir被重新用于Wayland合成器，现已在工业和嵌入式环境中使用；Ubuntu桌面通过切换到GNOME而复兴。

Ubports接管了Ubuntu Phone并一直维护至今，甚至将其搭载在Pine64和Volla的新款（尽管小众）手机上。最近一次更新是在7月。

尽管参与者们有着温暖的回忆，但原始bug报告者在2016年留下的一条存档评论提醒我们，为什么Ubuntu Phone是发行版历史中的一个脚注，而非持续的功能：“我花了超过700英镑的真金白银购买Ubuntu品牌的硬件，手机和平板，不仅半成品，而且根本没人费心写任何用户文档？我认为这相当轻蔑。”他当时写道。

Ubuntu Phone并未在更广泛的世界中取得成功，但根据这个bug线程中迟来的温暖氛围，它显然对帮助创造它的人们有着特殊意义。而且，是的，有点像！尽管更统一、全高、标准化。与其为Ubuntu制作应用，想法是ISV可以将他们的API插入一个样板Scope中，以（或多或少）实现与应用相同的功能。
