Redox OS 实现 Golang 支持、GIMP 移植及简化 AI 政策

Redox OS 发布十月开发进展：Go 语言编译器已可在该平台运行，支持交叉编译和自举编译；GIMP 图像编辑器经数月努力成功移植；Servo 浏览器引擎更新至 0.7；初步 NUMA 支持运行良好，修复 RISC-V 动态链接，并实现用户路径下的无根包安装。此外，AI 政策简化为不接受 LLM 生成的贡献。

基于 Rust 的 Redox OS 开源操作系统现已发布十月开发摘要，重点介绍了近期的软件移植、NUMA 进展以及对这个从零构建的平台所做的其他改进。

Redox OS 在十月成功让 Go 编程语言编译器在该平台上运行。Golang 在 Redox OS 上既支持交叉编译，也支持自举编译。Golang 已适配使用 Relibc。

Redox OS 还经过数月努力成功让 GIMP 图像编辑器运行起来。Redox OS 还将其 Servo 浏览器引擎移植更新至较新的 Servo 0.7 代码状态。

Redox OS 还确认其初步 NUMA 支持运行良好，修复了 RISC-V 动态链接，并在用户等效路径中实现了初步的无根包安装。

Redox OS 在十月还将其 AI 政策简化为：

“Redox OS 不接受由 LLM（大型语言模型，有时也称为‘AI’）生成的贡献。”
