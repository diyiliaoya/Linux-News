F-Droid 的新应用表明它不会消失

F-Droid 发布了基于 Compose 的 2.0 版本，这是其历史上最大规模的更新。新版用 Kotlin 重写了原有 Java 代码库，界面全面现代化，底部导航分为探索、更新和设置三部分，搜索、筛选和后台更新检查等功能均得到改进。与此同时，F-Droid 正联合 70 多个组织反对谷歌 2027 年起强制开发者注册的政策，此次重大更新彰显了其不向谷歌压力妥协的立场。

F-Droid 的新应用表明它不会消失

基于 Compose 的 2.0 应用发布标志着该应用商店历史上最大规模的更新。

F-Droid 一直是下载免费和开源 Android 应用的首选之地。其客户端应用是人们接触最多的部分，多年来经历了多次升级。

但现在，经过一年多的开发和众多测试版本的积累，一次大规模重写终于到来。

全面重新设计

Kotlin 取代了原来的 Java 代码库，界面也基于 Compose 重建。最终的应用全面遵循 Material Design 3 设计规范，外观和行为都像是一款属于现代 Android 设备的应用。

应用的底部栏现在有三个部分：探索，用于查询和快速访问分类；更新，用于跟踪已安装应用、更新和问题；以及设置。

你还会发现，设置菜单已移至右上角，与新的探索页面并列。探索页面经过配置，会突出显示新添加的应用、最近更新的应用以及仓库中下载量最多的应用。相关分类被归组在一起，使得浏览完整目录更加容易，不会在长长的列表中迷失方向。

搜索现在除了应用名称外，还能处理分类、应用描述和翻译内容，搜索查询的结果也有所改善。你的搜索历史也会被保存，以供将来查询使用。

筛选功能也经过了重新设计；结果可以同时按反特性、设备兼容性和分类进行缩小范围。

这是旧版 F-Droid 应用的对比外观。

默认情况下，应用会在后台检查更新，不再需要过去触发仓库扫描的下拉手势。当然，进入三点菜单后，仍可从更新页面手动检查。

同样，将 F-Droid 图标隐藏为计算器应用的功能已移至设置中。应用分享工具已被暂时移除。

在公告的结尾，F-Droid 表示：

F-Droid 2.0 代表着一个重要的里程碑，但并不是故事的终点。重建应用为我们提供了更坚实的基础，但前方仍有大量工作要做。

随着新版本推送给更多用户，我们期待从实际使用中学到很多。从最早的设计讨论到众多 alpha 和 RC 版本，社区反馈塑造了 F-Droid 2.0，它将继续指导未来的改进。

此前，谷歌宣布从 2027 年起，每个 Android 应用开发者都需要向该公司注册，提供政府颁发的身份证件、签名密钥证明以及一笔费用。

这样一来，来自未注册开发者的应用将被阻止在经过认证的 Android 设备上运行。

当然，F-Droid 并没有坐视不管；其董事会成员 Marc Prud'hommeaux 发起了 Keep Android Open 运动作为回应，该运动目前已汇集了来自 20 多个国家的 70 多个组织。

其签署者包括电子前沿基金会、自由软件基金会、KDE、Proton、Codeberg、VideoLAN、LineageOS、CryptPad 和 Tor Project 等知名组织。

距离这一荒谬的封锁措施生效已不足 90 天，F-Droid 推出如此重大的更新，只会更加坚定他们不向谷歌强权策略让步的立场。

F-Droid 2.0 将在未来几周内逐步推送，所以如果你现有的安装还没有收到更新，请耐心等待。对于新安装，情况类似，因为最新的稳定版本仍是 1.23.0。

另一方面，如果你不想练习耐心的美德，可以从 GitLab 下载最新的 2.0 beta 版本。
