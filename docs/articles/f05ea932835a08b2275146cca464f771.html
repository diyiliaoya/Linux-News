Firefox 157 发布：全新视觉刷新，WebRTC 硬件 AV1 解码

Firefox 157 正式发布，带来被称为“多年来最大视觉刷新”的 Nova UI，更新了浏览器界面、侧边栏和菜单。该版本还新增 WebRTC 视频通话的硬件 AV1 解码支持，修复 HDR 视频问题，改进变速播放时的音视频同步，并移除了内置的 Amazon 搜索引擎。

作为 Mozilla Firefox 双周发布计划的一部分，Firefox 157 的二进制版本现已面向这款开源网页浏览器提供。

Firefox 157 最引人注目的是其 Nova UI，被称为该浏览器“多年来最大的视觉刷新”。Nova 界面旨在使浏览器外观、侧边栏和菜单更加现代化。

Firefox 157 现在还支持在兼容设备上为 WebRTC 视频通话使用硬件 AV1 解码。此前，Firefox 在 WebRTC 的 AV1 视频中一直依赖软件解码。

Firefox 157 版本还修复了 HDR 视频问题，改进了更改视频播放速度时的音频和视频同步，并移除了内置的 Amazon 搜索引擎。
