X.Org Server 与 XWayland 中又发现十余个漏洞

TrendAI 零日计划在 X.Org Server 和 XWayland 中披露了 12 个新的安全漏洞，涉及释放后使用、缓冲区溢出和越界读写等问题，影响 xorg-server-21.1.25 和 xwayland-24.1.14 之前的版本。

在 AI 的协助下，今晚又公开了十几个影响传统 X.Org Server 以及 XWayland 的安全漏洞。

TrendAI 零日计划发现了另外 12 个影响传统 X.Org Server 代码库以及 XWayland 的安全漏洞。TrendAI 零日计划过去曾发现大量 X.Org 安全问题，并且进一步延续了十多年前由另一位安全研究员定下的基调——那位研究员早在 2013 年就曾表示，X.Org 的安全性甚至“比看起来还要糟糕”。

最新一轮 X.Org Server 和 XWayland 安全披露包括：

* CVE-2026-88812：XKB SetGeometry TextDoodad 双重释放

* CVE-2026-93515：Present 扩展跨窗口 Notify 释放后使用

* CVE-2026-93516：XInput 被动抓取 modifierDevice 释放后使用

* CVE-2026-93517：GLX RenderLarge 堆缓冲区溢出

* CVE-2026-93518：XKB ResizeKeyType 数值截断

* CVE-2026-93519：XFixes 指针屏障事件列表缓冲区溢出

* CVE-2026-93520：XKB ChangeKeycodeRange 堆越界写入

* CVE-2026-93521：RandR ChangeProviderProperty 堆缓冲区溢出

* CVE-2026-93522：Glamor CopyArea CPU-FBO 堆缓冲区溢出

* CVE-2026-93523：XInput2 PassiveUngrabDevice 修饰键越界写入

* CVE-2026-93524：XKB SetMap 键宽/动作计数不同步越界读取

* CVE-2026-93536：GestureBuildSprite 释放后使用

大量释放后使用、缓冲区溢出以及越界读写问题继续存在于 X.Org Server 代码库中。

这些问题存在于新的 xorg-server-21.1.25 和 xwayland-24.1.14 之前的版本中。
