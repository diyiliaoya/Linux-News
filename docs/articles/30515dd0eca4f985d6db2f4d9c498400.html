AMD RDNA5 初始支持将登陆 Linux 7.5

AMD 已向 DRM-Next 提交最新内核图形/计算驱动更新，为 Linux 7.5 合并窗口做准备，其中最引人注目的是初步的 GFX13 支持，即面向 RDNA5 图形处理器的初始启用工作。补丁还包括 GMC 13 图形内存控制器和 SoC v2.0 支持，以及更多 DCN6 显示核心更新。目前仍属实验性支持，但 RDNA5 在 Linux 7.5 中的启用已开始。

AMD RDNA5 初始支持将登陆 Linux 7.5

发布于 2026 年 11 月 26 日 20:55 EST。

最初的 AMD GFC13 / GC 13 IP 补丁已被发布，针对预计用于 RDNA5 图形处理器的下一代图形 IP 块。巧合的是，这项最初的 RDNA5 图形驱动启用工作现在有望进入 Linux 7.5 内核。

今天发出了最新一轮 AMD 内核图形/计算驱动改动，进入 DRM-Next，为 Linux 7.5 合并窗口做准备。今天拉取请求中最值得注意的是初步的 GFX13 支持。它仍被视为非常初期/实验性的支持，但至少 RDNA5 在 Linux 7.5 中的启动工作已经开始。

除了新的图形控制器，今天提交到 DRM-Next 的 AMDGPU 补丁还包括用于更新图形内存控制器的 GMC 13 和 SoC v2.0 支持。此外还有更多 Display Core Next 6（DCN6）的更新，这很可能也用于驱动 RDNA5 硬件的显示。

最初的 RDNA5/GFX13 相关补丁并未透露下一代 AMD Radeon GPU 的任何特别揭示性细节，但我们将看到在推出任何新功能或能力方面还会有更多进展。

今天 AMDGPU 和 AMDKFD 的大多数其他改动都是错误修复。无论如何，很高兴看到这项初始的、推测为 RDNA5 的启用工作开始进入 Linux 7.5 内核，该内核将于第一季度稳定发布。预计后续内核版本将像往常一样继续完善开源 AMD GPU 驱动支持，同时有传言称 RDNA5 显卡将在 2027 年晚些时候首次亮相。
