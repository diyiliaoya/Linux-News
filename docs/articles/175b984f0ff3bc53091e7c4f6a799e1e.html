USB4STREAM 添加忙轮询选项：以增加 CPU 周期为代价降低延迟

发布于 2026 年 8 月 5 日下午 5:27（美国东部时间）。

Linux 7.2 的一个亮点新功能是 USB4STREAM，这是英特尔开发的解决方案，用于在 USB4 连接的系统之间快速发送数据。现在，在即将到来的 Linux 7.3 周期中，将添加忙轮询模式，以增加 CPU 活动为代价提供更低延迟的数据传输。

英特尔工程师开发了 USB4STREAM 协议，这是一种使用 USB4/Thunderbolt 在主机之间传输原始数据包的极简方法。英特尔 Thunderbolt 专家 Mika Westerberg 在 Claude Opus 4.8 的协助下，设计了一种用于 USB4STREAM 的忙轮询方法，以提供更低延迟的传输。排队中的补丁说明如下：

“使用中断和调度工作线程会增加延迟，因此对延迟敏感的应用可能希望避免这种情况。通过在 USB4STREAM 中添加一个新的 ConfigFS 属性：busy_poll，当激活时，将环切换到轮询模式，即可实现这一点。降低延迟的代价是消耗更多 CPU 周期，并且无法使用 poll(2) 等功能。”

对于 Linux 7.3+，可以通过以下路径切换 USB4STREAM 的忙轮询模式：

/sys/kernel/config/thunderbolt/stream/[xdomain].[service]/$name/busy_poll

该补丁目前位于 thunderbolt.git 的 next 分支中，等待即将到来的 Linux 7.3 合并窗口。
