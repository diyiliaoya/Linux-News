神秘的16-Tile和32-Tile AMX实现被热议以提升性能

发布于2026年7月27日美国东部时间下午12:41。

去年十月，Phoronix率先指出，来自一家“非Intel/AMD的企业实体”的新x86实现存在一些神秘之处，相关开发者未对此事进行详细说明。如今，同一位开发者又在Linux内核邮件列表中发布了一条半加密的消息，讨论16-tile和32-tile的Advanced Matrix Extensions (AMX) 实现。迄今为止，Intel仅拥有8-tile AMX。

Christian Ludloff曾作为x86架构专家在Google、AMD、TI等公司工作，同时也是Sandpile.org x86 CPU信息网站的维护者。正是他去年传达了关于一家“非Intel/AMD的企业实体”的x86消息，而今天他在Linux内核邮件列表上的不定期活动则围绕更大的AMX tile实现展开。

迄今为止，配备Advanced Matrix Extensions (AMX) 的Intel Xeon CPU实现仅支持八个tile。但现在，Ludloff正在谈论配置16个tile和32个tile的CPU，以提升性能。这发生在AMX演进为下一代AI计算扩展“ACE”（适用于未来AMD和Intel CPU）之前。

“如果x86 AMX/ACE的>8 tile不让你担心，那么你可以停止阅读。

-----------------------

我被要求记录16-tile和32-tile实现的x86 AMX/ACE行为。

16-tile或32-tile硬件实现的目标是通过运行利用额外tile的软件来获得额外性能。特别是，所述软件预计主要运行计算内核，最小化进程切换，并避免在存储和网络的中断处理程序中使用tile。使用虚拟机是可能的，但同样，在客户机之间快速切换并非目标场景。

支持16和32个tile的实现已经大规模运行了一段时间。”

该消息继续在规范范围内记录了16-tile和32-tile的AMX实现，并指出了AMX、APX和ACE规范中的各种疏忽。

目前仍无消息透露是谁要求Ludloff将这些技术细节传达给公共邮件列表。
