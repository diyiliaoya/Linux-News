Linux Mint 22.3 HWE 发布，搭载 Linux 内核 7.0

Linux Mint 22.3 (Zena) 的 HWE 版本 ISO 现已发布，默认搭载 Linux 7.0 内核，基于 Ubuntu 24.04 LTS。该版本旨在通过更新的硬件支持栈，让新硬件能够更好地运行长期支持系统。现有 Mint 用户无需重装，可通过软件更新获取 HWE 内核。官方建议仅在常规 ISO 无法正常工作时才使用 HWE 版本。

Linux Mint 22.3 HWE 发布，搭载 Linux 内核 7.0 - OMG! Ubuntu

一个全新的 Linux Mint 22.3 (Zena) 操作系统安装镜像现已可供下载，由最新的 HWE（硬件启用）内核驱动。

首个 Linux Mint 22.3 HWE ISO 于三月发布，其安装程序默认启动 Linux 6.17 内核。该镜像仍可下载，与最新版本（默认启动 Linux 7.0）以及原始 Linux Mint 22.3 (Zena) ISO（默认启动 Linux 6.14）并列提供。

这些镜像提供相同的核心 Linux Mint 22.3 体验，仍基于 Ubuntu 24.04 LTS，但整体构建在更新的硬件栈之上。现有 Mint 用户无需重新安装系统，因为 HWE 内核以软件更新的形式提供。

因此，正如我在上次报道中所指出的，这些并非 Linux Mint 的新版本，而是当前稳定版本搭配更新内核的版本。

Canonical 于七月开始推出最终的 Ubuntu 24.04 LTS 硬件启用（HWE）内核，将 Linux 7.0 从上游反向移植。该内核以及更新的 GPU 驱动和固件包将被“内置”到计划于九月发布的 Ubuntu 24.04.5 ISO 中。

Linux Mint 继承的正是 Canonical 的 Ubuntu HWE 更新。

所有这些硬件启用工作的目的是什么？Mint HWE ISO 与 Ubuntu 的 LTS 点版本介质一样，旨在让长期支持的操作系统版本在长期内保持可用。它们确保仅在新内核中才能正常工作或获得更好支持的新硬件能够启动和安装。

你应该使用 Linux Mint HWE 吗？

Linux Mint 的官方建议是，用户应坚持使用常规 ISO，即其网站在点击下载按钮时默认提供的版本。官方表示，仅当常规版本在设备上“无法正常工作”时，用户才应选择带有更新内核的 HWE 镜像。

现有 Linux Mint 22.3 用户无需下载 ISO 并重新安装即可获得新的 HWE 内核，因为它作为标准软件更新提供。

新的 HWE ISO 发布的同时，该发行版还宣布了对其原生内核管理工具的其他改进。
