Ubuntu 27.04“Tenacious T-Rex”开放开发

Ubuntu 27.04（代号“Tenacious T-Rex”）已开放开发，预计2027年4月22日发布，测试版4月1日推出。该版本将搭载GNOME 52桌面和Linux 7.6或更新内核，更多采用Rust，默认同步工具可能改为ntpd-rs，并加速Ubuntu Core Desktop开发。此外，TPM全盘加密支持将成熟，安全启动和打包工作推进，AI语音听写和启动器概念也在探索中。

Ubuntu 27.04（代号“Tenacious T-Rex”）的开发工作已于2026年10月30日开放，从Debian自动同步将引入自上一版本发布以来的一批更新软件包。在接下来的六个月里，这些软件包将经过测试、确定，并构成最终稳定版的基础。

Ubuntu 27.04计划于2027年4月22日发布，测试版将于4月1日先行推出（不是玩笑）。Ubuntu 26.10的测试版曾推迟一周，但希望新的开发周期波折更少。

期待什么

Ubuntu 27.04几乎肯定会搭载GNOME 52桌面，并视日程安排搭载Linux 7.6或更新内核。将融入更多Rust，Canonical已示意计划采用ntpd-rs作为默认同步工具。

其工程师将“加速”Ubuntu Core Desktop的开发，这是Ubuntu的全snap版本。它不会成为默认下载，而是预览版，因为对于常规用例它还无法达到日常驱动就绪状态——工作总得从某处开始。

此外，预计Ubuntu操作系统安装程序对TPM支持的全盘加密的支持将趋于成熟，围绕面向安全的系统启动和打包将有更多工作，为新的HWE固件计划做准备。

更多AI集成呢？

语音听写工具目前已在Ubuntu 26.04 LTS和26.10上处于技术预览阶段。为其提供支持的AI模型太大，无法默认随附，但可能会在桌面上引入面向用户的选入选项。

我最近还报道了Canonical一位工程师在公司“设计讨论”后构建的新AI支持的Ubuntu启动器概念。这是一个模拟原型，不是真实工具，但它表明Canonical正在探索将设备端AI融入桌面的方式。
