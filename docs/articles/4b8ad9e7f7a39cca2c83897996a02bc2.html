Sanket 让你重新设计 GNOME 的日期菜单和快速设置

Sanket 是一款 GNOME Shell 扩展，允许用户重新设计日期菜单、日历、通知和快速设置的外观与行为。它可以将通知放在浮动岛中或嵌入菜单内，将开关收缩为圆点，支持两行控件布局，并可拖拽调整控件顺序。该扩展兼容 GNOME Shell 45 至 51，用户可从 GNOME 扩展网站安装。

Sanket 让你重新设计 GNOME 的日期菜单和快速设置 - OMG! Ubuntu

Sanket 是一款 GNOME Shell 扩展，让你可以重新调整桌面日期菜单、日历、通知以及快速设置的外观和行为——甚至更多。

它可以将通知放在菜单下方的浮动岛中，或嵌入菜单内部。

当空间紧张时，开关可以缩小为圆点，并在需要时再展开，类似 Android 风格。

从药丸形变为圆点，其他菜单调整还允许你显示两行控件，并选择音量与亮度滑块在紧凑模式下是否保持可见。一个“编辑”模式还允许你拖放调整控件的顺序。

由于通知不再必须位于日历弹出窗口内，它变得更像仪表盘而非大杂烩。通过 Sanket 的天气预报可压缩为单个动画图标，时区可以以模拟图标显示。

Sanket 确实改变了通知的管理方式，只显示最新的通知。这对我来说有点不适应，因为展开列表（无论它在哪里）比直接看到它们更费力。通知可以被固定，这很不错。

但让它更有用的是，你不需要使用它提供的所有功能。

通过 Sanket 你可以改变很多——或者不改变。你可以保留默认布局，只将它用于其他事情，比如隐藏日历标题或“即将发生的事件”列表。

我喜欢它的设置中包含许多布局和选项的视觉预览，这样你就知道元素会移动到哪里，而不用经历“改点什么然后弄明白它做了什么”的常规操作。

配置？这个扩展有

如果你从未看过 GNOME Shell 的日历或快速设置菜单并想过“我希望我能改变那部分”，那么 Sanket 可能不那么吸引你。

但如果你喜欢自定义桌面，或试图让 GNOME 看起来更像其他桌面环境或操作系统——结合 Just Perfection 等扩展，这可以创建一个更有 ChromeOS 灵感的设置——那么它非常值得一看。

Sanket 适用于 GNOME Shell 45 到 51。你可以从 GNOME 扩展网站安装它（GNOME 扩展应用让你无需网页浏览器即可浏览和安装扩展）。
