Linux 7.4 合并 Slab 更新，带来显著性能提升

Linux 7.4 内核已合并 slab 更新，其中一项关键改进是优化了 sheaf 预填充 API 的性能，允许 barn 持有部分 sheaf 并从中补充 sheaf。在 will-it-scale 的 mmap1 基准测试中，该改动使 maple_node 缓存的吞吐量提升了 24%。这一性能优化由开发者 Hao Li 贡献。

Linux 7.4 合并 Slab 更新，带来显著性能提升

2026 年 10 月 23 日下午 04:27（美国东部时间）。

针对 Linux 7.4 的 slab 拉取请求刚刚被合并。对最终用户来说，这并非特别令人兴奋，但其中一项改动在测试内核内存管理子系统的基准测试中带来了 24% 的吞吐量提升。

Linux 7.4 slab 更新中最令人兴奋的一点是改进了内核 sheaf 预填充 API 的性能：

“- 通过允许 barn 持有部分 sheaf 并从 barn 中补充 sheaf，改进了 sheaf 预填充 API 的性能。这使得 will-it-scale mmap1 在 maple_node 缓存上的吞吐量提升了 24%。（Hao Li）”

这一改动此前已在我的关注范围内，并在《Linux 7.4 计划中的 MM 改动在一项指标上带来 +22904539.81% 提升，其他方面收益较为温和》一文中有所报道。总体而言，它为测试内核内存管理（MM）子系统的 will-it-scale 基准测试带来了 24% 的吞吐量提升。
