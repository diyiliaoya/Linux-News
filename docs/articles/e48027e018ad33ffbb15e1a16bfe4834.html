Ubuntu 26.04 停止通知用户更新，但这是有意为之

Ubuntu 26.04 LTS 的更新通知突然消失，经调查发现是设计变更：更新通知器仅在托盘图标可见时发送通知，而该图标默认被关闭且无菜单可重新开启。非安全更新因此未被标记，但安全更新仍通过无人值守升级自动安装。修复补丁已作为安全更新发布，版本为 update-notifier 3.207.2，彻底移除了托盘图标依赖，确保安装、无人值守升级或手动检查均能触发通知。用户也可通过命令手动恢复托盘图标。

Ubuntu 26.04 停止通知用户更新，但这是有意为之

幸运的是，修复补丁已经发布，作为安全更新推送。

如果你的 Ubuntu 26.04 LTS 系统上不再显示更新通知，那并非随机故障。OMG Ubuntu 追踪到 Launchpad 上的一个错误报告，两者均指向同一根本原因。

更新通知器仅在托盘图标可见时才会发送桌面通知，而该图标在 Ubuntu 26.04 中被关闭，且菜单中没有任何选项可以重新开启。

7 月 5 日提交该错误的用户发现，他的机器上有 10 个待处理的非安全更新，却没有收到任何安装提示。他手动进行了测试：强制启用托盘图标后，更新通知器弹出了通知；而关闭图标后，则完全没有反应。

Canonical 的 Marco Trevisan 早在 4 月就标记了一个自身问题：当时更新指示器不遵循自身设置，甚至无法手动开启。该问题在一天内得到修复，但图标默认保持关闭。再次评论该错误时，Marco 称这种设置是一种设计选择，并表示任何希望恢复图标的用户都可以通过设置启用它。

然而，实际情况并没有听起来那么糟糕。Ubuntu 默认在后台运行无人值守升级，因此安全补丁会自行安装，无论是否有通知出现。真正的缺口在于非安全更新——这类更新通常需要用户自行审查——完全没有被标记。

Alessandro Astone 已经发布了 update-notifier 3.207.2，作为针对 Ubuntu 26.04.1 的安全更新。它完全移除了对托盘图标的依赖。现在，一次安装、一次无人值守升级运行或一次手动检查，都会触发相同的通知。

由于该修复以安全更新的形式发布，借助无人值守升级，大多数系统会自动收到修复。

如果你更希望恢复托盘图标，可以打开终端并运行：

gsettings set com.ubuntu.update-notifier show-updates-status-icon true

或者直接通过应用中心的“更新”标签页、软件更新器，或运行以下命令来检查更新状态：

apt list --upgradable
