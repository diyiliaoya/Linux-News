Linux 7.3 为 Voodoo 3 / 4 / 5 及复古 Atari 计算机带来改进

2026年8月21日下午1:53（美国东部时间）

尽管由于 AI/LLM 生成的错误报告和补丁大量涌入，Linux 内核正在不断移除旧硬件驱动，因为这些硬件极不可能与现代主线内核版本一起使用，但 Voodoo 显卡和复古 Atari 计算机在即将到来的内核中却得到了一些喘息的机会。

帧缓冲设备（"FBDEV"）子系统的更新已提交并于今天合并到 Linux 7.3 内核中。对于 Voodoo 3 / 4 / 5 显卡支持，TDFXFB 驱动现在能够在没有 PC-BIOS 的情况下初始化这些 Voodoo 显卡。开源开发者 Daniel Palmer 进行了这项工作，使得“未启动”的 Voodoo 显卡能够在 Linux 上工作，即硬件从未被视频 BIOS 启动过。这主要对非 x86 计算机有用。

TDFXFB 驱动直接使用从视频 BIOS 获取的值来实现这一支持，使驱动能够自行初始化硬件，并将其带到通常由 vBIOS 完成的状态。

Claude Fable 5 协助调试了这一支持。该支持已在 x86_64 系统和带有 mediator PCI 桥接器的 Amiga 4000 上进行了测试。这些补丁还配合一些尚未合并的 3D 渲染支持补丁进行了测试，所有功能似乎都能正常工作。

另外，在此次 FBDEV 拉取请求中，还通过 ATAFB 帧缓冲驱动增强了 Atari 计算机支持。新代码增加了额外的视频位深，并增加了对 SuperVidel 的 SuperBlitter 的支持。新增的位深包括 8 位块状、16 位 RGB565 和 ARGB888。SuperVidel SuperBlitter 是 Atari Falcon 计算机的硬件协处理器升级，用于更快的屏幕绘制和像素操作。

这些 Voodoo 3 / 4 / 5 和复古 Atari 的改进，以及各种 FBDEV 修复和代码清理，都已合并。
