Apple HFS / HFS+ 文件系统支持在 Linux 7.3 中持续获得修复

2026年8月22日下午3:01（美国东部时间）

2025年初，有人讨论可能放弃 HFS 和 HFS+ 文件系统支持，因为相关代码已被遗弃超过十年，成为维护负担。但这一悲观前景很快逆转，一些开发者主动站出来维护这一古老的 Apple 文件系统支持。一年多后，幸运的是，这已成为一个成功的故事，更多的 HFS/HFS+ 文件系统修复持续进入 Linux 主线内核。

在过去一年的 Linux 内核更新中，HFS/HFS+ 文件系统修复源源不断。在正在进行的 Linux 7.3 合并窗口中，这些文件系统再次出现活动，而苹果本身在 macOS 世界中已多年不支持它们：苹果在 2009 年的 macOS 10.6 中终止了原始 HFS，并在 2017 年用现代 APFS 文件系统取代了 HFS+。

对于 Linux 7.3，有大量修复针对 Syzbot 发现的问题以及 xfstest 测试失败。包括 b-tree 位图损坏检查、验证改进、一些逻辑重构，以及 KUnit 测试的清理。
