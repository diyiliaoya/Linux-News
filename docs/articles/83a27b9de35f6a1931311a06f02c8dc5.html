GNOME 替换“不恰当”的截图音效，避免尴尬

GNOME 更换了截图时的相机快门音效，此前该音效在公共场合容易让人误以为是在偷拍，引发尴尬。新音效随 GNOME 51 提供，不再依赖 FreeDesktop 声音主题，同时更新了音量调节和设备插拔提示音。

下次在公共场合截取桌面截图时，再也不用担心别人以为你是偷拍狂了，因为 GNOME 已经更换了截图时播放的音效。

一段时间以来，当你截取桌面或应用窗口时，伴随的音效是相机快门声，就像智能手机拍照时听到的那样。在自己家里私下使用还算可爱，但在办公室或咖啡馆等公共场合就不那么可爱了。

问题就出在这个声音上：别人怎么知道你在截取桌面截图，而不是在偷拍照片？

为什么？因为那声音听起来相当令人毛骨悚然。

2024 年提交的一份 bug 报告揭示了问题：一位在公共咖啡店工作的 UI/UX 设计师，坐在一桌女性后面，没有意识到笔记本电脑音量未静音。他做了设计师常做的事——开始截图。

这位 bug 报告者面红耳赤地描述，截图声音如果脱离语境听，是“绝对不恰当的”，并警告说这可能给其他 Linux 桌面用户“带来极其尴尬甚至更糟的情况”。

而且他不是唯一一个因为截图声音意外过大而默默想钻地缝的人。

bug 报告的其他回复包括：“+1 支持‘这种默认行为让我在公共场合很尴尬’”，另一位则坦白：“是的，我也遇到过。”

我也有过这种经历；那“相机快门”声让我面红耳赤、手心冒汗，希望周围的人能忘记他们以为听到的声音，而不是集体伸长脖子朝我这边瞪眼咂嘴。

这个声音——点击下方播放可以听到——很有辨识度。如果你独自坐着，别人怎么知道你在截图而不是在偷拍：

许多 Linux 桌面使用的 XDG 相机快门音效

这不是 GNOME 的 bug，但他们还是修复了

问题是，这本来不怪 GNOME。

GNOME 并不提供这个音效。它来自 FreeDesktop 声音主题，许多 Linux 桌面和发行版（包括 Ubuntu 和 Fedora）都附带这个主题。

截图时播放声音作为可听提示（无障碍功能）是有用的，但没有理由它必须听起来像真正的相机。

所以，在测试 Ubuntu 26.10 时听到不同的声音，我很高兴。

我把新的“屏幕捕获”音效嵌入在下面。它短促而快速，你可能想多回放几次。在我听来，它有点像旧扫描仪重置的声音——绝对不像相机：

GNOME 新的屏幕捕获音效

Ubuntu 用户继续包含该声音主题，该主题继续链接到 FreeDesktop 声音集中的声音，用于某些效果，包括截图。

但 GNOME 51 现在忽略这一点；它作为 GNOME Shell 本身的一部分附带了一个小型声音包，包括你在上面听到的新“屏幕捕获”效果。

其他新声音——Ubuntu 可能会在最终发布前覆盖它们——包括调节音量时的新提示音，以及插入或拔出设备时的新钟声。

启动、铃声和警报仍使用原有声音。

虽然这是一个小改动，但做起来也很简单。它应该能帮助那些把笔记本电脑带到咖啡馆、共享办公空间、讲座办公室、公共场所的人避免尴尬——甚至当你的家人在房间里，你坐在沙发上时也一样。

毕竟，截屏以引起别人对屏幕上某物的注意，不应该意味着要引起别人对自己的注意，尤其是当那个声音……
