Apple M3 Pro / Max / Ultra 的初步支持正在为 Linux 7.3 上游化

2026年8月7日，下午1:31 EDT。

Linux 7.2 内核已上游化了对基础版 Apple M3 SoC 的设备树（DT）支持，用于在主线内核上启动，但许多功能仍待支持，对终端用户尚不实用。现在，对于即将到来的 Linux 7.3 内核，M3 Pro、Max 和 Ultra 变体也将获得在主线内核上启动的初步支持。

这些 M3 Pro / M3 Max / M3 Ultra 支持是主线 Linux 内核的基本设备树文件，使其达到与基础 M3 SoC 大致相同的支持水平……同样，由于 GPU 加速等功能尚未支持，对终端用户仍不实用。但至少这是一个开始，并为未来内核版本中更好的主线支持奠定了基础。

Apple M3 Pro 和 M3 Max 于 2023 年 10 月随 MacBook Pro 发布，而 M3 Ultra 于 2025 年 3 月随 Mac Studio 推出。目前尚不清楚主线 Linux 内核何时能为 M3 系列或更新型号提供可日常使用的支持。在此之前，用户更容易运行下游的 Asahi Linux 发行版，但即使在那里，许多 M3 功能仍由他们的小型志愿者团队进行开发，正如针对即将到来的 Linux 7.3 合并窗口的补丁所示，该补丁为所有搭载 M3 Pro/Max/Ultra SoC 的 Apple 设备布局了设备树。该补丁还包含对 Apple M1 和 M2 系列的 HWMON 支持，以应对 Apple 混乱的传感器。
