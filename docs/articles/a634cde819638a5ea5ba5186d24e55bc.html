Asahi Linux 现已正式支持 Apple M3 Macs - 但存在一些限制

Asahi Linux 开发者今日宣布，该 Linux 发行版现已正式支持搭载 Apple M3 系列芯片的 Mac 设备（Mac Studio M3 Ultra 除外）。虽然大部分 M3/M3 Pro/M3 Max 设备已能运行最新版本，但 GPU 支持尚不完善，3D 加速性能与功耗效率欠佳；同时，由于缺少 DCP 支持，睡眠功能和 HDMI 端口暂不可用。上游内核的 M3 支持仍在推进中，Linux 7.4+ 将进一步完善。

Asahi Linux 开发者今日宣布，他们现已正式支持在搭载 Apple M3 芯片的 Mac 上运行该 Linux 发行版。除 Mac Studio M3 Ultra 外，其他 M3 / M3 Pro / M3 Max 设备应可使用最新的 Asahi Linux 版本，但存在一些功能限制。

Asahi Linux 开发者今日宣布，搭载 M3 系列 SoC 的 Apple Mac 已达到“几乎”所有功能都支持的状态，与较旧的 M1 和 M2 硬件类似。

然而，最大的例外是 GPU 支持，他们承认目前 3D 加速的性能和功耗效率尚不理想。他们希望在接下来的几个月内能在 GPU 方面取得更多进展。

除了 GPU 支持不佳外，由于缺少 DCP 支持，Asahi Linux 在 Apple M3 上目前也无法提供睡眠功能。同样由于缺少 DCP 支持，M3 MacBook 上的 HDMI 端口也无法工作。此 M3 支持应涵盖除 Mac Studio M3 Ultra 之外的所有 Apple 设备。

关于下游 Asahi Linux 在 Apple M3 Mac 上正式支持的更多细节，可在此处查看。所有 M3 支持的上游化工作仍在进行中。主线 Linux 内核中已有初步的 M3 支持，可实现基本启动，但各种其他补丁仍需在 Linux 7.4+ 中上游化，才能达到与 Asahi Linux 本身类似的状态。
