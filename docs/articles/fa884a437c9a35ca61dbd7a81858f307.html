Linux Mint 27 圣诞季全新功能一览

Linux Mint 27 将于今年圣诞节发布，这是采用年度发布周期和男孩名字命名新策略后的首个版本。最大亮点是 Cinnamon 的 Wayland 会话不再处于实验阶段，与 X11 几乎持平。此外还带来 Nemo 预览窗格、改进的输入搜索、专用截图工具、重新设计的桌面、基于 LMDE 的新安装器以及休眠功能回归等更新。

这是一个历时一年开发的版本，带来了诸如 Wayland 会话不再处于实验阶段等重大变化。

Linux Mint 是一个基于 Ubuntu 的发行版，配备了自己的桌面环境和一套工具，使其成为一个真正独特的软件包，既适合新手也适合高级用户。

多年来，它遵循着熟悉的节奏，大约每六个月发布一个新版本，使用女孩的名字按字母顺序命名各个版本，从 2006 年的 Ada 到 22.3 的 Zena。

此后，这一节奏发生了变化，开发者们确定了更长的开发周期，改为每年发布一个主要版本，中间不再有点版本发布。

版本编号和命名也随着这一变化而改变，数字现在指向即将到来的年份，将用户从 27 带到 28 再到 29，并且男孩的名字取代了女孩的名字。

Linux Mint 27 是新策略下的首个版本。它计划在圣诞节发布，基于五年的支持期构建。

因此，通过这份功能概览，我们梳理了自一月份以来的每月新闻帖子，并专注于 Linux Mint 27 中的新变化。

以下所有内容都是对预期变化的预览。在稳定版发布之前，这些内容仍可能发生变化。

Cinnamon 的 Wayland 会话不再处于实验阶段。下一个 Cinnamon 版本中 X11 和 Wayland 都得到完全支持，Wayland 几乎与 X11 持平。这使得 Linux Mint 的旗舰体验为 Wayland 做好了准备，使其达到 Fedora 和 Ubuntu 等其他主流发行版的水平。

大部分基础工作围绕日常交互展开。窗口和菜单正确映射，防止焦点窃取，崩溃问题也得到处理。多显示器设置和 KVM 切换器也已覆盖。

图形方面也受到关注。支持硬件加速，包括针对 NVIDIA 卡的 GBM over EGL，同时 HiDPI 缩放已覆盖光标和基于 Chromium 的应用，如 Slack 和 VS Code。

确保 Wayland 支持的最后一块拼图是屏幕保护程序。新的屏幕保护程序由合成器渲染，由 Cinnamon 自身处理，取代了单独的进程，并且在 Wayland 和 X11 上都能工作。旧的屏幕保护程序将作为后备保留一个版本，然后被移除。

默认文件管理器 Nemo 获得了一个预览窗格，可以通过 F3 或从状态栏打开。它可以处理音频文件、图片和视频，并能显示元数据详情，如拍摄日期和使用的相机。

输入搜索功能——即打开文件夹并开始输入时触发的功能——变成了过滤视图，在你输入时缩小列表范围，取代了跳转到第一个匹配项并让你浏览其余项的方式。

Cinnamon 迎来了专用的截图工具。它可以捕获带或不带阴影的窗口，可以捕获所有显示器或仅一个显示器。

你还可以在复制或保存之前裁剪截图，并且该工具对绘制自己标题栏的窗口和依赖系统标题栏的窗口采用不同的阴影处理方式。

桌面出现在桌面上，并进行了重新设计，按类型而不是按打开它们的应用程序对最近文档进行分组。

侧边栏包含预定义的组，你可以显示、隐藏和重新排序。你还可以根据文件类型添加自定义组，并可根据需要将其限制在单个目录中。单个项目可以移除，整个列表可以一次性清除。

3. 系统和安装程序变更

Linux Mint 切换到 Linux Mint Debian Edition (LMDE) 已经在使用的实时安装程序，取代了 Ubiquity。新安装程序支持 OEM 安装、BIOS 和 EFI 系统、安全启动以及 LVM 和 LUKS 设置。

在 Ubuntu 放弃休眠功能后，休眠在 Linux Mint 27 中通过系统管理工具中新的“休眠”页面回归，使得再次设置变得容易。
