发行版发布：Manjaro Linux 26.1.0

Manjaro Linux 26.1.0 'Bian-May' 正式发布，这是该项目滚动发行系列的最新稳定版本，提供 GNOME、KDE Plasma 和 Xfce 桌面环境。本次更新将 GNOME 桌面升级至 50 系列，KDE Plasma 升级至 6.7 版本。GNOME 50 引入了重大改进的家长控制功能，允许家长监控屏幕时间、设置限制和就寝时间表，并支持自动锁定屏幕。此外，该版本还集成了来自巴西姊妹项目 Big Linux 的 Big Parental Controls 1.0，以符合当地法律要求。

发行版发布：Manjaro Linux 26.1.0

Philip Müller 宣布发布 Manjaro Linux 26.1.0，这是该项目滚动发行系列的新稳定版本，提供 GNOME、KDE Plasma 和 Xfce 桌面环境。本次更新将 GNOME 桌面升级至 50 版本，KDE Plasma 升级至 6.7 版本：

“Manjaro 26.1 'Bian-May' 已发布。自 2026 年 1 月发布 'Anh-Linh' 以来，我们一直努力推出 Manjaro 的下一个版本。我们将其命名为 'Bian-May'。GNOME 版本已收到多项更新，升级至 GNOME 50 系列。这包括 GNOME 50 于 2026 年 3 月最初发布以来的大量修复和打磨。GNOME 的家长控制在 GNOME 50 中取得了巨大进步。家长和监护人现在首次可以监控屏幕时间，并为儿童账户设置限制，包括就寝时间表。新功能允许在达到屏幕时间限制或就寝时间时自动锁定屏幕。家长和监护人还可以在需要时延长屏幕时间。我们还从巴西的姊妹项目 Big Linux 引入了 Big Parental Controls 1.0，以符合当地最近的法律要求。”

更多信息请参阅发布公告。
