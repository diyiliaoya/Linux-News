FireDragon 浏览器展翅翱翔，焕新登场

FireDragon 浏览器已从零重写，带来显著提升。

FireDragon 是 Garuda Linux 的默认浏览器，这款基于 Arch 的发行版以其精致的 KDE Plasma 定制和可靠性著称，尽管它始终处于最前沿。传统上，FireDragon 基于 Firefox 构建，因此拥有 Firefox 的扩展支持，并融合了 Garuda 的隐私默认设置。

现在，开发者改变了策略，更换了其基础代码，并交付了一个充满许多以可用性为导向的改进版本。

这次彻底改造为你带来了更好的搜索体验，默认搜索引擎是 DuckDuckGo。同时，它还附带了一个扩展的搜索工具列表，范围从注重隐私的 SearXNG 和 MetaGer，到大型科技公司的选项如 Google 和 Bing。

接下来是改进的首次使用引导体验，新的欢迎对话框现在包含一键切换开关，用于那些你通常需要深入设置才能找到的功能。如果你已经依赖像 Bitwarden 这样的独立密码管理器，可以关闭内置密码管理器以增强隐私（尽管可能破坏某些网站），或者开启预取功能以加快页面加载速度。

新的快速设置、搜索引擎选项和预装扩展（点击/触摸可展开）。

类似地，浏览速度也有小幅提升，TLS 1.3 现在默认启用，减少了重新连接已访问网站时的延迟。还有一个可选设置可以启用预取（与前面提到的相同），当你将鼠标悬停在链接上时就开始加载页面，或者在后台下载下一页内容，然后你才点击它。

其他值得注意的变化包括：v13 版本增加了对 XDG 基础目录的支持，现在通过网站权限处理 WebGL 和 DRM 内容。它还从默认扩展列表中移除了 uBlock Origin，只留下 Violentmonkey 作为唯一的预装附加组件。

你应该放弃 Firefox 吗？\n我花了一些时间体验 FireDragon v13，看看新的代码库表现如何，以及它是否会改变人们在它和原生 Firefox 之间做选择时的想法。大部分体验感觉很熟悉，不过也有一些粗糙的地方值得指出。

由新的欢迎对话框驱动的快速设置向导让我有点失望，因为页面上有很多空白区域；不过，选项本身工作得很好。

过了那个界面之后，浏览体验感觉像是 Floorp 或 Firefox 加上 Garuda 的风格。

垂直标签页是 FireDragon 最接近完全匹配 Firefox 的地方，布局看起来几乎一模一样。一个小问题是标题栏。Firefox 在 Fedora Workstation（搭载 GNOME）上会隐藏标题栏，但 FireDragon 显示了一个丑陋的标题栏，并且在设置中没有任何开关可以关闭它。

一个更大的缺失体现在系统主题跟随上。Firefox 会自动跟随系统的深色或浅色模式，同时应用于界面和支持的网站。FireDragon 没有为网站做到这一点，即使开启了“自动深色模式”。我在你正在阅读本文的网站 Omg! Linux 上进行了测试，重启浏览器也无济于事。

启用垂直标签页（左）和 FireDragon 设置（右）。

“常规”页面挽回了一些局面，提供了诸如关闭最后一个标签页时关闭浏览器窗口、启用中键粘贴、自动更新附加组件以及预取的额外控制等开关。

“主题”标签页让你更进一步，可以对任何已安装的主题进行微调，对显示什么和不显示什么有很高的控制度。

那么，你应该放弃 Firefox 吗？

如果你已经在使用 Garuda Linux，FireDragon v13 经过一些调整可以成为日常主力浏览器。如果你已经愉快地使用着 Firefox，那么主题跟随的 bug 和顽固的标题栏会让它难以打动你。

对于大多数 Linux 电脑，可以从 Flathub 安装 FireDragon 的 Flatpak 版本：

flatpak install flathub org.garudalinux.firedragon

有多种软件包可供选择。其中一个应该安装更快，第二个是相同的但带有调试符号，另外两个相同但分别对应上述两种情况。

像 Arch Linux 这样的平台上的用户，或者为 Linux 寻找替代软件包的用户，可以访问 Garuda Linux 的下载页面，你也可以参考 FireDragon 的 GitHub 仓库，但请注意它可能有点过时。
