Hylki：一款面向 GNOME 的现代 Rust 电子邮件客户端

Hylki 是一款基于 Rust 的 GNOME 桌面电子邮件客户端，支持多账户、会话线程、OpenPGP 加密、阅读模式等丰富功能，并提供大量自定义选项。其大部分 Rust 代码由 Anthropic 的 Claude 在人工指导下编写，但应用本身不含 AI 功能。可通过 Flatpak 安装，需 GNOME 50 运行时。

Hylki 是一款面向 GNOME 桌面的基于 Rust 的电子邮件客户端，内置了极其丰富的自定义选项。

它属于新近涌现的一批 Linux 邮件客户端，旨在作为现代、轻量级的替代方案，与功能更强大的邮件客户端竞争。

GTK4/libadwaita 界面？有。三栏垂直布局？有。围绕会话构建？有。哦，还有“没有 AI 编码工具就不会存在”？也有——我稍后会谈到这一点。

“打开迅速、阅读轻松、默认私密”

面向 GNOME 的现代邮件客户端

Hylki 的引导流程是个不错的亮点

你可以通过 GNOME 在线账户连接已设置的任何电子邮件账户，也可以使用手动 POP3/IMAP 账户配置来添加账户。它支持多账户，既可以单独访问每个账户，也可以通过统一收件箱访问。

我很喜欢首次运行的引导流程。通常这类东西我会随便点几下跳过。但这里，它很好地混合了各种选项和偏好设置，让你提前完成配置——其中一些可以在上面的截图中看到。

标准的邮件管理功能和操作都已涵盖，并且像 Geary 和现代网页邮件提供商一样，邮件使用会话线程（即它们会一起出现在同一视图中）。

窗口内撰写和 GPG 设置

新邮件可以内联撰写，也可以在弹出窗口中撰写，内容可以用富文本、Markdown、HTML 或纯文本编写。你甚至可以选择将邮件加入队列“稍后发送”，而不是立即发送。支持 OpenPGP（通过主机软件包）来阅读、签名和加密邮件。

不急着发送？

其他新颖功能包括“阅读模式”（将邮件内容精简为纯文本）、一组配色方案和替代应用图标、专用的附件视图、“专注模式”以隐藏图标和其他视觉杂物，以及与 GNOME 联系人的交互。

舒适性功能包括单键快捷键（Gmail 风格）、后台应用模式、手势支持，以及以不同于系统默认语言运行应用的选项。

而这还没有触及大量可用的自定义选项和配置设置。

说真的，有很多——从配置内联邮件预览中显示的行数，到编辑工具栏中按钮的顺序，再到创建本地邮件过滤器和管理 LDAP 目录。

由 LLM 制作，但在指导下完成

开发者表示，Anthropic 的 Claude 被用于编写大部分代码，尽管是在指导下进行，并且每个输出都“由人工维护者审查和测试，该维护者对每个版本签字确认”。

“其中绝大部分 Rust 代码是用 Anthropic 的 Claude 编写的”

该应用本身不包含 AI 功能，无论是本地还是云端，因此不存在重要邮件或整个收件箱被 LLM 因过度关注错误 token 以完成设定任务而直接搞砸的风险（机器生成怪癖带来的焦虑仍然存在）。

但 Hylki——一个冰岛语单词，意为“胶囊”——中的所有 artwork 据称都是人工制作的。主应用图标和标志由 Yiannis Ioannides 绘制。

撇开 AI 来源不谈——不同的人对使用的红线划在不同的地方，并非所有都出于哲学考量，但推动者的意图和技巧……

看起来还不错，运行得也很好，只是有点……

可能是心理作用，但我总觉得 LLM 制作的 GTK 应用界面有点……我说不太清楚。就像在某些地方对小细节缺乏关注，而在另一些地方又过度关注细节，形成了一种并置。

作为 Flatpak 提供，可下载

或通过网站，或通过命令行以节省一点时间。

Ubuntu 不预装 Flatpak，所以先安装它：

sudo apt install flatpak

需要 GNOME 50 运行时，该运行时可在 Flathub 上获取。这是一个共享运行时，会随第一个需要它的应用一起下载：

flatpak remote-add --if-not-exists flathub https://flathub.org/rep
