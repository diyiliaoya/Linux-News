ARCTIC 发布新款风扇控制器，已获主线 Linux 支持

发布于 2026年7月28日 美国东部时间晚上8点38分。

在 Phoronix 从事 Linux 硬件评测超过22年的时间里，我从未对一款风扇控制器如此兴奋过……ARCTIC 今天发布了他们的新款风扇控制器，而这款产品对 Linux 用户来说非常独特——它已经通过 ARCTIC 直接贡献的开源驱动获得了主线 Linux 内核支持。

ARCTIC Cooling 发布了一款 Linux 风扇控制器驱动，支持多达10个风扇通道，并能很好地集成到 Linux HWMON 接口中，用于风扇控制和监控。一开始有些令人困惑，因为现有的 ARCTIC 风扇控制产品没有任何用于与系统通信的 USB 接口，因此不清楚它关联的是什么。

他们继续完善其风扇控制器驱动，后来才明确这是针对一款新的/未发布的产品。该驱动已在 Linux 7.2 内核中主线化，该内核将于8月下旬作为稳定版发布。

这款产品之所以如此独特，是因为长期使用 Linux 的用户都知道，风扇控制器厂商通常不提供任何 Linux 支持，尤其是产品发布前。通常，Linux 的桌面风扇控制驱动大多由热情的 Linux/开源用户通过逆向工程自行创建。而这次，ARCTIC 不仅向主线内核贡献了开源驱动，而且是在产品发布之前就完成了。向他们致敬，因为我不记得在桌面风扇控制领域有过类似的情况。事实上，在2026年这居然还值得兴奋，这本身就挺可悲的——更多桌面 PC 散热厂商并没有更直接地为 Linux 内核做出贡献。

他们在 X 平台上宣布，新款“ARCTIC 风扇控制器”已发布。他们在公告中指出，这款10通道风扇控制器甚至“开源且已为 Linux 做好准备”。

除此之外，他们还提到了 Linux 支持。同时也有 Windows 和 macOS 支持。

这款新型风扇控制器的价格也出奇地便宜。最初的 Amazon.com 产品页面（联盟链接）显示，这款对 Linux 友好的风扇控制器仅售9美元。ARCTIC 将很快寄送评测样品，以便在未来的 Phoronix 文章中确认 Linux 驱动支持并进行测试。
