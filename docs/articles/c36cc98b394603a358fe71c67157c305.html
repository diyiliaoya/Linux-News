Convey：Linux 邮件应用 Geary 的 GTK4/libadwaita 分支

Convey 是一个基于 Geary 代码的新 Linux 邮件客户端，采用 GTK4/libadwaita 界面，并支持 Microsoft 365 账户。它保留了 Geary 的会话线程和标准三栏布局，更新了插件架构以使用新版 GNOME 安全与加密库，并新增 Microsoft Graph 后端。此外还改进了文件夹管理、键盘导航、深色模式适配和地址自动补全等功能。

Convey 是一个基于 Geary 代码的新 Linux 邮件客户端，采用 GTK4/libadwaita 界面，并支持 Microsoft 365 账户。

有点类似传统邮件，它在我报道另一款新邮件客户端后不久出现，那款客户端也从 Geary 中汲取灵感——Geary 的源码深受 Linux 用户喜爱，但其最后一个稳定版本发布于 2024 年。

Convey 自称是 Geary 的硬分支，与其说是致敬，不如说是延续——尽管是非官方的：Flathub 页面明确表示它“不隶属于 GNOME 基金会，也未获得其认可”。

Geary 于 2012 年首次发布，我定期报道过它。发布时，它采用类似网页邮件的会话线程（将整个往返对话归为一组，而不是将每条回复显示为单独消息），这在当时的 Linux 邮件客户端中相当新颖。

Convey 保留了许多前身广受欢迎的功能。

显然，在 2026 年这已不那么独特，因为大多数邮件客户端现在都使用会话线程——Convey 继续坚持这一点并不意外，同时也保留了 Geary 标准的三栏布局。

Convey 将界面移植到了 GTK4/libadwaita。这看起来更符合现代桌面，当然，也更好地集成并遵循现代系统特性，键盘快捷键也更好用。

Convey 还更新了插件架构，以使用新版 GNOME 核心安全和加密库，并新增了 Microsoft Graph 后端以支持 Outlook 和 Microsoft 365 账户。

Convey v50.0 的其他改进：

- 从侧边栏添加、重命名和删除文件夹

- 窗格之间的键盘导航

- 消息颜色跟随系统深色模式偏好

- 地址补全现在是可导航的下拉菜单

总之，这是一个令人欢迎的旧爱复兴。

不得不提的是，Geary 并未消亡——它仍可安装并继续工作——但已不再积极维护。最后一个新的稳定版本是 2024 年 5 月的 v46。在此之前，开发已经放缓。

它能在其他新邮件应用中脱颖而出吗？

过去 12 个月里，Linux 桌面邮件客户端有所增加，AI 编码工具在其中发挥了作用。

Convey 的代码有 AI 辅助的迹象，尽管其 GitLab 仓库和 Flathub 页面都未提及。

无论如何，它因其血统而与众不同——但接下来呢？

Geary 之所以受欢迎，是因为在 Linux 桌面邮件仍被“群件”套件、过时界面和繁琐配置主导的时代，它提供了一款轻量、易用的邮件客户端。

自那以后，情况已大不相同，所以有趣的是，Convey 是在精神上还是仅仅在血统上硬分支了 Geary。
