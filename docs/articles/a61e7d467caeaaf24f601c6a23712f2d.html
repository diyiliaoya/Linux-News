Void Linux 维护者因 AI 政策争议弃养 100 多个软件包

2026 年 9 月 12 日东部时间上午 11:11。

一位 Void Linux 维护者因项目关于 LLM 生成文本的 AI 政策争议，弃养了他维护的 100 多个软件包。

Void Linux 贡献者 Andrea Brancaleoni 上周提交了一个 Go 1.27.1 的 Void 软件包更新。作为后续，昨天他发帖提到了比较 Go 1.26 与 1.27 软件包升级影响的结果。

随后另一位 Void Linux 维护者询问生成这段比较文本时使用了什么工具，Brancaleoni 指出使用的是 GLM-5.3-Flash + OpenCode。

但 Void Linux 项目确实有关于 AI 使用的贡献政策，其中写道：

“在本节中，‘AI’指生成式人工智能工具，包括大型语言模型及类似技术。

所有贡献都应由人类完成。AI 工具可用于研究和学习，但贡献中的所有内容必须源自贡献者并被其理解。这包括代码、文档、问题、安全报告、拉取请求描述，以及所有 Void Linux 社区空间中的评论。

所有 AI 工具的使用都必须披露。

不要将 AI 审查工具引入拉取请求。

使用 AI 驱动的人类语言翻译工具是可以接受的，以促进跨语言障碍的贡献。”

因此，从技术上讲，在该 Void Linux 拉取请求中使用 AI 生成评论回复违反了政策。而且在那条违规消息中，AI 工具的使用并未事先披露。

现在，Brancaleoni 决定弃养他所监管的软件包。这导致 113 个 Void Linux 软件包被列为弃养。

现被弃养的软件包包括 Adapta、Autodia、SFML、abootimg、alacritty、arpwatch、asus-kbd-backlight、backblaze-b2、bash-preexec、beep、binfmt-support、bitlbee-facebook、bitlbee-steam、cdm、clementine、crane、csound、daemonize、darkhttpd、dep、diff-pdf、docker-cli、docker-gc、docker-gen、dtc、embree、entr、etcd、fcron、flannel、flint、font-fontin、forego、freeplane、fscrypt、gede、gettext-stub、git-cola、gkill、glock、go-bindata、go-jira、hans、hivex、hopper、hostaliases、hugo、iio-sensor-proxy、indicator-doom-cpu、interbench、ispc、jbigkit、kaitai-struct-compiler、kubernetes、kvirc、libguestfs、libnfc、libpodofo0.9.7、logstalgia、massren、mbox、mfoc、mkinitcpio-nfs-utils、mksh、moby、motion、openresolv、packer、pd、perl-Template-Toolkit、pinktrace、podofo、python3-Arrow、python3-b2sdk、python3-pdm-backend、python3-xattr、racket、rakarrack、rancher-compose、rmlint、rng-tools、rocker、runit-swap、sassc、scanmem、schroot、sift、splix、sublime-text3、subtle、supermin、sydbox、tag、tbb、terraform、terragrunt、texmaker、thermald、trollock、ttf-ubuntu-font-family、urbanterror-data、urbanterror、usbredir、vagrant、vba-m、virt-manager、virtme、webcat、websocketd、wpa_actiond、xboxdrv、xcompmgr 和 yoshimi。

其中包括一些值得注意的软件包，如 Alacritty、binfmt-support、Clementine、各种 Docker 软件包、fscrypt、Kubernetes、各种 Python 3 软件包以及 Intel Thermald，除非其他 Void Linux 维护者在这起 AI 政策争议中站出来维护它们，否则这些软件包现已被弃养。
