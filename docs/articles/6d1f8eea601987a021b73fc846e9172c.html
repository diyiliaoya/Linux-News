发行版发布：Asahi Linux 45

Asahi Linux 项目发布了基于 Fedora 45 的新版本 Fedora Asahi Remix 45，支持 Apple M1 和 M2 系统，并首次为 M3、M3 Pro 和 M3 Max 提供开箱即用的初始支持。该版本提供 KDE Plasma 6.8 旗舰桌面、GNOME 51 变体、服务器变体和最小化镜像。由于 Mac 不支持从外部存储启动，安装需通过 macOS 终端运行 Python 脚本完成。

发行版发布：Asahi Linux 45（DistroWatch.com 新闻）

让 Linux 能在搭载 Apple 芯片的电脑上运行的 Linux 项目发布了基于 Fedora 45 的新版本。Fedora 杂志报道：“Fedora Asahi Remix 是与 Fedora Asahi SIG 和 Asahi Linux 项目密切合作开发的。此版本包含了 Fedora Linux 45 带来的所有令人兴奋的改进。与之前的版本一样，Fedora Asahi Remix 45 支持 Apple M1 和 M2 系统。此外，此版本还包含对 Apple M3、M3 Pro 和 M3 Max 的开箱即用初始支持。Asahi Linux 上游现在正式支持这些新系统。目前尚未包含能在 M3 系统上实现高性能 3D 加速的 GPU 驱动。它们将在未来通过 Mesa 更新提供。Fedora Asahi Remix 提供 KDE Plasma 6.8 作为我们的旗舰桌面体验。Fedora KDE Plasma Desktop 45 带来的所有新功能和令人兴奋的特性均已包含在内。还提供了一个 GNOME 变体，搭载 GNOME 51，两个桌面变体均与 Fedora Linux 提供的内容保持一致。Fedora Asahi Remix 还提供 Fedora 服务器变体，适用于服务器工作负载和其他类型的无头部署。最后，我们为希望从头构建自己体验的用户提供了最小化镜像。”

获取该发行版需要运行脚本，而不是从 ISO 文件安装。安装说明可在 Fedora Asahi Remix 网站上找到。
