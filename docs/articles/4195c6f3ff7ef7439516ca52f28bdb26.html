Ubuntu 用户现在可以针对特定 Launchpad PPA 提交缺陷报告 - OMG! Ubuntu

Launchpad 现已为个人软件包档案（PPA）提供缺陷跟踪功能，使用户更容易报告 PPA 内特定软件的问题。

为什么这很重要？并非所有 PPA 都由其上游对应方维护——坦率地说，这些人并不总是关心其软件中可能由他人打包方式引起的特殊问题。

此外，PPA 常用于提供比标准 Ubuntu 仓库中更新或实验性的软件版本，不同的 PPA 可以分发同一软件的不同版本。

借助新的跟踪支持，用户终于可以针对从该 PPA 安装的软件包提交问题。缺陷可以涉及整个 PPA、其中的单个源码包，或针对特定 Ubuntu 版本的构建。

Canonical 的 İlker Emre Koç 说明了这一好处：

用户从测试 PPA 安装了较新版本的软件，然后遇到崩溃。现在可以针对测试 PPA 中的版本提交问题，而不是针对软件包报告问题（后者可能暗示 Ubuntu 仓库中的版本受到影响）。

对于使用 PPA 分发自己软件的开发者以及为他人软件打包的维护者来说，这一期待已久的功能应能减轻分类和修复缺陷的负担。

PPA 缺陷跟踪已在 Launchpad 上线。开发者可以前往其 PPA 并选择相应选项来探索可用功能——想要报告异常的用户也可以这样做。

在其他 Launchpad 新闻中，这个代码托管站点将在 27.10 周期末（所以还有一年）淘汰其蓝图功能，原因是使用率低。它还在考虑在 Launchpad 之上创建一个“现代、专门构建的翻译平台”。
