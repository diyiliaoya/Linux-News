Rust Nightly 将开始默认启用并行前端

Rust 后端早已多线程编译，但前端默认单线程。Rust Nightly 正开始默认启用并行前端，以便在最终稳定前进行更多测试。并行前端可加速构建，基准测试显示 2/4/8 线程均有明显提升。未来数月将监控 Nightly 测试结果，再推广至稳定版。

Rust Nightly 将开始默认启用并行前端

2026年11月16日上午09:39 EST。

虽然 Rust 的后端长期以来一直使用多线程来编译代码，但 Rust 前端默认一直是顺序执行的。终于，Rust Nightly 正在开始默认启用其并行前端，以便在最终稳定之前进行更多测试。

Rust 前端的并行化已经可行相当长一段时间了——他们曾希望在 2024 年就将其稳定——但默认使用单线程。使用多线程显然有助于加速 Rust 程序的构建过程，在前端和后端流程中都能利用多个 CPU 核心。
