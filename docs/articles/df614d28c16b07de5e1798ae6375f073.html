发行版发布：Qubes OS 4.3.2

Qubes OS 团队发布了 4.3.2 稳定版，这是一个整合了自上一稳定版以来所有安全更新和错误修复的补丁版本。新版本将默认 Fedora 模板升级至 Fedora 44，kernel-latest 升级至 Linux 7.2，并包含大量错误修复。已知问题涉及从 4.3 之前备份恢复的模板可能仍指向原版本仓库，但全新安装和从 4.2 就地升级的用户不受影响。

发行版发布：Qubes OS 4.3.2

Qubes 团队宣布发布 Qubes OS 4.3.2，这是该项目面向单用户桌面计算的安全导向操作系统的一个更新版本：“我们很高兴地宣布 Qubes OS 4.3.2 稳定版发布。此补丁版本旨在整合自上一个稳定版发布以来发生的所有安全更新和错误修复。我们的目标是提供一种安全便捷的方式，让用户通过最新的 ISO 安装（或重新安装）最新的稳定版 Qubes。ISO 及相关验证文件可在下载页面获取。Qubes 4.3.2 有哪些新内容？默认 Fedora 模板升级至 Fedora 44；kernel-latest 升级至 Linux 7.2；安全更新；大量错误修复。Qubes 4.3.2 中的已知问题：在 4.3.2 中从 4.3 之前的备份恢复的模板，可能仍会指向其原始的 Qubes OS 发行版仓库。在全新 4.3.2 安装上的新模板不受影响。从 4.2 就地升级到 4.3（而非从备份恢复模板）的用户也不受影响，因为就地升级过程已在第 4 阶段包含了上述修复。”请阅读公告的其余部分以获取更多细节和相关链接。

Qubes OS 是一个免费开源、面向单用户桌面计算的安全导向操作系统。Qubes OS 利用基于 Xen 的虚拟化技术，允许创建和管理称为 qubes 的隔离隔间。这些 qubes 以虚拟机（VM）的形式实现。这使得操作系统的每个组件都能与其他部分隔离，防止入侵扩散或信息泄露。
