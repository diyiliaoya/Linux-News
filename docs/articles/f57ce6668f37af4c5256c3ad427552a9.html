LightDM 死而复生，但 Canonical 已不再掌舵

LightDM，这个由 Canonical 在十多年前打造的显示管理器，在沉寂四年后终于发布了新版本 1.33.0。项目原维护者早已宣布其“基本无人维护”，但两位新维护者 Joshua 和 Neal 接手，将其转变为社区维护的项目。新版本主要修复了自 1.32.0 以来积累的问题，并增加了对 Qt6 的支持，同时保持与 Qt5 的兼容。Linux Mint、elementary OS 等发行版仍在使用 LightDM，新维护者正在招募更多贡献者。

经过数年的沉默、新维护者的加入以及一次发布，LightDM 终于回归。

看着一个所有人都以为已经悄然死去的 Linux 项目带着新的提交重新出现，总有一种满足感。这种情况发生的频率比人们预期的要高，而且通常值得庆祝。

其中一次复兴就是 LightDM 的回归，这是 Canonical 在十多年前打造的显示管理器。

上周发布了 1.33.0 版本，该版本带来了一系列改进，并引入了两位接管项目的新维护者。上一个版本 1.32.0 发布于 2022 年 7 月，标志着项目在长达四年的时间里几乎没有任何进展。

要知道，LightDM 的原维护者 Robert Ancell 早已将项目称为“基本无人维护”，多年来，关于其未来的疑问也时不时出现在各种论坛上。

幸运的是，两位愿意让项目继续下去的人站了出来，使其成为一个社区维护的项目，而不是 Canonical 的项目。Joshua 和 Neal 都因在众多开源项目中的工作而闻名。Joshua 领导着 Ubuntu Cinnamon Remix，而 Neal 则无需过多介绍；他多年来一直为 Fedora、openSUSE 和 CentOS 做贡献。

至于 1.33.0 实际带来了什么，维护者表示，其主要目的是标记自 1.32.0 以来积累的修复，并清理积压多年的拉取请求。

没有破坏性更改，也没有依赖项更改，因此现有的 LightDM 设置应该可以毫无意外地升级。最值得注意的新增功能是客户端库对 Qt6 的支持，但这并不意味着 Qt5 会被弃用。基于旧工具包构建的欢迎器将继续正常工作。

还有一长串较小的修复。VNC 服务器处理已得到修补，因缺少 PAM 模块而导致的日志错误洪流已消失，一批多席位和 FreeBSD 特有的错误也已清除。

如果你不知道，LightDM 是一个轻量级、跨桌面的显示管理器。它是你登录屏幕背后的软件，负责验证你的身份，并在你登录后将你交给桌面会话。

Canonical 构建 LightDM 是为了取代 GDM，它最初在 Ubuntu 11.10 中作为 Unity 背后的登录屏幕亮相。Ubuntu 本身在 2017 年放弃 Unity 转向 GNOME Shell 时也放弃了 LightDM，但 LightDM 从未真正消失。

Linux Mint 在同一年采用了它，并将其与自己的 slick-greeter 搭配使用，而 elementary OS 则通过 Pantheon Greeter 运行它。几个 Ubuntu 风味版本和 Fedora 衍生版也仍然依赖它。

如果你认为你可以帮助 LightDM 发展成更强大的东西，那么请注意，Joshua 和 Neal 正在寻找新的贡献者加入。你可以通过 Matrix 直接联系他们。

他们还指出，不再需要签署贡献者许可协议。

虽然我在这里还有更多要补充的——不要在这个项目上释放你的“钢铁军团”（我相信正式术语是“AI 代理”）；最近这种情况已经发生在许多开源项目上，而这个项目刚刚复兴。它不需要被幻觉和无意义的修复所淹没。

维护者还要求，任何为 bug 修复提交拉取请求的人，首先展示重现问题的方法。
