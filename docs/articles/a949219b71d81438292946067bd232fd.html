Apple M5 基础支持预计将登陆 Linux 7.5

Apple M5 SoC 基础型号的初步支持已进入 apple-soc/dt-7.5 Git 分支，预计将随 Linux 7.5 内核合并。该支持仅提供极少量硬件支持，作为未来开发的基础，硬件与早期 Apple Silicon 代际基本一致。GPU 支持仍是主要障碍。此前 Linux 7.4 已引入 Apple M4 初步支持，7.2 引入 M3 支持。

Apple M5 SoC 基础型号的非常基础的支持预计将被合并到 Linux 7.5 内核中，目前该支持已排入“apple-soc/dt-7.5”Git 分支。

继 Linux 7.4 中引入 Apple M4 初步支持、Linux 7.2 中引入 Apple M3 支持之后，Linux 7.5 现在预计将提供 Apple M5 基础型号及使用该芯片的 Apple Mac 的初始设备树支持。但就像目前主线内核中的 M3/M4 支持一样，它将非常有限。

参与 Apple M5 设备树工作的 Yureka Lilian 将其描述为“最少量的硬件”支持，但他们会在此基础上继续构建，并在未来的 Linux 内核版本中扩展：

“本系列仅涵盖最少量的硬件，可作为未来开发的基础。这里添加的硬件与早期 Apple Silicon 代际相比基本保持不变。”

仍然存在的最大障碍之一是为更新代际的 Apple Silicon M 系列 SoC 提供适当的 GPU 支持。

该系列已由 Sven Peter 排入“apple-soc/dt-7.5”，因此请期待 Linux 7.5 中这一非常原始的 Apple M5 支持，以帮助推动后续开发工作。
