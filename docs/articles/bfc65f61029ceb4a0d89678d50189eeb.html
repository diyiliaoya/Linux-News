Linux 7.4 特性令人兴奋：Radeon HDMI 2.1 默认启用、AMD PerfOpt、Apple M4

Linux 7.4 内核合并窗口即将开启，带来多项重要更新：AMDGPU 驱动默认启用 HDMI 2.1 支持，AMD PerfOpt IOMMU 特性默认开启可大幅提升 iGPU 的 AI/LLM 性能，新增 Zen 6 支持及 Ryzen AI Max 400 NPU 支持。Intel 方面为 Panther Lake 做准备并改进 Battlemage 显卡。此外还包含 Apple M4 初始设备树、高通 Snapdragon X2 笔记本支持、EXT4 IOmap 缓冲 I/O、FUSE 大 folio、Google Tensor G5/Pixel 10 主线支持等。

Linux 7.3 内核预计将于今天晚些时候发布稳定版，该版本包含许多令人兴奋的变更和改进。然而，Linux 7.4 内核的合并窗口随后将开启，预计这个后续内核周期会有更多令人兴奋的变更被合并。以下是 Linux 7.4 预期的一些众多令人兴奋的特性变更预览。

在 AMDGPU 图形驱动方面，AMDGPU 终于默认启用 HDMI 2.1 支持！既然 VRR 和 ALLM 支持也已就位，在那些补丁于今年晚些时候最终开源之后，AMDGPU 内核驱动的 HDMI 2.1 支持已处于良好状态。有了 Linux 7.4，现代 Radeon 显卡应能获得不错的 AMDGPU HDMI 2.1 体验。

在 AMD iGPU 方面，AMD PerfOpt IOMMU 特性带来了非常好的改进。默认启用该 AMD PerfOpt 特性可为 AMD iGPU（包括前代硬件）带来巨大的 AI/LLM 性能提升。

Linux 7.4 还带来了更多 AMD Zen 6 支持补充和改进，例如新的 BTB CTX 隔离特性、AMD RMPOPT 优化、针对 Ryzen Zen 6 CPU 的 AMD P-State 驱动改进。Linux 7.4 还新增了对 Ryzen AI Max 400 系列（Gorgon Halo）NPU 的支持，此前该设备 ID 被错误地从 AMDXDNA 加速器驱动中遗漏。

在 Intel 方面，为 Rugged Panther Lake 做准备，合并了 Intel BFF 驱动。Intel 在图形方面也为 Battlemage 带来了不错的改进：迁移队列上的 CPU 绑定和 ULLS。Intel 图形驱动还引入了 vRAM 健康检查和降级内存处理。

针对 NVIDIA Nova 驱动仍有大量工作在进行中。

同样令人兴奋的是，Linux 7.4 将上游支持几款高通 Snapdragon X2 笔记本。高通方面还有更多工作持续落地。

在 Apple 方面，Linux 7.4 计划为 MacBook Neo 添加 Apple M4 和 A18 Pro 的初始设备树。但与当前 Apple M3 的上游 Linux 内核支持一样，它尚未可供最终用户使用。Apple M3 及更新硬件的更多启用工作仍在进行中，在所有硬件功能接通并工作之前，但至少主线内核可以启动。Linux 7.4 的 Apple Silicon 支持还看到音频支持进入上游。

Linux 7.4 预计还将主线支持 Google Tensor G5 SoC 和 Pixel 10 设备。

Linux 7.4 还带来了其他硬件改进，例如多款笔记本和手持游戏设备的改进、对 Raspberry Pi 10 英寸 Touch Display 2 的支持。

在文件系统方面，EXT4 引入了 IOmap 缓冲 I/O 路径，带来不错的性能提升。FUSE 的大 folio 是用户空间文件系统的另一个性能项目。

Linux 7.4 预计还将引入 Intel Instruction Timeout（Notify VM Exit），以解决 TDX 虚拟机内可能的拒绝服务攻击向量。在虚拟化方面，微软还为 Linux 内核贡献了一个半虚拟化 IOMMU Hyper-V 驱动。Linux 7.4 的另一个虚拟化新增是……
