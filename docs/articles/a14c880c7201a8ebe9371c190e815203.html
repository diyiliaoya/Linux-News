Linux 7.4 合并 539 个 MM 补丁：从优化到更多 DAMON 工作

Linux 7.4 合并窗口已接收 539 个内存管理（MM）补丁，审核率为 76%。主要更新包括：DAMON 新增对 HugeTLB 内存的访问监控和自动调优的大页折叠机制；/proc/PID/smaps_rollup 使用 per-VMA 锁降低延迟；优化 zone-device 结构页初始化和 MGLRU 性能；交换代码修复与清理；以及更多 page-to-folio 转换。

Andrew Morton 为 Linux 7.4 合并窗口发送了大量内存管理（MM）相关补丁。本周期补丁总数达到 539 个，审核率为 76%。

与大多数周期一样，MM 补丁散布于性能优化、folio 转换以及围绕 DAMON 数据访问监控的持续工作之中。

DAMON 在每个内核周期都持续获得大量工作。DAMON 的变更包括支持对 HugeTLB 支持的内存进行访问监控。DAMON 还新增了一种自动调优机制，用于折叠大页。

/proc/PID/smaps_rollup 现在在可能的情况下使用 per-VMA 锁，以在另一个线程忙于更改其映射时“显著”降低延迟。

本轮的 MM 优化包括通过避免冗余工作来加速 zone-device 结构页的初始化。多代 LRU（MGLRU）代码也有一些性能工作。

Linux 交换代码进行了一些修复和代码清理。

Linux 内核中继续发生更多向使用 folio 的转换。交换 I/O 和其他元素中进行了一些 page-to-folio 转换。

有关 Linux 7.4 众多 MM 变更的更多细节，可通过已合并到 Linux Git 的内容查看。
