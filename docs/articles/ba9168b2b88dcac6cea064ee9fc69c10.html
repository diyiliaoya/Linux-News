KosmicKrisp 取代 MoltenVK，成为 Mac 上 Vulkan 的首选方案

2026 年 11 月 25 日东部时间晚上 08:39 发布。

最初作为一项在 Apple Metal 之上分层实现 Vulkan API 以便在 macOS 和 iOS 上使用的计划，这项由 LunarG 主导的工作现已成为现代 Apple 设备上 Vulkan API 支持的首选方案。

Khronos Group 今日宣布，Vulkan Portability Initiative 及 MoltenVK 在帮助 Apple 平台支持 Vulkan 方面已经“完成了它的工作”。但既然 KosmicKrisp 已在 Apple Silicon 上实现 Vulkan 1.4 一致性，该可移植性计划正被弃用。随着 KosmicKrisp 更健壮的 Vulkan 实现被内置到 Mesa 中，Vulkan 规范中用于帮助可移植性的临时扩展也不再需要。

MoltenVK 曾是 Vulkan 在 Apple 系统上的先驱，而如今 KosmicKrisp 成功在 Apple Metal 之上提供了完全符合规范的 Vulkan 实现。MoltenVK 也曾是唯一利用可移植性扩展的 Vulkan 分层实现。

MoltenVK 现被视为已弃用，而使用它的已发布应用可以继续工作。MoltenVK 也仍可用于 KosmicKrisp 无意支持的老旧 Intel Mac，或用于较旧的 macOS 版本。KosmicKrisp 目前也不支持 iOS，仅支持 macOS。
