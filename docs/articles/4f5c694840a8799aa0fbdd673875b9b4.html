eCryptfs 修复潜在恶意意图问题，部分可追溯至 2006 年首次亮相

Linux 内核中的 eCryptfs 堆叠加密文件系统在 Linux 7.3 内核中迎来多项错误修复，其中一些涉及潜在恶意构造的数据，且漏洞可追溯至 2006 年 eCryptfs 首次引入时。该文件系统常用于 Ubuntu 主目录加密和 Chrome OS。修复内容包括针对下层加密文件中恶意元数据的加固、内核与用户空间 miscdev 通信的加固、锁修复、挂载选项显示修复以及内存分配优化等。部分安全漏洞疑似通过 AI 工具发现。

eCryptfs 是 Linux 内核中的堆叠加密文件系统实现，用于透明加密文件。在 Linux 7.3 内核中，它迎来了一系列错误修复。其中许多修复涉及潜在恶意构造的数据，以及可追溯至 2006 年 eCryptfs 首次引入时的漏洞——该选项因用于 Ubuntu 主目录加密和 Chrome OS 而闻名。

eCryptfs 代码现已针对下层加密文件中的恶意构造元数据进行了加固和修复。同时，针对内核与用户空间 miscdev 通信中的恶意行为也进行了加固和修复。此外，还有锁修复、与加密文件名相关的挂载选项显示修复、避免不必要的内存分配以及其他改进。

其中一些安全修复可追溯至提交 237fead61998，即 eCryptfs 于 2006 年首次引入主线内核之时。至少部分这些漏洞似乎是通过 AI 工具发现的。
