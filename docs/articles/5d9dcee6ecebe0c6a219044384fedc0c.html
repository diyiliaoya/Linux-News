Intel 工程师向 Linux 内核邮件列表提交补丁，确认 Nova Lake S 和 Nova Lake P 处理器的集成显卡将支持 SR-IOV（单根 I/O 虚拟化），配合 Xe 内核显卡驱动使用。同时，Intel GPU D 系列（原 Crescent Island）也在此补丁中加入 SR-IOV 支持。该补丁可能需等到 Linux 7.5 内核周期才能合并。

Intel Nova Lake S 与 Nova Lake P 将支持 Xe 显卡的 SR-IOV

2026年10月15日 下午5:04 EDT

Intel 工程师向 Linux 内核邮件列表提交了一个补丁，确认搭载集成显卡的 Nova Lake S 和 Nova Lake P 处理器将配合 Xe 内核显卡驱动支持 SR-IOV。

对于希望在虚拟化环境中使用 Intel 集成显卡的用户来说，这是个好消息：Nova Lake P 和 Nova Lake S 的集成显卡据称将支持单根 I/O 虚拟化（SR-IOV）。不那么令人意外的是，Intel Crescent Island 硬件——现称为 Intel GPU D 系列——也在此同一补丁中为 Xe VFIO 代码添加了 SR-IOV 支持。

“Crescent Island (CRI)、Nova Lake-S (NVL-S) 和 Nova Lake-P (NVL-P) 在 Xe 驱动中支持 SR-IOV。将其 PCI ID 添加到 xe-vfio-pci 设备表中，以便生成的 vfio_pci 模块别名允许用户空间为其 VF 选择此变体驱动。”

该补丁已在 Linux 内核邮件列表上接受审查。鉴于下周就是 Linux 7.4 的合并窗口，而 DRM-Next 的截止日期已过，此补丁可能要等到 v7.5 内核周期，除非它作为 Linux v7.4 的早期“修复”提交。
