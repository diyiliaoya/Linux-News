Ghostty 1.4 发布，Linux 平台大幅改进

开源终端模拟器 Ghostty 发布 1.4.0 版本，经过七个月开发带来多项改进。Linux 和 macOS 性能优化，空闲时压缩回滚缓冲区可减少高达 90% 内存占用；完整支持 Kitty 图形协议（含动画和相对定位）；GTK 版本支持拖拽重新排列分屏；修复分数缩放下的文字模糊问题；新增独立 SSH 包装器、Kitty 剪贴板协议等。该版本要求 GTK 4.18 和 libadwaita 1.7，不再支持 Ubuntu 24.04 LTS。

开源终端模拟器 Ghostty 发布了一个重要的新版本。

Ghostty 1.4.0 经过七个月的开发，带来了多样化的变更。Linux 和 macOS 上都有令人欢迎的性能优化，更强大的 SSH 实现，以及更简单的重新排列标签分屏的方式——拖拽它们！

这个基于 Zig 的应用的更新提供了完整的 Kitty 图形协议支持（包括动画和相对定位）——这是除 Kitty 之外第一个做到这一点的终端。如果你使用 TUI 工具或脚本在终端中渲染图像，这是一个重大成就。

Kitty 协议支持已完整

开发者表示，此更新大幅提升了性能。值得注意的是，1.4.0 现在会在终端空闲时压缩离屏回滚缓冲区。这将大量文本历史记录使用的物理内存减少高达 90%。

如果你回滚或使用今年早些时候更新中添加的文本搜索功能，内容会被解压缩。

GTK 应用在 125% 和 150% 等分数显示缩放下渲染文字清晰，这应该能解决经常被提及的文字模糊问题。

此更新还将 OpenGL 替换为 EGL 渲染管线，该管线在独立线程上运行，并使用 DMA-BUF 将帧传递给 GTK。这需要系统 EGL 库；如果 GPU 无法导出 DMA-BUF，则使用较慢的基于 CPU 的复制。

拖拽终端分屏，放置区域高亮显示

GTK 版本中的终端分屏可以通过拖拽重新排列。当一个标签有两个或更多分屏时，每个分屏都有一个拖拽手柄，可以抓住分屏并将其拖放到另一个分屏上。

其他变更包括：

独立 SSH 包装器

更好的终端模拟准确性

Kitty 剪贴板协议

性能改进

值得注意的 Linux 变更：

终端获得焦点或关闭时，桌面通知会消失

Noto emoji 字体更新，使更新的 ZWJ 序列渲染为单个字形

Dolphin 的“在此处打开 Ghostty”在运行实例中打开新窗口

分屏调整大小不再闪烁，也不能再被调得太小

选择文本时鼠标光标保持文本形状

如果 window-theme = ghostty，命令面板使用终端颜色

URL 现在通过 XDG 桌面门户打开

GTK 版本的配置选项包括 gtk-horizontal-tab-scroll，可设置为 false 以禁用双指滚动切换标签，以及 tab-close-button-position，用于将关闭按钮移到每个标签的开头。

安装 Ghostty 1.4.0

Ubuntu 26.10 将包含 Ghostty，但不会是最新版本。要获得上述变更，你需要使用其他方法。

有很多可用的方法。在 Ubuntu 上通过非官方社区维护的 PPA 安装（该 PPA 有自己的 PPA 以便轻松更新）。还有 GitHub 提供官方二进制文件（推荐；支持应用内更新），也可以通过 Homebrew 和其他 CLI 包管理器获取。

Ghostty 放弃对 Ubuntu 24.04 LTS 的支持

根据终端的 GTK/Adwaita 版本政策，1.4.0 要求 GTK 4.18 和 libadwaita 1.7，Ubuntu 24.04 LTS 不再满足要求。这意味着 Ghostty 的 DEB 版本（例如来自上述 PPA）无法再安装。

另外，底层的终端模拟库将为未来版本的 GNOME Console 提供终端支持。Linux Mint 的新终端应用 Ptyxis 不使用该库，但据说其设计受到了 Ghostty 的启发。
