Fedora 45 Beta 性能测试：令人满意地平淡无奇的基准测试

发布于 2026 年 10 月 1 日下午 04:57（美国东部时间）。

尽管最近几周已有不少开发版基准测试，而且还有更多即将到来，但一些 Phoronix 读者询问为何缺少任何早期的 Fedora 45 Beta 测试。理由很充分，它基本上很平淡，但这里还是提供一些测试来说明情况。

由于 Fedora 会向现有 Fedora 版本推送新的 Linux 内核版本作为稳定更新，同时还有其他软件包升级（例如 Mesa 会升级到新的功能版本），因此比较 Fedora 各版本远不如比较 Ubuntu 等发行版那样令人兴奋——后者由于更保守的 SRU 策略，每六个月会有更大的版本跃升。随着 Fedora 春季版本迅速转向当年最新的 GCC 编译器功能版本，这也使得秋季 Fedora 版本不那么引人注目，只是转向新的 GCC 点版本。

也有一些例外，例如秋季 Python 的大版本发布，因此 Fedora 45 相比 Fedora 44 搭载了 Python 3.15-rc2。对于某些版本，他们还会进行有针对性的编译器优化和其他可能影响整体系统性能的更改，但通常由于 Fedora 更宽松的稳定更新策略（会推送新的 Linux 内核和 Mesa 版本），Fedora 各版本之间的性能变化往往不太广泛。

无论如何，我最近运行了一些基准测试，比较了截至 9 月 23 日所有可用更新的 Fedora Workstation 44 与 Fedora Workstation 45 Beta。所有测试都在同一台 System76 Thelio Major 工作站上完成，配备 AMD Ryzen Threadripper 9980X 64 核处理器、4 x 32GB DDR5-5600 内存、1TB NVMe SSD 和 AMD Radeon AI PRO R9700 显卡。

Fedora 44 和 Fedora 45 Beta 都运行在 Linux 7.2 上，Fedora 45 Beta 默认使用 GNOME 51 而非 GNOME 50，两者都使用 Mesa 26.2、GCC 16.2.1，并采用 Btrfs 文件系统。Fedora 45 Beta 确实搭载了 Python 3.15-rc2，而 Fedora 44 则是 Python 3.14.7。
