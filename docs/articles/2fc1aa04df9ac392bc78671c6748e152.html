CachyOS 为服务器版奠定基础

CachyOS 最新版本为即将推出的服务器版奠定了基础，CLI 安装器新增了实验性配置文件，同时其 GUI 包管理器 Shelly 进行了全面重写，采用 Rust 编写，性能更优。此外，新版本还引入了新的欢迎界面、列表/网格视图、AUR PKGBUILD 预览、系统托盘支持、手持设备检测改进以及 DNS 处理优化。用户可通过 Shelly 或终端轻松更新。

CachyOS 为服务器版奠定基础

CLI 安装器的新实验性配置文件针对即将推出的服务器版，而 Shelly 则进行了全面重写。

无论你喜欢还是讨厌，滚动发布发行版已经在 Linux 桌面市场中占据了一席之地。它们提供了前沿的体验，如果维护得当，可以保持相当稳定，但如果处理不当，也会让用户吃尽苦头。

CachyOS 就是其中一种越来越受欢迎的选项。它提供了针对 CPU 优化的重建 Arch 软件包栈，以及为响应性调优的自定义内核，是一款性能出色的发行版。

你可能还记得去年年底，开发者曾预告了针对 NAS 设置和托管提供商的专用服务器版的计划。他们最新的发布向我们展示了部分工作进展，以及典型的发行版改进。

本次更新带来了许多新增内容，例如 Hyprland 的选项，用 lightdm-slick-greeter 替换了 SDDM，以及 COSMIC 引入了新功能。除了常规的 bug 修复和代码重构工作外，还新增了服务器版安装配置文件的实验性支持，这标志着新变体开发中的一个重要里程碑。

Shelly 在四月份成为 CachyOS 的默认 GUI 包管理器，取代了 Octopi，我们在使用后发现这是一个有前途的转变。在这次 CachyOS 发布中，Shelly 的 v3 迭代迎来了迄今为止最重大的变化。

它已从使用 Rust 编写，用原生二进制文件取代了托管运行时，启动更快，内存占用更少。

与之相伴的是首次运行时显示的新欢迎界面，以及用于浏览软件包的列表和网格视图，还有带有构建输出的 AUR PKGBUILD 预览。

新增了用于同步数据库、清理缓存和移除孤立软件包的页面。同样，其 CLI 版本现在可以在一个地方搜索仓库和 AUR，并在仓库、AUR、AppImage 和 Flatpak 中运行更新检查。

系统托盘小程序已移植到 Rust。新的标志将两个先前独立的步骤合并，同时启用自动更新检查和启动托盘图标。

然后是手持设备检测，目前基于主板名称模式匹配，支持保加利亚语本地化，并且不再因某些情况而出现问题。

最后，我们看到了应用，其 DNS 处理已重新设计，解决了一个导致基于速度测试的排名无法实际选择最快服务器的问题。

请查看发布公告博客，了解我们在此略过的较小更改。
