Linux Mint 将在笔记本上“带回”休眠功能

Linux Mint 计划在12月发布的 Linux Mint 27 中重新引入休眠功能，通过系统管理工具让用户轻松启用并配置休眠。当前版本合盖仅挂起，仍耗电，电量耗尽会导致会话丢失。新版本将提供“挂起后休眠”和“先挂起再休眠”两种混合模式，兼顾灵活性与数据安全。

Linux Mint 将在笔记本上“带回”休眠功能 - OMG! Ubuntu

Linux Mint 的下一个版本将加入休眠模式，这样你可以在会话中途合上笔记本，而无需担心回来时电池已耗尽。

定于今年12月发布的 Linux Mint 27 中的系统管理工具，让启用休眠并确保其按需配置变得轻而易举。

当前版本的 Linux Mint 在合上笔记本盖子时会挂起。虽然处于休眠状态，设备仍会消耗一些电量。如果睡眠期间电池耗尽，挂起的会话就会失效——这种结果“比正常关机更糟”。

休眠会将你的会话保存到磁盘并关机。当你启动时，会话会被恢复（虽然设备关闭时电池仍会耗尽，但比挂起时消耗得更少）。

休眠也有缺点。它比挂起慢，恢复速度不如挂起快，并且需要较大的交换空间来存放数据。

Linux Mint 中的睡眠模式

Linux Mint 将提供两种混合模式：

挂起后休眠。

同时将会话保存到磁盘，这样如果你离开时电池耗尽，你仍然可以恢复它。

先挂起再休眠。

先挂起，然后在电池电量极低时进入休眠模式。

两者都提供比当前更灵活的行为，而且由于标准挂起功能仍会保留，没有人会错过。

Linux Mint 表示，Ubuntu 从其可用的睡眠模式中移除了休眠，这就是为什么 Mint 中也缺少该功能。Ubuntu 仍默认关闭休眠，而且如果启用了安全启动，通常也会被阻止。
