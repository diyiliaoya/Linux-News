YT-DLP 被 IFPI 视为盗版工具

国际唱片业联合会（IFPI）向欧盟提交意见，将开源下载工具 yt-dlp 列入盗版观察名单，与非法下载网站归为同类。IFPI 称其为音乐产业的重大难题，并点名四位维护者的 GitHub 账号。yt-dlp 拥有超19.5万 GitHub 星标，支持数千平台，由全球社区维护。该观察名单由欧盟委员会编制，旨在施压境外服务商，不具法律约束力。

YT-DLP 被 IFPI 视为盗版工具

他们向欧盟盗版观察名单提交的意见，将这款开源工具与非法下载网站归为同一类别。

它在 GitHub 上拥有超过 195,000 颗星，支持数千个平台，并由一个全球开发者社区积极维护。不幸的是，国际唱片业联合会（IFPI）希望将其列入欧盟的盗版观察名单。

需要说明的是，国际唱片业联合会（IFPI）代表着 70 个国家约 8,000 家唱片公司。

在向欧盟“假冒与盗版观察名单”磋商提交的意见中，该组织称 yt-dlp 是“音乐产业的重大难题”，并点名了四位维护者的 GitHub 账号。

该观察名单由欧盟委员会贸易与经济安全总司负责编制，旨在列出被举报参与或协助侵犯版权的欧盟以外在线服务和实体市场。

虽然听起来很严重，但这项工作并非为了收集法律结论，也不强制要求采取任何形式的直接行动。它更接近一种点名行为，意在向欧盟以外的运营商和政府施压，要求其处理被点名的服务。

2027 年版名单正在根据截至 2026 年 9 月收到的意见进行汇编，最终名单预计于 2027 年第二季度公布。

他们的意见说了什么？

这份意见涵盖了一系列版权执法关切，从 AI 音乐生成器和流媒体欺诈服务到域名注册商。yt-dlp 出现在“流媒体”部分，与 Y2mate 等商业网站归为一组。

他们将这款工具描述为一种通过解析网页数据并与平台播放端点交互来获取内容的应用程序，GitHub 是其源代码、预编译二进制文件和安装说明的主要分发渠道。

IFPI 点名了该项目四位维护者的 GitHub 账号：yt-dlp 的创始人，他在 2021 年至 2024 年间领导该项目，以及项目文档中提到的一些核心维护者。

同一份意见还指出，Y2mate 等平台在大规模协助版权侵权。

它是工具，不是服务

正如欧盟委员会所描述的那样，观察名单针对的是位于欧盟以外的在线服务提供商和实体市场。

从任何传统意义上讲，yt-dlp 都不符合这两种描述。

IFPI 也承认这一点，并指出该项目的开源性质、其 Unlicense 许可，以及庞大的国际开发者社区，使其“难以遏制和/或移除”。

从他们的角度来看，没有可封锁的中心域名，没有可切断的支付处理商，也没有可施压要求遵守下架请求的托管提供商。

源代码在全球分发，任何具备相应技能的人都可以编译它。但这并不意味着 yt-dlp 是一个盗版平台。

它是一个用于下载音频和视频内容的命令行工具，将其与专门的翻录或盗版网站归为一类，是把通用下载器与主要目的为协助未经授权复制的服务混为一谈。

观察名单此前曾被用于对商业流媒体翻录平台进行执法。

Y2mate 和其他十一个流媒体翻录网站于 2025 年在越南被关闭，Y2mate 此前也曾出现在名单上。

在此之前，2024 年，一家法院裁定托管提供商 Hosting Concepts 对协助规避行为负有责任。这表明，将一款开源命令行工具与那些商业服务相提并论，本身并不能使该工具成为那些服务之一。
