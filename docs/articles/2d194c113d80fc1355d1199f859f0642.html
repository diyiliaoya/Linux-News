2GB Raspberry Pi 4 现价比首发价高出 50%

受内存组件成本持续上涨影响，Raspberry Pi 宣布自2026年10月1日起，2GB版Raspberry Pi 4和Raspberry Pi 5价格上调12.50美元。2GB Pi 4首发价45美元，现价67.50美元，涨幅达50%。1GB版本暂未涨价，公司建议用户按需选购并尽量从授权经销商处购买，同时期待未来内存成本回落后能下调价格。

当然，其单板计算机的进一步涨价是由内存组件的持续成本所推动的。

自2026年10月1日起，2GB Raspberry Pi 4或Raspberry Pi 5的价格将上涨12.50美元（12英镑）：

作为背景，2GB版Raspberry Pi 4于2019年以45美元首发。后来降至35美元，又在2021年回升至45美元。随后在2月上涨10美元至55美元。如今售价67.50美元的2GB Pi 4，比首发时贵了50%——令人震惊。

过去几年，Raspberry Pi各型号已多次涨价。该公司推出了3GB版Pi 4，以提供更实惠的选择。

尽管该公司表示，在前几轮涨价中它得以维持较低密度单板计算机的价格，但它补充说，持续的行业经济形势意味着这“已变得不可持续”。

“过去两年内存价格急剧上涨，并且仍在继续攀升；与其他公司一样，我们不得不提高许多产品的价格，以跟上生产成本”，该公司在一篇博客文章中写道。

由于内存和存储成本，Pine64也已停止其Linux硬件系列的生产。

也不全是坏消息。Raspberry Pi 4和Raspberry Pi 5的1GB版本价格不变，而Compute Module 4和Compute Module 5的2GB版本同样受到影响——至少目前如此。

鉴于持续的成本压力，Raspberry Pi为爱好者和开发者提供了一些建议。

其一，“确保”他们为任务选择正确的产品，不要为不需要的余量多付钱（甚至指出较旧的型号，如Raspberry Pi 3，可能就足够了）。其二，尽可能只从授权经销商处购买，以确保最低价格。

在最后一丝乐观中，他们认为内存组件的虚高成本将“最终回落”，并且他们期待逆转这些让全球爱好者钱包吃紧的涨价。
