Ikey Doherty 与 Omarchy：为何他构建 Barney 而非另一个发行版

Ikey Doherty，Solus 和 AerynOS 的创造者，带着 Barney 回归，这是一个用 Rust 编写的工具，可从源代码构建 Linux 发行版，以便你轻松创建自己的 Omarchy。

他退隐后复出，而 Omarchy 的融资正是原因。

他称 DHH 发行版背后的资金荒谬，并承诺用更少的资源做得更好，即通过一个基于 Rust 的工具从源代码构建 Linux 发行版。

自 8 月推出以来，Omarchy 的认捐金额已超过 1300 万美元，当时包括 Michael Dell 在内的八位科技高管每人投入了 100 万美元。这一热潮也引来了一些反对声音，最近一次是 1Password 承诺捐赠 30 万美元，而其员工表示反对。Ikey 的视频发布一天后，该基金会宣布从 Meta、Anthropic、OpenAI 和 Fireworks 获得 195 万美元的 AI 代币。

不是发行版，而是一种立场

Barney 是一个旨在帮助你构建 Linux 发行版的工具；该仓库将其描述为“又一个该死的构建 Linux 发行版的工具”，并指出交付发行版并非预期目标。

Ikey 计划展示发行版是如何构建的，而不是发布他所称的“又一个壁纸重制版”发行版，他将在 YouTube 频道上展示这一过程。

所有内容都从源代码构建，输出会根据生成它们的来源进行缓存。更改依赖项，则基于它构建的任何内容都会重新构建。布局保持无状态，Doherty 表示这一概念是他帮助在 Intel 的 Clear Linux 团队中开创的，后来在 Solus 和 AerynOS 中推广（AerynOS 是 Solus 的继任者）。

构建在容器中运行，结果按内容存储，因此不同包中的相同文件只存储一次。计划甚至包括从头重建工具链。

所有内容都用 Rust 编写，并以 MPL-2.0 许可证发布。项目名称本身对他个人意义重大，因为 Barney 是他儿子的名字。

工作已经开始。该系列的第一集已经上线，标题为“第 0 集：准备就绪”。要访问幕后内容，Ikey 已设立了 Patreon，人们可以直接支持他。

一位爱尔兰游民的回应

不要以为 Ikey 没有资格谈论此事。

Omarchy 的创造者 David Heinemeier Hansson（更广为人知的名字是 DHH）曾写过一篇文章，将丹麦的狼群与在哥本哈根公园露营的罗姆人进行比较。

自然，作为世代面临歧视的爱尔兰游民，Ikey 必然会做出反应。在社交媒体上分享他的视频（开头链接的那个）时，他称 DHH 的言论“恶心”，并表示资金和观点共同将他拖回了这场游戏。

他的笔记本电脑购买计划

Michael Dell 是发布时的支持者之一，Ikey 已将该品牌列入他的回避名单，同时点名批评 Omarchy：

“说实话，在 Michael Dell 表示支持 DHH 之后，我不会再买戴尔笔记本电脑了。暂且不提它又是一个壁纸重制版发行版……我无法容忍 DHH 的言论（在多个话题上）。作为爱尔兰游民，我强烈谴责他关于游牧民族的言论。作为前 Linux 发行版开发者，即使你付钱给我，我也不会碰他的东西。”

只有时间能证明一切。目前，我的看法是这个问题没有抓住要点。Barney 并不是要成为每个人都安装的发行版。按照 Doherty 自己的说法，成功在于在业界的注视下展示一个真正的发行版是如何构建的。

你已经知道他以前曾放弃过大型项目。Solus 和 AerynOS 都在没有他的情况下继续发展。Barney 当然也可能成为下一个。

让我印象深刻的是这一切的时机。另一位 Clear Linux 成员 Auke Kok 正在从头构建一个系统，而他们两人都没有等待某个基金会来启动。

我内心的乐观主义者说，如果他们两人合作，他们可以交付一些东西，向 Linux 生态系统展示，向一个项目投入荒谬的资金并不是构建优秀系统的唯一途径。
