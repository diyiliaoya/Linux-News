Nouveau 准备最终默认启用原子模式设置

2026年7月31日，上午11:22 EDT。

继 Nouveau 内核驱动解锁 Mesa NVK 驱动的 Vulkan Video H.264 支持之后，另一个即将到来的功能变更是这个开源 NVIDIA Linux 驱动终于准备默认启用原子模式设置。

Nouveau 长期以来一直支持原子模式设置，但尚未默认启用。

原子模式设置允许用户空间的合成器/程序将完整的硬件配置传递给内核，以单个原子事务的形式提交。原子模式设置反过来可以减少屏幕闪烁，并在现代 Linux 桌面上提供更可靠的模式设置体验。大多数 Linux 桌面软件都支持原子模式设置，且主要的开源 DRM 内核驱动早已支持。

Red Hat 的 Lyude Paul 一直在处理补丁，以在 Nouveau 驱动中默认启用原子模式设置。这影响 NVIDIA NV50 / GeForce 8 系列及更新的硬件。

默认启用 Nouveau 原子 KMS 的补丁说明：

“Nouveau 是内核中少数几个未默认启用原子模式设置的现代硬件驱动之一，部分原因是当 Ben 最初编写它时，没有太多好的原子模式设置客户端来实际测试。

然而如今，原子模式设置已成为常态——用户空间对非原子驱动的支持开始逐渐腐化——这导致了其自身的一系列问题。同时，许多这些问题只需在 Nouveau 中开启原子模式即可解决。此外，我已在大多数我工作的机器上默认启用 Nouveau 的原子模式设置，并已修复了相当多的问题，以至于情况似乎相当稳定（除了我桌面上一个屏幕闪烁的 bug，我不太确定这与原子模式设置有关）。

这个补丁系列默认启用原子模式设置，至少对 NV50 及更新硬件生效。NV04 保持不变，因为从未为其实现原子模式设置。该系列还强制在 NV50 以下禁用原子模式设置，并在内核调试输出中添加 nouveau.atomic 的值。”

鉴于当前的时间安排，这个更改可能不太可能及时进入 Linux v7.3 周期，但希望这个默认更改不久后就能落地。
