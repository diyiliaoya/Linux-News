Extension Manager 0.7 发布，带来新功能与修复

Extension Manager 0.7 版本发布，新增 GNOME 搜索提供程序支持，可直接从概览打开扩展首选项；扩展详情页展示更多信息，支持动画 GIF 截图；已安装扩展列表新增批量卸载模式，并恢复了对不支持扩展的过滤功能。该应用免费开源，可通过 Flathub 安装。

Extension Manager 0.7 发布，带来新功能与修复 - OMG! Ubuntu

这款桌面应用让用户无需浏览器即可更轻松地浏览、安装和管理 GNOME Shell 扩展，现已发布。

该版本包含多项受欢迎的改进、新功能，并恢复了一些在早期版本中失效的实用功能。

通过新更新，你现在可以从概览中查找并打开已安装扩展的首选项，因为该应用现在捆绑了一个 GNOME 搜索提供程序。安装此版本后，如果你会用到该功能，可在设置中启用它。

从概览跳转到扩展首选项

扩展详情页显示更多细节，包括以前需要访问网页才能看到的信息，如版本和 GNOME 支持情况。已安装的扩展会显示卸载按钮和安装路径位置，并附带在文件管理器中打开的按钮。

一些扩展使用动画 GIF 来展示其主要功能或特性，该应用利用 Glycin 来渲染动画截图。

应用列表中的更多信息——包括动画 GIF

在已安装扩展列表中，选择模式允许你一次性批量卸载扩展；如果在启用扩展后发生错误，新对话框会显示错误详情（以前显示在下拉列表中）。

该应用再次默认仅显示支持你当前 GNOME 版本的扩展搜索结果。如果需要，可以选择显示所有（即不受支持的）结果。

在 v0.7.0 中，过滤不受支持扩展的功能已恢复

该应用还计划允许查看扩展作者页面，页面将列出该作者的其他扩展。支持该功能所需的部分代码已包含在此版本中，但实际功能本身被暂缓推出。

该应用是专为 GNOME 设计的免费开源软件。你可以从 Flathub 安装最新版本，它依赖 GNOME 51 运行时（因此如果你没有其他应用使用该运行时，它也会被一并拉取）。

Ubuntu 仓库中提供的是较旧版本的 Extension Manager，但要享受此处提到的更改，你需要从 Flathub 安装，或等待 Ubuntu 27.04 发布。
