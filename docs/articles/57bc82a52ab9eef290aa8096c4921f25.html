ARCTIC 的 Linux 风扇控制器驱动将采用 BSD-2-Clause 双许可

ARCTIC 为其桌面风扇控制器发布的 Linux 驱动现已改为 GPLv2+ 与 BSD-2-Clause 双许可，便于移植到 BSD 等非 GPL 平台。该驱动此前已主线化，此次变更将随 Linux 7.4 内核周期合入。产品售价 8.99 美元，是 Linux 下高性价比的官方支持风扇控制器。

ARCTIC 为 Linux 发布了一款风扇控制器驱动。对于一家面向发烧友的公司来说，自己发布 Linux 驱动本就罕见——这类外设的驱动支持通常留给开源社区——而更引人注目的是，他们在产品尚未发布前就发布了 Linux 驱动并使其进入主线。最终，ARCTIC 风扇控制器成为 Linux 下最好的桌面风扇控制器，售价不到 10 美元。如今，这款开源驱动正在采用双许可，以帮助其进入更多操作系统。

ARCTIC 现已将其 "arctic_fan_controller" 驱动双许可为 GPLv2+ 和 BSD-2-Clause。此前它仅为 GPLv2+，现在增加了 BSD-2-Clause。

该驱动采用 BSD-2-Clause 双许可，将有助于那些希望将此风扇控制器驱动引入 BSD 或其他偏好非 GNU GPL 平台的人。对于希望在 Linux 或 Windows 之外管理桌面 PC 风扇转速的潜在客户来说，这是一个虽小但重要的变化。

该双许可已进入 hwmon-next Git 分支，因此将在今年晚些时候的 Linux 7.4 内核周期中实现。

这款风扇控制器仍可在（联盟链接）等渠道以 8.99 美元购买，使其成为一款非常出色且价格实惠、拥有官方 Linux 支持的选项。
