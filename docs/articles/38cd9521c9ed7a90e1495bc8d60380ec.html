KDE Linux 接近 Beta 里程碑，现默认搭载 NTSYNC

KDE 开发者 Nate Graham 发布月度博客，介绍 KDE Linux 在十月的进展。该发行版开发已超过一年，目前完成约 85% 的 Beta 里程碑。十月改进包括安装器新增基础幻灯片、内核默认启用 NTSYNC 模块以提升 Wine/Proton 游戏性能、基础镜像加入 wayland-protocols。仍需完成交换支持、Discover 更新体验、双启动体验、Flatpak 崩溃处理等。

KDE 开发者 Nate Graham 于周日发布月度博客，概述了 KDE Linux 的当前状态以及该内部 Linux 发行版在十月期间所做的一些更改。此外，KDE Linux 在作为 KDE 参考 Linux 发行版开发一年多后，正接近其 Beta 里程碑。

对于首次安装 KDE Linux 的用户，十月的一项改进是 KDE Linux 的安装器现在有了基础的幻灯片。KDE Linux 安装器幻灯片类似于其他 Linux 发行版的操作系统安装器。

在内核方面，KDE Linux 现在默认启用 NTSYNC 内核模块。默认启用 NTSYNC 增强了通过 Wine/Proton 在 Linux 上游戏的开箱即用体验和性能。

在桌面方面，wayland-protocols 被添加到 KDE Linux 基础镜像中，以扩大操作系统对一些依赖它的 KDE 项目的支持。

KDE Linux 正接近其 Beta 里程碑，截至十一月初大约完成了 85%。相关页面显示，在交换支持、改进 Discover 内的更新体验、KDE 基础设施更改、改进双启动体验、更好地处理 Flatpak 崩溃以及其他改进方面仍有工作要做。

更多关于 KDE Linux 近期更改的细节，请参阅 2026 年十月报告。
