Ubuntu 的 IRC 支持频道将被“日落”，部分用户不满

Ubuntu 计划将 IRC 作为官方支持渠道“日落”，此举引发长期用户不满。近期 Ubuntu 26.04.1 LTS 发布公告未包含 IRC 支持频道链接，引发社区讨论。Ubuntu 社区委员会成员 Aaron Rainbolt 表示，未来将逐步淘汰 IRC，转向 Matrix 等现代平台。尽管 IRC 频道不会关闭，但官方将不再推荐使用。部分用户认为 Matrix 无法完全替代 IRC，且 IRC 在透明度和决策记录方面仍有价值。

Ubuntu 的 IRC 支持频道将被“日落”，部分用户对此不满。

最近的 Ubuntu 26.04.1 LTS 发布公告中，在“如果您有问题”部分没有包含 Ubuntu 支持 IRC 频道的链接——尽管从查看来看，最后一次列出 IRC 的公告是 Ubuntu 24.10 的公告。

这引发了关于 Ubuntu 支持 IRC 频道是否仍是官方社区支持选项的疑问（Ubuntu 26.04 中的应用仍包含指向提及 IRC 的页面的链接）。

Ubuntu 社区委员会成员 Aaron Rainbolt 表示，这一遗漏可能是“偶然的”，并在 Ubuntu 的 Discourse 上发布了一个后续讨论，标题为“保持 IRC 作为 Ubuntu 的官方支持方法”，计划在适当时候“将 IRC 作为 Ubuntu 官方通信平台日落”。显然，这尚未发生，但即将到来——尽管这一消息不会登上头版。

Canonical 最近一直在现代化其基础设施，例如，砍掉 Bazaar 代码托管，退役 Ubuntu Pastebin。其目光将转向为 IRC 上的传统集成而保持在线运行的服务器，如 irclogs.ubuntu.com 存档和各种交互式机器人。

在 2006 年到 2016 年间很有用，但在 2026 年是否还值得继续维持？

Ubuntu 开发团队已于 2025 年 3 月将其讨论移至 Matrix。虽然曾尝试过 IRC 桥接，但根据 Rainbolt 的说法，目标是让所有人都使用“社区整体监控、维护和工作的”平台。

这并不意味着 IRC 上的频道会终结。它们不会离线，仍会存在，任何人都可以自由加入、潜水或聊天——毕竟，日志脚本和机器人对于基本的聊天任务并不是必需的。

而 IRC 本身——除了 Freenode 的闹剧之外——即使在现代替代品的冲击下，仍然保持韧性。

Ubuntu 可能不再引导用户到其旧 IRC 频道提问或寻求帮助，但毫无疑问，仍然会有人类（或机器人）可以回答问题。

一些热心的 IRC 用户并不相信 Matrix 是完美的替代品，指出支持房间活动量低，账户设置过程更复杂。但是，自从 AI 聊天机器人出现以来，向人类同伴寻求帮助并不是大多数人的首选。

目前尚未确定任何面向用户的转变日期——就目前而言，如果有什么值得注意的变化——所以现在，如果您潜伏在 Ubuntu 支持（或其他）频道上：保持冷静，不要 /quit。

更多可能让人惊讶的是，这些频道竟然还没有被“日落”。

当 Ubuntu 治理会议在 IRC 上举行时，存档对于透明度、投票记录、决策等尤为重要。现在会议通过 Jitsi 在 Matrix 上进行。Canonical 工程师也使用自己的内部聊天平台进行沟通。
