NVIDIA CUDA 13.5 发布，为 Vera Rubin 提供生产级支持

2026年11月4日 下午4:11（美国东部时间）。

伴随今日发布的 NVIDIA 620.70.06 Linux 驱动，NVIDIA 还发布了 CUDA 13.5，为 Vera Rubin 带来通用可用（GA）支持。

NVIDIA CUDA 13.5 为 Vera Rubin 提供通用可用支持，这建立在现有 CUDA 13 版本中的初步支持之上。伴随 GA 支持而来的还有新的性能改进和其他增强，使新的 Vera Rubin 硬件受益。

CUDA 13.5 还实现了多 GPU 通信以及与现有 CUDA 库在 CUDA Tile 上的互操作性、CUDA Python 的批量内存拷贝、新的 GPU 资源管理能力、Nsight 中围绕 AI 训练/推理的新性能分析能力，以及各种其他开发者改进。

关于这个规模相当大的 CUDA 13.5 稳定更新的更多细节，可通过 NVIDIA 开发者博客查看。
