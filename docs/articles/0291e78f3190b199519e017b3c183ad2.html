CutefishOS 携全新氛围编码桌面回归，不再使用 Qt 或 GTK

CutefishOS 项目宣布回归，使用 Anthropic 的 Fable 5.1 和 Opus 5.5 AI 模型从零重写了整个桌面环境，包括系统应用。新桌面拥有自己的 Wayland 合成器和图形库，不基于 Qt 或 GTK，界面风格类似 macOS，应用启动迅速。目前尚无发布日期，代码仓库尚未公布。

在上面的视频演示中，可以看到界面的整体观感模仿了 macOS，顶部栏包含一个[全局菜单]、标准状态小组件。

[控制中心]包含 Wi-Fi、蓝牙、深色模式、勿扰模式、摄像头和麦克风的开关，以及媒体控制和用于调节显示亮度和音量的滑块。

还有一个可配置的 Dock，可置于屏幕左侧、底部或右侧，带有调节其大小和玻璃效果的滑块，以及[多种模式]。

与 GNOME 类似，Cutefish 桌面的[概览]模式将打开的窗口铺展在网格中，允许用户通过顶部的一个便捷按钮添加新工作区（项目称之为“["空间"]”）。

[系统应用]包括文件管理器、终端、日历、系统监视器、文本编辑器、视频播放器、截图工具和图像查看器，似乎都是为新的 CutefishOS 桌面体验专门打造的。

Chromium、Firefox、KeePassXC、Ghostty 和 LibreOffice 也作为可在该桌面上运行的应用出现在启动器中。

该项目称[整个桌面已从零重写]，包括系统应用，并且应用启动非常快。更进一步声称合成器和图形库均为自研。

[当被问及]桌面是否基于 GTK 构建时，项目方（即 Reion）澄清说它不基于 Qt 或 GTK。

回顾 CutefishOS

CutefishOS 于 2021 年作为基于 Debian 11 的测试版发行版问世，围绕一个受 macOS 启发的、名为 CutefishDE 的桌面构建。当时它就已经在状态栏中提供了全局应用菜单和若干捆绑应用。

2022 年，该项目网站停止加载，仓库活动几乎停滞。随后一位 Reddit 用户开始为社区分支招募人员。该分支计划[被搁置]，因为项目 GitHub 表示已回归并将推出新网站。

如果你今天想测试新桌面，请注意[尚未公布发布日期]。当一位 X 用户表示迫不及待想试用演示时，项目方回复称还需要一段时间才能测试。

翻查该项目的[GitHub]，你会发现没有列出新桌面的专用仓库。从 Reion 迄今为止开发 CutefishOS 的地方来看，那里是关注新代码的地方。

这并非唯一的氛围编码桌面；[Starling 是另一个实现]，可能也会让你感兴趣。
