Firefox 隐藏了一款贪吃蛇游戏，以下是玩法

Firefox 浏览器地址栏的计算器功能中藏有一个彩蛋：当计算结果为 150 时，会出现 Firefox 图标，点击即可玩隐藏的贪吃蛇游戏。玩家用方向键控制蛇头移动，吃豆子得分，但要避免撞墙或撞到自己。该功能自 Firefox 151 版本起就已存在。

Firefox 隐藏了一款贪吃蛇游戏，以下是玩法 - OMG! Ubuntu

如果你感到无聊，想快速玩点小游戏，只要你知道方法，就能在 Firefox 的地址栏里玩上一把。

据 Hentzschel 发现，Mozilla 的浏览器有一个彩蛋，只有使用地址栏的计算器功能时才会触发。

通常，计算结果旁边会出现一个图标，用于将数值复制到剪贴板。但如果计算结果是 150，则会出现一个 Firefox 图标。点击该图标会展开一个下拉菜单，里面是著名迷你游戏贪吃蛇的可玩版本。

要尝试的话，打开 Firefox，聚焦地址栏并输入 100+50。计算结果旁边会显示一个 Firefox 图标，以及复制按钮。输入 15^2-75、75*2 或任何其他结果为 150 的受支持数学公式，效果相同。

如果结果不是 150，就不会出现游戏。

摧毁任何网页——一款很酷的浏览器游戏

玩法很简单：键盘方向键分别控制以 Firefox 图标为头的蛇向上、下、左、右移动。

你的目标是引导 Firefox 蛇在棋盘上移动，吃掉出现的豆子——但要避免撞到游戏板的边缘或自己的尾巴。

简单吗？算是吧，但那些豆子会让蛇的尾巴随时间变长。吃的豆子越多，坚持得越久，分数就越高——挑战也越难！

Firefox 并非第一个内置隐藏游戏的网络浏览器。最著名的是谷歌标志性的恐龙游戏，当你有一点点时间时，玩一玩很有趣。
