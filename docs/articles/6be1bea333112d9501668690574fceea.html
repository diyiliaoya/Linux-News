发行版发布：CobaltX 0.3

CobaltX 0.3 发布，这是一个基于 Arch Linux 的游戏专用发行版，搭载 KDE Plasma 6 和 Linux Zen 内核。新版本引入 X Mode 全屏游戏启动器、手持设备支持、快速设置与 TDP 控制、主题屏幕键盘、手柄光标等功能，并支持一键安装 NVIDIA 驱动。

Anton Batishchev 宣布发布 CobaltX 0.3，这是该项目基于 Arch Linux 的游戏专用 Linux 发行版的更新版本，搭载 KDE Plasma 6、Linux Zen 内核和预装的游戏套件：

“0.3 'Fullscreened' 版有什么新内容？X Mode——一个全屏、手柄优先的游戏启动器，拥有自己的登录会话——将 Steam、Heroic、Bottles、Lutris 和你自己的游戏集中在一处；启动进入 X Mode——在安装程序中选择 X Mode 或桌面，随时切换；手持设备支持——通过 Handheld Daemon 为 ROG Ally 系列、Legion Go、MSI Claw 等设备提供内置控制和背键；快速设置和 TDP——性能模式、以瓦为单位的功耗限制、亮度和音量，在 X Mode 和桌面上均可使用；CobaltX 键盘——主题化屏幕键盘，可输入到任何应用或游戏（手柄或触摸）；手柄光标——在桌面上使用摇杆作为鼠标；库 + 添加游戏——添加未自动找到的 AppImage、.exe 文件、脚本或 ROM；打开应用——恢复或关闭正在运行的应用，对冻结的应用强制关闭……”

请访问 GitHub 查看完整的变更和更新列表。

发行版发布：CobaltX 0.3

CobaltX 是一个专为游戏玩家构建的基于 Arch 的 Linux 发行版。它采用 KDE Plasma 桌面，并预装了完整的 Linux 游戏套件，即 Steam、Heroic Games Launcher、Bottles、Lutris、Wine、RetroArch、MangoHud 和 GameMode。它使用 Archiso 工具和自定义 Calamares 系统安装程序构建。在底层，该发行版部署 Linux Zen 内核以实现低延迟桌面性能。CobaltX 还通过发行版欢迎应用中的一键安装选项提供对 NVIDIA GPU 的支持。
