Obscura VPN 现已推出 Linux 桌面应用 - OMG! Ubuntu

Obscura VPN 已发布原生 Linux 应用，让桌面用户能更轻松地使用它（无需再费心处理 WireGuard 配置文件）。

Linux 平台并不缺少 VPN 提供商，但由前 Bitcoin Core 贡献者 Carl Dong 创立的 Obscura 有着与大多数服务不同的卖点。

你的流量不会通过单一提供商路由，而是采用两步中继：Obscura 充当“入口节点”（看到你的原始 IP 地址），而另一家 VPN 提供商则充当“出口节点”（你访问的网站）。

Obscura 的 Linux 应用还支持基于 QUIC 的隐蔽协议，可将你的 VPN 连接伪装成普通的 HTTP/3 网页浏览。这有助于流量绕过那些可能禁止 VPN 流量的严格网络和服务封锁。

但 Obscura 之所以能将自己宣传为“首个不记录你活动的 VPN”——强调是他们的原话——是因为两家公司都无法获得关于用户及其浏览习惯的完整信息。

一些商业 VPN 提供多跳功能，但所有流量仍然流经同一家公司，理论上如果该公司有需要或收到要求，就能拼凑出完整信息。

隐私保护延伸至注册环节；Obscura 不需要个人信息，你使用随机生成的账号登录，类似。付款通过门罗币（XMR）或比特币闪电网络完成，不过对隐私不太在意的人也可以通过 Stripe 用卡支付。

其他功能则是标准 VPN 配置：服务器位置、隧道功能。

除了新的 Linux 桌面应用，Obscura 还将代码库从 PolyForm 非商业许可证 1.0.0 重新授权为 GPLv3，进一步践行其“对开源软件的承诺”。

下载 Obscura VPN for Linux

Obscura VPN Linux 应用适用于一系列主流发行版。它官方支持 Ubuntu 24.04 LTS 及更高版本，因此也兼容 Pop!_OS 24.04、Linux Mint 22.3——但仅限 Intel/AMD 设备（尚无 ARM 版本）。

在 Ubuntu 上安装需要添加 Obscura Linux 仓库，但该公司通过一个 Deb 包简化了操作（它安装的是仓库，而非应用）：

curl -fsSLO https://linux-pkgs.obscura.com/deb/obscura-repository.deb

sudo apt install ./obscura-repository.deb

sudo apt update && sudo apt install obscura

需要说明的是，这不是免费的 VPN 服务；你需要有效的付费订阅才能使用。

Obscura VPN 每月约 8 美元，比其他选项更贵，但你可能觉得为解耦路由和 QUIC 混淆支付溢价非常值得。

新订阅者可使用促销码享受 25% 折扣。

尽管 Obscura 在 VPN 提供商中有些默默无闻，因为它不在社交媒体上大力宣传，没有免费套餐，也没有用网页邮件、办公套件和云存储等附加服务来填充产品，但它可能值得研究。

这与 Apple 的 iCloud+ Private Relay 概念相同。在那里，Apple 是入口节点，Cloudflare、Fastly 或 Akama 被用作出口节点。是的，有些公司可能会对其隐私资质嗤之以鼻，但我这里只是在概念层面讨论。
