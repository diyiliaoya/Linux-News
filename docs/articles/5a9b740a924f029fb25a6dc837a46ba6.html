Purism 发布第二代 Librem 5 Linux 手机

Purism 正在众筹其 Linux 智能手机的新版本，该版本采用 RISC-V 架构而非 Arm。新机搭载八核 SpacemiT K1 RISC-V SoC，内存升至 8GB，存储升至 128GB，支持从 SD 卡启动第二系统，并首次支持 1300 万像素拍照和高清视频录制。外观、屏幕和电池与初代相同，保留物理开关。售价 1159 美元起，众筹持续至 2027 年 2 月。

Purism 正在众筹其 Linux 智能手机的新版本，该版本采用 RISC-V 架构而非 Arm。

新机将使用八核 SpacemiT K1 RISC-V SoC，取代四核 Arm64 NXP CPU。这一处理器转变将提供比初代 Librem 5 更好的性能和更长的电池续航，且使用时不会那么热。

内存提升至 8GB RAM（原为 3GB），存储从 32GB 跃升至 128GB。Librem 5 v2 将运行 PureOS，这是 Purism 基于 Debian 的操作系统，使用……

SD 卡读取速度更快，这很方便，因为设备可以从存储卡启动第二操作系统。板载硬件编码意味着 Librem 5 将首次能够拍摄 1300 万像素照片和录制高清视频。

Librem 5 v2 采用与初代手机相同的壳体设计、5.7 英寸（720×1440）IPS TFT 显示屏和可拆卸 4500mAh 电池。它保留了 USB-C 端口、音频插孔以及用于禁用摄像头、调制解调器和 GPS 的物理 kill 开关。

为何没有设计升级？这是有意为之；与初代机型的兼容性使代际间的维修和升级更加容易。

采用模块化无线板，v2 手机提供改进的 4G 调制解调器（计划推出可更换的 5G 模块）。但 v2 将支持双 SIM 卡，而 v1 为单 SIM 卡。

Librem 5 v2 售价 1159 美元起

“RISC-V 是未来，Librem 5 v2 是将它带给主流受众的完美产品，”Purism 首席技术官 Jonathon Hall 在发布时表示。

“将我们从大科技公司的控制中解放出来始于基础，而 RISC-V 的基础使我们摆脱寡头控制。Librem 5 v2 让你掌控自己的数据，并将其与我们在现代时代所期望的易用性相结合”。

鉴于对初代 Librem 5 的普遍反馈——饱受延迟、涨价和做工参差不齐的困扰——充其量是褒贬不一。但值得称赞的是，Purism 仍在制造、销售和支持这些手机（以及他们的其他设备和服务）。

不过，后续机型向 RISC-V 过渡并非易事。图形加速、新驱动和电源管理（在手机上相当关键）将是艰巨的任务。

还需要更多工作来使日常软件栈可编辑，比如浏览器性能（在最新最快的 RISC-V 芯片上仍然迟缓）以及提供 Arm 应用兼容层来运行非 RISC-V 原生软件。

众筹持续至 2027 年 2 月
