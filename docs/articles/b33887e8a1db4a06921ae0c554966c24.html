Linux 7.3-rc1 发布：支持 AMD Zen 6、提升 Btrfs 性能及 2026 款 Steam 手柄

2026年8月30日，美国东部时间下午5:51。

为期两周的合并窗口已经结束，Linux 7.3-rc1 内核现已可供测试。

Linux 7.3-rc1 的发布伴随着大量新代码的落地，包括新的/改进的硬件支持、文件系统增强、安全改进以及更多内容。当然，由于 AI/LLM 驱动的活动，Linux 内核的不同部分也进行了大量修复。

Linux 7.3 为 Intel 混合 CPU 带来了新的优化，对即将推出的 AMD Zen 6 平台提供了更多支持，提升了 Btrfs 性能，为 NVK Vulkan Video 提供了 Nouveau 支持，为 2026 款 Valve Steam 手柄提供了内核驱动支持，初步支持 M3 Ultra / Pro / Max，启用了新的 AMD 图形 IP，Intel Starfire 的初步启用，Nova Lake 的 Intel Xe3P 图形现已默认启用，FailFS 已上游化，USB4STREAM 增加了低延迟模式，以及许多其他新功能。Linux 7.3 还包含了 Valve 带来的游戏改进，以增强在显存非常有限的系统上的体验。此外，由于 AI/LLM 代理的持续噪音，一些旧/过时的硬件驱动继续被移除。

现在，让我们继续在 Phoronix 上进行更多 Linux 7.3 内核测试和性能基准测试。我将在未来几天内发布更详尽的 Linux 7.3 内核功能概述。

Linus Torvalds 尚未在 LKML 上发布他的发布评论，但预计很快会发布。Linux 7.3-rc1 可通过 Git 获取。

Linus Torvalds 现在发布了标记 Linux 7.3-rc1 的惯常消息。他说：

“两周过去了，现在是周日下午，合并窗口已经关闭。

没有什么特别突出的——除了它很大。这不是我们有过的最大的 rc1，但肯定名列前茅，至少在提交数量上是这样。

而且我认为这不再让任何人感到惊讶。这是我们一段时间以来一直看到的相同模式。

它作为一个实际的差异也很大，而*这*的原因也不令人惊讶：这又是一个带有大量 AMD GPU 寄存器转储的版本。这次是 AMD DCN6 寄存器头文件。它们非常庞大。一如既往。这就是当你将所有硬件定义转储为 C 头文件 #define 时所得到的。还有伴随新代的代码。总而言之，AMD GPU 代码和头文件转储约占整个 rc1 补丁的三分之一。

但如果你只是屏蔽掉那一大块，事情看起来相当正常，这个合并窗口尽管很大，但感觉与大多数合并窗口没有太大不同。我因为自己是个一流的傻瓜，在中间进行了系统升级，然后不得不追查由此引起的问题，这让我自己变得不必要地困难，但那完全是我自己的错。我知道我不应该这样做，但我只是天真地想‘不会出问题的’。嘿，最终一切都很好，我只是让这个合并窗口比本应更困难。

让我们希望这个版本的其余部分会顺利进行。并且要小且平淡。但我在骗谁呢？它几乎肯定不会小，但我总是可以希望。”
