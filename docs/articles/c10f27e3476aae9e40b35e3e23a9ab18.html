Firefox 158 发布，支持 JPEG XL

Firefox 158 现已开放下载，原生支持 JPEG XL 图像格式，该格式压缩率优于 WebP、PNG 和 JPEG，并支持广色域、HDR、高比特深度、动画、Alpha 通道及无损与渐进式编码。此外，AI 浏览模式可自动填充表单，本地翻译新增三种语言，滚动更平滑，PDF 生成更易访问，并包含多项开发者功能与安全修复。

Firefox 158 现已开放下载，开箱即支持 JPEG XL 图像。

据称，JPEG XL 的压缩效果优于其他图像格式，包括 WebP、PNG 和普通的 JPEG。它支持更广的色域、HDR 和高比特深度，以及动画、Alpha 通道和无损与渐进式编码。

Mozilla 花了数月时间在 Firefox 中测试 JPEG XL 支持，此前通过浏览器的一个可选开关让用户试用。

其他变化与修复

AI 驱动的浏览模式（使用 OpenAI 和阿里巴巴等云服务提供商）现在可以为你填写表单字段，从你打开的其他标签页或已保存的自动填充数据中提取相关信息。

说到 Firefox 与 AI，浏览器的本地、私密翻译功能新增了对阿尔巴尼亚语、白俄罗斯语和菲律宾语的网页文本互译支持。

Mozilla 表示，通过打印对话框从网页创建 PDF 会生成“更易访问”的文档，并补充说包括缺失数学符号在内的多个 PDF 渲染问题已得到解决。

有人问我为什么这么“推销”Firefox，因为它不是 Ubuntu 制造的，而且存在“更好的浏览器”。Firefox 是 Ubuntu 的默认浏览器；本博客关注的是在 Ubuntu 上运行、可用于 Ubuntu 或对 Ubuntu 有用的东西——而不仅仅是专为 Ubuntu 制造的东西。

据称，Firefox 158 中滚动网页“更平滑、更精确”，因为浏览器不再将滚动位置四舍五入到整个屏幕像素。在放大页面上或高分辨率显示器上滚动时，这一改进感受最为明显。

自定义标签页背景现在会被存储，你之前使用的自定义壁纸现在会列在页面上。

一组新的安全修复

你可以从 10 月 12 日星期一起通过下载 Firefox 158。那里有适用于所有主流操作系统的二进制构建和安装程序，与官方网站将链接到的版本相同。

Windows、macOS 和 Linux（二进制构建）上的现有用户将能够从 10 月 13 日星期二起在应用内更新。Linux 发行版仓库、软件商店（Flathub、Snap）和其他格式将在此日期之后开始打包。

如果你使用的是 Ubuntu，无需急于下载任何东西。与所有其他更新一样，此更新将通过 Snap Store 的自动更新送达你。
