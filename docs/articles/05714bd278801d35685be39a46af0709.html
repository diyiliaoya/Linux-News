Linux 7.3 很可能成为下一个 LTS 内核

Linux 内核关键维护者 Greg Kroah-Hartman 在 Linux 内核邮件列表中表示，计划将 Linux 7.3 作为下一个长期支持（LTS）内核，除非出现意外阻碍。他反对为了成为 LTS 而强行向 7.4 添加功能，并指出过去这样做曾给维护者带来很多麻烦。LTS 内核提供至少两年的维护和重要修复回移。Linux 7.3 已随 Ubuntu 26.10 发布，并将于今年晚些时候回移到 26.04。

Linux 7.3 很可能成为下一个 LTS 内核 - OMG! Ubuntu

看起来它将成为新的长期支持（LTS）内核。

内核关键维护者之一 Greg Kroah-Hartman 在 11 月初于 Linux 内核邮件列表的一封回复中暗示了这一点，当时他正在讨论 Linux 7.4 的状态及其可能的发布时间。

在回复 Linus Torvalds 时——Torvalds 指出人们期待 Linux 7.4 被指定为 LTS（因为它正发展成一个大版本，而长期内核的选择部分基于其功能丰富程度）——Kroah-Hartman 表示他计划让 7.3 成为 LTS。

“如果人们只是为了让它成为 LTS 而试图把功能强行塞进 7.4，那恰恰是不应让它成为 LTS 的最佳理由”，他说，并指出过去发生这种情况时曾给维护者带来“很多麻烦”。

相反，他表示，开发者应该“指望 7.3.y 成为下一个 LTS”，除非出现意外阻碍计划。

这虽不是正式盖章的决定，但已足够明确，足以形成这样的印象。

LTS 内核获得更长时间的修复

Linux LTS 内核的维护时间比标准稳定版长得多（至少 2 年），并获得重要缺陷和安全修复的回移。

由于 Linux 被广泛应用于企业、工业和云环境，许多人选择长期版本以确保可靠性。如果更广泛的社区有需求（并提供帮助），LTS 内核的支持窗口可以延长至最初的 2 年之后。

内核发布表尚未将 v7.3 列入 LTS 表，但由于自 Kroah-Hartman 发消息以来还没有发布点版本，这大概就是原因。

Linux 7.3 已随 Ubuntu 26.10 发布，并将于今年晚些时候回移到 26.04。其变化包括改善低显存 AMD GPU 上的游戏体验、更快的 ext4 I/O，以及重新设计内核在应用组之间分配 CPU 时间的方式。

Linux 7.4(.0) 暂定于 2026 年 12 月 27 日发布。
