Mesa Vulkan 驱动将迎来类似 Gallium3D 的 "Shiva" 框架

Collabora 的 Faith Ekstrand 在 XDC 2026 上提出为 Mesa Vulkan 驱动开发名为 Shiva 的新框架，其定位类似 Gallium3D 之于 OpenGL。随着 Vulkan API 日益复杂且碎片化加剧，Shiva 将作为 Vulkan API 的抽象层，让驱动面向 Shiva API 而非直接面向 Vulkan。计划先适配 Nouveau 和 Arm Mali Panfrost 驱动，预计约两年后可能惠及用户。

"Shiva" 正在为 Mesa Vulkan 驱动开发，类似 Gallium3D

2026 年 9 月 28 日晚上 08:32 EDT。

Shiva 正进入 Mesa Vulkan 驱动的开发阶段，作为一个类似 Gallium3D 的新框架，但面向 Vulkan 驱动而非 OpenGL。这项工作还需要一段时间才能见到成果，但有望在未来带来更多的代码共享以及更好的 Mesa Vulkan 驱动开发体验。

来自 Collabora 的 Faith Ekstrand 今天在多伦多举行的 XDC 2026 上介绍了为 Vulkan 驱动引入 Gallium3D 式框架的想法。随着 Vulkan API 的不断增长，Ekstrand 承认现状已不再那么理想。Mesa Vulkan 驱动之间的碎片化日益加剧，各种转换/辅助工具层出不穷，开发 Vulkan 硬件驱动的复杂性也在不断增加。

Shiva 被提议作为 Mesa 内部一个待开发的框架/基础设施，以类似于 Gallium3D 为 OpenGL 驱动所做的出色工作的方式服务于 Vulkan 驱动。Shiva 将作为 Vulkan API 的抽象层，Ekstrand 指出：“Vulkan 在 2016 年实现起来既有趣又简单……而 2026 年的 Vulkan 充满了向后兼容的累赘。”更糟糕的是，Ekstrand 预测随着 Vulkan 的演进，其实现难度只会越来越大。

Mesa Vulkan 驱动将面向 Shiva API 而非直接面向 Vulkan API，以处理各种抽象。它也具有前瞻性，面向 Rust 驱动等更多方向。

计划是在不久的将来开始开发 Shiva，最初将着手适配 Nouveau 和 Arm Mali Panfrost 驱动。不过估计大约需要两年时间，才可能为用户带来实际成果。
