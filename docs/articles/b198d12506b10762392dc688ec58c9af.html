GNU Binutils 2.47 发布，新增更多 RISC-V 扩展与新选项

2026年7月26日下午3:36（美国东部时间）

继本周末发布的 GNU C 库 2.44 之后，GNU Binutils 2.47 版本现已可用。这是一套重要的二进制工具集，广泛应用于 Linux 系统及其他使用 GNU 工具链的平台。

GNU Binutils 2.47 引入了一个新的汇编器命令行选项 --reloc-section-sym=[all|internal|none]，用于控制是否将引用局部绑定符号的重定位调整为使用节符号。Objdump 和 readelf 现在新增了 --debug-info-dir 选项，用于指定查找独立调试信息文件的路径。Objdump 还新增了 --show-global-vars 选项，用于显示目标文件中全局变量的位置和类型。此外，链接器新增了对存档中所有格式下无符号索引的 --no-symbol-index 选项的支持。

BFD 链接器还新增了零级优化选项。当使用 BFD 并指定 "-O 0" 时，它将停止合并可合并节的内容。这可以显著加快链接过程，但代价是生成更大的二进制文件。Binutils 2.47 还弃用了对 32 位 s390 目标的支持，而 64 位 s390x 目标仍将继续维护。

GNU Binutils 2.47 新增了对以下较新 RISC-V 标准扩展的支持：zalasr v1.0、svrsw60t59b v1.0、zvabd v1.0、smpmpmt v1.0、zvqwdota8i、zvqwdota16i、zvfwdota16bf 和 zvfqwdota8f v1.0、zvqwbdota8i、zvqwbdota16i、zvfwbdota16bf、zvfqwbdota8f 和 zvfbdota32f v1.0，以及 SpacemiT 的 xsmtvdot v1.0、xsmtvdotii v1.0。
