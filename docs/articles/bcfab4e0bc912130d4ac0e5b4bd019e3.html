操作系统发布：OpenIndiana 2026.10

OpenIndiana 项目发布了 2026.10 快照版，提供 Live、文本和最小安装镜像。该版本新增 UEFI 帧缓冲支持，启用 illumosfb X.Org 驱动，更新 Firefox 和 Thunderbird 至 159.0，升级 Python、Perl、Rust、Clang、GCC 等开发工具，更新 QEMU 和 VirtualBox，并加入 TeX Live 2026、Foliate 电子书阅读器和 zoxide 等新应用。

OpenIndiana 项目发布了其开源操作系统的新版本，该系统由 OpenSolaris 家族演变而来。新版本 2026.10 更新了开发者工具、虚拟机实用程序和网页浏览器：

“OpenIndiana Hipster 2026.10 快照已可用，请访问下载页面获取日期为 2026 年 10 月 30 日的 Live、文本和最小安装镜像。现有安装可继续通过 IPS 更新。值得注意的变化：Live 镜像支持 UEFI 帧缓冲；illumosfb X.Org 驱动现已启用，安装在 X 服务器的模块路径中并包含在 Live 镜像内，在 illumos 帧缓冲控制台上自动配置；浏览器和邮件客户端更新，Firefox 和 Thunderbird 达到 159.0 版本；开发工具——新增 Python 3.15.2 和 Perl 5.44.0，以及 Rust 1.99.0、Clang 23.1.4 和 GCC 15.3.0；解释器新增内容与下方众多模块更新分开列出；虚拟化更新——QEMU 达到 11.1.2，VirtualBox 7.2.22；QEMU 客户机代理拆分为独立软件包；新应用程序——TeX Live 2026 和 Foliate 3.2.1 电子书阅读器加入集合，还有 zoxide shell 导航工具；其他变化包括 OpenSSH 10.6p1、OpenSSL 3.5.9、MariaDB 12.3.3，以及包括 OpenJDK 11/17、ripgrep 和 Claws Mail 在内的应用程序获得更多 SPARC 构建支持。”
