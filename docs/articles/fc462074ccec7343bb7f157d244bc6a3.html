Ubuntu 26.10 的第三个（也可能是最后一个）月度快照现已可供下载。

“Stonking Stingray”在 8 月或 7 月没有发布月度快照——没有给出原因——而 Ubuntu 26.10 测试版计划于 9 月 24 日发布。

因此，这可能是最后一个快照，尽管 Canonical 的 Utkarsh Gupta 表示，可能会有一个“惊喜快照”来“测试我们机制的一些更改”。

Ubuntu 的月度快照严格用于测试。它们不是 alpha 版本，也不适合生产环境。团队表示应将其视为“一次性产物”。自推出以来，它们的作用是帮助 Canonical 测试和迭代新的构建系统。

而且，它们还充当了一系列非官方的软性截止日期，促使发行版工程师将希望更多人测试的功能落地。

对我们大多数人来说，使用最新的每日构建版来测试 Ubuntu 26.10 比使用月度快照更好，原因很简单：快照只是快照，它们会更快过时。

自 6 月快照以来，已有大量软件包更新落地，包括即将推出的 GNOME 51 的关键组件，以及默认应用的新版本，例如（获得了视觉签名）和（显示软件、镜头和其他元数据）。

该快照由 8 月发布的 [内核] 提供支持。

你不会在这里找到 Ubuntu 新的 AI 语音转文字功能 Myna。我上周分享了 Ubuntu 语音转文字技术的视频演示，但它并未包含在此快照或每日构建中。

但除非你是开发者或经验丰富的漏洞猎手，否则现在还没有必要尝试——毕竟官方 Ubuntu 26.10 测试版几周后就要发布了。

Ubuntu 26.10 快照 3 可从官方 cdimage 服务器下载，该服务器还提供 Ubuntu 26.10 各风味版本、衍生版本和硬件变体的新快照，包括 Raspberry Pi 和 Arm64。
