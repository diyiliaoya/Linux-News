Wordbook：GNOME 的现代离线词典

Wordbook 是一款专为 GNOME 桌面设计的现代离线词典应用，基于 WordNet 词汇数据库和 eSpeak 发音引擎，采用 GTK4/libadwaita 界面，完全离线运行。它提供同义词集分组、随机单词、收藏、历史记录和自动补全功能，特别适合英语学习者。文章还讨论了离线词典的实用性，并建议 GNOME Shell 的概览搜索未来能集成单词定义查询功能。

他们常说不要以封面评判一本书，如果这本书是词典，很少有人会这么做，但桌面词典应用又如何呢？

我最近遇到了 Wordbook，一款由 WordNet 和 eSpeak 发音支持的现代英英词典。Wordbook 属于 GNOME Circle，其 GTK4/libadwaita 界面非常适合桌面环境。

Wordbook：一本用于理解单词而非仅仅列出单词的词典

Wordbook 使用词汇数据库，将单词按含义分组为“同义词集”。这使得探索相关单词、区分形近但义异的单词以及寻找精确的替代词变得更加容易。

它还包含随机单词选项、收藏夹和历史记录，以及自动补全功能。这些对英语学习者都很有用。

更好的是，它完全离线运行。

它提供了一种更传统的词典查询工具，但通常需要互联网连接，而且界面相当过时。如果你只需要“这个词是什么意思？”，它就能满足需求——在我看来，它做得更好。

总的来说，使用网页浏览器查找单词定义更快。同义词也是如此；向搜索引擎询问一个替代词，它会给出更精确的结果——而且随着大语言模型的加入，甚至可能找到一个完全符合你想表达意思的术语。

我希望能有一个像 GNOME Shell 那样的 Linux 工具。即便如此，一款包含发音的离线词典仍有其用途，例如在互联网不可靠时、需要无干扰工作时，或者那些不想把每次查询都交给大型科技公司的人。

Wordbook 的功能听起来也对那些正在掌握英语（及其众多怪癖）的非母语者特别有益。

macOS 和 iOS 有一个简洁的“查找”功能。你可以在任何可选文本上高亮一个单词，右键点击并选择“查找”。匹配的定义会出现在你所在的位置，而不会把你跳转到网页或应用（尽管也有这个选项）。我非常喜欢这种方法。

在写这篇文章时，我惊讶地发现，即使安装了 Wordbook，你也无法在 GNOME Shell 的概览中查找单词的含义。它可以进行计算、显示其他国家的时间，并显示表情符号供复制到剪贴板。

但定义单词？不行。

也许 Wordbook 可以通过添加定义查找来扩展它？

GNOME 51 中的浮动搜索结果只是该功能更大雄心的一部分。一个能回答“这是什么意思？”的桌面搜索工具将是非常有用的定义。

如果大语言模型被信任的话。
