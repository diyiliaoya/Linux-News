GNOME Shell 搜索重新设计采用浮动覆盖层

GNOME Shell 的下一个版本（GNOME 51）预计将于9月发布，其搜索体验将迎来重大改进。目前，从概览启动搜索会切换到独立的搜索结果屏幕，而新设计将搜索结果以浮动覆盖层的形式从搜索框展开，覆盖在工作区或应用网格上方，避免切换视图。该设计已通过合并请求实现，并获得了开发者与设计师的积极反馈，但因讨论延迟，可能仍有望赶上GNOME 51的发布。此外，GNOME Shell 还有其他设计改进计划，如直接编辑、简化日历、马赛克窗口管理等。

GNOME 51 可能会为 Shell 带来浮动搜索覆盖层

GNOME Shell 的下一个版本将于9月发布，它“很可能”包含重新设计的搜索体验。

目前，当你在 GNOME Shell 概览中开始搜索时，一个专用的搜索结果屏幕会替换你正在查看的界面，即工作区行和停靠栏（即 dock）。

GNOME 的设计基于“语义”模型，元素会从特定位置可见地进入和退出，以便用户了解一个屏幕与下一个屏幕的关系。

对于搜索，结果将出现在一个“从搜索框弹出”的覆盖层中，浮动在工作区概览或应用网格上方。这个想法已在 GNOME 设计模型中探索过（见下面的动画演示）。

一个开放的合并请求已提交，旨在将理想化的“shell 搜索”体验变为现实。

动画：Jakub Steiner

根据上面的动画模型，该合并请求将 GNOME Shell 的搜索体验重新设计为浮动覆盖层，该覆盖层明确源自搜索字段，但覆盖在概览（工作区）或应用网格上方，而不是像现在这样“切换到单独的视图”。

该代码引发了 GNOME 贡献者和设计师的大量讨论，他们一直在帮助测试，并提供反馈和代码来完善它，以便其能够落地。

Cassidy James Blaede（曾任职于 System76）也参与了讨论，称其“看起来很棒”。长期担任 GNOME 设计团队成员的 Sam Hewitt 将覆盖层搜索描述为“期待已久”。

但讨论似乎推迟了合并请求的接受，使其未能赶上 GNOME 的开发截止日期。一个冻结请求已开启，如果得到关键人物的热情支持，它仍有可能在9月的 GNOME 51 发布中准备就绪。

在一篇题为“GNOME Shell 设计梦想”的博客文章中，讨论了这一设计变更及其他设计变更，GNOME 设计师 Tobias Bernard 显得充满希望，提到它“很可能”会在 GNOME 51 中发布。

如果确实如此，它将进入 Ubuntu 26.10。

GNOME Shell 可能会看到更多设计变更

Bernard 建议支持“更丰富的内容和操作类型”，类似于其他桌面启动器和工具（如 macOS 上的 Spotlight）。搜索已经可扩展——Ubuntu 26.04 添加了 Snap Store 应用匹配和网络搜索快捷方式——因此存在扩展空间。

GNOME Shell“愿望清单”上的其他设计变更包括可直接编辑的快捷方式、更简单的日历小程序、“马赛克”风格的窗口管理、透明顶栏、动态电池图标以及不那么单调的登录屏幕。

如果你有技能（不是设计技能）来实现更多这些想法，Bernard 的帖子提到，现在比以往任何时候都更容易在 GNOME Shell 上进行开发。要参与并提供帮助，请加入 Matrix 上的 #gnome-design 房间。
