Linux 7.4 为 IO_uring 的 I/O 路径引入 DMA-BUF 支持

2026 年 10 月 27 日 下午 05:09 EDT 发布。

今日为正在进行的 Linux 7.4 合并窗口合并了相关基础设施，以在内核的 I/O 路径中启用对出色 IO_uring 的支持。

这个概念已经讨论了一段时间，之前也有类似目标的补丁，而现在它终于在 Linux 7.4 主线中实现，通过 IO_uring 启用 DMA-BUF 读写支持。Linux 的 DMA-BUF 框架允许不同的设备驱动和子系统共享硬件内存缓冲区，而无需 CPU 进行拷贝。DMA-BUF 在 GPU 驱动中尤其流行，并且在媒体和网络驱动中也有工作，用于高效的零拷贝缓冲区共享。

主导这项工作并经历了十一轮补丁审查的 Pavel Begunkov 解释了这项新功能：

“这是文件的一项选择性启用功能，它们需要实现一个新的文件操作才能使用它。本系列仅支持 NVMe 块设备。用户 API 构建在 io_uring 的‘注册缓冲区’之上，其中 dmabuf 以特殊方式注册，但之后可以像任何其他‘注册缓冲区’一样与 IORING_OP_{READ,WRITE}_FIXED 请求一起使用。它通过一个新的文件操作创建，生成的结果映射随后以一种新的迭代器类型通过 I/O 栈传递。还有一些额外的基础设施将其粘合在一起，计数请求、管理生命周期并实现失效处理。”
