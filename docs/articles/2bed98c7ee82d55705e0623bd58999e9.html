Linux 7.4 将引入 Apple M4 和 MacBook Neo 所用 A18 Pro 的初始设备树

Asahi Linux 开发者 Sven Peter 提交了面向 Linux 7.4 合并窗口的 Apple SoC 设备树更改，最引人注目的是为搭载基础版 M4 SoC 的 Apple 设备以及采用 A18 Pro SoC 的 MacBook Neo 引入初始设备树。这些设备树仅包含 M3 与 M4 之间基本未变的硬件模块，如 CPU 核心、中断控制器、电源状态、看门狗、串口、引脚控制器、i2c 和帧缓冲，尚不足以提供完整的 Linux 使用体验，GPU 等其余功能将在后续内核版本中启用。

Asahi Linux 开发者 Sven Peter 今天发出了他们准备为本月晚些时候的 Linux 7.4 合并窗口向上游提交的 Apple SoC 设备树更改的拉取请求。最引人注目的是为使用基础版 M4 SoC 的 Apple 系统以及搭载 A18 Pro SoC 的 MacBook Neo 提供的初始设备树。

使用基础版 M4 SoC 的 Apple Mac 以及搭载 A18 Pro 的 MacBook Neo 的初始设备树将在 Linux 7.4 中首次亮相。但正如近期内核中 Apple M3 初始设备树所显示的那样，这并不意味着想要在这些较新 Mac 上运行主线内核的 Linux 用户就能获得可用的体验。它足以开始引导 Linux 内核，但在 GPU 和其他仍有待启用的功能方面，仅此而已。

M4 设备树包含“最少量的硬件”，其中所包含的是 M3 与 M4 两代之间基本未变的硬件模块。已启用的设备包括 CPU 核心、中断控制器、电源状态、看门狗、串口、引脚控制器、i2c 和帧缓冲。其余所有功能将留待 7.4 之后的未来 Linux 内核版本。

M4 设备树适用于 MacBook Pro（14 英寸，M4，2024）、iMac（24 英寸，2x USB-C，M4，2024）、iMac（24 英寸，4x USB-C，M4，2024）、MacBook Air（13 英寸，M4，2025）、MacBook Air（15 英寸，M4，2025）和 Mac Mini（M4，2024）。

对于 MacBook Neo，它与 Apple M4 系列设备相当相似，但使用的是 A 系列 SoC。与 M4 支持一样，它在 Linux 7.4 中的支持将非常有限，只是为了鼓励未来的开发。这一初始启用包括 CPU 核心、中断控制器、看门狗、串口和帧缓冲。

这些初始设备树已在 Linux 7.4 合并窗口之前发布。Sven Peter 还为 Linux 7.4 发出了带有共享 GPIO 支持以及面向较旧 32 位协处理器的 RTKit 崩溃日志支持的补丁。
