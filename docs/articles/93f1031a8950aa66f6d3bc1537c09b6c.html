Linux Mint 预告内核清理技巧，Fedora 多年前已实现

Linux Mint 在七月更新中预告了一项新功能，旨在自动清理旧内核。该功能将内核管理从更新管理器移至系统管理工具，允许用户按系列分组管理内核，并设置保留数量，每周自动清理。Fedora 早已通过 DNF 包管理器默认实现类似功能，仅保留最近三个内核。Mint 的新方案提供更多手动控制，但尚未正式发布。此外，Mint 22.3 将默认使用 Wayland，Cinnamon 桌面将同时支持 X11 和 Wayland。

Linux Mint 预告内核清理技巧，Fedora 多年前已实现

这项正在开发中的功能将每周自动清除旧的和未使用的内核。

Linux Mint 项目定期发布月度新闻，让我们了解开发人员正在做什么以及整个项目的方向。

他们的七月更新向我们展示了该发行版未来打算如何处理内核，将整个工作从更新管理器中移出，并转移到完全不同的工具中。

来源：Linux Mint 博客

是，也不是。内核管理并不新鲜，过去更新管理器允许用户查看和删除单个内核，但该功能已被移除。

新的实现位于“系统管理”工具中，并且无论你使用的是 Linux Mint 还是 LMDE，它的行为方式都是一样的。

不再逐个跟踪单个版本，系统管理中的新“内核”页面将多个内核版本按系列分组。

设置该工具是一次性选择，你告诉它哪些内核系列对你重要，以及每个系列要保留多深的回退数量。

之后所有下游操作都会自动运行。你关注的系列会像往常一样通过更新管理器持续更新，而超出你设定限制的任何内容都会在每周的定时清理中被删除。

手动清理也是可能的，适用于你想快速释放一些空间以容纳其他内容的时候。单个内核也可以标记为“保留”，这样无论其系列是否被跟踪或有多旧，都不会被删除。

在你亲自去系统上寻找这个功能之前，要知道它尚未上线。Linux Mint 项目负责人克莱门特·勒菲弗表示，这只是下一个 Mint 版本功能的预览。

Fedora 已经有了这个功能

我理解 Linux Mint 必须重新实现他们的解决方案，但 Fedora 已经解决这个问题多年了。其 DNF 包管理器一直默认这样做。

其背后的设置称为“installonly_limit”。任何时候只保留最近三个内核构建。每当通过常规更新引入新内核时，DNF 会在同一事务中删除超出该限制的任何内容。

与 Mint 的每周清理不同，它背后没有单独的定时任务。它只在您实际更新时运行，因此通过 DNF 正常流程之外安装的内核将保持不变。

这两种方法最终以不同的方式解决了类似的问题。Fedora 的是一种固定的、始终开启的限制，直接与更新事务绑定。而 Mint 的新实现一旦发布，将为您提供更直接的控制。

内核管理并不是 Mint 七月帖子中唯一的内容。该团队还为 Linux Mint 22.3 发布了新的默认壁纸，这次基于 Wayland 支持，在 Cinnamon 中运行，在 Wayland 和 X11 上表现相同。

有关完整详情，包括新的环境变量页面和面板修复，请参阅官方公告。

Linux Mint 现在认为 Wayland 足够稳定，可以在下一个版本中包含，该版本预计在圣诞节发布。
