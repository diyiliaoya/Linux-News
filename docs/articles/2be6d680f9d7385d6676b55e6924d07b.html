SIMDjson 5.0 发布：持续让 JSON 解析更快

SIMDjson 是开源的高性能 JSON 解析器，多年前出人意料地开始利用 AVX-512 指令集来带来巨大的性能提升。SIMDjson 持续进一步优化自身，以实现更快的速度，今天发布的正是 SIMDjson 5.0。

SIMDjson 5.0 将其静态反射支持提升为官方正式支持的特性，更好地处理大整数，以及许多较小的特性——包括性能优化。
