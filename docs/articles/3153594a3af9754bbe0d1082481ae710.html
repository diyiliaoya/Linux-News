Debian 推理门户上线，为 Debian 开发者提供免费 AI/LLM 推理服务

2026 年 9 月 23 日 下午 05:08 EDT。

在 Debian 投票允许负责任地使用生成式 AI 之后，现在出现了一项由 Scaleway 资助的新计划，旨在让 Debian 贡献者更容易利用 AI：Debian 推理门户。

Debian 推理门户已作为一项新服务上线，为 Debian 贡献者提供自助式 AI/LLM 推理访问。DeepSeek V4 Flash 和 GLM-5.2 是初期向 Debian 贡献者提供的模型。Debian 推理门户提供 API 支持，供开发者与其偏好的代码编辑器及其他 AI 工具配合使用。获取 Debian 推理门户 API 密钥需要 Debian 开发者或 Debian 维护者的 Debian Salsa 账户。

Scaleway 为该 Debian 推理门户赞助每月固定额度的积分，并按周为每位用户分配预算。Debian 推理门户可用于打包、缺陷分类、修复、工具、文档及相关任务。
