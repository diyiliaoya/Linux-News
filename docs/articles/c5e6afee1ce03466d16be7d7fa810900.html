Valve 的 Timur Kristóf 在改进 Linux 上老旧 AMD GPU 方面的出色工作

Valve Linux 图形驱动团队的 Timur Kristóf 在过去一年中为 AMDGPU 内核驱动带来了多项改进，显著提升了对十年前 GCN 1.0/1.1 架构老显卡的支持。他将这些显卡从旧版 Radeon 驱动迁移到现代 AMDGPU 驱动，解锁了 RADV Vulkan 驱动、更好性能和软复位等功能，使老显卡在 2026 年及以后仍能胜任 Linux 游戏。他在多伦多 XDC2026 上分享了这一工作。

过去一年中，Valve Linux 图形驱动团队的 Timur Kristóf 为 AMDGPU 内核驱动带来了多项非常出色的改进，增强了对老旧（十年前的 GCN 1.0/1.1 时代）显卡的支持，使它们能更好地应对 Linux 游戏和其他任务。本周在多伦多，Kristóf 介绍了这项 AMDGPU 工作。他最初是在多年专注于用户空间 Mesa 3D 驱动代码之后，将其作为内核驱动开发练习而开始的。

对于拥有老旧 AMD GCN 1.0/1.1 显卡和 APU 的用户来说，Timur Kristóf 已成为一位传奇人物，他将这些设备从旧版 Radeon 驱动迁移到现代 AMDGPU 内核驱动，从而解锁了使用 RADV Vulkan 驱动的能力、更好的性能以及比旧版 Radeon 代码更全面的功能。在此过程中，他必须解决这些老显卡在 AMDGPU 显示代码中的缺陷，以及各种电源管理问题等。随后，他通过软复位支持和其他增强功能进一步改进了这些显卡，使这些老化的显卡在 2026 年及以后更适合 Linux 游戏使用。

要了解将旧 Radeon 显卡迁移到 AMDGPU 的影响，可以看看去年的报道：Linux 6.19 为老旧 AMD Radeon GPU 带来约 30% 的显著性能提升。由于 AMD 多年来未在这些老显卡驱动改进上投入太多资源，Valve Linux 团队的 Timur 真正填补了这一空白，带来了更好的体验。

对于那些希望听他讲述自己在 Linux 上改进 AMD Radeon GCN 1.0/1.1 时代显卡的努力的人，下面嵌入了他 XDC2026 的演讲以及相关链接。演讲还介绍了他在参与 AMDGPU 内核驱动开发方面的经验，以及其他一些细节，适合那些可能想参与开源 AMD Linux 内核驱动开发的人。
