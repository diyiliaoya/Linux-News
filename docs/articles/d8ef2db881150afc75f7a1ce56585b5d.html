Framework Laptop 12 更新至英特尔 Wildcat Lake，十月开始发货

2026年8月18日 下午12:14（美国东部时间）

去年，Framework Computer 推出了这款可升级且兼容 Linux 的 2-in-1 笔记本电脑。Framework Laptop 12 最初搭载英特尔第13代酷睿 "Raptor Lake" 低端处理器，而现在 Framework 正在为 Laptop 12 新增 Core Series 3 "Wildcat Lake" 作为升级选项，或用于新的 Laptop 12 订单。

Framework Computer 今日宣布，Framework Laptop 12 将新增 Core Series 3 "Wildcat Lake" 选项，并配备 Thunderbolt 4、WiFi 7、可选背光键盘等升级。Framework Computer 还将提供预装 Fedora Linux 的版本。

升级版 Framework Laptop 12 的预购今日开启，首批笔记本电脑将于十月发货。

关于升级版 Framework Laptop 12 的更多详情，请参阅官方公告。

搭载 Wildcat Lake 的 Framework Laptop 12 DIY 版起售价为：Core 3 304 型号 549 美元，Core 5 320 型号 779 美元，Core 7 350 型号 999 美元。DIY 版默认不含内存和存储。预装版售价分别为 699 美元、1099 美元和 1399 美元。关于 Linux 支持的详情，在近期内核版本下应该表现良好。就在本周，搭载 Wildcat Lake 的评测样品已经送达，因此未来几天 Phoronix 将开始进行英特尔 WCL 基准测试。
