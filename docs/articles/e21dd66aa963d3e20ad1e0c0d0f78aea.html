ONLYOFFICE 10.0 发布：全面拥抱 AI，打造最现代化的团队协作办公选择

ONLYOFFICE 发布 10.0 版本，在所有编辑器中引入 AI 工具，但开源版本需单独安装。新版本新增主页和四个模块化应用（文档空间、协作空间、表单、AI 代理），支持 MCP 服务器。各编辑器获得 AI 聊天功能，可摘要、改写、翻译、校对文档，生成演示大纲，分析表格数据等。此外还改进了协作、电子表格性能、演示导出和打印设置。

ONLYOFFICE 10.0 发布：全面拥抱 AI，打造最现代化的团队协作办公选择

在最新发布的 ONLYOFFICE 中，不仅有工作流应用，每个编辑器还获得了 AI 工具和各自的新升级。

ONLYOFFICE 正在为其套件中的每个编辑器推出 AI 工具，但开源版本并未内置这些功能。该公司表示，这一选择是对用户反馈的回应，因此这些版本需要单独安装 AI 工具。

如果你还不了解，他们有几个主要产品。ONLYOFFICE Docs 是可自托管或集成到其他平台的编辑器套件，而桌面版将编辑器带到 Linux、Windows 和 macOS，协作空间促进基于房间的协作。此外还有一套适用于 iOS 和 Android 的 Web 应用和移动应用。

随着 ONLYOFFICE Docs 10.0 的发布，他们引入了大量修复，以及模块化应用，应能帮助简化你的工作流程。

🆕 ONLYOFFICE Docs 10.0：有哪些新功能？

ONLYOFFICE Docs 现在有一个主页，其中包含一个应用类别，列出了四个预装的免费应用。每个都是可选的模块化应用，在需要时使用。

文档空间负责存储、组织和共享文件，协作空间用于与他人协作，表单用于构建表单和分析回复，AI 代理可用于部署代理以自动化任务和回答问题。

最后一个支持 MCP 服务器，可用于扩展推理、搜索和个性化知识库用例。

编辑器方面呢？

新增了“移除隐藏信息”选项，可在共享文件前清除元数据，保护选项卡提供签名选项，表格自动识别可用于电子表格。段落高级设置中新增了“保持与下段同页”功能，可防止标题与其内容分离，包括在表格和块内容中。

图形公式等内联对象在从右到左的文档中表现更可靠，基于行的裁剪会修剪超出行高的内容。随 8.1 版本引入的水平线现在也有了自己的设置窗口。

对于协作会话，编辑文件的用户列表中出现了一个新的“跟随”选项。如果点击它，你的鼠标光标将跳转到该用户的光标处；点击“跳转到用户”可跳转到该用户的位置。

电子表格功能加速、可用性调整和公式辅助。大型工作簿应该感觉更快，因为样式和数据现在分开存储，处理的单元格更少。

复制和剪切操作现在会在所选单元格上绘制动态轮廓，便于快速验证，保存并重新打开文件时工作表背景保持不变，键入时会出现函数常量提示。

在演示文稿中，你现在可以将演示文稿导出为 PDF 或视频文件，而演示者视图选项卡可让你访问一系列新视图，包括幻灯片、备注和计时器。

打印设置也更广泛，备注、讲义和大纲都可以从打印菜单中打印。

每个编辑器都有一个专用的 AI 选项卡，可启动 AI 聊天，常用操作作为提示预加载， alongside 你自己保存的提示。

文本文档可以摘要、改写、翻译和校对，并根据请求添加目录、标题和格式。演示文稿可获得大纲、幻灯片标题、演讲者备注和视觉创意。

在 PDF 中，AI 可以一键摘要、回答问题、起草电子邮件和编辑机密细节。在电子表格中，它可以整理杂乱数据、编写和解释公式、发现趋势，并构建预测和数据透视表。

对于更改语气等一次性任务，有诸如 AI 工具这样的工具在编辑时持续运行。虽然这些仅在企业版中提供，但你需要充值钱包才能访问 ONLYOFFICE AI 服务，该服务为你处理模型配置和部署。

对于自托管，你将能够使用任何流行的基于云的 AI 服务，或通过 Ollama 等工具使用本地服务。
