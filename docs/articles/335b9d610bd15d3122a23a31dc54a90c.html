Ubuntu 26.10 各风味版有哪些新变化？

Ubuntu 26.10 各社区风味版随主版本一同发布，包括 Kubuntu、Xubuntu 以及回归的 Ubuntu MATE。所有官方风味版共享 Linux 7.3 内核、Mesa 26.2 图形驱动和 Snap 商店支持。Xubuntu 升级至 Xfce 4.20，Kubuntu 搭载新版 KDE Plasma，Ubuntu MATE 在新维护团队下首次发布，Ubuntu Unity 继续维护并推进向 Lomiri 过渡。

与主版本一同发布的，还有各社区风味版的新版本，包括 Kubuntu、Xubuntu，以及令人欣喜地回归的 Ubuntu MATE。

所有 Ubuntu 官方风味版都与主版本共享相同的基础，包括 Linux 7.3 内核、Mesa 26.2 图形驱动、更新后的工具链，以及从 Snap 商店安装 snap 包的支持。

Ubuntu 26.10 风味版回顾

Xubuntu 26.10 搭载 Xfce 4.20，该版本包含错误修复以提升稳定性，并初步支持 Wayland（团队打趣说“适合那些足够爱冒险的人使用”）。

图像查看器新增了随机播放图片的选项，改进了打印功能，并可从网页链接打开图片。

降低了 CPU 占用，并新增了关闭 URL 高亮的选项。

自带的截图工具现在可以在 Wayland 下进行区域和全屏截图，并移除了 Imgur 上传选项。
