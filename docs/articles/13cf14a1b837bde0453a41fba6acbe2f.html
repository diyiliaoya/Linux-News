发行版发布：Omarchy 4.5.0

Omarchy 4.5.0 发布，这是基于 Arch 的 Linux 发行版，搭载定制的 Hyprland 平铺合成器。此版本是 Quattro 之后首个重大功能更新，合并了超过 740 个拉取请求，来自 180 多位贡献者。新增传统桌面模式、支持 M1/M2/M3/Neo MacBook 原生安装、支持 50 种语言。Super + L 可在平铺、滚动和浮动布局间切换工作区，浮动工作区提供标题栏和 dock。

发行版发布：Omarchy 4.5.0（DistroWatch.com 新闻）

David Heinemeier Hansson 宣布发布 4.5.0，这是该项目基于 Arch 的 Linux 发行版的更新版本，搭载定制的 Hyprland 平铺合成器。这是该发行版首个可安装在苹果 Silicon 系列处理器上的版本。

“Omarchy 4.5 是自 Quattro 以来的首个重大功能版本，而且是个大家伙——短短十二周内合并了来自 180 多位贡献者的超过 740 个拉取请求。它现在在默认平铺之外还提供传统桌面模式。你可以原生安装在 M1/M2/M3/Neo MacBook 上。它支持 50 种语言。还有无数其他功能、修复和改进。已经在用 Omarchy？运行 Update, Omarchy。新机器？在这里获取。Super + L 现在可在平铺、滚动和浮动之间循环切换任何工作区。在浮动工作区上，每个窗口都会获得主题颜色的标题栏，dock 显示你固定的应用、所有正在运行的应用以及所有已安装应用的网格。拖动可重新排序或固定，右键点击可获取更多选项，Super + M 可将窗口最小化到 dock。对于从 macOS 或 Windows 转来、尚未准备好完全投入平铺的用户来说，这是一个绝佳的入门方式。或者对于任何只是想要一个窗口可以随意铺开的工作区的人来说也是如此。按工作区混合搭配，状态栏会显示每个工作区使用的布局。”
