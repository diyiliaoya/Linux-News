Rune 走向开源，寻求与贡献者分享收入

基于 Go 的 IDE Rune 现已根据 GPLv3 许可证开源，贡献者保留其作品的版权。项目方还推出可选的积分计划，将部分服务收入分配给贡献者，并公开账本记录。Rune 支持 Linux 和 macOS，未来计划扩展对 Rust、Zig 等语言的支持。

Rune 走向开源，寻求与贡献者分享收入

Rune 走向开源，寻求与贡献者分享收入

这款基于 Go 的 IDE 现已在 GPLv3 下提供，贡献者保留其作品的版权。

它从专有软件转变为新的开源身份，采用 GPLv3 许可证，让你可以从代码仓库克隆、阅读或基于它构建。这次重新许可通过一系列操作完成，其中之一是标记了项目许可证过渡的提交。

开发者还决定基本保持提交历史完整，尽管这里那里有一些缺口。我指出这一点是因为开源的项目通常会先压缩历史，这样旧的秘密和敏感提交就不会进入公共仓库。

提供一些背景：Rune 是一款适用于 Linux 和 macOS 的 IDE，可用于编写和调试代码，在同一窗口中运行终端和 CLI 工具，并让编码代理承担部分任务。

团队通过展示运行结果来为其使用辩护，显示 Go 终端在一组终端工作负载上与同类工具保持同步。请记住，这些不是语言基准测试；它们只展示了该 IDE 已经走了多远。

Rune 团队还希望将语言支持扩展到 Go 和 Python 之外，Rust 和 Zig 已在主分支上进入测试阶段，并公开呼吁开发者管理自己的语言。

虽然 IDE 本身免费使用，但人们可以选择付费计划来访问 P2P Rune 网络、高级支持，以及为企业提供的带有额外功能的定制方案。

走开源路线允许贡献者保留其提交内容的版权，公司（Rune）不保留重新许可其作品的特殊权利。此前，项目要求贡献者签署 CLA；现在不再如此。

Ernest Romero Climent 对开源其他地方发生的事情感到不满，即公司在开源中构建，多年来依赖社区，然后在项目有价值时更改许可证。

他们希望通过一个可选的积分计划向贡献者支付报酬，被接受的工作获得积分，符合条件的服务收入的一部分资金组成资金池，然后根据每位贡献者持有的积分进行分配。

所有授予的积分都将在公共账本中跟踪，显示资金池背后的收入、任何扣除、以及每笔付款如何分配——所有这些都是可选的。你仍然可以在不加入该计划的情况下发送补丁。
