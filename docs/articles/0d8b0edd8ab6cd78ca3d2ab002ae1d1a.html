Firefox 161 带来经典主题选项和更智能的 VPN

Mozilla Firefox 161 现已开放下载，带来一系列小幅功能改进，应能让你的日常浏览更加顺畅。

本次更新对定制爱好者颇为友好。浏览器附加组件页面提供了一组“经典主题”可供安装。Mozilla 表示，其中包括“早期版本 Firefox 的 Proton 主题”、一款 OLED 主题以及纯色主题。

“Proton”主题只是配色方案（柔和的灰色），并非全面回退或重新换肤至旧版外观。本次更新移除了用于禁用它的（隐藏）标志。

你现在还可以为复制当前标签页的 URL 分配键盘快捷键。前往“辅助功能 > 自定义键盘快捷键”进行设置，然后按下该快捷键即可将地址复制到剪贴板，以便粘贴到其他地方。

Firefox 内置的免费 VPN——其带宽限制已放宽至明年年初——现在可以“针对特定站点开启或关闭”。该功能此前已支持站点排除，但这次支持的是……

在隐私方面，如果你从 Chrome 导入浏览历史记录，Firefox 现在会同步每个页面的访问频率，从而能立即在其自身的建议和快捷方式中，将你频繁访问的站点排在更靠前的位置。
