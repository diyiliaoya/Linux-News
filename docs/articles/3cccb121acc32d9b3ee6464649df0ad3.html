Nebula Matrix 网络驱动已排队等待 Linux 7.4

2026年9月21日下午1:23（美国东部时间）。

NBL 是一款新的以太网网络驱动，将在即将到来的 Linux 7.4 内核中首次亮相，用于支持 Nebula Matrix 网卡。

Nebula Matrix 是一家中国公司，为数据中心开发智能网卡（SmartNIC）和数据处理单元（DPU）。从 Linux 7.4 开始，他们的 NBL 驱动应会进入上游，用于支持其 m18110-NIC/m18000-NIC（以 SNIC s1000 系列数据中心产品名义销售）。

Nebula Matrix SmartNIC S1000 系列是一款中国国产 100GE 网络适配器，面向云计算、HPC 及相关领域设计，每卡最高支持 2x100G 接口。S1000 系列采用 PCIe Gen4 x16 接口，具备高端 100G 网络适配器应有的全部典型功能。Nebula Matrix 为该硬件提供 Windows 和 Linux 驱动，而现在将获得主线内核支持，从而带来更好的开箱即用体验，并在进行内核升级时更加便利。
