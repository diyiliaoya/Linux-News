AlmaLinux 将软件认证权交到用户手中

AlmaLinux 首次推出软件认证机制，用户可对自己已有的硬件进行认证，并在公共目录中查看已验证的软硬件。认证免费，硬件检测工具已重写，无需安装发行版即可运行，支持从 Live 介质或现有安装启动，并新增二维码注册流程。所有认证结果统一汇入公共目录，支持搜索和只读 API 批量获取数据。

你现在可以认证自己已有的机器，并查看公共目录中还有哪些经过验证的内容。

首次出现了一种在 AlmaLinux 上进行软件认证的方式，硬件测试套件也同步重写，两条认证路径的测试结果都会汇入同一个公共目录。

不必担心验证的成本或机器本身的正常运行时间。认证是免费的，硬件检查也不再要求你在自己的设备上安装该发行版。

在这种特定情况下，软件认证基本上就是一个列表加上随后的确认。发布者添加产品，并选择它运行在哪些 AlmaLinux 主要版本上。

确认来自那些在各种 AlmaLinux 版本上于自己硬件上运行软件的人，不过如果他们想发布自己的发现，需要注册一个账户。

硬件认证是受到关注的另一半。相关工具已被重写，开发者声称现在可以实现不到 10 分钟的认证运行。

另一项改进是，该工具不再需要安装 AlmaLinux，因为它可以从 Live 介质或机器上已有的安装运行。还有一个利用二维码的新机器注册流程。

如果你还不知道，这个工具会记录机器中的内容，一直深入到驱动程序和固件，然后启动一系列简短检查来决定是否通过。

这些检查覆盖面很广，从计算和内存错误、存储健康、网络驱动，到内核状态、虚拟化、GPU 和外设。

目录着陆页（左）和软件认证页（右）。

所有内容最终都会进入该目录，每个条目都是任何人都可以分析的结果。它保存了已验证的系统、组件和软件，以及已发布测试运行中的基准数据。

每个主要的 AlmaLinux 版本都单独跟踪，因此可以证明来源，目录中的所有内容都可以轻松搜索。你甚至可以利用免费的只读 API 来批量收集数据。

AlmaLinux 的基础设施负责人将注意力转向潜在测试者：

有两件事会让这一切变得值得。许多人和组织在尝试之前，希望证明 AlmaLinux 能在他们已有的硬件上运行，现在他们可以自己获得这种证明。

每提交一个结果，都在向硬件和软件供应商表明，官方支持 AlmaLinux 是一件轻而易举的事。

所以，如果你面前有硬件，或者有你每天依赖的软件，去告诉我们它能用。验证会累积，所以把你的验证添加到已经列出的内容上，和成为第一个一样有帮助。

最终，只有当供应商和个人用户愿意花精力运行测试并手动发布到门户上时，这一切才会奏效。
