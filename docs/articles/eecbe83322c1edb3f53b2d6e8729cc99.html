Firefox 156 降低了查看 JPG 时的 CPU 占用

Firefox 156 发布，内置 PDF 阅读器启动速度提升最高 45%，查看大尺寸 JPEG 图片时内存占用最多减少 20 倍、解码速度提升一倍。地址栏赞助建议在法国、德国和意大利上线。此外修复了富文本编辑器拖拽图片、MP4 中 FLAC 音频播放、画中画字幕、书签拖拽、DoH 下 HTTP 加载及内置 VPN 导致断网等问题，并包含安全补丁。

Firefox 156 发布，其内置 PDF 阅读器启动更快，查看大尺寸 JPEG 图片时 CPU 占用更低。

浏览网页时，你（几乎总是）看到的图片都小于其原始分辨率。也就是说，如果我在这篇文章中嵌入一张 4K JPEG，你看到的并不是完整尺寸：它会被缩小以适应页面。像素数据量相同，但被 CSS 压缩了。

在 Firefox 156 中，浏览器现在使用缩放技术在解码期间缩小图片，而不是先将完整尺寸的图片加载到内存中再缩小。

来自该 bug 报告的基准测试显示，加载超大图片时内存占用最多减少 20 倍，解码速度最多提升一倍。由于这些速度本来就已经很快，用户不会察觉到差异。但在幕后，它更加高效。

Firefox 内置 PDF 阅读器在此版本中启动速度最多提升 45%。浏览器现在会更早加载后台 PDF.js worker，而不是仅在需要时才启动它。

地址栏中的赞助建议已在法国、德国和意大利面向用户上线（等等）。这些建议已在其他一些地区提供。不想要它们？可通过“设置 > 搜索 > Firefox Suggest > 来自赞助商的建议”禁用。

除此之外，本版本其余内容主要是错误修复——一如既往地有价值且受欢迎。

在富文本编辑器中拖动图片时，图片常被替换为文本

MP4 中的 FLAC 音频在部分网站上无法播放

如果在画中画打开后才启用字幕，字幕不会加载

书签作为一组拖动时会被移出所在文件夹

启用 DNS over HTTPS 时，HTTP 网站无法加载

在 v155 中困扰我的一个问题已修复：如果启用内置免费 VPN，浏览器会失去所有网络连接。

一组新的安全补丁

这是 Mozilla 转向每月两次发布节奏以来的第二个版本。Firefox 157 将在两周后发布，如果一切按计划进行，将使 Firefox 新的 Nova 重新设计成为默认界面。

升级到 Firefox 156

Firefox 156 从今天（9 月 14 日星期一）起可从（如果你愿意直接下载）下载，并将于 9 月 15 日作为更新推送。

现有用户？在 Windows 和 macOS 上，或使用 Linux Firefox 二进制版，你可以在应用内更新。否则，请等待更新通过软件源、软件管理器或应用商店推送。

Ubuntu 用户会收到此更新——以及所有其他更新——作为自动后台更新。无需四处寻找，当更新准备好时，通知会提示你重启以安装更新。
