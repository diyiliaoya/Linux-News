GDB 18.1 调试器带来更好的 Windows 支持

GDB 18.1 正式发布，为 Windows 平台带来原生线程本地存储变量支持、Windows 10 及以上版本的非停止模式、调度器锁定等功能，并改进 Windows Terminal 控制台支持和文件名显示一致性。此外还新增 AArch64 MinGW 目标，改进 inferior 参数处理、AArch64 浮点模式寄存器支持，以及新增多个命令和 Python API 改进。

GDB 18.1 调试器带来更好的 Windows 支持

2026 年 9 月 25 日 12:47 EDT。

GDB 18.1 于今日发布，这是 GNU 调试器的最新版本，支持 C/C++、Fortran、Rust 以及 Go、Ada 等多种语言。

Microsoft Windows 在 GDB 18.1 调试器版本中获得了大量关注。Windows 上的 GDB 现在支持原生线程本地存储（TLS）变量，Windows 10 及更高版本支持非停止模式，调度器锁定现在可以正常工作，改进了对 Windows Terminal 控制台的支持，以及其他变更。在用户体验方面，Windows 上的文件名现在统一使用正斜杠显示，而不是正反斜杠混用。GDB 18.1 还新增了 AArch64 MinGW 目标。

GDB 18.1 还改进了 inferior 参数的处理，增加了对 AArch64 上浮点模式寄存器（FPMR）的支持，并新增了 "save history"、"set/show/unset local-environment"、"info proc environ" 等命令。

GDB 的 Python API 以及调试器的 GAP 协议支持也继续得到改进。
