Mesa 26.2 发布，支持 NVK 网格着色器及多项 Vulkan 改进

2026年8月5日下午6:13（美国东部时间）

Mesa 26.2 稳定版现已发布，这是这套通常用于 Linux 系统的开源 OpenGL 和 Vulkan 驱动的最新季度功能版本。

对于这些开源用户空间 3D 驱动来说，这又是一次精彩的功能更新，尤其是在 Vulkan API 方面，大部分活动通常集中于此，但 Zink（OpenGL-on-Vulkan）和 Rusticl（Gallium3D 上的 OpenCL）也取得了良好进展。

Mesa 26.2 为 Intel ANV 和 AMD RADV Vulkan 驱动带来了多项优化，继续推进 Vulkan Video 的工作，KosmicKrisp（Vulkan 到 Apple Metal 的驱动）现在支持 Vulkan 1.4，Rusticl 继续提供更好的 OpenCL 支持，NVIDIA NVK Vulkan 驱动持续成熟，新的 KRAID 编译器已合入 Arm Mali Panfrost/PanVK 驱动，AMD GFX12.1 图形支持的早期工作也已开始，同时合入了多种新的 Vulkan 扩展。甚至旧的 Radeon R600g 和 R300g 驱动在 Mesa 26.2 功能开发期间也获得了多项修复。
