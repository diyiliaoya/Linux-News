RTL8723BS 驱动继续主导 Linux 7.3 的暂存区活动

2026年8月29日晚上8:33（美国东部时间）。

RTL8723BS 驱动于 2017 年为 Linux 4.12 合入内核暂存区。九年过去了，它仍然留在暂存区，并且仍然是清理和代码改进的频繁目标，因为它试图走出暂存区。

本周，Linux 7.3 的暂存区驱动更新已合并，Greg Kroah-Hartman 表示“这里没有任何重大变化”。在暂存区的变动中，RTL8723BS WiFi 驱动再次占据主导地位。RTL8723BS 是一款基于 SDIO 的 802.11 b/g/n WiFi 和蓝牙驱动，曾被各种廉价单板计算机以及早期的 Intel Compute Stick 设备使用。这个驱动一直很混乱，并因其各种抽象和代码意大利面条而被描述为“一团糟”。近十年后，它仍然留在暂存区，并不断进行代码改进，以及针对恶意 WiFi 接入点的加固等。

对于 Linux 7.3 的暂存区改动，这个 Realtek 驱动轻松占据主导地位，大部分改动涉及编码风格、重构以及解决驱动中的其他问题。其中许多改动仍然来自 Linux 内核新人，以积累内核驱动开发经验。

目前，许多改动都相当平凡，比如重命名驼峰式命名变量、删除未使用的代码片段，但近十年后，清理工作仍在继续。

由于没有新的暂存区驱动或其他类似内容，持续的 RTL8723BS 清理工作仍然是 Linux 7.3 暂存区拉取请求的主要焦点（以及暂存区活动的大部分）。
