Ubuntu 26.10 新增对骁龙 X2 笔记本的早期支持

Canonical 发布了基于 Ubuntu 26.10 Beta 的测试版镜像，为搭载高通全新骁龙 X2 芯片的笔记本提供早期支持。该预览版旨在提前发现漏洞并收集用户反馈，预计大部分工作将纳入 10 月 15 日发布的正式版。同时，Ubuntu 对骁龙 X1 设备的支持也有所扩展，并升级至 Linux 7.3 内核。Canonical 表示正与高通合作，计划明年为 X2 设备打造官方认证镜像。

Canonical 发布了一个 Ubuntu 26.10 测试版，为搭载高通全新骁龙 X2 芯片的笔记本提供早期支持。

这个新的预览版 ISO 基于 Ubuntu 26.10 Beta 构建，Canonical 的 Tobias Heider 表示，目的是尽早发现即将发布的版本中的漏洞并收集用户反馈。他预计“大部分”工作成果将体现在 10 月 15 日发布的最终版本中。

能够运行 Ubuntu 26.10 骁龙概念镜像的新款 X2 设备包括联想 Yoga Slim 7（第 11 代）、惠普 EliteBook X G2q 以及华硕 Zenbook A14/A16。

Ubuntu 对骁龙 X1 设备的支持也有所扩展。联想 IdeaPad Slim 3、荣耀 MagicBook Art 14 笔记本以及联想 Ideacentre Mini 01q8x10 迷你主机等设备现已被纳入支持范围。

改进之处众多，因为 Ubuntu 26.10 使用了 Linux 7.3——相比 Ubuntu 26.04 LTS 的 7.0 内核是一大飞跃——并且主线内核对骁龙 X Elite 设备的支持在近几个内核版本中已逐渐成熟。

什么是 Ubuntu 概念镜像？

Ubuntu 概念镜像是 Canonical 定期提供的、针对特定硬件的实验性 Ubuntu ISO，用于测试。它们没有固定的发布计划，不会像其他镜像那样经过同等程度的测试，也不受“官方”支持。

如果你拥有兼容设备并想尝试，可以将其刷入 U 盘并用于启动。只是不要期望体验完美无瑕。部分功能需要使用 qcom-firmware-extract 从 Windows 安装中提取固件。

与其他 Ubuntu 概念镜像一样，你无法从 Canonical 获得正式支持，但可以从其他测试者那里获得大量非官方的帮助和建议。你应该在 Launchpad 上针对该项目提交漏洞报告，并注明你的笔记本型号。

明年，Ubuntu 的骁龙支持预计将更进一步。Canonical 表示正与高通合作，为基于 X2 的设备打造官方认证镜像。
