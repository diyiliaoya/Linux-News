侧边栏中的密码（后）和标签页搜索（前）

搜索已打开的标签页也稍微容易了一些。新增了一个键盘快捷键来激活标签页搜索过滤器。该功能并不新鲜（可以通过“列出所有标签页”按钮触发），但一个容易记住的快捷键有助于发现该功能。

在 Windows 或 Linux 上，按下[快捷键]即可触发标签页搜索。它会聚焦地址栏，你输入一些词语，就会返回设备上已打开或已同步设备上打开的标签页中的匹配项（如果已登录 Mozilla 账户）。

Wayland Linux 标签页的烦恼

在 Linux 上，Firefox 159 解决了几个影响标签页行为的 Wayland 问题。

在某些情况下，点击标签页可能会使其分离成独立窗口（如果你只是想选择或移动它，这并不太有用）。相反，在使用 Wayland 的 Linux 桌面上向上拖动标签页则不会分离标签页。

而使用 AMD GPU 的 Linux 系统用户如果注意到 Firefox 在显示 Mapbox GL JS 地图的网站（如 ChatGPT）上消耗过多内存，会很高兴听到该问题现已解决。
