Ubuntu 现已提供 RISC-V 官方桌面镜像

Canonical 开始为 RISC-V 架构构建官方 riscv64 桌面镜像，随 Ubuntu 26.10 一同推出。目前提供 GNOME 和 Xubuntu 两个实验性 ISO，面向 SpacemiT K3 开发板，尚无官方支持，正式版将于 2026 年 10 月 15 日发布。此举解决了此前 RISC-V 厂商需自行构建恢复镜像的问题，用户可从与 Intel/AMD、Arm64 相同渠道下载。

随着 26.10 版本的推出，在 RISC-V 硬件上安装 Ubuntu 桌面变得更加容易，因为 Canonical 现在正在构建官方的 riscv64 桌面镜像。

即将发布的 Ubuntu 26.10 版本的实验性版本已经可以在 SpacemiT K3 上进行测试——这是 Canonical 与 SpacemiT 合作开发的开发板。其中一个 ISO 搭载标准的 GNOME 桌面，另一个则基于 Xubuntu 最小化版本构建。

Canonical 的 Valentin Haudiquet 表示，这两个 ISO 都是“实验性的”，且“尚未获得官方支持”。它们不会完美运行，确实存在一些问题，将在 2026 年 10 月 15 日发布的“最终”版本中解决。

为什么有两个镜像？

图片：Valentin Haudiquet

符合 RVA23 基准的 RISC-V 硬件仍然相当新。许多想要测试 RISC-V 但缺乏硬件的软件开发者使用 QEMU——在 QEMU 中，GNOME 桌面可能需要长达 30 分钟才能加载，因此需要一个更轻量、更快速的选择。

在真实硬件上，据称 GNOME 镜像能提供“不错的流畅桌面体验”，而随着近期 RISC-V 硬件能力的大幅提升，这无疑是个好消息。

为 Flutter 添加 RISC-V 支持是达成这一目标的部分工作，因为许多 Ubuntu 应用（包括操作系统安装器）都使用 Flutter。一些桌面 snap 尚未准备好支持 RISC-V，包括……

还需要处理设备树，Ubuntu 的构建流水线也需要能够生成新的 riscv64 ISO。

但是，不是已经有搭载 Ubuntu 的 RISC-V 平板电脑在售吗？

这并不是 Ubuntu 第一次拥有 RISC-V 安装器，因为服务器镜像已经存在多年，可以在其上安装 GUI 桌面（早在 Canonical 将 ISA 配置提升至 RVA23、仅支持较新且性能更强的开发板之前）。

但 Canonical 并未提供预装桌面的安装镜像。

那些与 Canonical 合作支持 Ubuntu RISC-V 的公司，其中许多销售预装 Ubuntu 的平板电脑、笔记本电脑和单板计算机，往往不得不自行构建和托管恢复镜像。

这一消息解决了这个问题：面向现代 64 位 RISC-V（RVA23+）硬件的官方镜像，可从与 Intel/AMD 和 Arm64 镜像相同的地方下载。

更喜欢 LTS？Ubuntu 26.04.1 LTS riscv64 桌面 ISO 也已提供，不过尚不支持 K3（Haudiquet 表示很快会支持）。

你可以从 Ubuntu 的每日构建文件夹下载 Ubuntu 26.10 桌面（RISC-V）测试镜像，Xubuntu 26.10（RISC-V）镜像则在 Xubuntu 每日构建文件夹中。
