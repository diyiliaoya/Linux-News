在Ubuntu上运行安卓应用现在出奇地简单

Waydroid是一个开源项目，让Ubuntu用户无需虚拟机即可运行安卓应用和游戏。在Ubuntu 26.04 LTS及更高版本中，只需通过apt命令即可安装。它使用容器化LineageOS，支持应用与Linux应用并排运行并集成系统硬件。安装后需下载约1.1GB镜像，支持Google Play（可选），但仅限Wayland，NVIDIA用户需软件渲染。配置需命令行操作，可调整DPI、启用多窗口等。

在Ubuntu上运行安卓应用现在出奇地简单

Ubuntu本身并不原生运行安卓应用和游戏，但Waydroid是一个开源项目，可以让你使用它们——而且在Ubuntu上设置起来非常简单。

在Ubuntu 26.04 LTS及更高版本上，只需一条简单的命令即可完成。无需添加PPA、寻找第三方软件包或运行来自Reddit帖子的脚本。

如果你有想在桌面上使用的安卓应用或游戏，Waydroid为你提供了实现的方法。

它运行的是容器化的安卓版本（LineageOS），而非虚拟机，这使得安卓应用可以与Linux应用并排运行，并与系统硬件集成。

它并不完美。它仅能在Wayland下工作，NVIDIA用户必须使用软件渲染（详情见下文）。运行效果取决于你的硬件，同样重要的是你同时打开了哪些其他程序，因为两个操作系统共享同一系统资源。

在Ubuntu上安装Waydroid

在Ubuntu 26.04 LTS（及更高版本）上，你可以安装Waydroid。打开终端并运行：

sudo apt install waydroid

它会拉取Waydroid v1.63版本以及运行所需的依赖项。

解包后，你可以从应用程序网格中启动Waydroid。首次运行向导会要求你选择要下载的安卓类型。如果你想使用Google Play及相关的GAPPS功能，请选择带有该功能的镜像。

选择你偏好的安卓版本

完成后，再次打开Waydroid，它会运行安卓系统设置。这会引导你登录Google账户等。之后，一些应用快捷方式（包括设置）将出现在应用程序网格中。

剪贴板是双向的，因此你可以在安卓应用和常规Linux应用之间复制/粘贴，应用通知会出现在GNOME中，这很不错。其他一切都会传递过去（我的蓝牙游戏手柄输入被传递了，这很烦人）。

尽管Waydroid运行完整的安卓版本，但实际镜像下载本身并不大，大约1.1GB左右。在我的系统上（安装了几个简单游戏），Waydroid总共占用了约4GB磁盘空间。

Waydroid在你的桌面上运行完整的安卓操作系统

配置通过命令行完成。如果你想更改显示缩放或启用多窗口模式，需要运行命令来实现——官方文档有详细说明。

更改仅在重启Waydroid会话后生效。右键单击应用网格或Ubuntu Dock中的Waydroid图标，可以找到包含停止和启动选项的上下文菜单。

我降低了显示缩放（原始值225太大，所以我降低了）：

sudo waydroid prop set persist.waydroid.dpi 180

我希望能够调整安卓应用的大小和移动它们，所以我通过运行以下命令启用了多窗口模式：

sudo waydroid prop set persist.waydroid.multi_windows true

在安卓内部，我禁用了选择文本字段时弹出的屏幕键盘（OSK）。禁用该功能的开关位于安卓的“设置 > 系统 > 语言和输入法 > 物理键盘”中。

根据你计划在Ubuntu上使用Waydroid做什么，你可能想设置一个共享文件夹，以便在系统之间传递文件更容易一些。

而且，如果你真的想要，你甚至可以创建自己的专用会话，让你登录到全屏安卓体验。

我可以在Waydroid上使用Google Play吗？

可以，如果你在初始设置时选择了“带Google应用的安卓”镜像。不过，你需要一个Google账户才能安装任何东西。

如果Google Play报告你的设备未通过Play Protect验证，网站文档页面有步骤说明如何（简单地）解决。

我可以在没有Google Play的情况下安装应用吗？

Google Play是可选的。你可以通过ADB或在安卓环境内安装APK，所以如果你更愿意使用像F-Droid这样的开源商店，你可以——替代或 alongside Google Play。
