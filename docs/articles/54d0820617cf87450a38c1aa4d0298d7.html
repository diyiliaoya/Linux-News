BleachBit 6.0.6 发布，修复 Linux 管理员清理问题

BleachBit 6.0.6 维护版本发布，新增 Helium 浏览器和 Docker Desktop 清理器，提升启动速度与文件擦除效率（512 KiB 块），扩展 Claude、VS Code、Chromium 等清理范围，修复 RedHat 管理员模式问题，并提供 Ubuntu 26.10 官方 .deb 安装包。

BleachBit，这款免费、开源且跨平台的系统清理工具，发布了新的维护版本——新增了对 Helium 浏览器和 Docker Desktop（包括其 AI 助手）的清理支持。

此次更新还提升了应用启动速度，并加快了深度扫描、文件删除和文件擦除的速度，后者现在以 512 KiB 块而非 4 KiB 进行擦除。

一些原有的清理器现在扩展到了更多区域。本次更新可以（可选地、不同程度地）清除 Claude、基于 VS Code 的编辑器以及 Chromium 的陈旧崩溃报告、GPU 缓存和会话文件。LibreWolf 清理现在覆盖 Linux 上该浏览器的 .deb 和 Flatpak 版本。

对于 Ubuntu 用户，BleachBit 6.0.6 能够检测并移除更多 snap 修订版（如果空间不足，你可以手动移除修订版；如果你在 Ubuntu 上安装 Myna 并尝试各种 AI 模型，修订版备份会不断累积）。

它还带来了适用于 Ubuntu 26.10 的官方 .deb 安装程序，这很受欢迎。

在 Linux 的其他方面，RedHat 上以管理员身份运行 BleachBit（一种用于清理系统文件的独立模式）的问题已通过使用 得到解决。如果在 Ubuntu 上使用 .deb 安装的版本并以管理员模式运行，也推荐这样做。

Windows 用户获得了大量平台特定的修复，以及一个新（-ish）标志，熟悉的 BleachBit 图标现在被放置在一个正方形上。Linux 和 BSD 也附带了 SVG 图标。

BleachBit macOS 移植工作仍在继续。此更新为 Adobe Acrobat、Claude、Devin、GIMP、Google Earth、TeamViewer、Visual Studio Code、VLC、Zen 浏览器和 Zoom 接入了清理器。

从官方网站下载 BleachBit，该网站提供所有主要操作系统的安装程序和运行时，包括 Ubuntu 的 .deb 和 AppImage 选项。
