Btrfs 为 Linux 7.4 带来更多性能改进

Linux 7.4 内核为 Btrfs 文件系统带来多项性能优化，包括 Zstd 解压速度提升约 8MB/s、减少 inode extent map 锁争用使收缩器处理时间降低 10-20%、通过重排锁定和刷新优化 reflink 速度，此外还包含错误处理修复、代码清理和多项缺陷修复。

随着 Linux 7.3 带来了一些值得享受的 Btrfs 性能改进，而开发中的 Linux 7.4 内核将为这个写时复制文件系统带来更多性能优化。

对于那些使用 Btrfs 的 Zstd 压缩支持对文件系统进行透明压缩的用户，Linux 7.4 将提供略快的 Zstd 解压速度。在这个下一个内核版本中，Btrfs 的 Zstd 解压速度有约 +8MB/s 的小幅提升。

更新后的 Btrfs 代码还减少了 inode extent map 锁的争用，以改善诸如 Btrfs 收缩器处理没有 extent map 的 inode 等情况，预计可将时间减少 10-20%。

Linux 7.4 上 Btrfs 的另一项性能改进是通过重排锁定和刷新来加速 reflink，以针对更常见的情况进行优化。

Linux 7.4 中的 Btrfs 还带来了错误处理修复、各种代码清理、多项缺陷修复以及其他改进。
