发行版发布：Peppermint OS 2026 "Void"

Peppermint OS 发布了其基于 Void Linux 的分支 PepVoid 的首个稳定版本。该版本为滚动更新，采用预装软件的 "Loaded" 模式，ISO 约 4GB，使用 XLibre 显示服务器。未来将推出精简的 "Flagship" 版本。

大约两年前，该项目开始试验一个基于 Void 的新分支，该分支将与发行版的 Debian 和 Devuan 版本并行开发。Peppermint OS 的 Void 分支（PepVoid）的首个稳定版本已发布：“我们很高兴地宣布 Peppermint OS Void 的发布。作为一个真正的滚动发行版，我们此版本的目标是扩大您对 Debian 和 Devuan 系列之外系统基础的选择。如果您在 Peppermint 社区待过一段时间，您会知道我们维护着几个不同的分支。我们的旗舰版有意保持精简，预装软件很少，以便您有一个干净的基础来按自己的方式构建系统。另一方面，我们的‘Loaded’分支开箱即用，预装了应用程序。我们有一段时间没有发布 Loaded 版本了，我们认为它是 Peppermint Void 的最佳起点，这就是为什么您会注意到 ISO 相当大，约为 4GB。对于那些喜欢更精简起点的人，我们将在未来发布此版本的旗舰版构建。就像我们的 Debian 和 Devuan 版本一样，此版本使用 XLibre 作为显示服务器。”更多细节可以在发布公告中找到。

Peppermint OS 是一个基于 Debian 和 Devuan（之前基于 Lubuntu）的 Linux 发行版，旨在快速且对系统资源友好。通过使用其站点特定浏览器，Peppermint 与云和基于 Web 的应用程序无缝集成。该发行版的其他功能包括直接更新和使用 Calamares 安装程序轻松逐步安装。该发行版曾采用混合 LXDE/Xfce 桌面环境，将 LXDE 的 lxsession 与 Xfce 的面板和应用程序菜单混合使用。
