DLSS5VKLayer 为原生 Linux 游戏及 Steam Play 接入 NVIDIA DLSS 5

2026年9月8日 下午3:31 EDT

对于那些希望在 Linux 上使用 NVIDIA DLSS 5 的用户，一个新的有趣开源项目是 DLSS5VKLayer。DLSS5VKLayer 是一个 Linux Vulkan 层，既适用于原生 Linux 游戏，也适用于 Steam Play (Proton) 下的 Windows 游戏，提供实验性的 DLSS 5 支持。

DLSS5VKLayer 采用了一种有趣的方法：它在 Wine/Proton 下运行一个 Windows 可执行文件，并通过这个隐式 Vulkan 层，利用 IPC 将渲染帧传递给它，然后将经过 DLSS 5 处理后的帧返回给 Vulkan 交换链。DLSS5VKLayer 使用 NVIDIA Optical Flow 进行矢量生成，以消除注入 DLSS 5 后出现的闪烁、抖动等类似伪影。DLSS5VKLayer 还可以选择性地使用 NVIDIA Smooth Motion 技术。

Windows NGX 神经渲染辅助程序可以在 Wine 下运行，或者使用自定义的 Proton 兼容工具。该项目提供了一个基于 Qt 的图形界面来控制体验，同时也有一个命令行辅助工具。

这仍然要求用户使用 NVIDIA GPU 并运行其官方图形驱动程序。此外，用户需要从 NVIDIA Windows 软件中获取 NGX DLL，并在设置过程中自行提供。

想了解更多关于 DLSS5VKLayer 的信息，可以访问该项目的 GitHub 仓库。需要提醒的是，该项目公开承认在创建过程中使用了本地运行的 Qwen 3.8 Flash Next 作为 AI/LLM 辅助工具。
