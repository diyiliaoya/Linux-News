Framework Laptop 13 Pro：旨在成为最佳可升级Linux笔记本电脑之一

发布于2026年7月27日上午11:00（美国东部时间）。

今年四月，Framework Computer 发布了 Framework Laptop 13 Pro，这是对其模块化/可升级笔记本电脑的彻底重新设计。这款全新的 Framework Laptop 13 Pro 配备了更大的电池（74Wh）、LPCAMM2内存支持、全CNC铝制机身、触觉触控板，以及一块经过功耗优化的触控显示屏。搭配能效极高的Intel Core Ultra Series 3“Panther Lake”SoC，Framework Laptop 13 Pro 从硬件角度来看，成为了一款令人难以置信的产品。

Framework Computer 最近向我们寄送了一台 Framework Laptop 13 Pro 的评测样机。评测解禁日期为今天，虽然我目前只有大约一周的测试时间，但从开箱的那一刻起，就明显看出这相比前几代 Framework Laptop 13 是一次多么重大的硬件升级。CNC加工的铝制机身手感极佳，类似于老款ThinkPad笔记本电脑或Apple MacBook Pro的质感。机身采用6063铝合金加工而成，同时保持了与前代 Framework Laptop 13 型号相同的外部尺寸，重量仅为1.4公斤。与以往的 Framework Computer 产品一样，硬件设计的开源CAD文件可供获取。

新的 Framework Laptop 13 Pro 仍然像之前的笔记本型号一样可升级，但由于采用了新的机身制造工艺，硬件品质现已提升到了新的水平。与之前的 Framework Laptop 型号相比，新显示屏是开机后另一个非常显著的体验提升。

借助新的 Panther Lake 主板上的 LPCAMM2 内存，Framework Computer 提供了16GB、32GB和64GB的选项，速度为7467 MT/s。

另一个需要重点注意的事项是，虽然有了全新的 Framework Laptop 13 Pro 机身，但 Framework Computer 保持了其组件的跨代兼容性。基于 Panther Lake 的新主板以及显示套件和其他组件，都沿用了早期单元的外形规格和接口，因此，如果暂时不想选择全新的机身，旧款笔记本电脑仍然可以用这些新组件进行升级。或者，如果你现在想升级机身，同时保留现有硬件组件，直到内存/存储价格等下降。

凭借新的74 Wh电池、功耗优化的显示屏以及Intel Panther Lake SoC的低功耗，Framework Computing 宣称这款笔记本的电池续航时间可达20小时。虽然由于存在众多变量以及不同的用户工作流程会导致截然不同的结果，我暂不公布具体的续航数据，但 Framework Laptop 13 Pro 的续航时间确实比之前的 Framework Laptop 13 型号（如搭载 Ryzen AI 9 HX 370 或 Ryzen 7 7840U 的配置）长了好几个小时。

对于曾组装过前代 Framework Laptop DIY 版本的用户来说，设置 Framework Laptop 13 Pro 的过程完全相同。非常简单直接。我没有遇到任何问题，整个过程非常顺畅。Framework Computer 继续支持 LVFS/Fwupd，使系统和组件固件更新变得简单直接。

Framework Laptop 13 Pro 在设计时充分考虑了对Linux的出色兼容性。运行现代Linux发行版（如 Ubuntu 26.04 LTS、Fedora Workstation 44、Arch Linux 等）的用户，应该能够在这款搭载 Panther Lake 的新笔记本上获得出色的开箱即用Linux体验。

由于目前使用这台笔记本的时间有限，我的大部分测试都是在 Ubuntu 26.04 LTS 上进行的。Ubuntu 26.04 LTS 在这款搭载 Panther Lake 的 Framework 笔记本上，使用 Linux 7.0 内核即可完美开箱即用。Panther Lake SoC 搭配 Arc B390 集成显卡、新的显示套件、新的触觉触控板以及所有其他组件
