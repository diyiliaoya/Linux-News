Laser：Linux 上全新的现代 CD 抓取工具

Laser 是一款面向 Linux 的现代 GTK4/libadwaita CD 抓取应用，可从 Flathub 安装。它能自动获取曲目元数据和封面，支持编辑曲目信息、自定义文件夹结构，并可一次性输出 FLAC、MP3、AAC、Opus、WAV 等多种格式，还能归档为镜像文件。不过它无法选择性地抓取部分曲目，只能整盘处理。

Laser 是 Linux 上全新的现代 CD 抓取工具 - OMG! Ubuntu

我床底下有一大箱 CD，多年来我一直打算把它们抓取出来。有些不在 Spotify 上，有些在，但不是正确的版本，还有一张的艺术家我几乎怀疑只是民间记忆——也许正是 Laser 这款新的 GTK4/libadwaita CD 抓取应用，促使我开始动手完成这件事。

需要它的不只是老用户。英国的 CD 销量正在蓬勃发展，因为被黑胶唱片高昂价格劝退的年轻买家转向了更便宜的实体格式。只需一个便宜的外置 CD/DVD 光驱，就能在笔记本电脑或 PC 上收听。

也许正因如此，在光驱从笔记本电脑上消失十年后，Linux 如今有了新的 CD 抓取软件。

Laser 专注于一项任务

Laser 专注于单一任务，是一款现代 CD 抓取工具，其界面更符合现代桌面的风格——当然比 Asunder 等旧选项更好，后者虽然仍可用，但基于 GTK3。Sound Juicer 也能抓取音频 CD，但在 Ubuntu 上点击提取没有任何反应。

于是，我从 Flathub 安装了 Laser，放入一张光盘，它立即从在线来源获取了曲目元数据和封面艺术。它允许下载封面并将其嵌入抓取的文件中，以便在音乐应用中显示，你也可以选择本地图片文件。

单首曲目的标题也可以在抓取前编辑，如果数据库列表与你的副本不符（或者你对混音、特邀艺术家等的格式很挑剔），这会很方便。你还可以设置提取文件的文件夹结构。

在抓取方面，Laser 可以一次性提取为多种音频格式——FLAC、MP3、AAC、Opus 和 WAV。可以配置编码器质量和压缩率，你还可以将光盘归档为镜像文件，即一个带有 CUE 表的大文件。

最后，当提取完成时（但仅当光驱支持时），它会弹出 CD。

它做不到一件本应做到的事

Laser 不让你选择要抓取哪些曲目——它会抓取光盘上的每一首曲目，无论你是否全都想要。

我觉得这是一个奇怪的遗漏。

事后删除不需要的曲目当然很容易，但一开始就不抓取它们会加快速度。

Laser 运行良好。它产生了我想要的结果：一些 CD 的高质量抓取，我可以添加到我的 Linux 媒体服务器，然后在本地访问/流式传输到其他设备。任务完成。

我只处理了床底下箱子里 250 张光盘中的 10 张。怀旧是个陷阱！但在翻找它们的过程中，我确实发现我对 1990 年代女子组合的记忆是真实的，她们的单曲……
