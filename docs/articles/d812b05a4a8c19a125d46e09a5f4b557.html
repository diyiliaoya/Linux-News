Wine 11.17 发布，初步支持显示模式模拟

2026年9月4日下午4:11（美国东部时间）

Wine 11.17 于今日发布，这是该软件的最新双周功能开发版本，旨在让 Windows 游戏和应用能够在 Linux 上运行。

今日 Wine 11.17 版本中最令人兴奋的可以说是初步的显示模式模拟支持。Rémi Bernon 领导了这项工作，允许 OpenGL 根据模拟分辨率进行缩放。这也被描述为 OpenGL 渲染虚拟化。渲染按照预期的虚拟尺寸进行，然后渲染到实际物理大小的宿主窗口上。

Wine 11.17 还引入了新的 VKD3D 版本，用于在 Vulkan 之上支持 Direct3D 12。

Wine 11.17 还改进了对首选 UI 语言的支持，并总共修复了 44 个已知错误。过去两周的错误修复范围非常广泛，涉及不同的新旧游戏以及许多应用修复。

Wine 11.17 的完整更改列表可在发布公告中找到。

VKD3D 2.1 发布，为上游 Wine 中的 Direct3D 12 带来新功能

Wine 11.16 发布，支持 VA-API 硬件解码，改进 ARM64 支持

Wine 11.15 发布，包含 Wayland 修复，修复了 20 年历史的 MSXML3 错误

Wine 11.14 为 FreeBSD 带来 WoW64 模式，开始菜单支持图标

Wine 11.13 更好地支持输入指针，改进 X11 的键盘扫描码映射

Wine 11.12 发布，包含 Wayland 分数缩放及其他 Wayland 增强功能
