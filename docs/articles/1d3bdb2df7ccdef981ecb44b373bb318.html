High Tide（Linux Tidal 客户端）新增播放列表编辑与艺术家屏蔽功能

High Tide 1.6.0 版本发布，新增播放列表编辑、艺术家和曲目屏蔽功能，并加入偏好设置面板管理屏蔽项。主页面封面新增播放按钮，专辑标题旁显示显式内容、Dolby Atmos、Hi-Res 或无损等标签。设置中可选择始终播放“干净”版本。新增专辑制作人员页面和月度最常听艺术家页面。其他改进包括使用系统强调色高亮正在播放、收藏排序、播放时保持电脑唤醒等，并修复了多个错误。该应用通过 Flathub 分发，需 TIDAL 订阅使用。

High Tide（Linux Tidal 客户端）新增播放列表编辑与艺术家屏蔽功能 - OMG! Ubuntu

一款非官方的 TIDAL 音乐流媒体 Linux 应用，使用 GTK4/libadwaita 构建，现已发布 1.6.0 版本。该版本加入了付费流媒体服务官方客户端中的更多功能支持，包括屏蔽艺术家和曲目使其不出现在播放列表或自动播放队列中，并新增偏好设置面板以查看和管理屏蔽项。

TIDAL 最近新增了一项整体屏蔽的选项。High Tide 中没有面向用户的设置，但相关功能已就绪，并将在未来更新中推出。

主页面封面现在显示播放按钮，与官方客户端一致。这些按钮意味着你可以直接从主页开始播放专辑或播放列表，无需点击进入后再按播放。

终于——可以编辑播放列表了。此前版本的播放器确实允许将新曲目添加到现有播放列表，但无法创建、编辑或删除播放列表，也无法移除曲目。很高兴看到这一功能落地。

现在专辑标题旁会显示标签，指示专辑是否为显式内容、是否提供 Dolby Atmos、Hi-Res 或无损。在设置中，还有一个选项可以始终播放专辑/曲目的“干净”版本（如果可用）。

新增了专辑制作人员（背面）和页面。该页面显示每月最常听的艺术家（与 TIDAL 自身创建的月度最常听播放列表分开）。现在你还可以查看专辑信息和曲目制作人员页面。

High Tide 1.6.0 的其他亮点：

- 专辑行中的正在播放高亮使用系统强调色

- 显示整个收藏，而不仅仅是前 1000 项

- 收藏可按排序

- 音乐播放期间保持电脑唤醒的选项

包含大量错误修复，包括长时间暂停后恢复播放的问题、保存的曲目无法离线播放，以及偶尔切换专辑后显示错误歌曲的问题。

High Tide 已在 Flathub 上架

由于这不是独立的音乐播放器，只有订阅 TIDAL 才有用（我也是如此，尽管是通过家庭计划免费获得访问权限）。TIDAL 不提供免费的广告支持计划。

TIDAL 不提供官方的 Linux 桌面应用，尽管官方网页应用在大多数浏览器中可用（存在非官方的桌面封装）。但没有什么能比得上一个可靠的本地桌面播放器。

虽然是非官方的且未得到 TIDAL 本身认可，但使用了 Tidal API 和适当的基于浏览器的身份验证。它是免费的，用 Python 编写，采用 GTK4/libadwaita 界面。
