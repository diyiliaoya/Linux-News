KosmicKrisp 现已符合 Vulkan 1.4 标准，性能向 Apple Metal 靠拢

2026年10月3日上午07:24 EDT。

这是由 LunarG 主导的项目，旨在为 Mesa 中的 Apple 系统开发一个现代 Vulkan-on-Metal 驱动。作为 MoltenVK 的现代替代方案，该项目持续取得良好进展，现已通过 Vulkan 1.4 合规性认证，性能也在不断逼近原生 Apple Metal API。

LunarG 的 Aitor Camacho Larrondo 本周在多伦多 XDC2026 上介绍了 KosmicKrisp 及其最新进展，其中最引人注目的是 KosmicKrisp 通过了 Vulkan 1.4 CTS，并被 Khronos Group 认定为合规实现。LunarG 认为 KosmicKrisp 在现代 macOS 上已具备生产就绪状态，可在 Apple Silicon 硬件上通过 Metal 提供 Vulkan API 支持。

令人兴奋的是，其性能相对于替代方案 MoltenVK 的 Vulkan-on-Metal 实现表现良好，且与原生 Metal 性能差距不大。

LunarG 正在持续投入以增强 KosmicKrisp 的性能并清除剩余错误。预计还将实现其他 Vulkan 功能，并增强围绕该 Mac 版 Vulkan API 实现的工具支持。迄今为止，KosmicKrisp 仅专注于 macOS，而非 iOS。要让 KosmicKrisp 在 iOS 上真正成为现实，还需要更多资源。
