GNOME OS 开发者正在设计“Toolpak”，类似于面向工具的 Flatpak

GNOME 开发者 Jordan Petridis 公布 GNOME OS 的 Toolpak 计划，旨在为开发工具提供类似 Flatpak 的现代打包方案。Toolpak 采用 UAPL3 可发现磁盘镜像格式，为二进制文件提供挂载命名空间，工具可无限制访问系统，并前置到 $PATH。它默认可复现，处理许可与 SBOM 要求，便于编排构建。目前正开发原型，未来几周将分享更多细节。

GNOME 开发者 Jordan Petridis 今天发布了一篇博客文章，向世界介绍了 GNOME OS 的 Toolpak 计划。

虽然 Flatpak 对于桌面 Linux 应用和其他针对不同应用的容器化软件解决方案效果很好，但对于为现代操作系统栈开发软件的开发者来说，它们往往不太适用。对于许多开发工具而言，目前还无法享受沙箱和隔离，但 GNOME OS 开发者目前正在将 Toolpak 作为一种现代替代方案来推进。

Toolpak 采取的设计思路是：QEMU、strace 等工具都独立于宿主操作系统，工具应当开箱即用，无需对它们全部进行修改。因此，他们在 Toolpak 上采取的方法是：利用 UAPL3 可发现磁盘镜像作为其镜像格式，为二进制文件使用挂载命名空间，工具对其他一切拥有不受限制的访问权限，工具被前置到 $PATH，工具对系统拥有完全且任意的访问权限，而可以用 Flatpak 打包的应用则应被排除在这个更自由的 Toolpak 概念之外。

Toolpak 还旨在默认实现可复现性，处理所有许可和 SBOM 要求，便于编排构建，以及满足其他现代开发需求和交付物。GNOME OS 开发者目前正在开发 Toolpak 的原型，并计划在未来几周内分享更多内容。
