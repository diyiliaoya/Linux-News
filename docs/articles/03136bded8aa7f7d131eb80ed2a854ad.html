发行版发布：Raspberry Pi OS 2026-09-15

Simon Long 宣布发布 Raspberry Pi OS 的新功能更新，这是一个基于 Debian 的 Linux 发行版，专为 Raspberry Pi 系列单板计算机设计。最新版本为 Raspberry Pi Desktop 带来了更新的外观，并引入了新的图标停靠栏：

“今天为你带来 Raspberry Pi Desktop 的一些可选更新，它在保持简洁性的同时获得了一些现代功能。目前被称为 Raspberry Pi Desktop 的桌面环境已经存在了十多年——它最初只是对原版 LXDE 桌面进行轻度定制，多年来逐渐演变成一个底层几乎完全不同的系统，基于 Wayland 和 labwc。其外观经过多次刷新，有了新的图标、主题和桌面背景，以至于如今的 Raspberry Pi Desktop 与最初的 LXDE 在视觉上几乎没有共同之处。但有一件事从未改变，那就是桌面的整体感觉——凭借其任务栏、状态图标和主菜单启动器，它让人想起大约 30 年前 Windows 95 和 Apple System 7 时代的桌面设计巅峰。”

关于 Raspberry Pi OS

Raspberry Pi OS（原名 Raspbian）是一个基于 Debian GNU/Linux 的免费操作系统，针对 Raspberry Pi 硬件（armhf 处理器架构）进行了优化。Raspberry Pi OS 附带超过 35,000 个软件包，即以良好格式打包的预编译软件，便于在 Raspberry Pi 上轻松安装。
