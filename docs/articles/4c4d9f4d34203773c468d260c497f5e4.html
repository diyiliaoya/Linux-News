挑战红帽？Ubuntu 现在有了官方系统管理员认证

Ubuntu 现在提供认证考试，涵盖从 Linux 基础到 DevOps 的内容。学院启动还提供这些认证考试 10% 的折扣。

Canonical 于 2025 年 10 月推出了 Canonical Academy。当时，其系统管理员轨道只有一门考试对所有人开放，其余要么处于测试阶段，要么仍在建设中。

现在情况变了。Canonical 已通知 It's FOSS，系统管理员轨道的全部四门考试均已上线：

使用 DevOps 原则

通过全部四门考试，你将获得 Canonical Academy 系统管理员资格。

首门考试费用为 100 美元，之后每门考试费用为 125 美元。如果参加全部四门，整个轨道总计 475 美元。

为纪念发布，Canonical 提供任何考试 10% 的折扣，使用代码 [优惠码]，有效期至 1 月 10 日。你可以从 Ubuntu 认证考试页面支付考试费用。

每门考试均在线进行，在基于浏览器的 Ubuntu 环境中完成。根据 [描述]，考试混合了选择题、场景题和需要在实时系统上完成的动手任务。

考试环境中允许使用 man 手册和官方 Ubuntu 文档，但不能打开其他标签页。考试通过 [监考平台] 进行监考，因此你需要网络摄像头、麦克风和单显示器。

需要注意的一点是，考试推荐使用基于 Chromium 的浏览器，不支持 Firefox，这对于 Linux 认证来说有点讽刺。

你可以按任意顺序参加考试。每门考试时长在 75 到 120 分钟之间，一年内最多可重考两次。

Canonical 还整理了一份 [备考资源]，包含每门考试的准备材料，以及一份 [考生手册]，解释了考试形式和考试当天的规则。

这门 75 分钟的考试是轨道的基础，我建议你从这里开始。它也是所有考试中最简单的，尤其对初学者而言。它还能让你在花钱参加其他考试之前，很好地感受动手考试的形式。

考试涵盖从终端移动和操作文件、使用正则表达式搜索和修改文件、管道和重定向。你还会处理系统资源，如日志和日志轮转、cron 任务，以及使用 fdisk、fsck 和 parted 等工具修复分区和文件系统。

安全部分涵盖 SSH 密钥、用户和组、文件所有权和权限、密码规则和 sudo 策略。这是任何系统管理员绝对必须掌握的 Linux 知识，如果你每天使用 Linux，可能已经知道很大一部分。不过，认证考试仍然是测试知识的好方法，尤其是当你不能使用互联网或 AI 辅助时。

这门 90 分钟的考试更针对 Ubuntu。它涵盖安装 Ubuntu、创建可启动 USB、在 LTS 版本之间升级、安装专有 GPU 和 Wi-Fi 驱动，以及使用 GRUB2 和 initramfs 修复启动问题。LVM 卷和快照也在其中。

很大一部分是应用程序管理，从 apt 和无人值守升级到 deb 与 Snap 包的区别。你还会学到网络基础知识，如配置连接和第 2 层概念，如 MAC 地址和 ARP。

安全部分涉及 PKI、使用 ACL 的文件权限以及加入 Active Directory 域。甚至还有一小节关于开源社区，涵盖 LTS 发布周期和 Ubuntu 的治理。

这也是一门 90 分钟的考试，服务器端的内容在这里出现。你将接受关于使用 PXE 启动、autoinstall 和 cloud-init 部署 Ubuntu Server，以及启动到单用户模式的测试。

你还会使用 systemd 管理服务，使用 systemd 定时器或 cron 设置自动备份，使用 NFS 或 Samba 运行文件服务器，并使用 Apache 或 Nginx 和 MySQL 或 PostgreSQL 等数据库搭建一个基本的 Web 应用。在安全方面，有 SSH 访问和使用 ufw 或 iptables 设置防火墙。
