X.Org 库又公开 17 个安全漏洞

距 X.Org Server 和 XWayland 公开十几个漏洞不到两周，今天又公开了 17 个影响多个 X.Org 客户端库的安全漏洞，涉及 libX11、libXi、libXpm、libXrender 和 libXtst。这些漏洞主要由不同研究人员发现，多为越界读写，以及一些堆缓冲区溢出和可能的拒绝服务。已发布更新版本：libX11 1.8.14、libXi 1.8.4、libXpm 3.5.20、libXrender 0.9.13 和 libXtst 1.2.6。

距 X.Org Server 和 XWayland 公开十几个漏洞不到两周，今天又公开了超过十几个影响多个 X.Org 客户端库的漏洞。

今天公开了 17 个漏洞，影响 libX11 X11 库、用于 X Input 的 libXi、用于 X Pixmap 格式支持的 libXpm、用于 X RENDER 的 libXrenderer 以及用于 X TEST 扩展的 libXtst。

不同研究人员发现的这些漏洞主要是越界读写，以及一些堆缓冲区溢出和可能的拒绝服务。

更新版本包括 libX11 1.8.14、libXi 1.8.4、libXpm 3.5.20、libXrender 0.9.13 和 libXtst 1.2.6。
