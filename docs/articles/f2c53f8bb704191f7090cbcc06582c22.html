Era：GNOME 全新基于 Rust 的日历应用现已进入测试阶段

Era 是一款基于 Rust 的新 GNOME 日历应用，现已发布测试版并可从 Flathub 安装。它采用 GTK4/libadwaita 界面，支持事件管理、搜索、多视图切换及在线同步。其后端通过中间层连接 Evolution Data Server，实现后端热插拔。

Era 是 GNOME 的一款全新基于 Rust 的日历应用，被描述为“美观且高性能”。你无需预约日期就能试用它；测试版已可从 Flathub 安装。

（GNOME 51 中的日历应用获得了重大更新，尤其是在你能感受到而非看到的方面）。但话说回来，这也在所难免？在方框中排列数字网格并留出彩色事件标签空间的方式本就有限。

Era 覆盖了同样的功能：你可以浏览日期，添加、编辑和搜索事件，并与各种在线提供商同步。你可以在专用视图之间切换，并切换侧边栏来管理日历。

Era v0.1 中的事件对话框

事件编辑器也显示了你期望的所有字段和设置，让你可以为事件命名、精确设置时间/时长、选择重复或一次性事件，并且贴心地设置地点或会议场所。

GTK4/libadwaita 界面非常简洁，高度自适应，堪称教科书般的 GNOME 风格。很容易让人误以为它是核心应用。窗口较宽时，主日历视图上的叠加按钮很不错，我也喜欢界面在较窄宽度下依然保持可用性。

其后端也很有趣。Era 像 GNOME 日历一样使用 Evolution Data Server (EDS)，但并不直接连接 EDS。相反，它通过一个名为 EDS 中间层的组件来路由调用。这种方法允许后端热插拔（如果应用被移植到比如 Android，这会很有用）。

你可以在本地使用它，导入事件，或同步到支持的提供商。

由于这还处于测试阶段，我就不提出那个令人尴尬的假设性问题——它是否“标志着 Linux 日历应用的新时代”——因为说实话，日历通常很少是最令人兴奋的东西（除非每个月都展示一只不同的豚鼠坐在小篮子里）。

它并不是唯一一款新的 Linux 日历应用。Linux Mint 在其 XApps 项目旗下开发了一款新日历应用，看起来已经相当能干。这令人鼓舞，并且可以测试——Flathub 描述称该应用“与你共同成长”，基于我自己的第一印象，我很想看到它确实如此。
