NVIDIA 公布 Wayland 与 X.Org 延迟测试结果

2026 年 10 月 4 日上午 07:03 EDT。

NVIDIA 在多伦多 XDC 2026 上宣布了他们的 Display Config Server 项目，在这场年度开发者大会上，他们还展示了关于 X.Org 与 Wayland 延迟科学测试的发现。

在不同合成器和桌面环境下 X.Org 与 Wayland 的延迟对比，一直是热情的 Linux 桌面爱好者中激烈讨论的话题。一些人支持经典 X.Org 能提供最低延迟，而另一些人则经常分享自己的个人体验，支持现代 Wayland 方案。NVIDIA 工程师 Kamil Łysik 对 Wayland 与 X.Org 从按键到呈现的延迟进行了比较。为确保测量准确，使用了微控制器和光传感器进行端到端测量，并配合软件实现可重复的自动化测试。

测试使用 NVIDIA GeForce RTX 5070 显卡，并使用该公司的 R610 驱动分支，在 KDE KWin 6.7.4 和 GNOME Mutter 49.7 上进行了测试，X.Org Server 测试则使用 v1.21.1.24。

NVIDIA 的发现是，X.Org 与 Wayland 之间的延迟结果非常接近，很难得出明确的赢家。一些值得注意的结论包括：XWayland 不再像过去那样引入额外的帧延迟。可变刷新率（VRR）也被测得能“大幅改善”响应速度，并在 X.Org 和 Wayland 会话之间提供大致相同的延迟。
