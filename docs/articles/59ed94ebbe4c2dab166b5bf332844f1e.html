Linux 7.3 将报告五款更多联想笔记本电脑的风扇传感器

2026年8月10日下午2:40（美国东部时间）

继更多华硕主板在 Linux 7.3 下拥有可工作的传感器之后，这个下一个内核版本还将让更多联想笔记本电脑型号在 Linux 下报告其风扇传感器信息。

早在 Linux 7.1 中合并了 Yogafan 驱动，以支持更多联想 Yoga、Legion、Flex、Slim 和 IdeaPad 笔记本电脑型号的风扇转速监控。该 Yogafan 驱动将在 Linux 7.3 中进一步扩展，以支持更多联想笔记本电脑型号。

计划为 Linux 7.3 新增的设备支持包括 IdeaPad 3 15ALC6、Legion Pro 7 16、Yoga Pro 7 14IAH、Yoga 7 16ARP8 以及 XiaoXinPro 13ARE。

这些新增内容相当于增加了 69 行 C 代码，为这些额外的笔记本电脑型号添加了正确的 DMI 条目，以实现风扇转速报告功能。该补丁已排队在硬件监控子系统的“hwmon-next”Git 分支中，等待 Linux 7.3 合并窗口开启。
