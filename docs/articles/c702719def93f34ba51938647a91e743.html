GNOME OS 转向 Zswap 以应对 OOM 问题，Geary 邮件客户端分支取得进展

GNOME OS 现已默认启用 Zswap，以缓解内存不足问题并提升系统响应速度，同时推出了配套文档网站。第三方应用方面，Convey 作为 Geary 邮件客户端的分支亮相，新增 Microsoft 365 支持并移植至 GTK4。此外，GNOME 51、Shotwell 33、GTK 4.24 等也发布了重要更新。

2026年9月19日上午06:38 EDT。

除了本周的[GNOME 51 发布]之外，GNOME 桌面领域还有其他几项令人兴奋的进展。

GNOME OS 现在有了一个文档网站，提供指南和其他信息，帮助用户试用 GNOME OS 并进行相关设置。

GNOME OS 现在也采用了 Zswap，即使你的系统内存不太大，也能帮助保持系统快速响应。这一变化应该能帮助那些在 GNOME OS 上遇到过内存不足问题的用户，Zswap 将被默认使用。GNOME OS 依赖一个基于 Rust 的 zswap-generator 脚本来为 Zswap 创建正确的 systemd 配置。zswap-generator 将遵循内核命令行上的[参数]来禁用该功能。

在第三方 GNOME 应用新闻中，Convey 已作为 Geary 邮件客户端的分支首次亮相。Convey 分叉了 Geary，添加了 Microsoft 365 支持，移植到 GTK4 工具包，并带来了其他修复和 UI/UX 增强。
