为在Linux上为所有Apple M3系列SoC启用NVMe的补丁已发布

发布于2026年9月25日 06:27 AM EDT。

Linux 7.2带来了初步的Apple M3支持，Linux 7.3带来了M3 Pro / Max / Ultra支持，但主线Linux内核对于M3系列硬件的支持仍然非常基础，尚未准备好日常使用。不过更多工作仍在持续上游化，今天补丁被发布，旨在让NVMe存储在所有Apple M3硬件上运行起来。

Janne Grunau发布了七补丁系列，用于在所有M3及M3 Pro / Max / Ultra设备上启用NVMe。M3系列的NVMe工作方式与之前的Apple M2 Pro / Max / Ultra设备相同。但由于设备树的原因，需要额外约140行YAML和设备树添加代码，才能为兼容的Apple M3系列实现这一NVMe支持。

考虑到时间安排，且这仅仅是为在Apple M3硬件上启用NVMe而添加的设备树内容，希望它仍能赶上10月的Linux 7.4合并窗口。

已在Linux内核邮件列表上发布以供审核。

虽然Apple M3支持仍在主线内核中逐步铺开，但那些拥有Apple M3硬件并希望运行Linux的用户，目前最好使用最新的下游Asahi Linux及其Apple M3支持，以便在官方内核树正式支持之前就能获得最新工作成果。
