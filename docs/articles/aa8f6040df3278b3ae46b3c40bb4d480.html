Rockstor 是一款基于 openSUSE 的专业 Linux 发行版，专为网络附加存储（NAS）和私有云存储解决方案而设计。它基于流行的开源技术，如 Btrfs 文件系统和 Docker（用于在软件容器内自动化部署应用程序）。除了标准的 NAS 功能（如通过 NFS、Samba、SFTP 和 AFP 进行文件共享）外，还支持高级功能，如在线卷管理、CoW 快照、异步复制、压缩和防位腐保护。Rockstor 提供额外的应用程序，包括 ownCloud、Syncthing、OpenVPN 和 Plex。这些应用程序（称为“Rock-ons”）由基于 Docker 的应用程序托管框架驱动。Rockstor 的用户界面使用 JavaScript 编写，使得在 Web 浏览器中管理服务器变得简单。
