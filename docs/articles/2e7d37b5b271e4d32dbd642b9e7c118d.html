Rio 终端新增 Quake 模式

跨平台、GPU 加速的终端 Rio（不是其他跨平台、GPU 加速的终端）上个月活动频繁。

在众多更新中，它增加了一个下拉式“quake”模式选项。这允许你分配一个键盘热键，让终端从显示器顶部滑出到光标下方。巧妙的是，这个快捷键可以全局生效，即使 Rio 不在焦点上也能使用。

它将终端引擎与渲染器分离，成为一个独立的 Rust crate，并通过 C 接口封装了相同的核心。其他开发者可以在不使用 Rio 本身的情况下，基于 Rio 的技术构建自己的终端前端。

据 Amorim 称，性能也得到了大幅提升。全屏 TUI 重绘速度提升高达 1.6 倍，滚动密集型纯文本（例如大量的 print 输出）的解析速度现在提升高达 2.7 倍。

Rio 0.5.x 中的其他更改包括恢复了对 Sixel 和 iTerm2 内联图像的支持，修复了 Kitty 图形协议的问题，并且在 Linux 上，Rio 现在通过读取标准的 XDG Desktop Portal，在 Wayland 和 X11 会话中都会遵循系统的浅色/深色偏好。

Rio 是一款用 Rust 编写的免费开源软件。从其网站下载最新版本，或从其 .deb 包获取。

Typhoon 天气应用新增托盘图标

跨平台开源天气应用 Typhoon 在其最新版本中增加了系统托盘图标。这使得当应用不在前台时，你可以从面板上查看温度，并在需要时快速将其调至焦点。

本月该应用还增加了交互式 24 小时降雨概率和温度预报，并修复了一些错误。

Typhoon 是对标志性天气应用的现代复兴，但它本身是一个非常独特的存在。它于今年早些时候发布，并配备了新功能和集成，使其成为 Linux 上最好的天气应用之一。

托盘图标是一个小改动，但对于那些想要面板小程序一目了然的好处，同时又能在需要时跳转到应用的人来说，这是理想的选择。

下载详情可在 Typhoon 网站上找到，其中列出了 Windows 和 Linux 的软件包。Ubuntu 用户可以使用 Snap 版本、Flatpak 和 .deb 包。

BleachBit 可以释放 AI 编码工具占用的空间

BleachBit 6.0.2 新增清理器

免费系统清理器 BleachBit 新增了清理器，这是我在六月汇总中提到的测试版的稳定版本。抱歉让你有似曾相识的感觉。

该工具现在能够清除 AI 编码工具（包括 Continue）产生的垃圾文件。它还能清除 Google Chrome 经常在后台下载的 4GB AI 模型，但请注意，Chrome 可能会再次下载它。

其他跨平台支持包括：清理 Linux 上的多个浏览器配置文件、DNS 缓存，以及在粉碎粘贴的文件后清除剪贴板；深度扫描可以检测损坏的符号链接。

在 Linux 上，BleachBit 6.0.2 改进了对回收站文件的检测，并且能够清理 Deb 安装的 Brave 浏览器和 Flatpak 版本的 qBittorrent 客户端。修复改进了 Snap 处理，并允许 BleachBit 的 CLI 模式在 Wayland 上以 root 身份运行。

BleachBit 6.0.2 可从 download.bleachbit.org 下载，包括新的 AppImage 选项。
