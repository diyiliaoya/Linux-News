Starling：一款用 Swift 编写、自带 Wayland 合成器并由 AI 辅助开发的全新 Linux 桌面

发布于 2026 年 7 月 28 日 上午 11:50（美国东部时间）

在大量通过 AI/LLM 编写的新开源项目涌现的时代，Linux 用户又多了一个全新的开源桌面选择。Starling 就是这样一个新项目，它主要通过 Claude 编写，使用 Swift 编程语言构建桌面，同时拥有用 C 语言实现的 Wayland 合成器。它还内置了一个 X11 服务器，用于处理 X11 客户端。

对于那些喜欢尝试评估新 Linux 桌面选项的人来说，Starling 刚刚被宣布为一个新的桌面选择，它是在过去半年中主要通过 AI（Claude）编写的。在给 Phoronix 的一封邮件中，这个项目的唯一开发者（与 Claude 合作）解释了其技术栈：

"- 自有的 Wayland 合成器，用 C 语言编写，实现了 xdg-shell、linux-dmabuf（零拷贝导入）、viewporter、fractional-scale-v1、pointer-constraints、relative-pointer、text-input-v3、presentation-time、primary-selection、idle-inhibit、cursor-shape-v1、xdg-decoration、xdg-activation、xdg-output 和 wlr-data-control。

- 内置 X11 服务器（DRI3/Present），因此 X11 客户端也能运行。

- 运行在 Flutter 引擎的 C 核心之上，通过 DRM/KMS 嵌入器实现。Shell、窗口管理器、合成器和应用都是 Swift 编写的——UI 框架是 Flutter 框架到 Swift 的完整移植，没有使用 Dart 虚拟机。

- 无特权会话：DRM 主控和输入来自 logind（通过 libseat），而非以 root 身份运行。像任何 Wayland 会话一样通过 GDM 启动。

- 作为原生客户端运行真实应用——Chrome、VS Code、Slack、IntelliJ、GIMP 和 Blender（通过 linux-dmabuf 使用 EEVEE 视口）——涵盖 Chromium/Electron、Qt6、GTK3/4、JetBrains 运行时和 Blender 的 GHOST。

- 以约 53 MB 的 .deb 包形式发布，适用于 Ubuntu 26.04。已在 AMD（Radeon 780M）和虚拟机中的 virtio-gpu/virgl 上验证。

这是一个诚实的早期预览版（v0.2）：已测试 AMD 和 virtio-gpu，尚未测试 Intel/NVIDIA；缩放当前固定为 2.0；仅支持 Ubuntu 26.04。"
