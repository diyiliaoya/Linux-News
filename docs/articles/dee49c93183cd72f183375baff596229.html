BSD 用户现在可以享受 Omarchy 风味了

Jordan Hubbard 借助 OpenAI 的 GPT 模型，在 FreeBSD 上构建了 Daemonarchy 项目，将 Omarchy 的安装程序和桌面外观移植到 FreeBSD 系统之上。该项目仅用不到两小时完成首版，现已发布多个版本，支持 ZFS 回滚、可选加密，并可通过现有 FreeBSD 系统安装。

Daemonarchy 保留了 Omarchy 的安装程序和外观，底层由 FreeBSD 处理系统。

Jordan Hubbard 于 1993 年与另外两人共同创立了 FreeBSD 项目，如今他在 OpenAI 的 GPT AI 模型的帮助下构建了 Daemonarchy。这个名字是对 Omarchy 的戏仿，用 BSD 守护进程取代了 Arch 作为基础。

至于 Omarchy，自从我们最初将其作为 Arch 的配置项目报道以来，它已经取得了长足发展。现在它可以从 ISO 安装，并成功吸引了大量资金。

无论如何，Daemonarchy 才诞生几周，就已经发布了多个版本，v1.3.1 于几小时前发布。

用户们一直在纠缠 Jordan，说 FreeBSD 应该像 Omarchy 一样易于设置且美观。这让他不禁思考：“为什么这还不存在？”他当时使用了 GPT，并用它来组建项目。

第一版耗时不到两小时。这个数字还不包括用于验证的构建时间。GPT 还为该项目挑选了名字。

该发行版所需的 ports 已上游到 FreeBSD 的 ports 树进行审查。安装程序还允许你在现有的 FreeBSD 系统之上安装 Daemonarchy。

Jordan 还将桌面所依赖的层归功于相关项目。

安装程序遵循 Omarchy 自身的安装程序，会询问键盘布局、账户详情、主机名和时区等常规基本信息。

Daemonarchy 可以占用整个磁盘，也可以安装到你选择的某个分区或空闲空间，最低需要 40 GB 存储空间。全盘安装会擦除驱动器，而分区模式只会覆盖你选择的分区。

由于安装程序不会缩小现有文件系统，任何双启动的用户都必须先从另一个操作系统腾出空间。所有内容都落在支持回滚的 ZFS 上，加密是可选的。

桌面就是 Omarchy 本身，仅做了 FreeBSD 所需的更改后移植过来，它运行在每日更新的快照上，每个镜像都固定到一个快照。

Wi-Fi 面板由相关组件支持，并使用 PipeWire 处理声音。蓝牙也可通过 FreeBSD 的蓝牙栈用于键盘和鼠标。

应用程序来自 FreeBSD 自己的软件包，使用 pkg 安装。Chromium 已预装。仅限 Linux 的应用暂时被搁置，直到特定版本在 FreeBSD 的 Linux 兼容层下经过测试。

Jails 为你提供携带自己软件包的隔离 FreeBSD 环境，而 bhyve 这个内置虚拟机监控程序则运行 Linux 和 Windows 等客户机虚拟机。

而且，如果你通过 Omarchy 的更新进行升级，它只会将更新应用于你的应用程序，而不动 FreeBSD 基础和内核。Daemonarchy 自己的软件包来自一个已签名的仓库，修复会在 ISO 版本之间发布。

壁纸、字标和登录主题都是项目自己的创作。

发布版略低于 2 GiB。使用 dd 将其写入 USB 驱动器，然后从中启动。

安装过程中需要互联网连接，因为安装程序会在进行过程中下载许多软件包。源代码位于 GitHub 上。
