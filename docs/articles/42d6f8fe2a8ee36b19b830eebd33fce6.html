Ubuntu 26.10 为戴尔 XPS 14 上的英特尔 Panther Lake 带来性能提升

2026 年 11 月 24 日东部时间上午 10:35。

搭载英特尔酷睿 Ultra 系列 3“Panther Lake”的新款戴尔 XPS 14 现已预装 Ubuntu 26.04 LTS 发售。对于不介意使用官方支持或长期支持（LTS）版本的用户，升级到新的 Ubuntu 26.10 可为 Panther Lake 带来额外的 CPU 和集成 GPU 性能提升。

上周我们发布了戴尔 XPS 14 在 Ubuntu 26.04 LTS 下的评测（https://www.phoronix.com/review/dell-xps-14-panther-lake），并与其他笔记本在该 LTS 版本上进行了对比。对于想了解升级到 Ubuntu 26.10 能获得何种提升的用户，本文展示了这台 Panther Lake 笔记本上 Ubuntu 26.04 LTS 与 Ubuntu 26.10 的性能对比。对于坚持使用 Ubuntu 26.04 LTS 的用户，升级后的内核、Mesa 组件及其他构成硬件启用“HWE”栈的部分也将在 2027 年 2 月的 Ubuntu 26.04.2 LTS 中回移。

用于测试的戴尔 XPS 14 DA14260 评测机配备英特尔酷睿 Ultra X7 358H、32GB LPDDR5-9600 内存、铠侠 512GB NVMe SSD，以及驱动 2880 x 1800 显示面板的集成 Arc B390 显卡。

Ubuntu 26.04 LTS 默认搭载 Linux 7.0 内核、GNOME Shell 50、Mesa 26.0.8、GCC 15.2 以及今年早些时候的其他默认组件。上个月发布的 Ubuntu 26.10 则搭载 Linux 7.3 内核、GNOME Shell 51、Mesa 26.2 图形栈、GCC 15.3 及其他更新组件。让我们看看这一软件升级对戴尔 XPS 14 性能的影响。
