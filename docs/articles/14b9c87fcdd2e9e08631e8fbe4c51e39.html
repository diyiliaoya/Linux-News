Darling 项目拥抱 AI 以在 Linux 上运行 macOS 二进制文件

Darling 是一个旨在 Linux 上运行 macOS 二进制文件的兼容层项目。该项目现已采纳 AI 辅助贡献规则，借助大语言模型弥补开发资源不足，甚至通过 AI 生成的补丁让《英雄联盟》macOS 版在 Linux 上运行。项目还初步支持了 ARM64 架构，并正将相关分支的补丁合并到上游。

Darling 是一个正在开发中的软件项目，旨在 Linux 上运行 macOS 二进制文件。这个 Linux 的 macOS 兼容层如今正迎来更活跃的发展，因为它转向利用 AI/大语言模型来协助开发。

Darling 已采纳了 AI 辅助贡献的规则。他们认为大语言模型可以成为非常强大的工具，鉴于其开发团队规模小、资源非常有限，这对他们很有益处。

“AI 改变了局面。过去只有少数贡献者时无法解决的问题，现在在经济上变得可行，这让我们能在更接近平等的条件下与 Apple 竞争。

该政策是我们如何负责任地使用这种力量的方式。它被写成给 AI 代理的指令，但也约束使用它们的人类。任何提交拉取请求的人都要对其中的每一行负责，并且必须能用自己的话解释它；维护者的问题由人来回答，而不是由机器人回答。其余部分体现了我们的净室规则：实现文档化的契约，而不是为单个应用打补丁；尊重 macOS 的分层；隔离并标记未文档化的怪癖；绝不使用泄露材料或 Apple 的受限源代码，例如 corecrypto。任何人都不应使用反汇编来生成匹配的代码。”

通过 AI 生成的补丁，他们甚至让 macOS 版的游戏《英雄联盟》在 Linux 上运行起来。今年出现了各种拥抱 AI 生成代码的 Darling“分支”，现在他们正努力将这些补丁合并到上游 Darling 中。

Darling 开发者还推出了对 ARM64 的初步支持。
