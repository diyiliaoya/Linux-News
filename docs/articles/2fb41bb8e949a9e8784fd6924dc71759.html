Automake 1.20 带来新功能，希望重建 GNU 作为领先构建系统的地位

发布于 2026 年 11 月 7 日美国东部时间上午 10:22。

GNU Automake 1.20 今日发布，带来新选项并改用 GPLv3+ 许可证。

在此版本之前，Automake 一直采用 GPLv2 许可证。现在 Automake 采用 GPLv3 或更高版本（GPLv3）。这与 Autoconf 保持一致，也符合自由软件基金会推荐使用 GPLv3+ 许可证的建议。

新选项用于让编译器和链接器继承 GNU make 的管道作业服务器，例如 GCC 的 -flto=jobserver 模式用于链接时优化。

Automake 1.20 还新增了“delete-on-error”选项。使用该选项会在生成的 Makefile.in 文件中发出一个特殊目标，指示 GNU Make 在其配方失败时删除该目标。

Automake 还新增了一个目标，用于列出相关文件。

GNU Automake 1.20 还附带各种缺陷修复。

Kamila Szewczyk 在 GNU Automake 1.20 发布公告中表示，希望将 GNU 构建系统重新确立为新软件项目的“首选构建系统”。考虑到如今 CMake 和 Meson 的采用速度，这将是一个艰巨的目标。

“新功能包括 `--enable-jobserver'，让编译器和链接器可以访问 GNU make 的 jobserver，delete-on-error 选项，以及 print-distfiles 目标。distcheck 默认不再需要 TeX。此版本还修复了一些长期存在的缺陷和限制，涉及依赖跟踪、VPATH 构建中的 lex/yacc 输出、Vala 构建、分发压缩和卸载检查。此外，GNU automake 已从 GNU GPLv2（或更高版本）许可证升级到 GNU GPL v3（或更高版本）许可证。

我对整个 GNU 构建系统（`autotools'）有大量计划。我打算继续解决旧问题和限制，并在 GNU Automake 中添加新功能，慢慢将其拖向未来。我的最终目标是再次将其确立为新软件项目的首选构建系统，同时继续简化现有用户的维护和可移植性。希望即将发布的版本能让我们越来越接近这一目标。”
