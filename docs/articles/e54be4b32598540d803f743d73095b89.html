Orion 浏览器 Linux 版在测试版发布数月后遭砍

Kagi 宣布终止 Orion 浏览器 Linux 版的开发，距其公开测试版发布仅数月。该原生 GTK 移植版于 2025 年公布，目标是与 macOS 版功能对齐，但未能实现。Kagi 计划将 Linux 版及 Windows 移植版代码开源，交由 FOSS 社区推进。macOS 和 iOS 版开发不受影响，Linux 测试版将不再更新，Kagi 不建议将其作为日常主力浏览器使用。

Orion 浏览器 Linux 版在测试版发布仅数月后遭砍

Kagi 宣布将终止 Orion 网页浏览器 Linux 版的开发。

Orion for Linux 的原生 GTK 移植版于 2025 年公布，公开测试版于今年早些时候发布。目标是实现与 macOS 版本的功能对等。近期的测试版发布已逐渐接近这一目标，但遗憾的是，最终未能达成——而事情就将止步于此。

Kagi 表示，计划将 Orion for Linux 的代码库以及 Orion for Windows 的进行中移植版开源。这或许能让 FOSS 社区有机会接手并“将它们推向前进”——不过开发一款独立的网页浏览器绝非易事。

“构建跨平台浏览器通常是由风险投资支持的公司或大型开源社区来完成的工作”，它在一份声明中表示，并补充说 Kagi 两者都不是，仅拥有少数几名由付费搜索引擎用户资助的开发者。

如果 Kagi 像大多数现代浏览器那样基于 Chromium 构建，本可以让事情轻松许多。Kagi 表示，它认为网络“需要不止一个引擎”，理想情况下，也需要不止一家公司能够塑造网络的样貌。

我认为 macOS 上的 Orion 是一款扎实的浏览器，我曾希望，尽管任务艰巨，Kagi 团队拥有足够的技术和想法来完成它——无论进展多么缓慢。

Orion for Linux 终于要开源了

Orion 从一开始并非开源，这让 FOSS 社区中的一些人对它失去了热情。如今它即将开源，这算是一个苦乐参半的消息。

Kagi 的商业模式（即由用户资助，因而只为用户构建）本意味着浏览器是为用户开发的，无需在界面中塞满吸引注意力的花招，也无需整合合作伙伴交易来提升收入。

从某种意义上说，正是这种商业模式将 Kagi 的焦点拉回了 macOS 和 iOS 版的 Orion：那才是其用户所在之处。

希望将其现有成果开源的决定，能以某种形式推动 Orion 向前发展，或至少让其组成部分被其他独立浏览器项目借鉴利用。

macOS 和 iOS 版 Orion 的开发不受此变更影响，但 Linux 测试版将不再获得更新。如果你已安装，可以继续使用，不过 Kagi 表示不建议将其作为日常主力浏览器，因为安全问题将不再修补。

Kagi 表示将在未来一个月内分享有关代码库开源的更多细节。
