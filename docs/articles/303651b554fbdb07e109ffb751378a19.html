Ubuntu 26.10 搭载基于 Rust 的 OpenPGP 工具

Ubuntu 26.10 默认预装了基于 Rust 的 Sequoia PGP，与 GNU 版本并存，为未来逐步淘汰 GnuPG 做准备。Canonical 还将其仓库迁移以提供官方支持。此外，该版本还默认包含完整的 Rust 核心工具集，并计划在后续版本中进一步用 Rust 重写基础组件，如 NTP 客户端。

Ubuntu 26.10 将基于 Rust 的 Sequoia PGP 加入默认安装

Ubuntu 26.10 搭载了基于 Rust 的 OpenPGP 实现，并计划在未来的版本中逐步淘汰 GnuPG。

Sequoia PGP 已被纳入 Ubuntu 26.10 的默认种子（即预装），Canonical 还迁移了其仓库，以便为其提供官方支持。

但它不会成为该发行版的默认 OpenPGP 工具链——至少目前还不会。Sequoia PGP 与标准的 GNU 版本一同开箱即用。Canonical 计划在不久的将来将其设为默认，从而“逐步淘汰”基于 C 的 GNU 版本。

目前，GnuPG 仍然会被调用，但 Sequoia（或配置为使用 Sequoia 库的应用程序）会调用 Sequoia。新版本可以通过命令行等方式运行以进行尝试。

Canonical 表示，采用 Sequoia 将使 Ubuntu 能够提供 OpenPGP 互操作性，同时受益于 Rust 版本所提供的“更易维护且内存安全的基础”。

其他 Ubuntu Rust 变更

这也不是新 Ubuntu 版本中唯一与 Rust 相关的变更。Ubuntu 26.10 开箱即用地提供了一套完整的基于 Rust 的核心工具集，完成了始于 25.10 的工作。

Canonical 的工程师计划在未来的版本中“氧化”更多基础软件包。Rust 重写的网络时间协议（NTP）正被考虑作为 Ubuntu 27.04 的默认时间同步客户端。

该公司还是 Trifecta Tech Foundation 的黄金赞助商，每年支付 4 万欧元以资助 Rust 软件的相关工作。
