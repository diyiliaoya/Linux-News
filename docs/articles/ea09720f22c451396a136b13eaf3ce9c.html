Ubuntu Core Desktop 在 27.04 之前“加速”开发

Canonical 宣布加速开发基于 snap 的不可变桌面系统 Ubuntu Core Desktop，并成立新团队，计划在明年 27.04 发布前提供每日构建。初期聚焦浏览器工作流、开发者工作站等用例，但面临桌面栈 snap 化、应用缺口及兼容替代打包系统等技术挑战。长期目标是使其成为 Linux 应用和 Ubuntu 桌面的默认体验。

Canonical 宣布正在“加速”开发 Ubuntu Core Desktop，这是其基于 snap 的不可变桌面操作系统版本。

Ubuntu Core Desktop 曾以预览形式供爱好者尝试。但缺乏明显进展和方向（更不用说最新的构建版本）让许多人怀疑 Canonical 是否对这个想法降温了。

不要指望很快出现奇迹。

创建全 Snap 的 Ubuntu 体验并与经典的基于 Deb 的桌面相当并非易事。首先，整个桌面栈需要做成模块化的 snap，以便各部分可以替换（KDE Plasma 桌面也将可用）。

还有一个“应用缺口”问题。人们日常计算所依赖的大量流行 Linux 软件并未在 Snap Store 中提供——无论是官方还是非官方，或者提供了但并非所有功能都可用，等等。

这并不简单地是“制作 snap 版本”的问题，尤其是开发者会希望访问替代打包系统，甚至 Flatpak，虚拟化和容器化需要以用户不会感到困惑的方式加以考虑。

此外，标准桌面构建提供的其他功能，沙盒化、不可变的桌面不应该提供。

简而言之，许多技术挑战挡在路上——但有人称之为有趣的部分！

Ubuntu Core Desktop 默认？

Seager 表示，长期目标是让 Ubuntu Core（以及在一定程度上 snap）成为“Linux 应用程序和工作流的事实目标，以及桌面、数据中心和边缘的默认 Ubuntu 体验”。

Seager 说，Ubuntu Core Desktop 将提供“更安全、更有弹性、更可信且面向未来的 Ubuntu”，用户将“在使用中尽情享受”。
