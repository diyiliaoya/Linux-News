systemd 合并对 Rust 程序的支持

systemd Git 仓库现已支持用 Rust 编写 systemd 程序，作为 C 语言的替代方案。核心库暂不支持 Rust，但各叶组件已可使用 Rust（无需 Cargo）。首个 Rust 组件 systemd-keyring-setup 用于在启动时配置密钥环并注册 X.509 证书，其代码尚未合并但预计很快。现有 C 代码不会移植到 Rust，Rust 支持为可选，默认自动检测，预计随 systemd 263 发布。

截至今日，在 systemd Git 中，systemd 程序现在可以用 Rust 编程语言编写，作为 C 语言的替代方案。

像 systemd 库这样的核心 systemd 代码尚不支持 Rust 代码，但对于各种 systemd 程序/叶组件，现在已经支持使用 Rust。这是不使用 Cargo 的 Rust。对于核心 systemd 代码中的 Rust，还有一些 Rust 阻碍需要首先解决。

systemd 对 Rust 的支持始于一个新组件 systemd-keyring-setup，它是用 Rust 编程语言编写的。新的 Rust 版 systemd-keyring-setup 实用程序用于在启动过程中配置密钥环并将 X.509 证书注册到内核的 dm-verity / fs-verity / BPF 密钥环中，并在之后处理它们。

这个 systemd-keyring-setup 代码尚未合并，但预计很快会合并，因为 Rust 基础设施已经落地。最初它全部是一个大提交的一部分，后来为了 Rust 启用、systemd-keyring-setup 以及这个新组件的其他准备工作而被拆分。

systemd 开发者不打算将现有的 C 代码移植到 Rust，所有 Rust 代码都用 Meson 构建，不使用 Cargo，并且只要求 C 链接。

systemd 的 Rust 组件比 C 版本略大，一个测试程序为 32KB，而其 C 版本为 20KB。至少目前，systemd 的 Rust 支持是可选的，由 Meson 选项切换，默认值为 auto。
