Firefox 155 新增两项改进，加速网页浏览

Firefox 155 作为最新稳定版发布，带来了两项关键技术改进：支持 QUIC v2 和 Happy Eyeballs v3。前者优化了 HTTP/3 连接，减少握手往返次数；后者通过并行尝试多种网络路径，加快网页加载速度。此外，Firefox 155 是唯一支持完整版 uBlock Origin 的非 Chromium 浏览器，因为谷歌已从 Chrome 商店移除该扩展。其他新功能包括 AI 聊天机器人集成（限美、加、法用户）、地址栏显示被拦截跟踪器数量等。Linux 用户可通过官方仓库或 Mozilla 服务器下载更新。

Firefox 155 新增两项改进，加速网页浏览

除了速度更快，Firefox 155 还是唯一支持 uBlock Origin 的非 Chromium 浏览器，因为谷歌昨天已将其移除。

以非常低调的方式，Firefox 155 作为这款注重隐私的流行网络浏览器的最新稳定版已经到来。

虽然此版本包含一系列改进，但我们将重点关注两项改变 Firefox 处理网页加载方式的技术改进。

HTTP/3 的 QUIC v2 支持

Firefox 现在不再只测试一条路径并希望它有效，而是同时尝试多种方式访问网站，并选择最先响应的那个。无需开启任何设置，也无需配置。你只会注意到，当 Firefox 在寻找真正连接到网站的方法时，那些一直加载不出来的页面变少了。

你看，每次 Firefox 加载页面时，它首先必须决定如何到达其背后的服务器。而且通常有不止一种选择：IPv4 地址、IPv6 地址，有时两者都有，并且根据网站的不同，还可以在 HTTP/2 和更新的 HTTP/3 之间选择。旧版 Firefox 会选择一个选项，然后等待看它是否有效，再尝试下一个，因此如果第一次猜测缓慢或失败，页面就会一直停留在那里而不加载。

Happy Eyeballs v3 改变了这一点。Firefox 会同时沿多条路径发起连接尝试，并采用最先到达的那条，而不是在开始时只提交一个猜测。

官方来说，Happy Eyeballs v3 是一个互联网草案，而非最终 RFC，由苹果和谷歌的工程师编写。Mozilla 自己针对此版本的开发者说明将该功能描述为“目前仅在某些平台上支持”，但没有指明是哪些平台。

QUIC v2 是当今网站加载速度背后的关键技术之一，Firefox 155 增加了对“稍新版本”的支持。真正重要的不是新版本本身，而是 Firefox 可以“立即切换”到它，跳过了两台计算机在无法立即就使用哪个版本达成一致时通常发生的来回协商。

这种来回协商过去常常需要额外的一次互联网往返。现在不需要了。

HTTP/3 是在浏览器和网站之间传输数据的最新协议版本，它运行在 QUIC 上，而不是较旧的 TCP 上。通过 QUIC 建立安全连接只需一次往返，而不是多次，这是 HTTP/3 在不稳定连接上感觉更快的重要原因。

这是切换的最佳时机

安装了 uBlock Origin 的 Firefox。

这是切换到 Firefox 的最佳时机。uBlock Origin 的完整版自 2025 年 7 月谷歌禁用 Manifest V2 以来在 Chrome 上一直无法使用，而昨天谷歌将其从 Chrome 网上应用店完全移除。

当然，Firefox 从未真正受到谷歌行为的影响，一直支持完整的 uBlock Origin 体验，其广告拦截能力没有任何削弱。你可以通过官方发布页面获取其最新版本。

Firefox 155 版本还有许多其他新增功能，包括 AI 聊天机器人集成（仅限居住在美国、加拿大或法国的用户）、地址栏中显示被拦截的跟踪器数量，以及重新排序容器的功能。这些都可能进一步促使你从 Chrome 或其他基于 Chromium 的浏览器切换过来。

Firefox 155 的二进制文件已经可用，不过官方下载页面尚未更新到新版本；应该很快就会更新。如果你等不及，想现在就获取此版本，虽然我建议等待，但你可以直接下载。

你的 Linux 发行版应该很快就会提供新版本。最好通过官方发行版方式获取更新。

Mozilla 服务器已经有适用于 Linux 的 155.0 构建版本。记得选择正确的平台和语言选项，以获取适合你电脑配置的软件包。
