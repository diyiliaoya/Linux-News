Firefox 158.0.1 发布，包含重要安全修复

Mozilla 发布 Firefox 158.0.1，主要修复了属于 eMudhra 证书机构的八个中间证书私钥泄露问题，防止攻击者伪造证书进行中间人攻击。此外还修复了文本选择时页面跳转、内置 VPN 无法激活、Linux 多显示器窗口位置错误以及 JPEG XL 格式半透明区域过暗等问题。更新已推送，各平台用户将陆续收到。

Mozilla Firefox 158.0.1 正在推出，包含一些重要的安全修复。

通常我不太会报道 Firefox 的小版本更新，因为它们主要修复的是大多数用户根本不会注意到的细微问题。但这次更新比往常更有“料”。

本次更新涵盖的是属于 eMudhra 证书机构的八个中间证书，其私钥已被泄露。任何持有这些密钥的人都可以签发浏览器视为真实证书的任意网站证书。如果他们还能拦截用户的连接，就可以冒充该网站并读取或篡改流量。

大多数 Firefox 用户已经受到保护，因为 Mozilla 在 10 月 17 日（接到通知后数小时内）通过 OneCRL 在后台撤销了这些证书。即便如此，Firefox 158.0.1 仍将撤销信息打包进本次更新。那些网络策略或其他设置禁用了 OneCRL 更新的用户，在升级到此版本后也能得到保护。

此版本中的错误修复解决了常见的一系列问题，包括：

- 选择文本时网站跳转到页面顶部

- 部分用户无法激活内置 VPN

- Linux 多显示器设置下 Firefox 窗口出现在错误的显示器上

- 某些 JPEG XL 格式的半透明区域显示过暗

该更新已经上线。如果你在 Windows 或 macOS 上使用 Firefox，或运行 Linux 二进制版本，下次运行时将在应用内收到更新。如果 Firefox 是从软件仓库或替代商店安装的，则需要手动安装。

使用 Firefox Snap 的 Ubuntu 用户将在后台自动收到此更新，并在下次重启应用时生效。
