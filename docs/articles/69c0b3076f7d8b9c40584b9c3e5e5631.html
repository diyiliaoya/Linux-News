Ubuntu 26.10 将搭载 Linux 内核 7.3

Canonical 将 Ubuntu 26.10 的目标内核从 Linux 7.2 调整为 Linux 7.3，原因是上游内核开发进度略早于预期。Linux 7.3 已发布第二个候选版本，预计10月底成为主线稳定版。Ubuntu 26.10 代号“Stonking Stingray”，将于10月15日发布，届时可能仍基于候选版本内核，后续通过软件更新完善。Ubuntu 26.04 LTS 用户可通过明年初的 HWE 更新获得同款内核。

Ubuntu 26.10 将搭载 Linux 内核 7.3

Ubuntu 26.10 将获得比原计划更新的内核，因为 Canonical 已将其目标从 Linux 7.2 切换到了 Linux 7.3。

这一重新考虑是由于八月初的进展略早于预期。那原本是 Ubuntu 工程师们为“Stonking Stingray”计划搭载的版本。

Ubuntu 的内核选择政策旨在每个 Ubuntu 版本发布时搭载正在开发中的上游内核，这可能意味着使用尚未“稳定”的内核——只要在内核选择截止日期时有候选版本构建可用即可。

Linux 7.3 本周发布了第二个候选版本，有望在十月底成为下一个主线（稳定）内核版本。

因此，Canonical 的内核团队表示，他们“重新评估”了 Ubuntu 26.10“Stonking Stingray”版本的目标内核，并正在“升级”将 Linux 7.3 作为首选候选。

Canonical 的 Kleber Souza 补充道：“此次更新使我们与最新的上游能力保持一致，特别是在最新硬件支持方面，同时仍能按计划推进我们即将到来的发布里程碑。”

截至撰稿时，Ubuntu 26.10 的每日构建仍运行在 Linux 7.2 上，但 Souza 表示团队正在“努力在 7.3-rc1 上游内核之上启用所有 Ubuntu 专属功能”。它应该可以通过 26.10 每日构建进行测试。

Linux 7.3 不太可能在 10 月 15 日 Ubuntu 26.10 发布时已经稳定，但内核“候选版本”构建相当稳健。任何最终的修复或更改都将通过软件更新推送。

更新的不一定总是更好，但就内核对新硬件的支持、更好的性能和安全性修复而言，嗯，它当然不会有坏处。

如果你使用的是 Ubuntu 26.04 LTS，你将能够通过下一次 HWE 更新获得相同的内核，该更新预计在明年初（2027年）Ubuntu 26.04.2 点版本发布前后推出。
