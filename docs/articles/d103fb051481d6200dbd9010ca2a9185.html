Linux 7.2 最佳特性：缓存感知调度、AMD Zen 6、AMDGPU HDMI 2.1 FRL

Linux 7.2 内核即将发布，带来了多项令人兴奋的新特性。其中，缓存感知调度（Cache Aware Scheduling）可显著提升多 LLC 域系统的性能；对 AMD Zen 6 处理器的支持已基本完善；AMDGPU 驱动初步支持 HDMI 2.1 FRL（默认禁用），并合并了 DC 电源模块以改善功耗表现；此外，还新增了 ISP4 驱动以支持高端 AMD Ryzen 笔记本的摄像头。Intel 方面，初步支持 Panther Lake R 等新平台。Apple M3 设备获得基础支持，但完整支持需等到 7.3。其他改进包括 USB4STREAM 协议、MGLRU 优化、WiFi 8 准备等。

Linux 7.2 最佳特性：缓存感知调度、AMD Zen 6、AMDGPU HDMI 2.1 FRL

发布于 2026 年 8 月 13 日下午 3:57（美国东部时间）。

该内核预计将于 8 月 16 日（周日）发布，以下是这个即将被 Ubuntu 26.10 及其他即将发布的 Linux 发行版采用的新内核版本中最有趣的新特性和变更。

**缓存感知调度**

对于运行在拥有多个最后一级缓存（LLC）域的现代系统上的用户来说，这无疑是新内核中最令人兴奋的特性之一。对于某些工作负载，缓存感知调度可以带来非常显著的性能提升，正如之前的基准测试所示。

**AMD Zen 6 支持**

Linux 7.2 继续为 AMD 的处理器做好准备，这些处理器最近随 EPYC 9006 "Venice" 系列发布，并将在未来几个月内应用于下一代台式机和笔记本电脑。仍有一些 Zen 6 补丁在流传，但主线内核支持现在似乎已经为所有标准功能做好了充分准备。

**AMDGPU HDMI 2.1 FRL**

对于 AMD 显卡，有初步的 AMDGPU HDMI 2.1 FRL 支持，尽管在此内核版本中默认禁用，并且 HDMI 2.1 规范的其他功能（如 VRR 和 ALLM）未包含在此内核版本中。AMDGPU 驱动还合并了 DC 电源模块，以更好地匹配 AMD Radeon 显卡在 Linux 下的功耗行为。

**ISP4 驱动**

AMD 方面另一个令人兴奋的是 ISP4 驱动被合并，用于支持 HP ZBook Ultra G1a 及其他即将推出的高端 AMD Ryzen 笔记本电脑上的网络摄像头。很高兴看到这个现代 AMD 图像信号处理栈终于整合在一起。

**Intel 支持**

Intel 方面，初步支持加固型 Panther Lake SoC "Panther Lake R"，更多 Diamond Rapids 和 Nova Lake H 的准备，TDX 运行时更新，以及其他增强。

**Apple M3 支持**

Linux 7.2 还提供了对 Apple M3 设备的初步支持，尽管 M3 Pro / Max / Ultra 的支持要到 Linux 7.3 才会到来。此外，这种 Apple M3 支持非常基础，仅能启动到控制台，没有更多功能。这些较新的（尽管已经落后两代）Mac 要在主线 Linux 内核上运行得更好，还需要一段时间。

**其他性能优化**

Linux 7.2 还为某些 Intel 图形硬件带来了各种性能优化，享受更好的性能；MGLRU 改进为 MongoDB 带来了可观的收益；前面提到的缓存感知调度；以及更快的读取速度。

**WiFi 8 准备**

Linux 的 WiFi 8 准备工作也在继续，Intel IWLWIFI 驱动正在进行相关工作，以及其他围绕 WiFi Aware 和 UHR 的 Linux WiFi 基础设施。

**USB4STREAM 协议**

Linux 7.2 的一个巧妙新功能是 Intel 开发的 USB4STREAM 协议，允许在 USB4/Thunderbolt 连接的系统之间快速发送数据包。

**更多详情**

有关此新内核中许多内核改进和其他变更的更详尽细节，请参阅 Linux 7.2 特性概览。此外，还移除了一些旧驱动/代码，例如 Hercules Monochrome ISA 显卡、Profibus 驱动、AF_ALG 已弃用、放弃对 ISA 和 PCMCIA 的 ARCnet 支持，以及其他旧驱动被移除。
