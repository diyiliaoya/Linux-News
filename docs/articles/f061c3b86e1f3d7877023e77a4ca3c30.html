Firefox 158 正式发布，默认支持 JPEG-XL

Firefox 158 正式发布，最大亮点是默认启用 JPEG-XL 图像格式支持，不再需要实验性选项。该版本还在智能窗口中支持更快速填充表单，并为开发者新增 CSS 类型化算术功能，允许 calc() 对不同单位但相同数据类型的值进行除法运算。

随着 Mozilla 对 Firefox 实行双周发布周期，Firefox 158 的发布二进制文件现已提供。Firefox 158 尤为引人注目的是终于默认启用了 JPEG-XL 支持。

Firefox 158 提供 JPEG-XL 支持！经过漫长等待，Firefox 158 终于准备好支持 JPEG-XL 图像，作为 WebP、JPEG、PNG 和 GIF 等格式的替代方案。图像请求的默认 HTTP Accept 头现在也支持 "image/jxl" 这一 JPEG-XL 图像格式。此前版本的 Firefox 中，JPEG-XL 需要通过实验性选项开启。

Firefox 158 现在还支持在智能窗口中更快速地填充表单，当点击表单字段或从来源中选择“填充”时即可使用。

在开发者方面，现在支持 CSS 类型化算术，可使用 calc() 等函数对相同数据类型但不同单位的两个值进行除法运算。更多 Firefox 158 开发者变更可在 developer.mozilla.org 查看。
