我们创建 Beehive Linux 的目标是提供一个快速、简单、安全的 i686 优化 Linux 发行版，没有多余的杂物和混乱。我们想要的是安装和设置都很快的东西，默认不包含 500 兆我们不需要或不想要的东西。并且内置原生 ReiserFS 支持。我们只是想要更好的东西。更紧凑。更干净。Beehive Linux 是一个由系统管理员制作、为系统管理员服务的发行版。它的意图是为工作服务器和工作站提供快速干净的设置。如果你在寻找向导和华而不实的小玩意，你来错地方了。如果你想用你和/或你的用户所需的服务来设置服务器，你来对地方了。Beehive 作为工作站也很好用，并且包含了 X、E、BlackBox 和 KDE——这不是 Beehive 的主要焦点，但嘿，每个管理员也需要工作站，对吧？Beehive Linux 不适合没有经验的人，或 Linux/*nix 新手。Beehive Linux 适合那些知道自己在做什么，并希望以最少的时间尽可能好地完成工作的人。
