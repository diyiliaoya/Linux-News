Linux Mint 发布两款全新桌面应用

Linux Mint 将在今年晚些时候推出两款新应用：日历应用 Clockenstien 和电子书阅读器 Book Reader，同时重新设计了文档管理工具 Library。新日历支持本地与在线同步，电子书阅读器提供类似 Kindle 的阅读体验，Library 则按文件类型分组管理文档。这些应用将随 Linux Mint 23 正式亮相。

Linux Mint 发布全新日历和电子书阅读器应用

今年晚些时候，Linux Mint 将迎来两款新应用：一款全新的日历和一款电子书阅读器。此外，这个基于 Ubuntu 的 Linux 发行版还重新设计了其（此前被忽视的）文档中心，以便更轻松地从一处查找和管理散落在设备各处的文档。

两款新应用均加入了 XApp 项目，这是 Linux Mint 自主开发的跨桌面 GTK 应用集合（目前带有 Claude 设计美学）。

Clockenstien 是 Mint 的新日历应用

——输入时请小心。

Clockenstien 是 Linux Mint 的新日历应用，但为了避免有人被这个糟糕的名字吓到，面向用户的标签只是“日历”。它终于加入了 Linux Mint 默认软件阵容（早该如此——之前的版本还是基于 GTK4/libadwaita 之前的旧构建）。

日历就是日历。它需要让你查看和浏览日期、添加事件、为不同任务创建日历——这些 Linux Mint 的旧日历也能做到。但与在线服务的集成很重要，因为我们大多数人白天会在不同设备间切换。因此，日历可以完全离线并保存在本地，也可以与 Google Calendar 等在线提供商同步，或通过 Nextcloud 等云服务使用 CalDAV 同步。

Clem 表示，目标是确保当远程日历无法工作或未同步时始终一目了然，这样用户就能知道是否出了问题。如果有一个重要事件你以为会收到提醒，却从未收到，静默失败是毫无帮助的。

“在实验室里，还有更多事情在发生”，

一个后台守护进程用于保持远程日历同步，并检查任何启用了提醒的即将到来的事件。如果出现问题，事件仍然可见，但会变为只读——你无法编辑或添加——直到连接恢复在线。

提醒通过通知代理处理。它们会在适当的时间显示在桌面上，以便你采取行动、稍后提醒或推迟。后端接口允许其他桌面环境交互或替换通知代理。

Book Reader 电子书阅读器

——简洁的渲染体验

Book Reader 应用是为打开 ePub 文件而设计的（意外吧）。它似乎提供了干净的阅读体验，Linux Mint 的 Clement Lefebvre 称其“类似于”Kindle 或 Kobo。它还会记录你在书中的位置，这样当你重新打开时，可以继续阅读。

功能方面，它提供了你期望的一切：章节和页面导航、全文搜索和书签，以及可调节的页面缩放和字体选项。注释功能让你可以用颜色高亮选中的文本，并添加笔记。

最后，一个内部查找系统让你可以选中一个词，并将其传送到搜索引擎（维基百科、词典等）以了解更多信息。

Library 重获新生

——个人文档中心

Linux Mint 还重新设计了其 Library 文档管理器，你可能通过包名“gnome-documents”知道它。

文档现在按文件类型分组，而不是按打开它们的应用分组。例如，你可以在一个视图中看到所有 PDF 文件，而不是在默认文档查看器打开的所有文件中四处寻找。

常见文件类型列在侧边栏中，但你可以选择显示哪些以及以什么顺序显示。更有用的是，你可以创建自己的自定义分组，包含不同文件类型的混合，甚至可以从特定文件夹中指定它们。

我什么时候能获得这些新应用？

这些应用将在 Linux Mint 23 中正式亮相，预计今年年底发布。该版本还将附带新的改进版。此外，团队迄今已披露和预告的其他变化（无疑还有一些尚未到来）。

如果你不想等待，源代码已在 GitHub 上（上面各段中均有链接）。你可以查看（双关语警报）以进行测试，并提交你发现的任何问题或你可能有的大功能请求。
