Linux 7.3 为 AMD Kaveri、Hawaii 及其他 GFX7 GPU 改进 GPU 重置恢复

AMDGPU 驱动在 Linux 7.3 合并窗口前获得了一系列新特性，其中最引人注目的是由 Valve 的 Timur Kristóf 贡献的 GFX7 系列 GPU 的软重置恢复补丁。该补丁利用 GFX IP 块软重置功能，使得 Kaveri、Kabini APU 以及 Hawaii、Bonaire 独立显卡在 GPU 挂起时无需重启系统或清空显存即可恢复，显著提升了用户体验。

Linux 7.3 为 AMD Kaveri、Hawaii 及其他 GFX7 GPU 改进 GPU 重置恢复

发布于 2026 年 8 月 3 日晚上 8:36（美国东部时间）。

除了上周提交给 DRM-Next 的 AMDGPU 特性拉取请求（其中包括针对旧款 AMD GPU 的 DRM 格式修饰符以及其他多项改进）之外，上周还提交了第二批 AMDGPU 特性工作，为即将到来的 Linux 7.3 合并窗口做准备。

Alex Deucher 于周五发送了一些针对 AMDGPU 驱动的额外特性更新，这些工作将在 Linux 7.3 合并窗口（大约两周后开启）之前，赶在新特性材料截止日期前合并到 DRM-Next 中。

这次后续拉取请求中最引人注目的是 Valve 的 Timur Kristóf 的更多工作。特别值得一提的是，其中包含一个重置补丁系列，用于在 GFX7 时代的硬件（如 Kaveri APU、Hawaii 独立显卡、Bonaire 独立显卡等）上使用 GFX IP 块软重置支持。Timur 在七月份解释道：

“GFX IP 块软重置已被实现为恢复方法，这样我们就可以在不重置整个 GPU 或丢失显存内容的情况下，仅重置 GFX 块。

修复了 GFX7 代码中的各种问题，使其能够与 IP 块软重置配合工作。主要挑战是修复 MQD/HQD 处理，确保软重置后不会挂起。还有其他一些小的修复。

重新设计了现有的 GFX7 软重置实现，类似于 GFX8 上的重新设计版本，使其更加健壮。实际上，这意味着现在它会重置 GFX IP 块中的所有内容（而不是猜测哪些部分需要重置），以保持一致性，并且现在还处理时钟和电源门控，以确保在 GFX IP 块软重置后不会降低 GPU 功能。

这改善了所有 GFX7 芯片的当前用户体验：

在 Kaveri 和 Kabini 上，目前没有可用的 GPU 恢复方法，因此这些芯片在挂起时需要用户手动重启计算机。

在 Hawaii 和 Bonaire 上，当前的 GPU 恢复方法总是清除显存内容，这意味着一个有 bug（挂起）的应用程序可能导致整个图形会话崩溃，这不太理想。

使用 GFX IP 块软重置意味着我们现在可以在 GFX7 APU 上实现有效的恢复，并且也可以在独立显卡上从 GFX 挂起中恢复，而不会导致整个系统崩溃。”

通过这个周末的 AMDGPU 拉取请求，这些针对老款 AMD Radeon 显卡的改进应该会成为即将到来的 Linux 7.3 合并窗口的一部分。这些针对 Linux 7.3 的 AMD 内核图形驱动的最后时刻特性补丁列表可以通过以下链接查看：
