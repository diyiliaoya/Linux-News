AMD ROCm HRX 的 Loom 0.2 扩展 C++ 支持并改进目标定位

发布于 2026 年 11 月 16 日美国东部时间晚上 08:37。

AMD ROCm 的 HRX Loom 作为支持 AI 代理工作流的编译器、运行时和服务基础设施，今日发布了新版本。

继上个月的首个版本之后，Loom 0.2 现已可用。这个新版本扩展了 C++ 程序支持、打包设备执行能力、原生 AMD GPU 启动与回放支持、大图管理、目标与 JIT 效率，以及各种其他改进。

在官方发布公告中，HRX Loom 0.2 被总结为：

“Loom 0.2.0 扩展了完整程序 C++ 编写、运行时提供的托管对象、有状态有限服务，以及打包的 AMD GPU/NPU 和 Vulkan 执行。它扩展了跨 x86、AIE2P、AMDGPU、SPIR-V 和 WebAssembly 的共享目标编译器，同时消除了 JIT 编译、图构建与更新、GPU 启动与回放、流水线规划和长上下文服务中的固定及超线性开销。”

很高兴看到跨不同硬件和基础设施的共享目标编译器改进。发布说明进一步阐述：

“Loom 工具、示例、服务、消毒器和硬件资格认证现在通过现有的 --device=amdgpu 拼写使用一个由 libamdf 支持的 AMD HAL。原生路径支持 RDNA 和 CDNA 执行、共享 CPU/GPU/NPU 内存契约、显式计算资源选择、协作执行、虚拟映射和可重用命令缓冲区。原先由 ROCr 支持的驱动、其 legacy-amdgpu 选择器及其独立的运行时和内存所有权路径已被移除。”
