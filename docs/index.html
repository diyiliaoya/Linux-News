Ubuntu 26.04 停止通知用户更新，但这是有意为之

Ubuntu 26.04 LTS 的更新通知突然消失，经调查发现是设计变更：更新通知器仅在托盘图标可见时发送通知，而该图标默认被关闭且无菜单可重新开启。非安全更新因此未被标记，但安全更新仍通过无人值守升级自动安装。修复补丁已作为安全更新发布，版本为 update-notifier 3.207.2，彻底移除了托盘图标依赖，确保安装、无人值守升级或手动检查均能触发通知。用户也可通过命令手动恢复托盘图标。
