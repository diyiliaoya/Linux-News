Ubuntu 26.10 加入 Windows 风格贴靠布局

Linux 内核 LZ4 压缩代码重新同步，以提升性能与代码整洁度

Linux 内核中的 LZ4 压缩代码将进行重新同步。目前内核中的 LZ4 代码是自 2017~2018 年以来未更新的上游分支。三星的 Michal Wilczynski 提交补丁，使内核可直接使用未修改的上游 LZ4 源码，不再维护分支。此举带来显著性能提升：EROFS 只读文件系统使用 LZ4 时，4K 簇吞吐量提升约 11%，64K 簇读取吞吐量提升高达 14%，其他内核内 LZ4 基准测试显示最高提升 21%。
