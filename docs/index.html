Linux 7.2-rc6 针对多款有问题的西部数据 SATA 硬盘实施规避措施

Linux 7.2-rc6 内核测试版合并了多项 ATA 修复，其中包括针对多款西部数据 SATA 硬盘的特定设备规避措施。这些硬盘因电源管理行为在 Linux 内核下无法正常工作，导致 SATA 总线离线或设备消失。修复方案是默认禁用这些硬盘的链接电源管理（LPM）功能。涉及的型号包括 WD100EFGX-68CPLN0（10TB Red Plus）和 WD102KFBX-68M95N0（10TB Red Plus Pro），以及 WD Green 2.5 480GB 硬盘。用户也可通过内核启动参数禁用 LPM，但会损失每块硬盘约 0.5~1.5W 的功耗节省。

GCC 编译器禁止 AI 代码贡献，但方式合理

GCC 指导委员会本周通过了新的 AI 政策，计划于 2027 年初进行审查。该政策规定，若贡献具有法律意义且部分内容源自大型语言模型，GCC 将不予接受。但允许维护者接受法律意义不大的 AI 生成贡献，前提是明确标记并符合项目标准。测试用例可豁免。政策仅适用于 GCC 本身，从其他项目导入的代码不受影响。AI 辅助贡献需在提交信息中添加“AI”标签。该政策比 Codeberg 的全面禁令更宽松，但比 Linux 内核的披露政策更严格。
