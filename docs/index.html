Intel 为 Battlemage 在 Linux 7.4 中带来重大改进

Intel 为即将进入 Linux 7.4 的 Xe 内核驱动提交了最后一批改进，核心是在迁移队列上实现 CPU binds 和 ULLS（超低延迟调度）。该改进可让 Battlemage 独显在持续处理 GPU 缺页时，拷贝任务快约 30–40µs，冷启动加速更明显，页错误基准测试持续提升数 GB/s。代价是功耗增加，但 ULLS 会在无缺页时自动退出以缓解。该补丁还修复了 Crescent Island 的 ULLS 并新增 Panther Lake 设备 ID。

Ubuntu 开发者 Gianpiero Carpinelli 正在为 Debian 的 APT 包管理工具添加 SHA3-256 和 SHA3-384 支持，以应对未来 SHA2 可能被破解的风险。相关代码已提交上游合并请求，SHA3 将作为 SHA2 的备选方案，但默认不启用。此举旨在确保 Ubuntu 24.04 LTS 在 2036 年支持结束前，若 SHA2 被攻破，系统能平滑迁移到更安全的哈希算法。
