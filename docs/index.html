Linux 7.4 的 Zstd 改进：避免冗余初始化

Usama Arif 提交了针对 Linux 7.4 的 Zstd 压缩补丁，旨在通过避免冗余的 cstream 和 dstream 初始化来提升性能。他发现首次初始化被丢弃且未处理任何数据，新补丁将流初始化推迟到首次遍历迭代。在 4KB crypto_acomp 基准测试中，压缩速度有单位数提升，解压速度在裸机上提升 13%，在虚拟机中提升 35%。补丁已进入加密子系统开发分支，预计将在 Linux 7.4 合并窗口提交。
