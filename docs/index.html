GCC 编译器禁止 AI 代码贡献，但方式合理

GCC 指导委员会本周通过了新的 AI 政策，计划于 2027 年初进行审查。该政策规定，若贡献具有法律意义且部分内容源自大型语言模型，GCC 将不予接受。但允许维护者接受法律意义不大的 AI 生成贡献，前提是明确标记并符合项目标准。测试用例可豁免。政策仅适用于 GCC 本身，从其他项目导入的代码不受影响。AI 辅助贡献需在提交信息中添加“AI”标签。该政策比 Codeberg 的全面禁令更宽松，但比 Linux 内核的披露政策更严格。

Nouveau 准备最终默认启用原子模式设置

Nouveau 内核驱动长期以来支持原子模式设置，但一直未默认启用。Red Hat 的 Lyude Paul 正在准备补丁，使 Nouveau 默认启用原子模式设置，至少对 NV50（GeForce 8 系列）及更新硬件生效。原子模式设置允许用户空间合成器/程序将完整硬件配置作为单个原子事务提交给内核，可减少屏幕闪烁并提高现代 Linux 桌面模式设置的可靠性。目前大多数 Linux 桌面软件和主要开源 DRM 驱动已支持该功能。补丁系列还强制在 NV50 以下禁用原子模式设置，并添加调试输出。预计该更改可能无法及时进入 Linux v7.3 周期，但希望不久后落地。
