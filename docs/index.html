Rhythmbox 3.5 让你跨应用同步播客收听进度

Ubuntu 将另一个系统 Deb 包转换为 Snap

Ubuntu 正在将其另一个核心系统 Deb 包转换为沙盒化的 snap 格式，以提升安全性并改善桌面集成。该包为 hwctl，是一个预装在 Ubuntu 桌面和服务器上的小型命令行工具。Canonical 工程师 Sergio Costas 表示，为了将 hwctl 与 gnome-control-center 及其他前端集成，并增强安全性，hwctl 包将仅以 snap 形式提供。在 Ubuntu 26.04 LTS 上，用户将自动迁移至 snap 版本，现有系统通过更新将 Deb 包替换为自动安装 snap 的虚拟包。Ubuntu 26.10 及更高版本将直接默认包含该 snap。

Denial WM：全新 Wayland 合成器，直接嵌入 Flutter

Denial 是一款全新的 Wayland 合成器，专注于 Arch Linux 的优化集成，并直接将 Flutter 引擎嵌入代码库。它使用 Rust 编程语言，并借助 Smithay 处理合成器职责。Denial 目前为 alpha 软件，其设计独特：不将 Flutter 作为应用运行在其他合成器之上，而是直接嵌入 Flutter 引擎，由 Rust 和 Smithay 合成器处理 Wayland 协议状态、输入、DMA-BUF、DRM/KMS 呈现等。应用缓冲区通过 EGL_EXT_image_dma_buf_import 导入为 GPU 纹理，无需 CPU 回读或像素拷贝。Flutter 直接渲染到 GBM 缓冲区用于 KMS 呈现，无中间渲染目标。开发者已将其作为日常桌面使用，支持原生 Wayland 应用、Steam 和 Proton 游戏、多显示器、音频、锁屏、屏幕共享等，并提供签名 Arch 包和 CI/CD。项目还保留了 Flutter 开发工作流，支持热重载和调试。
