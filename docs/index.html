Ubuntu 固件 HWE 将防止旧内核出现问题

Ubuntu 计划推出新的固件包方案，以解决 HWE 内核固件更新可能影响使用 GA 内核用户的问题。此前 Ubuntu 24.04 LTS 的固件回移植曾导致 Linux 6.9 GA 内核出现 AMD 回归问题。新方案让 HWE 内核使用独立的固件包，使 GA 内核用户继续使用标准固件集，同时两者在各自支持期内仍能获得针对性修复。Ubuntu 26.10 的固件包正被打包为 hwe 版本，预计 2027 年初回移植至 26.04。
