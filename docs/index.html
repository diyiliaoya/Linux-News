GNOME Shell 搜索重新设计采用浮动覆盖层

Linux Mint 将自动删除旧内核版本

Linux Mint 宣布对其内核管理进行全面改革，现在将每周自动删除旧内核。内核管理从系统管理工具中移出，并按系列而非单个版本跟踪内核。用户可以选择跟踪哪些内核系列，以及每个系列中保留的旧内核数量。受保护的内核不会被删除，自定义内核也可标记为受保护。手动清理按钮可立即释放空间，且提供已删除内核的列表。此更改可能通过软件更新到达现有用户，或随 Linux Mint 23 发布。
