AMD发布大规模补丁系列，在Linux内核中启用UALink

AMD工程师向Linux内核邮件列表提交了两个补丁系列，旨在为AMDGPU驱动引入UALink（超加速器链接）支持。UALink是一种开放标准的高速网络协议，用于连接数据中心内的GPU和AI加速器，支持单个域内最多1024个加速器。首个补丁系列约7000行代码，添加了核心基础设施和AMDGPU驱动集成，支持GPU间直接内存访问。第二个补丁系列包含三个补丁，暴露了新的IOCTL接口和文档。这些补丁展示了AMD在Linux内核中实现UALink的努力，有望提升AI工作负载的性能。
