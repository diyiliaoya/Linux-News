Linux Zswap 新补丁显示重大改进

Linux 开发者 Usama Arif 提交了两项 Zswap 补丁，旨在减少加载请求争用。补丁将压缩与解压缩的请求、等待和互斥锁分离，并在同步算法下使用栈上请求进行解压缩，从而避免加载路径获取 Zswap 锁。测试显示，单 vCPU 下最慢读取从 22.3 毫秒降至 0.97 毫秒，8 vCPU 下从 314 毫秒降至 7.0 毫秒，超过 10 毫秒的读取几乎消失。
