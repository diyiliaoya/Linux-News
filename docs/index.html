Linux 7.3 有望成为多年来最注重性能的内核版本之一

Linux 7.3 的合并窗口仍在开放，但已确认多项性能优化：存储方面，EXT4 和 XFS 文件系统通过 IOmap 反弹缓冲、日志与 fsync 修复、缓存 v2 等改进，大幅提升吞吐量；调度器方面，针对 AMD GPU 的调度优化和 Intel 混合 CPU 的集群感知调度修复，减少了卡顿；内存管理方面，修复了反向映射和 zsmalloc 的锁延迟问题；实时工作负载的延迟显著降低；RISC-V 新增多个 ISA 扩展支持。这些改进使 7.3 成为近年来最注重性能的版本。

Linux 7.3 TPM 为 TrenchBoot 进行清理准备工作

Linux 7.3 内核的 TPM（可信平台模块）子系统变更主要围绕代码清理和改进，为 TrenchBoot 支持铺平道路。TrenchBoot 是一个开源项目，利用硬件支持的动态信任根测量（DRTM）增强启动安全性和完整性。本次合并的 TPM 补丁由 Ross Philipson 提供，暴露了 TPM 常量，并解耦和增强了 tpm_buf 的健壮性，以实现最小化的早期 TPM 驱动。这些改动为未来 TrenchBoot 进入主线内核奠定了基础，即使 TrenchBoot 最终未能实现，TPM 驱动的清理也是有益的。
