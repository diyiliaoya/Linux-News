Arm 为 Linux 开发 "TLBID" 以提升高核心数 CPU 性能

Arm 本周发布了初始补丁集，为 Linux 内核添加 TLBI Domains（TLBID）支持。该功能允许仅对部分 CPU 核心执行 TLB 失效，而非全系统范围，从而降低高核心数 Arm 服务器处理器的开销。TLBID 尚未纳入 Arm 架构参考手册，且依赖 LLVM 23 或 GNU Binutils 2.46 以上版本，距离实际芯片应用尚需时日。
