Rhythmbox 3.5 让你跨应用同步播客收听进度

Rhythmbox 3.5.0 发布，这是该音乐播放器九个月来的首次更新。新版本引入了播客插件，支持通过自托管同步服务器（如 Nextcloud）在 Rhythmbox 与其他应用之间同步播客订阅和收听进度。播客页面也经过重新设计，显示已收听集数，并重新设计了通知。此外，歌词功能得到增强，默认从 lrclib.net 获取歌词，并支持读取 .lrc 文件或嵌入在 .ogg 文件中的歌词。最重要的变化是默认启用多流（multistream）后端，取代了 xfade，利用现代声音系统（如 PipeWire）进行混音，减少代码维护负担。同时修复了 2038 年时间问题。用户可通过 Flatpak 安装体验。

Ubuntu 将另一个系统 Deb 包转换为 Snap

Ubuntu 正在将其另一个核心系统 Deb 包转换为沙盒化的 snap 格式，以提升安全性并改善桌面集成。该包为 hwctl，是一个预装在 Ubuntu 桌面和服务器上的小型命令行工具。Canonical 工程师 Sergio Costas 表示，为了将 hwctl 与 gnome-control-center 及其他前端集成，并增强安全性，hwctl 包将仅以 snap 形式提供。在 Ubuntu 26.04 LTS 上，用户将自动迁移至 snap 版本，现有系统通过更新将 Deb 包替换为自动安装 snap 的虚拟包。Ubuntu 26.10 及更高版本将直接默认包含该 snap。

Zapscape：Linux KVM 客户机到宿主机逃逸及本地提权的最新漏洞

Zapscape 是一个影响 Linux KVM x86 代码的客户机到宿主机逃逸漏洞，自 2020 年内核变更引入，影响范围达六年。该漏洞源于影子 MMU 模拟代码中的释放后使用问题，攻击者可通过客户机操作使宿主机内核崩溃（DoS）或执行任意代码（RCE）。在 RHEL 等发行版中，/dev/kvm 为全局可写，非特权用户可利用此漏洞进行本地提权。该漏洞已于 7 月 21 日修复，并公开了概念验证代码。

Linux 7.2-rc7 恢复 Btrfs 修复工作线程基础设施以解决静默数据丢失

Linux 7.2 合并窗口期间，Btrfs 文件系统移除了 COW 修复机制，该机制用于检测没有有序 extents 的脏页。开发者曾认为内核内存管理层已解决相关问题，但实际导致静默数据丢失。为此，Linux 7.2-rc7 恢复了该修复工作线程基础设施，涉及 600 多行代码。SUSE 的 David Sterba 提交了相关补丁，Linus Torvalds 已接受。此外，本周还有其他 Btrfs 修复，包括编码 ioctl 写入泄漏、禁用高内存系统的大 folios 等。
