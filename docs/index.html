Linux 7.3 改进基于基准测试的 RAID 5/6 算法选择

Linux 7.3 内核将改进基于基准测试的 RAID 5/6 算法选择。该机制通过内核模块初始化时的内部速度测试，为 RAID5 和 RAID6 软件配置选择最优的 XOR 引擎及 RAID6 特定代码路径，以利用 AVX2 或 AVX-512 等硬件加速。本次更新包括启动时基准测试算法选择的多种改进、新增 XOR 和 RAID6 代码的 KUnit 基准测试覆盖，以及使用 4+1 磁盘进行更实际的负载计算，并报告数据磁盘而非仅奇偶校验磁盘的吞吐量。这些改动旨在提升 RAID 性能，尽管未提供量化数据，但任何增强都值得欢迎。

Linux 7.3 为上游化 FAMFS 文件系统做准备
