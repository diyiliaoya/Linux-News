PhotoCraft：一款开源、由AI构建的Photoshop克隆

Ubuntu 26.10 在安全启动下放弃 Btrfs、XFS 和 ZFS 的 /boot 支持

Canonical 调整了 Ubuntu 26.10 在启用安全启动时的引导方式，其签名的 GRUB 不再支持从 Btrfs、XFS、ZFS、LVM、LUKS 加密或软件 RAID 等文件系统读取 /boot，仅保留 ext4、FAT、ISO9660 和 squashfs。此举旨在减少引导链中的解析器数量，降低安全启动绕过漏洞的风险。禁用安全启动则不受影响，普通用户通常也不会受影响。
