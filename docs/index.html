Linux 7.3 有望成为多年来最注重性能的内核版本之一

Linux 7.3 的合并窗口仍在开放，但已确认多项性能优化：存储方面，EXT4 和 XFS 文件系统通过 IOmap 反弹缓冲、日志与 fsync 修复、缓存 v2 等改进，大幅提升吞吐量；调度器方面，针对 AMD GPU 的调度优化和 Intel 混合 CPU 的集群感知调度修复，减少了卡顿；内存管理方面，修复了反向映射和 zsmalloc 的锁延迟问题；实时工作负载的延迟显著降低；RISC-V 新增多个 ISA 扩展支持。这些改进使 7.3 成为近年来最注重性能的版本。
