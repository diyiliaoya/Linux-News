Linux 7.3 很可能成为下一个 LTS 内核

Linux 内核关键维护者 Greg Kroah-Hartman 在 Linux 内核邮件列表中表示，计划将 Linux 7.3 作为下一个长期支持（LTS）内核，除非出现意外阻碍。他反对为了成为 LTS 而强行向 7.4 添加功能，并指出过去这样做曾给维护者带来很多麻烦。LTS 内核提供至少两年的维护和重要修复回移。Linux 7.3 已随 Ubuntu 26.10 发布，并将于今年晚些时候回移到 26.04。
