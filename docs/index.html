Kmorph 旨在提供无需重启的 Linux 内核崩溃恢复

Kmorph 是一个新的开源项目，旨在为 Linux 系统提供无需重启的内核崩溃恢复。它基于多内核（Multikernel）技术，通过预先启动一个备用内核，在主内核崩溃时快速接管，实现约 2 秒的 Nginx 等服务恢复。该系统支持 x86_64 和 ARM64，并计划支持 RISC-V。目前 Kmorph 无法在主线内核上运行，其广泛采用取决于多内核代码能否进入主线。
