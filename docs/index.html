Rust 1.98 新增代数浮点方法，类似“-ffast-math”

Rust 1.98 版本发布，引入了针对 f32 和 f64 浮点类型的代数方法（如加法、减法、乘法、除法、取余），允许编译器利用实数代数性质进行优化，类似于其他语言中的 -ffast-math 选项。这些方法可能改变运算顺序以提升性能，但结果不确定且不保证与标准浮点运算一致。该特性源于 Rust 在 x86_64 上简单点积运算比 C++ 慢最多 8 倍的问题。此外，该版本还改进了整数格式化等功能。
