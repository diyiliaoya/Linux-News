Linux 7.3 的 IOmap 改进进一步提升 EXT4 与 XFS 性能

Linux 7.3 开发内核已合并 VFS 拉取请求，其中包含对 IOmap 框架的改进。IOmap 现已完全转换为迭代器模型，采用单一的 iomap_next() 回调，减少了间接调用，使编译器能生成直接且可内联的调用，从而提升性能。该改进尤其对 EXT4 文件系统的小型 I/O 操作带来显著提升，在 PCIe Gen5 NVMe SSD 上，4K 随机读性能从约 1.92M IOPS 提升至 2.19M IOPS，提升幅度在 4% 至 10% 之间，具体取决于 I/O 模式。此外，该更新也惠及 Btrfs、F2FS、XFS 等多个文件系统。
