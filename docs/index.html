Linux早期启动阶段物理内存分配器大幅提速：从约268秒降至约50毫秒

Linux 7.4内核的memblock改进中，Google工程师发现mm/memblock.c在查找候选区域时使用线性搜索而非二分搜索，在KHO功能导致严重碎片化时耗时极长。改用二分搜索后，最坏情况复杂度降至O(N log N)，KHO内存检索时间从约268秒缩短至约50毫秒。该优化已随Linux 7.4的memblock拉取请求提交。
