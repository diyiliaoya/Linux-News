补丁大幅提升内核Zstd性能，修复令人尴尬的低效问题

Linux内核邮件列表今日收到一组补丁，通过修复现有代码中一个非常不幸的疏忽，大幅提升了Zstd压缩和解压缩的效率。开发者Usama Arif指出，内核Zstd代码在每次创建压缩或解压缩上下文时，都会动态检测CPU是否支持BMI2指令集，而这种检测涉及两次序列化的CPUID指令，且每次操作都会执行，导致性能严重下降。通过仅检测一次BMI2支持，补丁在crypto_acomp基准测试中实现了解压缩时间减少71%、压缩时间减少18%的显著效果。
