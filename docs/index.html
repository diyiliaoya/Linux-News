Linux 7.4 将并行移除 NVMe 命名空间以提升速度

Linux 7.4 内核将合并一项 NVMe 优化：移除命名空间时改为并行处理。此前逐个移除每个命名空间需等待约 20 毫秒的 RCU 宽限期，64 个命名空间耗时超过一秒。新方案通过异步域并行移除，使宽限期重叠，显著缩短控制器断开等场景的耗时。
